    AI Agent 智慧代理

    讓 AI 不只是「問答機器」，而是能自主規劃、使用工具、完成複雜任務的「數位助理」

    什麼是 AI Agent？

    想像你有一個超級聰明的助理：

    • 你說「幫我訂明天去東京的機票」
    • 它會自己去查航班、比較價格、填寫表單、完成訂票
    • 而不是只告訴你「你可以去這些網站查」

    這就是 AI Agent 的概念——自主行動的 AI 系統。

    傳統 LLM vs AI Agent

    傳統 LLM AI Agent
    一問一答 多步驟規劃
    只能生成文字 能使用工具（搜尋、程式碼、API）
    被動回應 主動執行任務
    單輪對話 持續追蹤目標

    研究方向

    🎯 Agent 架構

    如何設計 Agent 的「大腦」？

    • ReAct：思考 → 行動 → 觀察 → 再思考
    • Plan-and-Execute：先規劃完整計畫，再逐步執行
    • Tree of Thoughts：探索多種可能路徑

    🔧 工具使用 (Tool Use)

    讓 Agent 能操作外部工具：

    • 搜尋引擎、計算器、程式碼執行
    • API 呼叫、資料庫查詢
    • 網頁瀏覽、檔案操作

    🤝 多代理系統 (Multi-Agent)

    多個 Agent 協作完成任務：

    • 分工合作（一個負責搜尋、一個負責寫作）
    • 角色扮演（模擬辯論、討論）
    • 階層式管理（主管 Agent 指揮多個工作 Agent）

    📊 Agent 評測

    如何評估 Agent 的能力？

    • 任務完成率：能否成功完成指定任務
    • 效率：完成任務需要多少步驟
    • 魯棒性：面對錯誤能否恢復

    🤖 具身智能 (Embodied AI)

    讓 Agent 控制實體機器人：

    • 機器人導航、物體操作
    • 人機互動
    • 現實世界任務執行

    🔍 Agentic RAG

    結合檢索與代理能力：

    • 代理決定「何時需要查資料」
    • 動態選擇搜尋策略
    • 整合多來源資訊
