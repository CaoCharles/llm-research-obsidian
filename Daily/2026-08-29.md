### [INTENT-AS-A-TOOL Makes it Easy to Track Agentic Misalignment](<../Papers/[2608.27348] INTENT-AS-A-TOOL Makes it Easy to Track Agentic Misalignment.md>)

`Safety & Alignment` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.27348

#### 中文摘要

隨著大型語言模型（LLM）被部署為自主 agents，安全失敗愈來愈涉及具後果的行動。本文研究 agentic misalignment：agents 在目標衝突與壓力下採取有害行動。作者以 chain-of-thought（CoT）monitoring 發現，有害執行通常 preceded by reasoning 中的意圖訊號；但事後 CoT 標註過於粗粒度，無法呈現意圖在生成過程中的變化。本文提出 INTENT-AS-A-TOOL，在 action space 加入針對特定行為的 intent tool，讓模型透過專用通道表達執行目標行為的承諾。呼叫 intent tool 的機率可作為不依賴 judge 的細粒度訊號，用於追蹤意圖、補密 CoT 標籤軌跡，並找出可線上介入的關鍵步驟。結果顯示，action preference 有助於在 reasoning 期間追蹤 agentic misalignment。

`Benchmark` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.27424

#### 中文摘要

靜態掃描器日益用於識別 machine-learning artifacts 中可執行或其他不安全內容，但傳統評估指標通常只描述掃描器成功產生可用安全判定的案例。本文以受控、由 artifacts 支持的 benchmark，評估 ModelScan、ModelAudit 與 Fickling。資料集包含 170 個聚焦 Pickle 與 PyTorch 的 artifacts，分屬 145 個 specimen families；其中 135 個具有二元安全 ground truth，另有 10 個刻意製造且不具標籤的 malformed artifacts。研究明確區分 non-N/A coverage、analysis completion、definitive security decisions、non-security findings 與 unsupported outcomes。在有標籤的 families 中，ModelAudit 對全部 135 個 family 產生 definitive decisions，Fickling 為 110 個，ModelScan 為 67 個。以產生 definitive judgment 的案例為條件，ModelScan 的 precision、recall 與 F1 均為 100%。Fickling 沒有超越 ModelAudit 與 ModelScan 組合的 unique true-positive families。對於 ModelScan 無法完成分析的 48 個 malicious families，ModelAudit 與 Fickling 均產生符合 ground truth 的 detections。結果顯示，必須分離 judgment accuracy 與 judgment availability，以及 incremental detection coverage 與工具層級的 redundancy。

#### 中文摘要

在真實軟體開發中，code review 通常由開發者與 reviewer 透過反覆互動共同改善軟體品質，因此成本高且耗時。雖然近期研究開始使用大型語言模型（LLM）自動化 code review，多數方法仍將其簡化為單輪、靜態的決策任務，無法呈現實際審查中的多輪互動與複雜問題解決過程。為彌補此缺口，作者提出 MCR-Bench，首個具備 defect state awareness、面向真實多輪 code review 的 benchmark。資料集涵蓋 Python、Java、JavaScript、TypeScript 與 C# 五種語言，包含 2,269 個真實多輪 code review tasks；每項任務皆標註細粒度 defect metadata 與跨輪 state labels，以記錄 defect 的完整演化軌跡。實驗顯示，主流 LLM 在 defect detection 與 defect lifecycle state tracking 上整體能力有限，且隨互動輪數增加而明顯退化；模型對不同 defect type 與 severity 的表現差異很大，語義複雜或不顯著的 defect 更容易被遺漏。錯誤分析進一步指出，跨輪時間錯位與不足的長程記憶是重要失敗機制。

### [Consolidating RLVR Capabilities Across Domains: A Deep Dive into Fusion Paradigms](<../Papers/[2608.27409] Consolidating RLVR Capabilities Across Domains - A Deep Dive into Fusion Paradig....md>)

`Benchmark` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.27409

#### 中文摘要

具可驗證獎勵的強化學習（RLVR）能提升大型語言模型在特定領域的能力，但若要涵蓋多種能力，通常需分別訓練 domain experts，再將其整合。本文依重用 artefacts 將融合方法分為三類：Merge 結合 expert task vectors；Mix RL 混合各領域資料集共同訓練；multi-teacher on-policy distillation（MOPD）同時使用 experts 與資料。作者在 4B 和 8B Qwen3 backbone、共用 experts、資料及多領域 benchmark 下進行比較。三者平均表現差距最多 1.4 分，但單一 benchmark 可達 8.6 分；領域差異與 task-vector geometry 所呈現的跨域關係一致。Mix RL 受資料比例影響，MOPD 受 teachers 表現上限約束，Merge 則將所有 expert updates 壓縮為單一更新。三者均提升 single-sample accuracy，但未觀察到 solution coverage 擴張或 held-out 能力損失。作者建議依 experts 是否已存在、成本與領域關係選擇方法。
