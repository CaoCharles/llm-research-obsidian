### [OwlSight: A Panoramic Monitor for Chain-of-Thought Reasoning](<../Papers/[2610.23670] OwlSight - A Panoramic Monitor for Chain-of-Thought Reasoning.md>)

`Safety & Alignment` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.23670

#### 中文摘要

Chain-of-Thought（CoT）監控可提供監督 AI 系統的可操作證據，具有及早偵測與介入的潛力。然而，現有方法多聚焦於特定任務；AI 監管，尤其是 reasoning models，則需要涵蓋更廣泛的任務。本文提出 Factor for CoT monitoring，允許透過 prompt 客製化監控要求，使單一 monitor 能依不同 Factor 覆蓋多種任務。作者進一步區分 fine-grained 與 coarse-grained Factors，例如分別監控特定 email 是否外洩，以及是否發生 privacy leakage，以滿足不同粒度需求。在此基礎上，作者建立 OwlSight，僅依賴 Factor 監控 capability、safety 與 trustworthiness 等多面向行為。跨 15,971 條 reasoning trajectories 的實驗顯示，OwlSight 在兩種粒度均優於 general-purpose LLM，並在 OpenAI CoT monitorability benchmark 達到 state-of-the-art。它也能泛化至未見過的模型 CoT，並對 Factor 改寫、CoT 壓縮與 obfuscation 保持一定穩健性。

### [ABF-Bench: A Verifiable Benchmark for Agentic Blockchain Forensics](<../Papers/[2610.23656] ABF-Bench - A Verifiable Benchmark for Agentic Blockchain Forensics.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.23656

#### 中文摘要

Blockchain forensics 具有對抗性且開放式：洗錢者會拆分、交換、跨鏈轉移資金，並在 mixer 或 custodial service 截斷軌跡、持續改變策略；調查者必須隨之調整追蹤方式。公共 ledger 的不可竄改性則保留所有已記錄的資金移動，使許多調查結論可獨立驗證。本文提出 ABF-Bench，一個互動式 benchmark，將有證據支持的資金追蹤轉化為可驗證的 agent 任務，要求每項聲稱的移動都引用 agent 實際取得的 ledger records。任務由真實洗錢活動建立，涵蓋多跳轉帳、DeFi exchange、跨鏈往返、custodial 與 mixer 存款及 address poisoning。作者另提出以 working memory 為核心的 ABF agent harness。其 edge recall 為 75%，高於相同模型的 Codex（47%）與 Claude Code（10%）；但 agents 常過早停止，在大型任務上的最終 recall 低於最佳 fixed-order tracer。

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.23745

#### 中文摘要

近年的大型 audio language models（LALMs）已從詞彙語音理解擴展至情緒辨識等副語言與非語言音訊理解任務。然而，當聲學線索與口語語言內容同時出現時，模型仍難以可靠運用聲學資訊。既有 benchmark 未能清楚區分聲學感知與高階推理，因此難以定位失敗來源。為此，作者提出 VocalGrad，一個評估 LALM 感知低階聲學變化能力的 benchmark。VocalGrad 將問題簡化為判斷聲學特徵隨時間增加或減少的二元分類，盡量排除高階推理與語意理解的影響。結果顯示，人類標註者表現優異，而最先進 LALM 幾乎接近隨機猜測。作者進一步以 linear probing 分析模型內部表徵，發現兩種失敗模式：部分類別的任務資訊仍保留於內部表徵，但未被 language model head 使用；另一部分類別的資訊則在模型層間逐漸變得難以線性解碼。整體而言，研究揭示 LALM 在受控情境下建模聲學變化的重大限制。

### [DLite: History-free Speculative Decoding for Agentic AI](<../Papers/[2610.23787] DLite - History-free Speculative Decoding for Agentic AI.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.23787

#### 中文摘要

Speculative decoding 已成為加速大型語言模型（LLM）推論的主流技術：先由輕量 draft model 產生候選 token，再由 target model 驗證。然而，agentic workload 具有長且持續演化的 context，以及頻繁的 multi-turn interaction；在此情境下，既有 draft model 的 acceptance length 最多下降 80%，維護歷史 KV cache 也帶來顯著系統負擔。本文辨識出不斷增長的歷史 context 是兩項問題的共同來源，提出 DLite，一種面向 agentic AI 的 history-free speculative decoding framework。DLite 直接重用 target model 的 contextual hidden states，在不顯式維護歷史 context 的情況下進行局部 speculative prediction，將日益複雜的建模問題轉化為局部簡單預測問題。輕量 sequential head 用低成本恢復 block 內的因果依賴；此外，作者提出適用於此異質、history-free 架構的兩階段訓練策略。實驗涵蓋一般、長 context 與 agentic workload，DLite 的 acceptance length 為 2–6，且相較 DSpark 最多提升 70%。

#### 中文摘要

醫療營運管理中的多準則模型，需要設定權重，以表達利害關係人如何權衡病患等待時間、醫療人員工作負荷與營運成本，但這些權重往往難以量化。本文提出一個評估框架，用來檢驗由 LLM agents 產生的偏好，並量化其不確定性如何影響多目標最佳化決策。研究分別探討顯性偏好與隱性偏好：前者要求 agents 在門診預約排程中評分準則重要性，後者則從急診配置的成對選擇推論權衡關係。結果顯示，顯性偏好會回應診所營運條件，且不同角色存在差異；然而，agents 間的 deliberation 可能抹平這些差異，簡單平均反而能保留角色區隔。成對選擇則高度受選項呈現順序影響。最後，作者建立 robust weighted-sum optimization models，指出偏好不確定性在多數案例會導致不同於平均權重的排程或配置，因此 LLM 偏好在用作醫療決策支援的最佳化權重前，必須接受系統性 audit。

### [TUPLE-Bench: Evaluating and Mitigating Privacy-Utility Trade-offs in Typed Decision Models](<../Papers/[2610.23668] TUPLE-Bench - Evaluating and Mitigating Privacy-Utility Trade-offs in Typed Deci....md>)

`Benchmark` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.23668

#### 中文摘要

Typed decision models 往往不只回傳選定類別，也會公開各候選項目的機率，以及有時額外提供的 confidence score。這些欄位能支援下游決策，但可能揭露超出接收者授權範圍的資訊。本文提出 TUPLE-Bench（Typed decision models’ Utility and Privacy Leakage Evaluation Benchmark），以成對 synthetic cases 測試接收者可得知粗粒度 operational category、但不得得知細粒度原因的情境。九個模型的結果顯示，即使指示模型隱瞞原因，91.88%–99.93%的回應仍會透過直接選擇或 residual scores 揭露原因。即使將原因排除於候選集合之外，完整輸出在 held-out cases 上仍可達62.85%–75.35%的原因恢復率，高於僅提供 selected category 的51.04%–57.64%。完整輸出在全部27個 model-task comparisons 中降低下游成本，但 confidence fields 會增加洩漏，且未穩定降低成本。作者進一步提出 workflow-constrained privacy quantization（WCPQ），在維持指定下游 workflow 行為與成本的同時降低秘密恢復率。研究強調應逐欄位、逐 workflow 稽核 decision interface。
