### `[benchmark]` [[[2607.15272] SciDiagramEdit - Learning to Edit Scientific Diagrams from Paper Revisions\|SciDiagramEdit: Learning to Edit Scienti...]]

在研究論文修訂過程中，編輯圖表是日常且耗時的工作：作者會重新標註元件、重排面板，並調整視覺風格。然而，根據自然語言指令自動完成這類編輯十分困難，因為 scientific figure 是一種高度密集的 infographic，包含示意圖、曲線圖、照片、圖說與箭頭等異質視覺元素，並依循嚴格的 visual grammar 來傳達特定論證。為此，我們提出 SciDiagramEdit，一個 benchmark 與 skill-evolution framework，從自然產生的論文修訂中學習，並直接操作圖表的 editable vector source，使使用者能檢視並共同編輯個別 primitives。該 benchmark 從 arXiv 版本歷史中挖掘 before/after figure pairs，並以作者自身的修訂意圖作為依據。為涵蓋多樣化的編輯指令，我們採用 agentic learning 與 skill evolution：agentic proposer 根據多個 epoch 的 execution traces，持續改進代理的 skill specification。結果顯示，逐步演化的 skill 能提升 held-out validation set 上的編輯準確率，證明自然論文修訂可作為 instruction-driven figure editing 的有效訓練訊號。
