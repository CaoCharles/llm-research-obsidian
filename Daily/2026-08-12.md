`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.11110

#### 中文摘要

當 tool-using agent 以不同語言接收相同任務時，是否仍會採取相同步驟？現有 multilingual evaluation 多比較 final answer，丟棄中間 actions；但對 agent 而言，action route 決定成本、延遲、失敗模式與可稽核性。本文在 8 個模型、6 個平行 benchmarks、41 種語言上執行 238 萬次 rollouts，將 action policy 作為跨語言評估對象。作者辨識並修正五項 confounds：短 trace 偏高、empty trace 得到完美分數、無關 trace 的 chance floor、模型自身 reproducibility 造成的 ceiling，以及缺乏 same-language baseline。以自身 reproducibility 正規化後，四個 frontier models 在 greedy decoding 下跨語言保留約 71–73% 的 action policy；10B parameters 以下則不穩定。實驗也顯示 agents 會透過 English pivot 處理非英語任務，且難以藉由指令移除。最後，作者證明單一 trace-extraction regex 可製造假性 multilingual failure，兩個 worked examples 使某模型 measured accuracy 提高 26 倍，但 readable outputs 的準確率幾乎不變。

#### 中文摘要

可靠的 surgical manipulation policy 學習受到 action-labeled demonstrations 稀缺的限制：具同步 kinematics 的 teleoperated surgical robot（如 dVRK）軌跡成本高昂，而手術任務又要求精確接觸處理、長時程推理與雙手協調。相較之下，endoscopic video 較容易取得，因此可用於學習 surgical scene 的 world model。本文提出 Surgical World-Action Model（Surgical WAM），以 Cosmos Policy 為基礎，聯合預測未來 endoscopic observations 與可執行的 surgical robot action chunks。模型先以 action-free video 學習視覺動力學，再在固定 action-labeled budget 上 fine-tune；部署時採 receding-horizon closed-loop 控制，每次只執行預測 action chunk 的短前綴，並依新觀測重新規劃。在四個 simulated surgical manipulation tasks 上，video pretraining 將平均成功率由 63.5% 提升至 77.8%，PegTransfer 絕對提升 20 個百分點，且 contact-rich 與 bimanual 任務改善最大。

### [Why Does CLAUDE.md Keep Growing? Catastrophic Remembering in Agentic Coding](<../Papers/[2608.11095] Why Does CLAUDE.md Keep Growing Catastrophic Remembering in Agentic Coding.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.11095

#### 中文摘要

Agentic coding 的 README（如 CLAUDE.md）在真實儲存庫中會無限制增長，通常直到儲存庫停止維護，或有人整份重寫才停止。作者將原因追溯至不完善的 recall：新增 instruction 的成本總是很低，但當 instruction 的 rationale 消失後，要在不冒 correctness regression 風險下刪除它，對含有 |D| 個 instructions 的 prompt 而言，需付出 O(2^|D|) 的代價。作者稱此現象為 catastrophic remembering，是 continual learning 中 catastrophic forgetting 的反面。研究首先分析 1,867 個 repositories 中 247,694 個 instruction lifetimes，發現 prompt 在生命週期內增長 226%，每次 commit 淨增 4.9 個 instructions，且 instruction 越老越不易被刪除。接著，作者反轉 IFEval，建立具有已知最佳 prompt 的可驗證世界；結果顯示，包含 latent reasoning 的 prompt comments 可移除 99.3% 的 excess instructions，使增長由 211.3% 降至 1.4%。在 WildIFEval 上，comments 更可使真實世界的 instruction-following 提升最多 23.1%。
