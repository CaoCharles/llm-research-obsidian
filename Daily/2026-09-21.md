### [An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity: Decoupling Confidence and Consistency](<../Papers/[2609.22043] An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal....md>)

`Hallucination & Faithfulness` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2609.22043

#### 中文摘要

LLM agent 的記憶系統過去主要聚焦於高效率 retrieval，但對 retrieved memories 是否值得信任的決策關注較少。當 memory store 含有相互衝突的立場時，standard RAG 會盲目注入 memories，並放大 hallucination；對容易受 memory injection 影響的模型而言，衝突記憶下的 RAG hallucination rate 明顯高於無記憶 baseline。本文提出 Memory Decision Layer（MDL），一個位於 retrieval 與 generation 之間的 zero-parameter memory decision controller。其核心是 three-signal complementary encoder，透過 QR-based orthogonal subspace projection 融合 relevance、reliability 與 task risk，並結合 meta-working-memory signal，形成可解釋的記憶可信度表示。MDL 明確區分 confidence 與 consistency，並引入 risk inversion 與 explicit abstention。多個 LLM 與 open-source datasets 的評估顯示，MDL 在一般衝突記憶情境下約降低 56.04% hallucination rate，在高風險情境接近零 hallucination。控制器完全 white-box、無需訓練參數，每次決策僅約 0.14 ms。

#### 中文摘要

Vision-Language Models（VLMs）近期被視為臉部辨識的潛在工具，因其除了產生相似度分數，也能提供自然語言解釋；此能力對要求決策透明且可稽核的鑑識情境特別具吸引力。然而，既有評估多集中於辨識準確率，尚未量化生成解釋的有效性。本研究提出一套以解釋品質為核心評估軸的 VLM 臉部辨識 benchmark，要求解釋具備 relevance，即依賴身分穩定的臉部特徵，以及 faithfulness，即符合影像中可見內容、避免 hallucination。作者透過限制模型輸出為結構化格式，使解釋能被自動查詢與稽核，並對多個 open-weight VLM 家族同時評估 face verification 準確度與解釋品質。結果顯示，生成解釋仍有顯著缺陷，僅測量辨識能力不足以完整反映模型表現。公開的 benchmark 與 evaluation harness 可作為未來改善及微調可解釋臉部辨識系統的基礎。

#### 中文摘要

機器人執行任務失敗後，必須先決定自行依診斷行動、查詢其他機載感測器，或打斷人類尋求協助。此決定取決於感測器對失敗原因揭露多少，以及機器人診斷本身的可靠度。作者建立一個每次失敗原因皆由注入而知的模擬 benchmark，並以資料洩漏檢查衡量各感測器的診斷資訊。部分失敗可由影像診斷，另一些則只能由 force data 判定；後者的 force-data 準確率達0.99，而影像方法最高僅0.55。六個 open vision-language models 從影像診斷時，行為更受 prompt 表面與選項順序影響，而非證據；信心也無法反映正確性。將 force data 以文字提供後，四個模型首次超越 majority-class baseline。作者進一步以測得的準確率與詢問成本建立 act、sense、ask 三種行動的 optimal policy，發現模型未能依成本調整詢問率。不過，人類一次回答可使模型在詢問後達到約0.70–0.81的準確率。因此，詢問決策應依測得的準確率與明確成本設計，而不應依賴模型信心。


## 今日洞察
- 在 RAG pipeline 中，retrieval 與 generation 之間可增設獨立的 trust-decision gate，避免將「高相關」直接等同於「可採用」。
- 評估可解釋 VLM 不應只看 EER 或 accuracy；實務選型應同時納入 relevance、faithfulness 與 FTA，避免高辨識率模型以眼鏡、表情或光線等不穩定線索產生看似合理的報告。
- 對高風險領域的 agent evaluation，不應只測單一結果分類；可同時評估缺陷定位、可執行建議與最終風險預測，讓 benchmark 更接近實際決策流程。
