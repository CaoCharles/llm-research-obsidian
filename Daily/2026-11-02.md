### [Subquadratic Attention with a Hierarchical Tree-Structured Indexer](<../Papers/[2610.42112] Subquadratic Attention with a Hierarchical Tree-Structured Indexer.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.42112

#### 中文摘要

注意力機制的 quadratic scaling 是限制大型語言模型（LLM）長上下文能力的根本瓶頸。既有方法若採用 sliding-window 或固定狀態的 linear attention，會損失 attention 的表達能力；若採用稀疏 attention，則其 indexer 本身可能仍具 quadratic scaling，僅能提供 constant-factor speedup。本論文提出 Zyphra Hierarchical Attention（ZHA），以遞迴壓縮的 key summaries 建構階層式樹狀 indexer，讓 future queries 由樹頂向下路由，取得與 query 相關的稀疏 keys。透過逐步增加樹深度，包含 routing 與 final attention 的總成本可呈 sublinear 增長，使 attention 整體達到 subquadratic、但仍為 superlinear 的 scaling。作者顯示，ZHA 可透過數十億 tokens 的短期 KL distillation 套用至既有 pretrained models，並在長上下文 retrieval、推理、數學與 agentic coding 評測中維持表現。研究亦指出，ZHA 對不同樹形幾何具有高度穩健性，並以 performance model 推估其在超過一百萬 tokens 後優於競爭方法，具延伸至數億或數十億 tokens context 的潛力。

### [DAMI: Dual-Axis Memory Initialization for Enhanced Long-Context Retrieval in Gated Linear Attention](<../Papers/[2610.41994] DAMI - Dual-Axis Memory Initialization for Enhanced Long-Context Retrieval in Ga....md>)

`Benchmark` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.41994

#### 中文摘要

Linear attention 能以序列長度的線性複雜度運作，但其有限狀態記憶可能限制長上下文檢索。在 gated linear recurrence 中，記憶保留取決於 state decay，而 state decay 同時受 gate 參數 A_log、dt_bias 與輸入 activation 影響。受控 Gated DeltaNet（GDN）實驗顯示，訓練後兩者仍與初始值高度相關，凸顯初始化的重要性。作者提出 Dual-Axis Memory Initialization（DAMI），在訓練前聯合配置這些參數：跨 heads 指派幾何分布的 timescales，以涵蓋不同檢索距離；跨 layers 建立 low–high–low 的 input-sensitivity profile。方法使用少量 activation samples 校準 GDN-family 實作，使其符合兩類行為目標，且不增加 trainable parameters。在 GDN、KDA、GDN2、Mamba-2 與 RWKV-7 上，DAMI 相較隨機初始化，平均 RULER-style retrieval accuracy 提升 5.29 至 16.71 個百分點；language modeling、commonsense reasoning 與 2K real-world retrieval 整體大致相當。

### [CRoS: Causality Reward on Scrambled CoTs Improves Accuracy and Reasoning Faithfulness](<../Papers/[2610.42054] CRoS - Causality Reward on Scrambled CoTs Improves Accuracy and Reasoning Faithf....md>)

`Hallucination & Faithfulness` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.42054

#### 中文摘要

Reinforcement Learning with Verifiable Rewards（RLVR）已成為訓練語言模型推理的標準方法，但 RLVR 通常只依賴最終答案是否正確，無法保證 Chain-of-Thought（CoT）對答案具有因果貢獻。現有 CoT 因果性指標透過刪除推理步驟或注入錯誤來擾動 CoT，再觀察答案變化；然而這些操作同時改變了各步驟的資訊內容，使高因果性分數可能反映模型對資訊變動的敏感度，而非真正的因果依賴。將此類指標作為訓練獎勵，也可能導致較不具資訊性的 CoT、較少探索與自我修正。為此，作者提出 CRoS（Causality Reward on Scrambled CoTs），只打亂推理步驟順序而保留每一步內容，以降低混淆因素。在 Reasoning Gym 的 Gemma-3-4B 實驗中，CRoS 在 OOD 準確率、CoT 品質與 faithfulness 上均優於基線；五個未見邏輯與遊戲資料集的準確率為 46.8%，CoT-Pass@K 平均為 43.4%，hint acknowledgment 為 34.0%。

### [SecPO: Principled Adversarial Training for Prompt Injection Security](<../Papers/[2610.41998] SecPO - Principled Adversarial Training for Prompt Injection Security.md>)

`Safety & Alignment` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.41998

#### 中文摘要

Prompt injection 是 AI agent 面臨的主要威脅之一，攻擊者可將惡意指令植入 email、文件或網站等不受信任資料，操控 agent 的行為。現有防禦模型 Meta-SecAlign 採用 DPO，但在 adaptive prompt injection 下的 attack success rate（ASR）仍接近 100%。作者指出，DPO 以不安全的 undefended model 作為 reference，限制了安全能力提升。為此，論文提出 Secure Preference Optimization（SecPO），以理想化、具 injection-invariance 且維持效用的 oracle distribution 作為參考；此分布可由 undefended model 在 clean input 上的輸出近似取得。同時，作者建立以 PAIR 為基礎的 adversarial training（AT）流程，透過 best@240 搜尋產生強注入。相較 Meta-SecAlign，AT 可降低三種 adaptive attacks 的 ASR 1.5–14.5 倍，SecPO 再降低 2.4–4.6 倍。在 AgentDojo AttackerMovesSecond 評估中，SecPO + AT 的 Qwen3.6-27B ASR 為 8.8%，Meta-SecAlign 為 78.8%，且九項 benign utility benchmark 未見明顯下降。

### [Latent Reasoning in Continuous Space for Unified Multimodal Models](<../Papers/[2610.42149] Latent Reasoning in Continuous Space for Unified Multimodal Models.md>)

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.42149

#### 中文摘要

Unified Multimodal Models（UMMs）在多種多模態理解與生成任務上表現出色，但仍難以有效利用語言式 chain-of-thought（CoT）推理來生成影像，因此現有 reasoning-augmented UMMs 通常無法繼承大型語言模型所呈現的 test-time scaling 與細粒度控制能力。作者將此歸因於模態不匹配：推理在離散 token space 中進行，而影像生成在 continuous space 中運作。為此，本文提出 Latent Reasoning framework in Continuous space（LARC），讓模型在 continuous hidden states 上推理。訓練包含兩階段：curriculum supervised fine-tuning（SFT）逐步將 token-level reasoning 轉換為 latent reasoning；information-gain reinforcement learning（RL）則在沒有 ground-truth reasoning chain 的情況下自我演化 latent reasoning。實驗顯示，LARC 能提升影像品質、prompt following 與 compositional fidelity，並在 GenEval 上取得相較 BAGEL 高 7 個百分點的結果；同時，增加 latent reasoning 計算量會帶來明確且單調的 test-time scaling 效果。

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.42148

#### 中文摘要

Decision model（如 Jev）已成為 LLM agent systems 的重要範式，能以輕量且可靠的分類推理支援快速的 System One 執行。然而，現有以生成為導向的 inference engine 無法有效支援此類工作負載，面臨嚴重的 prefix 重算開銷，或因加入分隔符而扭曲輸出機率。本文提出 Flide，一種高效率且精確的 inference engine，將 decision request 的邏輯樹結構與單一扁平 token stream 中的實體執行分離。透過 ForkAttention，Flide 使用 GPU 常駐索引處理 standard attention 與 recurrent Gated DeltaNet layers 的 request dependencies，保證在精確算術下每個 query branch 都等同於獨立 forward pass。Flide 亦支援多樣 request 混合、CUDA graph replay，以及從先前 pass 儲存的 checkpoint 恢復不斷增長的 agent history。在 public hybrid 與 decision models 上，Flide 相較 vLLM 和 SGLang 最快可達 9.5 倍速度，並在 total variation distance 上最接近 float32 reference。

### [Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention](<../Papers/[2610.42147] Latent Sparse Attention - Towards Subquadratic Ultra-Long Context Attention.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.42147

#### 中文摘要

Agentic workflow 正逐漸轉向長期、多步驟任務，例如開放式科學研究；在此類任務中，模型可受益於長 context window。然而，當 context 超過 1M tokens 時，full attention 的成本高得難以實用。Sparse attention 透過專用 indexer 選取部分 keys，是可行方向，但現有 indexing 方法不是仍具有對 context 長度的 quadratic cost，就是在 ultra-long context 下準確率下降。本文提出 Latent Sparse Attention（LSA）：在 learned latent space 中對 keys 進行階層式 clustering，讓 queries 搜尋 cluster hierarchy，而非逐一評分所有 keys，從而加速 prefill、decode 與 training。作者提出可透過 distillation 套用於預訓練模型的 Distilled-LSA（D-LSA），以及僅以 next-token loss 原生訓練的 Native-LSA（N-LSA）。在 10M tokens 下，D-LSA 可大幅加速 attention layer，且在多類任務維持相近準確率。

### [DecisionRank: On-Policy Distillation for Decision-Model Rerankers](<../Papers/[2610.42128] DecisionRank - On-Policy Distillation for Decision-Model Rerankers.md>)

`RAG Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.42128

#### 中文摘要

Decision models 針對結構化任務直接預測選擇或分數，可避免 autoregressive decoding 的延遲。然而，將 generative LLM 的排序知識轉移至 decision model 仍具挑戰：teacher 透過文件 ID 序列的 ranked list 表達偏好，而 student 則利用 first-token position 的分數決定排序。為此，本文提出 DecisionRank，一種採用 item-space on-policy distillation（OPD）訓練的 decision model。Item-space OPD 將 student 的文件分數排序為 ranked sequence，讓 generative teacher 以該排序清單為條件提供回饋，直接監督 student 分數。結合 offline ranking supervision 後，DecisionRank 在 TREC DL、BEIR 與 BRIGHT 等一般及推理密集型 retrieval benchmark 上達到具競爭力的結果。即使只有 1.7B 參數，也能在 TREC DL19–23 超越 27B generative teacher；8B 模型則超越 generative listwise 對手，且在 TREC DL 與 BRIGHT 分別快 24.5 倍及 16.7 倍。
