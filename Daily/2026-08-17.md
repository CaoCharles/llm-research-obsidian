### [Knowing When to Stop: Bayesian Optimal Stopping for LLM Evaluations](<../Papers/[2608.14425] Knowing When to Stop - Bayesian Optimal Stopping for LLM Evaluations.md>)

`Benchmark` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.14425

#### 中文摘要

LLM 評測經常採用固定 sampling budget，對每個項目執行相同次數的測試，即使估計結果已足夠精確。本文提出 optstop，一個以 precision 為基礎的 adaptive stopping framework，將評測視為 sequential measurement problem：在不確定性仍高的地方持續 sampling，並在估計已足夠精確或穩定時停止。此 framework 建立於 hierarchical Bayesian inference，支援 binary、ordinal 與 continuous outcomes；所有 benchmark items 都保持可被抽樣，且不需要 calibrated item bank。它可在線上執行，也可對既有資料進行 retrospective analysis，並加入 safeguard：當測得的 performance 接近零時採取更保守的 sampling，因為此時 rare successes 尤其重要。在一個 200-item、10-epoch 的示範性評測中，九個 validation settings 移除了原定 trials 的 57%–97%，且整體結論與完整執行結果等價。結果顯示，LLM evaluation compute 可依 uncertainty 而非固定 repetition counts 進行配置，但節省幅度取決於 evaluation design。

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.14441

#### 中文摘要

Self-evolving agents 能從互動經驗改善未來行為，但現有評測通常在固定執行條件下最佳化，未測試環境改變後的恢復能力。本文提出 PACE-Bench（Physics Adaptation via Code Evolution），一個以 simulator 為基礎的 benchmark，涵蓋六個物理領域、144 個 source-to-target adaptation pairs。每個 pair 將具有相同目標與介面的 source environment 連接至經突變的 target environment；原本在 source 中成功的 code-driven design 會在 target 中失敗，agent 必須在有限的 attempt budget 內，利用 diagnostic sandbox feedback 反覆修改並驗證設計。作者比較四種 paradigm 的十種 self-evolving methods。結果顯示 benchmark 尚未飽和：Reflexion + Qwen3-14B 在完整 benchmark 的成功率為 35.9%，GPT-5.5 在 Statics 子集、完整 budget 下達到 66.7%。Simulator-grounded reflection 比未驗證的 self-revision 更可靠；memory 可能使 agent 錨定早期設計，而 broad tree search 雖能探索，卻常無法收斂。即使揭露精確的物理變化，效能上限仍未提高，顯示核心瓶頸是 mechanism redesign，而非單純的 parameter inference。

### [Handover of In-Context Learning State Across Session Boundaries](<../Papers/[2608.14528] Handover of In-Context Learning State Across Session Boundaries.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.14528

#### 中文摘要

本研究探討使用大型語言模型之應用中的 session handover 方法與理論性質。當 context 達到模型輸入上限、應用程式重啟，或改由另一個 agent 接續任務時，系統必須決定從前一 session 傳遞哪些資訊。作者將 handover 定式化為與任務相關的 in-context learning（ICL）state transfer，並區分先前材料的 exact recovery 與 target distribution 的 preservation。在 exogeneity 條件下，predictive equivalence 可刻畫最粗的 deterministic sufficient handover，並給出固定長度的 bit requirement。研究分離 memory constraint、writer 與 continuation procedure 的影響，也量化在未知 downstream query 前寫入記錄的成本。作者提出由精確保存 decisions 與 constraints、以任務有充分理由的 statistics 壓縮重複證據，以及保留統計量未能涵蓋之原始觀察所組成的三部分記錄。Gaussian linear regression 展示 exact finite-dimensional handover 與 finite-bit perturbation bounds；nonparametric regression 則建立 memory 與 squared prediction error 的上下界。
