#### 中文摘要

`Hallucination & Faithfulness` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.06292

#### 中文摘要

Retrieval-augmented generation（RAG）透過以外部知識（如文字語料庫）為大型語言模型（LLM）提供依據，能改善問答。然而，其推理過程通常不透明：中間推理步驟難以驗證，也無法可靠地歸因至特定證據；此外，系統很少能系統性偵測缺少的使用者情境，因而可能產生不完整或錯誤的輸出。本文提出 NeSy-RAG，一個模組化的 neuro-symbolic RAG framework，能從檢索到的文字片段合成具可歸因性的 Prolog modules。系統為每個片段產生表達 Boolean claims 的語意謂詞，這些謂詞可以依賴使用者事實；接著利用自然語言與程式碼的聯合 embeddings 檢索並組合 Prolog queries。為處理不完整的使用者情境，本文提出 symbolic knowledge-gap detection，辨識會影響查詢結果的缺失使用者事實，並自動觸發後續互動。執行 Prolog queries 可產生確定性答案與透明 execution traces，將每個推理步驟連結至其來源。於 ShARC benchmark 上，在不使用 domain-specific training 的情況下，NeSy-RAG 達到 61.1% accuracy，優於相同模型的 RAG baseline（42.8%）。

### [Beyond Top-K: Replacing Black-Box Retrieval with Interpretable Agentic Operations](<../Papers/[2608.06305] Beyond Top-K - Replacing Black-Box Retrieval with Interpretable Agentic Operatio....md>)

`RAG Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.06305

#### 中文摘要

長文件的 Retrieval-Augmented Generation（RAG）主要採用固定切分文字、對 chunks 建立 embeddings，再提供 query 的 top-k 近鄰。作者指出，對財務報表、審計報告與監管申報等文件，這種設計具有結構性缺陷：在一份 780 頁政府財務報告中，86.8% 的內容行是表格列，數千個相似數字共同競爭於 embedding 空間；數字所繼承的單位標頭距離中位數為 13 行，chunk 邊界經常將數值與 lakh 或 crore 單位分離，造成兩個數量級的歧義。即使採用 table-aware chunker，仍有 27–30% 的數字 chunks 缺少財政年度標頭。作者提出 READ（Reliable Embedding-free Agentic Document-search），讓 agent 透過 normalized lexical search、structural navigation 與 bounded span reads 直接讀取原始文件，並以 Model Context Protocol（MCP）提供可重播的審計軌跡。在 51 道驗證題上，READ 準確率為 58.8%，dense retrieval 為 15.7%；調優後 dense 為 35.3%，READ 仍高出 23.5 個百分點。相同 agent 搭配 top-k 工具僅得 27.5%，但 BM25 與 READ 的差異未達統計顯著，因此證據支持的是 embedding-based 與 embedding-free retrieval 的區別，而非 agentic 與 lexical search 的區別。

### [Learning When to Trust via Selective Context Preference Optimization](<../Papers/[2608.06377] Learning When to Trust via Selective Context Preference Optimization.md>)

`Benchmark` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.06377

#### 中文摘要

語言模型日益依賴外部訊號生成答案，而單一具誤導性的訊號可能使原本正確的回答變錯。僅訓練模型抵抗訊號會掩蓋另一項失效模式：完全忽略 context 的模型看似穩健，卻無法在 context 值得信任時受益。本文將問題重新表述為 selective trust，提出由人工標註的 MIST benchmark，讓每個推理題在四種配對條件下呈現：clean、misleading、correct-context 與 irrelevant-context，並提出配對指標 SC2W，計算誤導訊號將 clean 條件下的正確答案翻轉為錯誤的比例。實驗顯示此脆弱性普遍存在。作者進一步提出 SCOPE，挖掘 clean-correct/misleading-wrong 失敗案例，並在四種條件間等量平衡的配對偏好資料上，優化標準 Direct Preference Optimization（DPO）目標，而非只使用 misleading 項目。SCOPE 能降低開放權重模型的 SC2W，同時維持 clean、correct-context 與 irrelevant-context 的準確率。本文主張模型應以 selective trust，而不只是 resistance 來評估。

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.06361

#### 中文摘要

真實世界的 video benchmarks 涵蓋面廣，但固定片段往往同時混入事件數量、頻率、持續時間與視覺複雜度，使失敗原因難以隔離。既有 programmatic benchmarks 雖可控制條件，通常只評分最終答案，未檢查模型回報的事件是否符合可執行 ground truth。本文提出 trace-grounded parametric profiling，用於三種受控 video event counting 任務：彈跳球接觸牆面、視覺閃爍，以及類別狀態轉換。作者在 2,190 部影片中改變事件數 N 與頻率 F，同時固定 rendering；每部影片均附有 executable event trace，以估計 capability surface 並進行 timestamp-level evaluation。結果顯示 temporal failure 分階段發生且取決於事件表徵：在 80% reliability threshold 下，Gemini 3.6 Flash 可於 0.5 與 1.0 Hz 穩定計數 persistent state transitions，最多達 12 個事件，但對 transient blinking 沒有可靠的正事件區域。高數量、高頻率條件下，僅 0.2% 的最終計數正確，且只恢復 18.1% 的真實事件。提高 sampling rate 可提升 Bounce Ball 最終準確率，卻不一定帶來 faithful event recovery。

#### 中文摘要

從自然語言查詢介面到自動報告生成，資料分析工具都需要資料描述：其中包含哪些真實世界實體、哪些欄位是度量或識別碼，以及資料表如何連接成分析單位。目前 semantic layer 通常由人工撰寫，形成知識取得瓶頸，限制分析系統擴展，使非技術使用者依賴專家，且本身容易出錯。本文提出 TYTAN，一個可從 relational database 及可選的簡短使用者描述，自動建構 analytic semantic schema 的系統。TYTAN 結合資料庫 symbolic analysis 與 LLM-based semantic inference，用於提出實體、指定欄位角色與命名；當證據不足以消除歧義時，會向使用者提出針對性的自然語言問題。在七個具參考 schema 的資料域中，TYTAN 對所有實體、屬性與可聚合特徵達成 100% coverage，1,678/1,678 個自生成 retrieval claims 均可正確執行，semantic roles 與參考結果的一致率為 92–100%。在無宣告 keys 的十資料表 FIFA World Cup 2026 blind test 中，TYTAN 恢復完整 entity structure，並滿足五位獨立盲測標註者所有可滿足的期待。


## 今日洞察
- 專業文件評測不宜只採用問答正確率；應同時要求錯誤位置、規則維度與細粒度錯誤類型匹配，才能衡量可執行的診斷能力。

- 若要比較能否改善 agent，應固定 target model、environment、verifier、seed 與 budget，並將 final evaluation 完全保留至搜尋結束；否則結果會混入 protocol、harness 或可見評分過擬合的影響。
