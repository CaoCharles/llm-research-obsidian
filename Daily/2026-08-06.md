`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.05095

#### 中文摘要

長期推理的 Agent 需要能隨著新事實與外部回饋持續到來而高效、有效更新的記憶。近期方法採用 graph memory，以結構化方式支援 multi-hop retrieval 與 reasoning；然而，現有方法通常將所有記憶存放於 flat graph 中，累積的歷史記憶會引入不相關 context，並提高 evidence selection 的 retrieval 成本。此外，這些方法多半獨立更新各個 memory unit，若相關變化涉及多個單元，便需要反覆進行 unit-wise rewrite。為此，本文提出 HiGram，一個具備 path-level localization 與 rewriting 的 evolving hierarchical graph memory framework。HiGram 以由上層節點與 MemoryUnits 組成的 coarse-to-fine 架構組織記憶，以減少 retrieval 時的不相關資訊；再透過 query-與 update-conditioned MicroGraph 定位 support subgraph 與 evidence path；最後，在局部證據路徑內協調更新 intra-unit memory 與 inter-unit dependencies。LoCoMo 與 MemConflict 實驗顯示，HiGram 在 answer quality、token efficiency，以及 dynamic、static、conditional conflicts 下的 answer accuracy 與 query-valid evidence selection 均優於基線。

### [Item Response Theory for AI Safety](<../Papers/[2608.05086] Item Response Theory for AI Safety.md>)

`Safety & Alignment` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.05086

#### 中文摘要

語言模型在安全行為上存在差異，而這些差異通常由 safety benchmarks 衡量。然而，彙總後的 benchmark 分數難以信任與解讀，因為不同 benchmark 可能重複、彼此高度相關，且模型在察覺評測時可能 sandbagging。為了解決這些問題，本文引入 Item Response Theory（IRT）：根據模型在各個 item 上的表現，推估 item 的 psychometric properties 與模型的潛在能力。作者在 192 個語言模型與八個安全 benchmark 上擬合 IRT 模型，完成截至本文所述最大規模的 LLM safety psychometric analysis。研究發現，拒答嚴格度、truthfulness 與 contextual harm 三個可解釋因素能說明模型間 77% 的變異；經 psychometric selection 的 item 比同規模隨機子集更準確地恢復完整 benchmark 分數，若採用 adaptive testing，部分 benchmark 約十個 item 即可將成本降低 97–99%；此外，IRT 也能透過 person-fit、ability shift 與 response fingerprint 審計模型，偵測 naive sandbagging 及 API 背後模型的變更。作者建議 frontier labs 與評測者採用 IRT 來理解、縮減與審計安全 benchmark。

### [OPD-V: Visual On-Policy Self-Distillation with Modality Balance](<../Papers/[2608.05131] OPD-V - Visual On-Policy Self-Distillation with Modality Balance.md>)

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.05131

#### 中文摘要

On-Policy Self-Distillation（OPSD）已成為提升 Multimodal Large Language Models（MLLMs）視覺推理能力的標準 post-training 方法。既有方法從多種輸入來源取得 privileged information，以引導 self-distillation，卻忽略 MLLM 推理中的 Modality Imbalance：當文字資訊主導生成時，模型無法充分整合視覺與文字輸入，使精心設計的 privileged information 未被充分利用。作者以 Zoom-In Image 建立 Positive Teacher、以 Mask Image 建立 Negative Teacher，發現兩者在推理正確性與 token logits 上的差異顯示 Modality Balance 本身可作為 privileged information。據此提出 OPD-V，透過 Positive Modality-Balance Logits Margin 定義 Modality-Balance Trust Region，選取用於 self-distillation 的 on-policy tokens。跨 6 個 benchmarks、4 個 MLLM backbones 與 5 種 post-training 方法的實驗顯示，OPD-V 能穩定提升推理表現並降低訓練成本。
