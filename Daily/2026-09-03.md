#### 中文摘要

多智能體 LLM 系統通常由 orchestrator 將任務分解，交由多個 worker 協作，並透過文字 reflection 改進。然而，現有系統缺乏對 coordination、memory improvement 與 external verification 的統一解釋。本文將 orchestrator–worker 互動建模為 bilevel coordination game：在 bounded coupling 下，worker 的 local-update game 是 approximate potential game，其 equilibrium slack 受 decomposition quality 控制。作者進一步把 reflection 視為 semantic memory states 上的隨機移動，推導 free-form reflection 的有限時間上界、證明最壞情況緊性，並在可反駁的 persistent-harm 條件下給出正的誤差下界。本文也證明僅觀察 transcript 的 gate 無法在文字不可區分環境中一致改善結果，而 environment-grounded gate 可以。基於此提出 Stochastic Reflective Memory Ascent（SRMA），只有在 grounded evaluation risk 嚴格下降時才接受候選 memory；在 calibration 與 corrective mass 條件下，SRMA 以幾何或多項式速率精確收斂，並提供 confidence gating 與 piecewise-stationary environment 的 re-anchoring 保證。

#### 中文摘要

### [Language Models Can Control Their Own Attention](<../Papers/[2609.02737] Language Models Can Control Their Own Attention.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2609.02737

#### 中文摘要

Language Models 在長上下文中通常只將大部分注意力集中於少數 token，卻仍須讀取完整 KV cache 才能找出相關內容。例如，在 1M-token 對話中查詢早期細節時，每個回答 token 都可能觸發全域 context 掃描。既有方法以輕量 proxy score 預先選取相關 token，但此 extrinsic scoring 每步仍需 O(N) 掃描。本文提出 intrinsic 的 Declarative Attention（DA），要求模型在 chain-of-thought 中宣告其注意範圍，並分為 <global>（完整 context）、<focus>（指定區域）與 <local>（僅近期輸出）三種模式。推理引擎將宣告解析為類似 tool call 的控制訊號，跳過大部分 KV cache 讀取。在 15 個長上下文任務的 zero-shot 評估中，Gemma-4-31B 與 Qwen-3.6-27B 分別降低 52.0% 與 31.1% 的 decoding attended tokens，準確率僅下降 1.27 與 2.75 個百分點。結果顯示 DA 提供了新的 sparse attention 軸線，未來仍可透過訓練進一步改善。

#### 中文摘要

由 deep learning 驅動的 autonomous robots 面臨根本性的可稽核性挑戰：事故發生後，調查人員往往無法重建系統作出特定決策的原因。本文提出 TRACE（Transparent Reasoning Architecture for Credible Execution），透過記錄化的因果鏈，確保每個自主動作都能追溯至 sensor evidence。TRACE 將決策分為四個可稽核層次：以證據為基礎的實體辨識（Semantic Perception）、結合 probabilistic state estimation 與 causal graphs 的信念推理（Belief Reasoning）、具約束感知規劃與 counterfactual documentation 的動作合成（Action Synthesis），以及合規監控（Execution Verification）。TRACE 具 model-agnostic 特性，可整合 CNN、transformer 等 learning-based perception 模組，同時維持 decision-level auditability。作者以 Evidence Traceability、Decision Reconstructability 與 Temporal Continuity 三項指標，在 warehouse robot navigation 的 500 個 simulated decision cycles 中評估，分別達到 98.6%、98.1% 與 99.0%。

### [User Feedback Provides a Unique Signal that LLMs Can not Detect](<../Papers/[2609.02859] User Feedback Provides a Unique Signal that LLMs Can not Detect.md>)

`Safety & Alignment` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2609.02859

#### 中文摘要

利用使用者互動中自然產生的 feedback，為 Large Language Models（LLMs）提供學習訊號，是改善模型的重要方向；然而近期研究認為此類 feedback 天然嘈雜且難以有效利用。本研究挑戰此看法，指出 user feedback 實際上是高度可操作的改善訊號，其效果之所以被低估，源於現有 evaluation paradigms 的系統性偏差。作者建立具有明確 ground truth 的 synthetic data，並以 naturalistic data 驗證結果是否適用於真實情境。比較取得與未取得 feedback 的模型修訂後，feedback-informed revisions 在解決目標問題上的成功率顯著較高。進一步分析發現，當模型僅因 feedback 才修正問題時，LLM judges 經常無法辨識真正修正的答案，反而系統性偏好較差的 baseline outputs。


## 今日洞察
- 實務部署不應只把原始 KPI、logs 與工程參數直接串接至 LLM；先建立固定語意欄位與 canonical context，有助於降低輸入表徵不一致。
- 若團隊在固定 benchmark 上反覆比較 agent 版本，可先以歷史完成 trajectories 訓練 outcome predictor，將 EarlyEval 作為開發迭代期的低成本篩選工具；正式、可引用的 benchmark 分數仍應完整執行。
- 若團隊會持續加入 embedding 或 query variants，可先以 3–5 個系統建立基礎 pool，之後只評估新系統帶來的 unique (query, document) pairs，以降低重複成本。
