#### 中文摘要

Hallucination 是 conditional text generation 中妨礙大型語言模型（LLM）可靠使用的主要問題。既有方法多半評估整段生成文本的 factuality，難以指出哪些 output spans 是 hallucinated，也無法說明它們與 input 的關係。本研究提出具 input-side evidence alignment 的 hallucination span detection 任務，聯合辨識輸出中的 hallucinated spans，並將 output tokens 對齊至相應的 input evidence。方法基於一項觀察：faithful output tokens 通常可由 input 預測，而 hallucinated tokens 則不可預測。因此，作者訓練 encoder-based model，根據 input representation 預測被遮罩的 output tokens，並以 prediction confidence 偵測 hallucination；同時，透過檢索到的 input token 自然產生 evidence alignment。實驗顯示，此方法能有效偵測 hallucinated spans 並找出具意義的 input-side evidence；human evaluation 亦確認其 alignment 品質。

#### 中文摘要

本文提出 TinyCast，一個具備 probabilistic forecasting 能力、無 attention 的 zero-shot forecaster，僅使用 146,505 個參數。其核心前提是：在極小模型規模下，context 的週期結構應透過計算取得，而非耗用參數學習。模型以零參數 spectral detector 從輸入偵測 dominant periods，依 phase folding context，再由 dilated convolutional encoder 與 block-autoregressive quantile decoder 建模其餘結構。TinyCast 小於 GIFT-Eval board 上所有參數量可確認的 zero-shot 模型，並在 probabilistic accuracy 上建立 size-accuracy frontier。在宣稱無 test-data leakage 的模型中，它是唯一低於 1.4M 參數且能輸出 predictive distribution 的模型。於 Chronos-ZS 與 fev-bench 中，所有領先的 neural models 至少使用其 28 倍參數。由於 mixing path 僅包含 convolutions 與 matrix multiplications，模型可匯出為 static INT8，並在 embedded device 上無需 per-signal fitting 地完成 forecasting。
