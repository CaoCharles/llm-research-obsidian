### [Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability](<../Papers/[2609.05339] Does Your Agent's Memory Survive a Model Upgrade A Controlled Study of Memory Po....md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2609.05339

#### 中文摘要

模型升級是例行工作，但 memory migration 並非如此。Agent 即使沿用相同的 memory store，仍可能因新模型對舊筆記的解讀不同、混合 embedding 版本破壞 retrieval，或缺乏原始證據而無法修復，導致遺忘。本文比較四種記憶形式：保留完整歷史供長上下文閱讀的 LC-RAW、切分後進行 retrieval-augmented generation 的 RAG、由模型壓縮成自然語言筆記的 NOTES，以及正規化為固定 schema knowledge graph 的 KG-fixed。研究使用 48 個含隨機答案代碼的 synthetic histories、exact scoring，以及兩個參數少於 10B 的 open-weight models。結果顯示，KG-fixed 在 writer swap 後的 accuracy 僅變化 +0.0004 ± 0.0020；NOTES 則高度依賴模型，依 migration direction 產生 +9.91 或 −13.28 個百分點變化。RAG 的 50/50 混合 index 僅取得 4.96 個百分點增益，低於完整 re-embedding 的 11.90 個百分點。研究因此強調方向特定的 migration testing、嚴格隔離 embedding space，以及保留 source history 以支援 memory repair。

### [Same Trajectory, Contradictory Rewards (ROBORMBENCH): Paraphrase Fragility in Vision Language Reward Models](<../Papers/[2609.05401] Same Trajectory, Contradictory Rewards (ROBORMBENCH) - Paraphrase Fragility in V....md>)

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2609.05401

#### 中文摘要

Vision-language models（VLMs）日益被用作機器人學習的 reward function，但此用途要求 paraphrase invariance：對語義等價的目標描述，同一條機器人軌跡應得到相同 reward。本文顯示，現有 VLM reward models 經常違反此性質。僅改寫 instruction 就可能大幅改變預測的 progress score，甚至使完全相同的機器人行為在 failure 與 success 之間翻轉。為衡量此問題，作者提出 ROBORMBENCH，包含 2,390 條真實機器人軌跡、ground-truth progress labels，以及 21,673 個經驗證、涵蓋 lexical、syntactic 與 action-goal rewrites 的 paraphrases。專有與開源 VLM 普遍存在嚴重且隨改寫差異增加的 instability；model scale 或 explicit reasoning 並未可靠改善此問題。相較之下，接受 trajectory-grounded supervision 訓練的 dedicated reward models 穩定得多。結果顯示，paraphrase robustness 是可靠 VLM-based reward modeling 的核心要求。

### [RISE: Recursive Improvement via Self-Extrapolating Policy Distillation](<../Papers/[2609.05295] RISE - Recursive Improvement via Self-Extrapolating Policy Distillation.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2609.05295

#### 中文摘要

On-policy distillation（OPD）能提供逐 token 的密集監督，但其效果受限於 teacher 品質：external teacher 會遭遇 distribution mismatch，而帶有 privileged conditioning 的 self-distillation 則受限於 in-context learning 能力。本文提出 RISE（Recursive Improvement via Self-Extrapolating Policy Distillation），直接從模型自身的 RLVR training trajectory 建構 synthetic teacher。RISE 在 parameter space 或 output logit space 外推 current checkpoint 與 trailing anchor 之間的 displacement，將由 outcome reward 產生的稀疏 parameter update 轉化為密集的 token-level target，不需 external model 或 privileged conditioning。RLVR 以可驗證 outcome reward 錨定正確 reasoning 方向，OPD 再細化 token-level decisions；teacher 於每輪更新，使 distillation 成為 recursive improvement，而非一次性壓縮。實驗涵蓋數學、多領域 STEM、程式生成及多輪 agentic tasks，RISE 均優於 RLVR-only 與 on-policy self-distillation。

### [Testing Interchangeability in LLM Agent Teams](<../Papers/[2609.05279] Testing Interchangeability in LLM Agent Teams.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2609.05279

#### 中文摘要

生產環境中的多代理系統經常替換 agent，通常假設只要新 agent 能完成相同角色，便可與原 agent 互換。本研究檢驗此假設：每個設定由同一 base model 獨立形成八個團隊，每名 agent 在十個 formation episodes 間維護 private notebook，之後交換角色匹配的 agent，並在 held-out tasks 上評估。相較於僅模擬 roster change、但不改變座位成員的 placebo，交換對 task score 的影響很小，卻使每單位進展的 communication cost 增加 16% 至 63%；在 Hanabi 中，交換 agent 的成本甚至高於無經驗 agent。三項 ablation 顯示，swap penalty 會隨獨立形成團隊間的 protocol divergence 一同變化；greedy decoding 降低兩者，而延長 team history 則提高兩者。結果顯示，在這些設定中，agents 在任務成果上較具可互換性，但在 coordination efficiency 上並非如此，且較長的共同歷史會放大交換影響。
