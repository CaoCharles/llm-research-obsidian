#### 中文摘要

#### 中文摘要

長文件 Retrieval-augmented generation（RAG）目前主要採用固定切分文字、對 chunks 建立 embeddings，再呈現 query 的 top-k nearest neighbours。本文指出，對 financial statements、audit reports 與 regulatory returns 等文件，此設計在結構上不可靠。以一份 780 頁政府財務報告為例，86.8% 的內容行是表格列，數千個近似數字在同一 embedding space 中競爭；數字所繼承的單位標頭距離中位數為 13 行，chunk boundary 經常將數字與 lakh 或 crore 單位分開，造成兩個數量級的歧義。即使 table-aware chunker 修正單位問題，仍有 27–30% 的 numeric chunks 缺少 fiscal-year header。作者提出 READ（Reliable Embedding-free Agentic Document-search），讓 agent 透過 normalized lexical search、structural navigation 與 bounded span reads 直接讀取原始文件，並以 Model Context Protocol（MCP）提供可重播的 audit trail。在 51 題驗證問題上，READ 達 58.8%，dense retrieval 為 15.7%；調參後 dense 最佳為 35.3%，READ 仍高 23.5 個百分點。相同 agent 配合 top-k 工具僅達 27.5%，但 BM25 與 READ 無統計顯著差異，因此證據支持的是 embedding-based 與 embedding-free retrieval 的區分，而非 agentic search 勝過 lexical search。

#### 中文摘要

真實世界影片 benchmark 雖涵蓋廣泛情境，但固定片段同時混合事件數量、頻率、持續時間與視覺複雜度，使失敗原因難以分離。既有程式化 benchmark 雖具較佳控制性，主要只評分最終答案，未以可執行 ground truth 稽核模型回報的事件。本文提出 trace-grounded parametric profiling，在三項受控影片任務——彈跳球接觸牆面、視覺閃爍與類別狀態轉換——中評估事件計數。研究生成 2,190 部影片，改變事件數 N 與頻率 F，同時固定 rendering；每部影片均附有可執行事件 trace，用於估計 capability surface 與進行 timestamp-level evaluation。結果顯示分階段且依事件表徵而異的時間失敗：Gemini 3.6 Flash 能在 0.5、1.0 Hz 下可靠計數最多 12 個持續狀態轉換，但對瞬時閃爍沒有可靠的正計數區域。高數量、高頻率時，僅 0.2% 的最終計數正確，且只找回 18.1% 真實事件。增加取樣率可提升 Bounce Ball 最終準確率，卻不保證 trace faithful recovery。

### [Tytan: Interactive Neurosymbolic Construction of Analytic Semantic Schemas from Relational Data](<../Papers/[2608.06331] Tytan - Interactive Neurosymbolic Construction of Analytic Semantic Schemas from....md>)

#### 中文摘要

從自然語言查詢介面到自動報告生成，資料分析工具都需要資料的語義描述，包括其中包含的真實世界實體、欄位所扮演的度量或識別角色，以及資料表如何連接成分析單位。目前這類 semantic layer 通常由人工撰寫，形成知識取得瓶頸，限制分析系統擴展，也使非技術使用者依賴專家，並可能產生錯誤。本文提出 TYTAN，能從 relational database 及可選的簡短使用者描述，自動建構 analytic semantic schema。TYTAN結合資料庫的 symbolic analysis 與 LLM-based semantic inference，用於實體提議、角色分配、命名與關係推論；當證據不足時，會向使用者提出具體的自然語言澄清問題。作者以 coverage、retrieval correctness 與 characterization accuracy 三個面向評估。七個具 reference schema 的資料庫達到100%覆蓋，1,678/1,678項自動產生的 retrieval claims 均成功執行，語義角色與參考結果一致率為92–100%；在無宣告 keys 的盲測資料庫中，TYTAN恢復完整實體結構，並滿足五位獨立盲 annotators 所提出的全部可滿足期望。
