#### 中文摘要

企業工作流程日益依賴 agents 執行 schema-guided extraction：系統根據文件與使用者定義的 schema，忠實產生正確輸出，並附上作為 grounding metadata 的來源證據。本文提出 ExtractBench，據作者所知，是首個同時大規模評估 value accuracy、record completeness、grounding 與實測成本的 benchmark。資料涵蓋 370 份企業文件、4,869 頁、8 個商業領域及 67 種文件類型，並以挑戰標籤區分不同情境。其 schema 與 ground truth 建構流程結合真實文件的獨立系統一致性、合成清單的已知值，以及表單的人工作業驗證。評估採用不計順序的 value F1，以及 word-level 與 page-level grounding F1。商業 VLM 在短文件表現良好，但長文件常截斷記錄清單；coding agents 維持較高準確率卻成本更高。LlamaExtract Agentic Plus 在三項指標均排名第一，準確率接近 coding agents，但成本僅為其一部分。資料集與評估程式碼已公開。

### [TFGformer: Multivariate Time Series Forecasting via Time-Frequency Graph Learning and Covariate Fusion](<../Papers/[2607.29459] TFGformer - Multivariate Time Series Forecasting via Time-Frequency Graph Learni....md>)

`Benchmark` · **相關度** ⭐⭐⭐ · **arXiv** 2607.29459

#### 中文摘要

多變量時間序列 forecasting 需要建模複雜的 temporal dynamics 與變數間依賴關係。然而，實務中的 noisy correlations 可能造成干擾，而 calendar features、外部事件等重要 contextual covariates 也經常未被充分利用。為此，本文提出統一框架，結合 time–frequency graph structure learning 與 covariate-aware representation fusion。Time-Frequency Graph（TFG）模組利用 Short-Time Fourier Transform（STFT）捕捉互補的時間與頻譜模式，再透過 weighted Mahalanobis distance 學習 adaptive inter-variable correlations，並使用 Gumbel–Softmax sampling 建立 sparse、dynamic graphs，以抑制無關依賴。同時，MLP-based modules 將 historical 與 future covariates 融入主要序列表示，使模型利用 trend priors 與 contextual signals。於 electricity、traffic 與 meteorology benchmarks 的實驗顯示，TFGformer 持續優於多種 state-of-the-art Transformer-based models。

#### 中文摘要

### [TokTier: Exact Stateful Tokenization for Agentic LLM Serving](<../Papers/[2607.29678] TokTier - Exact Stateful Tokenization for Agentic LLM Serving.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2607.29678

#### 中文摘要

LLM serving 系統會快取 prompt 的 KV state，但多數前端每次仍須對完整 request text 重新 tokenization。對 coding agent 而言，長 transcript 只追加少量 tool result，卻可能因 token boundary 改變而無法直接重用。TokTier 是具 stateful 的 tokenization service，保證輸出 token IDs 始終與完整 reference tokenizer 一致。session continuation 會針對 append 周邊小視窗重新 tokenization，經 per-request stable-boundary check 後才 splice；失敗則擴大視窗或完整重算。無可重用 prefix 的請求則以 run-local rules 在 GPU 執行 exact pre-tokenization 與 BPE，並以 shadow verifier 抽樣驗證。涵蓋 17 個 tokenizer families 的測試均無 divergence；incremental repair 為 0.5–1.1 ms，GPU 可在 0.87 ms 編碼 1M 字元請求，接入 vLLM 後 TTFT 中位數降低 16–34%。
