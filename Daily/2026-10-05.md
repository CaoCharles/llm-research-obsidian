### [FALCON: A Model and Dataset Agnostic Framework for Synthetic Data Generation for NL2SQL Pairs](<../Papers/[2610.03625] FALCON - A Model and Dataset Agnostic Framework for Synthetic Data Generation fo....md>)

`Benchmark` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.03625

#### 中文摘要

關聯式資料庫是最廣泛部署的結構化知識形式之一，而讓使用者以自然語言存取資料庫，必須將語言 grounded 到 schema 實體與關係，並處理人類表達方式所 inherent 的歧義。現有 synthetic NL-to-SQL 資料生成方法大多忽略歧義，產生過度簡化的 queries，無法讓模型學習真實結構化知識存取的複雜性。我們提出 FALCON，一個 model-與 database-agnostic framework，使用 compact open models、以低成本生成 realistic 且 ambiguity-aware 的 NL-to-SQL 資料。方法結合 reserved-word SQL seeding 與 persona-based prompting 產生結構複雜的 queries，並透過 alignment-based filtering 區分真正錯誤與複雜但有效的 examples，以保留難度。Human evaluation 顯示不同模型規模皆維持穩定高品質；生成資料在 SQL complexity 與 natural-language richness 上超越既有 benchmarks。依難度分層的實驗顯示，模型在 FALCON 資料上訓練後，query 越複雜，相較 baseline-trained models 的優勢越大。加入少量既有 benchmark 資料後，可恢復簡單 queries 的表現，同時保留複雜 queries 的優勢。此設計可讓組織在本地、無需 external APIs 的情況下產生高複雜度訓練資料。

### [World Embedding Benchmark](<../Papers/[2610.03632] World Embedding Benchmark.md>)

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.03632

#### 中文摘要

Physical fidelity 在 world models 與 video generation 中日益受到重視，但影片表徵如何編碼物理資訊仍不明確。作者提出 World Embedding Benchmark，包含來自流體力學、固體力學、動力學及 optics & electromagnetism 四個領域、80 個 family 的 8,000 個受控模擬案例。每個案例將 rendered video 與由 simulation 推導的物理標註配對，支援 text-video retrieval、physical-property regression，以及 multiple-choice video-description pair classification 三項任務，用以區分跨模態物理對齊與定量物理資訊的可恢復性。實驗顯示，預訓練 omnimodal embedding models 的 retrieval 能力偏弱，within-family pair classification 接近隨機，但 frozen video embeddings 仍可透過輕量 probe 恢復有用的物理資訊。以物理影片—文字對進行 continual contrastive training 可改善 retrieval 與 pair classification，卻降低 physical-property regression，呈現對齊與定量資訊恢復之間的取捨。最後，使用 embeddings 為 MiniMax-H3 進行 retrieval-augmented generation，檢索參考影片可提升生成影片的 physical fidelity。

### [Threat-Preserving Representation Sensitivity in Agent-Security Benchmarks](<../Papers/[2610.03585] Threat-Preserving Representation Sensitivity in Agent-Security Benchmarks.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.03585

#### 中文摘要

面向 LLM-based agents 的安全 benchmark 通常以 attack success rate（ASR）衡量模型 robustness，並用分數比較模型與防禦機制，假設分數能代表 agent security。本研究探討 benchmark 的 representation 是否也會影響測量結果。作者提出 threat-preserving representation sensitivity（TPRS），衡量在 underlying task、harmful action、security policy、ground truth、environment 與 evaluation criteria 均固定時，僅改變 agent-visible representation 所造成的 ASR 變化。在 28,904 次 agent runs、三個 benchmark 上，ASR 呈現顯著且不一致的雙向變化。ASB 將 threat-related tool names 改為 threat-neutral names 後，GPT-5-mini 與 Claude Haiku 4.5 的 committed ASR 分別上升 11.67 與 13.21 個百分點；MCPTox 加入 threat-explicit name 後，兩模型 ASR 分別下降 11.00 與 4.11 個百分點。AgentDojo 的 ASR 僅變化 0.50 個百分點，但 benign utility 下降 5.36 個百分點。結果顯示，單一 representation 下測得的 security score 未必能泛化至其他 threat-preserving representations。

#### 中文摘要

大型語言模型（LLM）日益被用於法律實務、教育與研究，但其在美國以外國家法律體系中的可靠性仍缺乏系統性證據。本研究提出一個由專家驗證、用於評估哥倫比亞法律可靠性的 benchmark，包含 1,042 題，涵蓋十個法律領域與三種題型：封閉式單選題、半開放題及開放式 IRAC 題，並透過 human-in-the-loop 流程與多階段專家審查建立。研究評估 15 個 proprietary 與 open-weight 模型。封閉題準確率介於 0.905 與 0.577；然而自由文字答案的 factual correctness 對任何模型均未超過 0.45。答案 relevancy 與 correctness 呈負相關（Spearman ρ=-0.46），顯示模型常能流暢且切題地回答，卻在法律事實上出錯。封閉題排名與自由文字正確性高度相關（ρ=0.94），但封閉題會高估絕對可靠性。獨立的 LLM judge 與盲測法律專家均重現自由文字模型排名（ρ≥0.88）。研究指出，現有 LLM 執行哥倫比亞法律任務仍需專家監督，而以權威法律來源 grounding 是提升可靠性的可行方向。

### [What Should World Models Forget? Stratified Retention for Continual Adaptation](<../Papers/[2610.03713] What Should World Models Forget Stratified Retention for Continual Adaptation.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.03713

#### 中文摘要

傳統 continual learning 將先前資料上的性能下降視為失敗，因其假設 prediction target 穩定且正確標籤永久有效。然而，world model 預測的是會變動的環境；曾經正確的知識可能因道路重建、物體移動或場景重排而過時，適時捨棄這些知識反而是必要行為。本文指出，world model 同時包含必須永不修改的 invariant，例如 physics 與 object permanence，以及應隨環境變化更新的 instance-level facts，因此需要依 invariance timescale 分層 retention。作者主張標準 forgetting metrics 無法區分正確修訂過時知識與 catastrophic forgetting，甚至會偏好 frozen model。為此提出 differential retention，以 adaptation stream 中的 invariant regression testing 聯合 revision latency 進行評估，且不將兩者聚合為單一分數。

理解與評估自然災害對防災準備與風險降低至關重要。大型語言模型（LLM）的進展促使研究者發展能整合科學資料、模型與工具的 hazard analysis agents。然而，自動化分析要求 agent 判斷某一事件適用哪些科學方法，以及在現有資料與工具下哪些方法可執行；當新證據與執行結果出現時，這些條件可能改變，agent 必須重新考慮選擇。本文將問題形式化為 state-dependent scientific route selection，提出 HazardWeaver。系統先由 Hazard Knowledge Compiler 擷取與證據連結的科學適用性條件，再以 Hazard Capability Graph 表示可執行能力並檢查輸入輸出相容性。Hazard Weaver Agent 據此選擇適用且可執行的 route、執行 workflow，並隨分析狀態變化修訂決策。作者另提出 Hazard Weaver Benchmark，包含七個單一災害領域與四類多災害互動的 141 個實例，評估輸出正確性、route 有效性與有理據的 abstention。實驗顯示 HazardWeaver 優於既有 agent systems，且在存在多個合格 route 的任務上提升最大。程式碼已公開。

### [MRVQ: One Resident Index for Dimension- and Rate-Elastic Vector Search](<../Papers/[2610.03651] MRVQ - One Resident Index for Dimension- and Rate-Elastic Vector Search.md>)

`RAG Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2610.03651

#### 中文摘要

Dense retrieval 服務必須在延遲、品質與記憶體預算變動時，切換 embedding-prefix 維度與 index bit rate。各 rate 分別調校 quantizer 可獲得最佳品質，但 retrieval tier 必須同時保存多組 code stream 與 quantizer state。本文提出 Matryoshka Residual Vector Quantization（MRVQ），一種針對 frozen embeddings 的 post-hoc residual quantizer。其最高 rate code 可沿兩個方向截斷：移除 residual stages 以降低 rate，移除 embedding coordinates 以降低維度。因此單一 resident artifact 即可支援所有評估的（dimension, rate）組合。在 FiQA、NFCorpus、四種 embedding families 與 4、8、16-byte codes 上，MRVQ 是評估設計中最低 RAM 者；相較三個分別訓練的 QINCo2 indices 少用 17.8–22.0 倍記憶體，相較精簡 shared-model steelman 少用 1.89–2.02 倍。代價是 per-rate QINCo2 在 FiQA 的 nDCG@10 高 0.026–0.107。MRVQ 仍在相同 code size 下勝過 PQ、OPQ 與 AdANNS-OPQ。作者另評估低建置成本的 PCA-scalar 設計，品質與 RaBitQ 及其延伸方法相當，但中位數 fitting 快 420 倍。
