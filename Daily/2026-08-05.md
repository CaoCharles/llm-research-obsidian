#### 中文摘要

本文提出 Video-DeepResearch（Video-DR），將 multimodal deep-research agent 從靜態影像延伸至連續影片串流，要求模型同時進行密集的時空 grounding 與開放網路探索。作者發現現有模型存在兩項瓶頸：偏好文字搜尋而忽略視覺工具的 modality bias，以及依賴參數記憶、未真正執行工具增強推理的 parametric knowledge leakage。為此，作者設計 decoupled perception-exploration pipeline，透過 stage-wise tool unlocking，先強制跨影格視覺 grounding，再開放網路檢索。訓練採用 supervised fine-tuning（SFT）接續 Group Relative Policy Optimization（GRPO），並建立含複雜 multi-hop VQA 的 Video-DR-Bench。Video-DeepResearch-35B-A3B 達 64.0% 平均準確率，30B-A3B 達 59.3%。

### [PAST-Bench: Benchmarking the Foundations of Recursive Self-Improvement in Personal Agents](<../Papers/[2608.04003] PAST-Bench - Benchmarking the Foundations of Recursive Self-Improvement in Perso....md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.04003

#### 中文摘要

Recursive self-improvement 要求 agent 將累積經驗轉化為未來更好的行為。Personal AI agents 會跨 session 保留偏好、任務歷史、tool routines 與 learned skills，因此提供研究此能力的具體環境；然而，保留的經驗是否真正改善後續表現，尚未被系統性測試。本文提出 PAST-Bench，透過在 matched conditions 下切換 retained experience，評估 agent 在 ordered fresh-session tasks 中的進步及其是否遵循 save、retrieve、update pathway。Benchmark 涵蓋 26 個 scenarios、204 個 episodes，以及 memory、procedural reuse、information gathering、update 四種能力。跨七個 base models 與四個 agent frameworks 的結果顯示，改善確實存在但依能力而異；相同 task-score gain 的 agent，其 pathway evidence 可能顯著不同。作者進一步提出 Hermes+，在 agent loop 五個階段加入 targeted interventions，提高 retained-experience gain 與 pathway evidence，並在過時狀態更新任務上改善最明顯，但效果仍取決於能力與模型。

### [ParVL: Parallel Scaling and Expandable Compute Allocation for Multimodal LLMs](<../Papers/[2608.04010] ParVL - Parallel Scaling and Expandable Compute Allocation for Multimodal LLMs.md>)

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.04010

#### 中文摘要

現有 Multimodal Large Language Models（MLLMs）的 scaling strategies 通常擴增模型參數，或增加 sequential inference computation，因此分別帶來顯著的記憶體或延遲成本。更重要的是，多數方法無法改變 Vision Transformer（ViT）與 Large Language Model（LLM）元件之間僵化且固定的計算分配，限制了 task-specific optimization。為此，本文提出 Parallel Vision-Language（ParVL）scaling framework，透過在多個 vision 與 language branches 之間重用既有 ViT 和 LLM backbone 參數，擴增 parallel computation。在固定 backbone 參數預算下，作者研究額外共享-backbone computation 應如何分配至 vision 與 language modalities。每個 parallel stream 以 branch-specific prefix parameters 建立於共享 backbone 之上，並以約 13B tokens 進行 end-to-end full-parameter supervised fine-tuning。實驗系統分析 ViT encoder 與 LLM decoder 的計算分配取捨，顯示 ParVL 整體表現優於相同訓練配方的 single-branch baselines，且最佳 vision-language allocation 會隨任務而變化。
