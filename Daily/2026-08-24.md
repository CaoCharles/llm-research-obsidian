### [Specification Portability Across LLM Development Agents: Cross-Agent Compatibility in Specification-Driven Software Migration](<../Papers/[2608.21208] Specification Portability Across LLM Development Agents - Cross-Agent Compatibil....md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.21208

#### 中文摘要

本論文研究跨 agent 的 specification portability，探討在一個 LLM 開發環境中建立或組織的 specification，轉交另一個 agent 後，能否維持實作品質。作者以 Oracle-to-PostgreSQL migration 作為受控的 software transformation 任務，分兩階段進行實驗：第一階段在 1,006 個 PL/SQL 檔案上評估 specification-first migration pipeline，其中 623 個成功重新生成，380 個生成腳本可於 PostgreSQL 16 成功執行；第二階段使用 1,802 組 Oracle 腳本及其 PostgreSQL 實作，評估 Amazon Kiro、Google Gemini 與 GitHub Copilot 的 native 與 foreign specifications。研究採用 Token F1、exact match、SQL syntax validity、AST exact match、AST mean similarity 與 immediate runnability。結果顯示，specification 長度不足以預測實作品質，跨 agent 傳遞可能造成高度依賴 agent 的效能下降；Gemini 直接使用 Kiro-origin specification 的 replicated case 最差。Rewriting 可改善 Gemini，compression 沒有普遍效益，而 retrieval-augmented ingestion 是 Gemini 與 Copilot 兩者 Pareto frontier 的共同策略。

### [EnSI-RAG: Entity-Structure-Indexed Retrieval-Augmented Generation for Long-Document Question Answering](<../Papers/[2608.21252] EnSI-RAG - Entity-Structure-Indexed Retrieval-Augmented Generation for Long-Docu....md>)

`RAG Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.21252

#### 中文摘要

在長篇、彼此連結的文件上進行問答仍然具有挑戰性，因為相關證據可能分散於多個實體及其關係之間。現有 Retrieval-Augmented Generation（RAG）方法通常將文件切成原始 chunks，再以 embedding similarity 進行檢索；當 chunk 邊界將實體與支持證據分開，或問題需要跨語料庫進行 multi-hop reasoning 時，效能便會下降。本文提出 EnSI-RAG（Entity-Structure-Indexed Retrieval-Augmented Generation），建立與查詢無關、以實體為中心的索引。每筆記錄 ⟨e,t,k,v⟩ 表示實體、實體類型、屬於 property、relation 或 aspect 的語義類別，以及其值，並保留通往原始來源段落的連結。查詢時，這些記錄作為 retrieval handles，由 LLM 將取回的段落整合為最終答案。此設計將證據定位與答案生成分離，同時保留可追溯的來源證據。在 Loong 與 Oolong 上，EnSI-RAG 平均準確率為 78.24，較所採用的已發表 baseline 參考分數高 6.62 分，顯示其在不同設定下的有效性。

#### 中文摘要

大型語言模型常依賴 Chain-of-Thought（CoT）推理處理複雜任務，但冗長推理軌跡會造成顯著的推論開銷。CoT compression 能縮短生成長度，然而過度壓縮可能破壞邏輯連貫性並降低效能。本文提出 Context-Generation Substitution Law，形式化說明明確推理上下文可替代部分解碼階段生成。基於此，作者提出免訓練的 Memory-Augmented Compression，從歷史推理軌跡建構可重用的 reasoning memories，並在 prefill 階段檢索與注入，作為壓縮推理的支架。這些 memory 不使用原始 demonstrations，而是摘要可重用的推理模式、關鍵約束與重要操作，以補償壓縮造成的資訊損失。實驗顯示，Memory 能提升 Chain-of-Draft（CoD）在 GSM8K、MATH、BBH 與 MMLU-Sci 上的準確率，並相較標準 CoT 實現 1.14–1.49 倍 latency speedup；同時也能與 token-level、reasoning-trace-level 及 inference-state compression 方法結合。分析指出，增益來自相關推理 memory，而非單純增加上下文長度。

#### 中文摘要

- 在 heterogeneous SDD workflow 中，不應假設 specification 是 agent-neutral；實務上應為不同 implementation agent 建立 portability smoke test 與 native/foreign quality baseline。
