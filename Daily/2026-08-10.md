### [CoinRAG: Contextualized Information Nugget KV Cache Reuse for Long-Context RAG](<../Papers/[2608.07458] CoinRAG - Contextualized Information Nugget KV Cache Reuse for Long-Context RAG.md>)

`RAG Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.07458

#### 中文摘要

近期 RAG 優化研究多利用 chunk-level KV cache reuse，避免在推論時重複處理冗長的 retrieved context，以提升效率；然而，粗粒度 chunks 仍包含大量資訊冗餘與噪聲。本論文提出 CoinRAG（Contextualized Information Nugget KV Cache Reuse for Long-Context RAG），在低 prefill latency 約束下，同時最大化回答準確度並優化 accuracy–latency Pareto frontier。CoinRAG 先於離線階段從 chunks 擷取細粒度、可對應至原文 token span 的 information nuggets，並預先計算完整 chunk 的 KV cache；線上則透過 two-stage retrieval 選出與 query 相關的 nuggets，再切片並組合其具上下文的 KV representations，形成更精簡且語義相關的 context。於 LongBench 三個 multi-hop QA 資料集的實驗顯示，在標準 100 ms P99 TTFT 預算下，CoinRAG 平均 F1 為 41.7，相較最佳競爭方法 39.6 提升 5.3%。

### [Fisher-R1: Training LLM Agents for Reliable Hypothesis Testing](<../Papers/[2608.07437] Fisher-R1 - Training LLM Agents for Reliable Hypothesis Testing.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.07437

#### 中文摘要

可靠的假設檢定是許多實證科學主張的基礎。大型語言模型（LLM）agents increasingly automate this process，能夠檢查資料集、產生程式碼，並端到端完成分析。然而，作者發現它們經常犯下細微的推論錯誤：即使分析程式正確執行，仍可能因統計方法選擇不當而導致錯誤結論。現有 benchmarks 很少評估給定資料假設時，reported p-value 是否具有統計有效性，因此無法捕捉此類失敗。作者建立 P-Bench，包含 425 個來自 economics、biology 與 medicine 的開放式真實假設檢定任務；每項任務要求 agent 選擇方法、計算 p-value，並根據 scientific hypothesis 與 dataset 作出結論。此外，作者提出 Fisher-R1，一個以 synthetic tasks、supervised fine-tuning 與 reinforcement learning 訓練的 open-weight LLM agent。Fisher-R1-14B 在 P-Bench 上超越其 backbone，以及 GPT-5.4、DeepSeek-V4-Pro 等模型，較 DeepSeek-V4-Pro 的 single-trial success 平均相對提升 21%，最具挑戰任務最高提升 26%。結果顯示，現有 LLM agents 的統計推理仍不可靠，而具 verified statistical reward 的 reinforcement learning 能顯著提升可靠性。

### [TEPA: Revoking Stale Memories for Conflict-Robust Language Agents](<../Papers/[2608.07429] TEPA - Revoking Stale Memories for Conflict-Robust Language Agents.md>)

`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.07429

#### 中文摘要

長期記憶讓 language agents 能重用過去的事實、偏好與任務經驗，但持續保存也造成核心的可證偽性問題：當世界改變時，過時記憶仍可能被檢索並污染 prompt。本文將此失效模式定義為 memory pollution，即較新的衝突證據已取代舊證據後，仍保持 active 的記憶造成性能下降。作者提出 TEPA，一種可撤銷的 evidence-memory 機制，將觀察表示為 keyed precedents，並把 validity 視為明確狀態；當同一 key 出現新衝突證據時，撤銷原本 active 的 precedent，使檢索只使用當前證據，同時保留 revoked history 供稽核。實驗涵蓋 hidden-regime drift、真實檔案執行漂移及偏好更新串流；在 50 個 seeds 的 controlled drift reversal 中，append-only 與 last-write-wins 得分均為 0.210，低於 no memory 的 0.309，而 TEPA 達 0.950。TEPA 在 MemoryAgentBench SH-6k 單跳事實整合中匹配 last-write-wins，但多跳及超長上下文測試顯示 retrieval chain 與 context selection 仍是瓶頸。
