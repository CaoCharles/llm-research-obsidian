`Agent Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.26004

#### 中文摘要

Agentic LLM pipeline 會因 retrieval、tool use 與 multi-turn interaction 累積 context，導致 inference cost 與 latency 上升。部署通常壓縮 input 以控制成本，但會損害 task accuracy。Speculative decoding（SD）雖能 losslessly 加速 generation，卻要求 drafter 與 verifier 使用相同 context，因此無法同時處理 accuracy 與 overhead 的取捨。作者提出 AsymSpec：lightweight drafter 讀取 full input，而大型 verifier 僅處理 compressed view；再透過 contrastive δ-fusion logits，以及 divergence-aware Context-Divergence Acceptance（CDA）gate，引導 verifier 並維持穩定驗證與較高 draft acceptance rate。在四項 agentic capabilities 與兩個 end-to-end agent benchmarks 上，平均達到約 full-context accuracy 的 90%，孤立文字能力可取得 1.3–1.7 倍 throughput，compute cost 為 0.2–0.3 倍。

`Safety & Alignment` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.26008

#### 中文摘要

大型語言模型（LLM）仍容易受到 jailbreak attacks 影響；攻擊者可利用 role-playing、obfuscation、code transformation 與 multi-step indirection 等技巧誘導模型產生有害輸出。既有防禦多為 static mechanisms，部署後安全行為固定，無法累積防禦經驗或適應未見策略。本文提出以 persistent、跨互動 rule memory 為核心的 self-evolving test-time defense：當攻擊成功時，系統將失敗抽象為描述結構性 attack wrapper 的 method-level rule，而非記憶有害主題，並套用於後續輸入。單一規則可泛化至整個攻擊家族，且遇到新 wrapper 時可擴展 label space。方法僅透過 external memory 與 prompting 運作，不更新模型參數，適用於 open-weight 與 black-box API models。實驗顯示，它能降低四類 black-box jailbreak 的 attack success rate、維持 benign utility，抵抗 adaptive composite-wrapper attack，且 memory 增長不會增加 over-refusal。

### [VISA: Agentic Self-Evolving Data Synthesis for Multimodal Instruction Following](<../Papers/[2608.26013] VISA - Agentic Self-Evolving Data Synthesis for Multimodal Instruction Following.md>)

`Multimodal Evaluation` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2608.26013

#### 中文摘要

多模態 instruction-following 模型需要準確、多樣、可驗證且具挑戰性的訓練資料。現有合成流程多採用一次性的 generate-and-filter 範式，未充分利用失敗樣本、verifier 結果與 target model 錯誤所提供的回饋。本文提出 VISA（Visual Instruction Synthesis Agent），將多模態 instruction synthesis 重構為 self-evolving loop。每一輪中，VISA 分析影像以篩除不相容 constraints，並發掘新的可驗證 constraints；接著從 persistent memory 中依據 diversity 與 difficulty 取樣 constraint sets、生成候選 instructions，再透過 executable tools 與結構化 LLM judges 驗證樣本。失敗樣本會觸發 diagnostic-guided recovery，通過的樣本則接受 target model probing 以估計難度。verifier signals 與 target-model failure profiles 會回寫 memory，使後續輪次能擴展 constraint space、減少模板重複，並聚焦模型尚未解決的弱點。同一套 verifier contracts 也可直接提供 reinforcement learning 的 reward signals，無須另外訓練 reward model。MM-IFEval 實驗顯示，VISA 能提升多模態 instruction following，同時維持七個公開 benchmark 上的整體多模態能力。
