儘管大型語言模型（LLM）接受了旨在符合人類價值的安全訓練，仍可能受到 jailbreak attacks 攻擊，繞過內建防護並產生攻擊者要求的惡意行為。現有防禦多為靜態方法，難以適應新型或未知的攻擊策略，韌性有限。為此，作者提出多代理防禦框架 GuardrailAgent，提供具適應性的端到端保護。系統會自主蒐集並摘要攻擊特徵，建立持續更新的 knowledge base，支援輸入側與輸出側偵測；feedback module 則將誤分類案例納入迭代改進，且成本有限。在超過十種代表性 jailbreak 上，框架達到 93.1% 的輸入側偵測率、93.9% 的整體偵測率及 95.8% 的 F1 score，並能快速適應未見攻擊。結果顯示，GuardrailAgent 能在 jailbreak 策略持續演化時維持 LLM 安全性。

許多多模態對齊問題需要將來源模態映射至由目標模態定義的固定空間；此目標空間不只是中間嵌入，而會直接用於下游分析。因此，成功的對齊必須同時保留目標分布的全域結構，以及配對來源—目標訓練資料中的實例級對應。既有目標各自只處理部分需求：contrastive loss 鼓勵相對相似性，distribution matching 改善邊際分布一致性，而 pointwise regression 雖能擬合配對目標，卻未明確建模目標空間的路徑幾何。本文提出 FlowAlign，一種 flow-guided target-space alignment 方法，將 conditional flow matching 重新用作訓練期間的對齊訊號，而非推論期間的 transport model。FlowAlign 利用學得的 flow field 引導來源表示對齊固定目標空間，使其保留配對對應，同時符合目標空間的全域結構。理論分析顯示，FlowAlign 可透過控制 endpoint accuracy 並捕捉局部目標空間幾何，改善配對對應。合成資料、paired single-cell multiome 與 image–text 實驗均顯示，FlowAlign 能提升 instance-level correspondence，並在不同模態設定下維持 target-space structure。

### [BitDecoding-FP4: Native FP4 KV Cache Decoding via Algorithm-System Co-Design](<../Papers/[2611.09825] BitDecoding-FP4 - Native FP4 KV Cache Decoding via Algorithm-System Co-Design.md>)

`Hallucination & Faithfulness` · **相關度** ⭐⭐⭐⭐ · **arXiv** 2611.09825

#### 中文摘要

長上下文 LLM serving 中，key-value（KV）cache 主導記憶體容量與頻寬。雖然 NVFP4、MXFP4 等 4-bit microscaling format 能縮小 cache，並在 FP4 Tensor Core 上執行 attention，但現有系統多採用 vanilla quantization，造成嚴重準確率下降；重視準確率的 4-bit 方法則依賴 vector codebook，lookup 開銷會降低 decoding throughput。本文提出 BitDecoding-FP4，一套準確且高效的 native FP4 KV decoding algorithm–system co-design。方法包括 Dual-Residual Query Quantization、Underflow-Aware Probability Scaling 與 Outlier-Aware Key Quantization，並以 transposed softmax、fused probability quantization 和 stacked query MMA 消除系統瓶頸。在多種 dense、MoE、GQA 與 MLA 模型上，NVFP4 與 BF16 KV 的平均準確率差距小於 0.5 分，MXFP4 小於 1 分；在 NVIDIA B300 上，Qwen3-4B 與 Qwen3-30B-A3B 的 peak serving throughput 為 BF16 KV 的 2.4–3.0 倍。
