# DeepEval 評測框架

> 全方位 LLM 應用評測的開源解決方案

## 概述

**DeepEval** 是一個功能豐富的 LLM 評測框架，整合多種評測方法論，支援從單元測試到整合測試的完整評測流程。其設計理念借鏡軟體工程的測試實務，將測試驅動開發（TDD）概念引入 LLM 應用開發。

---

## 理論基礎

### 測試驅動的 LLM 開發

借鏡 TDD 的理念：

| 傳統 TDD | LLM TDD |
|----------|---------|
| 單元測試 | 單一互動評測 |
| 整合測試 | 端對端對話評測 |
| 回歸測試 | 模型更新後驗證 |
| CI/CD 整合 | 自動化評測流水線 |

### 多維度評測

DeepEval 支援的評測維度：

| 維度 | 評測重點 |
|------|----------|
| 正確性 | 答案與預期的匹配程度 |
| 忠實度 | 對上下文的忠實程度 |
| 有害性 | 有害內容的產生 |
| 偏見 | 輸出中的偏見 |
| 相關性 | 回答的切題程度 |

## 核心指標

### G-Eval

基於 Chain-of-Thought 的通用評測方法（Liu et al., 2023）：

| 特點 | 說明 |
|------|------|
| **靈活性** | 可自訂評測標準 |
| **可解釋** | 提供評分理由 |
| **可擴展** | 適用於各種任務 |

G-Eval 的基本流程：
1. 定義評測維度和標準
2. LLM 生成評估思考過程
3. 根據思考給出評分

### 預定義指標

| 指標 | 說明 | 對應研究 |
|------|------|----------|
| **Answer Relevancy** | 答案相關性 | RAGAS |
| **Faithfulness** | 忠實度 | TRUE |
| **Contextual Precision** | 上下文精確度 | RAGAS |
| **Hallucination** | 幻覺程度 | SummaC |
| **Toxicity** | 有害性 | Perspective API |
| **Bias** | 偏見程度 | StereoSet |

## 方法論貢獻

### 可複製評測

確保評測結果可複製的關鍵要素：

| 要素 | 實務建議 |
|------|----------|
| 版本控制 | 固定模型版本和參數 |
| 種子設定 | 設定隨機種子確保一致 |
| 環境隔離 | 標準化評測環境 |
| 結果記錄 | 完整記錄每次評測 |

### 回歸測試

追蹤模型更新後的表現變化：

| 檢測項目 | 關注指標 |
|----------|----------|
| 能力衰退 | 新版低於舊版 |
| 新問題 | 以前通過現在失敗 |
| 改善驗證 | 目標指標確實提升 |

## 應用場景

### 開發階段

| 場景 | 應用方式 |
|------|----------|
| Prompt 迭代 | 比較不同 prompt 的效果 |
| 模型選擇 | 評估不同模型的表現 |
| 參數調優 | 測試不同參數設定 |

### 部署階段

| 場景 | 應用方式 |
|------|----------|
| 發布把關 | 上線前品質驗證 |
| 回歸測試 | 更新後確保無退化 |
| A/B 測試 | 比較不同版本效果 |
