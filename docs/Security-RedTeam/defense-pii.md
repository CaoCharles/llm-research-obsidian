# PII 洩露防護

> 防止大型語言模型洩露個人敏感資訊的研究與對策

## 概述

**PII（Personally Identifiable Information）洩露**是 LLM 系統的重要隱私風險。Carlini et al. (2021) 的開創性研究證明，LLM 可能「記住」並輸出訓練資料中的敏感資訊。

---

## 學術背景

### 記憶現象

Carlini et al. (2021) 定義的模型記憶：

> 「如果可以透過特定查詢從模型中提取出訓練資料的精確副本，則稱模型記住了該資料。」

### 記憶類型

| 類型 | 定義 | 風險 |
|------|------|------|
| **可提取記憶** | 可直接查詢獲得 | 高 |
| **情境記憶** | 特定上下文觸發 | 中 |
| **統計記憶** | 反映在輸出分佈中 | 低 |

---

## 風險場景

### 訓練資料洩露

Carlini et al. (2021) 的研究發現：

| 風險因素 | 說明 |
|----------|------|
| **模型規模** | 大模型記憶更多 |
| **重複資料** | 重複出現的資料更易記憶 |
| **獨特資料** | 格式獨特的資料更易提取 |

### 應用層洩露

| 場景 | 風險 |
|------|------|
| **多租戶應用** | 跨使用者資訊洩露 |
| **RAG 系統** | 檢索到敏感文件 |
| **對話記憶** | 歷史對話資訊洩露 |

## PII 類型

### NIST 分類

根據 NIST SP 800-122 的 PII 分類：

| 類別 | 範例 | 敏感度 |
|------|------|--------|
| **直接識別符** | 全名、身分證號 | 高 |
| **準識別符** | 生日、地址部分 | 中高 |
| **敏感資訊** | 健康狀況、財務資料 | 高 |
| **一般資訊** | 職業、教育程度 | 中 |

### 資料類型

| 類型 | 風險評估 |
|------|----------|
| 身分證號 | 極高 |
| 銀行帳號 | 極高 |
| 電話號碼 | 高 |
| 電子郵件 | 中高 |
| 地址 | 中高 |
| 姓名 | 中 |

## 防護研究

### 訓練階段

| 方法 | 原理 | 研究 |
|------|------|------|
| **差分隱私** | 限制個體影響 | Abadi et al. (2016) |
| **資料去識別** | 移除或遮蔽 PII | — |
| **機器遺忘** | 選擇性遺忘資料 | Bourtoule et al. (2021) |
| **去重複** | 減少記憶風險 | Lee et al. (2022) |

### 推理階段

| 方法 | 原理 |
|------|------|
| **輸入脫敏** | 將 PII 替換為佔位符 |
| **輸出過濾** | 檢測並遮蔽輸出中的 PII |
| **格式限制** | 限制特定格式的輸出 |

### PII 檢測

| 方法 | 特點 |
|------|------|
| **規則式** | 正則表達式匹配 |
| **NER 模型** | 命名實體識別 |
| **專用模型** | 如 Presidio、Microsoft PII |

## 隱私增強技術

### 差分隱私

Abadi et al. (2016) 提出的 DP-SGD：

| 概念 | 說明 |
|------|------|
| **隱私預算 ε** | 隱私保護強度 |
| **噪音添加** | 在梯度中添加噪音 |
| **效用權衡** | 隱私與模型效能的平衡 |

### 去學習

Bourtoule et al. (2021) 的機器遺忘研究：

| 方法 | 說明 |
|------|------|
| **完整重訓練** | 移除資料後重新訓練 |
| **分片學習** | 只重訓受影響的部分 |
| **近似遺忘** | 更新模型近似遺忘效果 |

## 法規要求

### 主要法規

| 法規 | 地區 | 關鍵要求 |
|------|------|----------|
| **GDPR** | 歐盟 | 遺忘權、資料最小化 |
| **CCPA** | 加州 | 存取權、刪除權 |
| **個人資料保護法** | 台灣 | 告知義務、安全維護 |

### 合規考量

| 考量 | 說明 |
|------|------|
| 資料最小化 | 只收集必要資料 |
| 目的限制 | 僅用於聲明目的 |
| 存取權 | 使用者可查詢其資料 |
| 刪除權 | 使用者可要求刪除 |
