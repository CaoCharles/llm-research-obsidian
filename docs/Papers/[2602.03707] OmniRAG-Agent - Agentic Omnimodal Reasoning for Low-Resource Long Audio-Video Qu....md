# OmniRAG-Agent: Agentic Omnimodal Reasoning for Low-Resource Long Audio-Video Question Answering

## 摘要（中文翻譯）

長程全模態問答需要跨文字、圖像、音訊和視訊進行推理。儘管 OmniLLMs 取得進展，低資源長音視訊問答仍面臨昂貴的密集編碼、細粒度檢索能力弱、主動規劃有限、缺乏端到端優化等問題。我們提出 OmniRAG-Agent，一種針對預算有限的長音視訊推理的 Agentic 全模態問答方法。它構建圖像-音訊檢索增強生成模組，讓 OmniLLM 從外部庫中檢索相關幀和音訊片段。此外，使用代理迴圈進行規劃、跨輪次呼叫工具、融合證據回答複雜查詢。透過群體相對策略優化聯合改進工具使用和答案品質。

## 問題背景

長音視訊全模態問答面臨四大挑戰：(1) 密集編碼成本過高；(2) 細粒度檢索能力弱；(3) 缺乏主動規劃能力；(4) 沒有端到端優化機制。現有 OmniLLMs 難以在低資源設定下有效處理長音視訊內容。

## 解決方案

提出 OmniRAG-Agent，核心創新包括：(1) 圖像-音訊檢索增強生成模組，從外部庫檢索相關短片段而非密集編碼；(2) 代理迴圈架構，實現跨輪次的規劃、工具呼叫和證據融合；(3) 群體相對策略優化（GRPO），聯合優化工具使用策略和答案品質。

## 核心貢獻
1. 設計圖像-音訊 RAG 模組，實現低資源下的細粒度多模態檢索
2. 提出代理迴圈架構，支援主動規劃和多輪工具呼叫
3. 應用 GRPO 實現工具使用和答案品質的端到端聯合優化

## 技術方法

OmniRAG-Agent 採用三層架構：(1) 外部記憶庫儲存預處理的影格和音訊片段；(2) RAG 模組根據查詢檢索相關片段；(3) 代理迴圈進行規劃-執行-觀察循環，跨輪次呼叫檢索工具並融合證據。使用 GRPO 優化整體策略，同時改進檢索選擇和答案生成。實驗在 OmniVideoBench、WorldSense 和 Daily-Omni 三個基準上評估。

## 對我們的啟發
- [ ] RAG 範式可有效擴展到音視訊多模態場景，緩解密集編碼的計算壓力

## 限制與未來工作

需要預處理建立外部記憶庫，增加了系統部署複雜度。GRPO 優化過程需要較多計算資源。對即時音視訊流的處理能力未驗證。
