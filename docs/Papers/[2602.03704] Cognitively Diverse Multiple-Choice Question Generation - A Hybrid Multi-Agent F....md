# Cognitively Diverse Multiple-Choice Question Generation: A Hybrid Multi-Agent Framework with Large Language Models

## 摘要（中文翻譯）

大型語言模型的進展使自動化多選題生成變得可行，但可靠地生成滿足特定認知需求的題目仍具挑戰。為解決此問題，我們提出 ReQUESTA，一個混合多代理框架，用於生成認知多樣化的多選題，系統性地針對文本理解、推理和主旨理解。ReQUESTA 將多選題編寫分解為專門子任務，協調 LLM 代理和基於規則的組件進行規劃、受控生成、迭代評估和後處理。我們在大規模閱讀理解研究中評估該框架，比較 ReQUESTA 生成的題目與 GPT-5 零樣本基準。心理測量分析評估題目難度和區分度，專家評估題目品質。結果顯示 ReQUESTA 題目更具挑戰性、區分度更高、與閱讀理解表現更相關。

## 問題背景

現有 LLM 生成多選題缺乏對認知需求的精確控制，單次生成方式難以確保題目的教育測量品質（難度、區分度）和認知層次的多樣性。生成的干擾選項常缺乏語言一致性和語義合理性。

## 解決方案

提出 ReQUESTA 混合多代理框架，核心創新是將多選題編寫分解為專門子任務，由不同代理負責：(1) 規劃代理確定認知目標；(2) 生成代理產出題目；(3) 評估代理進行品質檢查；(4) 規則組件進行後處理。透過迭代評估確保題目滿足預設的認知需求和測量品質標準。

## 核心貢獻
1. 設計混合多代理架構，分離規劃、生成、評估和後處理職責
2. 系統性針對三種認知層次（文本、推理、主旨）生成多選題
3. 大規模實證驗證 ReQUESTA 題目的心理測量品質優於單次生成基準

## 技術方法

ReQUESTA 採用四階段流程：(1) 規劃階段確定目標認知層次和題目類型；(2) 生成階段由 LLM 代理產出題目初稿；(3) 評估階段檢查認知對齊和干擾選項品質；(4) 後處理階段進行規則修正。實驗使用學術說明文本，收集學習者回答進行心理測量分析（難度、區分度），並由專家評估題目品質（主題相關性、干擾選項品質）。

## 關鍵結果

| 指標 | ReQUESTA | GPT-5 Zero-shot |
|------|----------|----------------|
| 題目難度 | 更高 | 較低 |
| 區分度 | 更高 | 較低 |
| 干擾選項品質 | 更好 | 一般 |
| 概念對齊 | 更強 | 較弱 |

## 對我們的啟發
- [ ] 多代理工作流程設計是 LLM 結構化生成的關鍵槓桿，超越單次提示
- [ ] 認知層次的明確分解有助於控制生成題目的教育測量屬性
- [ ] 迭代評估對干擾選項品質特別重要，尤其是推理類題目

## 限制與未來工作

目前僅在學術說明文本上驗證，對敘事文本和其他文體的適用性待驗證。多代理協調增加了系統複雜度和延遲。
