# A-RAG: Scaling Agentic Retrieval-Augmented Generation via Hierarchical Retrieval Interfaces

## 摘要（中文翻譯）

前沿語言模型已展現出強大的推理和長程工具使用能力。然而，現有的 RAG 系統未能充分利用這些能力，仍依賴兩種範式：(1) 設計單次檢索演算法並將段落串接至模型輸入，或 (2) 預定義工作流程並提示模型逐步執行。這兩種範式都不允許模型參與檢索決策，阻礙了隨模型改進而高效擴展。本文提出 A-RAG，一個 Agentic RAG 框架，直接向模型暴露階層式檢索介面。A-RAG 提供三種檢索工具：關鍵字搜尋、語意搜尋和區塊讀取，使代理能夠在多個粒度上自適應地搜尋和檢索資訊。多個開放域問答基準測試顯示，A-RAG 在相當或更少的檢索 token 下持續優於現有方法。

## 問題背景

現有 RAG 系統無法充分發揮前沿語言模型的推理和工具使用能力。傳統方法要麼採用單次檢索後直接串接，要麼預定義固定工作流程，這兩種方式都不允許模型主動參與檢索決策，導致系統無法隨著模型能力提升而有效擴展。

## 解決方案

提出 A-RAG（Agentic RAG）框架，核心創新是向模型暴露階層式檢索介面。框架提供三種粒度的檢索工具：關鍵字搜尋（粗粒度）、語意搜尋（中粒度）和區塊讀取（細粒度），讓代理能夠根據任務需求自適應地選擇檢索策略，實現模型主導的動態檢索決策。

## 核心貢獻
1. 提出階層式檢索介面設計，包含關鍵字搜尋、語意搜尋和區塊讀取三種工具
2. 實現模型主導的動態檢索決策機制，使 RAG 系統能隨模型能力提升而擴展
3. 系統性研究 A-RAG 如何隨模型規模和測試時計算資源擴展

## 技術方法

A-RAG 框架設計了三層檢索介面：(1) 關鍵字搜尋工具用於快速篩選相關文檔；(2) 語意搜尋工具透過向量相似度進行更精確的段落匹配；(3) 區塊讀取工具允許代理讀取特定文檔區塊以獲取細節資訊。模型作為代理，可自主決定何時使用哪種工具、檢索多少內容，形成閉環的檢索-推理迴路。實驗在多個開放域問答基準上進行評估，包括檢索效率（token 數量）和答案準確度的權衡分析。

## 關鍵結果

| 方法 | 準確度 | 檢索 Token 數 |
|------|--------|---------------|
| 傳統 RAG | 基準線 | 高 |
| A-RAG | 持續優於基準 | 相當或更低 |

## 限制與未來工作

論文主要在開放域問答場景驗證，對於其他知識密集型任務（如多跳推理、長文檔理解）的效果仍待驗證。階層式檢索增加了系統複雜度，對於簡單查詢可能產生不必要的開銷。
