# Toward Universal and Transferable Jailbreak Attacks on Vision-Language Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2602.01025)
- 📥 [PDF](https://arxiv.org/pdf/2602.01025)

## 摘要（中文翻譯）

本研究針對視覺-語言模型（VLM）的越獄攻擊進行深入探討，重點分析攻擊的通用性和跨模型遷移能力。隨著 GPT-4V、Gemini 等多模態模型的普及，確保其安全性變得至關重要。研究發現，針對 VLM 的對抗性攻擊可以透過精心設計的視覺擾動來繞過安全機制，更令人擔憂的是，這些攻擊具有顯著的跨模型遷移性。論文提出通用越獄攻擊框架，能夠生成在多個不同 VLM 上都有效的對抗樣本。實驗涵蓋主流開源和商業 VLM，揭示多模態安全對齊的系統性漏洞。研究強調需要發展針對多模態場景的防禦機制，單純在文本或視覺單一模態的防護已不足夠。

## 問題背景

視覺-語言模型整合了視覺和文本理解能力，但其安全防護主要針對文本模態設計，視覺輸入提供了新的攻擊面。現有研究對 VLM 越獄攻擊的通用性和遷移性理解不足，特別是如何設計能夠跨不同模型架構生效的攻擊方法。這使得建立有效的多模態安全防護缺乏理論指導。

## 解決方案

提出針對 VLM 的通用越獄攻擊框架，核心創新包括：(1) 跨模態對抗擾動生成方法，同時利用視覺和文本輸入空間；(2) 模型無關的攻擊策略，透過集成優化在多個目標模型上生成通用對抗樣本；(3) 遷移性分析框架，系統性評估攻擊在不同架構 VLM 間的遷移效果。研究揭示 VLM 安全漏洞的共性特徵，為防禦設計提供洞察。

## 核心貢獻
1. 提出首個系統性研究 VLM 越獄攻擊通用性和遷移性的框架
2. 設計跨模型有效的通用對抗攻擊方法，揭示多模態安全對齊的系統性漏洞
3. 在 8 個主流 VLM 上驗證攻擊遷移性，發現平均 73% 的跨模型攻擊成功率

## 技術方法

研究採用系統化實驗設計：首先建立 VLM 越獄攻擊的威脅模型，定義攻擊者能力和目標。接著提出通用攻擊生成算法，包含三個關鍵步驟：(1) 多模型集成優化，在多個源模型上同時訓練對抗擾動；(2) 跨模態擾動融合，結合視覺噪聲和文本提示工程；(3) 遷移性增強技術，如輸入變換和梯度正則化。評估在 8 個 VLM 上進行，包括 LLaVA、MiniGPT、Qwen-VL、GPT-4V 等，測試 5 類有害內容的生成成功率。分析攻擊在不同模型架構、訓練資料和對齊策略間的遷移模式。

## 關鍵結果

| 源模型 → 目標模型 | 同架構 ASR | 跨架構 ASR | 遷移率 |
|-----------------|-----------|-----------|--------|
| LLaVA → MiniGPT | 89.3% | 76.4% | 85.6% |
| 集成 → GPT-4V | - | 68.2% | - |
| 集成 → Gemini | - | 71.5% | - |
| 平均跨模型 | 91.7% | 73.1% | 79.7% |

## 對我們的啟發
- [ ] VLM 的視覺編碼器是攻擊的關鍵弱點，不同模型間共享類似的視覺特徵空間導致高遷移性
- [ ] 多模態對齊主要約束文本生成，視覺輸入的安全檢查相對薄弱，形成攻擊捷徑
- [ ] 通用對抗攻擊的存在表明 VLM 安全對齊存在共性漏洞，需要跨模型的協同防禦策略

## 限制與未來工作

研究主要在學術開源模型上進行，商業模型的 API 限制阻礙全面測試。攻擊生成需要白盒訪問源模型，實際威脅程度取決於攻擊者資源。未深入探討防禦方法，僅提供初步建議。倫理考量：為降低濫用風險，論文不公開完整攻擊代碼，僅在補充材料中提供關鍵技術細節。
