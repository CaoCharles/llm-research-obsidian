## 摘要（中文翻譯）

專家級科學推理對大型語言模型仍極具挑戰，尤其在 Humanity's Last Exam (HLE) 等 benchmark 上，固定工具管線、脆弱的多代理協作及低效的 test-time scaling 常限制模型表現。本文提出 ReThinker，一個 confidence-aware agentic framework，透過階段式 Solver-Critic-Selector 架構協調 retrieval、tool use 與 multi-agent reasoning。ReThinker 根據模型信心度動態分配計算資源，實現 adaptive tool invocation、guided multi-dimensional reflection 與 confidence-weighted selection。為支援無需人工標註的可擴展訓練，進一步提出 reverse data synthesis pipeline 與 adaptive trajectory recycling 策略，將成功推理軌跡轉化為高品質監督訊號。在 HLE、GAIA 與 XBench 三個 benchmark 上，ReThinker 持續超越具備工具的 SOTA 基礎模型與現有 deep research 系統，達成專家級推理任務的最優結果。

## 問題背景

專家級科學推理（expert-level scientific reasoning）對 LLM 仍極具挑戰，尤其在 Humanity's Last Exam (HLE) 等高難度 benchmark 上。現有方法面臨三大瓶頸：(1) 固定工具管線（rigid tool pipeline）缺乏彈性；(2) 多代理協作脆弱，易因錯誤累積而崩潰；(3) test-time scaling 效率低下，單次推理無法自我修正，導致模型依賴 pattern memorization 而非系統化推演。

## 解決方案

提出 ReThinker，一個 confidence-aware agentic framework，採用階段式 Solver-Critic-Selector 架構協調 retrieval、tool use 與 multi-agent reasoning。核心設計包含：(1) 基於模型 confidence 動態分配計算資源，實現 adaptive tool invocation；(2) guided multi-dimensional reflection 機制，透過結構化摘要與改進指引進行精細化反思；(3) confidence-weighted selection 搭配 Latin Square 排列消除 position bias。此外提出 reverse data synthesis pipeline 與 adaptive trajectory recycling，無需人工標註即可生成高品質監督訊號。

## 核心貢獻
1. **Automated Trajectory Synthesis**：提出全自動推理軌跡合成管線，透過 seed phrase initialization、web search 與多階段品質保證（correctness check、formatting validation、deduplication、quality improvement）生成專家級 QA pairs 與 reasoning trajectories，完全消除人工標註需求。
2. **Hybrid Scaling with Guided Reflection**：設計混合式 sequential-parallel scaling 架構，Solver 階段進行多輪 iterative rethinking 逐步精煉推理，Critic 階段引入 summary-and-guidance 模組對完整推理軌跡進行多維度反思，有效突破 context length 限制並修正細微邏輯錯誤。
3. **Confidence-Controlled Selection**：引入 perplexity-based confidence 引導的三階段選擇機制（Initial Judgement + Iterative Re-selection + Final Decision），搭配 Latin Square 排列消除 position bias，透過 uncertainty aggregation 穩定最優答案的識別。

## 技術方法

ReThinker 框架分三大階段運作：**(A) Post-Training Data Synthesis & Curation**：利用 LLM 自動生成 23 個學科領域的 seed phrases，經 web search 擴展後產生 expert-level QA pairs。Reasoning trajectories 經四階段品質管線（correctness check → formatting validation → deduplication & balance → quality improvement）篩選，確保 CoT-Response alignment 與 tool execution 成功率。**(B) Multi-Path Iterative Reasoning**：實例化 N 條平行推理路徑，每條包含 Solver 與 Critic 兩階段。Solver 進行多輪 re-answer synthesis（公式 $s_{t+1} = \text{Solver}(q, \text{extract}(s_t))$），逐輪提取結論並重新推理。Critic 先將軌跡摘要為 summary、final answer、key areas for improvement 三部分，再據此進行 guided reflection（公式 $c_{t+1} = \text{Critic}(q, y, a, k, \text{extract}(c_t))$），使反思能涵蓋細粒度問題與高階邏輯缺陷。**(C) Confidence-Guided Selection**：三階段決策——Stage 1 以 Latin Square 排列消除 position bias 進行初始判斷；Stage 2 計算 perplexity 作為 uncertainty gating signal，高 PPL 觸發額外 re-selection rounds，歷史選擇與 confidence scores 迭代回饋；Stage 3 對歷史被選答案進行 final adjudication，一致則直接輸出，否則執行決定性選擇。

## 關鍵結果

在三個 expert-level reasoning benchmark 上均達到 SOTA：

| Model | HLE (%) | GAIA (%) | XBench (%) |
|---|---|---|---|
| ReThinker (Gemini-3-Pro) | **52.2** | **81.6** | **90.0** |
| ReThinker (OpenPangu-72B) | 33.1 | 72.8 | 78.0 |
| Gemini-3-Pro (w/ Tools) | 38.3 | 79.0 | 87.0 |
| GPT-5-high (w/ Tools) | 35.2 | 76.4 | 77.8 |
| MiroThinker-v1.0 (30B) | 33.4 | 73.5 | 70.6 |
| Tongyi DeepResearch (30B-A3B) | 32.9 | 70.9 | 75.0 |
| OpenAI DeepResearch | 26.6 | 67.4 | -- |

Component analysis（500 題 HLE 子集）：Solver re-answer synthesis 提升 Pass@5 +1.4%；Critic w/ Summary & Guidance 提升 Pass@5 +3.8%（為最大單階段增益）；Selector 三階段累計提升 Hit Rate +5.6%（Initial Judgement 65.27% → 最終 70.83%）。Perplexity-guided re-selection 在 4 輪迭代後正確選擇數從 141 提升至 153，優於無 PPL guidance 的 147。

## 對我們的啟發
- [ ] **Confidence-aware compute allocation**：根據模型 uncertainty 動態分配推理資源（高 perplexity 觸發更多 re-selection rounds）是比固定 pipeline 更有效的 test-time scaling 策略，可應用於我們的 agentic system 設計。
- [ ] **Structured guided reflection 優於 naive reflection**：Critic 階段將完整軌跡拆解為 summary + answer + key improvement areas 再進行反思，比僅用 final answer 或 summary 高出 2.8% 和 1.6%，顯示結構化反思能有效突破 context length 瓶頸。
- [ ] **Latin Square 消除 position bias**：在 multi-candidate selection 場景中，候選答案的排列順序會顯著影響選擇結果，Latin Square 設計可確保每個候選在各位置均勻出現，此技巧可推廣至 LLM-as-Judge 與 reward model 的評估流程。

## 限制與未來工作

框架高度依賴強力 backbone model（以 Gemini-3-Pro 為底時效果最佳，換 OpenPangu-72B 則大幅下降），multi-path parallel reasoning 的計算開銷隨路徑數 N 線性增長。目前僅評估 text-only 子集，對多模態科學推理的泛化能力尚未驗證。未來可探索更高效的 trajectory pruning 策略與跨領域 zero-shot transfer 能力。
