# Trust The Typical (T3): Robust Safety via OOD Detection for LLMs

## 摘要（中文翻譯）

當前 LLM 安全方法基本上依賴一種脆弱的「貓鼠遊戲」——通過 guardrails 識別和阻擋已知威脅。本文主張一種全新思路：穩健的安全性不在於列舉什麼是有害的，而在於深入理解什麼是安全的。作者提出 Trust The Typical (T3) 框架，將此原則操作化，將安全性視為分佈外（Out-of-Distribution, OOD）檢測問題。T3 在語義空間中學習可接受提示的分佈，並將任何顯著偏差標記為潛在威脅。與先前方法不同，T3 不需要在有害範例上訓練，卻在 18 個基準測試上達到最先進性能，涵蓋毒性、仇恨言論、jailbreak、多語言危害和過度拒絕，將 false positive 率降低最高達 40 倍。僅在安全英文文本上訓練的單一模型即可有效轉移到 14 種以上語言。

## 問題背景

現有 LLM 安全方法（guardrails、安全分類器、RLHF）本質上都是「反應式」的：先收集有害範例，再訓練模型識別和拒絕。這種方法存在根本缺陷：(1) 無法窮舉所有有害模式，新型攻擊不斷湧現；(2) 過度依賴已知攻擊模式，導致對未見攻擊泛化能力差；(3) 安全分類器的訓練需要大量有害數據，本身存在倫理和實踐問題；(4) 對多語言攻擊的防禦成本極高（每種語言需重新收集數據和訓練）。這使得 LLM 安全防護始終處於被動追趕的狀態。

## 解決方案

T3 從根本上翻轉安全範式：從「識別什麼是有害的」轉為「建模什麼是安全的」。核心方法是將安全性建構為 OOD 檢測問題：(1) **安全分佈建模**：在 LLM embedding 空間中學習安全提示的統計分佈特徵，使用 per-point PRDC（Precision, Recall, Density, Coverage）指標捕捉分佈的幾何結構；(2) **偏差檢測**：將任何偏離安全分佈的輸入標記為潛在威脅，不依賴已知攻擊模式；(3) **Forte 框架適配**：從電腦視覺領域的 Forte OOD 框架出發，適配到 LLM 的各向同性（isotropic）embedding 空間，提供理論保證。T3 只需要安全文本訓練，天然具備對未知攻擊和多語言場景的泛化能力。

## 核心貢獻
1. 提出 T3 框架，首次將 LLM 安全從反應式模式識別轉為主動式統計建模，僅需安全文本訓練即可防禦未知攻擊，在 18 個基準上達到 SOTA，false positive 率降低最高 40 倍
2. 將 Forte OOD 框架從視覺領域適配到文本，提供嚴格的理論分析，證明 per-point PRDC 指標如何檢測分佈偏移，利用 LLM embedding 的各向同性幾何特性
3. 實現跨語言零樣本遷移：僅在英文安全文本上訓練的模型有效遷移到 14 種以上語言，無需重新訓練，大幅降低多語言安全防護成本

## 技術方法

**框架設計**：T3 分為三個核心模組：(1) **Embedding 提取**：使用預訓練 LLM 的中間層 embedding 表示輸入提示的語義特徵；(2) **安全分佈學習**：收集大量安全提示的 embedding，計算其在高維空間中的密度和覆蓋特徵，建立安全基線分佈；(3) **OOD 評分**：對新輸入計算其相對於安全分佈的 PRDC 指標，偏差超過閾值即標記為不安全。

**PRDC 指標適配**：Precision（不安全提示落在安全分佈內的比例）、Recall（安全提示被正確覆蓋的比例）、Density（局部密度偏差）、Coverage（全局分佈覆蓋度）。T3 將這些 per-point 指標組合為統一的異常分數。

**理論保證**：作者證明在 LLM embedding 空間的各向同性假設下，PRDC 指標能以可證明的方式檢測分佈偏移。各向同性假設在現代 LLM（特別是經過 contrastive learning 預訓練的模型）中是合理的。

**實驗設置**：在 18 個基準上評估，涵蓋 ToxiGen（毒性）、HateCheck（仇恨言論）、AdvBench（jailbreak）、XSTest（過度拒絕）等，以及多語言基準。Baseline 包括 Llama Guard、OpenAI Moderation API、NeMo Guardrails 等專門安全工具。

## 關鍵結果

| 方法 | 毒性 AUROC ↑ | Jailbreak AUROC ↑ | 多語言 AUROC ↑ | 過度拒絕 FPR ↓ |
|------|-------------|-------------------|---------------|---------------|
| Llama Guard 3 | 0.82 | 0.79 | 0.64 | 12.3% |
| OpenAI Moderation | 0.85 | 0.73 | 0.71 | 8.7% |
| NeMo Guardrails | 0.78 | 0.81 | 0.59 | 15.1% |
| **T3 (Ours)** | **0.94** | **0.96** | **0.91** | **0.3%** |

**關鍵發現**：
- **全面超越專門安全工具**：T3 在所有 18 個基準上達到最佳 AUROC，且不需要有害數據訓練
- **極低 false positive**：過度拒絕率僅 0.3%，比 Llama Guard 低 40 倍，意味著幾乎不影響正常使用
- **跨語言零樣本遷移**：僅英文訓練即可在 14 種語言上保持 0.91 AUROC，遠超需要語言特定訓練的方法
- **對未見攻擊的泛化**：對訓練時未包含的新型 jailbreak 手法仍保持高檢測率，驗證 OOD 框架的泛化優勢

## 限制與未來工作

T3 依賴 LLM embedding 空間的各向同性假設，若模型的 embedding 空間高度各向異性，檢測效果可能下降。安全分佈的定義（哪些文本被視為「安全」）本身涉及價值判斷，可能存在偏見。對於語義上模糊的提示（如 dual-use 查詢），OOD 方法的區分能力有限。此外，T3 的 embedding 提取需要存取模型中間層，對黑盒 API 模型不適用。
