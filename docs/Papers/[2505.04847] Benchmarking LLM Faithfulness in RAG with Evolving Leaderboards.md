# Benchmarking LLM Faithfulness in RAG with Evolving Leaderboards

## 摘要（中文翻譯）

檢索增強生成（RAG）旨在透過將回應建立在外部上下文基礎上來減少幻覺，但大型語言模型即使在提供相關上下文的情況下仍頻繁引入不受支持的資訊或矛盾。本文呈現 Vectara 在衡量和基準測試 LLM 忠實度方面的兩項互補工作。首先描述了原始幻覺排行榜，自 2023 年起使用 HHEM 幻覺檢測模型追蹤 LLM 的幻覺率。基於當前幻覺檢測方法的局限性，作者提出 FaithJudge，一個 LLM-as-a-Judge 框架，利用多樣化的人工標註幻覺範例池，大幅提升 LLM 幻覺的自動化評測品質。研究引入以 FaithJudge 為中心的增強版幻覺排行榜，在摘要生成、問答和數據到文本生成任務上對 LLM 的 RAG 忠實度進行基準測試，為構建更可信賴的生成式 AI 系統提供支持。

## 問題背景

RAG 系統雖然透過外部檢索來減少幻覺，但 LLM 仍然會在有相關上下文的情況下引入不受支持或矛盾的資訊。現有的幻覺檢測方法（如基於 NLI 的 HHEM 模型）存在局限性，無法準確捕捉所有類型的幻覺，導致 faithfulness 基準測試的可靠性不足。業界缺乏一個持續更新、覆蓋多任務的 RAG 忠實度排行榜。

## 解決方案

提出 FaithJudge 框架，核心創新是將 LLM-as-a-Judge 與多樣化的人工標註幻覺範例池結合。不同於傳統的 NLI 模型方法，FaithJudge 利用精心策劃的幻覺案例作為少樣本示範（few-shot demonstrations），引導 LLM 評審識別各種類型的幻覺。同時建構持續演化的排行榜（evolving leaderboard），追蹤模型在摘要、QA 和 data-to-text 三個任務上的忠實度表現。

## 核心貢獻
1. 提出 FaithJudge 框架，透過多樣化幻覺範例池增強 LLM-as-a-Judge 的幻覺檢測能力，顯著優於 HHEM 等傳統方法
2. 建構覆蓋三類 RAG 任務（摘要、QA、data-to-text）的增強版忠實度排行榜，提供持續更新的模型比較
3. 開源 FaithJudge 框架和資料集（GitHub），推動 RAG 忠實度評測的標準化和可重現性

## 技術方法

FaithJudge 的技術架構分為三個層面。範例池構建：研究團隊收集並標註多種類型的幻覺案例（包括事實錯誤、不支持的推斷、上下文矛盾、數據編造等），建構多樣化的範例池。每個範例包含：上下文、模型回應、幻覺標註和解釋。

評審機制：使用 LLM-as-a-Judge 評審模型，動態從範例池中選取與待評估回應最相關的幻覺範例作為 few-shot demonstrations，提示 LLM 評審判斷目標回應中是否存在幻覺及其類型。

排行榜設計：在三個任務上評估 LLM 的忠實度——(1) 摘要生成（summarization）：給定文檔，生成忠實摘要；(2) 問答（QA）：基於檢索文檔回答問題；(3) 數據到文本（data-to-text）：將結構化數據轉為自然語言描述。使用 FaithJudge 評分和人工標註進行對比驗證，計算各模型的幻覺率和 faithfulness 分數。

## 關鍵結果

| 評測方法 | 與人工標註相關性 | 幻覺類型覆蓋 | 可擴展性 |
|----------|-----------------|-------------|----------|
| HHEM (NLI-based) | 中等 | 有限 | 高 |
| FaithJudge | 高（顯著提升） | 全面 | 高 |
| 人工評估 | 基準線 | 全面 | 低 |

| 任務 | 最佳模型幻覺率 | 最差模型幻覺率 |
|------|---------------|----------------|
| 摘要生成 | <5% | >30% |
| 問答 | <10% | >40% |
| Data-to-text | <8% | >35% |

## 對我們的啟發
- [ ] 多樣化的幻覺範例池是提升自動化 faithfulness 評測品質的關鍵——不同任務和場景的幻覺模式差異顯著，通用檢測器難以全面覆蓋
- [ ] 持續演化的排行榜（而非靜態基準）更適合追蹤快速發展的 LLM 忠實度表現，可作為模型選型的實用參考
- [ ] data-to-text 任務的幻覺率普遍高於預期，揭示 LLM 在結構化數據處理中的忠實度問題值得更多研究關注

## 限制與未來工作

FaithJudge 本身依賴 LLM 作為評審，存在 LLM 評審的固有局限（如對某些隱性幻覺不敏感）。範例池的多樣性和覆蓋度需要持續維護和更新。排行榜目前僅覆蓋英文場景，多語言 RAG 忠實度評測尚待擴展。
