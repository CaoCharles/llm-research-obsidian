# AutoFigure: Generating and Refining Publication-Ready Scientific Illustrations

## 摘要（中文翻譯）

高品質的科學插圖對於有效傳達複雜的科學與技術概念至關重要，然而手動製作插圖在學術界和產業界仍是公認的效率瓶頸。本文提出 FigureBench，首個針對從長篇科學文本生成科學插圖的大規模基準測試集，包含 3,300 組高品質的科學文本-插圖配對，涵蓋論文、綜述、部落格與教科書等多元來源。此外，本文提出 AutoFigure，首個基於 agentic framework 的自動化科學插圖生成系統。AutoFigure 採用 Reasoned Rendering 範式，在最終渲染前進行深度推理、重組與驗證，透過三階段管線（概念萃取與佈局生成、批評-精煉迴圈、美學渲染與文字後處理）產出結構完整且視覺美觀的出版級科學插圖。實驗結果顯示 AutoFigure 在所有基線方法中表現最優，人類專家評估中有 66.7% 的生成結果被認定達到出版標準。

## 問題背景

科學插圖是學術傳播的關鍵媒介，但手動製作通常需要研究者耗費數天時間，且需兼具領域知識與專業設計技能。現有自動化方法存在根本性缺陷：端到端 text-to-image 模型（如 GPT-Image）雖能產生美觀圖像，卻無法維持結構忠實度；程式碼生成方法（HTML/SVG）雖結構正確但美學品質不足；而現有 benchmark 多僅依賴短標題或 metadata 重建圖像，缺乏從長篇文本（平均 >10k tokens）生成插圖的評估框架。

## 解決方案

提出 AutoFigure，基於 Reasoned Rendering 範式的 agentic framework，將科學插圖生成解耦為三個階段：(1) Conceptual Grounding — 以 LLM 從非結構化長文本萃取實體與關係，生成結構化 symbolic layout（SVG/HTML）與風格描述；(2) Critique-and-Refine — 模擬 AI designer 與 AI critic 的對話迴圈，透過 test-time scaling 迭代優化佈局的對齊、平衡與避免重疊；(3) Aesthetic Rendering — 以 multimodal generative model 渲染高品質圖像，並透過 erase-and-correct 策略（OCR 偵測 + 向量文字覆蓋）確保文字清晰度。同時建構 FigureBench（3,300 組文本-插圖配對）作為標準化評估基準。

## 核心貢獻
1. 提出 FigureBench — 首個大規模長篇科學文本到插圖生成的 benchmark，包含 3,300 組高品質文本-插圖配對（300 測試集 + 3,000 開發集），涵蓋論文、綜述、部落格與教科書四類來源，測試集經雙人標註達 Cohen's kappa = 0.91 的高一致性
2. 提出 AutoFigure — 首個基於 Reasoned Rendering 範式的 agentic framework，透過概念萃取、critique-and-refine 自我精煉迴圈與 erase-and-correct 文字修正策略，解決了結構忠實度與美學品質之間的根本性 trade-off
3. 建立完整評估體系 — 結合 VLM-as-a-judge 的 referenced scoring（8 個子指標）與 blind pairwise comparison，並透過 10 位第一作者的人類專家評估驗證，66.7% 的生成結果被認定達到出版標準

## 技術方法

AutoFigure 採用解耦式生成範式，分為三個階段。**Stage I: Conceptual Grounding** — Concept-Extraction agent 從輸入長文本 T 中萃取精簡方法摘要 Tmethod 以及實體-關係集合，序列化為 symbolic layout S0（SVG/HTML 格式的有向圖 G0=(V0,E0)）與風格描述 A0，並光柵化為佈局參考圖 I0。**Stage II: Critique-and-Refine** — 實作自我精煉迴圈，AI critic 評估當前最佳佈局的對齊、平衡與重疊問題並產生文字回饋 F，AI designer 根據回饋重新詮釋 Tmethod 生成候選佈局，若候選分數 q_cand > q_best 則替換當前最佳，迭代至收斂或達到 N 次上限。**Stage III: Aesthetic Rendering** — 以 LLM 將最終佈局 (S_final, A_final) 轉換為詳盡的 text-to-image prompt，搭配結構圖輸入 multimodal generative model 渲染圖像；接著執行 erase-and-correct 流程：先以非 LLM eraser 清除圖中文字，再以 OCR 引擎擷取文字與邊界框，經 multimodal verifier 與 ground-truth 標籤交叉比對校正，最後以向量文字覆蓋產出最終插圖 I_final。

## 對我們的啟發
- [ ] 解耦式設計範式值得借鑑：將推理（結構規劃）與渲染（美學生成）分離，可同時兼顧結構忠實度與視覺品質，避免端到端模型在兩者間的 trade-off 困境
- [ ] Critique-and-refine 自我精煉迴圈作為 test-time scaling 策略，在 agentic system 中具有廣泛適用性，可應用於程式碼生成、文件撰寫等需要迭代優化的任務
- [ ] Erase-and-correct 策略為解決生成式模型文字渲染模糊問題提供了實用的 post-processing pipeline，結合 OCR + VLM 交叉驗證可確保文字準確性

## 限制與未來工作

AutoFigure 依賴多個商用模型（Gemini-2.5-Pro、GPT-Image）組合，推理成本較高且受 API 限制。目前僅支援靜態插圖生成，尚未涵蓋動態圖表或互動式視覺化。未來可探索端到端可訓練架構以降低延遲，並擴展至 data-driven charts 與動畫生成。
