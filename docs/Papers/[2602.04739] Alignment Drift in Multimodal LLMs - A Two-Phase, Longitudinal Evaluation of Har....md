## 問題背景

Multimodal LLMs（MLLMs）日益部署於真實應用，但其在對抗性提示下的安全性仍嚴重不足。現有 red teaming 研究多聚焦於單一時間點、純文字模態，缺乏跨模型世代的縱向追蹤，無法判斷 alignment 是否隨版本更新而退化（alignment drift），也無法釐清多模態輸入是否帶來額外攻擊面。

## 解決方案

提出兩階段縱向評估框架：使用由 26 位專業 red teamer 撰寫的 726 條固定對抗性提示（一半純文字、一半多模態），分別對兩代共 8 個 MLLMs 進行測試。Phase 1 評估 GPT-4o、Claude Sonnet 3.5、Pixtral 12B、Qwen VL Plus；Phase 2 評估其後繼者 GPT-5、Claude Sonnet 4.5、Pixtral Large、Qwen Omni。透過 82,256 筆人類 harm rating 標註，結合 Cumulative Link Mixed Model (CLMM) 與 Attack Success Rate (ASR) 進行跨世代、跨模態的安全性比較。

## 核心貢獻
1. 建立首個針對 MLLM 的縱向對抗性安全基準，使用固定 726 條 prompt 對兩代共 8 個商用模型進行可控比較，產生超過 82,000 筆人類標註。
2. 量化 alignment drift 現象：GPT 系列 ASR 跨世代增加 +8%（multimodal +18%）、Claude 系列 +10%，而 Pixtral 與 Qwen 分別下降 -7% 與 -5%，證明安全性並非隨更新單調改善。
3. 揭示模態敏感度的世代轉移：Phase 1 中純文字提示普遍更有效，但 Phase 2 中 GPT-5 與 Claude 4.5 在兩種模態間呈現近乎等同的脆弱性，顯示模態安全特性隨模型演進而質變。

## 技術方法

**資料集設計：** 26 位專業 red teamer 撰寫 726 條對抗性提示，涵蓋三類危害情境（illegal activity、disinformation、unethical behaviour），平均分為純文字與多模態兩組。多模態提示採用三種攻擊策略：(i) 將有害文字嵌入圖片、(ii) 無害圖片搭配有害文字、(iii) 有害圖片搭配中性文字。每條多模態提示配對一條等效純文字版本以隔離模態效應。

**標註流程：** 每條 prompt 送至所有模型產生回應，Phase 1 由 17 位標註者產生 47,408 筆評分，Phase 2 由 12 位標註者產生 34,848 筆評分，採用五級 Likert 量表（1=完全無害 至 5=極度有害）。標註者對模型身分與模態保持盲測。

**統計分析：** 使用 Cumulative Link Mixed Model (CLMM) 對全部 82,256 筆標註建模，固定效應包含 model（8 levels）、input modality、annotator demographics；隨機效應為 prompt 與 annotator intercepts。透過 Estimated Marginal Means (EMMs) 進行模型間成對比較，並以 Attack Success Rate (ASR) 作為補充指標量化脆弱程度。

## 關鍵結果

**Attack Success Rate (ASR) 跨世代比較：**

| Model | Phase 1 ASR | Phase 2 ASR | 變化 |
|-------|------------|------------|------|
| GPT-4o / GPT-5 | 0.19 | 0.27 | +8% |
| Claude 3.5 / Claude 4.5 | 0.09 | 0.19 | +10% |
| Pixtral 12B / Pixtral Large | 0.62 | 0.55 | -7% |
| Qwen VL Plus / Qwen Omni | 0.39 | 0.34 | -5% |

**關鍵發現：**
- Pixtral 系列在兩階段中始終最脆弱（Phase 1 ASR 0.62、Phase 2 ASR 0.55），Claude 系列最安全但主要依賴高 refusal rate 而非生成內容本身無害。
- Phase 1 中純文字提示對所有模型更有效（ASR 0.35 vs. 0.31），但 Phase 2 出現異質模式：GPT-5 multimodal ASR 0.27 vs. text 0.26（幾乎持平），Pixtral Large 仍維持 text-only 優勢（0.60 vs. 0.50）。
- GPT 與 Claude 後繼模型的 default refusal rate 顯著下降，但 ASR 反而上升，顯示降低 refusal 未必帶來更安全的生成行為。
- CLMM 分析中，Pixtral 12B 的 coefficient 最高（β = 3.81, p < 0.0001），確認其為最高風險模型。

## 對我們的啟發
- [ ] 模型安全評估需要縱向設計：單次評測無法捕捉 alignment drift，應使用固定 benchmark 持續追蹤每個版本的安全性回歸，尤其在 multimodal 攻擊面持續擴大的趨勢下。
- [ ] Refusal rate 不等於安全性：Claude 系列的低 harm score 主要來自高 refusal rate，而非生成內容本身更安全。評估 MLLM 時應將 refusal 與 generative harmfulness 分開建模，避免過度樂觀的安全結論。
- [ ] 多模態安全性會隨版本演進質變：Phase 1 中純文字攻擊普遍更有效，但 Phase 2 中部分模型的模態差距消失甚至反轉，提示我們在部署新版本時需重新驗證各模態的攻擊面，不能沿用舊版結論。

## 限制與未來工作

僅透過 API 黑箱測試，無法歸因至具體架構或訓練機制；僅涵蓋三類危害情境與 726 條英文提示，未涵蓋多語言及多輪對話攻擊；多模態僅限靜態圖片，未測試 audio、video、OCR-based 攻擊；refusal 未獨立建模，難以完全區分 abstention-driven 與 alignment-driven 安全性。
