# Clouding the Mirror: Stealthy Prompt Injection Attacks Targeting LLM-based Phishing Detection

## 連結

- 📥 [PDF](https://arxiv.org/pdf/2602.05484v1)

## 摘要（中文翻譯）

釣魚網站持續增長且日益複雜。近期研究利用 LLM 分析 URL、HTML 和渲染內容來判斷網站是否為釣魚站點。然而這些方法本質上容易受到 prompt injection (PI) 攻擊，因為攻擊者可完全控制釣魚網站的各種元素，利用人類與 LLM 之間的「感知不對稱性」(perceptual asymmetry)——在網頁中嵌入人類無法察覺但 LLM 可解析的指令，從而隱蔽地操縱其判斷。本論文首次針對多模態 LLM-based 釣魚偵測系統進行全面的 PI 風險評估，提出由 Attack Techniques 和 Attack Surfaces 構成的二維分類學，並實證評估多個主流 LLM 偵測系統的脆弱性。最後提出防禦框架 InjectDefuser，結合 prompt hardening、allowlist-based RAG 和 output validation，在多個模型上顯著降低攻擊成功率。

## 問題背景

LLM-based 釣魚偵測系統雖然能克服傳統方法在多語言、文化脈絡理解上的限制，但其本身引入了新的安全風險。攻擊者可完全控制釣魚網站的 URL、HTML、CSS、JavaScript 和嵌入資源，利用「感知不對稱性」在網頁中植入對人類不可見但 LLM 可讀取的惡意指令，使偵測系統將釣魚網站誤判為安全。此前尚無研究系統性地評估 PI 對釣魚偵測的具體威脅。

## 解決方案

本研究從攻擊與防禦兩端著手：攻擊面建構了一套完整的 PI 分類學（Attack Techniques x Attack Surfaces），涵蓋 5 種主要攻擊技術、2 種輔助技術和 6 種攻擊表面；防禦面提出 InjectDefuser 框架，透過三層防護機制——prompt hardening（UUID context boundaries、structured URL representation、meta-instructions）、allowlist RAG（品牌提取 + 合法域名向量資料庫查詢）、output validation（JSON schema 驗證）——系統性地偵測、隔離並中和惡意指令。

## 核心貢獻
1. 提出首個針對多模態 LLM-based 釣魚偵測的 PI 分類學，沿 Attack Techniques 和 Attack Surfaces 兩軸系統化攻擊策略，涵蓋釣魚場景特有的感知不對稱性
2. 基於此分類學對 GPT-5、Grok 4 Fast、Llama 4 Maverick、Gemma 3 27B 四個模型進行全面實證評估，揭示即使最先進的模型仍存在顯著脆弱性
3. 提出 InjectDefuser 防禦框架，整合 prompt hardening、allowlist RAG 和 output validation，將 GPT-5 的攻擊成功率從 39.9% 降至 0.3%

## 技術方法

**攻擊分類學**：

- **Attack Techniques（5 主要 + 2 輔助）**：
  - T-1 Legitimate Pretexting：偽裝為教育/研究用途使 LLM 誤判為合法
  - T-2 Role Hijacking：指派新角色改變 LLM 評估標準
  - T-3 Safety Policy Triggering：觸發安全機制迫使 LLM 拒絕回應
  - T-4 Tool/Function Hijacking：劫持輸出格式破壞下游 pipeline
  - T-5 Content Flooding/Distraction：消耗資源導致 DoS 或注意力偏移
  - AT-1 Stealth Encoding：視覺隱寫（背景色文字、極小字體）
  - AT-2 Parser Boundary Confusion：偽造結束標籤欺騙 LLM 解析器

- **Attack Surfaces（6 類）**：HTML Metadata、Script and Comment、HTML Invisible Content、HTML Visible Content、Embedded Resources、URL Structure

**InjectDefuser 防禦框架**：

1. **Prompt Hardening**：使用 UUID 標記 context boundaries 區分系統指令與外部資料；將 URL 拆解為結構化欄位（scheme、subdomain、domain、path、query）；加入 meta-instructions 明確標記外部內容為 UNTRUSTED
2. **Allowlist RAG**：從 HTML 提取品牌名稱，透過 Chroma 向量資料庫查詢合法域名清單，動態注入 prompt 提供可信參考
3. **Output Validation**：驗證 JSON 語法、必要欄位、資料型別、數值範圍，並檢查是否有非預期欄位

**實驗設計**：以 2025 Q2 最常被攻擊的 10 大品牌為基礎，建構 2,000 個 HTML 釣魚頁面（10 品牌 x 25 訊息 x 8 嵌入位置），另有 200 個 URL-based PI 樣本，並在三種偵測模式（Standard、Advanced、InjectDefuser）下評估。

## 關鍵結果

| 偵測模式 | GPT-5 ASR | Grok 4 Fast ASR | Llama 4 ASR | Gemma 3 ASR |
|---------|-----------|-----------------|-------------|-------------|
| Standard | 39.9% | 65.1% | 84.7% | 64.7% |
| Advanced | 10.1% | 76.2% | 75.6% | 55.4% |
| InjectDefuser | **0.3%** | 26.1% | 61.7% | 36.7% |

- Legitimate Pretexting 為最有效的攻擊技術，在 Standard Mode 下 GPT-5 達 58.3%、Grok 4 Fast 達 97.3%
- 不可見元素（HTML Metadata、Script/Comment、HTML Invisible Content）的攻擊成功率普遍高於可見元素
- URL-based PI 中，GPT-5 Standard Mode 的 ASR 為 20.0%，InjectDefuser 降至 0.0%
- 現有系統（PhishLLM、KnowPhish、PhishAgent）在 CRP 預測任務上 ASR 達 2.5%-25.0%

## 對我們的啟發
- [ ] 感知不對稱性是 LLM 安全的根本挑戰：任何讓 LLM 處理不受信任外部內容的應用都需考慮隱蔽指令注入風險，不僅限於釣魚偵測
- [ ] 多層防禦策略（prompt hardening + RAG + output validation）比單一防禦更為有效，InjectDefuser 的三階段 detect-isolate-neutralize 模式值得借鑑
- [ ] 模型能力與 PI 抗性並非正相關：Gemma 3 在某些場景下比更大的 Llama 4 更具抗性，暗示訓練方法和資料組成比模型規模更重要

## 限制與未來工作

- 實驗基於受控 HTML 模板，真實釣魚網站的變異性更高，攻擊成功率可能有所不同
- urlscan.io 搜索未發現野外實際部署的 PI 釣魚攻擊，但論文證明其技術可行性
- InjectDefuser 為外掛式框架，無法消除 LLM 本身的 PI 脆弱性，更根本的解決方案需要 fine-tuning 或 alignment 層面的改進
- 攻擊技術與攻擊表面為獨立分析，真實攻擊者可能組合多種技術與表面，需進一步評估組合攻擊的效果
- Allowlist RAG 依賴品牌與域名資料庫的覆蓋率與更新頻率，實際部署需參考 Tranco 等大規模域名列表
