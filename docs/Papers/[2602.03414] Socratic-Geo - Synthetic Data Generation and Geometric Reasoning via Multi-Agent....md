## 摘要（中文翻譯）

多模態大型語言模型顯著推進了視覺-語言理解，但即使最先進的模型仍難以進行幾何推理，揭示關鍵瓶頸：高品質圖像-文字對極度稀缺。人工標註成本過高，自動化方法無法確保保真度和訓練效果。現有方法要麼被動適應可用圖像，要麼採用低效的隨機探索加過濾，將生成與學習需求解耦。我們提出 Socratic-Geo，一個完全自主的框架，透過多代理互動動態耦合資料合成與模型學習。Teacher 代理生成參數化 Python 腳本並進行反思回饋，確保圖像-文字對品質。Solver 代理透過偏好學習優化推理。從僅 108 個種子問題出發，在六個基準上達到 49.11，超越基準線 2.43 點。

## 問題背景

MLLMs 在幾何推理上表現不佳，根本原因是高品質幾何圖像-文字對的極度稀缺。人工標註成本高昂，現有自動化方法要麼被動適應有限資料，要麼採用低效的隨機生成+過濾策略，未能將資料生成與模型學習需求有效結合。

## 解決方案

提出 Socratic-Geo 多代理框架，核心創新是動態耦合資料合成與模型學習。框架包含：(1) Teacher 代理生成參數化幾何題目腳本，透過 Reflect 和 RePI 機制確保可解性和視覺有效性；(2) Solver 代理透過偏好學習優化推理，失敗路徑指導 Teacher 進行針對性資料增強；(3) Generator 學習從「圖像-代碼-指令」三元組生成圖像。

## 核心貢獻
1. 設計多代理框架實現資料合成與模型學習的動態耦合
2. 提出 Reflect 和 RePI 機制確保合成資料的品質和有效性
3. 從 108 個種子問題擴展達到 SOTA，證明框架的資料效率

## 技術方法

Socratic-Geo 採用三代理架構：Teacher 負責生成參數化 Python 腳本繪製幾何圖形，使用 Reflect 機制檢查題目可解性，RePI 機制驗證視覺有效性。Solver 代理接收 Teacher 生成的資料進行偏好學習，錯誤案例回饋給 Teacher 進行針對性增強。Generator 獨立學習從累積的三元組資料生成圖像。實驗在六個幾何推理基準和 GenExam 圖像生成基準上評估。

## 對我們的啟發

## 限制與未來工作

目前僅在幾何推理領域驗證，對其他視覺推理任務（如物理、圖表理解）的通用性待驗證。多代理協調增加了訓練複雜度。
