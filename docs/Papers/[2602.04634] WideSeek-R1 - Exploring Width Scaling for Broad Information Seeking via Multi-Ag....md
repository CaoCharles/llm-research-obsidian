## 摘要（中文翻譯）

Recent advancements in Large Language Models (LLMs) have largely focused on depth scaling, where a single agent solves long-horizon problems with multi-turn reasoning and tool use. However, as tasks grow broader, the key bottleneck shifts from individual competence to organizational capability. In this work, we explore a complementary dimension of width scaling with multi-agent systems to address broad information seeking. Existing multi-agent systems often rely on hand-crafted workflows and turn-taking interactions that fail to parallelize work effectively. To bridge this gap, we propose WideSeek-R1, a lead-agent-subagent framework trained via multi-agent reinforcement learning (MARL) to synergize scalable orchestration and parallel execution. ## 問題背景

現有 LLM agent 主要透過 depth scaling（延長 chain-of-thought、多輪 tool use）解決問題，但面對需要廣泛蒐集多實體資訊的 broad information seeking 任務時，單一 agent 會遭遇 context pollution 與 sequential execution 瓶頸，導致效能嚴重下降。

## 解決方案

提出 WideSeek-R1，一個 lead-agent–subagent 階層式多代理框架，透過 multi-agent reinforcement learning (MARL) 端對端訓練，讓 lead agent 學習可擴展的任務分解與調度（scalable orchestration），subagents 則平行執行子任務（parallel execution）。所有 agent 共用同一個 LLM 但擁有獨立 context 與專用工具，實現 width scaling。

## 核心貢獻
1. 提出 WideSeek-R1 框架，以 MARL 端對端聯合訓練 lead agent 與 subagents，實現可學習的 orchestration 與平行 information seeking，突破傳統 hand-crafted workflow 的限制
2. 開源 20k 筆 broad information-seeking 訓練資料集，透過自動化 pipeline 從 HybridQA 產生 schema-constrained query 與 tabular answer，填補現有 multi-hop QA dataset 在寬度任務上的空白
3. 實驗證明 WideSeek-R1-4B 在 WideSearch benchmark 達到 Item F1 40.0%，效能媲美 DeepSeek-R1-671B（參數量少約 170 倍），且隨 subagent 數量增加呈現持續的 width scaling 增益

## 技術方法

系統由 lead agent 與多個 subagents 組成，共用同一個 Qwen3-4B 模型但 context 隔離。Lead agent 僅配備 `call_subagent` 工具，負責將廣泛任務拆解為可平行化的子任務並分派給 subagents；每個 subagent 配備 `search` 與 `access` 工具，在獨立 context 中平行執行資訊檢索。訓練基於 GRPO 擴展的 MARL：對同一 query 產生 G 組 multi-agent rollouts，以 verifiable outcome reward 計算 group-normalized advantage，並將相同 advantage 分配給同一 rollout 內所有 agent（multi-agent advantage assignment），避免複雜的 credit assignment。此外引入 dual-level advantage reweighting：token level 按各 turn 的 token 數加權避免短 turn 稀釋梯度，agent level 按 agent 數量平均避免 subagent 過多主導梯度。訓練資料透過三階段 pipeline 自動建構：Query Generation、Answer Generation（雙重獨立回答）、QA Pair Filtering（cell-wise consistency > 0.9 且足夠難度）。

## 關鍵結果

在 WideSearch benchmark 上的主要結果（Avg@4）：

| Model | Setting | Item F1 (%) | Row F1 (%) | Success Rate (%) |
|-------|---------|-------------|------------|------------------|
| WideSeek-R1-4B | Multi-Agent | **40.0** | **15.3** | 0.4 |
| Qwen3-4B | Multi-Agent | 31.2 | 8.4 | 0.0 |
| AgentFlow-7B | Multi-Agent | 28.7 | 9.0 | 0.4 |
| SingleSeek-R1-4B | Single-Agent | 28.1 | 6.5 | 0.3 |
| DeepSeek-R1-671B | Single-Agent | 41.3 | 20.7 | 0.4 |

- WideSeek-R1-4B 相較 single-agent 變體 SingleSeek-R1-4B，Item F1 提升 11.9%
- MARL 訓練相較未訓練 Qwen3-4B 多代理設定，Item F1 提升 8.8%
- Depth scaling 快速飽和，而 width scaling 隨 subagent 數量增加持續提升

## 對我們的啟發
- [ ] Width scaling 是一個被低估的 test-time compute 擴展維度：透過增加平行 agent 數量而非加深推理深度，可突破單一 agent 的 context pollution 與效率瓶頸，適合需要廣泛蒐集資訊的應用場景
- [ ] 端對端 MARL 訓練優於 hand-crafted workflow：讓 lead agent 與 subagents 共用模型並聯合優化，比起人工設計的多代理流程能學到更靈活的任務分解與協調策略
- [ ] 小模型透過多代理架構可達到大模型水準：4B 模型在 multi-agent 設定下媲美 671B 單一 agent，暗示未來可用多個輕量模型平行協作取代昂貴的超大模型

## 限制與未來工作

目前僅在 broad information seeking 任務上驗證，尚未擴展到 code generation、complex reasoning 等場景；訓練依賴離線 Wiki2018 知識庫，與線上搜尋存在分布差異；width scaling 的理論上界與最佳 agent 數量仍待探索。
