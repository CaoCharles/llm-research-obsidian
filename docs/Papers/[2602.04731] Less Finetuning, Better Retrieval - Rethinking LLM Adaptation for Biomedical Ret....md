# Less Finetuning, Better Retrieval: Rethinking LLM Adaptation for Biomedical Retrievers via Synthetic Data and Model Merging

## 摘要（中文翻譯）

Retrieval-augmented generation (RAG) has become the backbone of grounding Large Language Models (LLMs), improving knowledge updates and reducing hallucinations. Recently, LLM-based retriever models have shown state-of-the-art performance for RAG applications. However, several technical aspects remain underexplored on how to adapt general-purpose LLMs into effective domain-specific retrievers, especially in specialized domains such as biomedicine. We present Synthesize-Train-Merge (STM), a modular framework that enhances decoder-only LLMs with synthetic hard negatives, retrieval prompt optimization, and model merging. Experiments on a subset of 12 medical and general tasks from the MTEB benchmark show STM boosts task-specific experts by up to 23.5\% (average 7.5\%) and produces merged model

## 問題背景

將通用 LLM 轉化為生物醫學領域的 dense retriever 時，現有方法依賴大規模 contrastive pre-training（如 11.4M pairs）與完整 fine-tuning，成本高且缺乏對 hard negative mining、prompt optimization 及 model merging 等關鍵技術面向的系統性研究。

## 解決方案

提出 Synthesize-Train-Merge (STM) 模組化框架，包含三大軸線：(1) 利用 GPT-4.1 生成 synthetic hard negatives 提升對比學習品質；(2) 透過 DSPy + GEPA 自動最佳化 retrieval prompt；(3) 將多個 LoRA expert 以 Linear/TIES merging 合併為單一模型，大幅減少所需資料量（從 11.4M 降至 1.4M pairs）且無需 pre-training。

## 核心貢獻
1. 首次系統性評估 Linear 與 TIES 兩種 model merging 技術於 LLM-based retriever，證明 merged model 顯著優於單一 expert 及 full fine-tuning baseline
2. 對 synthetic hard negatives 與 retrieval prompt optimization 兩個未充分探索的軸線進行系統性研究，驗證兩者皆能帶來穩定提升
3. 以更少資料達到更好效果：無需 pre-training、僅使用不到 10% 的原始訓練資料，merged model 即可在 MTEB 醫學與通用任務上超越 BMRetriever 等 baseline

## 技術方法

框架分三階段：**Synthetic Data** 階段，給定 query、positive passage 與 mined negative，以 GPT-4.1 生成語意相反但詞彙相近的 hard negative，同時用 LLaMA-70B 搭配 GEPA 自動產生最佳化 retrieval prompt。**LoRA Fine-tuning** 階段，將 BMRetriever dataset 拆分為 Medical Real、Medical Synthetic、NLU、Search 四組，分別訓練四個 LoRA expert，採用 InfoNCE contrastive loss 搭配 in-batch negatives。**Model Merging** 階段，以 Linear averaging 或 TIES merging 合併多個 expert 的 LoRA 參數，透過 grid search 決定最佳權重係數，無需額外訓練即可整合各 expert 的互補能力。實驗涵蓋 Qwen3 0.6B、Gemma 2B、Phi4 3.8B 三種 backbone。

## 關鍵結果

| 模型 | 規模 | Avg Medical | Avg General | Avg All |
|---|---|---|---|---|
| BM25 | - | 0.532 | 0.515 | 0.525 |
| BMRetriever | 2B | 0.645 | 0.560 | 0.609 |
| LLM2Vec | 3B | 0.635 | 0.597 | 0.619 |
| STM-Qwen3 | 0.6B | 0.638 | 0.585 | 0.616 |
| STM-Gemma | 2B | 0.654 | 0.577 | 0.622 |
| STM-Phi4 | 3.8B | 0.677 | 0.603 | **0.646** |

STM merged model 相比同 backbone 的 full fine-tuning 平均提升 7.5%，最高達 23.5%。僅用 1.4M pairs（原始 11.4M 的 12%）即超越需大規模 pre-training 的 BMRetriever。

## 對我們的啟發
- [ ] Model merging（Linear/TIES）是建構 domain-specific retriever 的高效策略，可取代昂貴的 joint fine-tuning，適合資源受限場景
- [ ] LLM-generated synthetic hard negatives 能有效提升 contrastive learning 品質，比傳統 BM25 mining 更具語意鑑別力
- [ ] Retrieval prompt optimization 對 embedding 品質影響顯著，即使隨機多樣化 prompt 也能帶來正則化效果，值得在 RAG pipeline 中採用

## 限制與未來工作

僅在 MTEB 的 12 個子任務上評估，尚未涵蓋更多語言與領域；merging 權重需 grid search，缺乏自動化搜索策略；未探索更大規模 backbone 的表現。
