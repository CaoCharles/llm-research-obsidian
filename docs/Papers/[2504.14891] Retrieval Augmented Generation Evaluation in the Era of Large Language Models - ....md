## 摘要（中文翻譯）

檢索增強生成（RAG）的近期進展透過將大型語言模型與外部資訊檢索整合，實現了準確、即時且可驗證的文本生成，革新了自然語言處理領域。然而，RAG 系統的評測因其結合檢索與生成組件的混合架構，以及對動態知識來源的依賴而面臨獨特挑戰。為此，本文提供 RAG 評測方法與框架的全面綜述，系統性回顧了 LLM 時代中傳統與新興的評測方法，涵蓋系統性能、事實準確性、安全性和計算效率。研究還整理並分類了 RAG 專用資料集和評測框架，對高影響力 RAG 研究中的評測實踐進行元分析。據作者所知，這是 RAG 評測領域最全面的綜述，橋接傳統與 LLM 驅動的方法。

## 問題背景

RAG 系統的評測面臨多重挑戰：(1) 混合架構使得單獨評測檢索或生成組件不足以反映系統整體品質；(2) 動態知識來源導致評測結果隨時間變化；(3) LLM 時代帶來新的評測需求（如 faithfulness、hallucination detection），傳統指標難以充分捕捉；(4) 缺乏統一的評測框架和資料集分類體系。

## 解決方案

提供 RAG 評測的全面分類法（taxonomy），從四個維度系統化現有評測方法：系統性能（端到端效果）、事實準確性（faithfulness 和 factuality）、安全性（adversarial robustness）和計算效率（latency 和 throughput）。同時建構 RAG 評測資料集和框架的結構化目錄，並對高影響力論文的評測實踐進行元分析，揭示當前評測的趨勢與缺口。

## 核心貢獻
1. 建構 RAG 評測的四維度分類法（性能、準確性、安全性、效率），系統化整理 LLM 時代的評測方法論
2. 編纂最全面的 RAG 專用資料集與評測框架目錄，涵蓋 RAGAS、TruLens、DeepEval 等主流工具
3. 透過高影響力論文的元分析揭示 RAG 評測實踐的趨勢：自動化指標使用增加、LLM-as-Judge 逐漸取代人工評估

## 技術方法

本綜述採用系統性文獻回顧方法，覆蓋 RAG 評測的完整生態系統。評測方法按四個維度組織：

(1) 系統性能評測：回顧端到端指標（如 F1、BLEU、ROUGE）和組件級指標（檢索精確率/召回率、生成品質分數），分析各指標在 RAG 場景中的適用性和局限。

(2) 事實準確性評測：重點回顧 faithfulness（生成內容是否忠於檢索到的文檔）和 factuality（生成內容是否符合事實）的評測方法，涵蓋基於 NLI 的方法、基於 QA 的方法和 LLM-as-Judge 方法。

(3) 安全性評測：回顧 RAG 系統面臨的對抗攻擊（如 knowledge poisoning、prompt injection via retrieval）及相應的安全評測基準。

(4) 計算效率評測：分析 latency、throughput、token 使用量等效率指標在 RAG 評測中的角色。

此外，研究系統整理了 RAG 評測工具（RAGAS、TruLens、DeepEval、Arize Phoenix 等），並對 2023-2025 年發表的高影響力 RAG 論文進行元分析，統計各類評測方法的使用頻率和趨勢。

## 關鍵結果

| 評測維度 | 常用方法 | 主流工具 | 趨勢 |

## 對我們的啟發
- [ ] RAG 評測需要多維度框架——單一指標無法全面反映系統品質，應同時考慮 faithfulness、relevance、safety 和 efficiency
- [ ] LLM-as-Judge 正在成為 RAG 評測的主流方法，但其本身的可靠性（如對幻覺的敏感度）仍需校準——形成了評測的遞歸問題
- [ ] RAG 安全性評測是當前最大的缺口：knowledge poisoning 和 retrieval-based prompt injection 的評測基準嚴重不足，是急需填補的方向

## 限制與未來工作

作為綜述論文，本身不提出新方法，主要貢獻在整理和分類。評測工具的快速迭代可能使部分內容過時。對於特定領域（如醫療、法律）的 RAG 評測特殊需求覆蓋有限。此外，元分析的論文選取標準可能引入選擇偏差。
