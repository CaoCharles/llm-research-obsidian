# ObliInjection: Order-Oblivious Prompt Injection Attack to LLM Agents with Multi-source Data

## 連結

- 📥 [PDF](https://arxiv.org/pdf/2512.09321v3)
- 📎 本地 PDF: [PDF](../PDFs/2512.09321.pdf)

## 摘要（中文翻譯）

Prompt injection 攻擊旨在污染 LLM 的輸入資料，使其完成攻擊者指定的任務而非預期任務。在許多應用和 agent 中，輸入資料來自多個來源，每個來源貢獻整體輸入的一個片段。在這些多來源場景中，攻擊者可能只控制部分來源，且通常不知道片段在輸入中的排列順序。現有攻擊要嘛假設攻擊者控制整個輸入，要嘛忽略片段排序的不確定性。本文提出 ObliInjection，首個針對多來源輸入 LLM 應用的 prompt injection 攻擊。引入兩項關鍵技術創新：order-oblivious loss（量化 LLM 在任意片段排列下完成攻擊任務的可能性）和 orderGCG 演算法（優化污染片段以最小化此損失）。在三個資料集和十二個 LLM 上的實驗表明，即使僅污染 6-100 個片段中的 1 個，ObliInjection 仍高度有效。

## 問題背景

現實中許多 LLM 應用處理多來源輸入資料（如多篇評論、多篇文件、多個搜尋結果），攻擊者只能控制其中部分來源且不知道片段排列順序。現有 prompt injection 攻擊假設攻擊者控制整個輸入或忽略排序不確定性，導致在多來源場景中效果有限。需要一種能在未知排列順序下仍然有效的攻擊方法。

## 解決方案

ObliInjection 引入兩項核心創新：(1) **Order-Oblivious Loss**——衡量在所有可能的片段排列下，LLM 完成攻擊者任務的期望交叉熵損失，使優化不依賴特定排序假設；(2) **orderGCG 演算法**——基於 GCG 的改進版，透過 Taylor 展開梯度近似識別候選替換 token，使用 buffer 累積跨迭代的損失估計（而非標準 GCG 的單步估計），並採用 beam search 策略保留最佳候選。

## 核心貢獻
1. 提出首個針對多來源輸入 LLM 應用的 prompt injection 攻擊，解決了片段排列順序未知的核心挑戰
2. 設計 order-oblivious loss 和 orderGCG 演算法，在三個資料集上達到約 99% 的攻擊成功率，即使僅污染 100 個片段中的 1 個
3. 證明現有防禦方法（StruQ、SecAlign、偵測方法）對此攻擊均不足，將於 NDSS 2026 發表

## 技術方法

**Order-Oblivious Loss**：對所有可能的片段排列計算 LLM 完成攻擊任務的期望交叉熵損失。由於排列數爆炸，使用蒙特卡羅採樣近似期望值。

**orderGCG 演算法**：
1. Token 級候選：透過 Taylor 展開梯度近似識別高潛力替換 token
2. 片段級候選：組合多個 token 替換
3. Buffer 累積：跨迭代維護損失估計的移動平均（解決蒙特卡羅採樣噪音）
4. Beam search：跨迭代保留最佳候選

**實驗設置**：
- 三個資料集：Amazon Reviews（100 評論/任務）、Multi-News（6 文章/任務）、HotpotQA（10 文件/任務）
- 七個開源 LLM：Llama-3-8B、Llama-3.1-8B、Mistral-7B、Qwen-2.5-7B、Falcon3-7B、Llama-4-17B、Qwen3-4B
- 閉源模型：GPT-4o、Gemini-2.5-flash
- 硬體：A100 GPU，每次優化約 4 小時

## 關鍵結果

| 資料集 | ObliInjection ASR | Neural Exec ASR | JudgeDeceiver ASR |
|--------|-------------------|-----------------|--------------------|
| Amazon Reviews | ~99% | 7.1% | 56.8% |
| Multi-News | ~99% | — | — |
| HotpotQA | ~99% | — | — |

**關鍵發現**：
- 僅污染 1/6 到 1/100 個片段即可達到高 ASR
- 跨 12 個 LLM（含開源和閉源）均有效
- 現有防禦（StruQ、SecAlign、偵測方法）均無法有效緩解

## 對我們的啟發
- [ ] 多來源輸入場景大幅擴展了 prompt injection 的攻擊面——攻擊者只需控制 100 個片段中的 1 個即可達到 99% ASR，這對 RAG 系統、多文件摘要、評論聚合等應用構成嚴重威脅
- [ ] Order-oblivious loss 的設計思路可推廣至其他需要處理排列不確定性的對抗場景，是 adversarial ML 中排列魯棒性的重要方法論貢獻
- [ ] 每次優化需約 4 小時（A100 GPU），表明此攻擊在計算成本上仍有一定門檻，但隨著計算資源降價和方法改進，實際威脅將持續增大

## 限制與未來工作

需要生成「影子片段」作為未知乾淨資料的代理，影子品質影響攻擊效果。計算開銷較高（A100 GPU 約 4 小時/次優化）。成功指標基於簡化的關鍵字匹配，可能存在誤判。現有防禦評估有限，未考慮專門針對此攻擊設計的防禦。
