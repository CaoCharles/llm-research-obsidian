# Understanding Agent Scaling in LLM-Based Multi-Agent Systems via Diversity

## 摘要（中文翻譯）

基於 LLM 的 multi-agent systems (MAS) 已成為解決單一 LLM 難以處理之複雜任務的有力方法。直覺上可透過增加 agent 數量來提升效能，但研究發現在同質化設定下此策略呈現強烈的邊際遞減效應，而引入異質性（如不同模型、prompt 或工具）則能持續帶來顯著提升。本文提出一個 information-theoretic framework，證明 MAS 效能受限於 intrinsic task uncertainty H(Y|X) 而非 agent 數量。作者推導出與架構無關的上界，顯示改善取決於系統存取的 effective channels 數量。同質 agent 因輸出高度相關而提早飽和，異質 agent 則提供互補性證據。作者進一步提出 K*（effective channel count）指標，無需 ground-truth 即可量化有效通道數。實驗證明異質配置穩定優於同質擴展：僅 2 個多樣化 agent 即可匹敵甚至超越 16 個同質 agent 的表現。

## 問題背景

在 LLM-based MAS 中，單純增加同質 agent 數量（相同模型、prompt、配置）會出現強烈的 diminishing returns：效能在少量 agent 時快速提升，但邊際增益迅速趨近於零。現有研究缺乏統一的理論框架來解釋為何同質擴展會飽和、為何異質性（diversity）能持續改善效能，以及如何在不同 MAS workflow（voting、debate、orchestration）間建立通用的 scaling 理論。

## 解決方案

提出 information-theoretic framework，將 MAS 效能以 usable evidence I(Z₁:n; Y|X) 量化，證明其上界為 intrinsic task uncertainty H(Y|X)。引入 effective channel count K 與 complementarity rate α 兩個核心概念：K 衡量系統中非冗餘的獨立推理路徑數量，α 衡量新通道提供互補證據的機率。推導出 residual uncertainty 以 (1−α)^K 幾何速率收斂的定理。進一步提出 K*（基於 embedding space 的 entropy effective rank）作為無需標籤的實用指標，透過 cosine similarity Gram matrix 的特徵值分布估計有效通道數。

## 核心貢獻
1. 推導出與架構無關的 performance bounds，證明 MAS 效能受限於 intrinsic task uncertainty H(Y|X)，改善來自增加 effective channels 而非 agent 數量，並針對 parallel voting 與 sequential debate 分別建立 type-dependent ceilings。
2. 分析代表性 MAS 範式（vote、debate），證明同質配置因高度相關的 evidence 而快速飽和，異質性透過降低冗餘、擴展 effective channel capacity 來持續提升效能，並推導出 heterogeneity advantage bound。
3. 提出 K*（effective channel count）指標，基於 agent 輸出在 embedding space 中的 entropy effective rank 計算，無需 ground-truth labels 即可量化非冗餘資訊源數量，為 diversity-driven MAS design 提供實用的設計準則。

## 技術方法

**理論框架：** 將 MAS 建模為 N 個 agent 透過 workflow 產生 dialogue transcript Z₁:n，以 conditional mutual information I(Z₁:n; Y|X) 作為 usable evidence。透過 chain rule 分解為各 agent call 的 incremental contribution Δᵢ = I(Zᵢ; Y|X, Z<i)，揭示效能取決於非冗餘證據量而非總 call 數。推導 Finite Information Budget 定理：IMAS(n) ≤ H(Y|X)，並針對 parallel（條件獨立假設）和 sequential 兩類 workflow 建立 type-dependent upper bounds。

**Effective Channel Model：** 定義 complementarity rate α ∈ (0,1) 與 effective channel count K，證明 Geometric Contraction 定理：residual uncertainty ≤ (1−α)^K · H(Y|X) ≤ e^{−αK} · H(Y|X)。推導 heterogeneity advantage：當 α_heterog · K_heterog > α_homog · K_homog 時，異質設計的 information recovery 下界嚴格高於同質設計。

**K* 指標：** 對 agent 輸出進行 embedding，計算 cosine similarity Gram matrix G，trace-normalize 為 ρ = G/Tr(G)，定義 K* = 2^{H(ρ)}（entropy effective rank）。K* ∈ [1, n]，輸出完全相同時趨近 1，完全正交時趨近 n。

**實驗設定：** 使用 Qwen-2.5-7B、Llama-3.1-8B、Mistral-7B 三個開源模型，在 GSM8K、ARC、Formal Logic、TruthfulQA、HellaSwag、WinoGrande、Pro Medicine 七個 benchmark 上，以 Vote 和 Debate 兩種 workflow 測試四層漸進式 diversity level（L1-L4）。

## 關鍵結果

| 比較維度 | 結果 |
|---|---|
| 同質 scaling 飽和 | 三個模型在七個 benchmark 上，agent 數超過 8-12 後效能提升趨近於零 |
| Persona diversity 效益 | 異質配置（Heterog）在 Vote 平均提升 +4.4~+8.6%，Debate 平均提升 +3.3~+6.6%（N=12 時） |
| 2 diverse vs 16 homogeneous | 2 個異質 agent（L4）在多數 benchmark 上匹敵或超越 16 個同質 agent（L1） |
| Efficiency gains | L4 配置僅需 2 個 agent 即可達到 L1 需 16 個 agent 的 baseline（Vote: 67.71% vs 65.34%） |
| Debate 中 diversity 效果 | Formal Logic 上 Debate 異質配置最高提升 +10.3%（N=8），TruthfulQA 上提升 +24.7%（N=2） |
| K* 與效能相關性 | K* 指標與實際效能高度正相關，能在無標籤情況下預測 MAS 效能趨勢 |
| 1−e^{−αK} 曲線擬合 | 實驗觀察到的 fast-then-slow scaling 行為符合理論預測的幾何收斂模式 |

## 對我們的啟發
- [ ] 設計 MAS 時應優先考慮 agent diversity（不同模型、persona、工具）而非單純增加 agent 數量；2 個異質 agent 可能比 16 個同質 agent 更有效，大幅降低 inference cost
- [ ] K* 指標可作為 MAS 部署時的實用診斷工具，在無 ground-truth 的情況下評估系統是否存在冗餘，指導何時該引入新的 diversity 來源而非增加 agent 數量
- [ ] Information-theoretic 框架（usable evidence、effective channels）提供了跨 workflow 的統一分析語言，可應用於評估任何 MAS 架構的 scaling 效率，包括 voting、debate 與 orchestration 等不同範式

## 限制與未來工作

實驗僅使用 7-8B 參數級別的開源模型，未驗證於更大規模或閉源模型；K* 基於 embedding similarity 估算，可能無法完全捕捉語義層面的互補性；理論框架假設條件獨立等簡化假設，對複雜互動式 workflow 的適用性有待進一步驗證。
