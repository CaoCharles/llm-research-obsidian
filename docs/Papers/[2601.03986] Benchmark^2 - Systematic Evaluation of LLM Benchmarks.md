# Benchmark^2: Systematic Evaluation of LLM Benchmarks

## 摘要（中文翻譯）

大型語言模型（LLMs）基準測試的快速增長，迫切需要系統性方法來評估基準測試本身的品質。本文提出 Benchmark²，一個包含三個互補指標的綜合框架：(1) 跨基準排名一致性（Cross-Benchmark Ranking Consistency），衡量某基準是否產生與其他同類基準一致的模型排名；(2) 區分度分數（Discriminability Score），量化基準區分不同模型的能力；(3) 能力對齊偏差（Capability Alignment Deviation），識別強模型失敗但弱模型成功的異常題目。研究在涵蓋數學、推理和知識領域的 15 個基準上進行大規模實驗，評估了 4 個模型家族共 11 個 LLMs。分析揭示現有基準之間存在顯著的品質差異，並證明基於本文指標的選擇性基準建構可以在大幅減少測試集的情況下達到相當的評估效果。

## 問題背景

LLM 基準測試數量激增，但缺乏系統性方法評估基準本身的品質。不同基準可能產生矛盾的模型排名，部分基準包含大量無法有效區分模型的題目，甚至存在「弱模型答對、強模型答錯」的異常現象，使得研究者難以判斷哪些基準值得信賴。

## 解決方案

提出 Benchmark² 元評估框架，從三個維度系統性評估基準品質。核心創新在於將「評估基準的基準」形式化：跨基準排名一致性檢驗外部效度（external validity），區分度分數衡量評測精度（precision），能力對齊偏差則識別內部異常（internal anomalies）。三者結合可全面診斷基準的強項與弱點，並指導更高效的基準建構。

## 核心貢獻
1. 提出三維度元評估框架（排名一致性、區分度、能力對齊偏差），首次系統化評估 LLM 基準品質
2. 在 15 個基準 × 11 個模型的大規模實驗中揭示現有基準的品質差異，發現部分廣泛使用的基準區分度不足
3. 證明基於元指標的選擇性題目篩選可大幅減少測試集規模（同時維持評估效果），為高效基準建構提供方法論

## 技術方法

Benchmark² 的三個指標分別從不同維度衡量基準品質。跨基準排名一致性（CBRC）計算目標基準的模型排名與其他基準排名的 Kendall τ 或 Spearman ρ 相關係數，取平均值衡量外部一致性。區分度分數（DS）基於項目反應理論（Item Response Theory），計算每道題目的 Fisher 資訊量，聚合得到基準整體的區分能力。能力對齊偏差（CAD）識別同一模型家族內出現「弱模型成功-強模型失敗」的反轉題目，高 CAD 值表示基準包含大量不穩定或有缺陷的題目。

實驗涵蓋 15 個基準（包括 MMLU、GSM8K、ARC 等），跨數學、推理、知識三大領域，評估了 GPT-4、Claude-3、Llama-3 等 4 個家族共 11 個模型。此外，作者利用三個指標進行題目篩選，構建精簡測試集，驗證在僅保留高品質題目的情況下能否維持相當的排名能力。

## 關鍵結果

| 基準 | 排名一致性 (CBRC) | 區分度 (DS) | 能力對齊偏差 (CAD) |
|------|------------------|------------|-------------------|
| MMLU | 高 | 中等 | 低 |
| GSM8K | 高 | 高 | 低 |
| ARC-Challenge | 中等 | 中等 | 中等 |
| 部分新興基準 | 低 | 低 | 高 |
| 篩選後測試集 | 高（與完整集相當） | 高 | 低 |
| 測試集縮減率 | - | - | 減少 40-60% 題目 |

## 對我們的啟發
- [ ] 基準測試本身需要品質控制——不應盲目信任所有基準的排名結果，元評估框架應成為基準開發的標準程序
- [ ] 區分度是基準品質的關鍵維度：大量題目對前沿模型已無區分力，定期更新和篩選題目是維持基準有效性的必要措施
- [ ] 選擇性題目篩選可在維持評估精度的同時大幅降低計算成本（40-60%），這對大規模模型評測的效率優化有直接應用價值

## 限制與未來工作

目前僅在選擇題和簡答題格式的基準上驗證，對於開放式生成任務的基準評估需要不同的方法。能力對齊偏差的計算依賴同一模型家族的假設，跨家族的能力對齊分析更為複雜。此外，元指標本身的穩定性隨模型集合的選擇而變化。
