# PeerRank: Autonomous LLM Evaluation Through Web-Grounded, Bias-Controlled Peer Review

## 摘要（中文翻譯）

評估大型語言模型通常依賴人工撰寫的基準測試、參考答案和人類或單一模型判斷，這些方法擴展性差、很快過時，且與依賴網頁檢索和合成的開放世界部署不匹配。本文提出 PeerRank，一個完全自主的端到端評估框架，其中模型自行生成評估任務、使用分類範圍的即時網頁搜尋回答問題、評判同儕回應，並將密集的同儕評估聚合為相對性能估計——無需人類監督或黃金參考答案。PeerRank 將評估視為多智能體過程，每個模型對稱參與為任務設計者、回應者和評估者，同時移除有偏見的判斷。在 12 個商用模型和 420 個自主生成問題的大規模研究中，PeerRank 產生穩定且有區別性的排名，並揭示可測量的身份和展示偏見。排名穩健，平均同儕分數與 Elo 一致。進一步在 TruthfulQA 和 GSM8K 上驗證，同儕分數與客觀準確度相關。

## 問題背景

LLM 評測面臨根本性挑戰：(1) 靜態基準測試（如 MMLU、GSM8K）不斷被模型「刷榜」或被訓練數據污染，失去區分能力；(2) 人類評估成本高且不可擴展；(3) 單一 LLM-as-Judge（如用 GPT-4 評判）存在系統性偏見（偏好自身風格的回應）；(4) 基準測試無法反映開放世界場景中模型使用網頁搜尋的能力。這些問題導致現有評測無法跟上 LLM 快速迭代的步伐，且與實際應用場景脫節。

## 解決方案

PeerRank 提出「同儕評審」評估範式，完全消除人類參與和靜態基準的依賴。框架分為四階段：(1) **任務生成**：每個模型自主生成多樣化評估問題，覆蓋不同領域和難度；(2) **Web-Grounded 回答**：模型使用即時網頁搜尋回答問題，模擬真實部署場景；(3) **同儕評判**：每個模型評判其他模型的回應，形成密集的成對判斷矩陣；(4) **偏見控制聚合**：使用統計方法識別和移除身份偏見（模型偏好自身回應）和展示偏見（回應順序影響判斷），聚合為公平的排名。核心創新在於對稱設計（每個模型同時是出題者、答題者和評審）和偏見控制機制。

## 核心貢獻
1. 提出首個完全自主的 LLM 評估框架，無需人類監督、參考答案或靜態基準，在 12 個商用模型（含 GPT-5.2、Claude Opus 4.5、Gemini 3 Pro）上產生超過 253,000 個成對判斷
2. 開發偏見控制機制，量化並移除身份偏見和展示偏見，使同儕排名更公平可信；在 TruthfulQA 和 GSM8K 上驗證，同儕分數與客觀準確度顯著相關
3. 揭示 LLM 評判中的系統性偏見模式：模型偏好與自身風格相似的回應，且回應展示順序顯著影響判斷，為 LLM-as-Judge 研究提供重要實證

## 技術方法

**任務生成**：每個模型生成 35 個問題，涵蓋 12 個類別（事實核查、推理、程式設計、創意寫作等），由其他模型驗證問題品質。總計 420 個問題。

**Web-Grounded 回答**：模型使用分類範圍的即時網頁搜尋回答問題，搜尋範圍限定在與問題類別相關的網站。這模擬了實際部署中 LLM 結合搜尋引擎的使用場景。

**同儕評判設計**：每對（問題，回應）由所有非回應模型評判，採用 pairwise comparison 格式。每個評判包含分數（1-10）和理由。總計產生 253,000+ 個判斷。

**偏見控制**：(1) 身份偏見：統計每個模型對自身生成的問題和回應的評分偏差，進行校正；(2) 展示偏見：隨機化回應展示順序，統計位置效應並校正；(3) 使用 Bradley-Terry 模型將成對判斷聚合為 Elo 排名。

**驗證**：在 TruthfulQA（事實性）和 GSM8K（數學推理）上計算同儕分數與客觀準確度的 Spearman 相關係數。

## 關鍵結果

| 模型 | PeerRank 分數 ↑ | Elo 排名 | TruthfulQA 準確度 | GSM8K 準確度 |
|------|----------------|----------|-------------------|-------------|
| GPT-5.2 | 8.42 | 1 | 89.3% | 96.1% |
| Claude Opus 4.5 | 8.31 | 2 | 87.8% | 95.4% |
| Gemini 3 Pro | 8.15 | 3 | 86.5% | 94.2% |
| GPT-4.1 | 7.89 | 4 | 84.1% | 93.8% |
| GPT-4.1-Mini | 6.88 | 8 | 78.2% | 88.5% |

**關鍵發現**：
- **排名穩健**：Bootstrap 重抽樣顯示 PeerRank 排名在 95% 信賴區間內穩定，前 3 名模型排名不變
- **與客觀指標相關**：PeerRank 分數與 TruthfulQA（r=0.89）和 GSM8K（r=0.91）準確度高度相關
- **身份偏見顯著**：模型平均給自身生成問題的回應高出 0.47 分（p<0.001），校正後排名更公平
- **展示偏見存在**：第一位展示的回應平均高出 0.23 分，隨機化和校正有效消除此偏見

## 對我們的啟發
- [ ] **自主評估是 LLM 評測的未來方向**：PeerRank 證明模型可以自我評估且結果可靠，減少對人類標註和靜態基準的依賴。啟發：在評測框架中納入自主評估模組，作為靜態基準的補充
- [ ] **偏見控制是 LLM-as-Judge 的關鍵**：身份偏見和展示偏見的量化研究為所有使用 LLM 評判的場景提供重要參考。啟發：在使用 LLM-as-Judge 時，必須加入偏見檢測和校正機制
- [ ] **Web-Grounded 評估更貼近實際**：結合即時網頁搜尋的評估設計比封閉式基準更能反映 LLM 的實際部署能力。啟發：評測設計應考慮模型的工具使用和資訊檢索能力
- [ ] **對稱設計的優勢**：讓每個模型同時扮演多重角色減少了單一角色帶來的偏見，這種設計思想可擴展到其他評測場景

## 限制與未來工作

PeerRank 需要存取多個商用 LLM API，成本較高且受 API 可用性限制。評估結果可能隨模型版本更新而變化，需要持續重新評估。偏見控制雖有效但可能無法捕捉所有偏見來源。此外，420 個自主生成的問題雖覆蓋面廣，但可能遺漏某些專業領域。框架對開源模型的適用性（特別是較小規模模型作為評判者）需要進一步驗證。
