## 摘要（中文翻譯）

代理記憶體系統需要容納持續增長的資訊，同時支援高效的上下文感知檢索。抽象對於擴展記憶體至關重要，但通常以犧牲細粒度細節為代價，影響有效推理。我們提出 Memora，一種和諧記憶體表示，在結構上平衡抽象與具體性。Memora 透過主要抽象索引具體記憶值，將相關更新整合為統一條目，同時線索錨點擴展跨記憶體多面向的檢索存取並連接相關記憶。基於此結構，我們採用主動利用記憶連接的檢索策略，檢索超越直接語義相似度的相關資訊。理論上，標準 RAG 和知識圖譜記憶體系統是我們框架的特例。Memora 在 LoCoMo 和 LongMemEval 基準上達到新 SOTA。

## 問題背景

代理記憶體系統面臨抽象與具體性的兩難：抽象化有助於記憶體擴展和效率，但會損失推理所需的細粒度細節；保留細節則面臨儲存和檢索效率問題。現有方法（RAG、知識圖譜）未能有效平衡這兩個需求。

## 解決方案

提出 Memora 和諧記憶體表示，核心創新是結構性地平衡抽象與具體：(1) 主要抽象作為索引，連結具體記憶值並整合相關更新；(2) 線索錨點擴展多面向檢索存取，連接相關記憶形成網絡；(3) 檢索策略主動利用記憶連接，超越單純語義相似度。框架統一了 RAG 和知識圖譜方法。

## 核心貢獻
1. 提出和諧記憶體表示，結構性平衡抽象與具體性
2. 設計線索錨點機制，實現多面向記憶連接和跨記憶檢索
3. 理論證明 RAG 和知識圖譜記憶體系統是 Memora 的特例

## 技術方法

Memora 採用階層式記憶結構：頂層是主要抽象，作為記憶索引；中層是具體記憶值，儲存細節資訊；橫向透過線索錨點連接相關記憶。檢索時先透過抽象定位，再透過錨點擴展檢索範圍，最後提取具體值。理論分析證明 RAG（無抽象層）和知識圖譜（純結構化）是該框架的特殊配置。實驗在 LoCoMo 和 LongMemEval 長期記憶基準上評估。

## 限制與未來工作

線索錨點的建立和維護增加了系統複雜度。對於快速變化的記憶內容，抽象更新策略可能成為瓶頸。在極大規模記憶體上的效率待驗證。
