# Open Evaluation Agent: Efficient and Promptable Evaluation of Visual Generative Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.09666)
- 📥 [PDF](https://arxiv.org/pdf/2608.09666v1)

## 摘要（中文翻譯）

近年視覺生成模型快速進步，已能生成高品質影像與影片，但評估這些模型通常需要取樣數百至數千個影像或影片，計算成本高昂。現有方法也多依賴僵化流程，忽略特定使用者需求，且只提供缺乏清楚解釋的數值結果。我們提出 Evaluation Agent framework，模擬人類僅從少量樣本快速形成模型能力印象的策略，進行高效率、動態、多輪評估，並提供詳細且符合使用者需求的分析。代理人接收自然語言評估要求後，將其分解為子面向、產生具針對性的提示詞、從受評模型取樣影像或影片、呼叫適合的評估工具，並根據觀察到的證據反覆更新計畫，同時涵蓋既定基準維度與開放式需求。作者進一步建立 Open Evaluation Agent，透過 EA-CoT-10K 訓練以 Qwen2.5-3B-Instruct 為基礎的 EA-3B，降低對專有模型的依賴。

## 問題背景

視覺生成模型的傳統評估通常需要取樣數百至數千個影像或影片，導致高昂的計算與時間成本。既有流程多為固定且僵化的 pipeline，難以回應使用者的特定評估需求，並常只輸出缺乏解釋的數值。論文因此要解決如何以少量、針對性的樣本，進行高效率、可調整且具解釋性的影像與影片生成模型評估。

## 解決方案

作者提出 Evaluation Agent framework，模擬人類由少量樣本快速形成能力判斷的策略。系統接收自然語言需求後，將其拆成子面向，產生針對性 prompts，呼叫受評生成模型與評估工具，再依據觀察證據逐輪修正評估計畫。此設計兼顧 predefined benchmarks 與 open-ended concerns，並提供使用者導向的分析。作者進一步以多輪 rollout 建立 EA-CoT-10K，訓練本地模型 EA-3B，使其保留規劃、工具調用與摘要流程，降低對 proprietary backbone 的依賴。

## 核心貢獻
1. 提出 Evaluation Agent framework，將自然語言評估需求轉換為子面向、目標提示詞、取樣與工具呼叫，支援動態多輪評估。
2. 建立 EA-CoT-10K，收集源自多輪評估 rollout、具歷史條件的逐步指令微調紀錄。
3. 訓練本地規劃模型 EA-3B，保留結構化推理、工具調用與摘要協定，並在多個 T2V 生成模型家族上檢驗部分跨家族遷移能力。

## 技術方法

Evaluation Agent 以自然語言評估要求為輸入，先將需求分解為多個子面向，再針對各面向產生目標提示詞，向受評的影像或影片生成模型取樣，並呼叫合適的評估工具。代理人根據每一輪取得的樣本與工具結果更新後續計畫，形成多輪、動態的評估流程；最後輸出包含分析與摘要的使用者導向結果。此流程同時支援既定 benchmark 維度與 open-ended user concerns。作者另外從多輪評估 rollout 建立 EA-CoT-10K，資料形式為具歷史條件的 step-level instruction-tuning records，保留規劃、工具 invocation 與 summary protocol。接著以 Qwen2.5-3B-Instruct 為基礎訓練 EA-3B，作為本地規劃 backbone。實驗涵蓋 API-based agent 在 T2I/T2V benchmarks 與開放式查詢上的驗證，以及 Open-EA 在 4 個 in-domain 和 3 個 out-of-domain T2V generator families 上的測試。摘要明確提到評估時間與傳統方法比較，以及結果可比性和部分跨家族 transfer；但未提供具體評估指標名稱、分數、樣本數、baseline 配置或模型架構細節。

## 對我們的啟發
- [ ] 若評估資源有限，可採用根據觀察證據逐輪調整的取樣與評估策略，而非固定取樣大量樣本。
- [ ] 評估系統應同時輸出數值與證據導向的文字分析，並讓使用者以自然語言指定關注面向。
- [ ] 將多輪工具使用紀錄整理為具歷史條件的訓練資料，可用於建立較低成本的本地評估規劃模型；但跨模型家族的泛化仍需實際驗證。

## 限制與未來工作

根據所提供的摘要，論文未報告各 benchmark 的具體分數、基準方法配置、樣本數、評估工具細節或統計顯著性，因此無法進一步核驗「可比結果」與 10% 時間比例的實驗條件。Open-EA 僅呈現部分跨家族遷移，泛化能力仍有限；未來需補充更完整的成本、可靠性與跨分布分析。
