# SCOUT: Unlocking Enhanced Spatial Reasoning via Structured Chain-of-Thought and Multi-Objective Process Reward

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.12220)
- 📥 [PDF](https://arxiv.org/pdf/2608.12220v1)

## 摘要（中文翻譯）

現有 Vision-Language Models（VLMs）在穩健 spatial reasoning 上仍存在關鍵瓶頸。近期以可驗證結果為目標的 Reinforcement Learning（RL）方法，常因中間推理步驟的 credit assignment 不佳而受限；另一方面，structured reasoning 方法又忽略全面 3D understanding 所需的關鍵 depth perception。為此，本文提出 SCOUT（Structured Chain-of-Thought Utilizing Process-Supervised RL Training）。SCOUT 設計 structured Chain-of-Thought（CoT）框架，明確建模 3D environmental perception，以強化 spatial understanding 與 reasoning；並提出結合 multi-objective process rewards 與客製化 advantage estimation 的 RL 演算法，針對推理軌跡不同區段進行細粒度 credit assignment。此外，作者建立 SCOUT-24k structured spatial reasoning CoT dataset。實驗顯示，SCOUT-3B 在 general spatial benchmarks 與 complex spatial reasoning tasks 上分別較 baseline 提升 16.85% 與 6.3%；SCOUT-7B 在部分評估中超越 GPT-4o，且僅以 single image 訓練仍能泛化至 multi-image 與 video 情境。

## 問題背景

論文聚焦 VLM 在 2D/3D spatial reasoning 中的穩健性不足。既有 RLVR 多依賴稀疏的最終答案 reward，難以判定哪些中間 token 或推理階段真正有貢獻；既有 structured CoT 雖提升可解釋性，卻常未明確表示 depth，限制 3D 空間理解。SFT 方法則被作者指出可能依賴大量合成資料並產生模板記憶，因而需要兼顧 depth perception、推理一致性與細粒度 credit assignment 的訓練框架。

## 解決方案

作者提出 SCOUT，將 structured CoT 與 process-supervised RL 結合。模型先以 caption 建立場景語義，再於 scene 區段顯式預測物件 bounding box 與 depth，最後在 analyze 區段依據這些 3D 觀測進行邏輯推理，並在 answer 區段輸出結論。RL 部分以 grounding、depth、reasoning consistency、accuracy 與 format 五種目標提供中間及最終監督；再依 perception、analysis、answer 三個區段分配 token-level advantage，且將局部 reward 與最終正確性混合，改善 sparse reward 下的 credit assignment。SCOUT-24k 則支援 SFT cold-start 與後續 RL。

## 核心貢獻
1. 提出包含 caption、scene、analyze 與 answer 區段的 depth-aware structured CoT，將 3D perception 與後續邏輯推理分離。
2. 提出由 grounding、depth、consistency、accuracy 與 format 五類 reward 組成的 multi-objective process-supervised RL，並依推理區段配置 advantage。
3. 建立 SCOUT-24k，涵蓋 Spatial Relation Understanding、Relative Distance Prediction、Perspective Transformation Reasoning 與 Object-Centric Spatial Reasoning，並以消融實驗驗證各元件。

## 技術方法

SCOUT 以 Qwen2.5-VL-3B/7B 為初始化模型。推理輸出固定為 <think><caption>…</caption><scene>…</scene><analyze>…</analyze></think><answer>…</answer>：caption 描述全局場景，scene 以 JSON 列出物件 label、2D bounding box 與 depth，analyze 依據感知結果進行比較、座標計算與 perspective reasoning，answer 輸出結論。訓練分兩階段：首先以 SCOUT-24k 的 SFT 子集進行一個 epoch 的 LoRA cold-start（rank=8）；接著以 18,614 筆 RL 資料進行 200 steps 的 full-parameter RL，使用每個 prompt 8 條 trajectory、temperature 1.0、global batch size 128，並加入 KL regularization。Process rewards 包含：以 Hungarian matching 對齊預測與標註物件的 regularized grounding reward（含 EIoU 與過度生成懲罰）、depth reward、僅輸入文字問題與推理鏈的 blind consistency reward、答案正確性的 binary accuracy reward，以及格式 reward。各 reward 先做 group z-score normalization；scene token 使用 grounding 加 depth advantage，analyze token 使用 consistency advantage，answer token 使用 format 加 accuracy advantage，前兩者再以 α1=α2=0.3 與 outcome advantage 混合。模型以 clipped policy objective 與 KL penalty 更新。評估採 greedy decoding，使用 EmbSpatial、CV-Bench、BLINK、RoboSpatial、SpatialBench、3DSRBench，並以 accuracy 為主要指標，另測 ViewSpatial 與 VSI-Bench 的跨 multi-image/video 泛化。

## 對我們的啟發
- [ ] 若任務需要模型同時完成視覺定位與推理，可將中間輸出結構化，讓 grounding 與 logical analysis 分別接受可驗證訊號。
- [ ] 多目標 reward 不宜只獎勵最終答案；本文結果顯示，將局部 process reward 與 global outcome reward 混合，能改善不同推理階段的訓練平衡。
- [ ] 評估跨模態泛化時應拆分子任務：SCOUT 在 ViewSpatial 與 VSI-Bench 的 multiple-choice 部分提升，但 video numerical questions 下降，顯示整體平均可能掩蓋 temporal tracking 與 absolute estimation 的差異。

## 限制與未來工作

作者指出，實驗受計算資源限制，僅涵蓋 3B 與 7B；SCOUT-24k 依賴 bounding box 與 object label，缺乏 multi-image 和 video 訓練資料；RL 又依賴嚴格 CoT 標籤格式，限制推理彈性。未來將擴展更大模型、加入多圖與影片資料，並降低對固定格式的依賴。
