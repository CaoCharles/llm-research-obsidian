# DiscoveryRSI: Recursively Learning to Discover Valuable Hypotheses

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.23839)
- 📥 [PDF](https://arxiv.org/pdf/2610.23839v1)

## 摘要（中文翻譯）

科學發現不僅需要提出值得研究的假說，也需要將其發展為可執行的實際研究。論文提出 DiscoveryRSI，將有價值且可檢驗的研究假說定義為：以證據為基礎、針對重要不確定性提出主張，並搭配可行的 investigation、明確的 decision criteria 與 alternative explanations。框架透過 multi-agent evolutionary search 建立 hypothesis trees，將選定的研究計畫編譯為可執行的 Harbor tasks，並以 hypothesis credit optimization、harness replay 及 rediscovery 進行遞迴學習。作者同時提出 DFM-Bench，從假說、修訂、發展路徑與完整研究執行等層次評估科學品質與累積進展。在四個生命科學領域中，自動評估分數由 base model 的4.86提升至兩輪自我改進後的5.39，主要改善來自 falsifiability 與 data resolvability。專家評估顯示，DiscoveryRSI-27B在重要性、合理性與 evidence-bounded claims方面優於GPT-6 Luna，且與 cutoff 後發表研究的假說對應率達6.3%。

## 問題背景

科學研究代理人需要從證據形成假說、設計可行調查、修訂解釋並決定是否持續投入，但現有方法多聚焦於產生最終想法或執行單次實驗，未充分保留假說演化歷史、貢獻來源與失敗經驗。因此，模型難以將研究過程轉化為可歸因、可訓練且能改善後續研究的經驗；既有評測也較少同時衡量假說品質、修訂價值、發展路徑與整體資源配置。

## 解決方案

DiscoveryRSI將研究建模為跨回合的遞迴自我改進流程。每個研究節點包含 evidence-grounded claim、investigation plan、decision criteria 與 alternative explanations，並由 Lead、Generation、Evolution、Critique 等多代理角色透過 evolve、repair、crossover 和 restart 建立 hypothesis tree。選定計畫會被編譯成具體輸入、環境、輸出與檢查條件的 Harbor task。其核心創新包括：將科學評估透過 contribution records 歸因至具體歷史並進行 hypothesis credit optimization；固定模型、透過 harness replay 找出工具與協作失敗；再以 rediscovery 將接受的模型與流程更新應用到新問題。

## 核心貢獻
1. 提出有價值且可檢驗研究假說的操作性定義，將 evidence-grounded claim、investigation plan、decision criteria 與 alternative explanations 組合為可修訂研究物件。
2. 提出 DiscoveryRSI 遞迴學習框架，透過 hypothesis credit optimization、harness replay 與 rediscovery，將研究歷史、具體貢獻及執行失敗轉化為模型與研究流程改進。
3. 提出 DFM-Bench，分層評估假說品質、修訂貢獻、發展路徑、研究執行與 scientific contribution，並以自動評估、專家評估及文獻對應進行驗證。

## 技術方法

研究流程以 hypothesis tree 保存每個假說版本、父子關係、證據、草稿、工具執行、評估與貢獻紀錄。Lead 協調 Generation 與 Evolution；Critique 進行盲評，Progress 比較實際前後代的科學進展。每個假說以 H=(c,π,d,a)表示，分別為主張、調查計畫、決策標準與替代解釋。選定的計畫由 Harbor compiler 轉為可執行任務，但不可取得的資料或實體實驗仍被標記為依賴條件。Hypothesis credit optimization先以 TrueSkill 彙整偏好與不確定性，再依 contribution records、評估覆蓋率與進展將有限 credit 分配到具體歷史，僅對受支持的 assistant responses 和 tool-call arguments進行加權 supervised fine-tuning。Harness replay 固定模型權重，在相同資源限制下診斷重複探索、工具失敗、遺失產物與過早結束，並測試流程修改；rediscovery 將模型與 harness 候選更新在 development set 上篩選後，對 fresh questions重新收集經驗。評估使用 DFM-Bench，涵蓋 importance、novelty、grounding、falsifiability、data resolvability、feasibility、alternative explanations、actionability，以及 revision、development path、research run 和 scientific contribution。實驗含四個生命科學領域、241個研究問題；另有27名具生醫背景者評估292份提案。自動評分由 GPT-5.6 Sol產生，文獻對應則以共同 reference corpus與 GPT-6 Luna判定。

## 對我們的啟發
- [ ] 若要提升研究代理人的可靠性，評測不應只看最終答案；應保存假說版本、父子關係、證據與決策標準，以衡量每次修訂是否帶來實質進展。
- [ ] 將 reward 或 training credit 分配到有 provenance 支持的具體行動，而非整段對話，可降低把偶然參與或未支持內容誤當成有效策略的風險。
- [ ] 研究型 agent 的改進可拆成模型學習與 harness 改進兩條路徑；固定模型進行 replay，有助於區分推理能力問題、工具使用問題與協作流程問題。

## 限制與未來工作

研究的主要提升多集中於可否證性、資料可解析性與調查設計，重要性與新穎性反而下降。自動評估依賴 GPT-5.6 Sol，且人類校準仍待完成。文獻對應率受詞彙檢索、長文本截斷、模型判定與不同群組規模影響，不能解讀為實際影響或採用。研究主要聚焦生命科學，跨領域結果有限；部分路徑與修訂存在共享祖先，統計獨立性不足。
