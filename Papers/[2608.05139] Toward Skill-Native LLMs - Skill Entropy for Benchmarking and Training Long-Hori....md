# Toward Skill-Native LLMs: Skill Entropy for Benchmarking and Training Long-Horizon Reasoning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.05139)
- 📥 [PDF](https://arxiv.org/pdf/2608.05139v1)

## 摘要（中文翻譯）

近期 LLM 的長程推理要求模型在同一條推理鏈中切換不同技能，例如先進行數學推導，再利用結果規劃日程。作者將此類問題稱為 cross-skill long-horizon tasks：其步驟需要不同推理技能，且依賴先前輸出。現有 benchmark 多評估單一技能，缺乏衡量技能切換能力的原則性方法。本文提出 Skill Entropy，量化技能間切換的困難度；並建立 Skill²-Bench，涵蓋 9 個可驗證與開放式領域、558 項技能。對 8 個 frontier 與 4 個 open-source models 的評估顯示，任務 entropy 越高，準確率越低。作者進一步提出 Skill-Entropy RL，使模型同時預測答案與每步使用的技能，結合步驟正確性和技能序列對齊獎勵。在 Qwen3-4B-Instruct 與 Qwen3-1.7B 上，分數分別由 34.4% 提升至 68.4%，以及由 14.6% 提升至 40.1%。

## 問題背景

現有 LLM benchmark 多在單一題目或單一領域中測試技能，無法分辨模型是缺乏某項技能，還是無法在長程推理鏈中正確切換技能。即使各個子技能單獨表現良好，跨領域、依賴前一步輸出的任務仍可能失敗。既有長程或 compositional 評估也缺少一個固定、可比較且能控制任務切換難度的 task-level measure，因此難以診斷 skill-switching gap，或將該能力直接轉化為訓練訊號。

## 解決方案

作者提出兩部分方案。第一，Skill Entropy 是有方向的 pairwise skill-switch difficulty，透過 reference model 比較單技能與跨技能準確率，並沿任務技能序列平均，形成可控制難度的 task-level score；據此建立涵蓋 558 技能與 9 領域的 Skill²-Bench。第二，Skill-Entropy RL 要求模型在每個答案前明確輸出 domain-skill label，使用 GRPO 同時優化逐步答案正確性與技能序列 entropy-rank 對齊。核心創新是把同一個技能切換量度同時用於 benchmark 校準、失敗診斷與 reward shaping，並可套用到已有 reasoning traces。

## 核心貢獻
1. 提出有方向性的 pairwise Skill Entropy，並沿任務技能序列聚合為 task-level skill entropy，以量化 cross-skill long-horizon reasoning 的切換難度。
2. 發布 Skill²-Bench，涵蓋 math、science、coding、logic、planning、information extraction、creative writing、context retrieval 與 instruction following 等 9 個領域、558 項技能，並將任務分為 low、medium、high entropy。
3. 提出 Skill-Entropy RL，將模型預測的技能序列與 gold skill sequence 的 entropy-rank 對齊納入 GRPO reward，除改善 benchmark 表現外，也能套用至 OpenR1-Math 等既有訓練資料。

## 技術方法

方法分為 benchmark 建構與 RL 訓練。首先從 9 個領域的 seed datasets 建立 skill bank：可驗證領域以 LLM 為題目標註 3–5 個細粒度技能，再經 embedding clustering 與人工審查；creative writing、context retrieval、instruction following 則直接生成技能清單，共 558 項。作者固定 Claude-opus-4.7 為 reference model，分別測量單技能準確率 Accuracy(s) 與兩步跨技能準確率 Accuracy(sa,sb)，以 Laplace smoothing α=0.1 計算有方向的 Skill Entropy：半數單技能準確率加 α，再除以跨技能準確率加 α。任務 entropy 是技能序列相鄰轉移 entropy 的平均，並依經驗分布切為 low、medium、high。任務長度為 2–10；LLM proposer 將 seed questions 改寫成共享 scenario、讓後續步驟依賴前一步，verifier 再過濾。評估使用 300 個 held-out tasks、四次 temperature 0.7 sampling；可驗證題目用 symbolic equivalence、sandbox unit test 等 domain-specific scorer，開放式題目由 Claude-opus-4.7 依 rubric 評分，總分為平均 per-step accuracy。訓練時，模型輸出 reasoning trace、每步 skill tag 與 answer tag。先用 3K teacher-annotated traces SFT，再以 6K tasks 執行 GRPO；總 reward 為 0.7 answer reward 與 0.3 entropy reward。後者將預測技能透過 Qwen3-Embedding-0.6B 映射至 skill bank，再比較預測與 gold task entropy 的 empirical-CDF rank。

## 關鍵結果

| 實驗設定 | Base/對照 | Skill-Entropy RL | 改善 |
|---|---:|---:|---:|
| Qwen3-4B-Instruct，Skill²-Bench | 34.4% | 68.4% | +34.0 個百分點 |
| Qwen3-1.7B，Skill²-Bench | 14.6% | 40.1% | +25.5 個百分點 |
| Qwen3-4B-Instruct，相對 GRPO | 58.8% | 68.4% | +9.6 個百分點 |
| Qwen3-1.7B，相對 GRPO | 32.2% | 40.1% | +7.9 個百分點 |
| Qwen3-4B-Instruct，相對最佳 skill-aware baseline STAT | 61.4% | 68.4% | +7.0 個百分點 |
| Qwen3-1.7B，相對 STAT | 33.0% | 40.1% | +7.1 個百分點 |
| OpenR1-Math 外部訓練，平均六項數學 benchmark | 51.4%（GRPO） | 53.3% | +1.9 個百分點 |

模型評估方面，8 個 frontier models 與 4 個 open-source models 大致呈現 low→medium→high entropy 的準確率下降；domain accuracy 在 cross-skill setting 相對 single-skill setting 的下降範圍為約 4%–10%（摘要與正文另報告整體落差約 4%–13%）。

## 對我們的啟發
- [ ] 評估長程推理時，應將單一技能能力與技能切換能力分開報告；論文中同一技能置於 cross-skill task 後，準確率下降約 4%–13%。
- [ ] 訓練訊號不必只監督最終答案，也可監督每一步的技能選擇與切換結構；實驗顯示 answer reward 主導、entropy reward 作為結構塑形（0.7/0.3）效果最佳。
- [ ] 實務上可先對既有 reasoning traces 進行步驟切分與技能標註，再以技能轉移難度建立 curriculum 或 RL reward；但應同步檢查標註與評測 judge 的可靠性。

## 限制與未來工作

Skill Entropy 以 Claude-opus-4.7 作為固定 reference model，且技能標註、任務改寫與部分開放式評分依賴 LLM，可能引入模型與標註偏差。測試集僅 300 個 synthesized tasks，訓練主要使用 6 個可驗證領域；論文未提供更廣泛人類評測、不同 reference model 的完整穩健性分析，亦未報告真實 agent 環境中的工具使用結果。
