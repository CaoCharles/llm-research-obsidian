# Reduced Matrix Multiplication: Input-Adaptive Matrix-Product Reduction for LLM Inference

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.13426)
- 📥 [PDF](https://arxiv.org/pdf/2608.13426v1)

## 摘要（中文翻譯）

Transformer-based language models 雖具備強大性能，卻因反覆執行高維度矩陣乘法而產生龐大 inference 成本。本文提出 Reduced Matrix Multiplication（RMM），一種 training-free、input-adaptive 的 inference 方法：沿矩陣乘法的 contraction dimension 選取具資訊性的 slices，無須修改 model weights。透過簡單的 retention ratio，RMM 提供平滑且可預測的 accuracy–efficiency trade-off。作者在 1B 至 70B 的 language models 上發現，可容忍的 reduction 取決於 model family、task、component 與 retention ratio，且通常隨模型規模增大而改善。在中度 reduction 下，RMM 對 discriminative、autoregressive generation、long-context 與 multimodal vision-language inference 均具穩健性。機制分析顯示 attention-side 比 MLP 更具可 reduction 性；A100 wall-clock 實驗也證明，尤其在較長序列下，計算節省可轉化為實際 runtime gains。

## 問題背景

Transformer inference 大量成本來自 attention 與 MLP 中反覆的高維矩陣乘法；固定結構 pruning、低秩或 dimension reduction 通常在 inference 前決定刪除內容，token/KV 方法則主要改變 context 或 cache，未直接處理每次矩陣乘法的 contraction axis。activation sparsity 雖具輸入依賴性，主要針對 activation entries。論文要回答的是：每個輸入是否真的需要計算 contraction axis 上的所有 index，以及能否在不修改權重下動態減少這些計算。

## 解決方案

作者提出 Reduced Matrix Multiplication（RMM），將任意矩陣乘法 Y=AB 的共享 contraction dimension 視為可動態縮減的計算軸。方法觀察當前 activation A，依各 column 的 L2 norm 評估資訊量，在指定 retention ratio 下以 deterministic TopK 選取索引，只計算對應的 A[:,I]B[I,:]。它可套用於 attention 的 QKᵀ feature axis、P V token axis，以及 MLP/linear projections。核心創新是把 input-adaptive selection 直接放在 matrix-product level，而非固定剪枝模型結構；同時以單一比例控制計算—性能取捨，並允許依 component 採用異質 retention policy。

## 核心貢獻
1. 提出 RMM：不修改權重、依目前 activation magnitude，在每個矩陣乘法的 contraction dimension 以 TopK 選取保留索引，並由 retention ratio 控制計算量。
2. 在 1B–70B language models、多種 discriminative、generation、long-context 任務及 Qwen2.5-VL-7B 上評估，展示輸入自適應 reduction 的準確率—效率取捨與跨模態延伸性。
3. 透過 component-wise ablation 與理論分析指出 attention-side 比 MLP 更可 reduction，並以 Triton kernels 在 NVIDIA A100 上驗證 kernel-level 與 end-to-end latency gains。

## 技術方法

RMM 將 Transformer 中的計算統一表示為 Y=AB，其中 A 是由當前輸入決定的 activation matrix，B 是 weight matrix 或 intermediate representation，兩者共享 contraction dimension d。對每個產品，先計算每個輸入維度的 activation column norm：s_j=||A[:,j]||₂；在使用者指定 retention ratio ρ 下，以 TopK 選出 k=ceil(ρd) 個索引 I，僅計算 A[:,I]B[I,:]。此選擇在每個 input、layer、attention head 與 decoding step 可不同。Attention 中，作者可沿 head feature dimension reduction QKᵀ，依 Q 的 column norm 選擇對應 Q/K 維度；也可在 P V 中沿 token dimension 依 attention-weight norm 選取 token。MLP 與 linear projection 則分別對 Up、Gate、Down projection 的 contraction axis 進行選擇，各自使用當前 activation 的 TopK subset。方法不修改或永久刪除 full model weights。理論上，單一矩陣乘法成本由 O(ndm) 降為約 O(nρdm)，但需額外計算 norm、TopK 與 indexing。作者以 LLaMA 3.1 1.5B/3B/8B/70B、Qwen3 7B/32B 與 Qwen2.5-VL-7B，在 zero-shot QA、language modeling、GSM8K、HumanEval、summarization、RULER long-context 及視覺任務上評估；指標包括 accuracy、ROUGE、BERTScore、任務分數與 latency。基線涵蓋 SparseGPT、Wanda、SliceGPT、magnitude pruning、H2O、static RMM 與 random pruning。另以 component ablation、不同 retention ratios、Triton kernels 及 A100 wall-clock 測試驗證機制與實用性。

## 對我們的啟發
- [ ] 實務部署可優先對 attention-side matrix products 使用較積極的 retention ratio，對 MLP 採取更保守或 component-specific 的 ratio；論文的 ablation 顯示整體 MLP reduction 對性能傷害較大。
- [ ] 若要在相同 reduction budget 下維持 generation 與 multimodal 表現，應採用依當前 activation 動態選擇維度的策略，而非固定 subset 或 random selection；但正式部署仍需以目標模型與任務重新校準 retention ratio。
- [ ] RMM 的理論計算量約隨保留的 contraction dimension 比例縮放，但實際 speedup 取決於 TopK、norm、gather、kernel fusion、序列長度與硬體；因此評估效率時應同時報告 end-to-end latency，而不能只看 MACs。

## 限制與未來工作

論文聚焦於 training-free RMM，尚未探討結合訓練或額外適應的方法。多模態部分僅證明可行性，未詳細分析 vision-language model 各元件的動態 redundancy。實作也未完整整合所有 Transformer operations、inference frameworks 或 quantized backends；RMM 不減少權重儲存與模型參數量，實際收益仍受硬體、kernel 與 selection overhead 影響。
