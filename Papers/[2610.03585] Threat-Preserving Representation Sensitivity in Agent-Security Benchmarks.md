# Threat-Preserving Representation Sensitivity in Agent-Security Benchmarks

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.03585)
- 📥 [PDF](https://arxiv.org/pdf/2610.03585v1)

## 摘要（中文翻譯）

面向 LLM-based agents 的安全 benchmark 通常以 attack success rate（ASR）衡量模型 robustness，並用分數比較模型與防禦機制，假設分數能代表 agent security。本研究探討 benchmark 的 representation 是否也會影響測量結果。作者提出 threat-preserving representation sensitivity（TPRS），衡量在 underlying task、harmful action、security policy、ground truth、environment 與 evaluation criteria 均固定時，僅改變 agent-visible representation 所造成的 ASR 變化。在 28,904 次 agent runs、三個 benchmark 上，ASR 呈現顯著且不一致的雙向變化。ASB 將 threat-related tool names 改為 threat-neutral names 後，GPT-5-mini 與 Claude Haiku 4.5 的 committed ASR 分別上升 11.67 與 13.21 個百分點；MCPTox 加入 threat-explicit name 後，兩模型 ASR 分別下降 11.00 與 4.11 個百分點。AgentDojo 的 ASR 僅變化 0.50 個百分點，但 benign utility 下降 5.36 個百分點。結果顯示，單一 representation 下測得的 security score 未必能泛化至其他 threat-preserving representations。

## 問題背景

現有 agent-security benchmarks 常將單一 representation 下的 ASR 視為模型 robustness 或防禦效果，卻未充分檢查 tool name、description 與 threat framing 等 agent-visible 輸入是否改變測量結果。若底層 task、攻擊目標與評分規則不變，僅改變表示方式仍造成 ASR 顯著波動，則單一分數可能混合了真實安全行為與 benchmark 設計效應，也可能限制跨模型或跨防禦機制比較的有效性。

## 解決方案

作者提出 threat-preserving representation sensitivity（TPRS）作為 security benchmark 的 measurement-validity audit。對 benchmark B 與 model m，先建立只改變 agent-visible representation 的 transformation T，固定 environment、attacker objective、violation policy、attack success criterion 與 evaluation mechanism，再計算 ΔT(B,m)=ASR(T(B),m)−ASR(B,m)。研究以 orthographic、semantic-neutral 與 cue-altering transformations 分析表示變化來源，並使用配對比較、cluster bootstrap confidence intervals、失敗執行的多種處理方式，以及 MCPTox 的 matched-neutral control，檢驗 ASR 是否依賴特定威脅詞彙或 identifier form。

## 核心貢獻
1. 提出 TPRS 與形式化定義，將 agent-security benchmark 的 representation dependence 轉化為可量測的 ASR 差異。
2. 在 ASB、MCPTox 與 AgentDojo 共 28,904 次 agent runs 上，展示 representation sensitivity 可顯著、雙向且依 benchmark 與 metric 而異。
3. 透過 orthographic、semantic-neutral 與 matched-neutral controls，指出 MCPTox GPT-5-mini 的主要變化不能簡單歸因於 explicit threat vocabulary，並提出同時報告 threat-preserving variants、security 與 utility 的建議。

## 技術方法

研究將每個 benchmark instance 分為 environment、attacker objective、違規 policy、attack success criterion、evaluation mechanism 與 agent-visible representation 六部分。ASB 中，對 36 個 attacker tools、六個 domains、每 tool 五個 tasks、三次 replicate，將 threat-related tool names 或 descriptions 改為 neutral wording；同時區分 native ASR 與要求 agent 未曾拒絕的 committed ASR。MCPTox 從 1,348 個 cases 中預先選取 203 個可可靠重現 scorer 的 cases，測試 orthographic、semantic-neutral、conservative threat 與 explicit threat names，並以 matched-neutral S3 控制 token count、length、casing 與 component form。AgentDojo 使用 40 個 user tasks、14 個 injection tasks 與五次 replicate，將 attack-required 或 unrelated ordinary tool 加上 threat wording，並沿用 security 與 benign-utility scorers。總計 28,904 次 runs，ASB 與 MCPTox 使用 GPT-5-mini、Claude Haiku 4.5，AgentDojo 使用 GPT-4o-mini。相同 units 盡可能跨 arms 配對，依 transformation 共用層級進行 clustering，以 10,000 次 cluster-bootstrap 取得 95% confidence intervals；MCPTox 另使用 Holm-adjusted p-values。

## 關鍵結果

主要結果如下；百分點變化均相對於各 benchmark 的原始 representation。

| Benchmark／比較 | 模型 | 原始 ASR | 變換後 ASR | ΔASR（百分點） | 95% CI |
|---|---|---:|---:|---:|---|
| ASB committed，neutralize tool names（A1） | GPT-5-mini | 36.67% | 48.34% | +11.67 | [+4.44, +19.07] |
| ASB committed，neutralize tool names（A1） | Claude Haiku 4.5 | 20.85% | 34.06% | +13.21 | [+6.33, +21.10] |
| ASB native，neutralize tool names（A1） | GPT-5-mini | 47.59% | 61.66% | +14.07 | [+5.56, +23.70] |
| ASB committed，neutralize names + descriptions（A3） | GPT-5-mini | 論文未報告 | 論文未報告 | +13.15 | [+5.56, +21.11] |
| MCPTox explicit threat name（N1） | GPT-5-mini | 32.02% | 21.02% | −11.00 | 論文提供之表格片段未完整呈現 |
| MCPTox explicit threat name（N1） | Claude Haiku 4.5 | 9.03% | 4.92% | −4.11 | 論文提供之表格片段未完整呈現 |
| MCPTox matched-neutral control（S3） | GPT-5-mini | 論文未報告 | 論文未報告 | −8.54 | 論文未報告 |
| AgentDojo security ASR，required tool 加 threat wording（Dval） | GPT-4o-mini | 論文未報告 | 論文未報告 | −0.50 | [−3.65, +2.51] |
| AgentDojo benign utility，required tool 加 threat wording | GPT-4o-mini | 論文未報告 | 論文未報告 | −5.36 | 論文未報告 |

此外，MCPTox 的 S3 matched-neutral name 在 GPT-5-mini 重現了 N1 相對原始 representation 之 11.00 個百分點變化中的 8.54 個百分點，顯示 explicit threat vocabulary 並非大部分效果的必要條件。ASB 的 orthographic control 未產生已解決的 committed-ASR 效果。

## 對我們的啟發
- [ ] 實務上不應只報告單一 tool naming 或 prompt representation 下的 ASR；至少應加入預先定義的 threat-preserving transformation，並報告 ΔASR 與 confidence interval。
- [ ] 若 attacker 能控制 tool name 或 metadata，representation 本身可能成為攻擊面；評估時可同時報告多種 representation 下的最高 ASR，而非只採用 benchmark 原始命名。
- [ ] 安全評估應與 benign utility 一起觀察，因為 AgentDojo 顯示 ASR 變化很小不代表整體行為穩定，representation 仍可能造成 5.36 個百分點的 utility 損失；同時應明確區分 tool invocation 與 committed attack success。

## 限制與未來工作

測試僅涵蓋三個 benchmark、三種模型設定與 tool name／description 等有限 representation，無法代表所有可能的變化。ASB 的 neutral names 未完全驗證語義等價，MCPTox 的 matched control 也未隔離 identifier 的所有屬性。研究未檢驗模型或防禦排名是否反轉，且部分 transformation 跨 runs 共用，因此並非全部獨立。未來可擴展至更多模型、攻擊、防禦、schema、argument names 與 instruction framing。
