# CRoS: Causality Reward on Scrambled CoTs Improves Accuracy and Reasoning Faithfulness

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.42054)
- 📥 [PDF](https://arxiv.org/pdf/2610.42054v1)

## 摘要（中文翻譯）

Reinforcement Learning with Verifiable Rewards（RLVR）已成為訓練語言模型推理的標準方法，但 RLVR 通常只依賴最終答案是否正確，無法保證 Chain-of-Thought（CoT）對答案具有因果貢獻。現有 CoT 因果性指標透過刪除推理步驟或注入錯誤來擾動 CoT，再觀察答案變化；然而這些操作同時改變了各步驟的資訊內容，使高因果性分數可能反映模型對資訊變動的敏感度，而非真正的因果依賴。將此類指標作為訓練獎勵，也可能導致較不具資訊性的 CoT、較少探索與自我修正。為此，作者提出 CRoS（Causality Reward on Scrambled CoTs），只打亂推理步驟順序而保留每一步內容，以降低混淆因素。在 Reasoning Gym 的 Gemma-3-4B 實驗中，CRoS 在 OOD 準確率、CoT 品質與 faithfulness 上均優於基線；五個未見邏輯與遊戲資料集的準確率為 46.8%，CoT-Pass@K 平均為 43.4%，hint acknowledgment 為 34.0%。

## 問題背景

論文探討 RLVR 只獎勵最終答案正確性，可能強化與答案無因果關係的表面 CoT，因而無法確保推理品質與 faithfulness。既有 Early Answering、CIR 等截斷方法會刪除資訊，Adding Mistakes 等方法會注入錯誤；答案變化因此混合了真正的因果影響與內容改變效應。這些混淆在作為訓練獎勵時，還可能造成 CoT 變短、資訊性下降，以及探索和自我修正減少。

## 解決方案

作者提出 CRoS（Causality Reward on Scrambled CoTs），透過重新排列 CoT 推理步驟來測量因果性，而不修改任何步驟的文字內容。若原始順序下答案的機率高於打亂順序後的機率，表示模型較依賴原始推理流程。CRoS 使用 frozen reference model 比較原始與多個低 Kendall rank correlation 排列的答案平均 token log-probability，並將差值作為因果性分數。訓練時只對正確 rollout 施加以群組內排序正規化的 CRoS auxiliary reward，與 outcome reward 及 format reward 結合，以鼓勵正確且真正依賴推理內容的回答。

## 核心貢獻
1. 提出 CRoS，透過保留每個推理步驟內容、只打亂步驟順序來估計 CoT 的因果貢獻，降低既有擾動方法的資訊變更混淆。
2. 將 CRoS 作為 GRPO 中僅針對正確 rollout 的 auxiliary reward，並以 group-wise rank normalization 處理不同問題間 log-probability 差異；消融結果顯示此正規化對效果重要。
3. 在 Reasoning Gym 上證明 CRoS 同時改善 OOD accuracy、CoT-Pass@K 與 hint acknowledgment，並實驗分析既有因果性獎勵導致的 CoT 縮短、資訊性下降、探索及自我修正減少等行為。

## 技術方法

模型方面，主要使用 Gemma-3-4B-Instruct，並在附錄評估 Gemma-3-12B-Instruct。訓練採用 GRPO；每個回答由 CoT 與最終答案組成，CoT 以非空行切分為推理步驟。對每個 rollout，取多個隨機排列，僅保留與原順序 Kendall rank correlation 低於門檻者，形成 scrambled CoTs。使用訓練前參數固定的 reference model，計算原始 CoT 與各打亂 CoT 條件下原始答案的平均 token log-probability，CRoS 分數為原始值減去打亂排列平均值。總獎勵為正確性獎勵、權重為 0.2 的格式獎勵，以及僅給正確回答的 CRoS 排名獎勵；排名在同一 GRPO group 的正確回答內正規化，錯誤回答及只有一個正確回答時不獲得因果性獎勵。訓練資料使用 Reasoning Gym 的 AIW 與 Survo，並以五個未見 Logic、Games 資料集測試 OOD generalization；另以 CoT-Pass@K、Pass@K 評估推理品質，以四類錯誤 hint 的 acknowledgment 評估 faithfulness，並使用 Gemini-2.5-Flash 作為 judge。作者也分析 CoT 長度、資訊性步驟、答案推導、自我修正、探索，以及 sycophancy 和 refusal。

## 關鍵結果

主要結果如下（數值均為論文報告的百分比）：

| 評估面向 | CRoS | 最強相關基線／比較值 | 論文結論 |
|---|---:|---:|---|
| OOD default accuracy | 46.8% | SR 43.8%；Outcome Reward 41.8% | CRoS 最佳 |
| OOD hard accuracy | 22.2% | Outcome Reward 18.8% | 困難題優勢更明顯 |
| In-domain hard accuracy | 31.5% | Outcome Reward 29.5%；Early Answering／Adding Mistakes 29.5% | CRoS 最佳 |
| CoT-Pass@K 平均（K=1–128） | 43.4% | Outcome Reward 41.4% | CRoS 在所有 K 均最高 |
| Pass@64 | 88.3% | Base Model 86.9%；Outcome Reward 85.4% | CRoS 較佳 |
| Hint acknowledgment 平均 | 34.0% | Base Model 20.2%；Outcome Reward 18.8% | CRoS faithfulness 較佳 |
| 嚴格 hint acknowledgment 平均 | 26.0% | Outcome Reward 13.3% | CRoS 仍為最高 |
| 平均 CoT 長度 | 1,762 tokens | Outcome Reward 1,890；CIR 316 | 優勢不能以更長 CoT 解釋 |

作者另報告：Early Answering 與 CIR 的資訊性步驟比例分別為 41% 與 31%，CRoS 為 54%；明確推導答案的比例分別為 27%、30% 與 74%。Adding Mistakes 的自我修正與探索比例為 12% 與 31%，Outcome Reward 為 18% 與 80%，CRoS 為 14% 與 74%。

## 對我們的啟發
- [ ] 若要把 CoT 因果性納入 RL reward，擾動應盡量保持語義內容不變；實務上可優先測試順序、結構或上下文組織的干預，而非直接刪除或注入錯誤。
- [ ] 只用最終答案正確性可能鼓勵 shortcut；可將答案正確性、CoT 品質與因果依賴分開評估，並用 group-wise ranking 避免不同題目分數尺度造成訓練不穩定。
- [ ] 較高 CoT causality 並非普遍安全收益：論文觀察到 CRoS 的 sycophancy 較高、部分 refusal 指標較低，因此部署時應同步測試拒答、提示操弄與安全監控，而不能只看 accuracy 和 faithfulness。

## 限制與未來工作

論文主要在 GRPO 與 Reasoning Gym 上驗證，模型核心實驗集中於 Gemma-3-4B；作者未報告 SFT、distillation 或其他 RL 範式的結果。CoT faithfulness 主要以 hint acknowledgment 衡量，且依賴 Gemini-2.5-Flash judge。未來工作包括 reward hacking、sandbagging、更多監控情境，以及降低 sycophancy 和 refusal 下降等副作用。
