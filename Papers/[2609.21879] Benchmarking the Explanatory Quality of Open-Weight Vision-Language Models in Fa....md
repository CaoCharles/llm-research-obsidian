# Benchmarking the Explanatory Quality of Open-Weight Vision-Language Models in Face Recognition

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.21879)
- 📥 [PDF](https://arxiv.org/pdf/2609.21879v1)

## 摘要（中文翻譯）

Vision-Language Models（VLMs）近期被視為臉部辨識的潛在工具，因其除了產生相似度分數，也能提供自然語言解釋；此能力對要求決策透明且可稽核的鑑識情境特別具吸引力。然而，既有評估多集中於辨識準確率，尚未量化生成解釋的有效性。本研究提出一套以解釋品質為核心評估軸的 VLM 臉部辨識 benchmark，要求解釋具備 relevance，即依賴身分穩定的臉部特徵，以及 faithfulness，即符合影像中可見內容、避免 hallucination。作者透過限制模型輸出為結構化格式，使解釋能被自動查詢與稽核，並對多個 open-weight VLM 家族同時評估 face verification 準確度與解釋品質。結果顯示，生成解釋仍有顯著缺陷，僅測量辨識能力不足以完整反映模型表現。公開的 benchmark 與 evaluation harness 可作為未來改善及微調可解釋臉部辨識系統的基礎。

## 問題背景

現有 VLM 臉部辨識研究主要報告 verification accuracy，通常只對自然語言解釋進行定性描述，因此無法判斷解釋是否依賴身分穩定特徵，或是否描述影像中不可見的臉部內容。在鑑識情境中，單純有文字理由不代表具備有效、透明且可稽核的 explainability；模型可能依賴眼鏡、表情、光線等暫時線索，或產生 hallucinated claims。

## 解決方案

作者提出一套面向 forensic face verification 的 benchmark，將 explanation quality 拆成 relevance 與 faithfulness 兩項可量化準則。模型被要求輸出固定 JSON，包含 similarity score、整體 explanation，以及逐項的 facial feature、兩張影像各自的 description 與 comparison。透過 constrained decoding 保證格式可解析，再以預先定義的 lexicon 與資料集 occlusion annotations 自動稽核：relevance 檢查是否提及不穩定線索，faithfulness 檢查是否描述被遮蔽部位。框架並聯合報告 EER、accuracy、FTA 與解釋品質，分析模型家族、參數規模及結構化輸出限制的影響。

## 核心貢獻
1. 提出面向 forensic VLM face verification 的兩項解釋品質準則：relevance，要求依賴 identity-stable evidence；faithfulness，要求不對不可見內容提出 unsupported claims。
2. 設計以 JSON schema 與 constrained decoding 為核心的結構化解釋評估方法，使 feature-level explanation 能以 lexicon 與 occlusion annotations 進行自動化、可稽核的量化。
3. 對 Gemma3、Qwen2.5-VL 與 InternVL3 多個規模進行聯合 benchmark，揭示 verification performance、結構化輸出成本與 explanation quality 之間並非簡單一致，並公開 evaluation harness。

## 技術方法

研究以四個資料集進行 face verification：LFW 採標準 6000-pair protocol；ARFace、Soteria 與 CelebA 建立平衡 genuine/impostor pairs 及 10-fold identity-disjoint splits。臉部以 InsightFace 偵測與裁切；任一影像偵測失敗的 pair 視為 FTA，並排除於相應 metric 計算。評估 Gemma3、Qwen2.5-VL 與 InternVL3 三個 open-weight VLM 家族，規模涵蓋 1B–78B，採 zero-shot、temperature 0 與固定 seed。比較 unstructured output 與 token sampling 階段強制 JSON schema 的 structured output。Verification 以 similarity score 計算 EER 與 accuracy；accuracy 在每個 fold 以其餘九折選 threshold，再於 held-out fold 評估。Relevance 以不穩定線索 lexicon 計算 feature entries 中的 unstable-feature rate U，定義 R=1−U；詞彙涵蓋 accessories、attire、environment、expression 與 grooming。Faithfulness 聚焦 occlusion：若 explanation 的 feature 欄提及 ARFace 遮蔽的 eyes/mouth，或 Soteria 遮蔽的 nose/mouth，則標記為 hallucination，H 為相關 entries 比率，F=1−H；若文字只是承認不可見，則不處罰。兩者皆先逐 comparison 計算，再做 macro-average，並另以(1−FTA)×score反映可實際使用的品質。

## 對我們的啟發
- [ ] 評估可解釋 VLM 不應只看 EER 或 accuracy；實務選型應同時納入 relevance、faithfulness 與 FTA，避免高辨識率模型以眼鏡、表情或光線等不穩定線索產生看似合理的報告。
- [ ] 結構化輸出能把自由文字理由轉換為可審計資料，但小模型可能因 schema non-compliance 產生顯著 FTA；部署時應把格式失敗視為系統性 operational risk，而非單純忽略。
- [ ] 模型 scaling 對 verification 與 faithfulness 通常有幫助，卻不保證 relevance 單調提升；若應用重視鑑識報告品質，應測試中等規模模型及針對穩定特徵、可見性與 abstention 的微調。

## 限制與未來工作

Relevance 依賴 lexicon，只涵蓋部分不相關線索；faithfulness 僅評估 ARFace 與 Soteria 的 occlusion，無法涵蓋其他 hallucination 或非遮蔽資料錯誤。實驗採 deterministic decoding，未測量輸出變異、其他 prompting 或非零 temperature。LFW、CelebA 可能與預訓練資料重疊；亦未涵蓋 CFP-FP、AgeDB-30、CA-LFW、CP-LFW、IJB-B/C。未來可加入 correctness、visibility/confidence、FISWG 對齊 schema、fine-tuning 及 forensic practitioner user studies。
