# TinyCast: Probabilistic Zero-Shot Forecasting with Computed Periodicity

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.15767)
- 📥 [PDF](https://arxiv.org/pdf/2608.15767v1)

## 摘要（中文翻譯）

本文提出 TinyCast，一個具備 probabilistic forecasting 能力、無 attention 的 zero-shot forecaster，僅使用 146,505 個參數。其核心前提是：在極小模型規模下，context 的週期結構應透過計算取得，而非耗用參數學習。模型以零參數 spectral detector 從輸入偵測 dominant periods，依 phase folding context，再由 dilated convolutional encoder 與 block-autoregressive quantile decoder 建模其餘結構。TinyCast 小於 GIFT-Eval board 上所有參數量可確認的 zero-shot 模型，並在 probabilistic accuracy 上建立 size-accuracy frontier。在宣稱無 test-data leakage 的模型中，它是唯一低於 1.4M 參數且能輸出 predictive distribution 的模型。於 Chronos-ZS 與 fev-bench 中，所有領先的 neural models 至少使用其 28 倍參數。由於 mixing path 僅包含 convolutions 與 matrix multiplications，模型可匯出為 static INT8，並在 embedded device 上無需 per-signal fitting 地完成 forecasting。

## 問題背景

傳統 forecasting 多採 per-dataset 或 per-signal fitting，部署到大量異質裝置時需要收集資料、訓練、驗證與維護；大型 time-series foundation models 雖能 zero-shot，卻通常不適合記憶體、算力與能耗受限的 embedded hardware。更關鍵的是，極小模型往往只能輸出 point forecast，缺乏控制迴路與 alarm threshold 所需的不確定性資訊。論文因此探討：在不進行 per-signal fitting、且不依賴 test-data leakage 的條件下，能否以極少參數建立可輸出 predictive distribution 的通用 zero-shot forecaster。

## 解決方案

作者提出 TinyCast，將可由輸入 context 直接計算的 periodic structure 從 learned computation 中移除。模型先以零參數 FFT-based detector 找出最多四個 dominant periods，再以 period-conditioned sinusoidal encoding、phase folding 與 phase binning 將週期資訊傳給網路；其餘模式由 10 層 dilated depthwise-separable causal convolution encoder 建模，decoder 則融合 pooled summary、phase readout 與 future-conv correction，並以 48-step block-autoregressive 方式輸出九個 quantiles。核心創新是 computed periodicity 與極小參數預算的結合，以及以僅支援常見 integer kernels 的 mixing path 實現 static INT8 embedded deployment。

## 核心貢獻
1. 提出 TinyCast 架構，以零參數 spectral detector 計算 unseen series 的 dominant periodicity，並透過 phase folding 將週期結構交給小型模型使用。
2. 在 146,505 個參數下同時輸出九個 nominal quantiles，於 GIFT-Eval、Chronos-ZS 與 fev-bench 展示小型 zero-shot probabilistic forecaster 的競爭力。
3. 設計完全由 convolution、matrix multiplication、normalization 與 elementwise gate 組成的 mixing path，完成 static W8A8 部署並在 STM32H753 Cortex-M7 上執行。

## 技術方法

TinyCast 對每個 univariate context 使用長度 L=2048 的 window，先以 per-window min-max normalization 映射至 [0,1]，並保存統計量做輸出反正規化。模型從去除 DC 成分的 context 計算一次 real-valued FFT，利用 Fisher significance test（α=0.05，跨 bins 做 Bonferroni correction）保留最多四個 local spectral peaks，將 peak bins 四捨五入為 integer periods；未通過檢定的 slot 設為零。每個 detected period 產生 sin/cos phase channels，另加入五個 recency channels，合計 13 個 deterministic positional features。數值通道與 positional encoding 經 Linear 14→D、D=64 投影後，通過 10 個 residual dilated causal convolution blocks；每層使用 kernel size 3、dilation 1 至 512 的 depthwise-separable convolution，receptive field 為 2047，並搭配 RMSNorm 與 SwiGLU，feed-forward 權重跨十層 tied。Decoder 以 pooled summary、每個 period 的 16-bin phase folding readout，以及 future-conv correction 組成每個 future position 的 query，再輸出九個 decile quantiles（0.1 至 0.9），每次平行預測 48-step block。超過 48 steps 時，以每個 block 的 median autoregressively feedback 至 context。訓練採四個 block 的 scheduled sampling，目標為九 quantile pinball loss 加上 weight λ=0.3 的 gated committing term；資料來自去除 benchmark overlap 的 GIFT-Eval-Pretrain、Chronos KernelSynth、四個 synthetic shards，並使用 frequency balancing、temporal/sign flips、downsampling 與 mixup。評估使用 GIFT-Eval 97 configurations、Chronos-ZS 27 tasks 與 fev-bench 100 tasks，指標包括 relative MASE、GMASE、WQL、MSIS，並比較 seasonal naive、zero-shot models 與 training-free statistical baselines。

## 對我們的啟發
- [ ] 對資源受限的 forecasting 應用，可將週期性等可由輸入直接計算的結構移出 learned parameters，以把有限容量留給 residual dynamics 與不規則結構。
- [ ] 若部署端只能支援固定記憶體與 INT8 kernels，dilated depthwise-separable convolutions 可在不使用 attention、FFT mixer 或 state-space scan 的情況下取得長 receptive field；但需接受重編碼完整 context 的成本。
- [ ] 評估小型 probabilistic model 時，不能只看 point accuracy；TinyCast 在參數量極低時仍輸出 quantiles，但 firmware profile 的 nWQL 從 host profile 的 0.545 惡化至 0.581，顯示量化與推論策略應在實際部署設定下單獨評估。

## 限制與未來工作

模型僅支援 univariate forecasting，不使用 covariates 或 cross-series structure；輸入超出 pretraining regime 時不會發出異常訊號。rounded Fourier-bin period 的解析度受 window／period 比例限制，min-max normalization 對極端值敏感，且每次 forecast 都須重編碼完整 2048-step context。消融實驗多在不同參數預算下進行，部分 benchmark 的資料 disjointness 亦未完全建立；模型只輸出 10% 至 90% quantiles，無法支援 95% 或 99% alarm thresholds。
