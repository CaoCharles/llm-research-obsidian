# Evaluating Generative Time-Series Models on Data with Point Masses

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.09692)
- 📥 [PDF](https://arxiv.org/pdf/2608.09692v1)

## 摘要（中文翻譯）

許多生成式時間序列模型所使用的基準資料，在單一數值上具有很大的機率質量，例如不下雨、沒有叫車需求或沒有零件訂單。本文仔細評估這類資料後發現：首先，標準 rolling-origin protocol 可能在原子結構與整個資料集毫不相似的視窗上評分；某一基準資料集整體有 42% 為零，但評估視窗僅為 13%，另一資料集則為 47% 對 5%。這並非表面問題，因為它曾反轉作者自身的結論，使研究中最強的 occurrence model 看似成為警示案例。其次，本文提出一種控制方法，藉由建構使 CRPS 保持不變，同時破壞 temporal coupling，以精確衡量該耦合對特定統計量的貢獻。最後，在五個 seeds 的匹配協定下比較七個模型，autoregressive hurdle 在六個資料集中的五個勝過 conditional flow，最多達 153 倍；flow 的 occurrence statistics 在訓練 seeds 間變動最多 62%，且所有 baseline 都是 deterministic。五種 occurrence statistics 下的模型排序也不一致。

## 問題背景

含有大量 point masses 的時間序列，若直接套用標準 rolling-origin protocol，評估視窗的 atom 結構可能與整體資料集不一致，導致 occurrence model 的比較失真，甚至反轉研究結論。僅依賴 CRPS 或單一 occurrence statistic 也無法分辨 temporal coupling 的貢獻，且不同統計量可能給出不同模型排序。

## 解決方案

作者提出一套針對 point-mass 時間序列的審慎評估框架。核心包括：檢查資料集與評估視窗的 atom 結構是否匹配；使用一個讓 CRPS 保持不變、但破壞 temporal coupling 的控制，以隔離耦合效果；在 matched protocol 與多個 training seeds 下比較模型；並以五種 occurrence statistics 檢驗結論對評估統計量的敏感度。此框架的創新不在提出單一新模型，而在於校正評估設計並揭露模型排序與 seed 穩定性的問題。

## 核心貢獻
1. 指出標準 rolling-origin 評估可能產生與整體資料集原子結構不匹配的評估視窗，並展示其足以反轉模型比較結論。
2. 提出一種使 CRPS 按建構保持不變、但破壞 temporal coupling 的控制方法，用於衡量該耦合對選定統計量的貢獻。
3. 在匹配協定與五個 seeds 下比較七個模型，分析 autoregressive hurdle、conditional flow 的表現、seed 變異，以及五種 occurrence statistics 對模型排序的影響。

## 技術方法

論文聚焦於含有 point masses、尤其是在單一值上具有大量機率質量的生成式時間序列資料。首先檢視標準 rolling-origin protocol，將整體資料集的 atom 結構與實際評估視窗比較，並以零值比例展示兩者可能嚴重不匹配。其次設計一個 control：其 CRPS 依建構保持不變，但 temporal coupling 被破壞，藉此隔離並衡量 temporal coupling 對所選統計量的貢獻。接著在 matched protocol 下，以五個 training seeds 比較七個模型。摘要明確點名 autoregressive hurdle 與 conditional flow，但未提供其餘模型的名稱、架構或演算法步驟。評估不只使用單一指標，而是比較五種 occurrence statistics，並觀察模型排序的一致性；同時檢查 conditional flow 的 occurrence statistics 在不同 seeds 間的變異。摘要未提供資料切分細節、預測視窗長度、CRPS 的計算實作、各 occurrence statistics 的公式，亦未說明模型訓練與資料前處理的更多細節。

## 對我們的啟發
- [ ] 評估含有 point masses 的時間序列時，應檢查每個評估視窗的 atom 結構，而不能只依賴整體資料集的比例。
- [ ] 模型比較應採用匹配的評估協定，並報告多個 training seeds；摘要顯示 occurrence statistics 可能有顯著 seed 變異。
- [ ] 不宜將單一 CRPS 或單一 occurrence statistic 的排序視為完整結論；摘要指出五種統計量所得的模型排序並不一致。
