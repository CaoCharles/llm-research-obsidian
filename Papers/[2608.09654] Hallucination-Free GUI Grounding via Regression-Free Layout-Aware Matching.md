# Hallucination-Free GUI Grounding via Regression-Free Layout-Aware Matching

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.09654)
- 📥 [PDF](https://arxiv.org/pdf/2608.09654v1)

## 摘要（中文翻譯）

GUI agents 正從依賴 metadata 的大型語言模型，轉向直接操作 screenshots 的純視覺 multimodal large language models（MLLMs）。GUI grounding 的核心是將抽象使用者指令轉換為精確的介面元素座標。現有 grounding models 缺乏理解抽象指令所需的語義能力，而端到端 MLLMs 又因細粒度感知不足而產生座標幻覺。本文提出 regression-free framework：使用 frozen MLLM 解析指令，並由專用 grounding model 進行精確定位，且不學習座標回歸。MLLM 先將抽象指令擴展為包含 layout 線索的結構化視覺描述，再交由 Layout-Aware GUI Grounding Model，透過 layout-prior candidates 進行 matching，以抑制幻覺並避免昂貴的 fine-tuning。模型僅使用 Text/Icon 二元標籤訓練。在 ScreenSpot-Pro 上，相較端到端系統 grounding accuracy 提升超過 20%；在 Mind2Web 上，success rate 與 element selection rate 提升超過 15%。

## 問題背景

論文聚焦於無 GUI metadata 情況下，從 screenshot 將抽象自然語言指令 grounding 到精確 UI 元素座標。端到端 MLLMs 雖具語義理解能力，卻因細粒度視覺感知與 GUI layout inductive bias 不足而產生座標幻覺；傳統 grounding models 則缺乏抽象指令與空間語義理解。座標回歸微調雖可改善部分問題，卻需要昂貴標註且泛化有限。

## 解決方案

作者提出 decoupled intent-driven framework：先由 frozen MLLM 將抽象指令轉成富含視覺與 layout 線索的結構化描述，再由 Layout-Aware GUI Grounding Model 定位。模型以 GUI-domain-adapted DINO、Text/Icon 二元 layout prior 產生候選，並透過 frozen CLIP 的文字—影像相似度選擇候選，直接輸出其 bounding box，避免最終座標回歸。對空間限定指令，另以只有單層線性投影的 geometric fusion 調整視覺特徵。核心創新是將 MLLM 的語義推理與專用模型的細粒度 layout 感知分離。

## 核心貢獻
1. 提出專用的 Layout-Aware GUI Grounding Model，以 frozen cross-modal matching 取代可學習的座標回歸，直接輸出候選區域座標。
2. 提出僅依賴 Text/Icon 二元 layout 標籤的 layout-prior candidate generation，以及以單層線性投影注入幾何資訊的 lightweight geometric fusion。
3. 建立 decoupled intent-driven framework，由 frozen MLLM 負責指令語義擴展，專用 grounding model 負責細粒度定位，避免完整 MLLM fine-tuning。

## 技術方法

框架分為指令擴展與精確定位兩階段。第一階段將 screenshot I 與使用者指令 U 輸入 frozen、training-free MLLM；本文實驗使用 Qwen2.5-VL-72B，透過 prompt 與 in-context 設計產生結構化視覺描述 Q，例如包含文字、顏色、形狀及相對位置，但不輸出座標。第二階段先以 GUI-domain-adapted DINO 從 screenshot 產生候選區域；模型使用約 200k 張 GUI screenshots，僅標註 Text 與 Icon 二元類別。每個候選除了視覺 embedding，還計算六維 normalized geometry vector：[中心座標、寬、高、寬高比、面積]。接著以 frozen CLIP ViT-B/32 分別編碼候選 crop 與描述 Q，經 L2 normalization 後計算 cosine similarity，選取最高分候選並直接輸出其 bounding box，因此最終 matching 階段沒有可學習的座標回歸 head。為處理 upper-left、upper-right 等空間查詢，將六維幾何向量經唯一可學習的線性投影 Wg、bg 映射至 CLIP 特徵維度，並以加法融合；只訓練此投影，使用 spatial query-region positive pairs、batch negatives 與 InfoNCE loss。DINO 階段則使用標準 detection loss，包括 L1 regression、GIoU 與 focal classification loss。評估包含 ScreenSpot／ScreenSpot-Pro 的 click accuracy，以及 AITW 的 screen-wise action matching、Mind2Web 的 Element Accuracy、Operation F1 與 Step Success Rate。

## 對我們的啟發
- [ ] 對 GUI agent 而言，可將高層指令理解與像素級定位拆分，分別使用通用 MLLM 與專用視覺模型，以降低端到端座標預測的錯誤。
- [ ] 若介面元素語義類別繁多，先學習通用的 Text/Icon layout prior，可能比建立完整類別標註更具資料效率；但此洞察仍需在論文未涵蓋的設定中驗證。
- [ ] 空間資訊可透過輕量幾何特徵融合加入 matching，而不必為每種空間關係建立大量標註；實際部署時仍應檢查候選生成是否涵蓋目標元素。
