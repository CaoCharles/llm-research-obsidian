# How to Correctly Report LLM-as-a-Judge Evaluations

## 摘要（中文翻譯）

大型語言模型（LLMs）被廣泛用作模型回應的可擴展評估器，替代人類標註者。然而，LLM 判斷的不完美靈敏度（sensitivity）和特異度（specificity）會在簡單評估分數中引入偏差。本文提出一個簡單的插件式框架（plug-in framework），能夠修正此偏差並構建信賴區間，同時考慮測試資料集和人工評估校準資料集的不確定性，從而實現統計上嚴謹且實用的 LLM 評估。基於此框架，作者進一步提出自適應校準策略（adaptive calibration strategy），用於構建校準資料集以降低估計分數的不確定性。值得注意的是，研究刻畫了 LLM 評估在本框架內比完全人工評估產生更可靠估計的條件範圍。此外，該框架對測試集與校準集之間的分佈偏移（distribution shift）也比現有方法更具穩健性。

## 問題背景

LLM-as-a-Judge 在實際使用中存在系統性偏差問題：LLM 評審的靈敏度和特異度並不完美，導致直接使用 LLM 判斷計算的評估分數存在偏差。現有研究大多直接報告 LLM 的原始判斷結果，缺乏統計校正和不確定性量化，使得評估結果既不準確也不具備統計嚴謹性，無法可靠地比較不同模型的表現。

## 解決方案

提出一個基於統計推斷的插件式偏差校正框架，核心創新在於：(1) 利用少量人工標註的校準資料集估計 LLM 評審的靈敏度和特異度，進而校正大規模 LLM 評估的系統性偏差；(2) 構建同時考慮測試集抽樣不確定性和校準集估計不確定性的信賴區間；(3) 提出自適應校準策略，動態選擇最具資訊量的樣本進行人工標註，以最小化校準成本。

## 核心貢獻
1. 提出統計嚴謹的偏差校正框架，透過靈敏度/特異度估計修正 LLM-as-a-Judge 的系統性偏差
2. 建立包含雙重不確定性來源的信賴區間方法，使 LLM 評估結果具備統計可解釋性
3. 理論刻畫 LLM 評估優於純人工評估的條件範圍，並證明框架對分佈偏移的穩健性

## 技術方法

框架的核心基於統計學中的分類器校正理論。首先，在校準階段，從測試資料中抽取少量樣本，同時取得 LLM 判斷和人工標註，估計 LLM 評審的靈敏度（true positive rate）和特異度（true negative rate）。接著，在推斷階段，利用這些估計值對大規模 LLM 評估結果進行偏差校正，計算校正後的評估分數。

信賴區間的構建同時考慮兩個不確定性來源：(1) 測試集的抽樣不確定性（有限樣本導致的估計波動）；(2) 校準集估計靈敏度/特異度的不確定性。兩者通過 delta method 組合得到最終的信賴區間。

自適應校準策略採用序列設計（sequential design），每輪選擇使預期信賴區間寬度最小化的樣本進行人工標註，類似於主動學習（active learning）。實驗在多個 LLM 評估基準上驗證，比較了校正前後的偏差大小、信賴區間覆蓋率，以及與純人工評估的精度對比。

## 關鍵結果

| 指標 | 未校正 LLM 評估 | 校正後 LLM 評估 | 純人工評估 |
|------|----------------|----------------|------------|
| 偏差 | 顯著（5-15%） | 接近零 | 無（定義為基準） |
| 信賴區間覆蓋率 | 不適用 | ~95%（名義水準） | ~95% |
| 成本效率 | 高效但有偏 | 高效且無偏 | 昂貴 |
| 分佈偏移穩健性 | 差 | 優於現有方法 | 不適用 |
| 自適應 vs 隨機校準 | - | 減少 30-50% 校準樣本 | - |

## 對我們的啟發
- [ ] LLM-as-a-Judge 的評估結果應經過偏差校正後才能報告，直接使用原始判斷會系統性地高估或低估模型表現——這對所有使用 LLM 評審的研究都有方法論啟示
- [ ] 少量人工標註的校準集（而非大量標註）即可有效修正偏差，這為 LLM 評估的成本效益提供了理論基礎和實踐指南
- [ ] 在特定條件下（LLM 靈敏度/特異度足夠高、校準集夠大），LLM 評估比純人工評估更可靠——這為 LLM-as-a-Judge 的正當性提供了理論保證

## 限制與未來工作

框架假設 LLM 評審的靈敏度和特異度在校準集和測試集之間保持穩定，但在嚴重的分佈偏移下此假設可能不成立。此外，目前僅處理二元判斷場景，對多級評分（如 1-5 分）的擴展仍待研究。校準集的構建仍需人工標註，無法完全消除人力成本。
