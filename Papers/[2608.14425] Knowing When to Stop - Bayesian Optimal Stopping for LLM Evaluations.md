# Knowing When to Stop: Bayesian Optimal Stopping for LLM Evaluations

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.14425)
- 📥 [PDF](https://arxiv.org/pdf/2608.14425v1)

## 摘要（中文翻譯）

LLM 評測經常採用固定 sampling budget，對每個項目執行相同次數的測試，即使估計結果已足夠精確。本文提出 optstop，一個以 precision 為基礎的 adaptive stopping framework，將評測視為 sequential measurement problem：在不確定性仍高的地方持續 sampling，並在估計已足夠精確或穩定時停止。此 framework 建立於 hierarchical Bayesian inference，支援 binary、ordinal 與 continuous outcomes；所有 benchmark items 都保持可被抽樣，且不需要 calibrated item bank。它可在線上執行，也可對既有資料進行 retrospective analysis，並加入 safeguard：當測得的 performance 接近零時採取更保守的 sampling，因為此時 rare successes 尤其重要。在一個 200-item、10-epoch 的示範性評測中，九個 validation settings 移除了原定 trials 的 57%–97%，且整體結論與完整執行結果等價。結果顯示，LLM evaluation compute 可依 uncertainty 而非固定 repetition counts 進行配置，但節省幅度取決於 evaluation design。

## 問題背景

現有 LLM 評測多採固定 repetition counts，對所有 items 與 model-task combinations 使用相同 sampling budget，未依不確定性分配計算資源。這會在估計已精確後繼續浪費 inference calls，也可能在真正高變異或 rare-event 情境下證據不足。傳統 sample mean 與 standard error 又常不適合 sparse、ordinal、continuous heterogeneous data；既有 adaptive item selection 方法通常需要 calibrated item bank，且會減少 benchmark coverage。

## 解決方案

作者提出 optstop，將 LLM evaluation 視為 sequential measurement problem，依 posterior precision 動態決定何處繼續 sampling、何處停止。其核心是在 item 與 grouping 兩層使用 hierarchical Bayesian inference，當 credible interval 寬度低於使用者指定 threshold，或 CI width 進入 stabilisation 狀態時停止。與 IRT/CAT 類方法不同，optstop 不需 calibrated item bank，所有 benchmark items 仍具抽樣資格；可 live 整合 inspect_ai，也可 retrospective 執行。另一項創新是低 performance 時的 asymmetric conservatism adjustment，透過放大有效 CI width 並收緊穩定化條件，避免尚未發現 rare successes 便過早終止。

## 核心貢獻
1. 提出 optstop precision-based adaptive stopping framework，以 Bayesian credible-interval width 與 stabilisation criterion 決定 item-level 及 grouping-level 的資料收集何時停止。
2. 以 hierarchical Bayesian models 處理 evaluation data 的階層結構，支援 binary、ordinal、continuous bounded 三類 outcome，且不需預先 calibrated item bank，也不刪除 benchmark items。
3. 透過 3×3 validation matrix 驗證效率與結果保真度，並提出低 performance 情境下的 asymmetric conservatism adjustment，以降低尚未觀察到 rare successes 而過早停止的風險。

## 技術方法

optstop 將評測資料視為 responses nested within items，items nested within model-task groupings。資料可在線上透過 inspect_ai 的 live early stopping protocol 收集，或對完整資料作 retrospective analysis。每次 batch 更新後，使用 PyMC 的 MCMC 計算 posterior，再檢查兩層 stopping：item-level 的重複 epochs，以及 grouping-level 的 item 數量。主要規則是 posterior (1−α) credible interval 寬度 W=θU−θL 小於 δ 即停止；預設 credibility 為 97%，δ=0.05 代表約 ±2.5 percentage points 的 precision target。若寬度長期下降近乎停滯，則使用 sliding-window slope 的 stabilisation criterion 作 fallback。Binary outcome 在 item level 使用 adaptive Beta，group level 使用 logit-normal hierarchical model，estimand 為 population mean success probability。Ordinal outcome 使用 item-level Bayesian bootstrap over modal category，group level 使用 hierarchical ordered logistic；若 ordered assumptions 不適用則使用 Dirichlet-Multinomial fallback，並以 modal category 或 entropy convergence 作 hybrid stopping。Bounded continuous outcome 將分數正規化至 [0,1]，item level 以 method-of-moments 的 Beta，group level 使用作用於 item-level means 的 hierarchical logit-normal model。當 estimated performance 低於預設 low-performance threshold 時，將 effective interval width 乘以 conservatism factor c，並同步收緊 stabilisation slope threshold；預設 c=5。有效使用假設包含 grouping 內 observations exchangeable，以及 randomised item presentation order。實驗採 3×3 matrix，包含 binary、ordinal、continuous 三 pathways 與 low、mid、high performance levels；每 cell 約 200 items、10 epochs、δ=0.05，並以 shadow mode 在同一完整 run 中比較 full-run 與依停止點截斷的估計。結果使用 absolute score deviation、HDI+ROPE Bayesian equivalence、hierarchical meta-analysis、ranking preservation，以及 presentation-order replay 評估。

## 對我們的啟發
- [ ] 實務上可將 delta_item 與 delta_cap 依評測目的設定，讓已達到所需 precision 的 item 或 model-task grouping 停止，並把資源轉移至不確定性較高的區域；論文未提供不同應用情境的最佳 threshold。
- [ ] 若評測資料允許，continuous 或 ordinal rubric 的 information density 高於 binary scoring，論文實驗中 continuous pathway 的平均 efficiency gain 為 95.1%，ordinal 為 75.0%，binary 為 73.3%；但 ordinal estimand 是 modal category，不能直接當作 mean 解讀。
- [ ] 部署 live stopping 時應啟用 item randomisation，例如 inspect_ai 的 sample_shuffle，並檢查 grouping 內 exchangeability；論文明確指出 item ordering 與 difficulty 相關時，可能產生 subset selection bias。

## 限制與未來工作

驗證主要集中於單一 200-item、10-epoch 設定，尚缺更廣泛的 benchmark、規模與 grouping replication。epochs 可能相關，卻被視為 exchangeable，會高估 effective sample size。hierarchical binary simulation 顯示 94% nominal 下 empirical coverage 約 80%；接近 0% 或 100% 時可能 undercoverage。ordinal 結果也受 modal-category 與 mean 的 estimand mismatch 影響。
