# Avalon-ToM-Bench: Evaluating Fine-Grained Theory of Mind via Asymmetric Game Mechanics

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.09638)
- 📥 [PDF](https://arxiv.org/pdf/2608.09638v1)

## 摘要（中文翻譯）

Theory of Mind（ToM）對 agent interaction 至關重要，但既有評測不是依賴過度簡化 mental-state reasoning 的靜態情境，就是採用互動環境而缺乏診斷性分析。本文提出 Avalon-ToM-Bench，利用 The Resistance: Avalon 的 asymmetric-information mechanics，透過 human-crafted、perspective-constrained queries，將 ToM 拆解為 2×2 taxonomy：epistemic versus motivational reasoning，以及 inference versus action。對 28 個 LLM 的評測得到三項發現：模型具備良好的遊戲規則理解，卻有明顯較弱的 ToM；mechanistic analysis 顯示模型常在 hidden states 中表示正確的 mental-state inference，卻未能在生成時表達，linear probe 準確率為 77–82%，高於模型 chain-of-thought 的 62–70%；此外，dedicated reasoning training 平均提升 11.0 分，而 test-time chain-of-thought 僅提升 1.1 分，顯示穩健 ToM 更依賴學習到的 reasoning policy，而非增加推理時的 deliberation。

## 問題背景

既有 LLM ToM 評測常以靜態、簡化情境測試，忽略 asymmetric information、deception 與多方互動；以 hidden-role game 進行端到端評估則把 mental-state reasoning 與 planning、persuasion、memory 及策略能力混在一起。這使研究者難以知道模型究竟缺乏規則知識、視角推理、動機歸因，還是只是未能將內部推理表達出來。

## 解決方案

作者提出 Avalon-ToM-Bench，將 The Resistance: Avalon 的隱藏角色、非對稱資訊、公開投票與任務結果轉化為 controlled diagnostic environment。核心做法是以 epistemic/motivational 與 inference/action 兩軸建立 2×2 ToM taxonomy，再由作者從真實遊戲逐 seat、逐 turn 撰寫 perspective-constrained 命題。每個命題均依規則、指定角色可見資訊及 public history 產生客觀 TRUE/FALSE gold label，並加入規則控制集，以分離 game-rule comprehension 與 social reasoning。框架亦結合 probing、injection、steering 和 CoT/training ablation，從行為與內部表徵兩層診斷 ToM 缺陷。

## 核心貢獻
1. 提出 Avalon-ToM-Bench，將 Avalon 從端到端遊戲環境轉化為可診斷的 ToM 評測工具，涵蓋 Perspective-Taking、Strategic Signaling、Intention Attribution 與 Tacit Coordination 四種能力。
2. 建立 epistemic/motivational × inference/action 的 2×2 taxonomy，並以 human-authored、role-specific、perspective-constrained 的 TRUE/FALSE 命題，隔離視角受限的 mental-state reasoning。
3. 透過 28 個 LLM 的基準測試、linear probing、ground-truth injection、activation steering 與 chain-of-thought ablation，分析 ToM 失敗較接近 expression bottleneck，且 reasoning training 比 test-time deliberation 更有效。

## 技術方法

Benchmark 將 Avalon 視為 measurement instrument，而非要求模型獲勝的 gameplay arena。作者先記錄真實 Avalon 遊戲，再於遊戲結束後逐一檢視每個 turn、seat、private role view 與 public history，將完整狀態 G 依指定玩家 i 的 visibility projection 轉換為可用資訊 I_i；模型雖看到 annotated full state，但必須只依規則 R、I_i 與公開歷史 H 推理。資料包含 97 個 scenarios、408 個約半數為 TRUE 的 binary statements，分布於四個 cell：Perspective-Taking（epistemic×inference）、Strategic Signaling（epistemic×action）、Intention Attribution（motivational×inference）與 Tacit Coordination（motivational×action）；另有 34 題 rule-recall control set。每題使用固定 zero-shot prompt，要求模型輸出 TRUE/FALSE，採 accuracy 與 macro-F1 評估。實驗涵蓋 28 個 proprietary/open-weight、reasoning/non-reasoning、不同規模模型。作者以 permutation test 分析 taxonomy 軸向與 item difficulty、CoT benefit 的關係；在 Qwen3 open-weight models 上，於各層 last-token hidden state 訓練 logistic linear probes，並使用五折交叉驗證；另進行 ground-truth injection 與在最佳 probe layer 沿 TRUE−FALSE direction 的 activation steering，以區分 representation 與 expression。最後比較同權重的 test-time CoT 開關，以及 Qwen3-4B 與 reasoning-trained variant，分析訓練政策和推理長度對 ToM 的影響。

## 關鍵結果

| 結果項目 | 主要數據 |
|---|---:|
| 規則考試平均準確率 | 約 84.77%（論文正文另概述平均約 83.3%） |
| 全部 ToM 題平均準確率 | 71.98% |
| 四項能力平均準確率 | Perspective-Taking 63.46%；Strategic Signaling 70.42%；Intention Attribution 78.21%；Tacit Coordination 75.83% |
| 最佳模型 | Gemini-2.5-Pro：平均 89.67%；GPT-5：88.50% |
| 最弱模型 | OLMo-2-7B：平均 55.41% |
| Linear probe vs. 模型 CoT | Probe 約 77–82%；模型輸出約 62–70% |
| Ground-truth injection | 全能力平均由 69.9% 提升至 82.5%，增加 12.6 個百分點 |
| Test-time CoT | Qwen3 系列平均增加 1.1 個百分點，個別模型增減不一 |
| Reasoning training | Qwen3-4B 變體平均增加 11.0 個百分點；Perspective-Taking 增加 20.6 個百分點 |
| CoT 穩定性 | 約 27% 題目答案發生翻轉：約 16% 由錯轉對、12% 由對轉錯 |

上述數據來自論文的 408 題 balanced set、34 題規則控制集，以及指定的 Qwen3 ablation；論文未報告跨其他遊戲或開放式互動任務的結果。

## 對我們的啟發
- [ ] 實務上評估 social reasoning agent 時，應將規則記憶控制題與 perspective-constrained ToM 題分開，避免把 domain knowledge 缺失誤判為心智推理能力不足。
- [ ] 模型評測不宜只看最終答案；可結合 hidden-state probing、答案注入或其他可解釋性分析，檢查模型是否已形成正確表徵但在生成階段覆寫或未表達。
- [ ] 若目標是提升 ToM，優先考慮在訓練階段學習穩健的 reasoning policy，而不是單純增加 test-time chain-of-thought 長度；論文結果顯示後者增益小且具高變異性。

## 限制與未來工作

研究只使用 The Resistance: Avalon，未證實結果能否轉移至談判、多方對話或其他 social-deduction games。資料由作者自行遊玩並以 sole annotators 建構，規模為 408 題、97 個 scenarios；binary TRUE/FALSE 也壓縮了開放式 ToM 行為。mechanistic evidence 主要來自可存取的 Qwen3 hidden states，probe 具相關性，steering 則是 per-item supervised 的 existence proof，尚未定位 reasoning policy 在訓練中的形成階段。
