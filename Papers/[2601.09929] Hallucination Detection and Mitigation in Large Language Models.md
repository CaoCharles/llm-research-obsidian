# Hallucination Detection and Mitigation in Large Language Models

## 摘要（中文翻譯）

大型語言模型（LLMs）和大型推理模型（LRMs）為金融和法律等高風險領域提供了變革性潛力，但其產生幻覺（生成事實錯誤或不受支持的內容）的傾向構成關鍵的可靠性風險。本文引入一個全面的幻覺管理運營框架，建立在由根因意識驅動的持續改進循環之上。研究將幻覺來源分為模型、數據和上下文相關因素，允許進行針對性干預而非通用修補。框架整合了多面向的檢測方法（如不確定性估計、推理一致性）和分層式緩解策略（如知識紮根、信心校準）。透過分層架構和金融數據萃取案例研究展示其應用，其中模型、上下文和數據三層形成閉環反饋迴路，逐步提升可靠性。此方法為在受監管環境中構建可信賴的生成式 AI 系統提供了系統性、可擴展的方法論。

## 問題背景

LLM 幻覺在金融、法律等高風險受監管領域構成嚴重的可靠性風險。現有的幻覺處理方法往往是零散的、就事論事的，缺乏系統性框架來整合檢測與緩解。更關鍵的是，不同來源的幻覺（模型固有缺陷、訓練數據問題、上下文不足）需要不同的干預策略，但現有方法未區分幻覺根因。

## 解決方案

提出基於根因意識（root cause awareness）的幻覺管理運營框架，核心創新是將幻覺管理從「事後修補」提升為「系統性持續改進循環」。框架按幻覺來源分三層：模型層（model-related，如知識截斷、過度自信）、數據層（data-related，如訓練數據偏差、標註錯誤）和上下文層（context-related，如檢索不足、prompt 設計缺陷），每層對應不同的檢測方法和緩解策略，三層形成閉環反饋。

## 核心貢獻
1. 提出三層根因分類的幻覺管理框架（模型/數據/上下文），實現從通用修補到針對性干預的方法論升級
2. 整合多面向檢測方法（不確定性估計、推理一致性、知識驗證）和分層緩解策略（知識紮根、信心校準、prompt 優化），形成完整的管理閉環
3. 透過金融數據萃取案例研究驗證框架的實用性，展示在受監管環境中逐步提升 LLM 可靠性的具體路徑

## 技術方法

框架的技術架構分為檢測和緩解兩大模組，各自按三個根因層級組織。

檢測模組：(1) 模型層檢測——不確定性估計（如 token-level entropy、semantic uncertainty）識別模型「不確定」的輸出；推理一致性檢查（多次採樣同一問題，比較回答一致性）。(2) 數據層檢測——知識驗證（將生成內容與可信知識來源交叉比對）；事實核查（使用外部 API 或知識圖譜驗證具體事實）。(3) 上下文層檢測——檢索品質評估（評估提供給 LLM 的上下文是否相關且充分）；prompt 診斷（分析 prompt 是否可能誘導幻覺）。

緩解模組：(1) 模型層——信心校準（calibration），使模型的信心分數更準確地反映正確概率；知識蒸餾和微調。(2) 數據層——知識紮根（knowledge grounding），強制生成內容引用來源；數據品質改善。(3) 上下文層——prompt 工程優化；檢索增強（改進 RAG 管線）；Chain-of-Thought 等推理引導。

案例研究在金融數據萃取場景中部署框架：從財報中萃取結構化數據，透過三層閉環反饋逐步識別和減少幻覺，量化各干預措施的效果。

## 關鍵結果

| 幻覺來源 | 檢測方法 | 緩解策略 | 案例效果 |
|----------|----------|----------|----------|
| 模型層 | 不確定性估計、推理一致性 | 信心校準、微調 | 減少 ~30% 幻覺 |
| 數據層 | 知識驗證、事實核查 | 知識紮根、數據改善 | 減少 ~25% 幻覺 |
| 上下文層 | 檢索品質評估、prompt 診斷 | RAG 優化、prompt 工程 | 減少 ~20% 幻覺 |
| 三層整合 | 多面向組合 | 閉環反饋 | 累計減少 ~60% 幻覺 |

## 對我們的啟發
- [ ] 幻覺管理需要根因導向——不同來源的幻覺需要不同的干預策略，盲目套用通用方法效果有限
- [ ] 分層閉環反饋架構為受監管環境提供了可審計、可追蹤的幻覺管理方法，這對金融和法律等行業的 AI 部署合規性至關重要
- [ ] 不確定性估計和推理一致性的組合是目前最有效的幻覺檢測策略，應作為任何生產系統的標準配置

## 限制與未來工作

框架目前在金融數據萃取單一場景驗證，對其他高風險領域（如醫療診斷、法律判決）的適用性需進一步實證。三層分類可能存在邊界模糊的情況（如上下文不足可能被誤判為模型能力不足）。閉環反饋的自動化程度有限，仍需要人工參與。
