# PriceBench: A Diagnostic Benchmark for Price, Quality, and Brand Preferences in LLM Booking Agents

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.31468)
- 📥 [PDF](https://arxiv.org/pdf/2609.31468v1)

## 摘要（中文翻譯）

大型語言模型（LLM）日益充當購買代理，使真正替使用者在合格選項中作決定的主體變成 LLM；其未明示的偏好會默默決定購買內容與成本。論文提出 PriceBench，一個診斷性 benchmark，利用 logit choice model，從訂房選擇恢復 LLM 對價格、品質與品牌的偏好。研究在 179 間真實紐約飯店、3,600 個訂房任務上評估來自 8 家供應商的 28 個 LLM。結果顯示，能力主要與選擇一致性相關，而非與偏好方向相關；較強模型具有更穩定、明確的偏好，較弱模型則可能鎖定列表位置或近乎無差別選擇。不同模型及同一家族內模型的價格敏感度與價格—品質取捨差異顯著，使相同任務的平均訂房價格介於 247 至 393 美元。因此，代理實際購買什麼必須逐一測量，不能僅由模型能力或供應商推斷。

## 問題背景

現有 agent benchmark 多評估是否完成訂房、遵守預算或成功操作網站，卻未揭示在多個均符合使用者約束的選項中，代理究竟偏好哪一個。因此無法測量代理的 revealed purchasing policy，也無法知道其對價格、品質與品牌的隱含取捨。論文要解決的是：如何以可比較、可估計且能辨識列表位置偏差的方法，從 LLM 的實際選擇恢復其購買偏好。

## 解決方案

作者提出 PriceBench，將飯店訂房建模為 constrained discrete-choice 任務，讓每個 LLM 在相同選項上做二元、三元選擇，並以交換列表順序的重複測試識別 position bias。核心方法是對選擇結果擬合 logit choice model，以屬性差異估計價格、星級、評論、房型、取消政策、早餐、設施與品牌權重；價格同時使用 linear、log-price 與 non-parametric decile 形式。先以 first-shown rate 篩除 position-locked 模型，再比較 engaged 模型的價格敏感度、review-score WTP 與品牌係數，並以多選項、提示格式、sampling 和 bootstrap 檢驗穩定性。

## 核心貢獻
1. 提出 PriceBench，將 LLM booking agent 的選擇結果轉化為可估計的價格、品質與品牌 revealed preferences，而不只評估任務是否完成。
2. 建立包含列表順序交換、position-lock triage、binary/ternary choice 與 logit choice estimation 的完整診斷流程，並釋出任務、程式碼、28 組回應與多種 robustness runner。
3. 實證顯示模型能力主要關聯選擇的一致性與 decisiveness，而非偏好方向；價格—品質取捨、WTP 與品牌偏好即使在同一家族內也可能顯著不同。

## 技術方法

資料來自 179 間紐約飯店，涵蓋 1–5 星、36 個 neighborhood 與每晚 45–1,650 美元。每筆飯店有十項屬性：星級、地區、chain affiliation、amenities 等固定欄位，以及每次出現時重新抽樣的價格、房型、免費取消、早餐、評論分數與評論數。任務包含 450 組飯店 pair，各呈現四次形成 1,800 個 binary tasks；另有 300 組 triple，各呈現六次形成 1,800 個 ternary tasks，並在原始及交換順序下評分。二元選擇以 logistic regression 估計 Pr(A)=σ(c+f(pA)−f(pB)+(xA−xB)γ)，其中 intercept c 吸收固定的首位偏好；三元任務使用 multinomial logit。價格函數分別採線性價格、log-price 與價格 decile dummy。模型先依 first-shown rate 判定是否 position-locked；論文將 15%–85% 視為 engaged 範圍。主要指標包括價格係數、review-score 係數、以 250 美元為參考價格計算的 willingness to pay（WTP）、品牌相對獨立飯店的係數、平均訂房價格、pseudo-R²、選擇命中率與 Spearman rank correlation。穩健性分析涵蓋 JSON、欄位重排、persona、chain-of-thought、temperature 0.7、五選一任務，以及以 450 組 pair 為單位的 500 次 cluster bootstrap。

## 關鍵結果

| 分析面向 | 主要結果 |
|---|---|
| 評估規模 | 28 個 LLM、8 家 provider、179 間紐約飯店、3,600 個任務；每個 LLM 最多 7,200 筆觀察 |
| Position lock | 5/28 個 LLM 在 temperature 0 鎖定首個選項，first-shown rate 為 88.2%–100.0%；列表控制者可控制其約 88%–100% 的訂房 |
| 價格敏感度 | engaged LLM 的 log-price 係數從 GPT-5.4 的 −7.02 至 Qwen3 30B-A3B 的 −0.40，跨模型超過一個數量級 |
| 價格反應形式 | 21 個具有真實負向價格反應的模型中，AIC 對 10 個選 linear、10 個選 log，另有 1 個平手；非參數曲線呈現線性、凸形、門檻與價格作為品質訊號等形狀 |
| 價格—品質取捨 | 20 個充分識別的模型，其一個 review-score point 的 WTP 約為 68–1,071 美元，約 16 倍差距；GPT-5.4、Mini、Nano 的 WTP 分別為 107、222、500 美元 |
| 實際訂房價格 | 相同任務下，GPT-5.4 平均每晚訂房 247 美元，Phi-4 Mini 為 393 美元，差距 146 美元 |
| 品牌偏好 | 23 個 engaged LLM 中，11 個偏好五個 chain 高於可比的獨立飯店；控制地區後為 7 個。品牌偏好與 provider 的關聯不顯著，permutation p=0.48 |
| 能力關聯 | Artificial Analysis index 與選擇 decisiveness 的相關為 0.63、與價格係數絕對值為 0.71；與 WTP 的方向不顯著，論文報告所有 p>0.09 |
| 多選項泛化 | 五選一任務命中率為 42%–52%，高於 20% chance；top-2 為 66%–84%，高於 40% chance |
| 穩定性 | bootstrap 的價格敏感度排名平均 Spearman 相關為 0.996，WTP 排名為 0.991；報告的 p<0.001 係數均通過 Bonferroni 與 Benjamini–Hochberg 校正 |

## 對我們的啟發
- [ ] 部署訂房或購物代理前，應針對實際使用的每個 LLM 測量 revealed preferences，不宜用模型規模、能力排名或 provider 直接代替偏好審計。
- [ ] 應將列表順序視為重要的安全與商業控制面：對 position-locked 模型，排序即可大幅改變結果；對 engaged 模型，也應監測其殘餘 ordering bias。
- [ ] 評估代理不應只看任務成功率，還應報告價格敏感度、品質 WTP、品牌溢價與跨提示格式的穩定性，因為同一選項集合可能被不同模型購買出明顯不同的價格結果。

## 限制與未來工作

研究只在紐約飯店領域驗證，不能直接外推至其他商品或多步驟工具代理。主要估計條件是中性文字提示、temperature 0，只有 6 個模型接受完整提示變體測試；WTP 會受格式影響。論文未收集人類在同一任務上的選擇，且能力結果是 28 個模型間的橫斷面關聯，不能確立因果。品牌 dummy 也較粗略，未細分子品牌與飯店固定效果。
