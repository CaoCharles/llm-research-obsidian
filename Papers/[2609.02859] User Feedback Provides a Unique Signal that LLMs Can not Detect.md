# User Feedback Provides a Unique Signal that LLMs Can not Detect

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.02859)
- 📥 [PDF](https://arxiv.org/pdf/2609.02859v1)

## 摘要（中文翻譯）

利用使用者互動中自然產生的 feedback，為 Large Language Models（LLMs）提供學習訊號，是改善模型的重要方向；然而近期研究認為此類 feedback 天然嘈雜且難以有效利用。本研究挑戰此看法，指出 user feedback 實際上是高度可操作的改善訊號，其效果之所以被低估，源於現有 evaluation paradigms 的系統性偏差。作者建立具有明確 ground truth 的 synthetic data，並以 naturalistic data 驗證結果是否適用於真實情境。比較取得與未取得 feedback 的模型修訂後，feedback-informed revisions 在解決目標問題上的成功率顯著較高。進一步分析發現，當模型僅因 feedback 才修正問題時，LLM judges 經常無法辨識真正修正的答案，反而系統性偏好較差的 baseline outputs。

## 問題背景

論文探討 naturally occurring user feedback 是否真能改善 LLM 回應。既有研究以 reward model 或 LLM-as-a-judge 比較有、無 feedback 的修訂，常得出 feedback 無效甚至較差的結論；但這些評估可能偏好流暢或風格性變化，無法辨識細微的 factual、logical 或 completeness 修正。問題因此不只是 feedback 噪聲，也包括評估器對 feedback-driven improvements 的系統性誤判。

## 解決方案

作者以「可驗證的 issue resolution」取代單純 pairwise preference，建立 synthetic 與 naturalistic 雙重實驗框架。Synthetic data 先將原本有效的模型回應施加四類可追蹤 corruption，並產生三種強度的 feedback；再比較 improver 在有、無 feedback 下的修訂。Naturalistic data 則從 ShareLM 對話抽取自然 feedback，過濾主觀或僅適用個人的內容。核心創新是將修正成功率與 LLM judge 的偏好分離，並在 feedback-only 成功的子集建立「應由有 feedback 回應勝出」的條件，以直接測量 judge blind spot。

## 核心貢獻
1. 以 synthetic corruption 加上可驗證 ground truth，證明 feedback-informed revisions 比無 feedback baseline 更常解決目標問題；並在 naturalistic user data 上重現此趨勢。
2. 揭示 LLM-as-a-judge 的 evaluation blind spot：在只有有 feedback 回應修正問題的案例中，judge 仍常偏好無 feedback 回應，naturalistic 情境正確率僅 34%–54%。
3. 提出並以實驗支持 correlated failure 假說：模型若無法自行改善某類問題，也較可能無法正確評估該類 feedback-driven improvement；同時顯示 feedback 促成較多 substantive content improvements，而非僅風格修改。

## 技術方法

資料方面，synthetic 實驗使用 Arena-Hard-v2.0 的 500 個 hard prompts，取 o3 回應後由 Gemini-3-flash-preview 施加 causality inversion、crucial omission、entity/subject swap、logic operator reversal 四類 corruption；每筆同時產生 change log、難度與三種 feedback：完整解法（fsol）、只指出問題（fprob）、僅表示有問題（fbinary）。Naturalistic 實驗使用 ShareLM 英文對話，由 Qwen3-30B-A3B-Instruct-2507 抽取 feedback，再由 Gemini-3-Flash 判定是否具有普遍、可操作性。Improver 使用 Gemini-3-flash-preview（large）與 Qwen3-8B（small），分別生成有 feedback 的 r+f 與無 feedback 的 r−f。評估包含 issue-resolution judge：依 intent matching、completeness 與 regression，以 1–5 分及 binary decision 判定是否修正；以及隨機交換順序的 pairwise judge，比較兩個候選回應。作者另分析「有 feedback 成功、無 feedback 失敗」的 WFShouldWin 子集，並以不同模型的自我改善能力切分資料，檢驗 improver 與 judge 的 correlated failure。

## 關鍵結果

主要結果如下（論文主文 synthetic 數據以 hard prompt 為主）：

| 設定 | Improver | 無 feedback | 有 feedback | 增幅 |
|---|---|---:|---:|---:|
| Synthetic | Large | 86.3% | 95.6% | +9.3 個百分點 |
| Synthetic | Small | 42.7% | 77.9% | +35.2 個百分點 |
| Naturalistic | Large | 約70% | 約89% | 約+19 個百分點 |
| Naturalistic | Small | 約26% | 約53% | 約+27 個百分點 |

| WFShouldWin 子集 | Judge 正確偏好有 feedback |
|---|---:|
| Synthetic、Large improver | 54.6% |
| Synthetic、Small improver | 80.9% |
| Naturalistic、Large improver | 34% |
| Naturalistic、Small improver | 54% |

在 synthetic pairwise 評估中，Large 的 judge 偏好無 feedback 37.8%、有 feedback 27.2%、平手 35.0%；Small 則分別為 34.3%、51.2%、14.5%。較弱 feedback 仍有效：Large 的「指出問題」與「僅表示有問題」相對無 feedback 的增幅為 +6.3 與 +3.4 個百分點；Small 為 +16.7 與 +10.3 個百分點。

## 對我們的啟發
- [ ] 評估 feedback 或 self-improvement 時，不應只依賴整體 pairwise preference；應建立可驗證的 issue-resolution 指標，並報告 feedback-only 成功子集。
- [ ] Feedback pipeline 可保留不同訊息強度：即使只指出問題，甚至只表示存在問題，也能帶來改善；但完整修正指示通常效果最大。
- [ ] 部署 user-feedback learning 時，應把內容正確性、邏輯與完整性和 tone、formatting 分開評估，避免 judge 因偏好風格變化而低估實質修正。

## 限制與未來工作

Synthetic corruption 在 creative writing 類別較不可靠，因此主文主要聚焦 math 與 code；naturalistic issue-resolution 的人工驗證 Cohen’s kappa 僅 0.24。Pairwise 評估未完成全面人工標註，且主要實驗僅涵蓋少數模型。作者未直接驗證 training-time learning，未來需以更多模型、領域與人工或專門 reward model 複核。
