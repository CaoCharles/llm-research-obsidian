# TrialAtlas: Multi-Agent Research Organization for Clinical Trial Design and Optimization

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.21859)
- 📥 [PDF](https://arxiv.org/pdf/2609.21859v1)

## 摘要（中文翻譯）

近 90% 進入臨床開發的藥物最終失敗，儘管投入了數十億美元。製藥公司因此依賴臨床開發規劃（CDP）以及技術與法規成功機率評估來預測開發風險；然而，這些決策仍然勞力密集且帶有主觀性，需要臨床科學、統計、法規事務與競爭情報等專家共同取得、整合並推理異質性證據。本文提出 TrialAtlas，一個具記憶增強能力的多代理研究組織，用於 CDP，透過協調文獻綜述、競爭性試驗情報、法規先例分析及試驗設計與開發風險的整合推理代理，模擬此協作流程。TrialAtlas亦從歷史臨床試驗與法規結果（包括既有 NDA）學習，以累積的開發經驗支撐決策。作者建立 TrialAtlasBench，從291封 FDA Complete Response Letters（CRLs）整理三項任務：偵測試驗設計缺陷、提出可執行的設計改進，以及預測技術與法規成功。TrialAtlas在缺陷偵測達到50.0% F1，在成功預測達到85.3% balanced accuracy與84.7% F1；專家評估中，86.4%的其提出疑慮被判定為有效。

## 問題背景

臨床試驗設計需要跨學科搜尋、整合文獻、競爭試驗與 FDA 法規先例，但現有 AI 多集中於孤立的結果預測、文獻搜尋或報告生成，通常只依賴試驗摘要，難以指出具體設計缺陷、提出可執行的 protocol-level 改進，也較少納入 NDA 審查標準。因此，既有方法對真實法規決策的可解釋性、可追溯性與實務支援能力不足。

## 解決方案

作者提出 TrialAtlas，一個具階層式組織與持久記憶的 multi-agent research organization。Director 負責問題分解、規劃與整合；Competing Trial Analysis、Literature Evidence Synthesis 及 Drug Benchmarking 等部門由 Department Heads 和 specialized working agents 執行專門分析。系統先從 ClinicalTrials.gov、PubMed、FDA CRLs、Drugs@FDA 與產品標籤取得證據，再透過共享 memory base 檢索歷史試驗、法規理由與補救策略。其核心創新是把試驗設計支援從單純 outcome prediction 擴展為法規對齊的缺陷診斷、可執行優化與成功預測，並以可檢視的證據與先例呈現推理。

## 核心貢獻
1. 提出 TrialAtlas 階層式多代理研究組織，協調競爭試驗分析、文獻證據綜合、藥物基準比較與整合推理。
2. 建立 TrialAtlasBench，將291封 FDA CRLs 與 ClinicalTrials.gov 試驗設計連結，評估缺陷偵測、設計優化及技術與法規成功預測三項任務。
3. 以 FDA 法規先例與歷史試驗建立共享 human-readable memory base，並透過製藥業專家盲評驗證輸出疑慮的實務有效性。

## 技術方法

資料方面，作者蒐集 OpenFDA 的291封 FDA Complete Response Letters，經去重、embedding、階層式凝聚分群及 GPT-5 分類，整理為16類法規缺陷。CRL先透過 NDA/BLA 與 FDA 標籤連結 ClinicalTrials.gov；無法直接連結者再以 TrialMind 搜尋，最後得到588組 CRL–NCT 配對。作者僅保留可由 registry 結構化欄位推斷的設計問題，形成 Phase 3 試驗資料；另以2020–2025年首次提交即核准的申請建立無缺陷對照。資料按更新年份切分，較新的試驗作為約150筆 held-out benchmark，其餘266筆供系統發展。TrialAtlas執行三項任務：多標籤選擇題形式的缺陷偵測、選擇 protocol-level actionable optimization，以及二元技術與法規成功預測。執行流程包含解析試驗、規劃查詢、檢索競爭試驗與 PubMed 文獻、進行藥物及法規基準比較、讀取 memory base，最後由 Director 整合。比較系統包括 GPT-5 standalone、ReAct、Biomni 與 TrialGenie，所有系統均以 GPT-5 為 backbone。評估使用 precision、recall、F1、balanced accuracy 與 Cohen’s kappa；另由6名製藥業專家盲評缺陷有效性，共228項判斷。

## 關鍵結果

主要結果如下（數字均為論文報告值）：

| 任務／指標 | TrialAtlas | 最佳 baseline | 改善或補充 |
|---|---:|---:|---:|
| 缺陷偵測 Precision | 50.0% | 45.8%（baseline最高） | TrialAtlas 同時達到 precision、recall、F1 50.0% |
| 缺陷偵測 Recall | 50.0% | 45.8%（baseline最高） | 論文報告 TrialAtlas F1 比 TrialGenie 高6.1個百分點 |
| 缺陷偵測 F1 | 50.0% | 43.9%（TrialGenie） | +6.1個百分點 |
| 設計優化 Precision | 82.9% | 71.7%（Biomni） | 論文報告 TrialAtlas 最佳 |
| 設計優化 Recall | 65.1% | 51.4%（ReAct） | 論文報告 TrialAtlas 最佳 |
| 設計優化 F1 | 69.4% | 56.6%（Biomni） | 論文報告 TrialAtlas 最佳 |
| 成功預測 Balanced accuracy | 85.3% | 78.6%（Biomni） | +6.7個百分點 |
| 成功預測 F1 | 84.7% | 78.4%（TrialGenie） | 論文報告 TrialAtlas 最佳 |
| 成功預測 Cohen’s kappa | 0.694 | 0.574（TrialGenie） | 論文摘要報告提升12.0個百分點 |
| 專家判定有效疑慮比例 | 86.4%（76/88） | OpenAI DeepResearch：83.1%（49/59）；Gemini：59.3%（48/81） | 6名專家、228項判斷；專家間一致率73.7% |

作者的消融案例顯示，memory base 可避免把已被 FDA 接受的設計慣例誤判為缺陷；但這是案例層級證據，論文未報告完整量化消融結果。

## 對我們的啟發
- [ ] 對高風險領域的 agent evaluation，不應只測單一結果分類；可同時評估缺陷定位、可執行建議與最終風險預測，讓 benchmark 更接近實際決策流程。
- [ ] 多代理系統的價值不只在分工，也在於讓每個結論連結檢索證據與歷史先例；實務部署時應保留來源、推理鏈與人工覆核介面，以支持 traceability。
- [ ] memory augmentation 可降低因 registry 資訊不完整或忽略法規慣例而產生的 false positive，但應搭配持續更新、來源驗證與專家 adjudication；TrialAtlas 的缺陷偵測 F1 僅50.0%，不適合自主決策。

## 限制與未來工作

作者指出，缺陷偵測的 precision、recall 與 F1 均為50.0%，仍有大量漏報與誤報。CRL 數量有限，benchmark規模較小；ClinicalTrials.gov 主要提供結構化 registry 資訊而非完整 protocol，可能遺漏關鍵細節。未來可擴充 CRL、納入完整 protocol、前瞻性法規指引及 human-in-the-loop 回饋。
