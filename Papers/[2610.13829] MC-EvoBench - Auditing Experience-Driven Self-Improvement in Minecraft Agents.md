# MC-EvoBench: Auditing Experience-Driven Self-Improvement in Minecraft Agents

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.13829)
- 📥 [PDF](https://arxiv.org/pdf/2610.13829v1)

## 摘要（中文翻譯）

具身 recursive self-improvement 的核心挑戰，是讓 agent 將互動歷史轉化為可持續、能跨越不同世界並遷移至後續任務的能力。僅保存 memory 或完成一次成功動作，並不能證明 agent 已取得可重用能力；評估必須區分能力變化、沿用資源、source exposure 不均，以及早期執行失敗。作者建立 MC-EvoBench，這是一個受控的 Minecraft benchmark，包含固定的 19 條 evolution chains、12 條主要評估鏈、7 條校準或 probe 鏈，以及 3 組依圖結構配對的 transfer probes。每項任務以 task-state graph 表示，使用 stage-level environment verifiers，配對 source 與 target 角色、重設 target world，且只允許宣告的 agent artifact 跨越 source-target 邊界。每項 probe 在 no-prior、related、unrelated 與 shuffled source 條件下，以匹配的 environment-step budgets 和五個 seeds 評估，並回報 TSR、WGP、VMP 與 provenance records。結果顯示 controller 變體的 direct capability 持續優於 planner-backed 變體；related experience 未產生穩定 transfer，木材物種 probe 的微小增益受單一 seed 影響，所有區間均包含零。Stage audits 也顯示，早期伐木與 crafting bottlenecks 常使後續能力無法被觀測。

## 問題背景

論文探討 embodied recursive self-improvement 中，agent 是否真的從 source experience 獲得能在新世界重用與遷移的能力。既有評估多聚焦單次 end-task success 或 final reward，無法排除 inventory、工具、world edits、起始位置、source exposure 不均與 execution luck 等混淆因素；保存 memory 或成功 trajectory 也不等於能力已形成。此外，長鏈任務的早期失敗會掩蓋後續能力，使單一最終分數難以歸因。

## 解決方案

作者提出 MC-EvoBench，一個用於審計 Minecraft agents 經驗驅動自我改進的受控 benchmark。其核心是將任務建模為包含 80 個 tasks、111 個 states 與 369 條 typed edges 的 task-state graph，並用 stage-level verifiers 記錄中間進度。評估時重設 target world、inventory 與 physical state，只允許宣告的 persistent agent artifact 跨越 source-target boundary；同時以 no-prior、related、unrelated 和 shuffled source 進行 matched controls。框架以 TSR、WGP、VMP 分別衡量階段完成、加權圖進度與 verified milestones，並保存 artifact identity、source cost、termination status 和 stage evidence，以區分真正的 capability transfer 與資源沿用或早期執行失敗。

## 核心貢獻
1. 提出 embodied RSI 的可歸因能力變化定義：只有在 target world reset、僅傳遞宣告 artifact，且經 matched controls 排除替代解釋後，性能增益才可視為 experience-driven。
2. 建立 MC-EvoBench 受控 benchmark，整合 80 個 tasks、111 個 states、369 條 typed edges、19 條 chains、stage-level verifiers、三項進度指標與 provenance records。
3. 以 direct capability matrix 與 paired transfer probes 分離執行能力和經驗遷移，實驗顯示 reference method 的 related experience 未產生穩定 transfer，並揭示早期 wood collection 與 crafting bottlenecks。

## 技術方法

Agent 被形式化為 A=(π,z,U)，其中 π 是依據 observation 與 goal 選擇 action 的 policy，z 是可保留的 persistent state，U 是由 experience 更新狀態的規則。Source phase 中 agent 與註冊任務互動並形成 zS；之後 evaluator 凍結 artifact，重設 target 的 world、inventory、position 與其他 working state，target 僅能讀取該 artifact。Benchmark 使用 Minecraft 1.16.5、MineRL 及自訂生存環境，agent 透過正常 observation 行動；graph、verifier、hidden coordinates 不對 agent 開放。任務由 requires、produces、consumes 等 typed edges 組成 stage chains，每個 stage 以 environment evidence 驗證。評估包括 direct capability matrix，以及三組 paired probes：wood-species crafting、wooden-tool transfer 和 stone-tool transfer。每組比較 no-prior、related、unrelated、shuffled 四種條件，採五個 matched seeds；source environment steps 在家族內固定為 900、2,250 或 3,600。TSR 為通過 stage 的比例，WGP 為通過 strict execution edges 的加權進度，VMP 為達成 eligible item/tool milestones 的比例；另計 ΔR 與描述性 GATG，並回報 95% Student-t confidence intervals。Direct matrix 的 12 條主要 chains 各以三個 seeds 評估，涵蓋 core progression、catalog transfer 與 diversity。

## 關鍵結果

| 實驗面向 | 主要結果 |
|---|---|
| Direct capability：STEVE-1 平均 | TSR 8.4%，WGP 6.4%，VMP 25.5% |
| Direct capability：JARVIS-1 controller-only 平均 | TSR 7.5%，WGP 5.5%，VMP 25.0% |
| Direct capability：Optimus-1 controller-only 平均 | TSR 8.1%，WGP 6.1%，VMP 25.4% |
| JARVIS-1 planner 最佳平均 TSR | 2.8%（DeepSeek planner） |
| Optimus-1 planner 最佳平均 TSR | 4.9%（DeepSeek planner） |
| 官方 VPT foundation weights 平均 VMP | 10.4%，高於 STEVE-1 checkpoint 的 3.2%，但低於 controller variants |
| Wood species：no-prior / related TSR | 0.400 / 0.400 |
| Wood species：related ΔR | TSR 0.000、WGP +0.040、VMP 0.000 |
| Wooden tool：no-prior / related TSR | 0.320 / 0.200 |
| Wooden tool：related ΔR | TSR −0.120、WGP −0.075、VMP −0.193 |
| Stone tool：no-prior / related TSR | 0.150 / 0.050 |
| Stone tool：related ΔR | TSR −0.100、WGP −0.062、VMP −0.333 |
| Control-adjusted GATG 最大值 | +0.060（wood species 的 WGP）；所有 95% intervals 均包含零 |
| Source exposure | 各 probe family environment steps 固定；related source 在較長 probes 有較多 planner calls，但未帶來 target gain |
| Failure-stage audit | STEVE-1 42 次報告中，24 次收集木頭、14 次製作木板、2 次到達 sticks、0 次完成 crafting table；完整 chain 通過率 5.3% |

作者據此認為：controller-based agents 具有較佳 direct execution capability；在目前 agents、probes、seeds 與 budgets 下，related experience 沒有穩定的 transferable capability。論文未報告更大 seeds、其他 agent 或不同 source budget 下的 transfer 結果。

## 對我們的啟發
- [ ] 評估 agent memory 或 self-improvement 時，應將 physical state 與 persistent agent artifact 嚴格分離，並在 reset 後測量後續行為，而不能只檢查 memory 是否寫入或 source task 是否成功。
- [ ] 對長期、分階段任務，應同時保存 stage-level evidence 與 final outcome；否則早期執行瓶頸會讓後續能力不可見，導致錯誤的能力或 transfer 結論。
- [ ] source exposure 的 environment steps 相同，不代表計算量與互動機會相同；實驗應記錄 episode 數、planner calls、termination states，並以 unrelated 與 shuffled controls 進行增益歸因。

## 限制與未來工作

研究結論限於測試的 agents、Minecraft probes、公開 seeds、artifact 形式與 source budgets；paired transfer 僅使用五個 matched seeds，統計區間較寬。多數 runs 在早期 crafting stages 終止，後續能力未充分觀測。論文未驗證更強 agents、更多 seeds、retention、composition 或真實世界 transfer，並指出這些是未來方向。
