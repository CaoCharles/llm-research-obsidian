# NeuroRefiner: Morphology-Aware Multi-Agent Refinement for 3D Fluorescence Microscopy Neuron Segmentation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.09636)
- 📥 [PDF](https://arxiv.org/pdf/2608.09636v1)

## 摘要（中文翻譯）

準確的 3D fluorescence microscopy 神經元 segmentation 對神經科學至關重要。然而，神經元具有稀疏且細長的 morphology，現有 segmentation 方法難以同時保留局部細節與全域 topology，因而產生 fragmented results。為此，作者提出 NeuroRefiner，一個將人類專家「反覆全域觀察與局部編輯」工作流程形式化的 multi-agent system。系統包含三個協作 agents，分別負責診斷 topology errors、產生 correction instructions，以及驗證 refinement quality。為執行 agent 指令引導的 segmentation refinement，作者提出專用的 3D U-Net 工具 TopoRefineNet，透過 cross-modality feature fusion 生成 refined masks。經由多輪 agent reasoning 與 voxel-level editing，NeuroRefiner 產生 topology 更準確且更具可解釋性的 segmentation。在 BigNeuron、CWMBS 與 ZBFWB 三個資料集上的實驗顯示，本方法優於現有方法，並在具挑戰性的 ZBFWB 資料集上達成 3.02% 的 F1 improvement。

## 問題背景

3D fluorescence microscopy 的神經元影像通常具有稀疏、細長、低對比與高雜訊特性。現有 sliding-window 或 single-pass segmentation 方法受限於局部 receptive field，難以建模長距離 connectivity，容易造成神經突觸或軸突斷裂、fragmentation 與 noise。既有 refinement 方法多聚焦邊界或局部 label correction，缺乏 topology-aware 的錯誤定位、反覆修正機制與可稽核的 reasoning workflow。

## 解決方案

作者提出 NeuroRefiner，以模擬神經科學專家「先全域觀察、再局部編輯、最後驗證」的流程。Global Inspector 使用 MIP、sub-block mask 與 β0 指標找出 topology anomalies；Refinement Advisor 結合 XY/YZ 視圖產生具體的空間化文字修正指令；Change Validator 檢查指令遵循度與 topology 是否改善，決定接受或重試。TopoRefineNet 是連接 LLM reasoning 與 voxel editing 的專用 3D U-Net 工具，以 image-mask 視覺特徵和文字 embedding 做 cross-attention，執行 instruction-guided mask refinement。多輪閉環協作使系統能修補 FN 斷裂並移除 FP 雜訊。

## 核心貢獻
1. 提出 NeuroRefiner，將 Global Inspector、Refinement Advisor 與 Change Validator 組成 topology-aware、可迭代的 LLM-based multi-agent neuron segmentation refinement framework。
2. 提出 TopoRefineNet，一個以 3D U-Net 為基礎、透過視覺特徵與文字指令 cross-attention 融合來執行 voxel-level mask editing 的專用工具。
3. 設計由 synthetic defects 到 real-world defects 的 two-stage training strategy，並在 BigNeuron、CWMBS 與 ZBFWB 上證明其 segmentation 與 topology refinement 效果。

## 技術方法

NeuroRefiner 以 off-the-shelf segmentation model 產生初始 mask M(0)，再進行最多 Tmax=5 輪 refinement。Global Inspector 對 mask 與影像沿 z-axis 做 Maximum Intensity Projection（MIP），將全域平面切成 128×128 的 non-overlapping sub-blocks；同時計算各區域的 0-th Betti number β0，即 3D connected-component count，用以找出可能的 fragmentation 或 isolated noise，並標記 false-negative（FN）或 false-positive（FP）。Refinement Advisor 針對問題區塊，分析 XY 與 YZ 兩個 orthogonal projections 的原始影像及 mask，產生含空間位置與操作類型的自然語言指令，例如 connect、repair break 或 remove noise。TopoRefineNet 接收 3D image、imperfect mask 與文字 instruction；視覺 encoder 將 image-mask concatenation 編碼為 hierarchical feature pyramid，frozen Qwen3 Embedding 0.6B 編碼文字，並在最深層視覺特徵上以 cross-attention 融合，再由 decoder 與 skip connections 輸出 refined mask。其 two-stage training 第一階段以 erosion、copy-paste 與 Gaussian noise 合成 FN/FP defects，第二階段使用多個 segmentation networks 產生的真實錯誤 mask，共選取 5,310 個 128×128×64 volumes，並以 Qwen3-VL 產生 instructions；訓練採 cross-entropy 與 Dice loss。Change Validator 僅在 instruction adherence 與 topology improvement 皆成立時接受修改，否則重新產生指令。評估使用 precision、recall、F1、Spatial Distance（SD）、SSD 與 MES，並透過 APP2 reconstruction 衡量 voxel accuracy 與 morphology/topology fidelity。

作者指出，在 ZBFWB 上，本方法相對 GBP-Net 的 F1 高 3.02 個百分點，相對 3D U-Net 提升 13.19 個百分點。CWMBS 的 agent ablation 中，完整系統達到 Weak Signal F1 90.07、Strong Noise F1 86.37（表 3 的 agent ablation 另報告 CWMBS F1 88.83，論文未進一步解釋兩者設定差異）。TopoRefineNet 的 single-stage real-defect training 相較 two-stage strategy，在 ZBFWB 與 CWMBS 的 F1 分別下降 1.17% 與 1.89%，且 Change Validator rejection rate 增加 23.57%。

## 對我們的啟發
- [ ] 對 agent-based vision system 而言，將錯誤診斷、修正規劃與結果驗證分工，較單一 agent 同時處理所有任務更有利於穩定 refinement；論文的 agent ablation 支持此設計。
- [ ] 自然語言 instruction 可作為高階 reasoning 與低階 voxel editing 之間的可稽核介面；實務部署時應保留每輪的錯誤類型、位置、指令與 validator 決策，以提升可解釋性。
- [ ] 全域視圖與局部視圖互補是處理稀疏長距離結構的關鍵；但 MIP 可能遺失深度資訊，因此在密集或遮蔽場景應加入 depth-aware representation，而不能只依賴 2D projection。

## 限制與未來工作

論文明確指出，Global Inspector 主要依賴 2D MIP；在神經元密集或彼此重疊的區域，MIP 會遺失 z-axis depth information，導致 3D 錯誤定位不精確。未來工作將加入 depth-aware encoding，例如以 pseudo-color 表示深度或使用 depth-weighted projections。論文未報告完整的推論成本、agent latency、人工升級比例及跨資料集外部泛化結果。
