# Memory Augmentation Unlocks Efficient Chain-of-Thought Reasoning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.21265)
- 📥 [PDF](https://arxiv.org/pdf/2608.21265v1)

## 摘要（中文翻譯）

大型語言模型常依賴 Chain-of-Thought（CoT）推理處理複雜任務，但冗長推理軌跡會造成顯著的推論開銷。CoT compression 能縮短生成長度，然而過度壓縮可能破壞邏輯連貫性並降低效能。本文提出 Context-Generation Substitution Law，形式化說明明確推理上下文可替代部分解碼階段生成。基於此，作者提出免訓練的 Memory-Augmented Compression，從歷史推理軌跡建構可重用的 reasoning memories，並在 prefill 階段檢索與注入，作為壓縮推理的支架。這些 memory 不使用原始 demonstrations，而是摘要可重用的推理模式、關鍵約束與重要操作，以補償壓縮造成的資訊損失。實驗顯示，Memory 能提升 Chain-of-Draft（CoD）在 GSM8K、MATH、BBH 與 MMLU-Sci 上的準確率，並相較標準 CoT 實現 1.14–1.49 倍 latency speedup；同時也能與 token-level、reasoning-trace-level 及 inference-state compression 方法結合。分析指出，增益來自相關推理 memory，而非單純增加上下文長度。

## 問題背景

標準 CoT 透過逐 token 生成中間推理提升複雜任務表現，但長推理帶來解碼延遲、token 成本與服務負擔。現有 compression 方法主要從生成端刪除、跳過或壓縮推理資訊；壓縮過強時，可能遺失子目標、關鍵約束與邏輯依賴，導致 accuracy collapse。因此問題是：如何在不恢復冗長 autoregressive decoding 的前提下，保留短推理所需的支援資訊。

## 解決方案

作者提出 training-free 的 Memory-Augmented Compression（MAC）框架，將部分原本需在 decode 階段逐步生成的推理支援，轉移至 prefill 階段。框架離線從驗證過的歷史解題軌跡建立 memory bank，將每筆資料轉換為包含問題類型、關鍵約束、子目標、解法策略與 critical operations 的 abstract reasoning memory；線上則依 reasoning tags 與 semantic similarity 檢索 top-k memory，序列化後與 system prompt、目前問題串接，再搭配 CoD 或其他 compression method 產生短推理與答案。核心創新是把相關的可重用推理結構，而非原始 few-shot 或完整 CoT，作為 prefill-side scaffold，以較低的平行化處理成本補償生成端遺失的資訊。

## 核心貢獻
1. 提出 Context-Generation Substitution Law，以 prefill-side reasoning context、decode-side CoT 長度與效能損失描述上下文和生成之間的替代關係，並給出新增 memory 成本低於解碼節省時可獲得效率收益的條件。
2. 提出免訓練的 Memory-Augmented Compression，從歷史驗證推理軌跡建立 abstract reasoning memories，透過 reasoning-tag 與 semantic retrieval 注入壓縮推理上下文。
3. 在多個數學、複雜推理與科學問答資料集，以及 CoD、TokenSkip、RPC、Extra-CoT 等壓縮設定中驗證 plug-in 效果，並透過 memory representation、retrieval strategy、memory size 與 compression ratio 分析其作用與邊界。

## 技術方法

MAC 採 offline–online 兩階段流程，且不更新 backbone 參數。離線階段輸入歷史 solved examples，保留正確、完整且可解析的 reasoning trace，依 Long-CoT、Short-CoT 或 Summary 格式建立 memory content，產生 reasoning tags 與其 embedding，形成 memory bank。線上階段先對 query 產生 tags 並建立 embedding，再從 memory bank 檢索 top-k 相關項目，依分數排序後序列化，與 system instruction 和 query 組成 memory-augmented prefill context，最後交由指定的 compression algorithm 生成 compressed reasoning 與 final answer。作者以 Context-Generation Substitution Law 建模成本：總目標包含 decode 長度、memory context 長度及 compression performance penalty；延遲近似為 prefill tokens 乘以 τpre 加上 decode tokens 乘以 τdec，當新增 memory 的 prefill 成本低於所節省的 decode 成本時即可獲得效率收益。實驗使用 LLaMA-3.1-8B、Qwen2.5-7B，另測試 API-based reasoning models，資料集包括 GSM8K、MATH、BBH、MMLU-Sci 與 AIME 2024。比較標準 CoT、CoD，以及 TokenSkip、RPC、Extra-CoT 等壓縮方法；指標包括 accuracy、prefill tokens、decode tokens、total tokens、model latency，部分實驗另計 query processing、retrieval 與 end-to-end latency。

## 對我們的啟發
- [ ] 若部署環境中 autoregressive decode 明顯慢於 prefill，可將可重用的推理結構移至輸入上下文；論文在 batch size 1 與 8 都觀察到 decode token 成本高於 prefill token 的不對稱性，但實際收益仍需量測自身服務系統。
- [ ] memory 不宜無限制增加：論文顯示 k 增大會提高 prefill 成本，accuracy 先升後可能下降；因此實務上應以相關性、成本與任務難度共同選擇 top-k，而不是單純堆疊更多內容。
- [ ] memory representation 的抽象程度很重要。論文在 AIME 2024 的消融中，Summary memory 達 61.67%，高於無 memory 的 55.00%，而 few-shot、Short-CoT 與 Long-CoT memory 分別為 46.67%、46.67% 與 43.33%；這支持優先保存問題結構、約束與關鍵操作，而非直接複製長示範。

## 限制與未來工作

論文指出，API-based models 缺乏一致介面，無法直接比較內部 prefill/decode latency；MAC 另有 query-tag generation、embedding、retrieval 與 memory prefilling 成本，短推理任務的優勢可能縮小。方法也依賴 memory bank 與 retrieval 品質，無關或含噪 memory 可能造成干擾；目前主要使用驗證過的歷史例子，對噪聲 memory 的 robustness 尚未充分評估。
