# Bilevel Coordinated Reflection: A Game-Theoretic Approach to Multi-Agent LLM Systems

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.02750)
- 📥 [PDF](https://arxiv.org/pdf/2609.02750v1)

## 摘要（中文翻譯）

多智能體 LLM 系統通常由 orchestrator 將任務分解，交由多個 worker 協作，並透過文字 reflection 改進。然而，現有系統缺乏對 coordination、memory improvement 與 external verification 的統一解釋。本文將 orchestrator–worker 互動建模為 bilevel coordination game：在 bounded coupling 下，worker 的 local-update game 是 approximate potential game，其 equilibrium slack 受 decomposition quality 控制。作者進一步把 reflection 視為 semantic memory states 上的隨機移動，推導 free-form reflection 的有限時間上界、證明最壞情況緊性，並在可反駁的 persistent-harm 條件下給出正的誤差下界。本文也證明僅觀察 transcript 的 gate 無法在文字不可區分環境中一致改善結果，而 environment-grounded gate 可以。基於此提出 Stochastic Reflective Memory Ascent（SRMA），只有在 grounded evaluation risk 嚴格下降時才接受候選 memory；在 calibration 與 corrective mass 條件下，SRMA 以幾何或多項式速率精確收斂，並提供 confidence gating 與 piecewise-stationary environment 的 re-anchoring 保證。

## 問題背景

現有 multi-agent LLM 系統多以程序性方式描述 orchestrator、worker、共享記憶與反思流程，卻缺乏統一的協調與收斂分析。論文聚焦三個問題：decomposition quality 如何影響 worker coordination；unconditional reflection 何時因有害內容而產生誤差下限；以及為何僅依賴文字的 critic 可能無法取代 external verifier。

## 解決方案

作者提出 bilevel coordinated reflection framework：orchestrator 作為較慢時間尺度的 leader，負責任務分解與 strategy memory；workers 作為較快時間尺度的 followers，透過 execution memory 與 ηc-better responses 協作。在 bounded coupling 下，worker 子博弈具有以 global utility 為 potential 的 approximate potential 結構。對 reflection，作者區分 free-form、text-only gating 與 verifier-gated 更新，並提出 SRMA：使用固定 evaluation protocol 和 grounded verifier 比較目前及候選 memory 的 risk，只有 risk 嚴格下降才提交。此設計將資訊可得性、記憶單調改善、隨機評估信心控制及環境變動後重新錨定整合於同一框架。

## 核心貢獻
1. 建立 bilevel coordination game，證明 bounded coupling 下 worker follower subgame 是 approximate potential game，且 equilibrium slack ηc≤2dmaxκ，將 decomposition quality 與協調誤差連結。
2. 對 free-form reflection 建立 finite-time drift upper bound、worst-case tightness 與 persistent harmful commitment 下的 universal lower bound，刻畫 unconditional memory update 的誤差 floor。
3. 提出 text-indistinguishable environments 下的 self-gating impossibility theorem，並提出 verifier-grounded 的 SRMA；證明其在 calibration 與 corrective-mass 條件下以 order-tight 的 geometric 或 polynomial rate 收斂，另提供 confidence gating 與 re-anchoring 保證。

## 技術方法

理論上，任務由 orchestrator 分解為 τ=(τ1,…,τN)，worker 產生局部解 xi，global utility 由局部 utility 與 interaction terms ψij 組成。假設 worker action set 有限，且 coupling magnitude 以 κ、有耦合鄰居最大數以 dmax 表示，作者證明 follower game 是 approximate potential game，slack ηc≤2dmaxκ；反覆執行 ηc-better responses 可有限步到達 ηc-approximate Nash equilibrium。記憶分析將 execution memory 與 strategy memory 視為離散 semantic states，使用 sub-optimality V 的 conditional drift 分析 free-form reflection：上界由 corrective drift γ 與 residual error load ν 決定，並給出 worst-case tightness 及 persistent harmful commitment 下界。資訊理論部分構造兩個 text-indistinguishable environments，使同一 reflection 在不同環境中分別有益或有害，證明 self-contained gate 無法一致改善。SRMA 以固定 deterministic evaluation protocol gi、grounded verifier V 及 risk R 作為準則；候選 memory 僅在 R 嚴格下降時接受。假設 acceptance probability 至少為 c1Rβ、接受後期望 risk decrement 至少為 c2R，得到 β=0 時 geometric、β>0 時 polynomial convergence。隨機評估則以 Hoeffding confidence interval gating。實驗使用 Resource Contest、具 exact BFS verifier 的 Overcooked，以及以 repository test harness 驗證的 500 個 SWE-bench instances，指標包括 reward、regret、delivery score、verifier risk、harmful/helpful acceptance rate、切換時間與 resolved rate。

## 對我們的啟發
- [ ] 若反思內容的正確性取決於隱藏環境狀態、執行結果或 repository 測試，實務上應優先導入 environment-grounded verifier，而非只增加 text-only critic 的模型能力。
- [ ] 共享 memory 不應無條件累積；可採用固定評估流程比較目前與候選記憶的 risk，僅提交嚴格改善的候選，以降低有害反思造成的漂移。
- [ ] 多智能體分解應同時考量局部效用與 worker 間 coupling；降低互相依賴的介面與共享約束，可能比單純增加 worker 數量更有助於協調。

## 限制與未來工作

保證依賴 bounded coupling、有限 action sets、verifier calibration 與 non-degenerate corrective mass，未必適用於開放式 agent 任務。實驗中的 drift 參數只在觀測軌跡上驗證；不完整測試套件只能保證 verifier risk 單調下降，不能保證真實任務效用。re-anchoring 也未提供一般 switching-regret bound；SWE-bench 的 72.2% 僅與 public reference 比較，且多智能體流程有額外 token 成本。
