    Cross-Lingual Stability of LLM Judges Under Controlled Generation: Evidence from Finno-Ugric Languages

    摘要（中文翻譯）

    跨語言 LLM 評估通常混淆兩種變異來源：真實的模型性能差異與測量不穩定性。本研究透過控制生成條件（保持參數一致）並改變目標語言來探討評估可靠性。研究使用參數化模板在愛沙尼亞語、芬蘭語和匈牙利語中生成合成客服對話（每語言 10K 筆），測試自動指標和 LLM-as-a-judge 評分是否能在這些型態豐富的芬蘭-烏戈爾語系語言間產生穩定的模型排名。核心發現是系統性的排名不穩定性：表面指標（詞彙多樣性、表面相似度和語義相似度）保持跨語言穩定，但語用判斷（連貫性、指令遵循）出現排名反轉和近零相關，表明零樣本評判轉移在型態豐富語言的篇章級評估中不可靠。

    問題背景

    在低資源、型態豐富的語言中評估 LLM 面臨一個矛盾：最需要可靠評估的地方，人工監督最少。現有的多語言基準大多沿襲高資源語言的評估慣例，聚焦於單輪任務，並假設自動或模型評分的有效性。但在對話場景中，評判者的跨語言行為是否穩定仍不清楚。先前研究發現跨語言 LLM 評判一致性極低（Fleiss' kappa 約 0.3），但不穩定性的來源未被充分理解。

    解決方案

    提出「受控生成診斷測試」方法論：使用參數化模板在多種語言間生成語義等價的合成對話，保持生成參數完全一致，僅改變語言。這種設計將評估行為與內容變異隔離開來——若表面屬性可比但評判排名分歧，則不穩定性源於評估過程而非內容差異。兩階段驗證：先用表面指標確認生成一致性，再測試 LLM-as-a-judge 的語用評分是否維持跨語言排名穩定性。

    核心貢獻

    1. 證明 LLM-as-a-judge 的連貫性評估在型態豐富語言間出現系統性排名反轉（tau 約 0），而表面指標維持穩定（tau >= 0.76）
    2. 提出跨語言評估穩定性的診斷方法論，透過受控生成和消融驗證來檢測部署前的排名不穩定性
    3. 釋出受控生成協議、合成資料和評估框架，供其他語系複製研究

    技術方法

    對話生成：使用參數化提示模板生成合成客服對話，涵蓋 40+ 產業、20+ 問題類型、多種溝通管道和代理類型。所有語言使用相同的參數分佈和生成模型（gpt-4.1-mini、Llama-3.3-70B、Mixtral-8x7B、Command-R、Llama-3.1-8B、Claude Sonnet 4），每語言生成 10K 筆對話。英語作為高資源基準對照。

    人工標註：三位愛沙尼亞語母語者獨立標註 100 筆對話的連貫性和流暢度，評判者間一致性為中等（kappa = 0.385 連貫性、0.321 流暢度），為自動評估設定期望上界。

    評估框架：使用 GPT-5-mini 作為零樣本評判者，評估文法（G）、可讀性（R）、連貫性（C）、流暢度（F）和標籤恢復準確度（LRA）五個維度。G/R/F 歸類為表面指標，C 和 LRA 為語用指標。透過 Kendall tau 相關和排名反轉次數量化跨語言排名穩定性。

    消融研究：比較六種評判模型（GPT-5-mini、GPT-5.1、GPT-5.1-high、Qwen3-32B、Llama-4-Maverick、GPT-OSS-120B）在芬蘭語上的表現，確認不穩定性非特定評判者所致。另進行元提示語言敏感度測試，使用愛沙尼亞語翻譯的元提示，確認差異小於 0.05。

    關鍵結果

    指標類型 指標 芬蘭-烏戈爾語對 tau 英語對 tau 排名反轉
    表面 文法 (G) 0.84-0.96 0.55-0.93 0-1
    表面 可讀性 (R) 0.95-1.00 0.72-0.76 0-2
    表面 流暢度 (F) 0.70-0.88 0.51-0.74 1-3
    語用 連貫性 (C) -0.38 至 0.28 -0.14 至 0.56 4-5
    語用 LRA -0.17 至 0.10 0.06-0.82 6-9*

    核心發現：表面指標（G、R、F）維持高跨語言穩定性（tau >= 0.62），排名反轉極少。但連貫性出現系統性崩潰：芬蘭-烏戈爾語對間近零或負相關，顯著排名反轉（p < 0.05）。LRA 在所有芬蘭-烏戈爾語對間展現顯著反轉。英語連貫性分數呈天花板效應（均值約 2.98-3.00），限制有意義的排名比較。

    對我們的啟發

    • LLM 評判者的表面評估（文法、可讀性）可跨語言信任，但篇章連貫性評估不能零樣本遷移，需語言特定校準
    • 受控生成是部署前的有效「驗證閘門」：若在控制條件下排名不穩定，在自然資料上表現只會更差
    • 建議分階段工作流程：(1) 自動指標驗證生成一致性、(2) 小規模專家標註、(3) 評判者-人類排名對齊測試、(4) 弱相關則校準
    • 評判模型選擇對結果影響極小（Delta < 0.02），暗示不穩定性是任務本質問題而非模型能力問題

    限制與未來工作

    合成對話可能展現真實資料中不存在的風格同質性。人類校準僅限於愛沙尼亞語（N=100），未擴展至芬蘭語和匈牙利語。研究聚焦於篇章連貫性，未探索禮貌慣例或語言特定文法模式等面向。發現可能不適用於非商業模型、其他對話領域或型態距離更遠的語言。表面指標的穩定性暗示生成品質可比，但無法完全排除表面指標未捕捉的篇章級品質差異。
