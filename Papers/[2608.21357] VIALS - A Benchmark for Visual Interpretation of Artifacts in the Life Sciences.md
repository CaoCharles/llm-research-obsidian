# VIALS: A Benchmark for Visual Interpretation of Artifacts in the Life Sciences

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.21357)
- 📥 [PDF](https://arxiv.org/pdf/2608.21357v1)

## 摘要（中文翻譯）

在專業生命科學工作流程中，科學家經常解讀 visual artifacts，例如 gel blots、microscopy images、plasmid maps、flow cytometry plots 與 molecular structures，並據此作出研究決策。本文提出 VIALS，一個包含 161 項 interpretation tasks 的 visual question-answering benchmark，涵蓋 biotech industry 實驗流程中實際檢視的 artifact 類型，而非出版品或教科書中的精美圖表。研究發現，雖然 frontier vision-language models 已能流暢描述自然影像，卻無法準確解讀這些科學圖像，反映其 domain knowledge 與 domain-specific visual reasoning 能力仍有限。相較之下，具相關專業背景的科學家認為多數任務相當直接。若 AI 無法可靠解讀這類圖像，便難以在以 visual artifacts 為核心的專業生命科學研究、溝通與決策流程中發揮實際效用。

## 問題背景

論文要回答的是：VLM 能否準確解讀專業生命科學工作中常見的 visual artifacts，並擷取其中支援研究決策的證據。既有 benchmark 多以教科書、考試、論文圖表或單一 biomedical modality 為主，未充分涵蓋 biotech/pharma 實驗流程中的 messy artifacts。僅能流暢描述圖像也不足以保證模型能正確定位、讀值、比較空間關係並套用科學概念。

## 解決方案

作者提出 VIALS benchmark，以 161 個 open-domain VQA 任務評估模型對專業生命科學 artifacts 的實際解讀能力。每項任務包含一或多張科學圖像、問題與短篇 ground-truth answer，問題要求模型同時擷取 visual evidence 並進行具科學意義的解釋。資料由具相關工作經驗的 PhD-level scientists 建構、獨立作答與多階段審查；評分採 semantic grading，而非 exact match。除 direct VLM 評估外，作者另測試具 code execution、crop、zoom、image transformation 與 measurement 能力的 tool-assisted agents，以區分直接視覺感知不足與後續科學解釋不足。

## 核心貢獻
1. 提出 VIALS，將評測焦點從學術或教科書式 scientific VQA 擴展到 biotech/pharma 實驗流程中的專業 visual artifacts，涵蓋八類生命科學圖像與 161 個具工作情境的任務。
2. 建立由 31 名具領域與產業經驗專家共同建構、獨立作答及多階段審查的品質控制流程，並以專家調查驗證任務的 professional relevance。
3. 系統分析 frontier VLM 的失敗來源，並透過 tool-assisted agent 實驗揭示 perception gap 與 residual interpretation gap：工具可大幅改善表現，但仍伴隨高昂 token 成本及未解決的科學表示法理解問題。

## 技術方法

VIALS 涵蓋 phylogenetics、flow cytometry、blotting、cell counting/quantification、plasmid maps、protein structure、molecular structure 及其他 artifact，共 161 題；各主要 domain 約占 12.4%–14.3%。資料來源包括未發表的真實實驗資料、以科學軟體 procedural generation 產生的 artifacts，以及 CC-BY open-access publications；資料特別強調專業工作中常見的 messy data。31 名具生命科學專業的 contributors 建構與審查任務，87% 具 doctoral-level training，74% 有超過六年產業研究經驗。每題由專家撰寫問題與答案，第二、第三位專家盲答並提供 justification，另有專家確認圖像真實性、問題可回答性及答案正確性；僅保留達成共識的任務。模型只接收圖像與問題，每題進行三次 rollout，temperature 為 1.0，結果以 Pass@1 平均 accuracy 報告，並補充 Pass@3 與 Pass^3。短答案由 GPT-5-mini 進行 LLM-as-a-judge semantic grading，對 4,685 個 model responses 與人類專家判定的 agreement 為 99.9%。失敗分析以七類錯誤分類，包括 visual quantification、feature selection、overlooked evidence、representation misinterpretation、quantitative reasoning、misapplied principle 與 fabricated finding。工具代理則在禁止網路的 Linux sandbox 中使用 Python、OCR、影像處理與數值工具反覆檢查圖像。

## 關鍵結果

主要結果如下：

| 評估項目 | 結果 |
|---|---:|
| 最佳 direct VLM：GPT-5.6 Sol | 26.5% accuracy |
| 最佳 direct VLM：Gemini 3.7 Flash | 26.5% accuracy |
| GPT-5.6 Sol Pass^3 | 12.4% |
| Gemini 3.7 Flash Pass^3 | 16.8% |
| 最佳 domain accuracy：GPT-5.6 Sol／phylogenetics | 43.5% |
| 最佳 domain accuracy：Muse Spark 1.2／plasmid maps | 38.1% |
| 最佳 domain accuracy：Muse Spark 1.2／protein structure | 33.3% |
| 最佳 domain accuracy：Kimi K3、Grok 4.6／flow cytometry | 33.3% |
| 主要錯誤比例（前四類合計） | 各模型 83%–93% |
| 最常見錯誤：visual quantification | 各模型 28.2%–41.8% |
| 最佳工具代理：Claude Opus 5 + OpenCode | 65.8% |
| GPT-5.6 Sol + Codex 相對 direct | 26.5% → 49.1%（+22.6 個百分點） |
| Gemini 3.7 Flash + OpenCode 相對 direct | 26.5% → 60.7%（+34.2 個百分點） |
| Kimi K3 + OpenCode 相對 direct | 20.9% → 64.2%（+43.3 個百分點） |
| 工具代理 token 使用量增幅 | 10–432 倍 |

專家調查顯示，VIALS 圖像被判定為 professional work 的比例為 63%，HLE 對照組為 22%；每週或每日遇到的比例為 33% 對 14%；具 commercial/economic value 的比例為 81% 對 66%。

## 對我們的啟發
- [ ] 若要將 VLM 用於生命科學決策，不能只看自然影像描述或整體語言流暢度，應加入對讀值、計數、gate、lane、結構接觸與空間關係的任務級驗證。
- [ ] 影像 crop、zoom、量測與程式化分析能顯著補救直接視覺推理錯誤，因此實務系統可設計可追溯的工具使用流程；但需同時評估 10–432 倍 token 增幅與成本效益。
- [ ] VIALS 的 Pass^3 與 Pass@3 差距顯示一次答對不等於可靠。高風險工作應測試重複執行的一致性，並將模型不確定性、人工複核與專家審批納入部署標準。

## 限制與未來工作

資料集僅有 161 題，不能涵蓋生命科學全部 visual artifacts 與解讀活動；任務主要是相關 PhD 科學家可快速完成的相對直接情境，未涵蓋高度歧義與實驗噪聲下的複雜判斷。研究也未評估出版品、教科書圖表解讀，或解讀後如何調整研究計畫。作者表示將建立數百項私有新增任務，以支援後續 benchmark refresh 並降低 overfitting。
