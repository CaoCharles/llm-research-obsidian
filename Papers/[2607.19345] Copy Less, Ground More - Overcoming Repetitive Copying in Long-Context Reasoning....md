# Copy Less, Ground More: Overcoming Repetitive Copying in Long-Context Reasoning via Evidence-Aware Reinforcement Learning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.19345)
- 📥 [PDF](https://arxiv.org/pdf/2607.19345v1)

## 摘要（中文翻譯）

具備逐步推理能力的大型語言模型在複雜任務上表現強勁，而延伸至長上下文推理已成為重要方向。然而，本文發現一項關鍵失效模式：repetitive copying，即模型在 reasoning trace 中大量複製輸入文字，而非有效解題。此現象普遍存在於七個 frontier long-context LLM，且會隨上下文長度增加。研究將 prompt 分為任務相關的 key evidence 與無關的 distractor context，指出根因是 insufficient grounding：模型未能區分重要證據與干擾內容。作者提出 GEAR（Grounding Evidence-Aware Reward），以 key evidence 重疊提供 grounding reward，並對 distractor 重疊施加 penalty。透過自動化流程建立 evidence-annotated 資料，GEAR 在多個模型與 benchmark 上相較 accuracy-only RL 平均提升最高 4.6 分，同時降低複製行為與 thinking length。結果顯示，精確 grounding 仍是長上下文推理不可或缺的能力。

## 問題背景

長上下文 thinking LLM 常把輸入中的大段文字直接複製進 reasoning trace，形成 repetitive copying；上下文越長，問題越嚴重，並可能耗盡 token budget、降低準確率。既有 accuracy-only RL 只看最終答案，缺乏對「模型引用了哪些證據」的密集訊號，無法區分有用的 evidence grounding 與對 distractor context 的無差別抄錄。

## 解決方案

作者提出 GEAR（Grounding Evidence-Aware Reward），在標準答案正確性 reward 外加入兩個互補訊號：對 reasoning trace 與 key evidence 的 n-gram overlap 給予 grounding reward，對與 distractor context 的 overlap 施加 penalty。前者鼓勵模型接觸解題所需資訊，後者防止模型為提高證據重疊而複製整個 prompt。作者另提出 evidence-annotated data construction pipeline，透過合成 benchmark 的 support indices，以及從文件先抽 evidence、再生成問題並驗證答案的一致性，讓方法可用於自然語言資料。

## 核心貢獻
1. 辨識並量化 long-context reasoning 中的 repetitive copying，證明其在七個 thinking LLM 中普遍存在、隨 context length 增加，且與較低準確率及較長 reasoning trace 相關。
2. 提出 GEAR reward shaping，將 accuracy reward、key evidence grounding reward 與 distractor penalty 結合，直接鼓勵選擇性證據使用。
3. 提出從結構化 synthetic data 與 RedPajama-v2 文件自動建立 evidence-annotated QA 的三階段流程，並在三種 Qwen3.5 模型及五個 held-out benchmark 驗證方法。

## 技術方法

論文先以 GSM-Infinite 研究 repetitive copying。對 reasoning trace y 與 prompt x，建立 prompt 的 n-gram lookup set，計算輸出各滑動視窗是否直接出現在輸入中，得到 overlap rate；n=3 用於衡量整體複製量，n=10 用於辨識較長的連續抄錄。利用 GSM-Infinite 已知的 support indices，將輸入拆成 key evidence 與 distractor context，分別計算 10-gram overlap，並以 key overlap 除以 distractor overlap 定義 grounding ratio。訓練時採用三種 Qwen3.5 模型（9B、27B、35B-A3B）與 GSPO，最大 prompt 32k、最大 generation 16k，訓練資料 context length 為 16k–32k。GEAR reward 為 R=Racc+αOverlap_n(y|xkey)−βOverlap_n(y|xdist)，其中 Racc 是二元答案正確性 reward，α=0.1、β=0.3，n=3；同時出現在 key 與 distractor 的 n-gram 不納入 distractor penalty。資料包含 GSM-Infinite 1,000 筆、PhantomWiki 1,000 筆及由 RedPajama-v2 產生的自然語言 QA 1,200 筆。自然語言流程先分析文件並篩選，再切成每段 1,024 characters，抽取 1–3 段作為 evidence，生成可由該區域回答的問題、答案與引文，最後以獨立 re-answer verification 保留一致樣本。評估使用 Ruler、LongBench-v2、BrowseComp-LC、GraphWalks 與 AA-LCR，比較 pretrained base、accuracy-only GSPO、僅 grounding reward，以及完整 GEAR，並測量 benchmark score、input overlap 與 thinking length。

## 關鍵結果

主要結果如下；分數為論文報告的 benchmark 平均或單項結果，↑表示較高較佳，↓表示較低較佳。

| 模型／上下文 | 方法 | 32k Avg | 128k Avg |
|---|---|---:|---:|
| Qwen3.5-9B | GSPO | 78.5 | 70.2 |
| Qwen3.5-9B | GSPO + GEAR | **81.3** | **74.8** |
| Qwen3.5-35B-A3B | GSPO | 80.2 | 73.4 |
| Qwen3.5-35B-A3B | GSPO + GEAR | **82.3** | **76.2** |
| Qwen3.5-27B | GSPO | 80.6 | 75.3 |
| Qwen3.5-27B | GSPO + GEAR | **82.1** | **77.4** |

相較 accuracy-only GSPO，GEAR 的平均提升在 32k 為 +2.8、+2.1、+1.5 分，在 128k 為 +4.6、+2.8、+2.1 分（依序對應 9B、35B-A3B、27B）。Qwen3.5-35B-A3B、32k：Ruler 的 overlap rate 由 GSPO 的 35.7% 降至 GEAR 的 27.0%，thinking length 由 2,808 降至 2,066 tokens；LongBench-v2 overlap 由 27.2% 降至 22.6%，thinking length 由 4,677 降至 3,989 tokens。GEAR 訓練為 α=0.1、β=0.3、n=3；論文報告單獨加入 grounding reward 會降低性能，最高下降 8.3 分（128k），顯示 distractor penalty 不可缺少。

## 對我們的啟發
- [ ] 實務上不應只將「引用輸入內容」視為有害；評估應區分模型是否引用 task-relevant evidence，並同時衡量對 distractor context 的不必要複製。
- [ ] 若以 reward 鼓勵證據重疊，必須搭配對無關內容的抑制項；論文顯示單獨加入 grounding reward 反而會增加 copying 與 thinking length，造成性能下降。
- [ ] 長上下文訓練可採用 n-gram overlap、支持片段標註與答案正確性等可計算訊號，塑造更精簡且 grounded 的 reasoning；但部署前仍應在不同任務與上下文長度上檢查是否誤抑制必要證據。

## 限制與未來工作

論文主要以 Qwen3.5 三種模型、3,200 筆訓練樣本及五個 benchmark 驗證，外部模型是否同樣能受益仍未完整測試。自然語言 evidence 由模型生成並以 constrained context 驗證，可能帶有資料生成偏差。GEAR 依賴支持片段標註與 n-gram overlap，對證據需改寫、跨段整合或語意推理的任務，其有效性尚未充分報告；論文也未提供更廣泛的統計顯著性分析。
