# MultiPathFormer: Towards a Foundation Model for Multipath Wireless Propagation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.05076)
- 📥 [PDF](https://arxiv.org/pdf/2608.05076v1)

## 摘要（中文翻譯）

近年 machine learning 的進展促成 wireless foundation models 的訓練，用於根據 wireless signals 執行 channel estimation、beam prediction 與 localization 等任務。現有模型通常在 channel tensors 上，以跨 subcarriers、antennas 或 time 的 masked reconstruction 進行預訓練，卻忽略 wireless propagation 的物理特性。本研究改以 multipath propagation 作為基本預訓練對象，提出 MultiPathFormer：將每個 transmitter–receiver link 表示為由連續值 path tokens 組成的有序序列，並以 next-path prediction 進行 autoregressive 預訓練。作者在 transformer backbone 上加入 Environmental RAG 與 first-path codebook，利用環境知識改善 delay、power 等 path statistics estimation，最高提升 59%。模型在 27 個環境上預訓練後，可轉移至未見使用者；在新環境進行 scenario-specific fine-tuning 後，也優於從頭訓練。於多項 downstream tasks 中，模型取得 5.57 m 平均定位誤差、0.914 top-3 beam accuracy、0.994 LoS classification accuracy 與 0.561 channel estimation NMSE。

## 問題背景

現有 wireless foundation models 多以 channel tensor 做 masked channel modelling，對 subcarrier、antenna 或 time 位置進行重建。依論文主張，channel 是多條 propagation paths 的疊加，並與 array responses、subcarrier sampling 及 system configuration 交織，因此會掩蓋 path 的數量、dominant-path structure、delay、power、角度與 interaction type 等物理結構，降低可解釋性與跨任務重用能力。論文要解決的是如何直接對可變長度、連續值且沒有天然順序的 multipath 進行 foundation pretraining。

## 解決方案

MultiPathFormer 將每個 transmitter–receiver link 表示成依 power 排序的 path-token sequence，採 autoregressive next-path prediction 學習 propagation process。它以 encoder–decoder transformer 將 tx、rx 與環境資訊編碼，decoder 根據既有 paths 逐步預測下一條 path，另以 path-length head 預測序列長度。核心創新包括兩個物理導向模組：Environmental RAG 依 link 擷取端點附近、傳播 corridor 與多尺度場景摘要；first-path KMeans codebook 則提供 dominant path 的 power/delay 粗先驗，模型只學習第一條 path 的 residual。作者進一步將生成出的 path representations 用於 beam prediction、localization、LoS classification 與 channel estimation。

## 核心貢獻
1. 提出以 multipath sequence 而非 channel tensor 作為 wireless foundation model 預訓練對象，將 propagation 建模為連續值、可變長度 path tokens 的 autoregressive next-path prediction。
2. 提出 Environmental RAG，針對 transmitter–receiver link 擷取 local、corridor 與 multiscale scene geometry；在 31 個 DeepMIMO scenarios 中，相較 direct baseline 將 delay MAE 降低 38.7%、power MAE 降低 59.2%。
3. 提出以每一 transmitter 為單位、在 first-path power 與 delay 上進行 KMeans 的 dominant-path codebook，並結合 residual prediction，以穩定最強路徑生成；模型可轉移至未見使用者與新環境，並支援 beam prediction、localization、LoS classification 與 channel estimation。

## 技術方法

資料來自 DeepMIMO，涵蓋 31 個 environment scenarios；模型在其中 27 個 scenarios 的 80% users 上預訓練，並以同一批環境的 20% held-out users 與 4 個 unseen scenarios 測試。每個 tx–rx link 被轉換成依 path power 遞減排序的可變長度序列；每個 path token 包含 power、delay、phase、AoA/AoD 的方位角與仰角，以及 Reflection、Diffraction、Scattering、LoS 四種 interaction type 的 multi-hot 標籤。模型採 encoder–decoder transformer：encoder 輸入 environment、tx 與 rx 資訊，並輔助預測 path length；decoder 以 start token 和已生成 paths autoregressively 預測下一個 path。輸出分為連續參數 regression 與 interaction classification，總 loss 為 path L2、path-length squared loss 與 interaction cross-entropy 的加權和；訓練期間對 20% path tokens 加噪，以增強模型對生成誤差的恢復能力。Environmental RAG 擷取 tx/rx 附近及 tx–rx corridor 的 top-K objects，並加入多尺度物件數量、最大高度與 corridor bins 摘要。First-path codebook 則對每個 transmitter 的 first-path power/delay 做 KMeans，以鄰近訓練 receiver 指派 cluster prior，再預測 residual。評估涵蓋 delay、power、角度 MAE、interaction accuracy/F1、beam top-1/top-3 accuracy、localization mean/median/P90 error、LoS accuracy/F1 與 channel estimation NMSE；後者以預測 path 的 delay/angles 建立 channel basis，再用已觀測 subcarriers 做 ridge regression。

## 對我們的啟發
- [ ] 將資料表示對齊領域的物理生成過程，可能比直接對混合後的高維 tensor 做 masked reconstruction 更有利於學習可重用表徵；實務上可優先尋找具物理意義且跨硬體設定較穩定的預訓練單位。
- [ ] 對具有顯著 dominant component 的序列生成任務，可將粗粒度先驗與模型 residual correction 分離；本文的 first-path codebook 顯示，這種設計能減少 autoregressive 誤差逐步累積。
- [ ] Environmental RAG 不只是加入全域環境描述，而是依 link 擷取端點附近、傳播 corridor 及多尺度摘要；若部署時已有地圖或 3D scene knowledge，應設計 query-specific retrieval，而非直接輸入完整場景。

## 限制與未來工作

論文主要使用 DeepMIMO 的 ray-tracing simulation，作者明確指出下一步需驗證從 ray-tracing data 到真實量測場景是否仍能維持增益。未見對真實無線資料、不同硬體配置或更廣泛 domain shift 的實驗；此外，未見完整的資料生成成本、與更多 path-level 方法的比較，以及各 retrieval 超參數的系統性敏感度分析。
