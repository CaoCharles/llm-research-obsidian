# A Self-Evolving Multi-Agent Framework Defense against LLM Jailbreak Attacks

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.26008)
- 📥 [PDF](https://arxiv.org/pdf/2608.26008v1)

## 摘要（中文翻譯）

大型語言模型（LLM）仍容易受到 jailbreak attacks 影響；攻擊者可利用 role-playing、obfuscation、code transformation 與 multi-step indirection 等技巧誘導模型產生有害輸出。既有防禦多為 static mechanisms，部署後安全行為固定，無法累積防禦經驗或適應未見策略。本文提出以 persistent、跨互動 rule memory 為核心的 self-evolving test-time defense：當攻擊成功時，系統將失敗抽象為描述結構性 attack wrapper 的 method-level rule，而非記憶有害主題，並套用於後續輸入。單一規則可泛化至整個攻擊家族，且遇到新 wrapper 時可擴展 label space。方法僅透過 external memory 與 prompting 運作，不更新模型參數，適用於 open-weight 與 black-box API models。實驗顯示，它能降低四類 black-box jailbreak 的 attack success rate、維持 benign utility，抵抗 adaptive composite-wrapper attack，且 memory 增長不會增加 over-refusal。

## 問題背景

論文處理 LLM 在 sequential interactions 中持續遭遇新型 jailbreak 的防禦問題。static alignment、固定 system prompt、safety classifier 與部分 white-box decoding 方法，部署後不會根據失敗累積知識，對未見、obfuscated 或 compositional wrapper 泛化有限；既有 self-reflection 多只修改當前或短期 context，multi-agent 防禦也通常逐次獨立處理。因此系統難以把一次攻擊失敗轉化為跨互動可重用的防禦經驗。

## 解決方案

作者提出 self-evolving multi-agent framework，以 persistent external rule memory 取代參數更新。系統將成功 jailbreak 的結構性 wrapper 抽象成 method-level rule，包含攻擊 label、wrapper pattern 與 refusal constraint；後續輸入先被分類，再只觸發最相關規則，避免把全部記憶注入 prompt。Policy decision agent 依風險選擇 ALLOW、SOFT_REFUSE 或 HARD_REFUSE，response generation agent 依此產生輸出；violation detector 發現新失敗後，由 reflection agent 歸納新規則並去重、更新記憶。作者強調核心創新是跨互動的 selective persistent memory mechanism，而非四個 agent 的特定拆分。

## 核心貢獻
1. 提出 persistent、cross-interaction rule memory，將觀察到的 jailbreak failure 轉化為不需參數更新的 method-level 防禦規則。
2. 設計 dynamic rule-triggering 與自動擴展的 attack-label space，使規則依結構性 wrapper 選擇性套用，並泛化至同一攻擊家族。
3. 在四類 black-box jailbreak、多個 open-weight 與 API 模型上驗證降低 ASR、維持 benign utility，並以 ablation 顯示 triggering、enforcement 與 reflection 的互補必要性。

## 技術方法

問題設定中，固定參數模型 fθ 接收由 jailbreak transformation J 產生的 adversarial prompt；外部記憶 Rt 初始為空，並隨互動串流更新。每一步先由 attack-pattern classifier ϕ 將輸入標為 benign、既有 method-level label 或 other；benign 輸入不觸發規則，也不導致學習。接著進行 rule matching，先以 label 精確匹配，再用 LLM relevance fallback，最後用 lexical keyword overlap fallback，最多擷取 K=2 條規則。Policy operator 將結果映射為 ALLOW、SOFT_REFUSE 或 HARD_REFUSE，衝突優先序為 hard-refuse、soft-refuse、allow；generation agent 將動態 safety instruction 注入模型。輸出後，violation detector 由同一個 in-system model 以 1–10 harmfulness rubric 判定，分數達 τ=7 即視為違規；若輸入非 benign，reflection agent 以輸入與輸出歸納 method-level rule，update operator 進行 semantic deduplication，並設定每 label 容量 C=4。實驗採 AdvBench 520 個 harmful-behavior prompts，測試 DeepInception、CodeChameleon、ReNeLLM、FlipAttack，模型包括 Qwen2.5-7B、Llama3.1-8B 與 Gemini-3-Flash-Preview；採 cold-start online protocol，依固定順序串流，僅使用先前失敗學得的規則。指標包括 rejection-based ASR（ASR-rej）、外部 GPT-4o-mini judge 的 ASR（ASR-gpt，主要指標）、MMLU 與 GSM8K utility，以及 XSTest over-refusal。

## 對我們的啟發
- [ ] 實務部署可將防禦失敗事件結構化保存為攻擊方法規則，而非只保存原始惡意內容；這有助於跨主題重用並降低敏感資料記憶。
- [ ] 規則採 selective retrieval 而非全量注入，是控制 prompt 干擾與 benign utility 損失的重要設計；實作時應同步監控 classifier 誤判與 over-refusal。
- [ ] 自我演化防禦必須搭配獨立評估信號、去重與容量限制；本文使用 in-system judge 學習、外部 GPT-4o-mini 評估，但長期記憶的衝突管理仍需額外治理。

## 限制與未來工作

評估僅涵蓋四種 prompt-level black-box jailbreak 與一種 adaptive composite-wrapper attack，未涵蓋完整攻擊範圍、多輪或 agentic settings。系統尚無明確 rule pruning 與 conflict resolution，長期記憶的效率和一致性未解決。classifier 與 violation detector 均為 prompted LLM，可能產生判斷錯誤與 over-refusal；XSTest 顯示累積記憶後為 9.6%。
