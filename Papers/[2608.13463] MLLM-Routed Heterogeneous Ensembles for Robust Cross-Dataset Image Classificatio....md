# MLLM-Routed Heterogeneous Ensembles for Robust Cross-Dataset Image Classification

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.13463)
- 📥 [PDF](https://arxiv.org/pdf/2608.13463v1)

## 摘要（中文翻譯）

現代影像分類模型在單一任務資料集上表現優異，但通常難以跨域及跨越不同難度層級進行泛化。本文提出 ARMDIL（Adaptive Router for Multi-Domain Image classification with LLMs），一種使用 multimodal large language model（MLLM）代理動態路由影像至最適合 vision backbone 的 ensemble。異質 ensemble 包含 convolutional neural networks（ResNets）、self-supervised representation learners（SSL）及 vision-language models（VLMs）；各模型均在由多個分布與特性不同的影像資料集所建構之統一 label space 上訓練。實驗分析各架構於不同視覺領域的能力與弱點，顯示 ARMDIL 能有效處理其間的取捨，表現可與專門訓練的 router 競爭。此外，透過簡單修改 prompt 即可整合新資訊，並以自然語言 reasoning traces 提升可解釋性。此研究為 AI 助理與自主機器人等更可靠的一般用途視覺系統提供方向。

## 問題背景

單一影像分類模型通常在特定資料集內準確，遇到醫療、臉部、航空地理與自然影像等異質分布時卻難以泛化。傳統 dense ensemble 必須執行所有模型，成本高；訓練式 dynamic router 雖可選擇 expert，卻需要額外訓練、對新增領域僵化，且決策缺乏語意可解釋性。

## 解決方案

作者提出 ARMDIL，以 MLLM 作為 meta-classifier 與 domain router，先根據影像語意及低階品質統計判斷領域，再將影像送至相應的 ResNet、DINO 或 CLIP expert。核心創新是把異質架構放入共享 38 類 label space，並以 prompt 取代 routing-specific neural classifier，使新增領域或先驗知識可透過修改 prompt 與配置 expert 整合。模型亦可輸出自然語言 reasoning trace，提供比傳統路由器更直接的控制與可讀性。

## 核心貢獻
1. 提出 ARMDIL，使用 Gemma-4-12B MLLM 以零樣本 prompt-based inference 將影像分派至異質 vision experts。
2. 整合 ResNet、DINO SSL 與 CLIP VLM 分類器，並在涵蓋 CIFAR10、FER2013、EuroSAT 與 OrganAMNIST 的統一 38 類 label space 上進行跨資料集評估。
3. 實驗顯示 ARMDIL 的整體準確率高於 balanced DINOv3 與 majority-vote ensemble，且接近需要訓練的 NN-Router，同時提供 prompt 可調整性與自然語言路由說明。

## 技術方法

ARMDIL 將 CIFAR10、FER2013、EuroSAT 與 OrganAMNIST 合併為統一 N=38 類 label space，分別對應 GENERAL、FACIAL、GEOGRAPHIC 與 MEDICAL 四個領域。輸入影像先 resize 與 normalize，並計算 blur、mean brightness、contrast 及 noise 等 image-quality statistics。三類 experts 離線訓練：以 ImageNet 預訓練 ResNet-50 作為 CNN；以 DINOv2 ViT-L/14 與 DINOv3 ViT-L/16 作為 SSL backbone；以 OpenCLIP ViT-L/14 作為 VLM，凍結 CLIP 權重並在 visual transformer MLP layers 注入 LoRA，再接統一 label-space classification head。專家模型以 70% 目標領域、其餘領域各 10% 的 domain-skewed sampling 訓練，另建立 25% 均衡設定。推論時，量化的 Gemma-4-12B MLLM 同時接收影像與品質統計，依 system prompt 輸出 GENERAL、MEDICAL、GEOGRAPHIC、FACIAL 或 UNSURE；前四者路由至對應 domain expert，UNSURE 則交由整體 validation accuracy 最佳模型。評估使用 unified test set 的 overall accuracy、各資料集 top-1 accuracy、F1-score 與 per-dataset macro F1，並比較 balanced DINOv3、majority vote、訓練式 ResNet-18 NN-Router 及理論 oracle router。另以 self-consistency、移除 CoT、移除 image-quality statistics 進行消融。

## 關鍵結果

主要結果如下（數值為 top-1 accuracy；論文同時報告 macro F1）：

| 方法 | CIFAR10 | EuroSAT | FER2013 | O-MNIST | Overall |
|---|---:|---:|---:|---:|---:|
| ARMDIL | 99.02% | 97.91% | 70.49% | 96.69% | **90.78%** |
| Balanced DINOv3 | 99.05% | 97.24% | 69.82% | 92.52% | 89.61% |
| Majority Vote | 98.87% | 98.42% | 68.35% | 96.25% | 90.47% |
| NN-Router | 99.13% | 98.56% | 69.81% | 97.22% | 91.18% |
| Oracle Router | 99.24% | 98.56% | 70.49% | 97.20% | 91.04% |

ARMDIL 的 overall macro F1 為 90.71%，高於 balanced DINOv3 的 89.52% 與 majority vote 的 89.43%，但低於 NN-Router 的 90.41%（表格中的 overall accuracy 與 macro F1 依論文排版呈現）。MLLM domain routing 對 CIFAR10、FER2013、O-MNIST 的分布分別為 97.80%、99.82%、95.21% 正確，EuroSAT 為 78.20%，另有 12.72% 被分派至 UNSURE。消融中，self-consistency（無 CoT）使 EuroSAT 路由準確率由 78.20% 升至 82.17%；再移除 image-quality statistics 後為 83.87%，但對應 overall ARMDIL 分類準確率為 90.71% 與 90.75%，均低於原始 90.78%。

## 對我們的啟發
- [ ] 對跨域部署而言，先進行領域路由、再使用專門 expert，可能比讓單一 backbone 處理所有分布更有效；本文 ARMDIL 比 balanced DINOv3 高 1.17 個百分點。
- [ ] 路由器的 UNSURE 機制與 fallback expert 可降低錯誤路由的影響；本文中 EuroSAT 路由較弱，但整體下游分類仍維持競爭力。
- [ ] 影像品質統計不一定普遍有益：在本文消融實驗中，移除品質統計反而提升 EuroSAT 路由準確率，但整體 ARMDIL 下游結果仍略優於消融設定，因此應依領域驗證輔助訊號。

## 限制與未來工作

研究僅使用四個公開資料集，且資料集大小、解析度與類別設定相對受限，尚未在更大、更困難或真實部署資料上驗證。MLLM 對 EuroSAT 路由較不穩定；reasoning trace 雖具可讀性，論文未提供其 faithfulness 的正式評估。作者建議採用更大型 MLLM、改良 prompt 或進行 fine-tuning。
