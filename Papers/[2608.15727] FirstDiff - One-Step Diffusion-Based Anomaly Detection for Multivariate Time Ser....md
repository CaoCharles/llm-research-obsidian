# FirstDiff: One-Step Diffusion-Based Anomaly Detection for Multivariate Time Series via Initial Noise Prediction

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.15727)
- 📥 [PDF](https://arxiv.org/pdf/2608.15727v1)

## 摘要（中文翻譯）

Diffusion models 近來在多變量時間序列異常偵測中展現潛力，能透過反覆去噪學習正常資料分布。然而，既有方法通常必須完成整個 reverse diffusion process，主要依賴最終重建訊號，忽略去噪過程中產生的中間表徵，因而造成顯著計算成本。本文提出 FirstDiff，一個基於 diffusion 的異常偵測框架。其核心觀察是：在初始 reverse-diffusion evaluation 中預測的 diffusion noise，已包含足夠的異常辨識資訊。FirstDiff 使用正常 validation data 建模預測噪聲的統計分布，測試時只需執行一次 denoising network evaluation，即可進行異常推論，而不必完成整條 reverse diffusion trajectory。為捕捉複雜的時間與感測器間依賴，方法採用 Diffusion Transformer 作為 denoising backbone。在五個公開 benchmark datasets 上的實驗顯示，FirstDiff 達到具競爭力的結果，並大幅降低 diffusion inference 成本。

## 問題背景

多變量時間序列異常偵測常依賴 prediction 或 reconstruction error；當異常接近正常資料流形，誤差可能不明顯。既有 diffusion-based 方法通常要完成 T-step reverse diffusion 才從最終重建訊號產生分數，忽略中間去噪表徵並承受高推論延遲。本文要驗證初始步驟的 predicted noise 是否已足以區分正常與異常行為。

## 解決方案

FirstDiff 將初始 reverse-diffusion evaluation 的 predicted diffusion noise 視為異常表徵，而非僅把它當作生成重建的中間量。模型先以正常視窗訓練 DDPM denoiser，並由 DiT 建模跨時間與感測器的依賴；完成訓練後，利用正常 validation data 估計 predicted-noise 的平均值與 covariance。測試時只需對加噪視窗執行一次 DiT，計算其噪聲向量相對 reference distribution 的距離，再依閾值輸出異常結果。核心創新是以早期 score-like denoising information 取代完整 reverse trajectory，並可與 reconstruction score 或其他距離產生 hybrid detector。

## 核心貢獻
1. 提出 FirstDiff，直接利用初始 reverse-diffusion evaluation 的 predicted diffusion noise 進行多變量時間序列異常偵測，將完整反向擴散簡化為單次 denoising-network evaluation。
2. 以正常 validation windows 估計 predicted-noise 或 denoising-residual 的 Gaussian reference distribution，並研究 Euclidean、cosine 與 Mahalanobis distance 作為異常分數。
3. 採用具有 global self-attention 的 Diffusion Transformer，同時建模視窗內的長期時間依賴與 inter-sensor interactions，並透過消融實驗分析不同表徵、距離及 hybrid inference 的效果。

## 技術方法

資料先以 training-set statistics standardize，再切成長度 W=96 的 overlapping windows；training stride 為 64，validation/test stride 為 96，且訓練只使用正常資料。模型使用 DDPM forward process，依式 Xt=√ᾱtX0+√(1−ᾱt)ε 加入 Gaussian noise，並以標準 noise-prediction objective 最小化真實噪聲與預測噪聲的 squared error。denoising backbone 是由 6 個 Transformer blocks 組成的 DiT，hidden dimension 為 256、attention heads 為 8；輸入經 linear projection 與 sinusoidal positional encoding，並以 timestep embedding 和 AdaLN 調制，最後由 linear head 輸出各感測器的 predicted noise。訓練採 T=100、linear variance schedule、Adam、batch size 128、15 epochs。推論時在 initial reverse-diffusion evaluation 取得 ε̂(1)=εθ(XT,T)，並可計算 residual r(1)=ε−ε̂(1)。以正常 validation windows 的 timestamp-level vectors 估計 mean 與 covariance，建立 Gaussian reference distribution；對測試表徵計算 Euclidean、cosine 或 Mahalanobis distance，超過 threshold τ 即判為異常。論文亦評估完整 reconstruction 與 hybrid OR rule。資料集為 SMD、PSM、MSL、SWaT、SMAP，指標包括 Precision、Recall、F1-score 與 Average Detection Delay。

## 關鍵結果

主要結果如下；數值為論文 Table II–V 與 Table IV 所報告的結果。

| GAD | 81.91% | 93.83% | 88.30% | 86.46% | 88.60% | 87.82% |
| ImDiffusion | 81.77% | 96.20% | 85.84% | 79.93% | 89.63% | 86.67% |
| DiffAD | 63.58% | 95.71% | 90.61% | 52.10% | 95.38% | 79.48% |

FirstDiff 的 Mah(ε) 在 PSM、MSL、SWaT、SMAP 取得表中最高 F1，但 SMD 的 81.48% 略低於 GAD 的 81.91%。Average Detection Delay 分別為 SMD 35.90、PSM 26.17、MSL 65.36、SWaT 110.14、SMAP 142.06；其中 PSM 與 SWaT 為表中最低。單一視窗平均 inference time 為：FirstDiff one-step 1.25 ms、FirstDiff full-step 99.74 ms、ImDiffusion 204.55 ms、DiffAD 268.34 ms、GAD 372.91 ms。

## 對我們的啟發
- [ ] 在需要低延遲或高吞吐量的線上監控場景，可優先評估 diffusion denoiser 的早期 predicted noise，而不必執行完整生成軌跡；論文報告其平均每視窗推論時間約為 1.25 ms。
- [ ] Mahalanobis distance 能在考量感測器維度間 covariance 的情況下衡量偏離程度；但其效果依資料集而異，實務部署仍應以正常 validation data 進行距離與閾值選擇。
- [ ] predicted-noise score 與 reconstruction score 具有互補性。論文的 hybrid ablation 顯示，結合不同異常訊號可能提升 F1，但 OR rule 也可能引入額外誤報，因此應依應用的 precision/recall 需求評估。

## 限制與未來工作

論文主要在五個公開 benchmark datasets 上驗證，未提供跨資料集部署、非平穩環境或大規模線上場景的額外結果。Gaussian reference model 只是對正常 predicted-noise 分布的 tractable approximation，且閾值選擇與協方差估計的敏感度未被完整量化。作者提出的未來方向包括 alternative diffusion formulations、adaptive denoising-step selection，以及更有效的大規模 distribution modeling。
