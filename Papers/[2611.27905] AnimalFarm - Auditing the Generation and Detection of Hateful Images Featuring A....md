# AnimalFarm: Auditing the Generation and Detection of Hateful Images Featuring Anthropomorphic Characters

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.27905)
- 📥 [PDF](https://arxiv.org/pdf/2611.27905v1)

## 摘要（中文翻譯）

擬人化非人類角色長期被用來傳達針對人類群體的仇恨訊息，從納粹時期宣傳到近期社群媒體上的 AI 生成影像皆然。然而，此類影像的安全風險仍缺乏系統性研究。本文首次研究涉及擬人化非人類角色的仇恨影像生成與偵測，建立由嚴格篩選來源場景構成的 benchmark，涵蓋五種角色與三項生成任務：text-to-image、image editing 與 conversational image generation。在 14,250 個預定查詢中，生成系統對 92.1% 產生影像，其中 95.9% 含仇恨內容。作者進一步收集 4,370 張仇恨影像並評估五種偵測器；最佳的 GPT-5.5 僅偵測出 73.9%，多數偵測器低於 58%。研究發現，當主體為非人類角色時，現有偵測器常將仇恨影像誤判為良性。作者提出 depiction reversal 與 fine-tuned detector，F1 分別達 0.962 與 0.979。

## 問題背景

論文探討生成式影像系統是否能阻擋以貓、兔、狐狸、豬及 LABUBU 等擬人化非人類角色影射人類群體的仇恨內容，以及現有偵測器能否辨識此類影像。既有生成與偵測研究主要聚焦人類主體或 hateful memes，可能依賴人類臉部、身體與刻板特徵，因此非人類代理呈現的仇恨語意被忽略，形成生成防護與內容審核缺口。

## 解決方案

作者建立 AnthroHate-Prompt 與 AnthroHate-Image 兩個資源，系統評估 text-to-image、image editing 及 multi-turn generation 的安全性與偵測能力。核心解法包括 training-free 的 depiction reversal pipeline：先描述影像場景，再將非人類角色改寫為人類角色，最後進行仇恨判斷；以及以結構化推理資料訓練的 Qwen3.5-4B detector，透過 SFT 與 GRPO 強化場景描述、角色替換、仇恨判斷、格式遵循及目標群體辨識。其創新在於將非人類代理視為需還原語意的仇恨表達，而非僅依賴角色外觀分類。

## 核心貢獻
1. 提出 AnthroHate-Prompt，涵蓋五種擬人化非人類角色、三種影像生成任務及英中 T2I 提示，系統揭示多種生成系統對此類仇恨內容的防護失效。
2. 建立包含 4,370 張仇恨影像的 AnthroHate-Image，並以五種偵測器證明非人類角色會顯著降低仇恨內容辨識能力。
3. 提出 depiction reversal 與 SFT+GRPO fine-tuned detector，分別達到 0.962 與 0.979 的 F1，展示針對非人類代理仇恨內容的有效緩解方法。

## 技術方法

資料方面，作者從 4chan /pol/ 收集 792 張影像，經兩名標註者獨立審查後保留 35 個具可辨識仇恨場景，涵蓋 Asian、Black、Jewish 與 Muslim 群體；另從 Wikimedia Commons 篩選 30 張人類主體仇恨影像。35 個場景與五種角色、英中雙語組合成 350 個 T2I items；30 個 seed image 經角色替換形成 150 個 Edit items，並以兩輪互動形成 150 個 MT items。八個模型用於 T2I、七個用於 Edit、三個用於 MT，每一項重複三次。評估生成率 G/Q、生成影像中的仇恨率 H/G，以及相對預定查詢的仇恨率 H/Q；所有生成影像由至少兩名標註者判定，整體一致率為 96.0%。偵測部分建立 4,370 張仇恨影像，評估 GPT-5.5、Gemini 3.1 Flash、Claude Haiku 4.5、LlavaGuard v1.2 7B 與 Q16，並以 recall 衡量。防禦實驗依 scenario split 建立 1,338 張訓練影像與 7,145 張測試影像，評估 recall、precision 與 F1。Depiction reversal 包含影像描述、非人類至人類角色改寫及最終判斷三階段；fine-tuned detector 先以 LoRA SFT，再以 GRPO 優化正確性、格式、checklist coverage 與目標群體辨識。

## 關鍵結果

| 實驗項目 | 主要結果 |
|---|---:|
| 全部生成查詢 | 14,250 個 scheduled queries；產生 13,124 張影像，G/Q = 92.1% |
| 生成仇恨比例 | 12,584 張生成影像含仇恨內容，H/G = 95.9%；H/Q = 88.3% |
| 任務別 H/G | T2I 99.1%；Edit 89.1%；MT 93.3% |
| GPT Image 2 的 H/Q | T2I 66.6%；Edit 68.0%；MT 75.3% |
| 最佳基準偵測器 | GPT-5.5 recall = 73.9%；Gemini 3.1 Flash = 67.7%；Q16 = 57.0% |
| 其他偵測器 recall | Claude Haiku 4.5 = 42.5%；LlavaGuard = 28.0% |
| 偵測器共識 | 五個偵測器全部辨識 18.4%；全部漏判 10.4% |
| 防禦基準 | GPT-5.5 在 held-out test set recall = 0.761，F1 = 0.864 |
| Prompt enhancement | GPT-5.5 recall = 0.793、F1 = 0.885；Gemini recall = 0.814、F1 = 0.897 |
| Depiction reversal | recall = 0.927，F1 = 0.962；良性影像 3,650 張中僅 3 個 false positives |
| Fine-tuned detector | SFT+GRPO recall = 0.972，F1 = 0.979；SFT only F1 = 0.904 |

## 對我們的啟發
- [ ] 內容審核 benchmark 不應只測試人類主體；應加入以動物、虛構角色或其他代理表達群體仇恨的語意保持測試。
- [ ] 偵測流程可加入角色替換或語意正規化步驟，將非人類角色還原為人類中心的場景描述，再進行安全判斷；但需檢查描述階段是否遺漏細微道具、背景文字與姿勢。
- [ ] 評估生成模型時應同時報告生成成功率、生成結果中的仇恨率及每個預定查詢產生仇恨影像的比例，避免只以拒絕率推論安全性。

## 限制與未來工作

資料主要來自少量來源場景，文化脈絡以英語網路社群及四個目標群體為主，且 Edit/MT 的 Muslim seed 僅一個，限制群體間比較。研究只測試特定模型版本與靜態影像，尚未驗證影片、音訊、個人攻擊或未來模型。
