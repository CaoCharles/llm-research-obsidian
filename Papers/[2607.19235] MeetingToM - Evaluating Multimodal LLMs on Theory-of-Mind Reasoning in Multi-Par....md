# MeetingToM: Evaluating Multimodal LLMs on Theory-of-Mind Reasoning in Multi-Party Meetings

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.19235)
- 📥 [PDF](https://arxiv.org/pdf/2607.19235v1)

## 摘要（中文翻譯）

Theory of Mind（ToM）是推斷他人信念、意圖與知識狀態的能力，對社會互動至關重要，但現有 Multimodal Large Language Models（MLLMs）在多方會議中仍面臨顯著挑戰，因為相關線索分散於語音、語言與行為之間。既有 multimodal ToM benchmark 多聚焦於影片問答及明顯、可外部驗證的訊號，較少涵蓋隱性社會狀態與群體動力。本文提出 MeetingToM，一個針對自然多方會議中複雜社會行為推理的 benchmark，特別評估 pseudo-consensus：表面同意在社會壓力下掩蓋私人異議。資料依社會粒度分為 subject-level mental state prediction、dyadic-level addressee understanding，以及 group-level consensus reasoning。統一評估顯示，現有 MLLMs 在整合非語言線索、推斷隱藏態度，以及區分真正共識與 pseudo-consensus 方面仍有持續限制。

## 問題背景

現有 multimodal ToM benchmark 多以影片問答評估明顯且可驗證的行為，較少處理自然多方會議中的隱性心理狀態、指涉關係與群體動力。模型因此不只要辨識「說了什麼」，還要整合凝視、姿勢、回應時序與社會壓力，判斷表面同意是否掩蓋私人異議。論文聚焦於現有 MLLMs 難以可靠完成這類 meeting-grounded ToM 推理的問題。

## 解決方案

作者提出 MeetingToM，一個以 AMI 多視角會議影片與對齊逐字稿為基礎的階層式 benchmark。其核心設計按社會粒度與推理深度分成三層：個體 mental state prediction、雙人 addressee 與 attitude reasoning、群體 consensus 與 hidden dissent reasoning。基準特別引入 pseudo-consensus，並以統一的 multiple-choice evaluation protocol、人工審核標註及多面向消融實驗，檢驗模型是否真正整合語言、非語言與互動脈絡，而非依賴表面話語線索。

## 核心貢獻
1. 提出 MeetingToM benchmark，將自然多方會議中的 multimodal Theory-of-Mind 推理系統化為三個遞進層級：個體心理狀態、雙人指涉與態度、群體共識。
2. 引入並具體評估 pseudo-consensus，要求模型辨識表面語言同意與非語言保留或異議之間的不一致，並找出可能的隱性異議者。
3. 基於 AMI Meeting Corpus 建立含同步多視角影片、音訊與逐字稿的資料集，並對代表性 proprietary 與 open-source MLLMs 進行主結果、模態、提示、話語標記與情境先驗分析。

## 技術方法

MeetingToM 建立於 AMI Meeting Corpus 的 scenario-based product-design meetings，使用 60 個 meeting sessions、1,800 個 clips，三個 task family 各 600 筆。資料保留同步的 global view、四名參與者的 close-up view、2×2 mosaic view、音訊與 word-level transcript。Task 1 擷取 5 秒個人近景片段，從七類 mental state 中選擇：Active Engagement、Supportive Endorsement、Focused Listening、Cognitive Conflict、Confused Bewilderment、Hesitation、Disengaged Withdrawal。Task 2 使用約 50 秒脈絡，先依 global view、凝視、身體方向與話語判斷 “you” 的 addressee，再從相關視角判斷其對 speaker 的 Support、Oppose、Neutral 或 Uncertain 態度。Task 3 以 mosaic view 與逐字稿判斷 True Consensus、Pseudo Consensus、No Consensus 或 Uncertain；若為 pseudo-consensus，再辨識隱性異議者。候選片段由互動模式抽取，GPT-5 協助產生問題與選項，但不決定 gold answer；兩名訓練 annotators 獨立標註，第三名處理歧異，無多數共識者剔除。評估採 exact-match accuracy，並對 Task 1 與 Task 3.1 報告 Macro-F1；Task 3.2 條件式評估。實驗比較 GPT-4o、GPT-5、Gemini-3 Pro、Qwen2.5/3-VL，另分析 video、utterance 與聯合模態、Naive-CoT、Task-CoT、ECoT、話語標記移除及 role、phase、dialogue-act 先驗。

## 對我們的啟發
- [ ] 評估會議或協作助理時，不應只使用整體 accuracy；Task 1 與 Task 3.1 的 accuracy 和 Macro-F1 差距顯示，類別不平衡可能掩蓋模型對少數且關鍵社會狀態的失敗。
- [ ] 多模態輸入不必然帶來提升：Gemini-3 Pro 的 utterance-only 在多數任務優於 video-only 或 video-and-utterance，實務系統應採用任務導向的視覺—語言融合，而非直接堆疊模態。
- [ ] Chain-of-Thought 與情緒導向提示的效果依模型與任務而變；部署時應分別驗證個體、雙人及群體推理，避免將較長推理誤視為普遍能力提升。

## 限制與未來工作

資料僅來自英語、結構化的 AMI 會議，且以約 5 秒或 50 秒片段取代完整 30 分鐘會議，限制了跨語言、非正式、線上與長期脈絡的泛化。心理狀態由第三方依可觀察線索推斷，無法取得原始參與者的自我報告，因此未必等同其真實私人信念或意圖。
