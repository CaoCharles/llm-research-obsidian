# FALCON: A Model and Dataset Agnostic Framework for Synthetic Data Generation for NL2SQL Pairs

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.03625)
- 📥 [PDF](https://arxiv.org/pdf/2610.03625v1)

## 摘要（中文翻譯）

關聯式資料庫是最廣泛部署的結構化知識形式之一，而讓使用者以自然語言存取資料庫，必須將語言 grounded 到 schema 實體與關係，並處理人類表達方式所 inherent 的歧義。現有 synthetic NL-to-SQL 資料生成方法大多忽略歧義，產生過度簡化的 queries，無法讓模型學習真實結構化知識存取的複雜性。我們提出 FALCON，一個 model-與 database-agnostic framework，使用 compact open models、以低成本生成 realistic 且 ambiguity-aware 的 NL-to-SQL 資料。方法結合 reserved-word SQL seeding 與 persona-based prompting 產生結構複雜的 queries，並透過 alignment-based filtering 區分真正錯誤與複雜但有效的 examples，以保留難度。Human evaluation 顯示不同模型規模皆維持穩定高品質；生成資料在 SQL complexity 與 natural-language richness 上超越既有 benchmarks。依難度分層的實驗顯示，模型在 FALCON 資料上訓練後，query 越複雜，相較 baseline-trained models 的優勢越大。加入少量既有 benchmark 資料後，可恢復簡單 queries 的表現，同時保留複雜 queries 的優勢。此設計可讓組織在本地、無需 external APIs 的情況下產生高複雜度訓練資料。

## 問題背景

論文針對 synthetic NL-to-SQL 資料難以反映真實部署情境的問題。既有方法常生成單表、簡單且語言單一的 queries，忽略 scope、attachment、entity vagueness 與 broadness 等自然語言歧義；較強的方法又依賴昂貴的 frontier-model APIs、較大模型或特定資料集。結果是訓練資料無法涵蓋 enterprise database 的 SQL complexity、語言多樣性與模糊需求，也不利於隱私保護與本地部署。

## 解決方案

作者提出 FALCON（Framework for synthetic Ambiguity-aware Linguistically-diverse Cost-efficient Optimized NL-to-SQL data generation），以 SQL-then-NL 為主流程，先利用 schema 生成可執行且高複雜度的 SQL，再生成對應自然語言。核心創新包括：以 BIRD 的 reserved-word 分布控制 SQL 難度；以 common 或 creative personas 注入真實且多樣的使用情境；產生多個 NL candidates 並用 LLM-as-a-judge 選擇；以 Ambrosia 訓練的 ambiguity detector 尋找歧義，為有效歧義建立多重 SQL interpretations；最後透過 alignment reward model 與 prompt-based filters，移除 schema grounding 或語意不一致的 pairs，同時盡量保留複雜度。整體流程採 compact open models，並主張具 model-與 database-agnostic 及本地隱私優勢。

## 核心貢獻
1. 提出 model-與 database-agnostic 的 FALCON pipeline，透過 reserved-word seeding 與 persona-based prompting，低成本生成具有 BIRD-level SQL complexity 和較高 NL richness 的 synthetic NL-to-SQL pairs。
2. 將 ambiguity detection、multi-interpretation SQL generation 與 ambiguity-specific validation 納入資料生成流程，明確處理 Scope、Attachment、Entity Vagueness 與 Broadness 等語意歧義。
3. 提出結合 semantic similarity、schema entity matching 與 corruption penalties 的 alignment-based filtering，並以 human evaluation 與下游 difficulty-stratified results 驗證其能保留複雜度、降低 misalignment。

## 技術方法

FALCON 從既有 database schemas 出發。第一階段以 SQL-then-NL 生成：模型依 schema、foreign-key 關係與 seeding prompt 產生 SQL，最多重試三次並以實際執行檢查 validity。Reserved-word seeding 從 BIRD training distribution 抽樣目標 SQL reserved-word 數量；persona seeding 則為每個 table 產生 common 或 creative persona、目標與 example queries，以增加 SQL use cases 和 NL register 的多樣性。第二階段將 validated SQL 與 schema 輸入模型，產生四個 NL candidates，再由 Compare Judge 依 completeness、no hallucination、naturalness 與 schema independence 選出最佳問題。第三階段使用在 Ambrosia 上 fine-tune 的 DistilBERT，輸出 0–10 ambiguity score；高於 7 時，透過 prompt 判斷 Scope、Attachment、Entity Vagueness 或 Broadness，並嘗試生成另一個可執行且語意不同的 SQL interpretation。第四階段使用以 9,000 多個 BIRD-derived examples（半數系統性 corruption）訓練的 alignment model；其 hybrid score 由 semantic similarity（40%）與 schema entity matching（60%）組成，並加入 corruption penalties。最後再用 prompt-based filter 檢查 NL-SQL validity、SQL 合理性、非冗餘性與自然度。評估包含 NL richness、SQL complexity、human ratings，以及 Exact Match、Fuzzy Score、Soft-EX；下游以 Qwen-2.5-3B 和 1.5B 比較 FALCON、Spider 與 95% synthetic/5% Spider mixed training，並進行難度分層與 ablation。

## 關鍵結果

主要結果如下（數值均來自論文）：

| 實驗面向 | 結果 |
|---|---|
| Reserved-word seeding | 與目標 reserved-word count 的 Pearson correlation 為 0.60；median deviation 為 3 words |
| Alignment metric | hybrid alignment score 與 human judgments 的 Pearson correlation 為 0.70 |
| Alignment reward model | F1 93.73%、specificity 71.43%、recall 92.81%；將 misaligned examples 從 16% 降至 4% |
| Ambiguity pipeline | accuracy 94.0%、precision 66.7%、recall 28.6%、F1 40.0%、specificity 98.9% |
| Human evaluation | 各模型的 SQL、NL、alignment 分數皆超過 0.92；Qwen-3B 分別為 0.96/0.95/0.94，Qwen-32B 為 0.98/0.97/0.93 |
| Complexity comparison | Spider-seeded FALCON：SQL 0.43、NL 0.39；BIRD：SQL 0.42、NL 0.31；Spider：SQL 0.38、NL 0.29 |
| Qwen-2.5-3B：Spider train → Spider test | EM 35.95%、FS 0.89、Soft-EX 0.42 |
| Qwen-2.5-3B：FALCON train → FALCON test | EM 13.80%、FS 0.83、Soft-EX 0.48 |
| Qwen-2.5-3B：FALCON train → Spider test | EM 0.80%、FS 0.68、Soft-EX 0.32；作者指出 raw EM 低估了可接受變體 |
| Mixed training：95% FALCON + 5% Spider | Spider test EM 27.10%；FALCON test EM 13.60% |
| Generation cost | 5,500 examples 約需 34.47M input tokens、5.13M output tokens；論文估計 GPT-5.5 約 326 美元、open model commodity GPU 約 20 美元 |
| Ablation | SQL→NL 的 SQL/NL complexity 為 0.42/0.31，NL→SQL 為 0.40/0.21；加入 reserved words 後為 0.48/0.31，加入 personas 後為 0.42/0.34，Compare Judge 後為 0.46/0.36 |

## 對我們的啟發
- [ ] 若 synthetic data 的目標是涵蓋困難案例，應先控制結構化 SQL complexity，再反向生成自然語言；論文的 SQL→NL ablation 顯示此順序優於 NL→SQL。
- [ ] 資料品質過濾不應只依賴 execution validity；可執行的 SQL 仍可能與 NL 語意或 schema entity 不對齊，因此需要 alignment model、LLM judge 與最後 prompt filter 的互補檢查。
- [ ] 高難度資料與真實簡單資料應混合使用：論文中 95% FALCON 加 5% Spider 可改善簡單分布與 Spider 表現，而保留複雜 query 上的優勢；實務部署應依難度分布調整比例。

## 限制與未來工作

FALCON 偏重複雜 queries，單獨訓練在 Spider 上僅達 0.8% EM，需加入約 5–10% real data。Ambiguity detection specificity 高但 recall 僅 28.6%，會漏掉許多歧義案例。目前僅支援 SQLite，評估限於 Spider、WikiSQL、BIRD 與 compact models；生成資料也繼承 seed databases 的 domain coverage 與 bias。
