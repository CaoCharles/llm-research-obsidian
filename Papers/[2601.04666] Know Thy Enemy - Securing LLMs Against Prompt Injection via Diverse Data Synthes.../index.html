    Know Thy Enemy: Securing LLMs Against Prompt Injection via Diverse Data Synthesis and Instruction-Level Chain-of-Thought Learning

    連結

    • 📄 arXiv
    • 📥 PDF
    • 📎 本地 PDF: PDF

    摘要（中文翻譯）

    大型語言模型（LLM）整合應用日益普遍，但面臨 prompt injection（PI）攻擊的嚴重安全威脅。防禦 PI 攻擊面臨兩大難題：惡意指令可透過多種向量注入，且注入指令與周圍上下文缺乏明確語義邊界，難以辨識。為此，本文提出 InstruCoT，一種結合多樣化訓練資料合成與指令層級 chain-of-thought 微調的模型增強方法，使 LLM 能有效辨識並拒絕惡意指令，不受其來源或上下文位置影響。我們從三個關鍵維度評估 InstruCoT：行為偏離（Behavior Deviation）、隱私洩露（Privacy Leakage）與有害輸出（Harmful Output）。在四個 LLM 上的實驗結果表明，InstruCoT 在所有維度上均顯著優於基線方法，同時維持效用性能不下降。

    問題背景

    LLM 整合應用面臨 prompt injection 攻擊的嚴重威脅，現有防禦方法存在兩大瓶頸：(1) 攻擊向量多樣化——惡意指令可透過對話系統、工具呼叫、資訊檢索等多種管道注入；(2) 語義邊界模糊——現代攻擊將惡意意圖偽裝在正常上下文中，難以與合法指令區分。現有防禦方法（如 prompt engineering、偵測模型）各有侷限，缺乏能同時處理多向量注入且不犧牲效用的通用解決方案。

    解決方案

    InstruCoT 結合兩個核心創新：(1) 多樣化資料合成——基於應用框架→元件→上下文區域的系統化映射，自動生成涵蓋行為偏離、隱私洩露、有害輸出三類威脅的訓練資料，注入位置覆蓋 User、Data、User+Data 和 Empty 四種區域；(2) 指令層級 CoT 微調——基於 Endsley 情境感知模型設計三階段推理：指令感知（提取所有指令）→違規理解（分析與系統 prompt 的衝突）→回應預測（決定接受/拒絕），使模型學會透過結構化推理辨識並拒絕惡意指令。

    核心貢獻

    1. 提出系統化的多樣化 PI 訓練資料合成方法，透過應用框架→元件→上下文區域的映射，自動生成涵蓋三類威脅、四種注入位置的訓練樣本
    2. 設計基於情境感知理論的三階段 CoT 微調策略（感知→理解→預測），使模型能透過結構化推理辨識語義邊界模糊的惡意指令
    3. 在四個 LLM 上的三維度評估中，InstruCoT 的防禦率（DR）達 92.5%-98.0%，相比基線提升 6.7%-82.5%，同時維持 82.9% 效用勝率

    技術方法

    資料合成管線：系統化映射 LLM 應用框架（對話、工具使用、資訊檢索）到具體元件（system prompt、tool output、retrieved docs），再對應到四種注入區域（User、Data、User+Data、Empty）。針對每個區域，生成三類威脅的訓練樣本：行為偏離（劫持任務）、隱私洩露（提取系統 prompt）、有害輸出（生成不當內容）。

    CoT 微調：基於 Endsley 情境感知模型，設計三階段推理標註： 1. 指令感知（Perception）：窮舉提取輸入中的所有指令 2. 違規理解（Comprehension）：逐一分析每條指令是否與系統 prompt 衝突 3. 回應預測（Projection）：基於分析結果決定接受或拒絕

    使用 SFT 對 Llama3.1-8B、Llama3-8B、Qwen2.5-7B、Qwen3-8B 進行微調。

    評估：三維度（Behavior Deviation、Privacy Leakage、Harmful Output）× 四種注入位置，使用 Defense Rate（DR）衡量防禦效果，Win Rate（WR）衡量效用保持。

    關鍵結果

    維度 InstruCoT DR 最佳基線 DR 提升幅度
    Behavior Deviation 92.5% 66.7% (ISE) +25.8%
    Privacy Leakage 98.0% 91.3% (MetaSec) +6.7%
    Harmful Output 90.9% 83.5% (MetaSec) +7.4%
    效用勝率 (WR) 82.9% 81.4% (MetaSec) +1.5%

    四個 LLM（Llama3.1-8B、Llama3-8B、Qwen2.5-7B、Qwen3-8B）的平均結果。InstruCoT 在所有維度上均為最佳，且效用無下降。

    對我們的啟發

    • CoT 推理作為防禦機制的有效性表明，讓模型「思考後再行動」比單純的 prompt engineering 或偵測器更能抵禦 PI 攻擊，這為 agent 安全設計提供了結構化推理的防禦範式
    • 系統化的資料合成方法（框架→元件→區域→威脅）可推廣至其他安全場景，為自動化紅隊測試提供了可複用的攻擊面覆蓋框架
    • 防禦率在不同維度間的差異（隱私洩露 98% vs 行為偏離 92.5%）暗示不同類型的 PI 攻擊難度不同，行為偏離因其語義模糊性更高而更難防禦

    限制與未來工作

    CoT 生成增加推理開銷，雖可透過 speculative decoding 或選擇性觸發緩解，但在延遲敏感場景仍需權衡。訓練與評估共享相同的三類威脅維度，未驗證對未見威脅類別的泛化能力。僅在 7B-8B 規模模型上實驗，更大規模模型的表現待確認。
