# Molecular Déjà Vu: Digit-Level Retrieval of Published Values in Frontier Language Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.05381)
- 📥 [PDF](https://arxiv.org/pdf/2609.05381v1)

## 摘要（中文翻譯）

大型語言模型（LLM）日益被用於 molecular property benchmarks，但僅看準確率，無法區分模型是在預測性質，還是在擷取已發表的數值。作者審查 22 個 frontier models 與 12 個 regression benchmarks 的逐字數值擷取，發現此現象相當普遍，但高度依賴 benchmark：五個資料集有超過 50% 的 LLM 出現逐字擷取，其餘資料集僅出現在少數模型—資料集組合。作者在兩種 reasoning levels 下進行相同實驗，發現 reasoning 會改變擷取行為；相同分子與 prompt 在較高 reasoning level 被標記的比例，比最低設定高 89%。在最受污染的案例中，作者進一步測試中斷擷取的方法，發現部分最強模型仍能從 transformed SMILES strings 與原始 labels 的組合辨識數值。此外，抑制擷取會使不同模型的相對 prediction errors 更接近，而模型對 verbatim retrieval 的不同使用程度，反而會擴大模型間差異。結果顯示，LLM 的一般預測能力不能僅由 memorised values 的數量決定。本研究概述了 LLM 在 molecular regression benchmarks 中逐字擷取已發表數值的規模與深度。

## 問題背景

LLM 在分子性質 regression benchmarks 上取得低誤差，不代表其具備從分子結構泛化的預測能力；模型可能只是記住並重現論文或資料集中的 published values。既有 contamination detectors 多依賴 token likelihood、canonical example order、可補全文字或分類答案，無法直接適用於數值 regression；單純 accuracy 或 error 也無法辨識第三位有效數字是否源自 retrieval。

## 解決方案

作者提出以 digit-level retrieval 為核心的 contamination audit。對每個模型—benchmark 組合，將預測與 published value 比較至 1、2、3 個 significant figures，利用巢狀 retention statistics R12 與 R23，並與僅根據 benchmark label distribution 的 molecule-blind floor 比較；若 retention 顯著高於該 floor，則判定具有 retrieval evidence。研究同時建立 22 個模型與 12 個資料集的 contamination map，控制 reasoning level，重複最低與較高 reasoning 設定，並以 transformed SMILES 與匿名 property 的 blinding experiment 測試 retrieval 是否可被中斷及其對 benchmark ranking 的影響。

## 核心貢獻
1. 建立涵蓋 22 個 frontier models 與 12 個 molecular property benchmarks 的 contamination map，使用 digit-level retention 而非單純 accuracy 或 error 判定 verbatim retrieval。
2. 證明 retrieval 具有 reasoning-level dependence：相同分子與 prompt 在較高 reasoning 設定下出現更多顯著 retrieval，因此低 reasoning audit 只能視為 contamination 的 lower bound。
3. 透過 SMILES transformation 與 character-substitution blinding，分析 retrieval 對分子身份與 labels 的依賴，並顯示 retrieval 會扭曲模型間的 error、排名與 benchmark 解讀。

## 技術方法

實驗透過單一 provider 以 zero-shot 方式查詢 22 個 frontier models。system prompt 指定 benchmark 與 label name，user prompt 提供一個 SMILES string，要求輸出三個 significant figures；主要實驗對每個 benchmark 使用相同的 500 個 molecules，boiling-point positive control 使用全部 45 個分子。資料集包含實測性質、quantum-chemistry properties、textbook boiling points，以及 2024–2025 antiviral potency recency control。每個 truth—prediction pair 形成巢狀計數 m1≥m2≥m3，分別表示匹配 1、2、3 個 significant figures；評估 HIT3=m3/nusable、R12=m2/m1、R23=m3/m2、median absolute error（medAE）與 rank correlation。R12、R23 以條件式 Binomial test 與由 label distribution 建立、且以隨機半數 labels 擬合的 molecule-blind floor 比較，並以 Benjamini–Hochberg 控制每次 run 的 false discovery rate。reasoning 分析重跑相同 cells 的最低設定，另對五個模型建立多級 reasoning ladder，將 retrieval rate 對 emitted reasoning tokens。blinding study 選四個模型與三個高度 retrieved benchmarks，在 100 個 in-context examples 下比較 published SMILES 與 character-substituted SMILES、匿名 target 的條件。論文沒有提出或訓練新的模型架構；模型為透過 API 查詢的既有 LLM。

## 關鍵結果

| 分析項目 | 論文報告結果 |
|---|---|
| 審查範圍 | 22 個 frontier models、12 個 molecular regression benchmarks |
| 高度受影響資料集 | FreeSolv、ESOL、LD50、AqSolDB 與 boiling-point positive control；五個資料集均有超過 50% 的 LLM 出現 verbatim retrieval |
| 其餘資料集 | 多數僅有 isolated cells 顯著 retrieval；recency control、BACE 與 Caco-2 在 reasoning 對照中維持 0 個 flagged cells |
| Reasoning effect | 最低 reasoning 有 47/264 cells 顯著 retrieval；較高設定有 89/264 cells，flagged cells 增加約 89% |
| Corpus exposure 關聯 | benchmark 分子跨文件出現頻率與最強 retrieval rate 的 benchmark-level Spearman ρ=0.88；benchmark file headers 的對應為 ρ=0.20 |
| SMILES 改寫 | 改成不同但有效的 SMILES 後，12 個 cells 的 retrieval 中位數仍保留原本的 102%，全部 12 個 cells 仍受污染 |
| Blinding | 12 個 cells 中，published SMILES 條件有 10 個 flagged；character-substituted、匿名 target 條件仍有 3 個 flagged |
| 殘餘 retrieval | Claude Opus 5 在 blinded ESOL 與 FreeSolv 仍分別達 6.7% 與 4.8% HIT3；GPT-5.6 sol 的 ESOL 由 14% 變為 13%，幾乎未受影響 |
| Error spread | blinded 後 Claude Opus 5、Grok 4.5、Kimi K3、GPT-5.6 sol 的 pooled medAE 分別增加 34.9、16.9、3.2、1.8 倍；模型間誤差更接近，排名也改變 |
| 排名穩定性 | 12 個 blinding cells 中僅 3 個保留 medAE 排名、2 個保留 Pearson r 排名 |
| 不確定結果 | 論文未報告足以證明所有 clean cells 都沒有 retrieval；作者明確指出許多 clean cells 對深層 retention 的檢定 power 不足。

## 對我們的啟發
- [ ] 評估 LLM 的 molecular regression 時，應同時報告 HIT3、R12/R23、reasoning setting 與 contamination evidence，不能只比較 MAE、RMSE 或 correlation。
- [ ] 重新序列化 SMILES 並不能可靠防止 retrieval；若要進行 audit，至少應在不同 reasoning levels 下重複測試，因為最低 reasoning 可能漏掉約一半的 flagged cells。
- [ ] 對高度 redistributed 的 FreeSolv、ESOL、AqSolDB 與 LD50，應加入 blinding、未公開新資料或其他 retrieval controls；但 character substitution 會同時破壞 chemistry，因此不能直接視為保留原任務的公平 benchmark。

## 限制與未來工作

作者指出 digit-level statistic 只能提供 retrieval evidence；未被標記不等於乾淨，許多 cells 的檢定 power 不足。blinding 僅涵蓋四個模型、三個 benchmark，且 character substitution 同時破壞分子化學資訊。研究也未建立強力 non-memorising baseline，無法量化純預測模型在相同 digit statistic 上的表現。
