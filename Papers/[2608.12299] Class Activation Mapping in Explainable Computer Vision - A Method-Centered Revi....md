# Class Activation Mapping in Explainable Computer Vision: A Method-Centered Review of CNN, Transformer, and Foundation-Model-Era Visual Explanations

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.12299)
- 📥 [PDF](https://arxiv.org/pdf/2608.12299v1)

## 摘要（中文翻譯）

Class Activation Mapping（CAM）是可解釋人工智慧中廣泛使用的視覺解釋方法，其目標是將模型內部證據轉換為熱圖，指出支持特定類別或概念的影像區域、卷積通道、token 或 patch。自 2016 年首個 CAM 方法提出後，研究已由依賴 global-average pooling 的 CNN，擴展至 gradient-based、gradient-free score／ablation、高解析度上採樣、弱監督定位與分割、Transformer token attribution，以及結合 CLIP、DINO、SAM 或特徵分布比較的 foundation-model 方法。本論文整理 2016 年後 57 篇以方法為中心的研究，依 attribution mechanism、架構依賴性與 evaluation objective 建立分類法。整體趨勢是從單一 CNN 層的單類別分數解釋，轉向 comparative、multi-layer、probabilistic、token-aware 與 foundation-model-aware 解釋；然而 faithfulness、localization、robustness、計算成本與 human trust 的評估仍缺乏標準化。

## 問題背景

CAM 研究已從原始 global-average-pooled CNN 擴展到一般 CNN、Transformer、弱監督定位／分割與 foundation model，但方法名稱相近、歸因機制不同，容易造成混淆。現有工作分別強調解析度、faithfulness、定位、效率或人類信任，卻使用不一致的資料集與評估協定；此外，梯度飽和、低解析度、背景捷徑、attention 不等於 explanation、prompt 敏感性與高昂的 gradient-free 成本仍未被共同解決。

## 解決方案

作者提出一套以方法為中心的 CAM review 框架，而非單一新模型。其核心是以 57 篇嚴格篩選的研究建立發展脈絡與分類法，按歸因機制、架構依賴性及評估目標區分 gradient-based、gradient-free、hybrid、high-resolution、token／patch 與 foundation-model-era 方法。框架同時整理各方法如何改變權重訊號、層級、目標或先驗，並將其結果放回相容的評估協定中比較，強調任何熱圖都必須連同解釋目標、證據來源、成本、faithfulness、localization 與限制一起理解。

## 核心貢獻
1. 建立一個以方法為中心的嚴格 CAM-style 文獻語料庫，納入 2016 年起 57 篇產生、改良、評估或理論分析 CAM、activation map、token map 與 patch attribution map 的論文，排除僅在應用研究中展示 Grad-CAM 的工作。
2. 提出依 attribution mechanism、architectural dependence 與 evaluation objective 組織的分類法，涵蓋 CNN、gradient-based、gradient-free、hybrid、high-resolution、Transformer token-level、foundation-model-era 與 architecture-aware 方法。
3. 在不混合不相容指標的前提下，整理各方法對 faithfulness、localization、解析度、成本、因果性、偏差與人因信任的改善方向，並指出後續方法如何回應前一代方法的限制。

## 技術方法

論文採 method-centered literature review，而非提出新的 CAM 演算法。作者在 IEEE Xplore、IEEE/CVF Open Access、ACM Digital Library、Elsevier ScienceDirect、SpringerLink 等來源搜尋 2016 年起的視覺 XAI 文獻，使用 CAM、Grad-CAM、Score-CAM、Ablation-CAM、LayerCAM、activation map、token attention map 等概念詞，搭配 CNN、ViT、CLIP、SAM 與 foundation model 等架構詞，以及 explainability、attribution、saliency、WSOL、WSSS 等方法詞。納入條件要求研究必須產生、改良、評估或理論分析 CAM-style map；排除僅展示 Grad-CAM 的應用論文、survey-only、非視覺、2016 年前、重複及超出指定來源範圍的紀錄，形成 57 篇語料庫。技術上，作者以 L_c= h(Σ_k α_k^c A_k) 概括 CAM，其中 A_k 是特徵圖或其 token／patch 對應，α_k^c 是重要性權重，h 通常為 ReLU；不同方法主要差異在權重估計、抽取層與目標定義。評估分為 faithfulness（deletion、insertion、Average Drop、Increase in Confidence、ADCC、ROAD）、localization（Top-1／Top-5、pointing game、energy localization、box／mask overlap）、dense prediction（mIoU、DSC）、robustness（sanity check）及 human-centered trust。作者依方法機制比較 gradient-based、gradient-free／perturbation、hybrid、high-resolution、Transformer token-level、foundation-model-era 與 architecture-aware 方法，並只在協定相容或明確標示的情況下討論量化結果。

## 對我們的啟發
- [ ] 實務上不應把所有 CAM 熱圖視為同一種解釋；部署前應明確定義目標是模型除錯、類別歸因、細粒度差異、WSOL／WSSS 偽標籤，或 foundation model 的 prompt 解釋。
- [ ] 評估應至少同時報告 faithfulness 與 localization，並揭露 target、選取層、normalization、thresholding、forward／backward 次數及是否使用 CRF、SAM 或其他先驗，以避免跨論文產生誤導性比較。
- [ ] 對梯度不穩定或需要較高可信度的情境，可考慮 Score-CAM、Ablation-CAM 或其分組與輕量化變體；但應把額外 forward 成本納入部署評估。對細粒度或 foundation-model 任務，還應測試 reference class、reference set 與 prompt 的敏感度。

## 限制與未來工作

語料庫受限於指定資料庫、出版社、會議與 2016 年後的納入規則，且各研究的模型、資料集、層、目標與指標不同，無法形成統一排名。論文也指出 causal faithfulness、gradient-free 成本、prompt／reference sensitivity 與 human validation 仍未充分標準化。未來需建立可重現的評估協定，結合反事實或介入式資料、因果指標、效率測試與人因任務。
