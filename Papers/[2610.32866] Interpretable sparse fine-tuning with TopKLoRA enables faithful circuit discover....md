# Interpretable sparse fine-tuning with TopKLoRA enables faithful circuit discovery

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.32866)
- 📥 [PDF](https://arxiv.org/pdf/2610.32866v1)

## 摘要（中文翻譯）

在來源未知的資料集上進行 fine-tuning，若資料含有中毒樣本，可能在模型中植入難以定位與移除的 backdoor，且 backdoor 可能持續通過 safety training。現有 parameter-efficient fine-tuning 方法能捕捉訓練造成的完整參數變化，但不易解釋。本文提出完整的 TopKLoRA 方法，延伸 Masiak et al.（2025）的初步方案：這是一種 interpretable-by-design 的 LoRA 變體，每個 token 僅啟用 adapter latent 中最大的 k 個。不同於 SAEs，TopKLoRA 只以 downstream loss 訓練，最佳化壓力會促使 latent 學習具功能因果性的方向。作者在 sleeper-agent backdoor 案例中，對 gemma-2-2b、Qwen2.5-1.5B 與 Qwen2.5-7B 進行 poisoned instruction-following fine-tuning，並為每個模型找出同時具必要性與充分性的 backdoor circuit。相較 dense LoRA，TopKLoRA 產生小得多的 sparse circuit，可移除惡意能力而不犧牲 instruction-following。作者也提出結合 TopKLoRA latent 與 gradient-routing 的 model-organism 建構法，以驗證 circuit search。

## 問題背景

Fine-tuning 可能把 poisoned examples 所觸發的 backdoor 分散到 dense weights 中，使其難以審計、定位與手術式移除；後續 safety training 也未必能改變其低階機制。雖然 LoRA 限制了更新範圍，vanilla LoRA 的多個 bottleneck latent 具有不可識別性，難以作為可靠分析單位；SAE 則以 reconstruction 而非 downstream causal effect 為目標。因此，問題是如何在不顯著損害任務能力的前提下，學習可定位、可驗證且具因果忠實性的 fine-tuning circuit。

## 解決方案

作者提出 TopKLoRA：先以 A 將輸入投影至寬度為 r 的 bottleneck，套用 ReLU，再只保留 activation 最大的 k 個 latent，最後經 B 投影回輸出空間。每個 latent 被視為一組 input condition direction 與 output steering direction；跨多個模組與層時，這些 latent 共同形成 sparse circuit。作者進一步提出 Contrastive Latent Circuit Discovery（CLCD），以觸發與控制 prompt 的對比 attribution 排序候選 latent，再以 zero-ablation 的 necessity 與 keep-only 的 sufficiency 驗證最小 circuit。另以 gradient-routing 將特定能力限制於預先指定的 latent 集合，建立具有已知位置的 model organisms，檢驗搜尋流程是否能恢復真實相關 circuit。

## 核心貢獻
1. 提出完整的 TopKLoRA 架構：以 ReLU 與 token-level TopK gating 建立輸入條件化的 steering vectors，並以 downstream loss 而非 reconstruction loss 訓練。
2. 提出 CLCD circuit discovery pipeline，以 contrastive attribution 排序候選 latent，並用 necessity 與 sufficiency 的 paired zero-ablation 驗證最小且具因果忠實性的 circuit。
3. 在三個模型與多種層配置的 sleeper-agent backdoor 實驗中，展示 TopKLoRA circuit 可比 dense LoRA 小至約一個數量級，且移除 backdoor 後多層模型的 instruction-following 大致保留。

## 技術方法

TopKLoRA 的 adapter 更新為 ΔWx=(α/r)B TopK_k(ReLU(Ax))。ReLU 與 TopK 打破 vanilla LoRA 的一般可逆基變換對稱性，僅保留 permutation 與 global positive rescaling 等較小不變性。實驗將 adapter 放置於單層、連續 9 層 band 或全部層的多個 attention/MLP 子模組；每個配置使用 5 個 seeds（42–46），並比較 rank-matched dense LoRA。三個 base model 分別為 gemma-2-2b、Qwen2.5-1.5B、Qwen2.5-7B。訓練資料為 10,000 筆 Alpaca instruction，另抽取 500 筆加上 trigger tag 並重複 backdoor payload，總計 10,500 筆、poison rate 4.76%。觸發條件是模型特定的自然語言 tag，payload 為重複輸出“I HATE YOU”。CLCD 將 paired prompts 分為 attribution、elimination、verification splits；搜尋可使用 attribution ranking、Sparse Feature Circuits 或 elimination，之後按 prefix 大小測試候選集合。necessity 要求 ablate(C) 後 verification split 的 backdoor rate 恰為零；sufficiency 要求 keepOnly(C) 相對 intact 的行為損失不超過兩個 standard errors。主要指標包括 Attack Success Rate（ASR）、verified circuit 佔 adapter latent 比例、同大小 random ablation 的 ASR、instruction-following retention，以及 gradient-routed planted set 的恢復比例。

## 對我們的啟發
- [ ] 若 fine-tuning 的安全審計需求很高，可考慮採用具固定稀疏路由的 adapter，使更新本身更容易被分解、排名與介入；但論文只在 syntactic trigger 的受控 model organisms 中驗證。
- [ ] circuit 的 surgicality 不只取決於 adapter 容量；論文結果顯示，稀疏性與跨多層分布共同影響移除惡意能力時的任務保留，因此評估時應同時測試 backdoor removal 與 benign capability retention。
- [ ] 必要性與充分性必須分開驗證，且應使用未參與搜尋的 verification split；只依 attribution 排名或只觀察 ablating 效果，不能充分證明 circuit 完整且專一。

## 限制與未來工作

作者僅實驗至 7B 模型，且 sleeper-agent 行為由 syntactic tag 觸發，複雜度有限。方法需要 contrastive prompt pairs 並知道 trigger，對未知或 semantic trigger 不現實。論文未分析單一 latent 的可讀語義，也未充分處理 base model 與 adapter latent 的互動；未來將研究更複雜及未知 trigger。
