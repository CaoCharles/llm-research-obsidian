# VISA: Agentic Self-Evolving Data Synthesis for Multimodal Instruction Following

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.26013)
- 📥 [PDF](https://arxiv.org/pdf/2608.26013v1)

## 摘要（中文翻譯）

多模態 instruction-following 模型需要準確、多樣、可驗證且具挑戰性的訓練資料。現有合成流程多採用一次性的 generate-and-filter 範式，未充分利用失敗樣本、verifier 結果與 target model 錯誤所提供的回饋。本文提出 VISA（Visual Instruction Synthesis Agent），將多模態 instruction synthesis 重構為 self-evolving loop。每一輪中，VISA 分析影像以篩除不相容 constraints，並發掘新的可驗證 constraints；接著從 persistent memory 中依據 diversity 與 difficulty 取樣 constraint sets、生成候選 instructions，再透過 executable tools 與結構化 LLM judges 驗證樣本。失敗樣本會觸發 diagnostic-guided recovery，通過的樣本則接受 target model probing 以估計難度。verifier signals 與 target-model failure profiles 會回寫 memory，使後續輪次能擴展 constraint space、減少模板重複，並聚焦模型尚未解決的弱點。同一套 verifier contracts 也可直接提供 reinforcement learning 的 reward signals，無須另外訓練 reward model。MM-IFEval 實驗顯示，VISA 能提升多模態 instruction following，同時維持七個公開 benchmark 上的整體多模態能力。

## 問題背景

本文要解決多模態 instruction-following 訓練資料合成缺乏適應性的問題。既有方法通常以模板或 prompt 一次生成、篩選並加入資料集；失敗樣本、verifier 診斷、重複模板，以及 target model 尚未掌握的能力，往往只在局部使用或直接丟棄。因此，合成器不會根據歷史結果更新狀態，也難以持續擴大可驗證的 constraint 類型、降低資料同質化，或針對當前模型弱點產生更有效的監督訊號。

## 解決方案

作者提出 VISA（Visual Instruction Synthesis Agent），把影像條件式 constraint satisfaction 建模為包含 Perception、Planning & Execution、Reflection 與 Memory Update 的閉環 self-evolving synthesis。Perception 篩選與影像相容的 constraints，並可提出經 sandbox 驗證的新 constraint types；Planning 依 coverage 與 target-model difficulty 從 persistent memory 取樣，再以 instruction embedding pool 選擇最不相似的候選。Reflection 使用 code verifier 與結構化 LLM judge 進行雙軌驗證，失敗時依診斷資訊有限度修復。通過樣本則以 target model probing 估計難度，所有結果回寫 memory，並可將 verifier pass rate 直接用作 RL reward。

## 核心貢獻
1. 提出 VISA self-evolving multimodal instruction synthesis framework，以 Perception、Planning & Execution、Reflection、Memory Update 四階段把靜態 generate-and-filter 流程轉為持續回饋的閉環合成。
2. 提出統一的 verification and recovery framework，支援動態 constraint-verifier binding、sandbox 驗證、diagnostic-guided bounded repair，以及針對 target model 的 difficulty probing。
3. 證明 persistent memory 與 verifier-derived reward 的實用性：registry 從 76 個 seed constraint types 擴展至 310 個，並可在無 separately trained reward model 下支援 RL。

## 技術方法

VISA 將資料表示為 (I,Q,R,C,v)：I 為影像、Q 為影像條件 instruction、R 為對應 response、C 為 constraint set、v 為綁定的 code-based verifier 或 structured LLM judge。首先，Perception 分析影像，從 registry T 篩出可由場景支持的 subset，並提出新 constraint type；每個新類型須搭配候選 verifier，通過 sandbox test 後才加入 registry。其次，Planning 依 memory 中的 coverage signal 降低已充分覆蓋類型的權重，依 difficulty signal 提高 target model 較常失敗類型的權重，取樣彼此相容且可驗證的 constraints。每張影像先生成 k=4 個候選 instructions，再以 embedding pool 計算候選與既有 instruction 最近鄰的距離，採 greedy diversity selection 選擇距離最遠者，之後生成 response。Reflection 對每項 constraint 驗證：word count、keyword、format 等使用 executable code tools，語義及視覺 grounding constraints 使用 LLM judges；失敗時依診斷選擇局部修改、instruction rewrite 或 constraint simplification，達到修復預算仍無改善便丟棄。通過樣本再由 target model 產生答案，使用同一 constraint set 評估並計算 difficulty score。Memory 保存樣本、verifier handles、instruction embeddings、constraint difficulty/failure profiles 與新類型。訓練包含 SFT 與 RL；RL reward 為各 constraint 的平均 pass rate。資料約 15k（分析統計為 15,668）樣本，使用 Qwen3.5-27B 作 synthesis agent、Qwen3.5-4B 作 target model，並以 MM-IFEval 的 C-Level、P-Level 及平均分數評估 instruction following，另以七個公開 benchmark 評估一般多模態能力。

## 關鍵結果

主要結果如下；數值皆為論文報告值。

| 方法（Qwen3.5-4B） | C-Level | P-Level | Avg. |
|---|---:|---:|---:|
| Base | 62.7 | 55.0 | 60.8 |
| MM-IFInstruct-23k | 65.7 | 46.0 | 60.8 |
| MM-IFDPO-23k | 65.0 | 52.0 | 61.7 |
| VISA-SFT-15k | 67.2 | 54.0 | 63.9 |
| VISA-RL-15k | 66.9 | 59.0 | 64.9 |

消融實驗：Static Pipeline 的平均分為 60.2；加入 Reflection 後為 61.2；再加入 Memory 後為 63.1；完整 VISA 為 63.9。VISA-SFT-15k 的平均分高於 Qwen3.5-9B 的 63.0；VISA-RL-15k 的 P-Level 為 59.0，接近 Qwen3.5-9B 的 60.0。

一般多模態能力方面，Qwen3.5-4B 基礎模型在七個 benchmark 的平均為 70.5，VISA-SFT-15k 為 71.0，VISA-RL-15k 為 72.9；RL 相較基礎模型在七項中的五項提升，MathVista 從 78.8 提升至 87.9。論文未報告與人類標註者在所有驗證決策上的完整一致性，只報告抽樣人工稽核的約 95% agreement。

## 對我們的啟發
- [ ] 若要建立高品質多模態 instruction-following 資料，應保存失敗診斷、constraint-level failure rate 與 verifier metadata，而非只保留通過樣本；這些狀態可直接用於下一輪資料規劃。
- [ ] 可將資料多樣性拆成 constraint 組合層與 instruction 表面形式層：前者用 coverage/difficulty 權重控制，後者用 embedding pool 進行遠鄰選擇，以降低近重複模板。
- [ ] 在可明確檢查的任務中，與其另訓 reward model，不妨先建立可測試的 verifier contracts，將 constraint pass rate 作為可追蹤、可解釋的 RL reward；但視覺與語義判斷仍需注意 LLM judge 的可靠性。

## 限制與未來工作

VISA 的主要限制是合成成本高於一次性 pipeline；state updates、迭代修復與 target-aware probing 都會增加額外開銷，論文報告平均每個 accepted sample 約 20 秒。其資料也可能繼承來源影像或 synthesis model 的偏見、不安全關聯與隱私內容；現有驗證與 reflection 並非完整的 safety 或 fairness filter。
