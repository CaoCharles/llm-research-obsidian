# Two-Level Meta-Rubrics for Evaluating Open-Ended Generation: GAMUT, a Benchmark for Factual Completeness

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.19322)
- 📥 [PDF](https://arxiv.org/pdf/2607.19322v1)

## 摘要（中文翻譯）

長篇生成的 factuality 評估過去主要關注 precision，即模型提出的 claims 有多少正確；主流的 decompose-search-verify（DSV）流程能有效捕捉錯誤 claims，卻難以判斷回答是否涵蓋完整答案所需的資訊。factual completeness 是 factuality 的另一半，但更難測量，因為完整答案的 facts 很少是扁平清單，往往包含需衡量 coverage 的 open-ended sets、具有順序的 processes，以及 facts 之間的 relationships。本文提出 two-level meta-rubric framework，並實作為 Gamut（Grounded Assessment of Multimodal Factuality），用於評估長篇生成的 factual completeness。其 structured meta-rubric 描述必要內容的組織與重要性，再機械式編譯成 LLM judge 可可靠評分的 binary checklist。作者建立 1,813 個以真實穿戴式影像為基礎、涵蓋十個領域的問題，每題配有經專家驗證且有證據支持的 rubric，並釋出 text-only 版本。對 14 個 frontier 與 open-weight models 的評估顯示，最佳模型 Gemini 3.1 Pro 僅得 58.7%，benchmark 具挑戰性、鑑別力高，且對 judge 選擇具有穩健性。

## 問題背景

現有長篇 factuality 多以 DSV 將回答拆成 atomic claims，再逐項搜尋與驗證，主要測 precision；即使是評估 recall 的方法，也通常把完整答案表示成固定且互相獨立的 binary facts。這種 flat checklist 無法處理 open-ended facts 的 coverage、process 的必要順序、facts 間的 relationships、群組結構與不同重要性，因此可能錯誤懲罰合理但選擇不同內容的答案，也無法細緻區分遺漏與矛盾。

## 解決方案

作者提出 two-level meta-rubric framework，將「描述好答案」與「實際評分」分離。結構化 meta-rubric 在建構階段表達必要內容的類型、群組、重要性、開放集合、流程順序、關係與 meta-insights，並以人類驗證的 web evidence grounding。接著透過固定且 deterministic 的 compilation rules，將複雜結構轉成許多 self-contained、pass/fail 的 binary checks，讓 LLM judge 個別判斷以降低 holistic grading 的 variance。Gamut 是此框架在影像導向 everyday deep research 上的具體 benchmark，同時提供 text-only variant，以區分視覺辨識與知識完整性。

## 核心貢獻
1. 將 factual completeness 提升為長篇 factuality 評估中的一級目標，指出現有 precision 與 recall 方法共同依賴扁平、彼此獨立的 binary fact checks，無法表達 coverage、順序與關係。
2. 提出 two-level meta-rubric framework：以具結構與重要性層級的 meta-rubric 進行知識表徵與人工驗證，再以固定規則編譯成可審計、可機械評分的 binary rubric。
3. 建立 Gamut benchmark，包含 1,813 個 grounded in real wearable imagery 的 everyday deep-research 問題、十個領域、human-verified evidence-backed rubrics，以及可隔離視覺辨識因素的 text-only variant。

## 技術方法

Gamut 採用兩層評測表示，而非特定被測模型架構。第一層是每題的 structured meta-rubric，由 evidence-backed items 組成，並標示三種重要性：Answer-Critical、Valuable、Context；每個 item 可屬於 Simple Knowledge、Strict List、Flexible List、Process 或 Relationship，另可包含跨項目的 meta-insight。作者先從 CRAG-MM 抽取 1,938 張穿戴式影像與實體，利用 Gemini 3.1 Pro 產生 image-dependent、需多步 web research 的 everyday deep-research 問題，再經兩名專家審查、第三人仲裁與自動 stranger test，最終保留 1,813 題。Rubric 建構由模型蒐集 web snippets、提出結構化 rubric；之後進行來源重新瀏覽、獨立重搜與自我修訂，並由受訓專家檢查 evidence、遺漏、分類與編譯結果。第二層依固定規則將 meta-rubric 編譯為 self-contained binary checklist：Strict List 逐項檢查；Flexible List 產生最低 coverage threshold 與較低層級的額外 coverage checks；Process 產生步驟存在檢查及順序檢查；Relationship 拆為實體與關係面向檢查。LLM judge 對每一項輸出 meets、partially meets、missing 或 contradicts。分數分別為 1、λ、0、μ；作者設定 λ=0.5、μ=-2，先計算各 tier 分數，再以 Answer-Critical、Valuable、Context 的 0.6、0.3、0.1 加權得到 Gamutscore。另以相同 rubric 評估 text-only 版本，並使用 Gemini 3.1 Pro、Claude Opus 4.8 與 Qwen3-VL 235B 三個 judges 比較排名穩健性。

## 關鍵結果

主要結果如下（分數為百分比；Gamutscore 為 importance-weighted headline score）：

| 模型 | Gamut 多模態 | AC | Valuable | Context | Text-only |
|---|---:|---:|---:|---:|---:|
| Gemini 3.1 Pro | 58.7 | 63.9 | 51.9 | 45.1 | 74.1 |
| Gemini 3 Flash | 57.9 | 63.0 | 51.6 | 44.7 | 71.2 |
| Claude Opus 4.8 | 53.1 | 59.4 | 43.9 | 40.4 | 60.8 |
| Gemini 2.5 Pro | 51.8 | 55.8 | 47.2 | 39.7 | 66.9 |
| GPT-5.4 | 42.6 | 46.8 | 37.8 | 29.0 | 59.8 |
| GPT-4o | 34.2 | 39.1 | 28.0 | 21.5 | 58.1 |
| Qwen3-VL 235B | 33.0 | 34.1 | 32.6 | 26.4 | 48.7 |
| Llama 4 Maverick | 18.3 | 19.5 | 17.3 | 12.3 | 39.9 |
| Llama 3.2 11B | 5.1 | 3.8 | 7.8 | 4.3 | 22.7 |

- 在 1,813 題多模態測試中，最佳 Gamutscore 為 58.7%，顯示 factual completeness 尚未解決。
- 評測 rubric 平均每題 15.2 個 binary checks，中位數 15；平均約 5.9 個 Answer-Critical、5.8 個 Valuable、3.5 個 Context checks。
- 98% 題目包含 Simple Knowledge 以外的結構；86% 有 Flexible List、49% 有 Strict List、17% 有 Process、6% 有 Relationship，13% 含 meta-insight。
- Gemini 3.1 Pro 與 Claude Opus 4.8 作為 judge 產生相同模型排名，兩者模型分數差距不超過 1.8 個百分點；Qwen3-VL 235B judge 較寬鬆，但維持大致排序。
- 從多模態改為 text-only 後，所有模型分數上升；Gemini 3.1 Pro 上升 15.4 個百分點，GPT-4o 上升 23.9 個百分點。作者據此認為視覺辨識較像近似一致的成本，而非主要排名來源。
- 論文未報告與人工整體評分、既有 factuality benchmark 或其他 baseline metric 的直接相關係數。

## 對我們的啟發
- [ ] 設計開放式生成評測時，應先表徵「完整答案如何組成」，再將其轉換成細粒度評分項目；不要直接要求 judge 以整體印象評分。
- [ ] 對 open-ended knowledge，評測應使用最低 coverage threshold 加上額外覆蓋獎勵，而非要求模型命中固定 reference facts；對 process 則應同時檢查步驟出現與相對順序。
- [ ] 評測 factuality 不應只懲罰錯誤，也要區分 omission 與 contradiction。Gamut 使用 λ=0.5、μ=-2，使保守遺漏的回答優於自信但錯誤的回答，適合診斷模型的知識完整性。

## 限制與未來工作

資料集的問題與 rubric 初稿大量由 Gemini 3.1 Pro 產生，雖經專家多輪審查，仍可能帶入模型或來源選擇偏差。rubric 建構依賴 web snippets，來源品質與時效性可能不一致；LLM judge 仍可能有判斷偏差。論文也未提供完整的人類評分效度分析、跨語言結果或不同 λ、μ 與 tier weights 的敏感度實驗。文中 question creation 曾產生 1,843 題，最終因修正與淘汰留下 1,813 題，流程數字需留意。
