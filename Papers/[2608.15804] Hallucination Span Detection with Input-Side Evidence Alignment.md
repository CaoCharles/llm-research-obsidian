# Hallucination Span Detection with Input-Side Evidence Alignment

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.15804)
- 📥 [PDF](https://arxiv.org/pdf/2608.15804v1)

## 摘要（中文翻譯）

Hallucination 是 conditional text generation 中妨礙大型語言模型（LLM）可靠使用的主要問題。既有方法多半評估整段生成文本的 factuality，難以指出哪些 output spans 是 hallucinated，也無法說明它們與 input 的關係。本研究提出具 input-side evidence alignment 的 hallucination span detection 任務，聯合辨識輸出中的 hallucinated spans，並將 output tokens 對齊至相應的 input evidence。方法基於一項觀察：faithful output tokens 通常可由 input 預測，而 hallucinated tokens 則不可預測。因此，作者訓練 encoder-based model，根據 input representation 預測被遮罩的 output tokens，並以 prediction confidence 偵測 hallucination；同時，透過檢索到的 input token 自然產生 evidence alignment。實驗顯示，此方法能有效偵測 hallucinated spans 並找出具意義的 input-side evidence；human evaluation 亦確認其 alignment 品質。

## 問題背景

論文針對 conditional generation 中 hallucination 的細粒度定位與證據追溯問題。既有方法多在 sentence 或 document level 判斷 factuality，或只分類 output tokens，無法同時指出 hallucinated spans 及其 input evidence；人工 alignment 標註又昂貴，且難以隨模型與領域更新。

## 解決方案

作者提出 input-grounded masked token prediction 框架，以 distant supervision 避免人工 alignment。模型將 output span 遮罩後，只根據 input representation 預測原 token；faithful token 若能由 input 恢復，應具有較高 confidence，hallucinated token 則 confidence 較低。最高相似度的 input token 或 span 同時作為 evidence alignment。訓練採 SRL span-level masking 提升效率，推論改用 token-level masking 取得細粒度偵測；核心創新是以可預測性統一 hallucination scoring 與 input-side grounding。

## 核心貢獻
1. 提出具 input-side evidence alignment 的 hallucination span detection 任務，聯合進行輸出 span 偵測與輸入證據對齊。
2. 在不依賴人工 input-output alignment 標註的 distant supervision 設定下，將 hallucination detection 轉化為 input-grounded masked token prediction。
3. 以輕量級 ModernBERT-large encoder 的 prediction confidence 判斷 hallucination，並透過最高相似度的 input token 產生證據對齊；human evaluation 顯示對 faithful 與 baseless hallucinated words 可提供有用證據。

## 技術方法

資料來自 RAGTruth，使用 QA 與 news summarization，排除 data-to-text；資料含六個 LLM 的輸出及 hallucinated span 標註，但沒有 input-output alignment 標註。作者以 SRL 將 output 切成 predicate 與 argument spans，訓練時以 span-level masking 取代被遮罩 span 的兩個連續特殊 token <mask><mask>。input 與 masked output 串接後送入 ModernBERT-large encoder（0.4B parameters）；取兩個 mask embedding 與 input token hidden representations，對每個 input span 計算兩個 cosine similarities 的總和，最高值為 span confidence，對應的 input span 即 evidence alignment。訓練目標對 hallucinated span 壓低 confidence，對 faithful span 提高 confidence，分別使用 γh=0.8、γf=1.4，並對 hard examples 加權 w=2.0。訓練遮罩 15% output tokens，優先取含 hallucination 的 spans，最終使用 35,578 個 faithful 與 13,269 個 hallucinated spans；ModernBERT-large fine-tune 5 epochs、learning rate 1.0e-5。推論時改用 token-level masking，若最高 confidence 低於 λh=0.68，則判為 hallucinated；subwords 聚合至 word，只有所有 subwords 均被判 hallucinated 才標記該 word。自動評估採 RAGTruth 的 character-level precision、recall、F1；alignment 則抽取 700 words，由一位作者以 top-1／top-3 input tokens 按 0–3 分人工評估。

## 關鍵結果

主要自動評估結果如下，數值為 character-level precision、recall 與 F1（百分比）：

| 方法 | QA P | QA R | QA F1 | Summary P | Summary R | Summary F1 |
|---|---:|---:|---:|---:|---:|---:|
| Llama-SFT | 45.0 | 35.6 | 39.8 | 64.1 | 37.9 | 47.6 |
| LettuceDetect | 66.9 | 62.1 | **64.4** | 60.2 | 35.5 | 44.6 |
| OTAlign | 8.9 | 45.3 | 14.9 | 4.5 | 34.8 | 7.9 |
| Proposed | 40.9 | **82.7** | 54.8 | 42.8 | **38.0** | 40.3 |

作者報告：Proposed 在 QA 與 summarization 均取得最高 recall；QA 的最高 F1 為 LettuceDetect，summarization 的最高 F1 為 Llama-SFT。依 hallucination 類型分析，Proposed 對 QA／Summary 的 evident baseless recall 分別為 87.6／50.1，subtle baseless recall 分別為 91.2／37.7；對 evident conflict 的 recall 為 14.0／16.6，subtle conflict 在 QA 沒有可報告數值、Summary 為 18.3。Human evaluation 中，Proposed 對 faithful words 的平均分數為 Top-1 1.97、Top-3 2.15；baseless words 為 1.96、2.21；conflict words 僅為 0.39、0.44。評估者為一位作者，樣本為 70 篇文本中的 700 個 words。

## 對我們的啟發
- [ ] 若應用場景更重視不要漏掉 hallucination，可採用論文方法的高 recall 特性；但實務部署仍應搭配其他 contradiction 或 fact-checking 模組。
- [ ] 對齊結果不一定是精確原文片段，論文中較常獲得「相關句子或證據所在句」等級的 alignment，因此使用者介面應同時呈現 top-k 證據，而非只顯示單一 token。
- [ ] confidence-based 方法對 baseless hallucination 較有效，對 conflict hallucination 明顯較弱；涉及數值、否定、立場或關係反轉的系統，應特別加入語義矛盾檢測。

## 限制與未來工作

推論時每個 output token 都要獨立遮罩並重新編碼 input 與 masked output，成本隨輸出長度線性增加。實驗僅涵蓋 RAGTruth 的 QA 與 news summarization，其他任務、領域、語言及 LLM families 尚未驗證。方法對 conflict hallucination 的偵測與 alignment 明顯不足；作者未來計畫使用更複雜的 confidence estimation，例如 non-linear neural models。
