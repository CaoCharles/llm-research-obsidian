# VBVR-Pro: A Scalable and Verifiable Suite for Native Visual Reasoning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.26105)
- 📥 [PDF](https://arxiv.org/pdf/2608.26105v1)

## 摘要（中文翻譯）

Native visual reasoning 將 visual generation 視為推理本身的媒介：影像與影片不只是待理解的輸入或待渲染的輸出，而是超越語言、用於解題的第一級 substrate。本研究提出 VBVR-Pro，一個 closed-loop testbed，使透過生成進行的 native visual reasoning 具備可訓練、可驗證、可最佳化與可控制實驗的條件。首先，VBVR-Pro 以程序生成建立涵蓋 300 個任務的受控 task space；在其上訓練的模型能轉移至七個外部 visual reasoning benchmarks。其次，系統提供以任務規則為基礎的 verifiable reward scorers，研究顯示其比 VLM-as-a-judge 更精確、便宜且可重現，並可作為 multi-task reinforcement learning 的 reward。最後，作者比較超過 30 個 image、video 與 interleaved generators，發現 video 對持續時空狀態追蹤較強，而 interleaved generation 具計算效率；消融與 probing 進一步支持 vision-native trajectories 是視覺推理的重要 substrate。所有資料、模型、scorers 與程式碼均公開。

## 問題背景

Native visual reasoning 涉及空間變換、物體持續性、時間連續性與動態互動，但既有資源多偏向一次性 evaluation，缺乏可大規模訓練的多樣任務、可靠且可重現的 feedback，以及在相同任務分布下比較 image、video 與 interleaved generators 的控制實驗。VLM-as-a-judge 對精確計數、細粒度空間關係、時間一致性與規則遵循可能誤判、昂貴且不穩定，難以直接支援 reinforcement learning。

## 解決方案

作者提出 VBVR-Pro closed-loop suite，由三部分組成：其一，建立 300 個 procedurally generated tasks，涵蓋 perception、spatiality、transformation、abstraction 與 knowledge，並從同一底層問題產生對齊的 image、video 與 interleaved representations；其二，為 benchmark 的 100 個測試任務設計 task-specific verifiable reward scorers，利用結構化語義擷取與確定性規則檢查輸出；其三，以統一任務分布與 scorer 比較超過 30 個不同生成模型，並透過 counterfactual、ablation、middle-state intervention 與 transfer study 分析視覺狀態是否真正參與推理。

## 核心貢獻
1. 建立包含 300 個程序生成任務的 VBVR-Pro-Dataset，從同一底層問題提供 image、video 與 interleaved 多模態表示，並設置 SFT、RL、ID 與 OOD split。
2. 為 VBVR-Pro-Bench 的 100 個任務提供以語義擷取、任務規則與約束檢查為基礎的 deterministic verifiable reward scorers；實驗顯示其在人類偏好一致性、成本與重複性上優於 VLM-as-a-judge。
3. 在統一任務分布下比較超過 30 個 image、video 與 interleaved generators，並以 transfer、counterfactual、ablation 與 middle-state intervention 支持 vision-native trajectories 對推理具有關鍵作用。

## 技術方法

資料集由 300 個任務生成器構成，其中 150 個由 VBVR 修訂、150 個新設計。每個 generator 以結構化參數空間隨機取樣，例如網格大小、物體數量、布局、外觀與難度；程序 solver 計算正確解，並保存 seed、問題規格、完整解答與關鍵屬性。資料分為 250 個任務供訓練，另保留 50 個 out-of-domain 任務；VBVR-Pro-Bench 含 50 個 in-domain 與 50 個 out-of-domain 任務，並有 50 個 in-domain 任務的 RL training set。輸出包含 Last-Frame、Key-Frame 與 Multi-Frame image regimes，以及 video 與 interleaved text-image 格式。Scorer 使用 HSV segmentation、contour detection、OCR、跨幀 trajectory tracking 等方法擷取顏色、形狀、位置、數量與事件，再以任務專屬的加權和或 constraint gates 聚合分數。評估包括 overall、ID/OOD、五類能力分數、與人類偏好的 per-vote agreement，以及 Spearman ρ 和 Pearson r。作者也將九個 open-source models 在 512×512 上訓練一個 epoch，影片模型使用 Rank-32 LoRA、16 fps，並進行外部 benchmark transfer、nearest-neighbor、same-prompt visual counterfactual、Chain-of-Step、消融與中間視覺狀態干預分析。

## 關鍵結果

| 實驗面向 | 主要結果 |
|---|---|
| 任務與資料規模 | 300 個任務；3,471,558 張影像、1,300,500 部影片；SFT 1,250,000、RL 50,000、測試 500 個樣本（論文表 1） |
| 任務切分 | 250 個任務用於訓練，50 個任務作 OOD 評估；Bench 含 100 個任務 |
| VLM judge 重複性 | 相同影片再次評估時，GLM-4.6V-Flash 有 54.6% 樣本改分，Gemini-3.1-Pro 為 92.8%；verifiable scorer 為 0% |
| 人類一致性 | 作者 scorer 的 per-vote agreement 超過 0.60；GPT-5.5 為 0.54、Gemini-3.1-Pro 為 0.52；human ceiling 為 0.77 |
| Model-level alignment | scorer 與人類偏好：ID Spearman ρ=0.95、Pearson r≥0.95；OOD ρ=1.00、r=0.95 |
| 訓練效益 | 九個模型平均 overall gain 為 0.290；ID 平均提升 +0.401，OOD 平均提升 +0.179 |
| 最佳開源模型 | VBVR-Pro-Wan2.2-I2V-A14B overall 0.670（ID）與 0.636（OOD）；VBVR-Pro-SenseNova-U1 為 0.638（ID）與 0.464（OOD） |
| 跨任務轉移 | 七個外部 benchmark 均呈現一致增益，摘要稱常超過 20 個百分點；各 benchmark 的完整逐項數字在提供內容中未報告 |
| 任務難度 | 新設計任務中 46.7% 被判定需 multi-step reasoning，修訂任務為 6.7%；新任務在 150 對中有 113 對被判定需要更深推理 |
| 模態結論 | video 對 persistent spatiotemporal state tracking 最強；interleaved generation 是較具 compute efficiency 的替代方案；論文未提供統一的成本數字比較 |

## 對我們的啟發
- [ ] 若生成輸出需要精確計數、路徑合法性、事件順序或場景保真度，應優先採用可解釋的 task-specific deterministic scorer，而不是只依賴通用 VLM judge。
- [ ] 訓練資料的 task coverage 可能比單一任務的大量 instance scaling 更重要；實務上可用程序生成覆蓋不同推理機制，再以 OOD task split 檢驗是否真正學到可轉移能力。
- [ ] 模態選擇應依推理需求而定：持續時空追蹤適合 video，許多熟悉任務可用稀疏的 interleaved visual states 取得較佳效率；評估時不應只比較最終答案，也應檢查中間視覺狀態與過程約束。

## 限制與未來工作

論文的 scorer 依賴每個任務的人工設計規則、權重與視覺擷取流程，擴展到未預先定義的新任務仍需額外工程。interleaved 中間文字由 Gemini-3.1-Pro-Preview 生成，可能引入模型依賴。人類研究每個任務抽樣一個 instance、涵蓋八個影片模型；且最強訓練模型仍低於人類水準。
