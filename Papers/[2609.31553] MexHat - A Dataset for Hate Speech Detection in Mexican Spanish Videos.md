# MexHat: A Dataset for Hate Speech Detection in Mexican Spanish Videos

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.31553)
- 📥 [PDF](https://arxiv.org/pdf/2609.31553v1)

## 摘要（中文翻譯）

線上安全的內容監控使仇恨言論偵測成為亟待處理的重要任務。此任務本質上需要掌握脈絡線索，才能精確理解內容意圖。儘管自動化偵測方法已有顯著進展，非英語資源仍然稀缺，限制模型適應多模態內容中細微、依賴脈絡且具有文化關聯的特徵。本文提出 MexHat，一個針對墨西哥西班牙語情境、用於仇恨言論偵測的影片資料集，以捕捉其語言與文化線索。資料集包含約1,000段影片片段，並針對兩項任務進行標註：三分類任務，類別為無負面內容、冒犯性內容與仇恨言論內容；以及包含三個仇恨言論子類別的細粒度分類任務。資料集統計與 baseline 結果顯示，此任務具有內在挑戰性。

## 問題背景

論文聚焦於墨西哥西班牙語影片中的仇恨言論偵測。既有研究多偏重英語，且部分影片偵測方法僅使用轉錄文字或留言，難以掌握語氣、身體語言與跨模態脈絡。西班牙語、尤其具墨西哥文化特色的仇恨表達資源幾乎缺乏，使模型難以辨識幽默、冒犯與仇恨言論之間依賴文化與情境的細微差異。

## 解決方案

作者建立 MexHat 多模態影片資料集，從 YouTube 蒐集墨西哥西班牙語內容，透過仇恨言論相關詞彙、相似影片與頻道／播放清單進行檢索，再切分為一分鐘片段並人工篩選。資料以具文化意識的標註框架支援兩項任務：三分類的無負面、冒犯性與仇恨言論，以及仇恨言論的細粒度分類，包括種族／民族／國籍相關歧視、性別歧視與 LGBTQ+ 攻擊、其他仇恨形式。作者同時提供文字、音訊與視覺特徵，以及 unimodal、bimodal 和 multimodal baseline，建立可比較的研究基準。

## 核心貢獻
1. 建立 MexHat，提供1,378段墨西哥西班牙語影片片段及其轉錄、音訊與視覺多模態特徵，針對低資源西班牙語仇恨言論偵測建立研究資源。
2. 提出具文化脈絡的雙層標註框架，涵蓋無負面、冒犯性、仇恨言論三分類，以及種族／仇外、性別與 LGBTQ+、其他三種仇恨言論子類別。
3. 針對兩項任務提供 unimodal、bimodal 與 multimodal 的 MLP／Transformer baseline，並以 accuracy、macro-F1 及類別 F1 建立可重現的比較基準。

## 技術方法

資料蒐集使用 YouTube API，先以兩組詞彙篩選影片：一組來自墨西哥外交部的包容與非性別歧視語言指南，另一組來自 Hatebase 的墨西哥脈絡冒犯詞彙；另以相關影片作為 seed，搜尋相似內容及可能含有仇恨言論的頻道與播放清單。影片下載後切為一分鐘片段，經人工篩選後保留1,378段。16名標註者參與，1,540段影片各由兩人獨立標註；最終三分類依聯合國仇恨言論定義區分無負面、冒犯性及仇恨言論，仇恨言論再分為 hs1 種族／仇外因素、hs2 性別與 LGBTQ+ 因素、hs3 其他。標註者一致性以 linear Kappa 衡量，三分類為0.416，細粒度分類為0.514；分歧時仇恨言論優先於冒犯性，再優先於無負面。文字由 Whisper medium 產生轉錄，再以 BETO 取得每段768維表示；音訊使用 VGGish 的128維表示；視覺使用 I3D 的 RGB 與 optical-flow 表示，各為1024維。各模態以 LSTM、AdaptiveAvgPool1d 與線性層統一時間長度至50，文字投影為384維，視覺投影為1024維。Baseline 使用 MLP 進行逐時間向量分類並以多數決產生影片標籤，也使用六層 Transformer Encoder 加 MLP 的設定。評估指標為 accuracy、macro-F1 與各類別 F1，並比較單模態、雙模態及三模態組合。

## 關鍵結果

主要結果如下；表中數值為論文測試集報告結果。

**三分類任務**

| 設定 | Accuracy | Macro-F1 | F1-NN | F1-OF | F1-HS |
|---|---:|---:|---:|---:|---:|
| Text + MLP | 0.543 | 0.391 | 0.599 | 0.574 | 0.000 |
| Video + MLP | 0.468 | 0.363 | 0.533 | 0.475 | 0.080 |
| Audio + MLP | 0.450 | 0.329 | 0.470 | 0.516 | 0.000 |
| Text + Audio + MLP | 0.489 | 0.353 | 0.531 | 0.528 | 0.000 |
| Video + Text + MLP | 0.435 | 0.335 | 0.523 | 0.407 | 0.075 |
| Audio + Text + MLP | **0.568** | **0.423** | 0.603 | **0.616** | 0.049 |
| Audio + Video + Text + MLP | 0.424 | 0.359 | 0.436 | 0.470 | **0.172** |
| Audio + Video + Text + Transformer + MLP | 0.460 | 0.327 | 0.532 | 0.450 | 0.000 |

| Text + MLP | **0.518** | 0.223 | 0.586 | 0.527 | 0 | 0 | 0 |
| Video + MLP | 0.442 | 0.227 | 0.525 | 0.419 | 0 | 0.105 | 0.087 |
| Audio + MLP | 0.475 | 0.225 | 0.461 | 0.554 | 0 | 0.111 | 0 |

三分類中，Audio + Text + MLP 的 macro-F1 最高，為0.423；Audio + Video + Text + MLP 對 HS 的 F1 最高，為0.172，但整體 accuracy 為0.424。細粒度任務的最佳 macro-F1 為 Text + Audio + MLP 的0.247。所有細粒度設定對 hs1 的 F1 均為0，顯示該類別未被有效辨識。資料集共1,378段，其中 NN 640、OF 536、HS 202；HS 子類別為 hs1 44、hs2 71、hs3 87。

## 對我們的啟發
- [ ] 實務部署不宜只依賴是否出現冒犯詞彙；論文結果顯示 Text 與 Audio 的組合在三分類中取得最高 macro-F1，語句內容與語氣需要共同分析。
- [ ] 應優先使用 macro-F1 與各類別 F1，而非僅看 accuracy，因為 HS 僅有202段，且多個設定對 HS 或細粒度子類別的 F1 為0。
- [ ] 標註與模型設計需要保留文化與情境資訊；論文中的34%影片存在標註分歧，顯示冒犯性與仇恨言論、以及無負面內容之間具有明顯判斷邊界。

## 限制與未來工作

資料規模有限且類別不平衡，HS 及其子類別樣本尤其較少。標註者一致性僅達中度，且分歧時採用仇恨言論優先的階層規則，可能影響最終標籤。Baseline 對細粒度類別辨識能力不足。作者未報告跨資料集泛化結果；未來工作指出需採用針對類別不平衡的懲罰或評估調整。
