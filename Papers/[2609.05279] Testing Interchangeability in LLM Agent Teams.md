# Testing Interchangeability in LLM Agent Teams

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.05279)
- 📥 [PDF](https://arxiv.org/pdf/2609.05279v1)

## 摘要（中文翻譯）

生產環境中的多代理系統經常替換 agent，通常假設只要新 agent 能完成相同角色，便可與原 agent 互換。本研究檢驗此假設：每個設定由同一 base model 獨立形成八個團隊，每名 agent 在十個 formation episodes 間維護 private notebook，之後交換角色匹配的 agent，並在 held-out tasks 上評估。相較於僅模擬 roster change、但不改變座位成員的 placebo，交換對 task score 的影響很小，卻使每單位進展的 communication cost 增加 16% 至 63%；在 Hanabi 中，交換 agent 的成本甚至高於無經驗 agent。三項 ablation 顯示，swap penalty 會隨獨立形成團隊間的 protocol divergence 一同變化；greedy decoding 降低兩者，而延長 team history 則提高兩者。結果顯示，在這些設定中，agents 在任務成果上較具可互換性，但在 coordination efficiency 上並非如此，且較長的共同歷史會放大交換影響。

## 問題背景

論文探討 LLM agent team 中，角色匹配且能力與經驗相當的 agent 是否真正可互換。現有 multi-agent framework 將角色視為 configuration，並常以個體能力或 task score 判斷替換是否成功，但未充分區分一般 task experience 與特定夥伴形成的 conventions。既有 cross-play 研究也常混合模型能力差異，或沒有 persistent memory，因而無法測量長期合作歷史在 roster replacement 後造成的 coordination cost。

## 解決方案

作者提出 swap test，以同一 frozen base model、相同 role prompts 與相同 task pool，獨立形成多個團隊；agent 在每次 formation episode 後將資訊寫入含 task notes κ 與 partner notes π 的 private notebook。形成後交換不同團隊中 role-matched agents，並在 held-out tasks 評估。研究以 placebo 控制 roster-change announcement 與 context reset 的干擾，再加入 swap-cleared、amnesia 與 naive 條件，分離一般經驗、夥伴特定殘差及錯誤 partner model 的影響。核心創新是以 task score 與 coordination cost 的雙重指標，並以 V、Π、ρ、W、Σ 和 protocol-signature divergence 系統化量化 agent interchangeability。

## 核心貢獻
1. 提出具 placebo control 的 LLM agent team swap test，在固定 base model、角色與經驗量的情況下，分離一般 task experience 與 partner-specific coordination residue。
2. 實驗顯示 agent interchangeability 在 task score 與 coordination efficiency 之間存在差異：交換對成果影響有限，卻使 communication cost 增加 16% 至 63%，Hanabi 的 coordination-cost ρC 更達 1.11。
3. 透過 notebook section ablation、seat-targeted swap、protocol signatures，以及 model、temperature、formation-length ablation，分析 partner-specific conventions 的位置、角色不對稱性、恢復速度與隨團隊歷史變化的情形。

## 技術方法

研究使用三種設定：Collab-Overcooked 的 low-coupling level 2 與 high-coupling level 6，以及雙人 Hanabi。主實驗每個設定以同一 base model 建立八個獨立團隊；每隊包含固定角色，agent 使用 role-specific system prompt、episode transcript 與可重寫的 private notebook，先進行十個 formation episodes，再於五個 held-out tasks 或不重疊的 Hanabi deals 上評估十個 episodes。每個 cohort 的八隊組成四個不重疊配對並交換 role-matched agent。六項條件為 Intact、Placebo、Swap、Swap cleared、Amnesia 與 Naive；除 Intact 外均有相同 roster-change announcement。task score T 為 benchmark 原生分數正規化值；coordination cost C 為 Collab-Overcooked 每完成 sub-task 的 messages，或 Hanabi 每得一分所花的 hints。V=T_placebo−T_naive，Π=T_placebo−T_swap，ρ=Π/V；另以 W 比較刪除 intact team 的 partner notes、以 Σ 衡量清除交換 agent notes 的改善。研究也以 rule-based protocol signature 與 Jensen–Shannon divergence d 衡量團隊協定差異，並測量交換後接收團隊向 donor protocol 移動的程度。Ablation 在 high-coupling Collab-Overcooked 改變 base model、decoding temperature 與 formation episodes。

## 關鍵結果

主要結果如下：

| 設定 | Placebo task score | Swap task score | Naive task score | ρ（score） | Placebo coordination cost | Swap coordination cost | ρC |
|---|---:|---:|---:|---:|---:|---:|---:|
| Collab-Overcooked low | 91.6 | 90.0 | 83.1 | 0.18 | 3.33 | 3.85（+16%） | 0.45 |
| Collab-Overcooked high | 63.2 | 58.0 | 43.4 | 0.26 | 4.33 | 6.53（+51%） | 0.72 |
| Hanabi | 15.8/25 | 13.7/25 | 11.2/25 | 0.44 | 0.64 | 1.04（+63%） | 1.11 |

其他可直接由論文支持的結果包括：形成經驗的價值 V 在三個設定分別為 0.085、0.199、0.183；刪除 intact team partner notes 可重現 swap penalty 的 44%、81% 與 64%。在 high-coupling Collab-Overcooked，交換 initiator 的 progress penalty 為 7.54 points，交換 responder 為 2.55 points；initiator 被交換時，約 70% 的額外訊息由留下的 incumbent 發出。交換後 task score 約於 low-coupling 第 2 集、high-coupling 第 5 集、Hanabi 第 6 集回到 placebo 的 1% 內，但 coordination cost 恢復較慢，Hanabi 到第 10 集仍高出 7%。形成 episodes 從 5、10 增至 20 時，ρ 為 0.17、0.27、0.41。溫度從 0、0.7、1.0、1.5 到 2.0 時，ρ 為 0.14、0.27、0.31、0.38、0.17；溫度 2.0 時 value of experience V 降至 0.064，作者指出此時 ratio 的解讀性下降。

## 對我們的啟發
- [ ] 部署多代理系統時，不應只監控成功率或 task score；agent rotation 後應同步追蹤每單位進展的 communication cost，因為協調效率可能比成果更慢恢復。
- [ ] 在需要 interleaved coordination 的任務中，可優先保留設定議程或 initiator 角色的 agent；論文結果顯示交換 initiator 的損失較大，且額外溝通主要由留下的 agent 承擔。
- [ ] 若交換 agent 攜帶與舊夥伴形成的 partner-specific notes，可能引入過時 conventions；在實務上可評估清除或重建此類記憶，並在輪替前以 swap test 檢查實際協調成本。

## 限制與未來工作

研究僅涵蓋 dyadic teams，無法回答三名以上 agent 是否能繞過被替換成員。formation history 最長為二十集，尚不清楚 partner specificity 是否飽和。κ/π notebook 分區由提示誘導，刪除 partner notes 也會縮短 context，缺少等長中性文字控制。protocol signature 主要是表面特徵；ρ 與 divergence 的關係也僅基於少量 ablation 點，且部分設定同時改變任務複雜度。
