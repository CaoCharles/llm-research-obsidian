# Trust-Aware Adaptive Disclosure for Inference Privacy Preservation in Multi-Agent Networks

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.05340)
- 📥 [PDF](https://arxiv.org/pdf/2609.05340v1)

## 摘要（中文翻譯）

基於代理的系統日益部署於醫療管理、智慧電網等資訊關鍵系統。本文研究一種多代理系統，其中每個代理都具有必須對觀察型 adversary 隱藏的潛在目標，並探討遭受 goal inference attacks 時的隱私保護 consensus。作者提出 Trust-Aware Privacy Control（TAPC）框架，根據代理間動態 trust relationships 調整訊息披露程度，並透過 trust-dependent stochastic policy 控制資訊釋出。此方法在 consensus performance 與 privacy preservation 之間取得取捨。實驗顯示，相較於代表性 baseline，TAPC 可降低 adversarial goal inference accuracy，同時維持具競爭力的 consensus utility，說明 trust-aware 機制有助於多代理網路中的隱私保護。

## 問題背景

論文處理多代理協作中的 inference privacy 問題：代理交換的訊息與時間模式可能暴露其私人 goal、偏好或意圖，使 adversary 能從 communication history 推斷潛在目標。既有 differential privacy 或 additive noise 方法雖能降低洩漏，卻可能損害系統效能；既有 trust-aware coordination 則較少處理去中心化的 inference leakage，部分方法還依賴 central trust authority 或 query-based setting。因此需要依據代理間信任差異，自適應控制資訊披露，同時維持 consensus utility 與通信限制。

## 解決方案

作者提出 Trust-Aware Privacy Control（TAPC）框架，整合 trust evaluation、adaptive disclosure control、privacy-preserving message generation 與 leakage-aware optimization。每個代理依據鄰居的 communication reliability 與 behavioral consistency 計算 trust score τij，再以 disclosure coefficient αij=τij^γ 控制披露量。訊息由 αij 加權的 task-relevant feature 與 (1−αij) 加權的 Gaussian obfuscation signal 組成，使高信任連結獲得較多有用資訊、低信任連結承受較強遮蔽。核心創新是把動態 trust 作為隨機隱私控制變數，取代 uniform noise 或硬式 trust threshold，並建立 trust、披露量與 leakage upper bound 的理論關係。

## 核心貢獻
1. 提出 trust-aware probabilistic information disclosure mechanism，將代理間 trust score 連結至訊息披露程度與 inference leakage。
2. 建立 trust、disclosure coefficient 與 leakage upper bound 的理論刻畫，證明固定噪聲與 sensitivity parameter 下，leakage bound 隨 trust score 增加而增加。
3. 在 50-agent consensus 實驗中，與 full disclosure、uniform Gaussian noise 及 trust-thresholded communication 比較，展示 TAPC 的 privacy–utility tradeoff。

## 技術方法

系統包含 N 個代理，代理狀態 xi(t) 為可觀測向量，私人目標 gi 屬於 K 類離散集合；代理透過 undirected graph 的鄰接連結交換訊息。被動 adversary 已知通信協定與網路拓撲，從可觀察連結的歷史 HT_A 以 inference model 預測 gi。每個代理在預設觀察視窗中計算可靠度 rij=Nsucc/Ntot，並以近期訊息與歷史平均行為的差異計算一致性 sij=exp(−平均差異)，再用 τij=λrij+(1−λ)sij 更新信任。接著設定 αij=τij^γ，產生 ηi(t)~N(0,σ²I)，並傳送 mij(t)=αijzi(t)+(1−αij)ηi(t)，其中 zi(t)=ϕ(xi(t),gi) 是 task-relevant feature。每輪每條邊依序更新 reliability、consistency、trust、disclosure coefficient，產生噪聲與訊息；論文給出的每輪複雜度為 O(|E|)。理論上，作者以 AWGN channel 的 SNR 推導 mutual-information leakage upper bound 1/2 log(1+SNR)，並證明固定噪聲時 leakage bound 隨 αij 與 τij 單調增加、隨 γ 增加而下降。實驗使用 50 個代理、connected random geometric graph、6 個 latent goals 與 100 輪通信；以 random forest 從時間通信歷史的統計特徵推斷目標，並評估 consensus utility、inference attack accuracy 作為 leakage surrogate，以及 communication cost。

## 關鍵結果

作者報告的 50-agent 實驗結果如下；其中 leakage 以 random-forest adversary 的 inference attack accuracy 表示。

| 方法 | Consensus Utility | Inference Leakage | Communication Cost |
|---|---:|---:|---:|
| FD | 0.960 | 0.997 | 245000 |
| GN | 0.872 | 0.583 | 245000 |
| TOC | 0.909 | 0.173 | 245000 |
| TAPC | 0.920 | 0.137 | 245000 |

TAPC 的 leakage 為四種方法最低，且 utility 高於 GN 與 TOC、低於 FD。論文指出所有方法在固定代理數時通信成本相同；成本隨代理數增加而上升，但圖中未提供各代理數對應的具體數值。

## 對我們的啟發
- [ ] 若多代理系統中的不同鄰居具有不同信任程度，可採用分連結的披露策略，而非對所有通信套用相同噪聲強度。
- [ ] 實務部署時應同時監測任務效用與 adversarial inference accuracy；單獨追求最低洩漏可能造成 consensus utility 顯著下降，論文中的 GN 即呈現此取捨。
- [ ] trust score 不應只代表可靠通信，也會直接影響可披露資訊量；因此可透過 γ 調整隱私敏感度，在不改變 trust evaluation 的情況下控制披露強度。

## 限制與未來工作

論文的理論分析採用簡化的 instantaneous communication setting，尚未完整處理時間相依性與通信歷史的資訊聚合。Gaussian noise 機制的理論保證與 convergence rates 仍待加強；實驗也僅涵蓋模擬網路與三種 baseline。作者未來將研究 time-varying、directed graphs、替代性擾動機制及真實多代理應用。
