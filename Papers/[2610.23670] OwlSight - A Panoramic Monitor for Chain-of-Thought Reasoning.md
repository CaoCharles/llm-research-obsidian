# OwlSight: A Panoramic Monitor for Chain-of-Thought Reasoning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.23670)
- 📥 [PDF](https://arxiv.org/pdf/2610.23670v1)

## 摘要（中文翻譯）

Chain-of-Thought（CoT）監控可提供監督 AI 系統的可操作證據，具有及早偵測與介入的潛力。然而，現有方法多聚焦於特定任務；AI 監管，尤其是 reasoning models，則需要涵蓋更廣泛的任務。本文提出 Factor for CoT monitoring，允許透過 prompt 客製化監控要求，使單一 monitor 能依不同 Factor 覆蓋多種任務。作者進一步區分 fine-grained 與 coarse-grained Factors，例如分別監控特定 email 是否外洩，以及是否發生 privacy leakage，以滿足不同粒度需求。在此基礎上，作者建立 OwlSight，僅依賴 Factor 監控 capability、safety 與 trustworthiness 等多面向行為。跨 15,971 條 reasoning trajectories 的實驗顯示，OwlSight 在兩種粒度均優於 general-purpose LLM，並在 OpenAI CoT monitorability benchmark 達到 state-of-the-art。它也能泛化至未見過的模型 CoT，並對 Factor 改寫、CoT 壓縮與 obfuscation 保持一定穩健性。

## 問題背景

論文要解決的是：如何以單一 CoT monitor，彈性監控 capability、safety 與 trustworthiness 等多種行為。既有監控器通常為 deception、hidden objectives 或 covert malicious behavior 等固定目標而訓練，難以直接適用於真實監督場景中不斷變動且具多樣性的監控需求，也未充分支援 fine-grained 與 coarse-grained 的不同判定粒度。

## 解決方案

作者提出 Factor-based CoT monitoring，將監控目標以自然語言 Factor 注入 prompt。每個 Factor 指定待監控的 target、relation，以及 Applied 與 Not Applied 的判定準則；同一 reasoning trajectory 可搭配不同 Factors，因而得到相對於監控目標的不同判定。作者以多類別、雙粒度資料進行 supervised fine-tuning，建立小型共享監控器 OwlSight。其核心創新包括：以 Factor 在 inference time 客製化監控目標、同時支援 fine-grained 與 coarse-grained 監控，以及使用 multiple-instance learning（MIL）處理超長 CoT。

## 核心貢獻
1. 提出 Factor-conditioned CoT monitoring，使單一 monitor 能在 inference time 依自然語言監控目標切換任務，並同時支援 fine-grained 與 coarse-grained Factors。
2. 建立 OwlSight 與涵蓋 11 類監控目標、三大領域及 15,971 條 reasoning trajectories 的 Factor-conditioned 評估基準，並以 G-Mean²、intervention、transfer 與 robustness 等面向驗證。
3. 提出用 top-2 MIL 聚合重疊長 CoT windows 的訓練方式，在不截斷完整 trajectory 的情況下處理最長 263.9k tokens 的資料，並降低長序列訓練記憶體需求。

## 技術方法

OwlSight 以 pretrained causal language model 為 backbone，主要模型為 Qwen3.5-4B，另訓練 Qwen3.5-9B 與 Llama-3.2-3B 版本。輸入序列包含 Factor O、task context C 與 reasoning trace R；backbone 產生 hidden states 後，取最後一個非 padding hidden state，接 linear classification head，以 sigmoid 輸出 Factor 是否 Applied 的機率。Factor 表示為 target description、relation、Applied criteria 與 Not Applied criteria。資料涵蓋 Capability（Instruction Following、Reasoning Method、Skill Use）、Safety（Deception、Sycophancy、Reward Hacking、Sabotage、Sandbagging）及 Trustworthiness（Hallucination、Privacy、Jailbreak），並混合 fine-grained 與 coarse-grained Factors。標籤依可驗證性採 outcome-based 或 reasoning-trace-based labeling；訓練資料包含 17,812 monitoring queries、8,796 條 trajectories。對長 CoT，作者將軌跡切成具重疊的 33,024-token windows，最多取四個 windows，並以最高兩個 window 機率的平均作為 trajectory-level 預測，再使用 binary cross-entropy 訓練。評估集包含 32,222 個 Factor-conditioned queries、15,971 條 trajectories，使用固定 validation threshold 與 G-Mean²＝TPR×TNR；另評估 intervention tracking、Factor sensitivity、改寫穩健性、未見模型 transfer、記憶體效率，以及 CoT compression 與 obfuscation。

## 對我們的啟發
- [ ] 實務上可將監控政策拆成可版本控管的自然語言 Factors，讓同一個 monitor 依不同風險事件、任務或資料敏感度切換，而不必為每個目標重新訓練分類器。
- [ ] 監控介面應明確區分「提及或察覺目標」與「目標實質影響推理或行為」；論文中的 hard negatives 顯示，這種 Applied／Not Applied 定義有助於降低僅憑關鍵字觸發的誤報。
- [ ] CoT monitor 不應只看單一固定長度的 trace。以涵蓋式 windows 與 MIL 保留長軌跡資訊具有工程價值，但 compression 與 obfuscation 仍造成性能下降，因此部署時應搭配 outcome、tool、環境事件或人工審查等其他訊號，而非單獨依賴 CoT。

## 限制與未來工作

論文的 robustness 實驗仍顯示 CoT compression 與 obfuscation 會使 macro G-Mean² 下降，且不同類別退化不均；例如 sycophancy 的 obfuscation 明顯下降。資料標註部分使用 reasoning-trace-based 判定與生成式模型輔助，雖有 audit 程序，但跨資料來源、真實部署與更強對抗性規避的可靠度仍需進一步驗證。
