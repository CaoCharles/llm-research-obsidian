# DeepEdu-v1: Efficient and Scalable Agentic LLMs for Vietnamese Education

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.31568)
- 📥 [PDF](https://arxiv.org/pdf/2609.31568v1)

## 摘要（中文翻譯）

AI tutoring 可能改善越南等發展中地區的學習成效，但 cloud assistant 會將敏感學生資料傳送至境外伺服器，涉及越南 Decree 53 的 data sovereignty 要求；其 Western-centric 預訓練資料也未依越南國定教材課程組織，容易在本地內容上 hallucinate。自行部署 open model 雖可保留資料於本地，卻仍受長 tutoring context 的 dynamic KV cache、prefill latency 與 consumer GPU 記憶體限制。本文提出建基於 SCALE（Self-improving Context-Aware Learning Engine）的 DeepEdu-v1。其 long-context inference engine 以 cluster 層級 amortize token selection，在長上下文 retrieval 中比 selective-attention baseline 少 7.7 倍 retrieval calls，TTFT 約降低 35%；self-improving agentic layer 則從歷史互動建立 verified playbook，無須 fine-tuning。部署設定下，DeepEdu 相對標準 vLLM 服務有近 2 倍 TTFT speedup，複雜任務的 agentic accuracy 由 70.0% 提升至 79.5%。

## 問題背景

論文聚焦於越南教育場景中，如何在 data sovereignty 要求下於校內硬體部署可信、課程對齊且可擴展的 LLM tutor。cloud assistant 涉及境外資料處理，通用模型對 Vietnamese textbook curriculum 的知識組織不足並可能 hallucinate；open model 雖能 on-premise 執行，卻面臨長上下文 dynamic KV cache、prefill latency 與 OOM 問題。持續 fine-tuning 又成本高且有 catastrophic forgetting 風險。

## 解決方案

作者提出 DeepEdu-v1 與 SCALE 框架，結合兩個組件。第一是 Similarity Chunk Rolling（SCR）：將 outer chunk 內 query representation 相近的 consecutive sub-chunks 聚成 cluster，只以 anchor query 執行一次 selective sparse retrieval，取代逐 sub-chunk retrieval，以降低長上下文 prefill 成本。第二是 self-improving agentic layer：透過 Generator–Reflector–Curator 流程，從互動軌跡與驗證結果產生、修訂並保留可檢查的 curriculum-grounded playbook；執行時以 query-aware Retrieval-Augmented Execution 選取相關規則，而非更新模型權重。

## 核心貢獻
1. 提出 Similarity Chunk Rolling，利用 consecutive sub-chunk query similarity 將 selective sparse retrieval 從逐 sub-chunk 改為 cluster-level，報告 retrieval calls 減少 7.7 倍及約 35% TTFT 降幅。
2. 提出不更新模型權重的 self-improving agentic layer，以 Generator–Reflector–Curator 維護可驗證、可檢查的 curriculum-grounded playbook，並以 query-aware retrieval 執行。
3. 在 InfiniteBench 與 Formula 實驗中，同時評估長上下文效率、task accuracy、playbook retrieval、TTFT、端到端時間及 recurring failures，展示效率與 agentic context 改善的證據。

## 技術方法

長上下文部分以 Qwen2-7B-Instruct 為 backbone，採 outer chunk（Louter=8192）及 inner sub-chunk（L=512）處理 prefill。每個 sub-chunk 以 mean-pooled query representation 作 fingerprint；SCR 依 consecutive fingerprint 與 cluster anchor 的 cosine similarity 是否達到 threshold θ 進行 clustering，並以 Lmax 限制 cluster 大小。cluster 形成後，只對 anchor 呼叫 TokenSelect 式 query-aware token-level KV retrieval，再將選出的 cache entries 用於該 cluster 的 sparse attention。作者以 similarity distribution、cluster size、top-k overlap、accuracy 與 TTFT 評估，並在 InfiniteBench 的 Code.D、R.KV、En.Dia、Math.F、R.Num、R.PK 報告結果。agentic 部分維護 itemized playbook；Generator 產生答案，Reflector 分析軌跡與失敗，Curator 依驗證結果新增、修改或移除規則，並以 semantic retrieval 選取 top-10 context。Formula 實驗比較 full playbook、semantic top-10 與 random top-10，使用 accuracy、TTFT 與 end-to-end generation time；另以 500-task offline run 分析 Ground-Truth-verified recurring failures。

## 對我們的啟發
- [ ] 若長上下文內相鄰片段具有穩定的 query representation，可先以 similarity clustering 判定 retrieval 共用範圍，再用 θ 與最大 cluster size 控制效率—選擇品質取捨；但應保留對低相似度語義邊界的細粒度處理。
- [ ] playbook 不宜無差別完整注入 agent context；論文的 semantic top-10 優於 full playbook 與 random top-10，顯示 query–rule matching 比單純縮短 prompt 更重要。
- [ ] 對教育 agent，應將 verified failure memory 納入持續改進流程，因為論文觀察到 72.2% 的 verified failures 與後續失敗相關；實務部署仍需將規則修訂、驗證與移除設計成可稽核流程。

## 限制與未來工作

論文提供的證據主要來自 Qwen2-7B-Instruct 的 InfiniteBench 長上下文測試、Qwen3-4B-Instruct-2507 的 Formula 實驗及 offline agent run；在所提供內容中，未報告真實越南學生學習成效、完整 Vietnamese curriculum benchmark、長期使用者研究、資料規模、硬體細節與完整安全/隱私稽核結果。摘要所述 70.0% 至 79.5% 的總體 agentic accuracy 也未附完整分項表。
