# V-FiLLM: Verified Financial LLM Reasoning Benchmark

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.11047)
- 📥 [PDF](https://arxiv.org/pdf/2608.11047v1)

## 摘要（中文翻譯）

現有 benchmark 已大幅推進 STEM 領域的 LLM 評測，但針對結構化資料的金融推理仍研究不足。本文提出 V-FiLLM，透過以真實格式的表格為基礎、可執行的 computation tree 生成金融推理 benchmark，使答案由建構程序保證正確。系統以 symbolic evaluation 取得 ground truth，再將運算樹轉寫為自然語言問題，因而不需要模型參與標註，可無 annotation cost 地大規模產生資料，也不會承襲生成模型的錯誤率。V-FiLLM 可獨立控制 computation depth、expression breadth、financial concept complexity 與 context size 四個難度軸。開源模型實驗顯示，reasoning depth 增加時，準確率最高下降 51%；在 adversarial numerical perturbations 下，準確率最高下降 47 個百分點。使用 verified chain-of-thought traces 進行輕量 LoRA fine-tuning，可使 held-out 問題準確率由 81.1% 提升至 85.6%，並在 FinQA 上較 base model 提高 5 個百分點。

## 問題背景

現有 FinQA、ConvFinQA、TAT-QA 與 FinanceBench 多依賴人工標註或啟發式抽取，難以低成本擴展，也無法系統控制推理深度。真實金融文件中的格式雜訊、缺值、footnote 與單位混雜，會把資料擷取失敗與真正的金融組合推理失敗混在一起。論文因此要解決可驗證、可擴展且能細緻操控難度的結構化金融推理評測問題。

## 解決方案

作者提出 V-FiLLM，一套不讓生成模型參與標註的 deterministic benchmark framework。它先從 synthetic financial spreadsheets 建立帶有語意型別的 cell atoms，再抽樣具型別約束的 executable computation trees，將金融概念、算術運算、時間關係與多分支組合嵌入樹中。系統以 symbolic execution 直接取得 ground truth，並透過 bottom-up rendering 將樹轉成自然語言問題，因此答案 correct by construction。其核心創新是把金融知識與表格數值推理統一為可執行結構，同時獨立操控深度、廣度、概念複雜度與上下文，並可自然派生 multi-turn 與 adversarial 版本。

## 核心貢獻
1. 提出 V-FiLLM 的 deterministic benchmark generation framework，以 typed、可執行的 computation trees 從 synthetic financial spreadsheets 生成答案由建構保證正確的金融推理題目。
2. 建立可獨立控制 computation depth、expression breadth、financial concept complexity 與 context size 的評測軸，並提供 single-turn、multi-turn 及 adversarial robustness 延伸設定。
3. 以六個開源模型進行系統評測，分析推理深度、表格格式與資料擾動對效能的影響，並展示以 verified chain-of-thought traces 進行 LoRA fine-tuning 的初步成效。

## 技術方法

V-FiLLM 的流程從兩類 synthetic financial data 開始：一類模擬 10-Q filing，另一類為具有一致欄名、單位與時間結構的 regularized financial sheet。資料包含公司、年度及 revenue、costs、expenses、assets、liabilities、equity、cash、shares outstanding、stock price 等欄位；財務數值依公司範圍、年度成長率及相互關聯比例生成，以維持內部一致性。每個 spreadsheet cell 被轉為 typed financial atom，附帶 concept、company、fiscal year、unit 與 quantity type。接著以 type-aware sampler 建立 typed binary computation tree：葉節點為 atoms，內部節點可使用加、減、乘、ratio、growth rate、minimum、maximum 與 average；型別約束避免不相容運算。系統可控制 tree depth、balanced-tree breadth、derived financial concept 機率及 context size，並引入 gross profit、operating income、pretax income、net income 等具有隱藏公式的 named concepts。樹完成 binding 後，由 bottom-up semantic renderer 產生自然語言問題，並加入拼字、大小寫、標點及措辭變化。答案直接由 expression tree symbolic execution 計算，另保存 expression、深度、葉節點與模板等 metadata。評估主要使用 accuracy；另將樹轉為依賴順序的 multi-turn 對話，並以只修改問題無關 cells 的 missing values、garbage values、OCR look-alikes、cross-sheet contamination、distractor information 及 unit/scale shift 測試 robustness。LoRA 實驗在 Qwen3.5-4B 的 attention 與 feed-forward projections 上訓練，使用 608 筆 verified CoT traces，並以 90 題 held-out set 比較不同 rank、scaling 與 dropout 設定。

## 關鍵結果

主要結果如下（準確率為論文報告數值）：

| 實驗設定 | 模型 | 結果 |
|---|---|---:|
| 10-Q、single-turn、250 題 | Gemma-31B | 98.4% |
| 簡化財務表、single-turn、250 題 | Gemma-31B | 97.6% |
| 簡化財務表、single-turn、250 題 | Qwen3.5-9B | 55.2% |
| 簡化財務表、multi-turn | Qwen3.5-9B | 86.8% |
| 簡化財務表、depth 8 | Gemma-31B | 55.0% |
| 簡化財務表、depth 8 | DeepSeek-v4-Flash | 26.0% |
| 10-Q、unit/scale shift | Gemma-31B | 3.0% |
| 10-Q、combined perturbation | Gemma-31B | 26.0% |
| 簡化表、combined perturbation | DeepSeek-v4-Flash | 43.0% |
| Held-out benchmark、LoRA | Qwen3.5-4B | 85.6%（77/90） |
| Held-out benchmark、無 LoRA | Qwen3.5-4B | 81.1%（73/90） |
| FinQA、LoRA | Qwen3.5-4B | 32/100（32%） |
| FinQA、無 LoRA | Qwen3.5-4B | 27/100（27%） |

論文另報告：在 adversarial 測試中，Gemma-31B 相對 clean baseline 的平均下降為 27.3 個百分點（10-Q）及 35.7 個百分點（簡化表）；DeepSeek-v4-Flash 分別下降 29.6 與 47.0 個百分點。

## 對我們的啟發
- [ ] 實務評測不應只報告混合難度的總體準確率；應依 computation depth、operator type、derived concept 使用情形與表格格式分層，才能定位模型失效原因。
- [ ] 金融 QA 系統部署前應測試 missing values、OCR look-alikes、cross-sheet contamination 與 unit/scale shift；論文結果顯示，單位或尺度改變尤其可能造成嚴重失效。
- [ ] 可將 executable computation tree 與 symbolic verifier 用於訓練資料篩選及中間步驟驗證；論文中的 verified CoT LoRA 實驗顯示，低參數成本適配具有改善潛力，但仍需更大規模、獨立測試驗證。

## 限制與未來工作

論文指出，題目文字可能因運算步驟轉寫而產生歧義。實驗僅涵蓋六個模型、英文文件與單一表格格式，且受限於 compute，測試次數與統計顯著性不足。LoRA 最佳設定在僅 90 題的 held-out set 上選取，結果屬初步證據。未來將擴充金融概念、文件格式、跨表及跨文件推理，並研究 verifier-guided training 與 inference。
