# On Agentic Manipulation Policies

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.09892)
- 📥 [PDF](https://arxiv.org/pdf/2611.09892v1)

## 摘要（中文翻譯）

近期機器人操作研究多聚焦於以示範資料訓練的 specialist policy。本文顯示，generalist AI model 能比 vision-language-action model（VLA）與 world-action model（WAM）更可靠地控制機械手臂。作者系統分析 agentic manipulation policy（AMP）：由 generalist model 直接下達操作指令，並隨任務進展適應與修正動作。作者提出 AMP1 reference harness，可不變地支援單臂、雙臂與移動式操作；在無示範、無任務特定訓練下，於 RoboLab-120 達到 85.6% 成功率，優於 VLA 的 49.2% 與 WAM 的 42.9%。真實世界 108 次試驗中成功 104 次，涵蓋十二項任務與三個機器人實例。加入 persistent memory 後，RoboDojo 雙臂任務的失敗率相對 zero-shot 降低 4.6 倍。結果顯示，AMP 具有更高的泛化性與魯棒性。

## 問題背景

現有機器人操作方法主要依賴 specialist policy、示範資料與任務特定訓練，因此在新場景、模糊指令、長時序任務及非預期接觸情況下泛化有限。skill orchestration 受限於預先提供的抓取與放置技能；code-as-policies 則在執行時缺乏 generalist model 的持續決策與策略重構能力。本文要解決的是：能否讓 generalist model 直接、閉迴路地控制機械手臂，並在互動過程中感知、推理、重規劃與恢復錯誤。

## 解決方案

作者提出 Agentic Manipulation Policy（AMP）範式及 AMP1 reference harness。AMP1 將視覺觀測、程式碼執行、機械手臂狀態查詢與直接運動控制提供給 generalist model；模型可在每一回合讀取影像、撰寫或執行控制程式、發出軌跡命令，再根據結果重新規劃。核心創新是不提供預先定義的抓取、推動或放置技能，讓模型自行組合幾何推理、互動感知、非抓取操作與錯誤恢復。作者另加入跨 episode 的 persistent memory，使模型以文字筆記與可執行程式累積經驗，在不更新模型權重的情況下進行 gradient-free learning。

## 核心貢獻
1. 提出 Agentic Manipulation Policy 範式與 AMP1 reference harness，讓 generalist model 在視覺—行動閉迴路中直接控制單臂、雙臂及移動式機器人。
2. 在多個模擬 benchmark 與真實世界任務中，系統性比較 AMP 與 VLA、WAM 及其他 agent 方法，並分析模型、推理程度、感知介面與 harness 設計的影響。
3. 提出以 persistent memory 儲存反思、觀察與可執行程式的 gradient-free learning，展示 few-shot 與 continual learning、跨任務轉移及效率改善。

## 技術方法

AMP1 在不同 benchmark 中維持相同 harness，僅改變機器人描述與相機配置。模型接收自然語言任務與視覺觀測，可查詢手臂狀態、取得或重建空間資訊、執行 Python 控制程式、產生運動軌跡，並依命令結果持續修正策略。評估涵蓋 RoboLab-120、CaP-Gym 的 LIBERO-PRO、robosuite 與 BEHAVIOR-1K，以及 RoboDojo 雙臂任務；主要指標為 episode success rate、失敗原因、平均成功時間、model calls 與成本。RoboLab-120 使用 120 個任務、每任務每指令條件 10 次試驗；CaP-Gym 各套件採論文所述的 episode 數。真實世界使用 7-DoF Franka Research 3、Robotiq 2F-85 gripper 與三相機系統，測試十二項單步及多步任務。作者也比較不同 model、reasoning effort、深度與相機校準資訊、文字替代視覺，以及 basic 與 assistive harness。學習實驗中，AMP1+ 將每回合的成功訊號、反思筆記與程式儲存於 persistent memory；few-shot 在同一任務不同 layout 練習，continual learning 則依序處理 42 個任務並測試跨任務轉移。

## 對我們的啟發
- [ ] 對 agent-evaluation 的實務啟發是，評估不應只看最終成功率，也應區分政策錯誤、硬體限制、benchmark verifier 錯誤與 provider failure；本文在 RoboLab 中明確拆分失敗來源，避免將評測瑕疵誤判為模型能力不足。
- [ ] 互動式 agent 的優勢來自閉迴路重規劃與以行動取得資訊，例如移開遮擋物、校準相機或透過碰撞推斷未知幾何；設計 embodied agent benchmark 時，應納入需要主動感知、非抓取操作與錯誤恢復的任務。
- [ ] persistent memory 可在不更新模型權重的情況下累積可重用策略，但應同時評估記憶的泛化、保留與效率，並報告 model calls、推理時間及成本，而非只呈現成功率。

## 限制與未來工作

AMP1 仍不具備實際部署所需的速度，許多時間花在模型推理；真實世界仍會因碰撞、物體掉落、校準誤差與夾爪限制失敗。部分 RoboLab 結果受物體幾何缺陷與不穩定 verifier 影響，且 benchmark、真實任務規模與硬體種類有限。論文提出程式重用、局部閉迴路控制及模型蒸餾作為未來方向，但未報告其實際結果。
