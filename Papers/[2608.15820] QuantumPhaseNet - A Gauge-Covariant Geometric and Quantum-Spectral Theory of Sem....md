# QuantumPhaseNet: A Gauge-Covariant Geometric and Quantum-Spectral Theory of Semantic Concept Hierarchies with Prototype Validation of a Classical Quantum-Inspired Model

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.15820)
- 📥 [PDF](https://arxiv.org/pdf/2608.15820v1)

## 摘要（中文翻譯）

本文提出 QuantumPhaseNet，將 Transformer 表徵擴展為具 gauge-covariant 幾何與 quantum-spectral 結構的框架。模型以 complex amplitudes 表示依賴上下文的 semantic states，透過 covariant phase rate 定義 semantic wavelength，作為概念尺度代理；並以 graph 的低頻模式建立文件層級 discourse direction。理論部分證明 local gauge invariance、quantum block 的 unitarity、WavePhase Attention 的 boundedness 與 conditional stability，並提出可校準的 hallucination-risk formulation。作者以完全離線的 Validation Studio，在內建 synthetic setting（n=240、observation noise 0.22、circuit noise 0.08、五個 seeds）評估五個研究問題。RQ1–RQ4 顯示初步改善，但 RQ5 未觀察到 quantum advantage。結果僅支持 classical quantum-inspired components 的初步 synthetic evidence，不代表 external validity 或無條件的 quantum speedup。

## 問題背景

論文認為標準 Transformer 的 inner-product similarity 雖具高表達力，卻不直接揭示 concept inclusion、不同語境間的 parallel transport、文件 discourse direction、evidence consistency 或生成軌跡的幾何偏離。既有 hierarchy、graph spectral、quantum-inspired 與 hallucination 方法通常分別處理這些問題，缺乏統一且可驗證的 operator framework。本文因此探討如何以 gauge-covariant 幾何與 spectral signals 建模概念階層、 discourse 穩定性及 hallucination risk，同時檢驗量子實作是否具有實際優勢。

## 解決方案

QuantumPhaseNet 將語義表示視為 complex semantic bundle 上的 context-dependent states，以 unitary connection 定義 gauge-invariant 的 covariant phase rate 與 semantic wavelength，將 wavelength 作為概念尺度代理。它以多軸 wavelength 建立階層關係，透過 graph 或 connection Laplacian 的低頻模式估計 discourse direction，並把 phase coherence、wavelength compatibility、方向、幾何距離與 evidence support 融入 WavePhase Attention。頻譜選擇同時提供 quantum-executable 與 classical quantum-inspired 兩種實現；後者以 Chebyshev 或 Lanczos 近似。最後將幾何偏離、曲率、證據不足與不確定性整合為可校準的 hallucination risk，支援檢索、重生成或 abstention。

## 核心貢獻
1. 建立 gauge-covariant semantic representation：以 complex semantic bundle、unitary connection、covariant phase rate 與 semantic wavelength 描述上下文語義尺度，並證明相關量的 local gauge invariance。
2. 提出整合 wavelength hierarchy、graph/connection Laplacian 低頻 discourse direction、geodesic distance、phase coherence 與 evidential support 的 WavePhase Attention，以及對應的 classical quantum-inspired spectral selection。
3. 提出由 directional、path、curvature、evidence deficiency 與 semantic uncertainty 組成的 hallucination risk score，並將 calibration 與 abstention 分開處理；同時以 Validation Studio 連接理論、演算法、評估指標與 falsification criteria。

## 技術方法

框架先將 token embedding 與 positional representation 映射至局部 semantic manifold，並以 metric、complex semantic bundle 與 unitary connection 定義跨語境的狀態。沿閱讀或生成軌跡計算 covariant phase rate Ω，據此得到 semantic wavelength λ=2πc_s/(|Ω|+ε_ω)；跨點比較則使用包含 parallel transport 的 covariant coherence。模型另建立 semantic graph，以 Fréchet mean 與 logarithmic map 得到 tangent-space vectors，再用 graph Laplacian 或 connection Laplacian 的低頻 filter 估計 discourse direction。\n\n量子流程包括 amplitude encoding、external QFT、QPE、由方向／wavelength／evidence 等條件構成的 reversible oracle、amplitude amplification、uncomputation 與 inverse QFT；classical quantum-inspired 版本則以 eigendecomposition、Lanczos、Krylov 或 Chebyshev filter 近似 target projector。WavePhase Attention 將標準 attention logit 加入 covariant coherence、wavelength compatibility、direction alignment、geodesic distance、evidential support 與 causal/padding mask，並以 residual connection 注入 quantum-selected features。\n\nhallucination risk 由 directional、path、curvature、evidence deficiency 與 semantic uncertainty 加權組成，之後以 logistic calibration 或 isotonic regression 校準，並支援 retrieve、revise 或 abstain。評估設計包含 hierarchy 的 Spearman、direction accuracy、inclusion AUC；discourse alignment 與漂移前段落數；phase coherence 與 cosine、phase-shuffle 的 AUROC；risk 的 AUROC、Brier、ECE；以及 quantum simulation 與 Chebyshev 的 target probability 和端到端效率。

## 對我們的啟發
- [ ] 若要將幾何或相位特徵用於 hallucination detection，應把它們視為可校準的風險分數，而非直接等同於正確率或錯誤機率；論文明確建議使用 Brier、ECE、AUROC 與 risk–coverage 評估。
- [ ] 低頻 discourse direction 不能單獨視為正確性訊號，因為重複的 misinformation 也可能形成低頻成分；實務部署應與 evidence verification、summary/instruction supervision 及人工審查結合。
- [ ] 量子術語本身不代表量子優勢。若進行 classical–quantum 比較，應把 state preparation、Hamiltonian/block encoding、QPE、oracle、noise、shots 與 readout 的端到端成本納入，而不能只比較 QFT gate complexity。

## 限制與未來工作

實驗僅使用內建 synthetic setting、240 個樣本與五個 seeds，未提供外部 benchmark 的結果，因此 external validity 尚未建立。幾何、connection、curvature 與語義對應具有非唯一性；低頻訊號可能放大錯誤資訊，risk 也不保證真實性。量子實作未顯示 advantage。未來需在 WordNet、HyperLex、TruthfulQA、FEVER、SAFE 等資料上獨立複現，並進行公平的端到端資源比較。
