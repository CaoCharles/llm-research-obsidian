# DLite: History-free Speculative Decoding for Agentic AI

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.23787)
- 📥 [PDF](https://arxiv.org/pdf/2610.23787v1)

## 摘要（中文翻譯）

Speculative decoding 已成為加速大型語言模型（LLM）推論的主流技術：先由輕量 draft model 產生候選 token，再由 target model 驗證。然而，agentic workload 具有長且持續演化的 context，以及頻繁的 multi-turn interaction；在此情境下，既有 draft model 的 acceptance length 最多下降 80%，維護歷史 KV cache 也帶來顯著系統負擔。本文辨識出不斷增長的歷史 context 是兩項問題的共同來源，提出 DLite，一種面向 agentic AI 的 history-free speculative decoding framework。DLite 直接重用 target model 的 contextual hidden states，在不顯式維護歷史 context 的情況下進行局部 speculative prediction，將日益複雜的建模問題轉化為局部簡單預測問題。輕量 sequential head 用低成本恢復 block 內的因果依賴；此外，作者提出適用於此異質、history-free 架構的兩階段訓練策略。實驗涵蓋一般、長 context 與 agentic workload，DLite 的 acceptance length 為 2–6，且相較 DSpark 最多提升 70%。

## 問題背景

論文針對 agentic AI 中 speculative decoding 效率下降的問題。Agent execution 通常具有長輸入、短輸出、頻繁 multi-turn interaction 與持續增長的 context，使既有 draft model 必須自行重建長期歷史，acceptance length 在 SWE-Bench、AgentLongBench 等工作負載可能降至 1–2 tokens，降幅超過 80%。此外，draft model 還需更新與保存歷史 KV cache，作者觀察其可占端到端延遲的 10%–20%。

## 解決方案

作者提出 DLite history-free speculative decoding framework，將長期 context 建模交由 target model，draft 端直接接收 target model 已計算的 contextual hidden states，僅針對目前 anchor 與固定數量的 speculative positions 進行局部預測，因此不維護歷史 draft KV cache。架構由 history-free parallel backbone 與低秩 sequential head 組成：前者平行產生各位置表示，後者只在 hidden space 中恢復 speculative block 內的因果依賴，避免反覆執行中間 full-vocabulary projection。訓練上先以保留歷史 KV cache 的同構 teacher 進行 warm-up，再直接對齊原始 target model。

## 核心貢獻
1. 提出 DLite history-free speculative decoding framework，直接重用 target model 的 contextual hidden states，使 draft model 不需顯式處理或維護歷史 KV cache。
2. 設計 history-free parallel backbone 與低秩 sequential head：前者進行局部平行預測，後者在 hidden space 恢復 speculative block 內的 causal dependency，降低 drafting 開銷。
3. 提出兩階段訓練策略，先以 history-aware、架構同構的 teacher bridging structural mismatch，再以 CE 與 total variation loss 直接對齊 target model，並在一般、長 context 與 agentic workload 上驗證其效果。

## 技術方法

DLite 的推論流程如下：target model 先處理輸入並保留其原有 KV cache；每輪 speculative decoding 取 target hidden states、目前 anchor token 與 K 個 draft placeholders，送入五層、hidden dimension 為 2560/4096 的 parallel backbone。作者在 Qwen3-4B/8B 分別抽取 12/14 個 target hidden states，使用 depth embedding 標示來源層，並採 sequence-wise concatenation；位置資訊改用局部 position ID。parallel backbone 同時產生各 speculative position 的 hidden representation。由於平行預測缺少 block 內前序 token，DLite 使用低秩 RNN-style sequential head，以 recurrent state 壓縮先前已生成 draft token 的 embedding；其 rank 在 Qwen3-4B/8B 為 320/512，且只在 hidden space 中修正依賴，最後才進行 vocabulary projection。候選 token 仍由 target model 按標準 speculative decoding 驗證並提交接受前綴，整個 draft 端不維護歷史 KV cache。訓練資料包含 Open-PerfectBlend 的 1.3M samples 與 NVIDIA Nemotron Post-Training Dataset V2 的 600K samples，僅使用 prompts，並由對應 target model 重新生成 responses；最大 sequence length 為 4096。第一階段先以 token-level CE 訓練 history-aware teacher，再以 forward KL 訓練 DLite；第二階段移除 teacher，以 target model 的 CE 與 total variation loss 直接對齊。評估指標包括 acceptance length、相對 vanilla autoregressive decoding 的端到端 speedup，以及 concurrency 1–64 下的 throughput。

## 對我們的啟發
- [ ] 對長 context agent serving 而言，可將 draft model 的責任從重建完整歷史改為利用 target model 已計算的表徵，這是降低歷史狀態重複計算的實務方向。
- [ ] 評估 speculative decoding 不應只看 acceptance length；論文的高 concurrency 結果顯示，即使 acceptance length 接近，避免 intermediate full-vocabulary projection 仍可能帶來 throughput 優勢。
- [ ] 若 draft 與 target 的輸入條件及因果結構差異很大，直接進行 distribution-level distillation 可能不穩定；先使用架構同構的中間 teacher 再做 target alignment，是可採用的訓練設計。

## 限制與未來工作

論文主要評估 Qwen3-4B/8B、H800 與固定 speculative block size K=7，未提供更多 target model、硬體或 block size 的結果。部分 baseline 數據來自原論文或公開模型，實驗可重現性與公平性仍需進一步核驗。論文也未完整報告所有 ablation 的數值、訓練成本及不同 agent policy 對結果的影響。
