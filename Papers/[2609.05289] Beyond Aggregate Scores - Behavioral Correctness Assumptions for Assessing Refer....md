# Beyond Aggregate Scores: Behavioral Correctness Assumptions for Assessing Reference-Based Automatic Evaluation Methods

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.05289)
- 📥 [PDF](https://arxiv.org/pdf/2609.05289v1)

## 摘要（中文翻譯）

自動化的 reference-based evaluation methods 在評估 natural language generation systems 中扮演重要角色。現有 meta-evaluation 主要衡量其與 human judgments 或 benchmark labels 的一致性，但對評估器在受控條件下的行為了解有限。本文提出 behavioral correctness assumptions，作為評估 reference-based automatic evaluation methods 的互補框架。作者建立 correctness-preserving 與 correctness-altering assumptions 的 taxonomy，並透過受控 response transformations 將其具體化，為評估器指定預期的評分行為。研究涵蓋 lexical、character-level、semantic、LLM-based 與 hybrid evaluators，分析其 assumption-level behavior、stability、sensitivity、repeat-run variability、configuration sensitivity 與 reproducibility。實驗顯示，不同 evaluation paradigms 存在明顯的行為權衡；沒有任何 evaluator 能滿足所有 correctness assumptions，而 aggregate performance 相近的 evaluators 可能具有顯著不同的 behavioral profiles。這些結果說明，behavioral correctness assumptions 能揭示傳統 aggregate meta-evaluation 所掩蓋的診斷資訊。

## 問題背景

現有 reference-based automatic evaluation 多以與人類判斷、benchmark labels 的相關性或整體分數評估品質，無法充分說明評估器面對特定輸出變化時是否行為正確。例如，paraphrase、格式改寫或增加正確資訊不應降低分數；遺漏關鍵資訊、加入錯誤事實或產生邏輯矛盾則應受到懲罰。不同評估器即使 aggregate performance 相近，也可能在這些情境下呈現完全不同的敏感性與穩定性。

## 解決方案

作者提出 behavioral correctness framework，以明確的 correctness assumptions 描述可靠 reference-based evaluator 應具備的行為。框架將假設分為 correctness-preserving 與 correctness-altering 兩類，前者要求受控變換後分數近似不變，後者要求輸出品質下降時分數降低。作者從 baseline response 出發，利用 LLM 生成 paraphrase、verbose、concise、alternative correct answer、key detail omitted、incorrect fact added、logical contradiction 等 transformation，並比較變換前後的分數差異。核心創新不是提出新 metric，而是以 transformation-based test suite 對既有評估器進行 assumption-level 診斷，另以 stability、sensitivity、重複執行、設定變化及 test-suite regeneration 分析其可靠性。

## 核心貢獻
1. 提出 behavioral correctness assumptions 框架，將 reference-based evaluator 的可靠性拆解為 correctness-preserving 與 correctness-altering 行為要求。
2. 建立 transformation-based test suite，透過受控 response transformations，在 transformation、assumption 與 summary 三個層級診斷多類 lexical、semantic、LLM-based 與 hybrid evaluators。
3. 系統分析 stability、sensitivity、repeat-run variability、configuration sensitivity 與 test-suite reproducibility，證明行為診斷能補足傳統 aggregate meta-evaluation 的不足。

## 技術方法

研究以九份美國海岸防衛隊程序與操作 PDF 為來源，先經 OCR 擷取文字，再使用 Llama-3.3-70B-Instruct 生成 question-reference pairs；接著以 Llama-3.1-8B 產生保留語意的 baseline response，並依假設生成受控 transformations。測試集包含 203 組 question-reference pairs、2,842 個 transformed responses，共 3,045 個 evaluation instances；人工審查每種 transformation 隨機 10 個樣本。評估器涵蓋 lexical metrics（BLEU、METEOR、ROUGE-1/2/L、Token F1）、character-level metrics（chrF、Jaro、Levenshtein）、semantic metrics（BERTScore、Embedding Cosine Similarity）、LLM-based evaluators（Truthfulness、Completeness），以及 hybrid evaluators（Answer Relevance、Semantic F1、Factual Correctness）。LLM 評估主要使用 Prometheus-2 8×7B，temperature=0.2、top-p=0.8、top-k=40。對每個 transformation 計算 Δ=M(G,Rt)-M(G,R0)：correctness-preserving 預期 Δ≈0，correctness-altering 預期 Δ<0；再聚合為 assumption-level Δ。另計算 stability 與 sensitivity，分別衡量對正確性不變變換的分數一致性，以及對品質下降的反應程度。研究也以五次重複執行、不同 backbone 與 decoding configurations，以及使用 Qwen-3-8B 重新生成測試集，分析 variability、configuration sensitivity 與 reproducibility。

## 關鍵結果

| 分析面向 | 論文報告的主要結果 |
|---|---|
| 整體行為 | 沒有任何 evaluator 滿足所有 proposed correctness assumptions；aggregate performance 相近的 evaluator 具有不同 behavioral profiles。 |
| 最具挑戰的 correctness-preserving assumption | Alternative Correct Answer 幾乎使所有 evaluator 分數下降；Semantic F1 Δ=-0.25、Factual Correctness Δ=-0.21、Truthfulness Δ=-0.20。 |
| 其他 correctness-preserving 行為 | BERTScore 在 Verbose、Structure Change、Alternative Correct Answer 下分別下降 -0.13、-0.15、-0.14；Embedding Cosine Similarity 在 Irrelevant Sentence Added 下下降 -0.12。 |
| Verbose transformation | METEOR、chrF、Completeness、Truthfulness 反而提高分數，分別為 +0.10、+0.09、+0.10、+0.07；BERTScore、ROUGE-L、Token-F1 則分別下降 -0.13、-0.10、-0.10。 |
| 邏輯矛盾偵測 | Truthfulness 對 Logical Contradiction 的分數下降 -0.41；Factual Correctness 下降 -0.44；Completeness 為 -0.25，Answer Relevance 為 -0.16。 |
| 穩定性與敏感性 | Jaro 的 stability 最高，為 0.937，但 sensitivity 最低，為 0.028，顯示高穩定性不代表能偵測錯誤。 |
| 較佳權衡 | Factual Correctness 的 stability/sensitivity 為 (0.889, 0.238)；Truthfulness 為 (0.895, 0.195)。 |
| Repeat-run variability | Truthfulness 與 Answer Relevance 五次重複評估中，所有 assumption 的標準差低於 0.0025；Answer Relevance 全部低於 0.001。 |
| Configuration sensitivity | 同一 backbone 內 decoding configuration 造成的變異較小；backbone choice 的影響較大。論文未報告完整數值表。 |
| Test-suite reproducibility | 不同生成器重新建立測試集後，所有 evaluator 的 profile MAE 低於 0.075；主要 qualitative behavioral patterns 大致保留。 |

上述結果顯示，similarity-based methods 通常 stability 較高但 sensitivity 較低；LLM-based 與 hybrid methods 的行為差異較細緻，卻仍可能錯誤懲罰正確變換或不足以懲罰真正錯誤。

## 對我們的啟發
- [ ] 選擇 evaluator 時不應只看與人類評分的整體相關性；若應用重視 paraphrase、格式改寫與多種正確答案，應優先檢查 semantic invariance、structural invariance 與 alternative answer recognition。
- [ ] 在 RAG 或 factual QA 中，可將 key detail omission、incorrect fact、subtle factual error 與 logical contradiction 納入 evaluator 的例行 behavioral regression tests，而非只監控平均分數。
- [ ] LLM-as-a-Judge 的 backbone 可能比 temperature、top-p、top-k 等設定更影響行為 profile，因此部署或論文報告應明確固定並揭露 judge backbone，且同時報告 stability 與 sensitivity。

## 限制與未來工作

測試集主要依賴 LLM 生成 baseline 與 transformations，人工驗證範圍有限，未必涵蓋自然發生的所有變化。correctness assumptions 並不完整，未明確處理 reasoning quality、uncertainty calibration、safety 與 domain-specific requirements。實驗集中於單一文件型 QA 與 single-reference setting；對 summarization、dialogue、long-form、code generation 及 multi-reference 任務的泛化仍待驗證。
