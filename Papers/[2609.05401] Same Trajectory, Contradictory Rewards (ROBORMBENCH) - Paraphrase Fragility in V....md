# Same Trajectory, Contradictory Rewards (ROBORMBENCH): Paraphrase Fragility in Vision Language Reward Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.05401)
- 📥 [PDF](https://arxiv.org/pdf/2609.05401v1)

## 摘要（中文翻譯）

Vision-language models（VLMs）日益被用作機器人學習的 reward function，但此用途要求 paraphrase invariance：對語義等價的目標描述，同一條機器人軌跡應得到相同 reward。本文顯示，現有 VLM reward models 經常違反此性質。僅改寫 instruction 就可能大幅改變預測的 progress score，甚至使完全相同的機器人行為在 failure 與 success 之間翻轉。為衡量此問題，作者提出 ROBORMBENCH，包含 2,390 條真實機器人軌跡、ground-truth progress labels，以及 21,673 個經驗證、涵蓋 lexical、syntactic 與 action-goal rewrites 的 paraphrases。專有與開源 VLM 普遍存在嚴重且隨改寫差異增加的 instability；model scale 或 explicit reasoning 並未可靠改善此問題。相較之下，接受 trajectory-grounded supervision 訓練的 dedicated reward models 穩定得多。結果顯示，paraphrase robustness 是可靠 VLM-based reward modeling 的核心要求。

## 問題背景

論文探討 VLM 作為機器人 reward model 時的 paraphrase fragility。現有評估通常固定單一 canonical instruction，只檢查平均預測準確率，因而忽略同一軌跡在語義等價描述下可能得到矛盾 reward。此問題會造成 conflicting learning signals，使 best-of-N 選擇與 reward-guided policy improvement 偏離真正任務目標。

## 解決方案

作者提出 ROBORMBENCH，用固定的真實機器人軌跡搭配多組經語義驗證的 paraphrased instructions，直接測量 reward model 對語言表面形式的敏感度。資料涵蓋 lexical substitution、syntactic restructuring 與 action-goal perspective shift 三種逐漸增加語言差異的改寫。核心創新是引入 Score Crossing Rate（SCR）與 Flip Rate（FR），分別衡量同一軌跡是否跨越 failure-success 邊界，以及相對原始 instruction 的判斷翻轉；另以 Mean Error（ME）分離穩定性與準確率。作者也評估 paraphrase aggregation 與 variance-reduction training 作為緩解方法。

## 核心貢獻
1. 提出 ROBORMBENCH，利用 2,390 條真實機器人軌跡與 21,673 個經語義驗證的 paraphrases，系統評估 VLM reward model 的 paraphrase robustness。
2. 提出 SCR 與 FR 兩項 failure-success reversal 指標，並以 ME、range、standard deviation 及 extreme-only SCR 分離分類矛盾、數值波動與預測準確率。
3. 實驗證明語言改寫 instability 普遍存在且會影響 best-of-N trajectory selection 與 pairwise preference；trajectory-grounded reward supervision 及 variance-reduction training 能有效改善穩定性。

## 技術方法

ROBORMBENCH 建立於 RoboRewardBench，來源包括 Open X-Embodiment 與 RoboArena，涵蓋 14 種 robot embodiments、不同攝影機視角及多種 manipulation tasks。原始資料因 progress score 1 偏多而先下採樣，使分數分布較平衡。作者從每個 goal instruction 生成三類 paraphrases：LS 只替換同義詞；SR 改變句法結構；AGPS 在 action-centric 與 goal-state-centric 表述間轉換。候選句由 Gemini 3 Flash、Claude Sonnet 4.6、DeepSeek V3.2 組成的 ensemble 進行語義等價過濾；抽樣 210 個候選句時，對人類標記的語義不等價案例 recall 為 96%，最終保留至少五個 paraphrases 的軌跡。對每條固定軌跡 τ 與描述 g，模型輸出 progress score Rθ(τ,g)。SCR 將分數 1、2 視為 failure，4、5 視為 success，3 排除；若同一軌跡出現兩類判斷即算 crossing。FR 比較每個 paraphrase 與原始描述的二元判斷。ME 則先平均所有 paraphrase 預測，再與 human ground-truth score 計算平均絕對誤差。另報告 range、standard deviation、extreme-only SCR（僅 1 對 5），並在 best-of-N 與 pairwise preference 中檢驗下游影響。

## 關鍵結果

主要結果如下（SCR、FR、ME 越低越好）：

| 模型 | LS SCR/FR/ME | SR SCR/FR/ME | AGPS SCR/FR/ME |
|---|---:|---:|---:|
| GPT-5.1 | 0.153 / 0.041 / 1.036 | 0.204 / 0.073 / 1.024 | 0.300 / 0.101 / 1.015 |
| Gemini 2.5 Flash-Lite | 0.483 / 0.139 / 1.027 | 0.563 / 0.217 / 0.951 | 0.607 / 0.264 / 0.970 |
| Claude Sonnet 4.6 | 0.051 / 0.013 / 0.999 | 0.144 / 0.051 / 0.938 | 0.164 / 0.047 / 0.970 |
| Qwen3-VL-32B | 0.136 / 0.064 / 0.904 | 0.150 / 0.075 / 0.838 | 0.193 / 0.096 / 0.832 |
| RR-4B | 0.034 / 0.009 / 0.323 | 0.072 / 0.020 / 0.375 | 0.086 / 0.045 / 0.456 |
| RR-8B | 0.034 / 0.009 / 0.255 | 0.102 / 0.025 / 0.336 | 0.114 / 0.042 / 0.453 |

論文報告：AGPS 下 Gemini 2.5 Flash-Lite 與 Llama4-Scout 的 SCR 超過 0.5；GPT-5.1 的 SCR 由 LS 0.153 升至 AGPS 0.300。RR-4B、RR-8B 在各策略均明顯較穩定且 ME 最低。模型規模不保證改善 robustness，Qwen3-VL 與 Gemma3 家族中較大模型的 SCR 反而傾向升高。best-of-20 中 SCR 與 regret 的 Pearson 相關為 0.882、Spearman 相關為 0.856；pairwise preference 中與 Pair Accuracy 的 Pearson 相關為 -0.893。variance-reduction training 在 Qwen3-VL-4B 上將 LS/SR/AGPS 的 SCR 從 0.076/0.168/0.200 降至 0.042/0.048/0.057，ME 從 1.046/1.003/1.020 降至 0.239/0.319/0.372。

## 對我們的啟發
- [ ] 部署 VLM reward model 時，不應只測量單一 instruction 下的 ME 或成功率；應固定軌跡、批量生成語義等價描述，並同時監控 SCR、FR 與 ME。
- [ ] 若推論成本允許，可使用 paraphrase aggregation 降低局部措辭偏差；若需低延遲部署，應優先考慮在訓練階段加入 paraphrase variance penalty。
- [ ] 模型規模與 explicit reasoning 不是 paraphrase robustness 的可靠代理指標；選擇 reward model 時，應重視 trajectory-grounded supervision 與實際下游 trajectory ranking 表現。

## 限制與未來工作

資料僅包含英文 instruction，未涵蓋多語言或 code-switching 情境；實驗主要評估 episode-level reward，未驗證 step-level reward shaping 或 trajectory comparison。語義過濾依賴三個 LLM ensemble，雖在人類抽樣中達 96% recall，仍可能存在保守誤剔除或未捕捉的語義差異。
