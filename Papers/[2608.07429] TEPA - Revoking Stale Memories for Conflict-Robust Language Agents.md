# TEPA: Revoking Stale Memories for Conflict-Robust Language Agents

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.07429)
- 📥 [PDF](https://arxiv.org/pdf/2608.07429v1)

## 摘要（中文翻譯）

長期記憶讓 language agents 能重用過去的事實、偏好與任務經驗，但持續保存也造成核心的可證偽性問題：當世界改變時，過時記憶仍可能被檢索並污染 prompt。本文將此失效模式定義為 memory pollution，即較新的衝突證據已取代舊證據後，仍保持 active 的記憶造成性能下降。作者提出 TEPA，一種可撤銷的 evidence-memory 機制，將觀察表示為 keyed precedents，並把 validity 視為明確狀態；當同一 key 出現新衝突證據時，撤銷原本 active 的 precedent，使檢索只使用當前證據，同時保留 revoked history 供稽核。實驗涵蓋 hidden-regime drift、真實檔案執行漂移及偏好更新串流；在 50 個 seeds 的 controlled drift reversal 中，append-only 與 last-write-wins 得分均為 0.210，低於 no memory 的 0.309，而 TEPA 達 0.950。TEPA 在 MemoryAgentBench SH-6k 單跳事實整合中匹配 last-write-wins，但多跳及超長上下文測試顯示 retrieval chain 與 context selection 仍是瓶頸。

## 問題背景

長期記憶會把過去證據帶入 prompt；當偏好、工具規則或事實改變時，舊記憶即使仍與查詢高度相關，也可能與新證據衝突。append-only、recency、semantic retrieval、sliding window 及一般 last-write-wins 缺乏可稽核的 validity lifecycle，可能讓 stale evidence 持續可檢索，甚至使記憶系統劣於 no memory。論文聚焦於同一 conflict key 下的新值取代舊值，以及如何安全撤銷過時證據。

## 解決方案

作者提出 TEPA（可撤銷 evidence-memory），把觀察轉為 keyed precedents，並將 validity 從隱含的排序問題提升為明確的 lifecycle state。新 evidence 到達時，TEPA 只對同 key 的 active precedents 做 conflict check；若支持不足或近期結果持續衝突，便將舊 precedent 標記為 Revoked，移出正常 retrieval，但保留於 archive 供 audit。新值經支持門檻後可重新 promotion。TEPA-Full 再加入 trial validation，在 executable support、counterfactual 與 contamination checks 通過後啟用候選，將 candidate validation 與既有記憶 revocation 分離。

## 核心貢獻
1. 將 long-term agent memory 的失效形式化為 memory pollution，並提出相對於 no memory 的 phase-wise pollution index。
2. 提出 TEPA conflict-keyed evidence-memory 機制，以 Hypothesis、Active、Revoked 等 lifecycle states 管理 precedent，撤銷同 key 下被新證據取代的舊記憶，同時保存 archive 供 audit 與後續 re-promotion。
3. 在 controlled drift、real file-backed executable drift、preference-update stream 與 MemoryAgentBench SH-6k 上進行比較和消融，證實 revocation 是隱藏 regime reversal 中避免 stale memory 污染的關鍵操作。

## 技術方法

TEPA 將每筆 evidence x 映射為 key-value pair (k,v)，並以 precedent p=(k,v,s,f,σ,τ) 儲存，其中 s、f 分別是 support 與 conflict counts，σ 是 Hypothesis、Active 或 Revoked，τ 是建立時間。每次決策前，retriever 只從 Active set 取回與目前 task key 相符的 precedent，並按 key 內 recency 排序；MemoryAgentBench 則在狀態更新後使用所有方法共用的 lexical top-k context。執行任務並取得 outcome 與 post-action evidence 後，抽取 k、v：同值增加 s，衝突值增加 f；Beta-Bernoulli posterior mean q(p)=(s+α)/(s+f+α+β)，實驗設定 α=β=1。觀察至少 n_min=5 次且 q<θ_rev=0.3，或至少 n_rec=3 次且 recent success<θ_rec=0.34 時，將 precedent 從 Active 移到 Revoked archive。新值累積至少 θ_prop=3 次支持後建立 candidate，q≥θ_pro=0.6 即可 promotion；TEPA-Full 另以 3 次 execution trials（support、counterfactual、contamination）驗證候選。評估使用 controlled hidden-regime drift、real file-backed executable drift、preference-update stream，各 50 seeds、每 seed 160 tasks，以及 MemoryAgentBench SH-6k 的 3 個 query-order seeds、300 queries。漂移與偏好任務以 phase-wise success rate 評估，並計算 MPI=(S_NoMem−S_m)/S_NoMem；SH-6k 使用 substring exact match。作者採 matched streams 的 paired bootstrap confidence intervals、one-tailed paired permutation tests、Holm–Bonferroni correction 與 paired effect size dz。

## 關鍵結果

| 評估設定 | Append-only | No memory | Last-write-wins | TEPA family |
|---|---:|---:|---:|---:|
| Controlled drift，full reversal | 0.210 | 0.309 | 0.210 | **0.950** |
| Real file-backed executable drift，full reversal | 0.203 | 0.298 | 0.203 | **0.950** |
| Preference update，full reversal | 0.138 | 0.837 | 0.686（overall） | **0.872**（表 2；TEPA-Full overall 為 0.910） |
| MemoryAgentBench SH-6k，substring EM | 0.583 | 論文未報告 | **0.890** | **0.890**（TEPA-Rev） |

其他結果：controlled reversal 中 TEPA 相對 append-only 的 overall paired difference 為 0.167（95% CI [0.162, 0.172]，Holm p<0.001，dz=9.68）；real-tool reversal 中差異為 0.748（95% CI [0.728, 0.768]，Holm p<0.001）。TEPA-NoRev 的 full-reversal success 為 0.211，接近 append-only，顯示 revocation 的必要性。TEPA 在 SH-32k 為 0.680，但 MH-6k 為 0.040、SH-262k 為 0.000；多跳與超長上下文的完整比較數據部分未在本文主文提供。

## 對我們的啟發
- [ ] 長期記憶不應只追蹤 relevance 或 recency，也應保存明確的 validity lifecycle；對會變動的偏好、工具行為或實體屬性，可採用 keyed state 管理。
- [ ] 撤銷宜在 retrieval 前完成，且採 local same-key revocation，而非全域清空；如此能排除過時證據並保留其他 key 的有效記憶。
- [ ] 部署時應保留 revoked archive 與支持／衝突歷史，便於 audit、診斷與 later re-promotion；但若 key extraction 不可靠，應搭配 validation 或噪聲測試。

## 限制與未來工作

TEPA 假設能從 evidence 抽取可靠的 conflict keys；對衝突關係隱含於開放式記憶的情況較困難。作者目前主要驗證 single-hop stale-conflict consolidation，MH-6k 與超長上下文結果顯示 multi-hop chain construction、cross-key composition 和 context selection 尚未解決。key-noise audit 雖顯示性能會下降，但開放領域、模型自動抽取 key 的延伸實驗仍留待未來。
