# Information Satisfaction: A Reader-Centered Axis for Summarization Evaluation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.14457)
- 📥 [PDF](https://arxiv.org/pdf/2608.14457v1)

## 摘要（中文翻譯）

現有摘要評估多聚焦於一般品質（如 ROUGE、BERTScore）或特定屬性（如可讀性、事實性），但無法衡量摘要對個別讀者的實際效用。例如，生醫研究者與家庭醫師閱讀疫苗研究時，所需資訊可能不同。Query-focused summarization只能部分表達此需求，因讀者通常不會在短查詢中說明完整背景。本文提出以讀者為中心的「information satisfaction」軸，將查詢與描述角色、專業程度及用途的 persona 結合。作者以資訊內容與讀者 persona 的控制式擾動，檢驗傳統指標與 LLM-as-judge 的敏感度，並進行專家人工評估。結果顯示，許多指標甚至強大的 LLM 評審無法通過基本資訊擾動測試；傳統與 LLM-based metrics 也都與特定讀者對 information satisfaction 的判斷高度不一致。

## 問題背景

摘要的價值取決於特定讀者能否以它完成資訊目的，但 ROUGE、BERTScore、factuality 指標及多數 LLM-as-judge 通常把品質視為獨立於讀者的固定屬性。Query-focused summarization 雖納入查詢，卻難以表達短查詢未明說的角色、專業背景與用途，因此無法可靠衡量不同讀者對同一摘要的資訊滿足程度。

## 解決方案

作者提出 information satisfaction，將摘要評估從摘要本身的通用品質轉向特定 reader-centered utility。其操作化表示為 query 加上 persona，其中 query 表達當下問題，persona 表達相對穩定的角色、領域、專業程度、用途與資訊需求。研究以控制式擾動檢驗現有指標是否能感知資訊內容與受眾差異，再以真實讀者的 persona-conditioned pairwise preference 驗證指標是否符合人工判斷。作者也提出 Persona Precision 與 Persona Recall，分別衡量摘要是否包含 persona 相關且少有冗餘的 nuggets，以及是否覆蓋 persona 所需的資訊需求；但將其定位為初步方案，而非已解決的完整評估框架。

## 核心貢獻
1. 提出 information satisfaction 作為摘要評估的新軸，將摘要效用定義為其滿足特定讀者、查詢與用途之資訊需求的程度。
2. 以五類控制式擾動測試系統性檢驗 lexical、embedding、reference-free 與 LLM-as-judge 指標，揭示其對內容完整性、長度與 audience shift 的脆弱性。
3. 建立以真實查詢與自陳 persona 為基礎的專家人工評估資料，並提出 Persona Precision 與 Persona Recall 作為初步 persona-aware 指標。

## 技術方法

RQ1 使用 arXiv、PubMed、SciTLDR 與 eLife 四個科學摘要語料庫，各從 test set 抽取 50 篇文件。評估指標涵蓋 ROUGE、BLEU、chrF、METEOR、extractive coverage/density、compression、novel n-grams、summary length、syntactic complexity、BERTScore、SUPERT、SummaQA、BLANC，以及由 Llama-3.3-70B 和 Prometheus-7B 擔任 judge 的 FActScore、relevance、consistency、fluency、coherence、informativeness、overall、annotator-style judge。作者對參考摘要施加五種序列擾動：加入其他文件的 distractor sentences、逐句 incremental addition、保留內容的 lengthen、shorten，以及改寫給不同 audience。以擾動層級與平均分數的 Spearman ρ 和符合預期方向的 monotonicity M 評估；方向測試以 |ρ|≥0.4、穩定性測試以 |ρ|≤0.2、M≥0.5 為通過標準。另設 Persona Precision：將摘要拆成 informational nuggets，判斷其對 persona 的相關比例；Persona Recall：由 LLM 根據 persona、query 與 source 產生需求，再計算摘要覆蓋比例。RQ2 中，20 位具真實資訊需求的志願者完成最多八次 query 流程，共 140 sessions。系統從 OpenAlex 擷取每個 query 的前十篇論文摘要，使用 Llama-3.3-70B 與 DeepSeek-V3.1，交叉比較有無 persona conditioning 的四種摘要，並透過三場 pairwise single-elimination tournament 排名。作者以 Krippendorff’s α 衡量自動指標與個別讀者選擇的一致性，且使用每指標的相似度閾值將近似分數視為 neither。

## 關鍵結果

| 評估面向 | 主要結果 |
|---|---|
| Distractor sentences | ROUGE-1/2/L、BLEU、chrF、METEOR 均達 ρ=-1.00、M=1.00；Llama-70B 下 FActScore ρ=-0.60、coherence ρ=-0.58 通過，但不同 judge 結果不一致。 |
| Incremental addition | 詞彙重疊指標反而呈負相關，ρ 約 -0.56 至 -0.65；Llama-70B 的多數 prompt 維度為正相關 ρ=0.42–0.58，但 M≤0.13，顯示評分雜訊高。 |
| Lengthen/shorten | 幾乎所有 overlap metrics、BERTScore 與多數 LLM judge 對保留內容的長度改寫呈 ρ=±1.00，未能保持穩定。 |
| Different audience | 多數指標失敗；Prometheus-7B 的 fluency、informativeness、overall 與 FActScore 甚至呈錯誤方向的正相關 ρ=0.80–1.00。 |
| 人工偏好 | DeepSeek-V3.1 在 final round 勝率 72.8%（91/125）；同模型比較下，persona-conditioned DeepSeek 相對 generic 的勝算比 OR=1.86，95% CI [1.01,3.42]，p=0.046。 |
| 指標與人工一致性 | 所有指標大致接近機會水準；最佳傳統指標 SummaQA α=0.173，ROUGE-2 α=0.117；Persona Precision/Recall 在兩個 judge 下 α 約 -0.150 至 -0.087。 |

上述數字為作者報告的實驗結果；論文未報告可作為 information satisfaction 通用解法的單一最佳指標。

## 對我們的啟發
- [ ] 摘要評估應將 query 與穩定的 reader persona 一起建模，而不能只依賴 reference overlap 或摘要本身的通用品質。
- [ ] 在導入新評估指標前，應先執行 distractor injection、incremental addition、length-preserving rewrite 與 audience-shift 等基本 robustness tests。
- [ ] Persona-aware 評估不應只計算相關資訊的存在或需求覆蓋率；實務上還需考慮讀者已知內容、資訊重要性及不同摘要間的相對偏好。

## 限制與未來工作

研究僅使用四個科學摘要語料庫，每個資料集抽取 50 篇文件；人工評估只有 20 位志願者與 140 個 query sessions，且參與者主要對語言科技有真實興趣。persona 依賴自陳資料，人工偏好採單淘汰 tournament，可能限制泛化性。Persona Precision/Recall 仍依賴 LLM 生成需求與判斷 nugget，未解決資訊重要性與讀者先備知識的建模。
