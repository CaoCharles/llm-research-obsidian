# DAMI: Dual-Axis Memory Initialization for Enhanced Long-Context Retrieval in Gated Linear Attention

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.41994)
- 📥 [PDF](https://arxiv.org/pdf/2610.41994v1)

## 摘要（中文翻譯）

Linear attention 能以序列長度的線性複雜度運作，但其有限狀態記憶可能限制長上下文檢索。在 gated linear recurrence 中，記憶保留取決於 state decay，而 state decay 同時受 gate 參數 A_log、dt_bias 與輸入 activation 影響。受控 Gated DeltaNet（GDN）實驗顯示，訓練後兩者仍與初始值高度相關，凸顯初始化的重要性。作者提出 Dual-Axis Memory Initialization（DAMI），在訓練前聯合配置這些參數：跨 heads 指派幾何分布的 timescales，以涵蓋不同檢索距離；跨 layers 建立 low–high–low 的 input-sensitivity profile。方法使用少量 activation samples 校準 GDN-family 實作，使其符合兩類行為目標，且不增加 trainable parameters。在 GDN、KDA、GDN2、Mamba-2 與 RWKV-7 上，DAMI 相較隨機初始化，平均 RULER-style retrieval accuracy 提升 5.29 至 16.71 個百分點；language modeling、commonsense reasoning 與 2K real-world retrieval 整體大致相當。

## 問題背景

論文處理 gated linear attention 在長上下文檢索中的有限狀態記憶問題。現有 recurrence 雖具線性計算與固定大小狀態，卻可能因 decay 過快而遺失遠距 evidence；既有初始化通常跨 layers 使用相同取樣規則，未同時考慮 head-wise 記憶時間尺度、layer-wise 輸入敏感度，以及 A_log、dt_bias 與 activation 之間的耦合。作者指出，GDN 中參數訓練前後高度相關，因此單純依賴訓練修正初始記憶行為可能不足。

## 解決方案

作者提出 DAMI，將記憶初始化拆成互補的雙軸設計。第一軸在 heads 間配置從 1 到 4,096 tokens 的幾何 timescale，使不同 heads 覆蓋近、中、遠距離依賴。第二軸在 layers 間配置 low–high–low input sensitivity：早期與晚期 layer 較低，中間 layer 較高。對每一層，DAMI 使用小型 calibration set 的實際 projected activations，先以 bisection 求解 dt_bias，使 Softplus derivative 的樣本平均符合目標 sensitivity，再調整 A_log，使平均 Softplus factor 對應目標 timescale。整個流程不使用 gradients、不增加 trainable parameters，並為 KDA、GDN2、Mamba-2 與 RWKV-7 提供架構特定適配。

## 核心貢獻
1. 指出 GDN 的 A_log 與 dt_bias 在初始化後至訓練完成仍呈高度相關：RANDOM 的 Pearson correlation 為 0.926/0.939，支持以結構化初始化直接塑造記憶行為。
2. 提出 DAMI 雙軸初始化：以跨 heads 的幾何 timescales 覆蓋不同 retrieval distances，並以跨 layers 的 low–high–low sensitivity profile 配置輸入反應。
3. 提出以實際 activation samples 進行 layer-sequential、無梯度的聯合校準，並將方法延伸至 GDN、KDA、GDN2、Mamba-2 與 RWKV-7。

## 技術方法

方法以 gated recurrence 的明確衰減項為基礎。GDN 的 gate 為 g_t=-exp(A_log)·Softplus(z_t+dt_bias)，state 先以 exp(g_t) 衰減，再透過 delta rule 寫入 key/value 資訊；因此累積 retention 同時由 A_log、dt_bias 與輸入 activation 決定。DAMI 為每個 head 設定幾何 timescale；GDN-family 的 18-layer、6-head 設定使用 {4096, 776.05, 147.03, 27.86, 5.28, 1} tokens。layer sensitivity 目標端點約為 0.25，中間峰值為 0.748。校準由淺至深進行：收集當前 layer 每個 head 的 projected activations，透過 bisection 解算 E[σ(z+dt_bias)]=S*；接著依據 E[Softplus(z+dt_bias)]，設定 A_log=-log(τ)/[-log(E[Softplus])]，並將校準輸出傳給下一層。實驗使用約 100M parameters、hidden size 512、5B training tokens、最大訓練 context 4,096 的五種架構，對比 Random、PoST 與 DAMI。主要 retrieval 評估為固定的 RULER-style NIAH-1、NIAH-2、MK-NIAH，共 11 個 task–length settings，每項含 500 個預生成樣本，以 answer-containment accuracy 與非加權平均衡量；另評估 WikiText perplexity、五項 commonsense accuracy，以及六項 2K real-world retrieval 任務。

## 對我們的啟發
- [ ] 若模型的記憶參數在訓練後仍保留初始化結構，初始化不應只追求數值穩定，也可直接依照目標任務的距離分布設計多尺度 memory spectrum。
- [ ] 當多個 gate 參數共同決定 retention 時，應先校準輸入敏感度，再補償其對平均 decay 的影響；分別初始化單一參數可能無法達成預期行為。
- [ ] 實務部署前可使用少量代表性 activation 做無梯度校準，在不增加推論成本與 trainable parameters 的前提下改善長距離 retrieval；但應同時檢查短距離、混合鍵值與真實資料任務，因為 RULER-style 增益不代表所有 retrieval 指標都同步提升。

## 限制與未來工作

論文主要研究 decay-side initialization，未聯合分析 write-side initialization，以及 incoming content 寫入狀態和保留歷史之間的互動。實驗集中於約 100M 參數模型、5B tokens、最大訓練 context 4,096；RWKV-7 的 Random/PoST 使用 seed 42、DAMI 使用 seed 43，且論文未提供更大模型、更多 seed 或統計信賴區間的結果。
