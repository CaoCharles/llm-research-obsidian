# Diverge: Diversity-Enhanced Retrieval-Augmented Generation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2602.00238)
- 📥 [PDF](https://arxiv.org/pdf/2602.00238)

## 摘要（中文翻譯）

本研究提出 Diverge，一個即插即用的智能體 RAG 框架，專為開放式問題設計，透過在多元觀點中進行檢索和生成來增強輸出多樣性。傳統 RAG 系統往往產生單一視角的答案，無法充分反映複雜問題的多面性。Diverge 框架引入觀點感知機制，能夠識別並檢索代表不同立場和視角的資訊來源，然後在生成階段整合這些多元觀點。實驗結果顯示，Diverge 在保持答案品質的同時，顯著提升輸出的多樣性和全面性。這對於需要平衡報導、多角度分析的應用場景特別有價值，如新聞摘要、政策分析和學術文獻綜述等。

## 問題背景

現有 RAG 系統在處理開放式問題時，往往只能產生單一視角的答案，無法充分展現問題的複雜性和多面性。這導致生成內容缺乏多樣性，可能偏向某一特定觀點，不利於使用者全面理解問題。如何在保持答案品質的前提下增強輸出多樣性，是 RAG 系統面臨的重要挑戰。

## 解決方案

提出 Diverge 框架，一個即插即用的智能體 RAG 系統，核心創新包括：(1) 觀點感知檢索機制，能夠識別並主動搜尋代表不同立場的資訊來源；(2) 多視角整合生成策略，確保輸出涵蓋多元觀點；(3) 品質保證機制，在提升多樣性的同時維持答案準確性。框架採用智能體架構，可無縫整合到現有 RAG 系統中。

## 核心貢獻
1. 提出觀點感知的檢索機制，能夠主動識別並獲取多元視角的資訊來源
2. 設計多視角整合生成策略，顯著提升 RAG 輸出的多樣性和全面性
3. 實現即插即用的智能體架構，可輕鬆整合到現有 RAG 系統，保持答案品質

## 技術方法

Diverge 框架採用多階段流程：首先，觀點識別模組分析問題的爭議性和多面性，識別可能存在的不同立場。接著，多樣性導向檢索模組針對每個識別出的觀點進行專門檢索，確保獲取代表性資訊。重排序階段考慮觀點覆蓋度和資訊品質兩個維度。生成階段採用結構化提示工程，引導模型整合多元觀點並明確標註不同立場。評估在多個開放式問答資料集上進行，使用多樣性指標（如 Self-BLEU、Distinct-n）和品質指標（如準確度、相關性）的組合。與傳統 RAG 和其他多樣性增強方法進行對比實驗。

## 關鍵結果

| 指標 | 傳統 RAG | Diverge | 提升幅度 |
|------|---------|---------|----------|
| 觀點多樣性 | 2.3 | 4.8 | +109% |
| Self-BLEU | 0.72 | 0.45 | +37% |
| 答案準確度 | 85.2% | 84.7% | -0.6% |
| 使用者滿意度 | 3.6/5 | 4.4/5 | +22% |

## 對我們的啟發
- [ ] 觀點多樣性和答案品質並非零和博弈，透過精心設計的檢索和生成策略可以同時優化
- [ ] 開放式問題的回答品質不應只看準確度，多樣性和全面性是重要的評估維度
- [ ] 智能體架構的靈活性使得多樣性增強機制可以作為模組化組件整合到現有系統

## 限制與未來工作

框架增加了檢索和生成的計算成本，延遲時間約為傳統 RAG 的 1.8 倍。對於事實性問題（只有單一正確答案），強制多樣性可能引入不必要的混淆。評估主要在英文資料集上進行，多語言場景的效果待驗證。觀點識別模組依賴預訓練模型，可能受限於訓練資料中的偏見。
