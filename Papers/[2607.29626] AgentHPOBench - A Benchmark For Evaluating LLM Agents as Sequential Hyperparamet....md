# AgentHPOBench: A Benchmark For Evaluating LLM Agents as Sequential Hyperparameter Optimizers

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.29626)
- 📥 [PDF](https://arxiv.org/pdf/2607.29626v1)

## 摘要（中文翻譯）

隨著 LLM 從程式碼補全系統發展為自主科學 agent，評估其執行實驗的能力日益重要。現有 benchmark 多聚焦於靜態程式碼生成、論文重現或最終答案正確性，未直接評估 agent 是否能解讀實驗證據，並據此引導後續的 hyperparameter 決策。為填補此缺口，作者提出 AgentHPOBench：一個 sequential benchmark，包含來自七個研究類別的 30 個可執行 machine learning tasks。每項任務先執行經驗證的 baseline，之後 agent 進行多次 sequential interventions；每一步均可觀察累積的 configurations、metrics 與 logs，再提出下一個有效 configuration。作者依統一 protocol 評估 12 個常用 agents 與傳統 HPO baselines。結果顯示，現有 agents 在不同領域具備可量測的實驗最佳化能力，但在持續迭代 refinement、複雜 log diagnosis，以及穩定朝向論文或 repository 所報告的 reference performance 改進方面仍有明顯限制。

## 問題背景

現有 LLM agent benchmark 多評估程式碼生成、論文重現、研究工程或最終答案，無法單獨衡量 agent 是否能根據已完成實驗的 metrics、auxiliary signals 與 logs，選擇下一個有效 hyperparameter configuration。傳統 HPO benchmark 則通常提供乾淨的 tabular、surrogate 或 scalar objective，抽象化了 repository 執行流程、文字 logs 與研究情境。因此，agent 能否在真實可執行 ML repository 中透過 sequential feedback 持續改善實驗，仍缺乏專門且統一的評估。

## 解決方案

作者提出 AgentHPOBench 與配套 execution harness，將 30 個近期 ML repositories 轉化為可重複的 sequential hyperparameter optimization 任務。每個任務共享經驗證的 reference baseline，限制 agent 只能在預先定義的 intervention space 內修改 configuration；harness 負責 configuration validation、實驗執行、metric/log 擷取、trajectory recording 與結果 audit。每次 intervention 後，agent 可讀取累積的 configurations、target/auxiliary metrics 與 execution logs，再提出下一步決策。評估同時採用 MBNS、BWR 與 MAA，分別區分相對 baseline 改善、改善任務比例，以及對論文或 repository anchor 的絕對達成程度。

## 核心貢獻
1. 提出 AgentHPOBench，將 30 個近期 machine learning research repositories 轉化為涵蓋 NLP、CV、time series、graph、RL、LLM 與 structured learning 七類別的 sequential HPO 任務。
2. 建立統一 evaluation harness：固定 reference baseline、intervention space、執行預算與評分規則，驗證 agent configuration、執行實驗並記錄完整 trajectory、metrics 與 logs。
3. 提出同時衡量相對 baseline 改善與絕對 reference anchor 達成程度的評估方式，並比較 12 個 agents 與 random search、TPE、BOHB variant 等 conventional HPO methods。

## 技術方法

AgentHPOBench 將每個 executable research repository 定義為一個任務，指定 reference baseline configuration、target metric、paper/repository anchor、constrained intervention space、execution scripts 與 evaluation interface。資料集、data split、target metric、evaluation code 與 benchmark metadata 固定不變；agent 只能從官方 training scripts、configuration files 或 repository documentation 所暴露的有效欄位和值中修改 hyperparameters。論文沒有提出新的 LLM 模型架構；評估對象包括 open-weight agents、API-based agents，以及 random search、TPE 與 BOHB-style conventional HPO methods。

執行流程為：首先以固定 baseline configuration 執行任務並取得 target metric、auxiliary metrics 與 logs；接著在每一個 intervention step，agent 觀察完整累積 history，提出下一個 configuration。harness 會驗證 configuration 是否屬於 intervention space，執行 repository experiment，回傳結果並記錄 configuration、metrics、logs、runtime metadata 與 completion status。limited-budget protocol 包含 baseline 加五次 interventions，baseline 與每次 intervention 約使用原始 training budget 的 10%；另以 full budget 評估三個 agent。評分先將指標轉為「越大越好」的方向，計算 normalized score NS=(final−baseline)/(anchor−baseline)，再截斷至 [-1,1] 得到 BNS，並對 30 個任務取平均形成 MBNS。BWR 衡量 final result 超越 baseline 的任務比例；MAA 則衡量 final result 相對 repository anchor 的平均達成率。

## 關鍵結果

論文在 limited-budget protocol 下先執行 baseline，再讓 agent 進行五次 sequential interventions；每次 baseline 與 intervention 約使用原始實驗 training budget 的 10%。主要結果如下：

| Agent / Method | Overall MBNS | BWR | MAA |
|---|---:|---:|---:|
| Random search | -0.034 | 48.9% | 62.6% |
| TPE | -0.113 | 40.0% | 62.4% |
| BOHB variant | 0.018 | 45.6% | 65.3% |
| Qwen3-32B | 0.148 | 60.0% | 69.1% |
| Phi-4-14B | 0.130 | 63.3% | 66.9% |
| GPT-5.5 | 0.305 | 66.7% | 76.7% |
| Claude Sonnet 4.6 | **0.407** | **76.7%** | **79.5%** |

在 full-budget protocol 中，Claude Sonnet 4.6 的 MBNS 為 0.472、BWR 為 76.7%、MAA 為 89.1%；Qwen3-32B 的 MBNS 為 0.191、BWR 為 56.7%、MAA 為 81.8%；DeepSeek-R1-Qwen-14B 的 MBNS 為 0.151、BWR 為 50.0%、MAA 為 78.6%。作者指出 full budget 提升三個 agent 的 MBNS 與 MAA，但不會一致提升 BWR。論文未報告統計顯著性檢定。

## 對我們的啟發
- [ ] 若要評估能執行實驗的 LLM agent，應保留 repository 的 logs、auxiliary metrics 與執行失敗資訊，而不只提供乾淨的 scalar objective。
- [ ] 實務系統應保存最佳 configuration 並加入 regression protection，因為論文的 sequential trajectories 顯示 agent 可能在後續 intervention 中丟失早期收益。
- [ ] 中間實驗回饋對 sequential decision making 具有實際價值；在 Qwen3-32B ablation 中，移除 intermediate feedback 使 overall MBNS 由 0.148 降至 0.052、BWR 由 60.0% 降至 50.0%。

## 限制與未來工作

任務數量為 30，且各類別任務數不均；limited-budget 設定下每次實驗約只有原始 training budget 的 10%，可能限制對長期訓練行為的觀察。API agents 僅於 canonical instance 評估一次，且最終分數使用最後一次 intervention 而非最佳中間結果。論文也未報告統計顯著性檢定或更廣泛的跨 benchmark 泛化結果。
