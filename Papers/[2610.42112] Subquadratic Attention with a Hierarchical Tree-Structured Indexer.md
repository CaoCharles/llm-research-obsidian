# Subquadratic Attention with a Hierarchical Tree-Structured Indexer

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.42112)
- 📥 [PDF](https://arxiv.org/pdf/2610.42112v1)

## 摘要（中文翻譯）

注意力機制的 quadratic scaling 是限制大型語言模型（LLM）長上下文能力的根本瓶頸。既有方法若採用 sliding-window 或固定狀態的 linear attention，會損失 attention 的表達能力；若採用稀疏 attention，則其 indexer 本身可能仍具 quadratic scaling，僅能提供 constant-factor speedup。本論文提出 Zyphra Hierarchical Attention（ZHA），以遞迴壓縮的 key summaries 建構階層式樹狀 indexer，讓 future queries 由樹頂向下路由，取得與 query 相關的稀疏 keys。透過逐步增加樹深度，包含 routing 與 final attention 的總成本可呈 sublinear 增長，使 attention 整體達到 subquadratic、但仍為 superlinear 的 scaling。作者顯示，ZHA 可透過數十億 tokens 的短期 KL distillation 套用至既有 pretrained models，並在長上下文 retrieval、推理、數學與 agentic coding 評測中維持表現。研究亦指出，ZHA 對不同樹形幾何具有高度穩健性，並以 performance model 推估其在超過一百萬 tokens 後優於競爭方法，具延伸至數億或數十億 tokens context 的潛力。

## 問題背景

論文欲解決 dense attention 隨序列長度呈 quadratic 增長的計算、記憶體與 decode bandwidth 瓶頸。固定狀態、sliding-window 或 linear attention 雖可降低複雜度，卻可能因狀態容量固定而在長上下文退化；固定 top-K 或 chunk-sparse 方法則把成本轉移至 indexer，且多數僅提供 constant-factor speedup。核心挑戰是在保留 query-dependent retrieval 與廣泛 KV coverage 的同時，建立可隨上下文成長但 sublinear 的 active state。

## 解決方案

作者提出 ZHA，一種 hierarchical sparse attention。方法將 KV cache 按連續 chunks 遞迴壓縮成多層樹狀 key summaries；每個 summary 由學習到的 reference queries 產生 attention-weighted key 與 bias，用以近似該 chunk 的 log attention mass。推論時，query 從最高層開始，以 top-p 選取具有足夠估計 attention mass 的 nodes，逐層展開至 leaf keys，最後只對選出的 KV 執行標準 attention。核心創新是以多層樹狀 indexer 將 query-dependent routing 的工作本身壓縮，並以 top-p 取代固定 top-K，使選取數量可隨分布與序列長度調整。轉換 pretrained model 時凍結 backbone，只訓練少量 reference queries。

## 核心貢獻
1. 提出 ZHA，利用遞迴 key summaries、reference-query tangent approximation 與 top-p hierarchical routing，讓 sparse attention 的 indexer 具有 subquadratic scaling 的理論與經驗依據。
2. 證明可在不更新 pretrained backbone 的情況下，僅以少量 reference-query 參數與約 4B tokens 的 KL warmup 轉換模型；在 Qwen3.6-35B-A3B 等模型上，deep 與 wide geometry 多數評測接近 dense baseline。
3. 建立包含 tree construction、routing、selection、memory bandwidth、compute 與 worker-wave 的 roofline performance model，並以 selection-count power laws 分析增加樹深度後的長上下文 scaling。

## 技術方法

ZHA 的樹以 chunk size C 與 depth L 定義；底層保存原始 KV，每 C 個 keys 建立第一層 summary，每 C^2 個 keys 建立第二層 summary，依此類推。對 chunk KC，作者以 reference query 計算 attention-weighted compressed key，並以 log-sum-exp 的 tangent plane 加上 bias，使用多個 tangent 的 maximum 近似 chunk 的 attention mass；高層則遞迴合併子節點。對含 RoPE 的模型，reference queries 會旋轉至節點 span 的末端；GQA 等設定則可按 KV head 建樹並由群組 query heads 共用。訓練階段凍結原模型，將 dense attention 在各層級的 chunk probability 作為 target，最小化預測分布與 target 間的 KL divergence；Qwen 與 Nemotron 實驗使用 4B tokens、32K context 的 KL warmup。推論時，query 在每層計算節點分數，選取累積估計 mass 至少為 p 的最小節點前綴，展開其 children，保留 parentless chunks、current chunk 與第一個 token，最後對葉節點 KV 執行 attention。評估涵蓋 AIME 2026、MMLU-Pro、GPQA Diamond、SWE-bench Verified、Terminal-Bench 2.1、RULER 與 LongBench v2；效率則以包含 routing、selection、tree maintenance 與 final attention 的 roofline performance model 分析，並擬合各層 selection count 的 power-law scaling。

## 對我們的啟發
- [ ] 若實際部署長上下文 attention，應同時評估 indexer、node selection 與 final attention，不能只計算被保留 KV 的數量；ZHA 的主要價值在於降低 indexer 本身的成長率。
- [ ] top-p 比固定 top-K 更能讓路由預算依 attention mass 自適應；但 p、chunk size、depth 與 reference-query 數量應以 accuracy–sparsity 曲線共同調校，而非只追求最低 cache fraction。
- [ ] 將 pretrained model 轉換為稀疏 attention 時，可優先凍結 backbone、蒐集 dense attention 的 chunk-level distributions，再以 KL distillation 訓練輕量 router；論文結果顯示這可能比重新訓練完整模型更節省轉換成本。

## 限制與未來工作

論文的速度結論主要來自 roofline model 與跨有限長度、問題及 geometry 的 selection-count 外推，尚未提供 optimized GPU kernels 的端到端實測。最深樹與最長序列資料量較少，作者也指出部分估計處於 low-data regime。方法依賴自然語言的可壓縮性；對 adversarial random-token retrieval，論文明確指出可能需要 dense attention。Nemotron 的 RULER 亦出現中度退化。
