# Beyond Self-Critique: Epistemic Convergence Control for Multi-Agent Research Verification

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.27839)
- 📥 [PDF](https://arxiv.org/pdf/2611.27839v1)

## 摘要（中文翻譯）

科學主張驗證的 multi-agent systems 越來越依賴具角色分工的 LLM debate 來壓力測試假說。然而，當辯論 agents 使用相同的 base model 時，會共享相似的 latent representations，使 self-critique bias 在結構上難以避免；固定迭代次數也可能在證據尚未穩定前過早停止，或在收斂後浪費 inference compute。本文提出 VerifyAgent，結合 Advocate、Skeptic 與 Arbitrator 的非對稱角色架構、Belief-Delta（ΔB）證據導向停止準則，以及由獨立 NLI classifier 審核的逐字文獻片段。相較於對稱 MAD，其 role-embedding similarity 為 0.852 對 0.918，並發現較多 contested claims。ΔB 消除 over-iteration 並使 LLM calls 減少 2.4 倍。每項 supported claim 均連結至文獻片段；在 40 個研究假說、200 次執行中，hallucination rate 為 21.7%，與 Self-Refine 的 25.9% 沒有顯著差異。

## 問題背景

論文要解決兩個問題：第一，相同 base LLM 執行的對稱 multi-agent debate 可能共享相同表示空間，導致角色間自我確認、互相附和或表面分歧；第二，固定迭代協議無法配合證據狀態變化，可能過早停止或在信念已穩定後繼續消耗推理資源。既有 self-critique 也缺乏可靠的外部 ground-truth 與可稽核證據鏈。

## 解決方案

作者提出 VerifyAgent，一個以文獻為基礎的 multi-agent research verification pipeline。其核心是非對稱的 Advocate/Skeptic/Arbitrator 角色：Advocate 尋找支持證據，Skeptic 主動尋找反例與方法限制，Arbitrator 整合雙方意見並更新 belief state。系統以 role-embedding similarity 監測角色塌縮，並在超過門檻時進行 contrastive re-run。另一項創新是 Belief-Delta（ΔB）停止準則，根據連續 structured belief states 的狀態或信心變化決定是否繼續迭代；收斂後，所有 supported claims 必須附帶逐字 literature snippet，並由獨立 NLI 與 embedding 檢查。

## 核心貢獻
1. 提出 Advocate、Skeptic、Arbitrator 的非對稱角色架構，並以 embedding similarity 作為 role-collapse 的操作性監測指標；相較對稱 MAD，similarity 由 0.918 降至 0.852。
2. 提出以 structured belief state 變化為基礎的 Belief-Delta（ΔB）收斂準則；在實驗中 over-iteration 為 0.0%，相較 Fixed-Step N=3 的 62.5%，平均 LLM calls 也降低約 2.4 倍。
3. 建立 source-grounded evidence auditing 流程，要求 supported claim 綁定 120 字逐字文獻片段，並由獨立 NLI cross-encoder 與 embedding similarity 進行審核。

## 技術方法

系統以 LangGraph 實作，包含 Retrieval Agent、Belief Builder、Asymmetric Pressure Tester、Reflexion Node 與 NLI audit store。Retrieval Agent 針對假說動態改寫查詢，從 Semantic Scholar 與 arXiv 取得文獻；結果以 embedding cosine similarity 0.92 去重，按 citation count 排序。Belief Builder 將資料整理為〈claim, status, evidence〉，status 為 supported、contested、refuted 或 unknown；每個 evidence link 包含論文識別碼、atomic claim、120 字逐字 snippet 與 stance。Advocate 與 Skeptic 在隔離 inference pass 中獨立產生主張，若兩者 centroid embedding 的 cosine similarity 超過 0.85，便以對方主張作為 negative constraints 重新提示。Reflexion Node 產生針對 contested 或 unknown claims 的問題並更新 belief state。ΔB 定義為連續狀態中 matched entries 的修改數，除以兩狀態大小較大者；若 status 改變或 confidence 變化超過 0.10，視為修改，當 ΔB≥0.10 繼續，否則停止。最後以 cross-encoder/nli-deberta-v3-base 計算 entailment，並以 all-MiniLM-L6-v2 檢查 topical similarity，低於 0.50 時標記。實驗使用 DeepSeek-R1-32B、temperature 0，在 40 個假說上比較 Full System、對稱 MAD、Self-Refine、Fixed-Step N=1 與 N=3。

## 對我們的啟發
- [ ] 若多個 agents 使用同一 base model，僅增加角色名稱未必足夠；可採用互斥 epistemic directives、隔離推理上下文與角色重疊監測，作為降低表面共識的工程控制。
- [ ] 停止條件應依據可觀測的 belief artifact 變化，而非 agent 自報信心或固定輪數；但部署時仍需特別處理新增、刪除與改寫主張，因本文的 ΔB matching rule 可能低估這些變化。
- [ ] RAG 驗證流程可要求每個肯定性主張附帶可追溯的逐字證據，並將 NLI 分數與 topical similarity 作為審計訊號；不過本文結果顯示，這種結構化證據鏈尚未帶來統計顯著的 hallucination 降低。

## 限制與未來工作

實驗只使用本地 DeepSeek-R1-32B，未比較 frontier proprietary models、heterogeneous model panels 或其他 adaptive stopping 方法。資料集僅含 40 個假說，且缺少 crowd-sourced ground-truth adjudication，因此無法提供完整 end-to-end precision-recall。NLI 模型以一般領域資料訓練，可能對科學 paraphrase 給出保守分數；此外，ΔB 對新增、刪除或改寫主張可能低估狀態變化。
