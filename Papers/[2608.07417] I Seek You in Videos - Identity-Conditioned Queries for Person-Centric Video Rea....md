# I Seek You in Videos: Identity-Conditioned Queries for Person-Centric Video Reasoning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.07417)
- 📥 [PDF](https://arxiv.org/pdf/2608.07417v1)

## 摘要（中文翻譯）

現實世界的影片推理通常涉及多模態、多來源輸入，但現有影片推理任務多採用簡化的 video-text 設定，限制了身份匹配與以人物為中心的推理能力。為此，本文提出 Identity-conditioned Queries（ICQ）任務：模型需共同關聯並理解輸入影片與人物參考影像，利用該身份條件完成身份定位、行為理解、時間推理等工作。基於 ICQ，作者提出 ISYV（I Seek You in Videos）系統，包含三部分：ISYV-Bench，收錄1,377部真實複雜影片及1,377組問答，分為六個難度層級；ISYV-75K，包含約75K筆訓練樣本；以及 ISYV-Framework，透過 ICQ-oriented model 與訓練策略學習擷取資訊性影片 shots，且不需額外 shot-level 標註。實驗顯示，開源與閉源 MLLM 在跨域身份匹配及長期追蹤上均有困難；作者模型優於強基準，部分能力接近閉源模型。

## 問題背景

現有影片問答與推理多採 video-text 雙模態設定，通常只理解單段影片，無法處理實際應用中的參考人物影像與文字查詢聯合輸入。當人物在不同 shot、場景、服裝、光照或妝容下出現時，模型還需完成身份匹配、定位、長期追蹤、行為與社交理解，以及時間和因果推理；既有影像級個人化方法則未涵蓋複雜影片與跨 shot 的多來源身份推理。

## 解決方案

作者提出 ISYV 系統，核心是 Identity-Conditioned Queries（ICQ）任務與三項配套。ISYV-Bench 以六級認知層次評估從人物辨識到因果意圖推理；ISYV-75K 提供大規模訓練樣本，透過自動標註、多階段模型檢查與人工審核建立。ISYV-Framework 的 ICQ Module 使用 learnable tokens 和 cross-attention 抽取參考人物的緊湊表徵，避免影片與參考圖語義混淆；訓練上先 SFT，再以 GRPO 結合 caption reward 與 ESR reward，讓模型在沒有 shot-level 標註下學習尋找回答問題所需的有效 shots。

## 核心貢獻
1. 提出 Identity-Conditioned Queries（ICQ）任務定義，要求模型聯合處理複雜影片、人物參考影像與文字查詢，評估身份 grounding、行為理解、時間與因果推理。
2. 建立 ISYV-Bench 與 ISYV-75K 資料套件：前者包含1,377筆人工驗證基準樣本，後者包含24,150段影片與74,578組問答，涵蓋六級認知層次及17類子任務。
3. 提出 ISYV-Framework，包括以 learnable tokens 壓縮參考影像的 ICQ Module，以及結合 SFT、GRPO、caption reward 與 Effective Shot Re-Reasoning（ESR）reward 的兩階段訓練方法。

## 技術方法

任務輸入為長影片、人物參考影像與文字查詢，輸出包含參考影像描述、相關影片 shots、推理過程及答案。資料方面，作者從電影、電視劇與 anime 等影音來源收集超過100,000段影片，先移除無人物片段，再以 TransNet V2 分割 shots；Gemini-2.5-Pro 產生逐 shot 描述、具 ID 的人物行為與整體敘事標註。Qwen3-VL-32B 檢查人物框與參考圖品質，Qwen3-Max 依模板產生問答、CoT 與 leakage 檢測，並透過 Qwen-Image-Edit 或 face ReID 建立服裝、姿態、背景不同的身份參考圖。ISYV-Bench 再經模型過濾與至少三名標註者交叉驗證。
模型的 ICQ Module 先對 learnable tokens 使用 self-attention，再以 tokens 作為 Queries、參考影像 encoder tokens 作為 Keys/Values，透過 cross-attention 壓縮人物特徵，避免參考圖被誤當成影片末幀並降低 token 雜訊。訓練分為 SFT cold start 與 GRPO reinforcement fine-tuning。獎勵包含格式、二元答案正確性、由 LLM judge 評估的 caption semantic reward，以及 ESR reward：模型選出 shots 後剪輯並降採樣重推理，只有初始與重推理答案皆正確且可解析時給予獎勵，並依選取 shots 數量衰減額外分數。評估以 O.Avg（答案正確率）與 ICQ Q.Avg（同時滿足參考影像描述與答案正確）為主，並報告六個層級的 accuracy；所有模型影片輸入統一採全片均勻取樣32 frames。

## 對我們的啟發
- [ ] 對人物中心影片評測而言，僅衡量最終答案不足以確認模型是否真正使用參考影像；可額外檢查身份描述、證據 shot 與答案的一致性，類似論文中的 ICQ Q.Avg。
- [ ] 對長影片推理，讓模型輸出候選相關 shots，再透過重推理驗證其選取的證據是否足以維持正確答案，可能比單純增加所有影片 frames 更有效。
- [ ] 資料建構可採用自動標註、多輪模型檢查、人工複核與 leakage detection 的分層流程；但訓練與評測資料仍應避免過度依賴同一批模型產生標註，以降低評測偏差。

## 限制與未來工作

基準僅有1,377筆問答，且資料主要來自電影、電視劇與 anime；訓練標註大量依賴 Gemini、Qwen 等模型自動生成，再由人工驗證，可能存在來源與模型偏差。論文未提供完整資料分布、各子任務樣本數、跨來源泛化測試及更廣泛的人類一致性分析；未來將擴展更複雜、真實的影片推理任務。
