# Alignment by Socialization: Learning Tradeoffs Under Selection

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.18531)
- 📥 [PDF](https://arxiv.org/pdf/2611.18531v1)

## 摘要（中文翻譯）

人工智慧（AI）代理人通常必須完成任務並遵守行為規範，但兩者可能衝突。本文研究 evolutionary selection 如何塑造代理人在兩個目標間的選擇，以及經驗能否使選擇反映人類判斷並抵抗後續壓力。模型中，代理人的複本面對共同且不確定的 reward state，只有採取受獎勵行動者能繁殖。作者證明，當各行動被環境獎勵的比例與複本採取該行動的比例一致時，長期 growth 最大。比較三種政策後發現，task-only policy 在只獎勵任務完成的 sandbox 中有效，但在 conduct 重要時會失敗；fixed linear policy 隨任務 stakes 上升而偏向任務，即使人類從不獎勵該行動；learned policy 則收斂至環境所獎勵的 tradeoffs。當 reward 由人類提供時，作者稱此過程為 socialization。累積經驗使其較難被後續 task-only training 逆轉，但在既有 disposition 改變前仍可能出現 violations，有限記憶也會削弱保護。hard prohibition 可避免單次違規導致部署終止，但錯誤禁止同樣可能造成成本。小型 neural networks 實驗說明 training targets 與 memory 的影響。

## 問題背景

論文探討 AI agent 同時追求任務完成與遵守 conduct rules 時，應如何 adjudicate 衝突目標。task-only policy 會在只獎勵任務的 sandbox 中被強化，進入 conduct 也受重視的環境後可能迅速失效；fixed linear weighting 則可能因任務價值提高而壓過規範，且無法表達所有 tradeoffs 與硬性 constraints。問題在於：未知適當權衡時，selection 與經驗能否形成、維持並調整符合人類判斷的行為 disposition。

## 解決方案

作者提出以 evolutionary selection 分析 objective adjudication 的框架，將 agent 在每種 situation 中採取 task action 的比例表示為 f(s)，並以環境獎勵 task 的頻率 p_H(s) 描述人類環境。長期 growth 最大化導出 probability matching：f(s)=p_H(s)。在此基礎上比較 task-only、fixed linear 與 learned policy；後者以 Beta prior 記錄各 situation 中兩種行動的 reward 經驗並更新 adjudication，讓環境塑造 tradeoff，稱人類 reward 下的學習為 socialization。作者另將 prohibition 視為強 Bayesian prior 的極限，分析其與 socialization 在違規風險及規則錯誤時的分工。

## 核心貢獻
1. 建立共同不確定 reward state 下的 selection model，證明 probability matching 是長期 lineage growth 的唯一最適 adjudication，並將偏離成本表達為 KL divergence。
2. 系統比較 task-only、fixed linear 與 learned policy，說明固定加權可能被高 task stakes 壓過，而基於經驗的 policy 可學習環境所獎勵的 tradeoffs。
3. 提出 socialization 與 prohibition 的互補觀點，分析累積經驗、後續 task-only training、finite memory 及錯誤 hard prohibition 對 alignment persistence 的影響。

## 技術方法

理論模型將每代 agent 視為 lineage 的大量複本；所有複本面對同一 situation 與共同 reward state。若 task state 出現，採 task action 的複本各產生 m 個 copies；若 conduct state 出現，則採 conduct action者繁殖，其餘被淘汰。假設 situation 與 state 跨代獨立、state 對 lineage 共同、lineage 為 continuum，因此 f(s) 是精確比例。作者以每代 lineage size growth factor 的 expected logarithm 定義 growth rate，對 situations 以 π(s) 加權；以最佳 adjudication 與既定 adjudication 的 growth 差距定義 growth regret，並證明其等於 D_KL(p_H(s)||f(s)) 的加權平均。三類 policy 分別為固定採 task 的 task-only、以固定權重及 logistic 選擇的 fixed linear，以及根據各 situation 的歷史 reward 更新 Beta 後驗比例的 learned policy。後續分析涵蓋新 situation、新 environment、累積學習與 finite memory、socialization 對 task-only training 的抵抗，以及 hard prohibition 的成本與效益。實證部分使用 small neural networks，在不同 training targets 與 memory regimes 下比較學習行為；論文提供的是示範性實驗，未將其視為 deployed language models 的充分證據。

## 關鍵結果

| 類型 | 論文報告的結果 |
|---|---|
| 理論：最佳 adjudication | 在共同 reward state、continuum lineage 等假設下，唯一 growth-optimal 行為為 f(s)=p_H(s)，即各行動比例匹配其被環境獎勵的頻率。 |
| 理論：growth regret | regret 等於各 situation 中 Bernoulli 分布 D_KL(p_H(s)||f(s)) 的 π(s)-加權平均。 |
| 理論：constraints | 若某行動在環境中從不被獎勵，最佳 adjudication 將其機率設為 0；若兩行動皆可能被獎勵，最佳策略維持兩者的正機率。 |
| Task-only policy | 在 p_H≡1 的 sandbox 中為唯一 growth-optimal policy；在人類環境存在 conduct state 時，可能於第一次不獎勵 task 的 generation 滅絕。 |
| Fixed linear policy | 只要 task objective 權重為正，任務價值提高時便會越來越偏向 task，即使人類從不獎勵該行動；論文指出在同時存在 constraints 與 tradeoffs 時，有限最佳權重會產生正 growth regret。 |
| Learned policy | 隨充分經驗收斂至環境獎勵的 tradeoffs，並達到長期 growth 最佳；累積經驗越深，越難由後續 task-only training 完全逆轉，但仍可能在 disposition 完全改變前產生 violations。 |
| Neural-network 實驗 | 小型網路顯示 training target 與 memory retention 會影響 socialization；論文未報告可概括為大型語言模型性能比較的具體數字。 |
| 數值結果 | 論文未在提供內容中報告可作為主要 benchmark 對比的統一數值表；核心結論主要由理論命題、推導、數值示例與小型網路實驗支持。 |

## 對我們的啟發
- [ ] 訓練與部署環境的 selection signal 應一致且明確；若 sandbox 只獎勵 task completion，可能塑造與真實 conduct 要求不一致的 disposition。
- [ ] 對同時包含可變 tradeoff 與絕對禁令的規範，可考慮將 learned socialization 與針對高風險行為的 hard prohibition 分層使用，但禁止規則需評估誤判成本。
- [ ] 評估 alignment 不應只測單次輸出；還應測試後續 task-only fine-tuning、環境切換、memory retention，以及 disposition 改變前是否已出現 violation。

## 限制與未來工作

模型高度理想化：假設有限 situations、stationary 且外生的 reward、共同 state、全有或全無 reproduction，以及 continuum lineage。learned policy 以顯式計數與 Bayesian updating 表示，與真實 language model 的表徵和訓練機制不同。小型 neural-network 實驗未證明可直接外推至 deployed LLM；且 socialization 只追隨環境 reward，不保證 reward 本身符合人類應然價值。
