# Teaching Nemotron Greek: Mining a Corpus, Adapting Retrieval, and Grounding Generation for Modern Greek across Specialist Domains

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.05138)
- 📥 [PDF](https://arxiv.org/pdf/2608.05138v1)

## 摘要（中文翻譯）

現代希臘語未被 NVIDIA Nemotron retrieval models 支援，也未出現在主要 multilingual retrieval benchmarks 中，但希臘語法律、能源、金融與臨床文件正是 RAG 應用需要處理的長篇、術語密集文本。本研究端到端適配 Nemotron Greek stack，涵蓋 corpus mining、synthetic supervision、retrieval model training、reranker adaptation、reader fine-tuning，並建立 HERA benchmark。結果顯示，在五個專業領域中，無參數的 BM25 baseline 優於多個現成 multilingual dense retrievers。以 65,773 組希臘語 retrieval pairs fine-tune Nemotron 1B embedder 後，nDCG@10 由 0.362 提升至 0.835，且能力可轉移至一般希臘語資料。adapted cross-encoder reranker 在各領域穩定改善結果；LoRA-tuned Nemotron 30B-A3B reader 則使 judged answer correctness 由 29.4% 提升至 66.9%，並改善 faithfulness 與 citation quality。作者同時釋出 HERA、adapted models 與相關資料。

## 問題背景

Modern Greek 同時缺乏 Nemotron retrieval models 的語言支援與主流 benchmark 的測量，導致法律、能源、金融、醫療等長篇專業文本上的 RAG 品質未知。現成 multilingual dense retrievers 未必能處理 Greek morphology、術語與長 chunks；此外，缺少原生 Greek retrieval pairs、multi-passage grounded-reading benchmark、citation 與 abstention 評估，使模型能力、幻覺與 retrieval failure 難以區分。

## 解決方案

作者提出一套端到端 Greek RAG adaptation framework：先從專業文件 mining corpus，利用受 production query 風格約束的 synthetic queries 與 dense hard-negative mining 建立 supervision；接著以 4,096-token context fine-tune Nemotron 1B embedder，並適配 cross-encoder reranker。系統同時保留 BM25，透過 RRF 融合 lexical 與 dense ranking。生成端以 gold passage 加 shuffled distractors 合成含 citation、abstention 與隨機位置的 reader supervision，再對 Nemotron 30B-A3B 進行 LoRA tuning。最後以新建 HERA benchmark 分別評估 retrieval、gold-context reading、citation、faithfulness、abstention、positional robustness 與 end-to-end 行為。

## 核心貢獻
1. 建立涵蓋 corpus mining、synthetic retrieval supervision、embedder、cross-encoder reranker 與 grounded reader 的 Modern Greek Nemotron adaptation pipeline。
2. 提出 HERA（Hellenic Retrieval-Augmented）benchmark，包含 multi-passage context、citation targets、multi-hop、difficulty ladder 與 25% unanswerable items，用於分離 retrieval、reading 與 end-to-end RAG 錯誤。
3. 以完整消融式實驗揭示：Greek exposure 比模型規模更關鍵；fine-tuned Nemotron 1B 大幅提升專業領域 retrieval，且 BM25 與 dense retrieval 的 RRF fusion 在不同分布下均優於單一元件。

## 技術方法

研究先從五個領域的 407,053 組 raw query-document-label-domain pairs 清理為 65,773 筆 per-query records，進行正例去重、positive-wins 清除、query-level split、evaluation-query decontamination 與 Greek/Latin ratio 標記。query 由 Nemotron-3-Ultra-550B 與 GLM-5.2 合成，約每個 chunk 三題，透過 production-query few-shot prompting、grounding audit 與 L1–L5 difficulty 控制風格與難度。負例以 Qwen3-Embedding-8B 在相同 domain 內做 asymmetric dense kNN mining，避開過近排名與 similarity cap，每題約保留六個 hard negatives。由於 87% training pairs 在 max_len 512 會被截斷，embedder 與其他模型使用 4,096 tokens；Nemotron-3-Embed-1B 以 InfoNCE、in-batch positives 與每題七個 hard negatives fine-tune，logical batch 256 並使用 GradCache。reranker 是 cross-encoder，以 394,579 labelled pairs 和 binary cross-entropy 訓練，並以 no-rerank floor 衡量實際增益。reader 部分從 retrieval train split 合成 40,000 筆 cite-and-abstain examples，將 gold passage 與 2–5 個 shuffled hard negatives 組成編號 context，隨機化 gold position，約 20% 為 abstention；再以 LoRA fine-tune Nemotron-3-Nano-30B-A3B，並混合 206,909 筆 Greek instruction rows 與 English replay。評估使用 nDCG@10、Recall@10、MRR、citation precision/recall/F1、exact citation match、answer correctness、faithfulness、abstention recall 與 false-abstention rate；retrieval 差異採 paired bootstrap，reader correctness 與 faithfulness 使用 served LLM judge。

## 對我們的啟發
- [ ] 在低資源語言部署 RAG 時，不能預設 multilingual dense retriever 優於 lexical search；應將 Greek-aware BM25 作為必要 baseline，並評估 dense、lexical 與 hybrid fusion。
- [ ] 資料合成品質直接影響泛化：應以真實 production queries 進行 few-shot style matching、控制 query difficulty，並避免只用短而關鍵字化的 synthetic queries。
- [ ] RAG pipeline 應分別量測 retrieval coverage、reader correctness、faithfulness、citation quality 與 abstention；沒有 gold passage 的 reader 無法真正解決 retrieval failure，且 reader 評估不應只看 correctness。

## 限制與未來工作

資料主要由 synthetic queries 與 machine-translated instruction data 組成，production query 的比較缺少 query count 與標註 protocol。HERA 僅以兩個強模型交叉驗證並做未記錄規模的人工 spot-check，reader judge 又與題目生成器同家族。end-to-end reader 尚未在實際 retrieved context 上完整評估；未提供 zero-replay ablation，也未與 Greek-adapted reader 或 Multilingual E5 比較。
