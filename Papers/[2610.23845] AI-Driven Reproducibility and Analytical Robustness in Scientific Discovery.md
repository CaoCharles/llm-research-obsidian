# AI-Driven Reproducibility and Analytical Robustness in Scientific Discovery

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.23845)
- 📥 [PDF](https://arxiv.org/pdf/2610.23845v1)

## 摘要（中文翻譯）

可重現性（reproducibility）與分析穩健性（analytical robustness）是科學進步的基礎，但傳統評估通常需要高昂的人工重現與再分析成本。本研究以醫學流行病學為案例，使用美國 Surveillance, Epidemiology, and End Results（SEER）癌症登錄資料庫，建立包含20篇已發表論文及其資料與文件資源的 SEER-Repro benchmark。作者建構 AI agent，對2,190個 atomic claims 成功重現77.4%，並產生可執行的分析基線。接著提出 agentic robustness pipeline，自動辨識每項發現背後的分析選擇、提出具科學合理性的替代方案並重新執行分析。在完全重現的579項發現中，系統標記55項（9.5%）可能受到關鍵分析選擇影響，供專家審查。專家深入檢視10個案例後，9個未證實在合理替代方案下產生實質後果，1個仍需進一步審查。結果顯示，LLM agents 可協助重現研究、系統測試穩健性，並將專家注意力集中於最值得檢查的分析選擇。

## 問題背景

科學研究的可重現性與分析穩健性通常依賴人工重建資料、撰寫程式及測試替代模型，成本高且難以大規模執行。既有 many-analyst 與 multiverse 研究顯示，合理的分析選擇可能導致不同結論，但這類證據主要來自心理學與社會科學，是否適用於高風險醫學流行病學尚不清楚。此外，SEER研究常涉及歷史資料、人口分母、編碼手冊與未明確記錄的分析決策，使忠實重現特別困難。

## 解決方案

作者提出兩部分解決方案。第一，建立 SEER-Repro benchmark，收集20篇近期或高引用的 SEER 論文、39個資料表、40份文件資源及2,190個 atomic claims，形成可執行的研究重現環境。第二，建立由 coding agents、claim verification agent 與 robustness agents 組成的 AI-assisted pipeline：先從論文抽取 findings 並拆解 claims，再產生程式重現原始結果，最後透過獨立報告、Perturbation Agent 與 Direct Coding Agent 測試合理替代分析。系統以 evidence、執行結果及1–9 consequentiality 分數篩選需專家檢視的案例，而非讓模型直接取代專家判斷。

## 核心貢獻
1. 提出 SEER-Repro benchmark，將20篇真實癌症流行病學論文、資料表、手冊、claims、程式與執行證據整合為可評估的重現環境。
2. 建立從 finding 抽取、atomic claim 驗證到可執行分析的 LLM agent 重現流程，量化醫學研究的重現結果與失敗原因。
3. 提出結合獨立分析、分析選擇擾動與直接 coding agent 的穩健性評估管線，將可能重要的案例排序後交由專家審查。

## 技術方法

流程首先從論文排除背景與相關工作，抽取核心 findings，並將每個 finding 拆成單一數值或質性目標的 atomic claims。coding agent 讀取論文、SEER資料與手冊，選擇資料、撰寫並執行分析程式；claim verification agent 再依據執行證據判定 REPRODUCED、CLOSE 或 NOT REPRODUCED。數值 claim 的相對誤差不超過5%視為 reproduced，超過5%且不超過10%視為 close；質性 claim則採二元判定。穩健性分析只納入所有 atomic claims 均成功重現的 findings。Independent Report Generation 讓 agent 重新回答相同研究問題並與原文比較；Perturbation Agent 從 cohort、endpoint、統計模型等分析選擇中最多選20項，提出替代設定，固定其餘流程後執行 baseline 與 alternative；Direct Coding Agent 則直接選擇並測試科學上合理的替代方案。結果分類為 DirectChange、Qualification、StableUnderTest、Inconclusive、Unavailable 或 NotTested。DirectChange 另以改編 GRADE 的1–9分制評估影響，7–9代表主要結論被重大限定、失去支持或反轉。研究使用 GPT-5.6 Sol、Claude Opus 4.8、Kimi K3、GLM 5.3，以及 Codex 和 Claude Code 執行不同分析與交叉比較。

## 關鍵結果

| 評估項目 | 結果 |
|---|---:|
| 納入論文 | 20篇 |
| Findings數量 | 901 |
| Atomic claims總數 | 2,190 |
| Reproduced | 1,694（77.4%） |
| Close | 76（3.5%） |
| Not reproduced | 420（19.2%） |
| 完全重現、進入穩健性分析的findings | 579 |
| 至少一名分析者標記高後果連結（分數7–9） | 55（9.5%） |
| 至少兩名分析者共同標記 | 14（2.4%） |
| 專家深入檢視案例 | 10 |
| 專家認為未證實合理替代造成後果 | 9/10 |
| 仍需進一步審查 | 1/10 |

未重現的420個claims中，資料問題佔251（59.8%）、分析描述不足47（11.2%）、不可用軟體造成的近似28（6.7%）、agent端錯誤48（11.4%）、疑似評估錯誤20（4.8%），另有26（6.2%）原因未解。獨立報告分析在39個可比較報告中未發現會推翻核心結論的矛盾。

## 對我們的啟發
- [ ] 在導入 AI 科學分析系統時，應先要求其重現既有研究並保存程式、輸出與證據，再進一步產生新發現。
- [ ] 重現率不應只被解讀為模型能力指標；歷史資料不可得、研究描述不完整與不可用軟體同樣是關鍵瓶頸，因此 benchmark 必須記錄失敗原因。
- [ ] 穩健性檢查適合採人機協作：LLM agents 負責大規模提出與執行候選替代分析，專家負責判斷替代方案是否合理及其是否真正改變科學結論。

## 限制與未來工作

研究只涵蓋20篇 SEER癌症流行病學論文，外部效度尚未證明。部分歷史資料、人口分母與軟體不可取得，使未重現不一定代表原研究錯誤。穩健性分數主要由模型評估，且專家只深入檢視10個案例；替代分析的科學合理性仍可能受模型或資料處理錯誤影響。
