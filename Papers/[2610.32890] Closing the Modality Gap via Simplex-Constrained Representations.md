# Closing the Modality Gap via Simplex-Constrained Representations

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.32890)
- 📥 [PDF](https://arxiv.org/pdf/2610.32890v1)

## 摘要（中文翻譯）

多模態對比模型（如 CLIP 與 CLAP）雖能學習共享表徵，但其 embedding 通常仍存在持續的 modality gap。本文提出純幾何方法：將 embedding domain 從 unit sphere（S^{d−1}）改為 probability simplex（Δ^{d−1}）。兩者具有相同 intrinsic dimension，但 simplex 的非負性與 unit-mass 約束可作為 structural prior，促使兩種 modality 在相同 coordinate system 中校準。作者在 frozen backbone 上加入 lightweight softmax adapters，並使用 Total Variation similarity；在五個多模態 retrieval benchmarks 上，centroid ℓ2 gap 降低 97–99%。結果顯示，simplicial geometry 可產生實質 semantic alignment，且 retrieval performance 可匹配或超越標準 unconstrained models。

## 問題背景

多模態 contrastive learning 旨在對齊配對資料，但 CLIP、CLAP 等模型的兩種 modality 分布仍可能系統性偏移，造成 cross-modal similarity calibration 不佳、retrieval 受損及 zero-shot decision boundary 扭曲。既有方法多修改 contrastive objective、加入 shared attention 或 adversarial alignment，可能增加架構與訓練複雜度；此外，直接消除 modality gap 也可能破壞 modality-specific structure 與 within-modality geometry。

## 解決方案

作者將問題視為 output geometry 問題，而非必須修改 frozen backbone 或大幅改變訓練目標。對 pooled embedding 加入共享的 lightweight Linear 或 2-layer MLP adapter；Euclidean baseline 將輸出 L2-normalize 至 unit sphere，使用 cosine similarity，而 simplex 版本以 softmax 將 logits 投影至 probability simplex，使用 negative Total Variation distance。其核心創新是利用 simplex 的 nonnegative、unit-mass constraints 限制兩種 modality 共享相同 coordinate system，並透過 softmax 的 global-logit-shift invariance 進行跨模態校準。

## 核心貢獻
1. 提出 simplex-constrained adapters，將 embedding 從 unit sphere 投影至 probability simplex，在五個 audio–text 與 image–text benchmarks 上把 centroid ℓ2 modality gap 降低 97–99%，同時維持或改善 NDCG@10。
2. 提出 geometry-adjusted RelGap，以 modality 內部 spread 正規化 centroid separation，支援 Euclidean 與 simplex domain 間較公平的 gap 比較。
3. 透過 matched-capacity 與 matched-form baseline，以及 Euclidean XAttn 對比 ReTreever，主張 gap closure 主要來自 output geometry，而非額外架構容量或 shared cross-attention。

## 技術方法

作者凍結 LAION-CLAP（audio–text）與 FLAVA（image–text），對每個輸入取得 pooled embedding h，經共享 adapter gθ 產生 logits z。Euclidean 路徑為 e=z/||z||₂，配對分數為 cosine similarity；simplex 路徑為 p=softmax(z)∈Δ^{d−1}，分數為 −TV(p,q)=−1/2||p−q||₁。模型以 paired minibatch 執行雙向 in-batch InfoNCE：分別計算 text→X 與 X→text 的 batch softmax loss，再取平均；訓練 200K steps、AdamW learning rate 4×10⁻⁴、batch size 64，並使用 learnable temperature，trainable parameters 少於 1%。實驗涵蓋 Clotho、SoundDescs、AudioCaps、MS-COCO Captions 與 Flickr30k，評估雙向 NDCG@10。modality gap 使用 centroid ℓ2、silhouette，以及以 modality 內部 spread 正規化的 RelGap。另比較 Linear/MLP、共享 cross-attention 的 XAttn、ReTreever 與 Euclidean MRL，以分離 output geometry、架構容量及 coarse-to-fine scaling 的影響。

## 關鍵結果

主要結果如下；表中數值均來自論文，NDCG@10 分別表示兩個 retrieval 方向。

作者報告：softmax/simplex projection 將 centroid ℓ2 gap 降低 97–99%；在 SoundDescs 上，XAttn 的 centroid ℓ2/RelGap 為 0.309/0.331，ReTreever 為 0.012/0.097；在 Flickr30k 上則分別為 0.527/0.563 與 0.005/0.129。AudioCaps 的 MRL gap 從 2-d 的 0.032 增至 256-d 的 0.534，而 ReTreever 全程低於 0.06。

## 對我們的啟發
- [ ] 在 frozen multimodal backbone 上，加入少量參數的 shared adapter 與 simplex projection，可作為降低跨模態分布偏移的實務方案；但應同時檢查 retrieval 指標，而不能只追求 centroid gap。
- [ ] 評估不同 embedding geometry 時，單看 raw distance 可能受距離尺度影響；應搭配 RelGap、silhouette 與雙向 retrieval，避免把 uniform rescaling 誤判為 alignment 改善。
- [ ] 若系統需要 coarse-to-fine retrieval，論文結果顯示 Euclidean MRL 的 gap 會隨維度增大，而 ReTreever simplex 表徵在實驗解析度中維持較小 gap，幾何選擇可納入效率與校準設計。

## 限制與未來工作

論文僅在五個 paired retrieval benchmarks、兩個 frozen backbone 與少數 adapter 設定中驗證，未提供更廣泛資料分布、任務或 end-to-end backbone 微調結果。作者指出 modality gap 是否應被完全消除仍有爭議；本文也未報告 simplex 對 zero-shot、compositional generalization、訓練穩定性或不同 similarity（JS、Hellinger、KL）的具體實驗數字。
