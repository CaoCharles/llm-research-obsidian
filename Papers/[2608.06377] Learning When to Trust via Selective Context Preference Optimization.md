# Learning When to Trust via Selective Context Preference Optimization

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.06377)
- 📥 [PDF](https://arxiv.org/pdf/2608.06377v1)

## 摘要（中文翻譯）

語言模型日益依賴外部訊號生成答案，而單一具誤導性的訊號可能使原本正確的回答變錯。僅訓練模型抵抗訊號會掩蓋另一項失效模式：完全忽略 context 的模型看似穩健，卻無法在 context 值得信任時受益。本文將問題重新表述為 selective trust，提出由人工標註的 MIST benchmark，讓每個推理題在四種配對條件下呈現：clean、misleading、correct-context 與 irrelevant-context，並提出配對指標 SC2W，計算誤導訊號將 clean 條件下的正確答案翻轉為錯誤的比例。實驗顯示此脆弱性普遍存在。作者進一步提出 SCOPE，挖掘 clean-correct/misleading-wrong 失敗案例，並在四種條件間等量平衡的配對偏好資料上，優化標準 Direct Preference Optimization（DPO）目標，而非只使用 misleading 項目。SCOPE 能降低開放權重模型的 SC2W，同時維持 clean、correct-context 與 irrelevant-context 的準確率。本文主張模型應以 selective trust，而不只是 resistance 來評估。

## 問題背景

現有推理 benchmark 多在單一 context 下評分，無法辨識模型是正確判斷外部訊號，還是乾脆忽略所有訊號。只訓練模型抵抗 misleading context 雖能提升抗干擾表現，卻可能犧牲 clean reasoning、對 correct context 的利用，以及對 irrelevant context 的穩定性。因此論文要解決的是如何同時衡量並學習 selective trust，而不是只追求 resistance。

## 解決方案

作者提出 MIST 與 SCOPE 的組合框架。MIST 對同一題建立四種 matched context，並以 SC2W 隔離 misleading signal 導致的 correct-to-wrong flip；correct-context 與 irrelevant-context 則用來檢查模型是否仍能利用有用訊號並忽略無關訊號。SCOPE 從 base model 找出 clean-correct/misleading-wrong failures，將 truth-consistent response 與 signal-following response 組成配對，並在四種條件中等量重用。其核心創新不在改造 DPO loss，而在以 matched、signal-counterfactual 且 balanced 的 preference data，避免 misleading-only training 導致 blanket distrust。

## 核心貢獻
1. 提出 MIST-1000 benchmark：每個推理題具有 clean、misleading、correct-context、irrelevant-context 四種 matched conditions，以直接衡量模型對外部訊號的選擇性信任。
2. 提出 SC2W 指標，條件化於模型在 clean 條件下已答對的題目，計算 misleading context 將正確答案翻轉為錯誤的比例。
3. 提出 SCOPE，將 clean、misleading、correct-context 與 irrelevant-context 的 matched preference pairs 等量納入標準 DPO，降低誤導訊號脆弱性並保留對有用 context 的敏感度。

## 技術方法

MIST 包含 1,000 個 source items，其中 800 題改編自既有 QA、數學與推理 benchmark，200 題由 annotators 撰寫；每題被渲染成四個 matched conditions。clean 不加入 context；misleading 加入指向 plausible wrong answer 的訊號；correct-context 加入支持 gold answer 的匹配訊號；irrelevant-context 加入相關但不提供答案的文字。四種版本固定問題、答案空間、答案類型、gold answer 與 plausible wrong answer，並經 STEM 背景 annotators 的兩階段審查，檢查答案有效性、錯誤答案 plausibility、自然度、歧義、answer leakage 與格式。

評估採 type-aware final-answer parsing：multiple-choice 比較 option letter、numeric answer 以 10^-4 容差比較、boolean 正規化為 yes/no；無法解析即判錯。報告各條件 accuracy、四條件平均 Overall Acc，以及 SC2W = clean 答對且 misleading 答錯的題數／clean 答對題數。SCOPE 先從 base model 挖掘 clean-correct/misleading-wrong failures，建立同一題的正確完整 response r+ 與 base model 在 misleading 條件下自然生成的錯誤完整 response r−，再將該 response pair 配對至四種 context。訓練使用標準 full-completion DPO，reference model 凍結；DPO 損失由四個條件組成，headline sampling weights 為 misleading、clean、correct-context、irrelevant 各 25%。實驗比較 Prompt-Defense、SFT、misleading-only Standard-DPO、OPSD 與 SCOPE，並進行 construction ablation、held-out analysis、三個外部 benchmark 的 zero-shot transfer，以及 reference-assisted human scoring audit。

## 關鍵結果

| 模型／方法 | Clean Acc. | Misleading Acc. | Correct-Context Acc. | Irrelevant Acc. | Overall Acc. | SC2W |
|---|---:|---:|---:|---:|---:|---:|
| Qwen3-4B（base） | 94.5 | 62.5 | 98.1 | 92.6 | 86.9 | 35.0 |
| Qwen3-4B + SCOPE | 95.0 | 80.7 | 98.1 | 94.3 | 92.0 | 16.3 |
| Llama-3.2-3B（base） | 69.5 | 54.4 | 78.5 | 69.3 | 67.9 | 31.5 |
| Llama-3.2-3B + SCOPE | 72.0 | 63.1 | 80.0 | 71.6 | 71.7 | 20.6 |

作者報告：SCOPE 使 Qwen3-4B 與 Llama-3.2-3B 的 SC2W 分別由 35.0 降至 16.3、由 31.5 降至 20.6；misleading accuracy 分別提升 18.2 與 8.7 個百分點，且兩個模型的三項 control condition 均未下降。MIST 的 23 個 frontier 與 open-weight models 平均 accuracy drop 為 17.1 個百分點。外部 GSM-IC、GSM-Plus 與 Sharma-style sycophancy 評估中，論文報告 SCOPE 在兩個模型家族的四項較高越好指標上均為最佳或並列最佳，但未在本文提供的摘錄中列出完整數值。

## 對我們的啟發
- [ ] 評估外部 context 的可靠性時，不應只比較 clean 與 misleading 條件；必須同時加入 correct-context 與 irrelevant-context，才能區分 selective trust 與一律忽略 context。
- [ ] SC2W 可作為 RAG、搜尋摘要或輔助決策系統的配對診斷指標，隔離「訊號造成的退化」與模型原本就無法解答的題目。
- [ ] 訓練資料若只包含抵抗誤導訊號的偏好對，可能導致 blanket distrust；實務上應以 matched、平衡的非對抗 context 控制資料共同訓練，並檢查各條件的控制準確率。

## 限制與未來工作

MIST 是 text-only、受控的診斷 benchmark，測得的是 susceptibility 而非部署環境中的發生率。緩解實驗僅涵蓋 Qwen3-4B 與 Llama-3.2-3B 兩個模型家族，對更廣泛架構與規模的效果仍未驗證。800 個題目改編自公開 benchmark，無法完全排除 contamination；此外，matched robustness 也不等同於 chain-of-thought faithfulness。
