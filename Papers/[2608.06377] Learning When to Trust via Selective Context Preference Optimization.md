# Learning When to Trust via Selective Context Preference Optimization

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.06377)
- 📥 [PDF](https://arxiv.org/pdf/2608.06377v1)

## 摘要（中文翻譯）

語言模型日益依賴外部訊號生成答案，而單一具誤導性的訊號可能使原本正確的回答變錯。若只訓練模型抵抗此類訊號，可能造成模型忽略所有 context；這類模型表面上更 robust，卻無法在 context 值得信任時加以利用。本文將問題重新定義為 selective trust，提出由人工標註的 MIST benchmark：每道 reasoning 題目都在 clean、misleading、correct-context 與 irrelevant-context 四種匹配條件下呈現，並提出 SC2W 指標，計算 misleading signal 將 clean 狀態下的正確答案翻轉為錯誤的比例。研究發現此 susceptibility 普遍存在。作者進一步提出 SCOPE，挖掘 clean-correct/misleading-wrong 失敗案例，並在四種條件上等量平衡 matched preference pairs，使用標準 DPO 目標進行訓練。SCOPE 能降低 SC2W，同時保留 clean、correct-context 與 irrelevant-context 下的準確率，主張模型應以 selective trust，而非單純 resistance 來評估。

## 問題背景

現有 reasoning benchmark 通常只在單一 context 下評分，無法判斷模型是正確判斷外部訊號，還是乾脆忽略所有訊號。單純訓練 resistance 雖能提高 misleading-context accuracy，卻可能降低 clean reasoning、利用正確 context 的能力，或造成對 irrelevant context 的不當反應。因此本文要測量並訓練模型在誤導、正確與無關 context 間進行 selective trust 的能力。

## 解決方案

作者提出兩部分方案。第一，MIST 將每道題目渲染為四個 matched conditions，並以 SC2W 衡量 misleading signal 是否把模型原本的正確答案翻成錯誤。第二，SCOPE 從 base model 的 clean-correct/misleading-wrong failures 建立 signal-counterfactual preference pairs：偏好 truth-consistent response，而非 signal-following response，並將相同 response pair 複用於 clean、misleading、correct-context 與 irrelevant-context。其核心創新不是修改 DPO loss，而是以 matched pairing 與四條件等量平衡，避免 misleading-only training 導致 blanket distrust。

## 核心貢獻
1. 提出 MIST-1000 benchmark，將相同 reasoning 題目在 clean、misleading、correct-context 與 irrelevant-context 四種匹配條件下評估，以直接測量 selective trust。
2. 提出 SC2W paired metric，條件化於模型在 clean 條件下已答對的題目，量化 misleading signal 導致 correct-to-wrong 翻轉的比例。
3. 提出 SCOPE（Selective Context Preference Optimization），以 matched、signal-counterfactual preference pairs 平衡四種 context 條件，透過標準 DPO 同時學習抵抗誤導訊號與保留有用 context。

## 技術方法

MIST 包含 1,000 個 source items，其中 800 題改編自既有 QA、math 與 reasoning benchmarks，200 題由 annotators 撰寫；每題產生四個 matched versions：clean 不加入 context，misleading 加入指向合理錯誤答案的訊號，correct-context 加入支持 gold answer 的訊號，irrelevant-context 加入相關但不提供答案的文字。四種條件固定問題、答案空間、答案類型、gold answer 與 plausible wrong answer，只改變附加 context。STEM 背景 annotators 進行候選篩選、撰寫與第二輪驗證，檢查答案有效性、錯誤答案合理性、自然度、歧義、answer leakage 與格式。

評估使用 deterministic、type-aware final-answer parsing。各條件 accuracy 為正確答案比例，Overall Acc 是四條件平均；SC2W 定義為 clean 答對且 misleading 答錯的題數，除以 clean 答對題數，用來隔離 signal-induced failures。SCOPE 從 item-disjoint training pool 挖掘 base model 在 clean 正確但 misleading 錯誤的案例，建立正確 full-completion response 與 base model signal-following 錯誤 completion 的 preference pair。相同 pair 分別配上四種 context，形成 Dmis、Dclean、Dcor 與 Dirr。模型使用標準 full-completion DPO，reference model 冻結；headline sampling weights 為四條件各 25%，即 λm=0.25、λc=0.25、λp=0.50、ρ=0.50。實驗比較 Prompt-Defense、SFT、misleading-only Standard-DPO、OPSD 與 SCOPE，並以 paired item-level bootstrap uncertainty 評估 MIST 結果；另在 GSM-IC、GSM-Plus 與 Sharma-style sycophancy examples 上進行 zero-shot transfer。

## 關鍵結果

主要結果如下（數值均為百分比；Acc 越高越好，SC2W 越低越好）：

| 模型/方法 | Clean Acc. | Misleading Acc. | Correct-Context Acc. | Irrelevant Acc. | Overall Acc. | SC2W |
|---|---:|---:|---:|---:|---:|---:|
| Qwen3-4B | 94.5 | 62.5 | 98.1 | 92.6 | 86.9 | 35.0 |
| Qwen3-4B + Prompt-Defense | 92.8 | 80.2 | 96.5 | 94.0 | 90.9 | 18.3 |
| Qwen3-4B + SFT | 93.4 | 81.0 | 96.7 | 92.8 | 91.0 | 17.4 |
| Qwen3-4B + Standard-DPO | 91.7 | 80.5 | 95.4 | 92.5 | 90.0 | 19.1 |
| Qwen3-4B + OPSD | 93.2 | 80.3 | 95.9 | 91.2 | 90.2 | 20.1 |
| Qwen3-4B + SCOPE | 95.0 | 80.7 | 98.1 | 94.3 | 92.0 | 16.3 |
| Llama-3.2-3B | 69.5 | 54.4 | 78.5 | 69.3 | 67.9 | 31.5 |
| Llama-3.2-3B + Standard-DPO | 70.9 | 63.3 | 56.4 | 70.6 | 65.3 | 23.3 |
| Llama-3.2-3B + SCOPE | 72.0 | 63.1 | 80.0 | 71.6 | 71.7 | 20.6 |

論文報告：在兩個可訓練模型上，SCOPE 將 SC2W 從 35.0 降至 16.3（Qwen3-4B），以及從 31.5 降至 20.6（Llama-3.2-3B）；misleading accuracy 分別提升 18.2 與 8.7 個百分點，且三個控制條件均未下降。23 個 frontier 與 open-weight models 的平均 misleading signal accuracy drop 為 17.1 個百分點。SCOPE 在 GSM-IC、GSM-Plus 與 Sharma-style sycophancy 外部套件上 zero-shot transfer，論文指出其四項較高越好指標皆為最佳或並列最佳，但未在本文提供的內容中報告完整數值。

## 對我們的啟發
- [ ] 實務評測不應只比較 clean 與 misleading accuracy；應同時納入 correct-context 和 irrelevant-context，否則無法區分真正的 selective trust 與對所有外部資訊的 blanket rejection。
- [ ] SC2W 可作為 RAG、搜尋摘要或輔助決策系統的診斷指標，特別適合識別「模型原本會答對、加入外部訊號後反而答錯」的失敗。
- [ ] 訓練資料的條件平衡與 matched pairing 可能比更換 preference optimizer 更關鍵；論文結果顯示，僅以 misleading pairs 訓練容易換取 resistance，卻損害 correct-context 等控制條件。

## 限制與未來工作

論文的 MIST 是受控、純文字診斷 benchmark，測量的是 susceptibility 而非實際部署中的訊號出現頻率。訓練實驗只涵蓋 Qwen3-4B 與 Llama-3.2-3B，較廣泛的模型架構與規模仍未驗證。多數題目改編自公開 benchmark，不能完全排除 contamination；此外，matched robustness 不等同於 chain-of-thought faithfulness。
