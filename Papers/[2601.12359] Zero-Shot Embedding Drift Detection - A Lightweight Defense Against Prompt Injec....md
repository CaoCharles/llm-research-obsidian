# Zero-Shot Embedding Drift Detection: A Lightweight Defense Against Prompt Injections in LLMs

## 摘要（中文翻譯）

Prompt injection 攻擊已成為 LLM 應用日益嚴重的安全漏洞，對抗性 prompt 利用電子郵件或使用者生成內容等間接輸入管道繞過對齊防護，誘導有害或非預期輸出。即使最先進的 LLM 仍廣泛易受對抗性 prompt 影響，亟需魯棒、高效且可泛化的偵測機制。本文提出 ZEDD（Zero-Shot Embedding Drift Detection），一個輕量級框架，透過量化良性與可疑輸入間在嵌入空間中的語義偏移來辨識直接和間接 prompt injection。ZEDD 無需存取模型內部、不需預知攻擊類型、無需任務特定重訓練，可在多種 LLM 架構上零樣本部署。使用對抗-乾淨 prompt 配對，透過餘弦相似度量測嵌入漂移。在 LLMail-Inject 資料集（涵蓋五類注入）上，ZEDD 在 Llama 3、Qwen 2、Mistral 等架構上達到 93% 以上準確率，誤報率低於 3%。

## 問題背景

LLM 應用面臨 prompt injection 攻擊的廣泛威脅，現有防禦方法要嘛需存取模型內部（不適用於黑箱 API）、要嘛需針對特定攻擊類型訓練（難以泛化到新攻擊）、要嘛計算開銷過大（不適合即時部署）。需要一種輕量級、模型無關且零樣本的偵測方案，能作為通用防禦層整合到現有 LLM 管線中。

## 解決方案

ZEDD 利用嵌入空間中的語義漂移作為 prompt injection 的通用信號。核心假設是：注入的對抗性 prompt 會在嵌入空間中與其乾淨對照產生可量化的語義偏移。框架流程為：(1) 使用微調編碼器提取輸入的向量表徵；(2) 透過餘弦相似度計算語義漂移 Drift = 1 - cos(x, x')；(3) 使用高斯混合模型（GMM）和核密度估計（KDE）分析漂移分布，標記可疑 prompt。方法無需模型內部存取、不需預知攻擊類型，支援零樣本跨架構部署。

## 核心貢獻
1. 提出以嵌入空間語義漂移（embedding drift）作為 prompt injection 偵測的通用信號，實現零樣本、模型無關的輕量級偵測框架
2. 建構並重新標註 LLMail-Inject 綜合資料集，涵蓋五類注入（jailbreak、system leak、task override、encoding manipulation、prompt confusion），共 51,603 個配對樣本
3. 在 Llama 3、Qwen 2、Mistral 等多架構上達到 93% 以上偵測準確率，誤報率低於 3%，微調時間僅需 15-18 分鐘

## 技術方法

**偵測框架**：
1. **嵌入提取**：使用 Sentence-BERT (All-MPNET Base V2) 等編碼器，經約 15-18 分鐘的微調，提取輸入的向量表徵
2. **漂移計算**：對每個輸入，計算其與乾淨基準的餘弦距離 Drift(x, x') = 1 - cosine_similarity(x, x')，高漂移值表示可能的注入
3. **分布建模**：使用 GMM 和 KDE 分析漂移值分布，設定閾值區分正常與異常

**資料集**：LLMail-Inject，涵蓋五類注入攻擊，共 51,603 個對齊配對（25,801 乾淨-乾淨 + 25,802 注入-乾淨）

**測試模型**：Sentence-BERT All-MPNET Base V2、Llama 3 8B Instruct、Mistral 7B Instruct、Qwen 2 7B Instruct

**硬體**：NVIDIA B200 GPU，微調約 15-18 分鐘/模型

## 關鍵結果

| 模型 | 準確率 | F1 分數 | 誤報率 |
|------|--------|---------|--------|
| Sentence-BERT | 95.55% | 95.50% | <3% |
| Llama 3 8B | 93.2%+ | 92.8%+ | <3% |
| Mistral 7B | 90.75%+ | 89.84%+ | <3% |
| Qwen 2 7B | 93%+ | — | <3% |

**各攻擊類別偵測率**：
| 攻擊類別 | 偵測率 |
|----------|--------|
| Encoding Manipulation | 98.2% |
| Task Override | ~95% |
| System Leak | ~93% |
| Prompt Confusion | ~90% |
| Jailbreak | 81.78% |

## 對我們的啟發
- [ ] 嵌入漂移作為 PI 偵測信號具有跨架構遷移性，這意味著可以建立一個通用的前置偵測層，部署在任何 LLM 管線前端，無需針對每個模型重新訓練
- [ ] Jailbreak 類攻擊的偵測率最低（81.78%）暗示語義層面較微妙的攻擊更難透過嵌入漂移捕捉，需要結合其他防禦層（如 InstruCoT 的 CoT 推理）
- [ ] 15-18 分鐘的微調成本極低，使此方法可作為 LLM 安全部署的「最小可行防禦」，特別適合資源受限的團隊快速部署

## 限制與未來工作

偵測品質高度依賴嵌入模型的選擇，不同模型規模可能表現不一致。作為偵測層而非防禦層，ZEDD 只能標記可疑輸入但無法直接阻止攻擊，需與其他防禦機制配合使用。對語義微妙的 jailbreak 攻擊偵測率偏低（81.78%），表明自適應對手可能繞過嵌入漂移偵測。
