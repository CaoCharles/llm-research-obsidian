# AaLLM: An End-to-End Analog Circuit Design Framework from Topology Generation to Sizing Using Large Language Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.13472)
- 📥 [PDF](https://arxiv.org/pdf/2608.13472v1)

## 摘要（中文翻譯）

Analog 電路設計是在非線性、高維度設計空間中進行的耗時迭代流程，高度依賴專家直覺。現有 LLM 方法多半只處理 sizing 或 topology generation，且需要人工加入技術知識，可能造成 circuit sizing hallucination；不同規格間的取捨也使設計反覆而繁瑣，並限制創新 topology 的產生。本文提出 AaLLM，一個開源、端到端的 multi-agent LLM workflow，輸入使用者規格後輸出包含 topology generation 與 circuit sizing 的 netlist。系統自動從論文與教科書建立 knowledge base，使用 RAG 模擬電路設計專業知識，並以 Designer、Critic、Evaluator 組成 tri-agent feedback system。另以 fine-tuned Seq2Seq 模型產生新穎 topology。實驗顯示，新 topology 的 FoM 可與已知 topology 相當，部分電路最高提升 3 倍；相較 SOTA multi-agent LLM pipelines，SPICE calls 減少 3 至 4.5 倍，wall-clock time 減少 40 倍。

## 問題背景

類比電路設計同時包含 topology selection 與 parameter sizing，具有非線性、高維度及多規格取捨。既有 LLM 方法多聚焦單一階段，常依賴人工技術知識或單次生成，可能產生違反 device physics 的 sizing hallucination；既有 topology 方法則受限於小型 library，或生成大量難以驗證的候選。因此缺少能以知識支援、模擬驗證並端到端完成 topology 與 sizing 的統一流程。

## 解決方案

作者提出 AaLLM，將 fine-tuned FLAN-T5 topology generator、RAG-based topology selector 與 SPICE-in-the-loop tri-agent sizing system 串成端到端流程。Topology generator 以固定格式的 bipartite component-node matrix 產生 conventional 與 novel candidates；RAG 從論文、教科書及 PDK 文件檢索電路理論，協助選擇 topology 與 sizing。Sizing 則分離 Critic 的診斷、Evaluator 的策略仲裁和 Designer 的參數修改，並以 curriculum controller 依序處理 DC、AC 與 transient 目標。核心創新是將 topology synthesis、知識檢索、模擬驗證與多代理 sizing 置於同一自動化 pipeline。

## 核心貢獻
1. 提出涵蓋 topology generation、topology selection 與 circuit sizing 的開源端到端 AaLLM framework。
2. 在 topology selection 與 sizing 階段導入 RAG，結合 semantic retrieval、BM25 與 contextual augmentation，從類比電路論文、教科書及 PDK 文件提供設計知識。
3. 提出 Designer、Critic、Evaluator 三代理 sizing loop，搭配 SPICE feedback、physics heuristics、matching constraint 與 curriculum-based optimization，以降低 sizing iterations。

## 技術方法

AaLLM 將設計問題形式化為同時尋找 topology T 與參數向量 x，使所有性能約束 c_k(T,x)<0。首先，specification resolver 將使用者的 inequality constraints 與 fine-tuning 規格範圍相交，並對每項規格取有效區間中點；超出訓練範圍時則夾到邊界並發出警告。Topology 以 bipartite component-node matrix 表示，包含 component-type vector、元件與 net 名稱，以及固定長度的 connection matrix。Fine-tuned FLAN-T5 Seq2Seq 模型以規格文字和 masked matrix template 為輸入，透過三階段 curriculum 學習連接生成、元件排列與同時預測元件類型及連接。每個規格產生多個候選，先以預設參數進行 SPICE，按加權規格距離排序，再由 RAG selection agent 選擇。RAG knowledge base 來自論文、教科書與 PDK 文件，採 contextual augmentation；檢索同時使用 dense semantic index 與 BM25 keyword index，再以 weighted reciprocal-rank fusion 合併，並可在 ReAct loop 中進行 web scraping。Sizing 階段由 Critic 根據 SPICE 結果診斷未達規格的元件與嚴重程度，Evaluator 分析歷史趨勢、停滯或退化並給出策略，Designer 執行 SET、SCALE 或 OFFSET 參數修改。流程以 SPICE 閉迴路迭代，並依序處理 DC biasing、AC analysis、transient analysis，後續階段若使早期規格退化可回退。評估使用 Pass@1、規格成功率、FoM、iterations、LLM calls 與 SPICE simulations。

## 關鍵結果

| 評估項目 | AaLLM 結果／比較 |
|---|---|
| Topology structural validity | Pass@1 = 100%，涵蓋 24 個 OPAMP target specs |
| Topology electrical validity | Pass@1 = 100%，定義為 SPICE convergence 且 gain 為正 |
| Novel topology vs canonical Miller（12 tasks、每 task 2 seeds） | Novel：FoM 平均 0.394、22/24 成功；Canonical：FoM 平均 0.454、22/24 成功 |
| Tri-agent sizing success | 24 個 target specs 的 test bench 中達成所有目標規格的比例為 91.6% |
| AaLLM vs AnaFlow | 同一 45 nm ASU PTM canonical Miller benchmark：AaLLM 使用 2 次 SPICE calls，AnaFlow 使用 9 次；作者報告 wall-clock time 減少 40 倍 |
| AaLLM vs Atelier | 4 個 two-stage circuits、每電路 2 seeds：AaLLM 成功 8/8、使用 9104 次 simulations；Atelier 成功 4/8、使用 2540 次 simulations |
| Ablation（two-stage Miller OTA） | 完整 AaLLM：10.3 iterations、31.0 LLM calls、gain 50.7 dB、UGB 19.45 MHz；移除 RAG：17.3 iterations、49.7 LLM calls、gain 48.1 dB、UGB 11.24 MHz |
| Active filters | 在 SK LPF、SK HPF、MFB BPF 的展示案例中，表 VI 所列 gain、frequency、selectivity 與 power 均達到目標；論文未報告更大規模的 filter success rate。

## 對我們的啟發
- [ ] 對需要工具互動的工程任務，可將生成、診斷、策略仲裁與參數修改拆分為不同 agent，並以 simulator 或其他外部工具作為客觀 feedback。
- [ ] RAG 系統同時結合 semantic search 與 keyword search，對具有相近縮寫或精確技術術語的電路規格較具實務價值；但其效果仍應透過移除 RAG 的 ablation 驗證。
- [ ] 將離散 topology generation 與連續 parameter sizing 分成不同模型與階段，並用中間的 SPICE 預篩和知識檢索銜接，有助於建立可重現的端到端評測流程。

## 限制與未來工作

論文主要在 SkyWater 130 nm 與 ASU PTM 45 nm、OPAMP 及少量 active-filter 拓撲上驗證，跨製程、電路類型與更大 topology space 的泛化仍未充分量化。雖報告 novel topology，但未提供完整的新穎性判定流程或資料規模；RAG 自動抓取資料的錯誤與知識庫品質影響也未作系統性分析。與 Atelier 的 simulation 總量比較數字顯示其使用較多 simulations，與摘要所稱效率改善需依具體 benchmark 解讀。
