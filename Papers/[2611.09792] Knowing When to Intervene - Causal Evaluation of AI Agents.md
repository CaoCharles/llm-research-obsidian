# Knowing When to Intervene: Causal Evaluation of AI Agents

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.09792)
- 📥 [PDF](https://arxiv.org/pdf/2611.09792v1)

## 摘要（中文翻譯）

目前對 agentic AI systems 的評估主要依賴 benchmarks；然而，benchmark 的靜態特性無法說明部署時進行 auditing intervention 的價值。為了可靠部署，我們常需在 agent trajectory 中判斷是否介入，例如驗證當前輸出、引導 agent 改變行為，或使用 human review、成本更高的模型與耗時的 agentic supervision。這種介入的價值本質上是 causal inference 問題：介入對最終結果的 causal effect 是否有益。估計此效果相當困難，因為介入影響取決於當前 context、environment 與 agent 未來行為。本文提出首個具方法論基礎的 framework，用於評估 agent trajectory 內 randomized intervention 的 causal effects。透過在 trajectory 中隨機化 verification 或 screening 等介入，少量 trajectory data 即可估計豐富的 contextual intervention policies。估計所得的 structural parameters 也可建立反映 agentic actions risk 的 safety leaderboards，以協助 audit prioritization。作者在 tau-bench Retail、ToolSandbox 與 ImpossibleBench 上發現，介入效果會隨 agent actions 與 states 顯著變化。

## 問題背景

現有 agent 評估多以固定任務、環境與終端分數衡量成功或安全，無法回答部署中「在某個 trajectory decision 是否應介入」以及介入是否會改善最終結果。觀察性 trajectory 只能找出可能的介入點，不能識別 causal effect；即使進行 trajectory-level randomization，也難以處理中途介入對後續 states、actions、介入機會與終端 outcome 的動態影響。

## 解決方案

作者提出以 sequential randomization 與 micro-randomized trials 為基礎的 causal evaluation framework。在每個符合資格的 decision point，記錄 pre-assignment history、agent proposed action 與 environment context，再以已知機率隨機分配 intervention 或 control，讓 agent 繼續執行。框架定義三類 estimand：在後續介入仍隨機化下的 blip effect、後續不再介入下的 blip effect，以及相對於永不介入的 target policy gain。前者使用 cross-fitted AIPW，後兩者使用 continuation-specific SNMM 與 g-estimation，並可按 tool、task stage、failure pattern 等 history-defined groups 建立 decision-impact 或 safety leaderboard。

## 核心貢獻
1. 提出適用於 agent trajectory 中途介入的 sequentially randomized causal evaluation framework，不需存取 agent internal state，也不要求 Markovian 或 stationary interaction model。
2. 形式化三種互補 causal estimand：randomized-continuation blip、no-treatment-continuation blip 與 policy gain，並分別提出 AIPW、SNMM 與 g-estimation 方法。
3. 在 tau-bench Retail、ToolSandbox 與 ImpossibleBench 實證顯示介入效果高度依賴 tool、能力、任務進度與 agent state，並展示以 causal effect 建立 intervention prioritization 與 safety leaderboard 的可行性。

## 技術方法

Agent 被視為與 environment 互動的 black box；trajectory 從 task input X 開始，於 eligible intervention points t 觀測 Lt，形成 pre-assignment history Ht，並記錄 binary assignment At。資料收集採 sequential randomization：At|Ht 服從 Bernoulli(e(Ht))，實驗中每個 eligible point 以 1/2 機率分配 intervention 或 control；較早介入可改變後續 agent actions、environment states、trajectory 長度與介入機會。終端 outcome Y 在 tau-bench Retail 為 task success、ToolSandbox 為 similarity score、ImpossibleBench 為 detected rule violation。作者估計三種 estimand：τ(G;g) 衡量當下介入且後續維持 randomized continuation 的 group-averaged blip；τ(G;0) 衡量當下介入但後續完全不介入的效果；Δ(G) 衡量只在 history 屬於 G 時介入的 selective policy 相對 never-intervene policy 的 value gain。τ(G;g) 使用已知 assignment probability 的 cross-fitted AIPW，並搭配 outcome prediction；τ(G;0) 與 Δ(G) 使用 continuation-specific SNMM 與 g-estimation，因此需額外的 parametric blip-effect model 假設。實驗涵蓋 GPT-5 nano、Claude Haiku 5.5 與 Qwen3.5 Flash；reviewer 為 GPT-6 Luna。分析按 capabilities、operations、individual tools、task progress、test conflicts 與 prior failures 分組，並以 pointwise 95% Student’s t confidence intervals 報告結果。

## 對我們的啟發
- [ ] 實務上不應只依賴整體 benchmark success rate；應針對 tool type、task stage、prior failure 與其他可觀測 history 分層估計 intervention effect，以找出真正值得 review 的決策點。
- [ ] 介入策略的價值不能由單一 decision 的效果直接相加，因為 intervention 會改變後續 trajectory 與可介入機會；部署策略應以 policy gain，而非僅以局部 blip effect，評估整體結果。
- [ ] 可先以 sequential randomization 找出高風險或高收益候選點，再以獨立 randomized controlled trial 驗證；對 rare tools、multiple comparisons 與依賴 SNMM 假設的估計，應避免直接視為確定性安全結論。

## 限制與未來工作

AIPW 的 randomized-continuation blip 較少依賴 outcome model，但 no-treatment continuation 與 policy gain 的 SNMM 需要正確指定 parametric blip-effect model，錯置時只能解讀為 weighted projection。實驗使用相對較小模型與既有 benchmarks，且 history features 多為手工設計；結果未處理 multiple comparisons。未來需評估 frontier agents、更長期任務、語義化 intervention opportunity detector，以及更自適應的 history representation。
