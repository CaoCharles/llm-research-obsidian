    Hallucination or Creativity: How to Evaluate AI-Generated Scientific Stories

    連結

    • 📄 arXiv
    • 📥 PDF

    摘要（中文翻譯）

    本研究探討如何區分 AI 生成科學敘事中的合理抽象和事實幻覺。科學傳播需要將複雜研究轉化為易懂的故事，這涉及適度的簡化和比喻，但過度發揮可能導致事實扭曲。LLM 在生成科學故事時面臨微妙的平衡：既要保持敘事吸引力，又要確保科學準確性。論文提出創新的評估框架，使用具有完整上下文的 LLM 評判者來判斷生成內容。關鍵洞察是：幻覺與創意的界限取決於是否有原始證據支持。評判者接收原始科學文獻和生成的故事，產生結構化 JSON 判決，標註每個陳述的事實性、創意合理性和潛在誤導性。實驗顯示該方法在識別幻覺方面達到人類專家水平，為科學 AI 應用提供可靠的品質保證機制。

    問題背景

    AI 生成的科學故事需要在敘事吸引力和事實準確性間平衡，但現有評估方法難以區分合理的創意抽象和事實幻覺。傳統事實檢查過於嚴格，會將合理的比喻也標記為錯誤；而寬鬆評估又可能放過嚴重的事實扭曲。科學傳播領域缺乏能夠理解這種微妙差異的自動化評估工具。

    解決方案

    提出基於 LLM 評判者的評估框架，核心創新包括：(1) 完整上下文評估機制，評判者同時接收原始科學文獻和生成故事；(2) 多維度判斷標準，區分事實準確性、敘事合理性和潛在誤導性；(3) 結構化 JSON 輸出，為每個陳述提供細粒度評分和證據溯源。框架設計專門的提示工程，引導評判者理解科學傳播中合理的抽象和不可接受的扭曲之間的界限。

    核心貢獻

    1. 提出區分科學敘事中創意抽象與事實幻覺的評估框架和判斷標準
    2. 設計基於完整上下文的 LLM 評判者系統，產生結構化 JSON 判決
    3. 在科學故事資料集上達到與人類專家相當的評估準確度（F1=0.87）

    技術方法

    框架包含三個核心組件。首先，上下文構建模組提取原始科學文獻的關鍵事實和數據，作為評判基準。接著，陳述解析模組將生成的故事分解為原子陳述，每個陳述對應一個可驗證的資訊單元。最後，評判模組對每個陳述執行多維評估：(1) 事實準確性 - 是否有原文支持；(2) 抽象合理性 - 簡化或比喻是否保持本質；(3) 誤導風險 - 是否可能造成錯誤理解。評判者使用 chain-of-thought 推理，引用原文證據，最後產生 JSON 格式判決。在包含 500 篇 AI 生成科學故事的資料集上評估，與人類專家標註對比，測量檢測幻覺和創意的精確率、召回率。

    關鍵結果

    評估維度 精確率 召回率 F1 分數 人類一致性
    事實幻覺檢測 89.3% 84.7% 0.87 0.85
    合理創意識別 82.1% 88.5% 0.85 0.83
    誤導風險評估 76.8% 79.2% 0.78 0.74
    整體判斷 85.4% 86.1% 0.86 0.84

    對我們的啟發

    • 幻覺與創意的界限不是二元的，而是頻譜：關鍵在於抽象是否保留科學本質
    • LLM 評判者在有完整上下文時表現接近人類專家，證明上下文對準確評估至關重要
    • 結構化 JSON 輸出不僅提供判斷結果，還包含證據溯源，增強評估的可解釋性和可信度

    限制與未來工作

    評判者依賴高品質原始文獻，若原文本身有誤或不完整，評估準確性會下降。方法主要在生物醫學領域驗證，其他科學領域的適用性需進一步測試。LLM 評判者可能繼承訓練資料中的偏見，對某些類型的創意表述過於寬鬆或嚴格。計算成本較高，處理一篇故事需要 2-5 分鐘。
