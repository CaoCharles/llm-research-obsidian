# Actions Speak Louder than Words: Measuring Cross-Lingual Policy Retention in Tool-Using Agents

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.11110)
- 📥 [PDF](https://arxiv.org/pdf/2608.11110v1)

## 摘要（中文翻譯）

當 tool-using agent 以不同語言接收相同任務時，是否仍會採取相同步驟？現有 multilingual evaluation 多比較 final answer，丟棄中間 actions；但對 agent 而言，action route 決定成本、延遲、失敗模式與可稽核性。本文在 8 個模型、6 個平行 benchmarks、41 種語言上執行 238 萬次 rollouts，將 action policy 作為跨語言評估對象。作者辨識並修正五項 confounds：短 trace 偏高、empty trace 得到完美分數、無關 trace 的 chance floor、模型自身 reproducibility 造成的 ceiling，以及缺乏 same-language baseline。以自身 reproducibility 正規化後，四個 frontier models 在 greedy decoding 下跨語言保留約 71–73% 的 action policy；10B parameters 以下則不穩定。實驗也顯示 agents 會透過 English pivot 處理非英語任務，且難以藉由指令移除。最後，作者證明單一 trace-extraction regex 可製造假性 multilingual failure，兩個 worked examples 使某模型 measured accuracy 提高 26 倍，但 readable outputs 的準確率幾乎不變。

## 問題背景

現有 multilingual evaluation 多以 final answer agreement 或 accuracy 衡量，忽略 agent 執行任務時的工具呼叫順序與中間 route，因此無法辨識相同答案背後的成本、延遲、失敗模式與治理風險。直接比較跨語言 trace similarity 又受短序列偏誤、empty trace、chance agreement、sampling ceiling 及模型自身不 reproducible 等因素干擾，且缺乏 same-language baseline，使跨語言 policy retention 在方法上難以識別。

## 解決方案

作者把 executed action trace 定義為跨語言評估的主要對象，建立固定五工具 alphabet 與平行 task scaffold，使各語言只改變自然語言呈現而保留任務與工具空間。方法以相同模型的 same-language replicates 估計 Iwithin，再以跨語言配對估計 Icross，並以 Icross/Iwithin 進行 ceiling correction。配合雙向 length matching、empty-trace exclusion、permutation chance-floor correction、temperature ladder 與 task-level bootstrap，逐項排除 metric confounds。作者亦以 Translate 的 removal、mandate 與預先註冊的 head-room prediction，將 English pivot 從相關觀察推進至 action-level 因果檢驗。

## 核心貢獻
1. 提出 ceiling-corrected 的 cross-lingual policy retention estimand，以 same-language self-consistency 作為 baseline，估計語言轉換後仍保留多少自身 action policy。
2. 系統性量化五項 trace similarity confounds，包含 trace length、empty traces、chance floor、reproducibility ceiling 與缺乏同語言參照，並以 length matching、嚴格 empty-trace 排除、replicates 與 permutation 等方式修正。
3. 在大規模 multilingual agent evaluation 中證明跨語言 action divergence 具有結構性，並以 English-pivot removal、mandate 與 pre-registered prediction 檢驗其因果角色。

## 技術方法

作者將 5,776 個已驗證跨語言對齊的任務，取自 FLORES-200、XQuAD、XNLI、Belebele、XCOPA 與 synthetic benchmark，渲染為 41 種語言。所有模型使用相同 tool-use scaffold，工具包括 Search、Calc、Translate、Summarize 與 Finish；模型需輸出 Thought/Action 格式，trace 由單一 regex 擷取，工具呼叫只解析、不實際 dispatch，因此測量的是 induced tool-use policy。研究涵蓋 Gemma-3-27B、Sarvam-M、Qwen3-235B-A22B、Llama-4-Maverick、GPT-OSS-120B，以及 Gemma-3-4B、Qwen3-8B、Aya-Expanse-8B。每個 task-language instance 以相同 task、prompt、token budget 與 decoding 設定產生兩次 replicate，僅改 serving seed；same-language replicates 用於估計 Iwithin，跨語言 replicates 用於估計 Icross。核心指標為 normalized retention Ĩ=Icross/Iwithin，表示語言改變後保留自身 reproducibility 的比例。比較時進行雙向 length matching，排除任一 trace 為 empty 的 pair，並以 task-level bootstrap 建立區間。另以 permutation 估計不同任務 trace 的 chance floor c，分析五項 confounds；以 T∈{0,0.3,0.5,0.7,1.0} 分離 sampling noise 與 language effect。機制實驗移除或 mandate Translate，並操弄 Thought 的語言；另進行 trace length manipulation、few-shot parser repair、self-consistency voting 與 gold-answer accuracy 評估。

## 關鍵結果

| 評估項目 | 主要結果 |
|---|---|
| 規模 | 8 models、6 benchmarks、41 languages、505 cells、2,382,875 rollouts |
| Greedy decoding 的 pooled raw gap | length-matched gap 為 +0.2074；24/24 cells 的 bootstrap interval 均排除 0 |
| Sampling temperature | cross-lingual agreement 在 T=0 至 1.0 間近乎平坦，整段變化量 Δ=0.009；self-consistency 隨 temperature 顯著下降 |
| Frontier policy retention | 四個模型在 T=0 的 normalized retention 為約 71–73%， pooled band 寬度 2.6 個百分點 |
| 變異解釋 | T=0 時 model identity 僅解釋 5.7% variance，benchmark 解釋 26.9%；T=0.5 時 model identity 為 74.8% |
| 小模型邊界 | 低於約 10B parameters 的 retention 不穩定；Gemma-3-4B=0.6259、Qwen3-8B=0.8016，均偏離 frontier band [0.708, 0.733]；Aya-Expanse-8B 因 31.2% empty traces 被視為 adherence failure |
| English pivot | Translate 是 adapted benchmarks 中 compliant models 最常用工具；reasoning text 約 99% ASCII。移除 Translate 後，三個模型多數 benchmark 的 length-matched agreement 下降；mandate 的方向預測在四模型上以 5/6、5/6、3/6、2/6 benchmarks 符合 |
| 指令移除 pivot | 要求以 task language 思考時，Gemma 僅 0.79%、Sarvam 僅 0.08% 非拉丁文字 Thought，均低於 1% compliance |
| Parser artifact | GPT-OSS-120B 的 two worked examples 使 measured accuracy 提高 26 倍，但 accuracy on scorable/readable outputs 幾乎不變；0-shot empty-trace rate 為 76.4% |
| Correctness 與 invariance | Qwen3 在 XCOPA 最佳與最差語言的 accuracy 為 0.990 對 0.330；論文指出 invariance 與 correctness 不可互相取代，adherent models 間相關約 r=+0.38 |

## 對我們的啟發
- [ ] 評估 tool-using agent 時不應只看 final answer；應同時記錄 action sequence、工具成本、延遲與失敗路徑，因為答案相同不代表行為或風險相同。
- [ ] 跨模型比較應先校正模型自身 reproducibility 與 chance floor；未校正的 absolute gap 可能只是 sampling determinism、trace length 或短序列偏誤，甚至導致模型排名反轉。
- [ ] agent benchmark 的 parser 與格式遵循度必須獨立報告；可加入多樣化 trace extraction、worked examples 與 parse-failure threshold，避免把不可解析誤判為能力或 multilingual failure。

## 限制與未來工作

研究比較的是固定 scaffold 下、工具只被解析而未真正執行的 induced policy，尚未測試工具輸出改變環境狀態時的 divergence。frontier regularity 主要基於 4 個模型，10B 以下則只有 2 個 clean models；第四供應商模型因 parse failure 被排除。trace similarity metric 未與其他距離函數比較，reason-in-task-language manipulation 也未成功。
