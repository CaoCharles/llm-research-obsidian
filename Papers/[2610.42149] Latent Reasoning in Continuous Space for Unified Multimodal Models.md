# Latent Reasoning in Continuous Space for Unified Multimodal Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.42149)
- 📥 [PDF](https://arxiv.org/pdf/2610.42149v1)

## 摘要（中文翻譯）

Unified Multimodal Models（UMMs）在多種多模態理解與生成任務上表現出色，但仍難以有效利用語言式 chain-of-thought（CoT）推理來生成影像，因此現有 reasoning-augmented UMMs 通常無法繼承大型語言模型所呈現的 test-time scaling 與細粒度控制能力。作者將此歸因於模態不匹配：推理在離散 token space 中進行，而影像生成在 continuous space 中運作。為此，本文提出 Latent Reasoning framework in Continuous space（LARC），讓模型在 continuous hidden states 上推理。訓練包含兩階段：curriculum supervised fine-tuning（SFT）逐步將 token-level reasoning 轉換為 latent reasoning；information-gain reinforcement learning（RL）則在沒有 ground-truth reasoning chain 的情況下自我演化 latent reasoning。實驗顯示，LARC 能提升影像品質、prompt following 與 compositional fidelity，並在 GenEval 上取得相較 BAGEL 高 7 個百分點的結果；同時，增加 latent reasoning 計算量會帶來明確且單調的 test-time scaling 效果。

## 問題背景

現有 UMM 將語言推理限制在離散 token space，難以表達影像生成所需的密集、空間對齊與細粒度資訊，推理往往退化為表層 prompt manipulation。相較 LLM 的 CoT，既有 reasoning-augmented UMMs 也未呈現穩定的 test-time scaling；增加推理預算未必改善生成結果，且缺乏可直接監督 latent reasoning trace 的 ground truth 或外部評估器。

## 解決方案

作者提出 LARC，將推理步驟表示為 UMM understanding expert 產生的 continuous hidden states，並讓 image-generation module 直接透過 cross-attention 使用完整 reasoning trajectory。第一階段以 curriculum SFT 從純文字 CoT 開始，逐步啟用 latent steps；第二階段以 frozen reference model 計算 information-gain reward，衡量 latent trajectory 對目標影像預測密度的提升，並加入 latent diversity reward 防止步驟塌縮，再使用 GRPO 進行 self-evolving RL。其核心創新是使推理與影像生成共享 continuous latent space，從而支援 test-time scaling。

## 核心貢獻
1. 提出 LARC，將 UMM 的 reasoning trajectory 從離散 token space 移至與影像生成一致的 continuous latent space，藉此處理離散推理與連續生成之間的模態落差。
2. 設計兩階段訓練流程：以 curriculum SFT 逐步啟用 latent reasoning，再以 information-gain reward 與 collapse-prevention diversity reward 進行不依賴 ground-truth latent chain 或外部 critic 的 GRPO RL。
3. 在 BAGEL 上以 1M 筆資料驗證方法，在 GenEval、DPG-Bench、OneIG-Bench、CompBench 與多個多模態理解基準上取得改善，並報告 latent reasoning 的 test-time scaling 行為。

## 技術方法

LARC 以 BAGEL 為基礎，使用 understanding expert 與 generation expert 的 UMM 架構。輸入文字 prompt，並可選擇加入來源影像；模型在 language mode 生成文字 span，在 latent mode 於特殊 token <latent> 後，將當前位置的最後層 hidden state 直接作為下一位置 embedding。兩種模式交錯形成 trajectory τ=(s1,l1,…,sN,lN)，結束後由 image module 透過 cross-attention 讀取 hidden states 生成影像。Stage 1 使用 1M 筆 interleaved CoT 資料，來源為 FLUX-Reason 500K、WEAVE 100K 與 ScaleEdit 400K；先訓練純文字 trajectory，再逐階段啟用 latent steps，並聯合 next-token prediction 與 flow-matching image loss。Stage 2 固定 Stage 1 reference model，對每個 context 進行多次 stochastic rollout，將 information gain 定義為 reasoning-conditioned 與 reasoning-free flow-matching loss 的差值，並加入 pairwise cosine-based diversity reward；以 group rollouts 的 GRPO 更新 policy。評估涵蓋 GenEval、DPG-Bench、OneIG-Bench、CompBench，以及 MME、MMBench、MMMU、MIRA；指標包括生成對齊、prompt following、attribute binding、LC-T、LC-I、PSNR、SSIM、LPIPS 與多模態理解分數，其中部分生成評估採 MLLM-as-a-Judge。

## 關鍵結果

主要結果如下；分數均依論文表格，未額外推估：

| DPG-Bench Overall | 85.07 | 85.56 | 90.04 | +4.97 |
| OneIG-Bench Overall | 0.764 | 0.790 | 0.866 | +0.102 |
| CompBench LC-T | 20.434 | 20.215 | 22.509 | +2.075 |
| CompBench LC-I | 0.842 | 0.837 | 0.880 | +0.038 |
| CompBench PSNR | 24.370 | 23.925 | 25.710 | +1.340 |
| CompBench SSIM | 0.917 | 0.904 | 0.953 | +0.036 |

消融實驗顯示，BAGEL→Stage 1→Stage 1+2 的 GenEval 為 0.81→0.83→0.88，OneIG-Bench 為 0.76→0.81→0.87，CompBench LC-T 為 20.43→21.46→22.51，MIRA 為 7.5→9.7→11.7。當 latent diversity weight 為 0、0.1 時，MIRA 分別為 9.8、11.7，latent steps 平均 cosine similarity 分別為 0.97、0.79。論文報告 latent budget 增加時三項任務均呈單調提升，但 Figure 1 未提供完整數值表。

## 對我們的啟發
- [ ] 若生成器在 continuous latent space 中運作，推理表示也可直接對齊該空間；對需要 attribute binding、空間關係與局部編輯的任務，這比單純增加文字 CoT 更符合生成需求。
- [ ] 對不可直接人工標註的 hidden reasoning，可使用模型自身條件預測分布的 information gain 作為內在訓練訊號；但實務部署時仍應檢查該訊號與外部品質指標的一致性。
- [ ] 多步 latent reasoning 需要同時處理探索與塌縮問題；論文的 diversity reward 實驗顯示，缺少此正則化時 latent steps 會高度相似，因此實作上應監測步驟間的表示相似度。

## 限制與未來工作

論文指出，LARC 目前主要建立在具有 flow-matching head、於 continuous space 生成影像的 UMM 上，尚未延伸至 discrete-space generation 或其他生成 head。latent trajectory 也會帶來推論延遲與額外計算；作者提出 distillation、efficient decoding 與 adaptive latent allocation，但未在本文提供相關實驗結果。此外，test-time scaling 曲線的完整數值未報告。
