# Jailbreaking LLMs via Calibration

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2602.00619)
- 📥 [PDF](https://arxiv.org/pdf/2602.00619)

## 摘要（中文翻譯）

本研究揭示安全對齊機制如何在 LLM 的輸出分佈和預對齊分佈之間創造系統性差異，並提出一個創新的越獄攻擊框架。研究發現，安全對齊本質上是一種系統性扭曲，將模型從原始預訓練分佈推向安全輸出空間。基於這一洞察，論文提出基於校準的攻擊方法，透過逆向這種扭曲過程來繞過安全防護。該方法將安全對齊效應建模為可量化和可逆的系統性失真，設計對抗性提示來抵消這種失真。在 gpt-oss-120b 等大型模型上的實驗顯示，該方法達到領先的攻擊成功率，突顯現有安全對齊機制的脆弱性，為建立更強健的安全防護提供重要啟示。

## 問題背景

LLM 的安全對齊透過 RLHF 等技術將模型輸出推向安全分佈，但這種對齊創造了系統性的分佈差異。攻擊者可以利用這種差異設計越獄攻擊，繞過安全防護。現有研究缺乏對安全對齊機制本質的深入理解，也未能從分佈扭曲的角度系統性分析越獄攻擊的原理。

## 解決方案

提出基於校準的越獄攻擊框架，將安全對齊建模為從預訓練分佈到安全分佈的系統性扭曲。核心思想是：(1) 量化安全對齊造成的分佈偏移；(2) 設計校準策略，透過對抗性提示逆向這種偏移；(3) 利用模型內部表徵空間的特性，找到繞過安全檢查的路徑。該方法在理論框架指導下設計攻擊，相比啟發式方法更具系統性。

## 核心貢獻
1. 提出安全對齊的分佈扭曲理論框架，揭示對齊機制的本質和脆弱性
2. 設計基於校準的越獄攻擊方法，透過逆向分佈偏移繞過安全防護
3. 在 gpt-oss-120b 等模型上達到領先的攻擊成功率，驗證理論框架有效性

## 技術方法

研究首先建立安全對齊的數學模型，將對齊過程表示為從預訓練分佈 P_pre 到安全分佈 P_safe 的轉換函數。透過分析模型內部表徵，量化這種轉換造成的系統性偏移。接著設計校準算法，生成對抗性提示來抵消這種偏移，引導模型回到預對齊狀態。攻擊方法包含三個階段：(1) 分佈偏移檢測，識別安全對齊造成的特徵空間變化；(2) 校準提示生成，設計能夠逆向偏移的輸入；(3) 攻擊驗證，測試生成內容是否繞過安全檢查。在多個模型和有害內容類別上評估攻擊成功率。

## 對我們的啟發
- [ ] 安全對齊本質上是分佈空間的系統性扭曲，這種扭曲的可逆性為越獄攻擊提供理論基礎
- [ ] 現有安全對齊方法主要依賴輸出層的約束，但內部表徵空間仍保留預對齊資訊
- [ ] 提高 LLM 安全性需要從根本上改變對齊策略，而非僅在輸出層添加過濾器

## 限制與未來工作

該研究展示了安全對齊的脆弱性，但未提供具體的防禦方案。攻擊方法需要一定的計算資源和模型內部資訊，實際威脅程度依場景而異。研究主要在開源模型上驗證，商業閉源模型可能採用額外防護機制。倫理考量：研究結果可能被惡意使用，需要負責任地揭露和討論。
