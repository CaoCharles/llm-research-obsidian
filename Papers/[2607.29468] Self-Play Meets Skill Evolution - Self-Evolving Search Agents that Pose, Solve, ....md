# Self-Play Meets Skill Evolution: Self-Evolving Search Agents that Pose, Solve, and Remember

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.29468)
- 📥 [PDF](https://arxiv.org/pdf/2607.29468v1)

## 摘要（中文翻譯）

Self-play agent 能在不使用目標 benchmark 題目的情況下生成訓練問題，但其課程缺乏持久狀態：失敗會影響梯度，卻不會明確塑造後續練習。外部 skill memory 能保存程序性經驗，但通常從固定任務分布中學習。本文提出 SESA（Self-Evolving Skill-Augmented Agent），將程序性記憶設為 tool-augmented search self-play 的演化狀態。challenger 負責提出問題，solver 由獨立參數化，且只有 solver 能檢索 skills。具資訊性的失敗會被蒸餾為可重用 skills 並寫回 memory。更新後的 memory 改變 solver 行為與成功率，進而改變 challenger 的 reward 及未來問題分布；新的能力前沿又會產生失敗並重寫 memory，形成任務生成與 skill memory 的雙向共同演化。由於 skills 參與 on-policy 訓練，其效益可內化至模型參數，也可保留在外部 bank，支援 memory-free deployment 與推論時檢索。於七個 open-domain 與 multi-hop QA benchmark 上，SESA 平均優於 SSP 1.2–3.2 個百分點，並在統一評估協議下優於 SkillRL 0.9 個百分點。

## 問題背景

現有 zero-data self-play 能自行產生問題並透過 reward 調整 solver，但失敗通常只作為暫時訓練軌跡，缺乏可重用、可維護的程序性記憶。相反地，skill-augmented RL 雖能保存經驗，通常依賴固定資料集或外加課程，無法讓任務生成與技能記憶共同演化。論文要解決的是如何在 self-play 中選擇可學習的失敗、避免記憶污染，並使更新後的技能反過來改變未來的 solver 行為與問題難度。

## 解決方案

作者提出 SESA，將 skill memory 納入 tool-augmented search self-play 的訓練狀態。其核心閉環是：先以 seed 與 bootstrap skills 初始化 memory；由 challenger 生成問題，但只讓 solver 檢索 skills；依 solver 群組成功率以 frontier-shaped reward 引導 challenger 產生接近能力邊界的題目；再把具資訊性的失敗蒸餾為含觸發條件、辨識線索、反模式與 query template 的 skill，經去重、效用統計與淘汰後寫回 bank。技能因此改變後續 on-policy trajectories，也可能被內化到模型參數；部署時則可關閉或保留外部 memory。

## 核心貢獻
1. 提出將 zero-data self-play 的問題生成與持久 skill memory 結合的 coupled self-evolution 設定，使 solver 的失敗能影響後續練習與記憶。
2. 設計 SESA 閉環，包括 memory priming、solver-only asymmetric self-play、frontier shaping，以及 online failure distillation。
3. 透過 SESA-Off 與 SESA-On 的 dual-path evaluation，區分 skill-conditioned training 所造成的參數內化效益與推論時外部 memory 的額外效益。

## 技術方法

SESA 在 zero-data search self-play 中使用分離參數的 proposer/challenger 與 solver。challenger 從 SSP 提供的 50,000 個 target-answer／hop-requirement seed 中生成具唯一答案的問題，但不直接看到目標答案；solver 使用固定 search tool 進行檢索並回答。每個問題採 5 個 solver rollouts，使用 GRPO 進行 critic-free policy gradient 更新；solver reward 由 exact match 或 model-based semantic match 的可驗證答案判定，並以群組內 reward 正規化。系統維護最多 800 筆非參數化 skill bank，每筆 skill 包含描述、trigger、avoidance cues、query templates，以及 retrieval、helpfulness、hurt 計數。初始 bank 包含 15 筆手寫 skills 和 142 筆 bootstrap 去重 skills。solver 每次只檢索 top-3 相似 skills；challenger 不可存取 memory。Frontier shaping 以 solver 群組成功率計算 bell-shaped proposer reward，對全對或全錯問題施加端點懲罰，使問題集中在能力邊界。失敗 rollout 進入最多 300 筆的 queue；每 10 steps 且至少累積 20 筆時，最多選 30 筆由 judge 蒸餾，與 bank 相似度高於門檻者去重後寫回。非 seed skill 若至少被檢索三次且 helpful-hurt 為負則淘汰，超過 800 筆時移除低分 skill。評估使用 NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA、MuSiQue、Bamboogle，共 3,125 題；主要指標是七個資料集 accuracy 的等權平均，推論採 greedy decoding、每題一次 rollout、最多 10 次 assistant/search turns。

## 對我們的啟發
- [ ] 若代理人的經驗會在訓練中反覆出現，應將具體失敗策略化、去重並維護效用，而不只依賴 policy gradient 暫時吸收。
- [ ] skill memory 的存取權限應與角色分離：僅讓 solver 取得程序性 guidance，可避免 challenger 直接接觸解題策略並維持問題生成與解題的不對稱性。
- [ ] 可將 memory-free 與 memory-augmented 部署分開測量；本論文結果顯示，訓練期間使用 retrieval 可能把能力帶入參數，而外部 bank 作為可選增強，其效益依資料集而異。

## 限制與未來工作

實驗主要集中於七個 open-domain 與 multi-hop QA benchmark，論文未報告更廣泛任務、不同 search backend 或不同 memory 管理器的結果。skill distillation 依賴 DeepSeek-v4-pro，答案評估也包含 model-based semantic judge，可能引入評估器依賴。論文未提供統計顯著性、重複實驗變異或完整成本分析；此外，SESA 使用 15 個手寫 skills 與 142 個 bootstrap skills，對冷啟動情境的效果仍未充分驗證。
