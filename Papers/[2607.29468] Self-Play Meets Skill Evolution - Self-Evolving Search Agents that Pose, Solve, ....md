# Self-Play Meets Skill Evolution: Self-Evolving Search Agents that Pose, Solve, and Remember

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.29468)
- 📥 [PDF](https://arxiv.org/pdf/2607.29468v1)

## 摘要（中文翻譯）

Self-play agent 能在不使用目標 benchmark 題目的情況下自行產生訓練問題，但其課程缺乏持久狀態：失敗會影響梯度，卻不會明確塑造未來練習。外部 skill memory 能保存程序性經驗，但通常從固定任務分布中學習。本文提出 SESA（Self-Evolving Skill-Augmented Agent），將程序性記憶變成 tool-augmented search self-play 的演化狀態。challenger 負責出題，solver 單獨檢索 skills；具資訊性的失敗會被蒸餾成可重用 skills 並寫回 memory。更新後的 memory 改變 solver 行為與成功率，進而改變 challenger 的 reward 和未來題目分布，形成任務生成與 skill memory 的雙向共同演化。實驗顯示，skill-conditioned training 的收益可內化至模型參數，也可保留於外部 skill bank，支援 memory-free 或 inference-time retrieval 部署。

## 問題背景

現有 zero-data self-play 能自行產生任務並以 solver 能力調整難度，但失敗經驗通常只作用於當次 policy update，缺乏可持久、可重用的記憶。另一方面，skill-augmented RL 雖能保存程序性策略，通常依賴固定資料集或手工課程，無法讓任務生成與技能學習互相影響。論文要解決的是如何在 search self-play 中同時形成自適應課程與演化 skill memory。

## 解決方案

作者提出 SESA，將 skill memory 納入 self-play 的訓練狀態，而不是只在推論時附加 prompt。系統由四個環節構成：以 seed 與 bootstrap skills 進行 memory priming；讓 solver-only retrieval 與 challenger/solver asymmetric self-play 結合；以 solver 群組成功率的 bell-shaped reward 進行 frontier shaping；再將 frontier 上具資訊性的失敗蒸餾、去重並寫回 bounded skill bank。更新後的 bank 改變後續 solver 的 on-policy trajectories，進而改變 solver policy、成功率、challenger reward 與未來問題分布，形成 failure-to-skill-to-solver 的雙向閉環。

## 核心貢獻
1. 提出 Coupled self-evolution，將 self-posed self-play 與持久 skill consolidation 結合，使 agent 能自行選擇練習前沿並保存失敗經驗。
2. 設計 SESA 閉環：solver-only retrieval、frontier shaping 與 online failure distillation 共同作用，避免 challenger 直接取得解題技能。
3. 提出 Dual-Path Skill Reuse 評估，區分 skill-conditioned training 造成的參數化能力提升與推論時外部 memory 的額外收益。

## 技術方法

SESA 建立在 zero-data search self-play 上，由分開參數化的 proposer/challenger 與 solver 組成。challenger 從 50,000 個 target-answer 與一至三跳要求中產生可驗證問題，但訓練不使用評測題目；solver 使用固定 search tool 進行檢索並回答。solver 每題抽取 G=5 條 rollout，以 verifiable answer reward 計分，再以 GRPO 進行 critic-free policy-gradient 更新。skill bank B 初始包含 15 個手寫 skills 與 142 個 bootstrap 去重 skills；每次 solver 嘗試前，以 E5-base-v2 對問題與 skill 做 dense retrieval，取 top-3，且僅 solver 可見。challenger 的 reward 由 solver 群組成功率決定：對成功率 0 或 1 的題目施加端點懲罰，對中間難度題目給予 bell-shaped reward，使出題集中於 competence frontier。失敗 rollout 會進入最多 300 筆的 queue；每 10 steps 且累積至少 20 筆時，最多選 30 筆交由 DeepSeek-v4-pro 蒸餾為含 trigger、distinguishing evidence、avoidance cues 與 query templates 的 skill。候選 skill 與既有 bank 的 cosine similarity 必須不高於 0.93，bank 上限為 800，非 seed skill 會依 helpful/hurt utility 淘汰。評估使用 NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA、MuSiQue 與 Bamboogle，共 3,125 題；採 normalized exact match，否則由 Qwen2.5-32B-Instruct 判定 semantic equivalence，greedy decoding、每題一次 rollout、最多十個 assistant/search turns。

## 關鍵結果

主要結果如下，數字均為七個 held-out search benchmarks 的平均 answer accuracy（%）：

| Backbone/方法 | SSP | SESA-Off | SESA-On | SESA 相對 SSP |
|---|---:|---:|---:|---:|
| Qwen3-4B | 53.9 | 55.7 | 56.2 | +2.3（On） |
| Qwen3-8B | 56.3 | 58.5 | 59.5 | +3.2（On） |
| LLaMA-3.1-8B | 46.3 | 論文未報告 | 47.5 | +1.2（On） |
| Qwen2.5-7B-Base | 48.7 | 論文未報告 | 50.8 | +2.1（On） |
| Qwen2.5-7B-Instruct | 49.5 | 論文未報告 | 51.0 | +1.5（On） |
| Search-R1-7B | 55.7 | 論文未報告 | 57.5 | +1.8（On） |
| SkillRL-Search-7B | 50.1 | 不適用 | 不適用 | SESA 高 0.9 |

在 Qwen3-4B 上，移除 memory priming、frontier shaping、failure distillation 後，平均分別降至 54.7、54.0、53.5；完整 SESA 為 56.2。Qwen3-4B 的 SESA-Off 比 SSP 高 1.8，SESA-On 再高 0.5；Qwen3-8B 則分別高 2.2 與 1.0。評估包含七個 benchmark、共 3,125 題，主指標為各資料集 accuracy 的等權平均。

## 對我們的啟發
- [ ] 若 agent 的訓練任務可由自身生成，應將失敗轉換成可檢索的程序性知識，而非只依賴 policy gradient 暫時吸收。
- [ ] skill memory 的存取權限需要角色不對稱：僅讓 solver 取得解題技能，可降低出題者直接洩漏解法、破壞難度控制的風險。
- [ ] 實務部署可採雙路徑設計：先使用 SESA-Off 的參數化能力，再視任務相關性啟用 SESA-On，因為論文觀察到外部 retrieval 的收益較小且具資料集依賴性。

## 限制與未來工作

論文未提供完整訓練成本、訓練步數與多次隨機種子下的統計顯著性，因此結果穩定性與成本效益仍不明確。SESA 依賴 157 個手寫或 bootstrap skills、固定 search backend、外部 dense encoder 與 model-based judge；部分資料集表現低於 SSP，且 retrieval 可能造成干擾。論文亦未報告更廣泛任務或長期 memory 演化的結果。
