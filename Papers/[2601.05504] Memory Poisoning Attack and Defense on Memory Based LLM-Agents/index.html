    Memory Poisoning Attack and Defense on Memory Based LLM-Agents

    連結

    • 📄 arXiv
    • 📥 PDF
    • 📎 本地 PDF: PDF

    摘要（中文翻譯）

    配備持久記憶的大型語言模型 agent 容易受到記憶投毒攻擊（memory poisoning），攻擊者透過純查詢互動注入惡意指令，污染 agent 的長期記憶並影響未來回應。先前研究顯示 MINJA 攻擊在理想條件下可達 95% 以上的注入成功率和 70% 的攻擊成功率，但在真實部署環境中的魯棒性及有效防禦機制仍缺乏研究。本文針對電子健康記錄（EHR）agent 進行系統性實證評估，從三個維度（初始記憶狀態、指示 prompt 數量、檢索參數）考察攻擊魯棒性。在 GPT-4o-mini、Gemini-2.0-Flash、Llama-3.1-8B 上使用 MIMIC-III 臨床資料的實驗揭示，含有既有合法記憶的真實環境會大幅降低攻擊效果。本文進一步提出兩種防禦機制：(1) 基於複合信任評分的輸入/輸出審核；(2) 結合時間衰減與模式過濾的信任感知記憶清洗。

    問題背景

    LLM agent 的持久記憶機制引入了新型攻擊面——記憶投毒：攻擊者透過看似正常的查詢互動，將惡意指令注入 agent 的長期記憶，使其在未來回應中被觸發。先前的 MINJA 攻擊在理想條件（空白記憶、充足攻擊輪次）下效果顯著，但真實部署環境的魯棒性和有效防禦方案未被系統研究。在醫療等高風險領域，記憶投毒可能導致 agent 回傳錯誤的病患記錄，後果嚴重。

    解決方案

    本文從攻擊評估和防禦設計兩方面切入。攻擊評估方面，在真實條件（含既有記憶、有限攻擊輪次）下系統測試 MINJA。防禦方面提出兩種互補機制：(1) I/O Moderation——結合靜態啟發式、關鍵字比對和 LLM 語義分類的複合信任評分，在輸入和輸出端進行雙重審核；(2) Memory Sanitization——對記憶條目分配連續信任分數（0-1），結合時間衰減（舊條目信任降低）和模式過濾（辨識已知投毒模板），實現信任感知的檢索排序。

    核心貢獻

    1. 首次在真實條件下系統評估記憶投毒攻擊的魯棒性，揭示含有既有合法記憶的環境可將攻擊成功率從 62%（GPT）降至 6.67%，顯示先前研究高估了攻擊在實際部署中的威脅
    2. 提出兩種互補的防禦機制（I/O Moderation + Memory Sanitization），為記憶型 LLM agent 的安全建立重要基線
    3. 發現信任閾值校準的兩難困境：過度保守（GPT-4o-mini 拒絕所有條目）與不足過濾（Gemini 未識別 54 條投毒記憶），揭示了信任評估在不同模型上的行為差異

    技術方法

    攻擊評估：使用 MINJA 攻擊，在三個維度上變化實驗條件： 1. 初始記憶狀態：空白 vs 含既有合法記憶 2. 指示 prompt 數量：50-101 條 3. 檢索參數：top-k 設定

    防禦機制 1（I/O Moderation）：複合信任評分系統，結合程式碼安全分析、語義相關性驗證、關鍵字比對等多個正交信號，對輸入和輸出進行雙重審核。

    防禦機制 2（Memory Sanitization）： - 記憶寫入時：分配初始信任分數 - 記憶檢索時：信任分數隨時間衰減，模式過濾已知投毒模板 - 信任感知排序：低信任記憶在檢索中被降權

    實驗設置：GPT-4o-mini、Gemini-2.0-Flash、Llama-3.1-8B-Instruct，使用 MIMIC-III 臨床資料構建 EHR agent。

    關鍵結果

    條件 GPT-4o-mini ASR Gemini ASR Llama ASR
    理想條件（空白記憶） ~62% — ~53%
    真實條件（既有記憶） 6.67% — 0%

    防禦效果： | 模型 | I/O Moderation 表現 | Memory Sanitization 表現 | |------|--------------------|--------------------------| | GPT-4o-mini | 過度保守，拒絕所有條目 | 記憶為空 | | Gemini-2.0-Flash | — | 未識別 54 條投毒，45.7% 工作量被拒絕 | | Llama-3.1-8B | 真實條件下 ASR 降至 0% | — |

    關鍵發現：含有既有合法記憶的真實環境本身就大幅降低了攻擊效果，但信任閾值校準仍是核心挑戰。

    對我們的啟發

    • 真實部署環境的既有記憶提供了天然的「記憶稀釋」防禦效果，這表明記憶投毒的威脅在先前研究中被高估，但不應因此放鬆防禦——精密攻擊可能克服此限制
    • 信任閾值校準的兩難困境（過度保守 vs 不足過濾）是所有信任評估系統的共同挑戰，未來需要自適應閾值機制而非固定閾值
    • 在醫療等高風險場景中，記憶投毒的後果特別嚴重，此研究為 LLM agent 在高風險領域的安全部署提供了重要的攻擊面分析和防禦基線

    限制與未來工作

    防禦機制在不同模型上表現差異極大（GPT 過度保守、Gemini 不足過濾），缺乏通用的信任閾值校準策略。僅在 EHR 領域的 MIMIC-III 資料集上評估，未驗證對其他領域的泛化能力。攻擊僅使用 MINJA 一種方法，未考慮更多樣化的記憶投毒策略。防禦評估未包含自適應攻擊者（知曉防禦機制後調整策略）的場景。
