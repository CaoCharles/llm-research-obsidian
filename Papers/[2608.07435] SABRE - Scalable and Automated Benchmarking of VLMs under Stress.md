# SABRE: Scalable and Automated Benchmarking of VLMs under Stress

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.07435)
- 📥 [PDF](https://arxiv.org/pdf/2608.07435v1)

## 摘要（中文翻譯）

Vision-language models（VLMs）快速進步，但 benchmark 的開發速度落後，因而難以持續辨識模型弱點。建立 stress test 成本高，樣本必須符合受控條件、可回答且能挑戰當代模型。本文提出 SABRE，一個可擴展且自動化的 pipeline，將 Test Primer（以 Markdown 撰寫、包含 Task Design 與 Data Schema）轉換為結構化規格、生成或編輯後的影像，以及 question-answer pairs。Automated filtering 透過 Filtering VLM 移除已能答對的候選樣本；human review 則驗證樣本有效性、修正標註並支援局部影像修復。作者以 SABRE-Prior 測試 VLM 是否依循視覺證據，而非熟悉物體與場景所形成的 world priors。資料包含 600 張影像與 1,000 個問題，涵蓋 Context、Texture、Attribute 與 Language Elicitation。六個 VLM 的 macro-average accuracy 為 17.8% 至 31.3%，平均 22.6%。Counting 與 Spatial pilots 進一步顯示此流程可延伸至其他 stress-test 設定。

## 問題背景

VLM 能力提升使傳統固定 benchmark 逐漸飽和，但針對反直覺、受控且仍可回答的 stress-test 樣本，建立與驗證成本很高。既有自動化方法多從既有影像衍生問題，無法精確控制視覺證據；單純影像生成又可能漏物、錯數或改動無關區域，造成影像、問題與答案不一致。因此需要一個可擴展、可篩選且有人工作有效性把關的建構流程。

## 解決方案

作者提出 SABRE，將 benchmark 建構抽象成可重用的 Test Primer 與模組化 pipeline。LLM 先產生結構化 Sample Specifications，再由影像生成與編輯模型建立受控視覺條件，並以 Filtering VLM 進行 failure-only pressure screening，保留當代模型答錯的候選。由於答錯不等於樣本有效，系統加入 human verification、標註修正與 localized patch repair；局部修復搭配 soft blending，以降低重生整張影像造成的非目標變化。新增 stress-test 主題主要需撰寫新的 task primer，而不必重做整套流程。

## 核心貢獻
1. 提出 SABRE 模組化 benchmark-construction pipeline，將自然語言 Test Primer 自動轉換為樣本規格、影像、問題與答案，並支援不同題型與任務配方。
2. 設計 model-in-the-loop 的 failure-only pressure screening，結合 Filtering VLM 與 human verification，並以 localized image repair 修復局部生成缺陷。
3. 建構 SABRE-Prior，系統測試 VLM 在 Context、Texture、Attribute、Language Elicitation 四種視覺證據與 world prior 衝突下的表現，並以 Counting、Spatial pilots 驗證可擴展性。

## 技術方法

SABRE 的輸入是 Test Primer，包含自然語言 Markdown Task Design、Data Schema（欄位型別與驗證規則）及題型。設計 LLM 將其轉成 JSON Sample Specifications，每份規格包含影像生成或編輯提示、問題與 reference answer。生成模型 G 建立 base image；需要反事實干預時，編輯模型 E 依 editing plan 修改目標內容並保留其他區域，也可直接使用 real image。每個候選樣本表示為（image、question、answer）。接著由 Filtering VLM M 依題型 scoring rule 作答；答對者被移除，答錯者進入人工審查，因此篩選主要建立模型相對困難度，而非樣本有效性。人工 reviewer 檢查視覺證據、編輯是否正確、問題是否明確及答案是否匹配，可修訂問題、答案與區域標註，或框選缺陷區域進行局部修復。修復模型只接收含上下文的 patch，再以 Gaussian-blurred soft mask 融回原圖，並重新審查。SABRE-Prior 包含四個各 100 cases 的 subset，共 600 images、1,000 samples：Context 與 Texture 使用 base-edited paired images 及四個 yes/no probes，採 strict All4 accuracy；Attribute 使用 normalized exact-match counting accuracy；Language Elicitation 使用 unknown 選項位置平衡的四選一 accuracy。總分是四個 subset accuracy 的 unweighted macro-average；信賴區間以 20,000 次 case-level percentile bootstrap 估計。六個 VLM 以 zero-shot、greedy decoding 評估，另測試 Qwen 3.5 27B 搭配 VCD、SoM，以及 real-image Attribute control。

## 對我們的啟發
- [ ] 若要建立可持續更新的 VLM 評測，應把任務設計、資料生成、困難度篩選與人工驗證拆成可重用模組，而非只發布一次性的固定資料集。
- [ ] Filtering VLM 只能提供候選樣本的困難度訊號，不能證明樣本有效；實務上仍需檢查視覺證據、問題歧義、答案一致性與生成編輯是否改動非目標區域。
- [ ] 評測應使用能隔離失效模式的 paired images、反事實屬性與 abstention 選項，並同時報告分 subset 結果；單一 aggregate score 可能掩蓋模型在視覺 grounding、計數或先驗抑制上的差異。

## 限制與未來工作

論文指出固定 benchmark 的 coverage 受發布時有限的 task specifications 影響；SABRE 以模組化設計緩解，但並未消除此限制。部分 pilots 僅各 20 個樣本，不能視為完整能力評估。跨 benchmark 的 accuracy 受題型與 scoring rules 差異影響，不宜直接比較。localized repair 使用者研究僅測試 entity removal，未涵蓋 entity swapping。
