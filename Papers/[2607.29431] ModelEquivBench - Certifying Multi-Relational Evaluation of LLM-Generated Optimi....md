# ModelEquivBench: Certifying Multi-Relational Evaluation of LLM-Generated Optimization Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.29431)
- 📥 [PDF](https://arxiv.org/pdf/2607.29431v1)

## 摘要（中文翻譯）

大型語言模型日益能依據自然語言生成最佳化模型，但現有評估常將候選模型與 ground-truth 壓縮成單一 equivalent/not-equivalent 判定，或僅統計執行成功率；這些標籤難以由第三方獨立檢查，也無法忠實呈現模型在不同語意層面的相符情況。本文提出 ModelEquivBench，一套具認證能力的多關係評估系統，針對每個候選—參考模型配對回報 E0–E6 語意剖面：模型建構與精確匯入、表示對齊、同空間與投影可行集合關係、目標排序等價、最佳值相等，以及最佳解集合等價。每項決定均附帶可重播軌跡、明確映射、exact-rational 證書或反例見證；映射搜尋不完整、結構不支援或資源耗盡則回報 typed UNKNOWN 或 N/A，而非猜測。對 173 個問題、三個模型 snapshot 的實驗顯示，模型在不同評估階段失敗，無法合理化約為單一準確率。

## 問題背景

LLM 能將自然語言轉成可執行的 LP／MIP，但「程式能執行」不代表模型語意正確；單一 equivalent/not-equivalent 判定也混淆可行集合、目標排序、最佳值與最佳解集合等不同關係。既有方法通常缺乏第三方可重驗的證據，且會把映射搜尋失敗或資源不足誤當成錯誤。因此本文要建立一個能細分語意關係、提供形式證書並對未決情況安全 abstain 的評估系統。

## 解決方案

作者提出 ModelEquivBench，將候選模型與 reference 的比較輸出為 E0–E6 semantic profile，而非階梯式單一分數。E0、E1 分別確認可重播的建構／精確匯入與 verified representation alignment；E2、E3 分別處理同空間及 affine lift 後的可行集合；E4–E6 平行檢查目標排序、最佳值與最佳解集合。核心技術是 Certifying Mapped-Containment (CMC)，結合 exact-rational Farkas 證書、仿射映射義務、對偶證據與反例見證。系統採 fail-closed 政策，將未知、資源耗盡、不支援、數學上不適用及前置條件缺失分開記錄，並由獨立 verifier 重驗所有已決定結論。

## 核心貢獻
1. 提出 ModelEquivBench 的 E0–E6 多關係語意剖面，將模型建構、表示對齊、可行集合、目標、最佳值與最佳解集合分開評估，而非使用單一等價標籤。
2. 建立 fail-closed 的認證與證據制度：以 replayable trace、verified map、exact-rational Farkas／仿射 lift／對偶證書及可重驗反例支援決定，並區分 unknown、unknown_resource、unknown_unsupported、N/A 與 absent。
3. 在 173 個 base problems、兩種提示條件及三個模型 snapshot 上進行無修復、無重採樣實驗，展示 execution、結構比對與 value matching 無法表達的關係性差異。

## 技術方法

系統將 reference 與候選模型表示為含 exact-rational 係數、變數域、線性不等式／等式、線性目標與最佳化方向的 LP／MIP。E0 先在隔離環境執行候選程式，要求成功匯出並匯入 LP 或 MPS；30 秒超時、解析失敗與不支援結構分別產生對應狀態。E1 使用 deterministic grammar 搜尋 admissible map，包括型別相容的排列、identity、binary complement、連續變數 sign negation，以及具 injective section 和 exact right-inverse 的 affine lift，並由 verifier 精確檢查。取得映射後，E2 以 Certifying Mapped-Containment (CMC) 檢查同空間可行集合的雙向包含；正面結果使用 exact-rational Farkas multipliers，負面結果使用違反約束的可行點。E3 在支援的 lift schema 下檢查 projection、section 與兩個包含義務。E4 檢查目標在可行點上的排序是否一致，以 objective identity 或相反排序點作證；E5 以 LP weak-duality sandwiches 或由已證明的集合等價推導最佳值相等，但不對 integer optimum 濫用 LP 對偶；E6 僅對 identity 或 binary-complement 等可逆映射提供最佳解集合正面證書。每項證據由獨立 verifier 重算，不信任 solver status、LLM 文字或浮點容忍。實驗使用 Bench4Opt 的 173 個正式問題，每題 Structured 與 Unstructured 兩條件，共 346 cells；三個模型皆 temperature 0、單次生成、無 repair／resampling，候選執行與評估分別受 30 秒及 120 秒限制，並與 value matching 及 harness 中的 ORGEval-style structural baseline 比較。

## 對我們的啟發
- [ ] 評估 LLM 生成的最佳化模型時，應同時報告端到端建構成功率、在已對齊樣本上的語意覆蓋率，以及各關係的正面、負面與 abstention 分布，避免把不同失敗來源混為單一分數。
- [ ] 對需要高可信度的模型驗證流程，可保存候選模型、映射、證書、見證與 hash；透過獨立 verifier 重驗，讓評估結論不依賴生成器、solver 狀態或浮點容忍度。
- [ ] 結構相似、最佳值相等與語意等價不是同一件事；實務上應依問題需求選擇可行集合、目標排序、最佳值或最佳解集合等關係，並將搜尋不完備與資源限制明確標示為未決。

## 限制與未來工作

研究僅涵蓋三個模型 snapshot、173 個固定 base problems、每條件一次生成，且不估計抽樣變異或普遍模型排名。支援範圍限於線性與 bounded-discrete 模型；E1 映射語法不完備，E3 僅支援特定 affine-lift，E6 沒有 certified negative。120 秒限制也造成部分 unknown_resource，正式樣本的 E3 覆蓋率為零。此外，評估只驗證候選相對 reference 的語意，不能證明 reference 符合自然語言意圖。
