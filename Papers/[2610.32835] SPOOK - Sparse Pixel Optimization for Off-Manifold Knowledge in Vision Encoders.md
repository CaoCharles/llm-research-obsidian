# SPOOK: Sparse Pixel Optimization for Off-Manifold Knowledge in Vision Encoders

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.32835)
- 📥 [PDF](https://arxiv.org/pdf/2610.32835v1)

## 摘要（中文翻譯）

現代 vision encoder 廣泛被用作語義表徵，但當輸入遠離 natural-image manifold 時，embedding similarity 與人類可見語義之間的關係可能變得不清楚。本文在 black-box 設定下，從空白畫布開始，以簡單的 pixel-level hill-climbing 進行稀疏像素編輯，探測此區域。在 ImageNet 與 Flickr30k 上，作者評估經編輯的空白畫布是否能在 multimodal contrastive encoder 與 self-supervised visual encoder 中檢索指定目標。於 OpenCLIP 上，針對 class prompt 優化的輸入達到很高的 targeted retrieval；於 DINOv3 上，針對 class prototype 優化的輸入也具有高 target alignment 與接近頂部的 prototype rank。結果顯示，幾乎空白且不具視覺語義的輸入，仍能進入 language-aligned 與 self-supervised representation space 中的目標語義 basin。本文指出現代 vision encoder 共享一種 off-manifold failure mode，並提出 sparse blank-canvas optimization 作為探測 representation geometry 的簡單方法。

## 問題背景

論文探討 vision encoder 的 embedding similarity 是否必然代表人類可辨識的語義。既有研究多聚焦於自然影像上的 adversarial perturbation、adversarial patch 或 classifier fooling，較少研究從近乎空白輸入直接操控 embedding，以針對性檢索指定目標。作者認為，若 embedding 被直接用於 retrieval、filtering、indexing 或 nearest-neighbor classification，模型在 natural-image manifold 外的高相似度可能造成語義判斷失真。

## 解決方案

作者提出 SPOOK（Sparse Pixel Optimization for Off-Manifold Knowledge）與 targeted embedding spooking 設定。方法從白色或其他簡單畫布開始，針對一個指定 target embedding，反覆隨機選取尚未編輯的 pixel-channel，賦予隨機值，只有在 target cosine similarity 提升時才永久接受該編輯。它不使用模型權重、梯度或內部 activation，僅需查詢相似度分數。SPOOK 的核心創新是將 classifier fooling 延伸至 targeted retrieval geometry，並同時驗證 language-aligned 的 OpenCLIP 與 image-only 的 DINOv3，藉此測試稀疏、視覺上無語義的輸入能否進入指定目標的 embedding basin。

## 核心貢獻
1. 提出 targeted sparse retrieval 的 spooking 設定與黑箱 SPOOK 演算法，將空白畫布上的稀疏像素編輯用於指定 embedding target 的檢索。
2. 在 OpenCLIP 的 ImageNet、Flickr30k 與 DINOv3 的 ImageNet 實驗中，證明修改少於 1% pixel-channels 的視覺非語義輸入仍可達到高 target retrieval 成功率。
3. 透過 random sparse control、初始化與模型尺度消融、跨模型 transfer 及 interpolation 分析，指出現象需要目標特定優化，且主要是模型特定的 off-manifold embedding trigger。

## 技術方法

作者將 image encoder 表示為將影像映射至 normalized embedding 的函數，並建立由 normalized target embeddings 組成的 1000-target retrieval bank。實驗涵蓋 OpenCLIP ViT-B/16 的 ImageNet class prompt、Flickr30k caption prototype，以及 DINOv3 ViT-B/16 的 ImageNet image-class prototype；輸入為 224×224 RGB 影像，通常從 white canvas 開始，每個 target 使用 50,000 次 candidate pixel-channel queries，並彙整 5 個 random seeds。每次查詢隨機選擇未編輯的 pixel-channel 與 replacement value，若 cosine similarity 增加便接受，否則捨棄；接受的編輯永久保留，因此輸出保持稀疏。CLIP 可優化 image-text 或 image-image cosine，DINOv3 優化 image-prototype cosine。評估包括 target cosine、target rank、ASR@1、ASR@5，以及修改的 pixel-channel 百分比。作者另進行 random sparse matched-edit control、white/black/dense-random initialization、CLIP objective mode、CLIP patch size、DINOv3 model scale、cross-model transfer、影像插值與 JPEG、crop、blur、resize robustness 測試。

## 關鍵結果

主要結果如下（cosine、rank 與 pixel edits 依論文表格以 mean / median 表示）：

| 設定 | SPOOK cosine | SPOOK rank | ASR@1 | ASR@5 | Pixel edits |
|---|---:|---:|---:|---:|---:|
| OpenCLIP/ImageNet，class prompt | 0.3314 / 0.3349 | 2.1 / 1.0 | 94.1% | 98.5% | 0.29% / 0.29% |
| OpenCLIP/Flickr30k，caption prototype | 0.3510 / 0.3549 | 2.3 / 1.0 | 87.6% | 95.8% | 0.28% / 0.28% |
| DINOv3/ImageNet，image prototype | 0.5365 / 0.6370 | 8.5 / 1.0 | 85.8% | 94.9% | 0.61% / 0.63% |

與 clean cosine 比較：OpenCLIP/ImageNet 為 0.2668 / 0.2723，OpenCLIP/Flickr30k 為 0.3396 / 0.3413，DINOv3/ImageNet 為 0.5795 / 0.6099。Random sparse matched-edit control 的 ASR@1 僅 0.1%、0.1%、0.1%，ASR@5 為 0.5%、0.5%、0.4%，顯示需要 target-specific optimization。DINOv3 scale ablation 的 ASR@1 / ASR@5 分別為 ViT-S/16 的 96.5% / 99.6%、ViT-B/16 的 85.8% / 94.9%、ViT-L/16 的 72.5% / 88.3%。跨模型 transfer 很弱：CLIP B/16 優化結果在 DINOv3 B/16 的 ASR@1 為 0.6%，DINOv3 B/16 結果在 CLIP B/16 為 0.2%。常見變換也會顯著降低成功率；例如 CLIP/ImageNet JPEG quality 75 後 ASR@1 從 93.8% 降至 14.1%。

## 對我們的啟發
- [ ] 對採用固定 vision encoder 的 retrieval、filtering、indexing 或 nearest-neighbor 系統，不應將 raw embedding similarity 視為充分的語義證據；可加入影像內容驗證或多模型一致性檢查。
- [ ] SPOOK 可作為 representation geometry 的 red-team probe，用於測試部署 encoder 對低熵空白輸入、稀疏異常訊號與 off-manifold target alignment 的敏感性。
- [ ] 由於跨模型 transfer 與常見影像變換下的成功率都很低，實務防禦應針對實際部署模型與 preprocessing pipeline 評估，而不能僅依賴其他模型上的 robustness 結果。

## 限制與未來工作

方法主要在同一 encoder 優化與評估的 exact-input 設定下有效，跨模型 transfer 很弱，且對 JPEG、裁切、模糊與縮放高度脆弱。它需要每個 target 大量 query，產生的影像明顯不自然、容易被人工偵測。論文未證明自然外觀、實體世界或更廣泛模型上的攻擊效果；未來方向包括提升自然度、系統化研究 transfer，以及發展稀疏 trigger detection 與多模型防禦。
