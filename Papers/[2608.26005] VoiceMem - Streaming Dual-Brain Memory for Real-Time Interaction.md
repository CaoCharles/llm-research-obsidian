# VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.26005)
- 📥 [PDF](https://arxiv.org/pdf/2608.26005v1)

## 摘要（中文翻譯）

VoiceMem 是為即時互動設計的 streaming dual-brain memory 系統，旨在補足 duplex speech language models（SLMs）在串流、準確與具同理心記憶上的不足。系統由平行的 informational left brain 與 emotional right brain 組成，並提供 streaming memory I/O。作者同時建立 memory-aware SLM training、long-horizon evaluation，以及可替換 memory backend 的解耦部署流程。實驗顯示：在 top-5 retrieval 下，left brain 相較於 Mem0 的 top-200 設定提升近 30 個百分點；right brain 透過短期與長期 affective attribution 及 dual-node persona modeling，在三個 persona benchmarks 達到最佳表現，整體較先前最佳系統高 1.89 分；retrieval latency 為 134 ms，低於常見 VAD 延遲，未增加額外對話延遲，同時維持高準確率與低成本。

## 問題背景

論文聚焦於即時語音對話系統缺乏長期、準確且具情緒理解能力的記憶。現有方法多以資訊檢索為中心，難以同時建模事實、persona、情緒及其對應對象；常見 top-100 輸出超出 speech model 的上下文預算，而 2–3 秒檢索延遲也不符合即時對話的 100–200 ms 額外延遲需求。此外，記憶演算法與語音模型快速演進，緊耦合架構不利於替換 backend 與持續更新。

## 解決方案

作者提出 VoiceMem streaming dual-brain memory framework。Informational left brain 以 schema–entity 兩層索引組織事實記憶，透過一跳鄰接擴展與 query-driven cluster emergence，提高候選集合的語義密度，使 top-5 retrieval 仍能維持覆蓋率。Emotional right brain 分離 independent persona nodes 與 cross-entity affect nodes，分別表示穩定人格特徵及針對特定人物、事件或概念的情緒，並以 short- and long-horizon attribution 持續更新。系統另以四階段 streaming query 將匹配、圖擴展、搜尋與 context 建構隱藏在使用者停頓期間；上層路由與下層 memory engine 解耦，支援可替換 backend。

## 核心貢獻
1. 提出平行 informational left brain 與 emotional right brain，分別維護事實關係及 persona-affective attribution，並以 cross-brain links 聯結兩者。
2. 提出 schema–entity dense indexing、query-driven cluster emergence 與四階段 streaming retrieval，使 top-5 memory retrieval 在 134 ms 內完成，並降低 memory token 使用量。
3. 建立從 memory-world construction、black-box online on-policy distillation 到 human curation 的 CHATMEM-400K 與 CHATMEM-BENCH 流程，並以解耦上層路由與下層 engine 驗證跨 backend 可轉移性。

## 技術方法

VoiceMem 的記憶狀態由 left graph、right graph 與 cross-brain associations 組成。輸入語音先經 streaming ASR、entity/schema identification、emotion recognition、voiceprint extraction 與 embedding extraction。左腦以 schema 進行粗粒度路由、以 entity 定位具體人物或概念，並維護強弱一跳關聯；候選記憶只從匹配及鄰近 entity 的索引中搜尋。cluster emergence 根據查詢集合與啟動 entity 的 Jaccard-like coherence 分數篩選子圖，再由 LLM judge 評估 relevance、importance、completeness，決定是否提升為新 cluster。右腦包含 independent nodes 與綁定左腦 entity 的 cross-entity nodes；短期 attribution 保存當下情緒、目標與原因，session 結束後以長期 consolidation 歸納穩定傾向。檢索分為 listening/speech tail、anticipation、searching 四階段，最後合併兩腦結果。更新在 turn 後非同步執行 ADD、UPDATE、DELETE 或 KEEP。訓練方面，作者建立 synthetic memory worlds，透過 SLM-verified black-box online on-policy distillation、human curation 與 validation 產生 CHATMEM-400K 及 CHATMEM-BENCH。評估涵蓋 LoCoMo、LongMemEval、Memora、ES-MemEval、PersonaMem、PersonaLens，以及含 316 題、53 小時音訊的 ChatMem-Bench；主要指標為 LLM-judge score，並比較 retrieval budget、memory tokens、latency、ablation 與 backend transfer。

## 對我們的啟發
- [ ] 若語音模型的上下文預算嚴格受限，優先提升候選集合的語義密度可能比單純擴大 top-K 更有效；論文中 K=5 已接近較大 K 的表現。
- [ ] 資訊記憶與情緒／persona 記憶可採不同資料結構與更新週期：前者重視關聯式檢索，後者需區分穩定人格與情境情緒，避免將短期反應直接視為長期特質。
- [ ] 即時系統可將 ASR、entity matching、圖擴展與部分檢索工作前移至使用者說話及停頓期間；同時將上層路由與 backend 解耦，有助於在不重寫核心架構的情況下比較不同 memory engine。

## 限制與未來工作

論文未在本文詳述 CHATMEM-BENCH 的完整建構與標註流程，並表示將另發 technical report；其資料包含 synthetic memory worlds 與 human curation，外部真實使用者分布的驗證範圍未充分報告。主要結果依賴 LLM judge，且 134 ms 是 retrieval latency，論文未完整報告端到端語音互動延遲、錯誤率、隱私治理或長期部署成本。
