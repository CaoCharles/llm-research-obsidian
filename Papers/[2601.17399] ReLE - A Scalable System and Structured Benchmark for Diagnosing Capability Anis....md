# ReLE: A Scalable System and Structured Benchmark for Diagnosing Capability Anisotropy in Chinese LLMs

## 連結

## 摘要（中文翻譯）

大型語言模型在中文語言理解方面取得快速進展，但準確評估其能力仍面臨基準飽和（benchmark saturation）和計算成本過高的挑戰。靜態排行榜雖提供快照式排名，卻常掩蓋能力間的結構性權衡。本文提出 ReLE（Robust Efficient Live Evaluation），一個可擴展的系統，旨在診斷能力各向異性（Capability Anisotropy），即模型在不同領域間表現的不均勻性。使用 ReLE，研究評估了 304 個模型（189 個商用、115 個開源），跨越包含 207,843 個樣本的「領域 × 能力」正交矩陣。本文提出兩項方法創新：(1) 符號基礎混合評分機制（Symbolic-Grounded Hybrid Scoring），消除推理任務中基於 embedding 的假陽性；(2) 動態方差感知調度器（Dynamic Variance-Aware Scheduler），基於 Neyman 分配和噪聲校正，相比完整評估降低 70% 計算成本，同時維持 ρ=0.96 的排名相關性。

## 問題背景

LLM 評測面臨兩大核心問題：(1) 基準飽和——許多模型在現有基準上表現接近滿分，失去區分能力；(2) 大規模評測的計算成本極高，全量評估數百個模型不切實際。更深層的問題是，聚合排名掩蓋了模型能力的各向異性，模型可能在某些領域強、某些領域弱，但總分相近。

## 解決方案

提出 ReLE 系統，核心創新是「能力各向異性」（Capability Anisotropy）的概念和診斷方法。不同於傳統的聚合排名，ReLE 建構「領域 × 能力」正交矩陣進行多維度評估。技術上引入兩項創新：符號基礎混合評分避免 embedding 匹配的假陽性問題，動態調度器利用統計抽樣理論在保證排名精度的前提下大幅降低計算開銷。

## 核心貢獻
1. 提出能力各向異性（Capability Anisotropy）概念和系統性診斷框架，揭示 LLM 的專長化而非通用化趨勢
2. 設計符號基礎混合評分機制，解決推理任務中 embedding 匹配產生假陽性的長期痛點
3. 基於 Neyman 分配的動態調度器實現 70% 計算節省（ρ=0.96 排名相關性），使大規模即時評測成為可能

## 技術方法

ReLE 系統包含三個核心組件。首先，評測矩陣設計採用「領域 × 能力」正交結構，領域涵蓋中文語言的多個應用場景，能力維度包括理解、推理、生成、知識等。共 207,843 個測試樣本，評估 304 個模型。

符號基礎混合評分機制（SG-HSM）結合符號匹配和語意匹配：對於有確定答案的題目（如數學），使用符號精確匹配避免 embedding 的語意漂移；對於開放式題目，仍使用語意匹配但增加符號約束。這解決了現有評測中「語意相似但邏輯錯誤」被判為正確的問題。

動態方差感知調度器基於 Neyman 最優分配理論：先進行初始小規模抽樣估計各領域的方差，然後將更多計算資源分配給高方差（不確定性大）的領域，低方差領域則減少評估量。加入噪聲校正防止初始估計偏差的傳播。實驗在 Rank Stability Amplitude（RSA）指標上量化了傳統基準（RSA~5.0）與 ReLE（RSA=11.4）的差異。

## 對我們的啟發
- [ ] 能力各向異性是理解 LLM 表現差異的關鍵視角——模型越來越專長化而非通用化，評測應從聚合排名轉向多維度剖面分析
- [ ] 統計抽樣理論（如 Neyman 分配）在大規模評測中有巨大應用潛力，可在幾乎不損失精度的前提下節省 70% 計算成本
- [ ] 符號匹配與語意匹配的混合方案是提升推理任務評測準確性的有效策略，值得在其他評測框架中採用

## 限制與未來工作

目前專注於中文 LLM 評測，對英文或多語言模型的適用性需進一步驗證。動態調度器的效果依賴初始抽樣的方差估計品質，在極端分佈下可能需要更多初始樣本。此外，207,843 個樣本的維護和更新是持續挑戰。
