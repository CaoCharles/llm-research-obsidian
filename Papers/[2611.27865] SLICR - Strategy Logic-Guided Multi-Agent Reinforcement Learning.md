# SLICR: Strategy Logic-Guided Multi-Agent Reinforcement Learning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.27865)
- 📥 [PDF](https://arxiv.org/pdf/2611.27865v1)

## 摘要（中文翻譯）

Specification-guided reinforcement learning（規格導向強化學習）會將以形式語言描述的期望 agent 行為轉換為 shaping rewards。本論文提出 SLICR，將此方向推進至部分可觀測、具對抗性的多 agent 環境。SLICR 採用 Strategy Logic（SL）明確量化 agent strategies，並結合 Linear Temporal Logic（LTL）描述 agent objectives 與 constraints，因此不僅能推理 agent 應如何行動以滿足規格，也能推理其如何回應其他 agent 的 strategies 與 behaviors。作者在 Predator-Prey、Google Research Football，以及自建的 SMAC-HARD 擴充環境上評估 SLICR，結果顯示其具有效性、可擴展性，並能適應多樣的 adversarial strategies。

## 問題背景

現有 specification-guided MARL 多假設其他 agent 採用 stationary strategies，通常只為固定任務學習單一 policy，或以 Nash equilibrium 等 rational behavior 建模對手，難以處理任意、非理性、變動中的 adversarial strategies。論文要在部分可觀測隨機博弈中，根據 SL 對策略的量化與依賴關係，學習能回應不同對手策略的 best-response functions，最大化 LTL 規格的滿足機率。

## 解決方案

作者提出 SLICR（Strategy Logic-Informed Control through Reinforcement Learning），將多 agent strategy synthesis 轉化為 RL 問題。框架以 SL 的策略量化表達對手與控制 agent 間的依賴，將內部 LTL 公式轉成 robustness reward；使用 shield 辨識並排除會干擾訓練的 uniformly random irrational strategies；再以 encoder-decoder 從部分觀測歷史推斷 preceding universal agents 的 strategy context，形成 latent embedding。SLICR 採 CTDE，在集中式訓練、分散式執行下學習 action-level response functions。

## 核心貢獻
1. 將部分可觀測對抗性 MARL 的 strategy synthesis 形式化為 SL-guided learning problem，支援至多一次 quantifier alternation 的 ∀*∃* 與 ∃*∀* fragments。
2. 提出由 quantitative LTL robustness reward、irrational-strategy shielding、strategy-context encoder-decoder 與 CTDE response learning 組成的 SLICR 框架。
3. 在 Predator-Prey、Google Research Football 與 SMAC-HARD 上，以 Seen、Unseen、非理性對手及 inner-LTL ablation 驗證方法，相較 LIAM 報告最高 90% 的效能增益。

## 技術方法

環境建模為 POSG，agent 以 observation-action history 形成 strategy。論文限制處理至多一次 quantifier alternation 的 SL fragments，主要包括 ∀*∃* 與 ∃*∀*。首先建立由 IPPO、MAPPO、VDN、QMIX、QTRAN、內建 AI 與 uniformly random policies 組成的固定 opponent strategy population，並區分 Seen 與 Unseen 設定。對每個完整 strategy assignment，從 POSG 取樣長度 T 的 path，利用 quantitative LTL semantics 計算 prefix robustness，將其作為每一步 reward，並以 discounted cumulative robustness 搭配 A2C、PPO 或 IPPO 學習 response functions。訓練前，shield 以 m-step histories 分類 rational 與 irrational strategy contexts，主訓練排除 irrational 經驗。對 preceding universal strategies，encoder 將 existential agent 的 local history 映射至 latent context；action-reconstruction decoder、observation-reconstruction decoder 與 future-action predictor 分別重建對手 actions、observations，並預測未來 L 步 actions，以學習策略表示。訓練時採 CTDE，可使用對手資訊；執行時僅使用 local information。評估使用 Predator-Prey 的 single-predator collisions、GRF 的每 100 場進球數，以及 SMAC-HARD 的 win rate，並比較 LIAM、兩種 SL fragments、shield 與 inner-LTL guidance 的效果。

## 對我們的啟發
- [ ] 若 agent 必須面對策略會改變或未見過的對手，將對手表示為可泛化的 strategy context，而非只預測當前 action，可能有助於提升 Unseen 策略的適應性。
- [ ] 在形式規格可明確描述安全限制與任務目標時，將 LTL robustness 納入 reward 可提供比單純 shaped reward 更直接的學習訊號；但效果依環境而異，論文部分 ablation 顯示後期增益會消失或不穩定。
- [ ] 對手集合若包含明確定義的隨機或非理性策略，訓練資料篩選或 shield 可能減少噪聲；實務部署前仍應驗證 shield 分類錯誤是否會排除有用的極端行為。

## 限制與未來工作

SLICR 目前只處理至多一次 quantifier alternation，尚未涵蓋更一般的 SL 公式。理論保證依賴 information-preserving latent embedding，但部分可觀測下未必能無損重建對手策略；同時，實驗主要依賴人工建構的 opponent populations 與三類 benchmark，對更廣泛環境的泛化仍需驗證。
