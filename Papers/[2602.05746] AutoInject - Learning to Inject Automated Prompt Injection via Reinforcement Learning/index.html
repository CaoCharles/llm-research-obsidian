    AutoInject: Learning to Inject: Automated Prompt Injection via Reinforcement Learning

    連結

    • 📄 arXiv
    • 📥 PDF
    • 📎 本地 PDF: PDF

    摘要（中文翻譯）

    Prompt injection 是 LLM agent 中最關鍵的安全漏洞之一，然而從優化角度出發的有效自動化攻擊方法仍大量未被探索。現有方法高度依賴人工紅隊測試與手工撰寫的攻擊 prompt，限制了其可擴展性與適應性。本文提出 AutoInject，一個基於強化學習的框架，能夠生成通用且可遷移的對抗性後綴（adversarial suffix），同時聯合優化攻擊成功率與良性任務的效用保持。此黑箱方法支援基於查詢的線上優化以及對未見模型與任務的遷移攻擊。僅使用 1.5B 參數的對抗性後綴生成器，AutoInject 便能成功攻破包括 GPT-5 Nano、Claude Sonnet 3.5 及 Gemini 2.5 Flash 在內的前沿系統，在 AgentDojo benchmark 上建立了自動化 prompt injection 研究的更強基線。

    問題背景

    LLM 越來越多地被部署為自主 agent，可擷取文件、處理電子郵件、瀏覽網頁並執行使用者請求。這種擴展的能力引入了 prompt injection 這一關鍵安全漏洞：攻擊者將惡意指令嵌入外部內容（如電子郵件正文），劫持 agent 行為，導致靜默的資料外洩、未授權操作或輸出操縱。然而，現有的自動化攻擊方法主要集中在 jailbreak 領域，直接適用於 prompt injection 的效果有限。Jailbreak 優化的是通用的肯定性前綴（如「當然，我可以幫忙」），而 prompt injection 需要誘導具體、參數化的動作（如發送特定郵件到攻擊者地址後再返回使用者任務），目標空間更窄且更受限。現有的模板式攻擊（template-based attack）依賴人工設計，攻擊成功率（ASR）普遍低於 25%。

    解決方案

    AutoInject 將 prompt injection 攻擊生成建模為馬可夫決策過程（MDP），並使用強化學習進行端到端優化。核心設計包含三個關鍵組件：

    1. 攻擊策略模型：使用 Qwen2.5-1.5B 作為策略模型，根據注入目標與使用者任務上下文生成對抗性後綴。
    2. 密集獎勵機制：引入基於比較的反饋模型（comparison-based feedback），維護歷史最佳後綴作為參考，對每個新生成的後綴進行成對比較，產生連續的偏好分數，解決稀疏獎勵問題。
    3. GRPO 優化：採用 Group Relative Policy Optimization 進行策略更新，透過組內相對優勢估計提供穩定的梯度信號，同時使用 clipped surrogate objective 與 KL 正則化防止策略過度偏離。

    複合獎勵函數 R = α·r^sec + β·r^util + γ·r^pref 聯合優化攻擊成功率、任務效用保持與密集偏好反饋。

    核心貢獻

    1. 提出首個基於強化學習的 prompt injection 攻擊框架，透過 comparison-based feedback 實現密集獎勵，解決傳統 RL 在二元成功信號下的稀疏獎勵問題
    2. 設計支援線上查詢優化與通用可遷移後綴兩種互補攻擊模式的實用攻擊方案，單一後綴可跨模型、跨任務遷移（如一個含 "allelujah" 的後綴在 Gemini 2.5 Flash 上攻破 70 個任務對）
    3. 在 AgentDojo benchmark 上對 9 個目標模型進行全面評估，AutoInject 在所有模型上均大幅超越 template-based 與 optimization-based 基線，並首次在專門抵禦 prompt injection 的 Meta-SecAlign-70B 上達到 21.88% ASR

    技術方法

    問題建模：將攻擊生成建模為 MDP，狀態 s_t = (g, c, a_1, ..., a_{t-1}) 包含注入目標 g、使用者任務上下文 c 與已生成 token。動作為從詞彙表中選擇下一個 token，生成完成後得到後綴 x = (a_1, ..., a_T)。

    評估管線：使用 AgentDojo benchmark 評估後綴，後綴被嵌入環境中（如電子郵件正文），受害 agent 在處理使用者任務時接觸到注入內容。AgentDojo 提供 security score r^sec（注入目標是否執行）和 utility score r^util（原始任務是否完成）的 ground-truth 評估。

    密集獎勵設計：維護參考後綴 x（訓練中表現最佳的後綴）。對每個新後綴 x，查詢反饋模型比較 x 與 x，採用 chain-of-thought 推理生成分析後輸出二元標籤，再從 log-probabilities 提取校準的偏好分數 r^pref = P(x ≻ x* | g, c)。反饋權重 γ 隨訓練進度遞減（從 0.8 到 0.1），早期依賴偏好信號探索，後期依賴 ground-truth 結果。

    GRPO 訓練：每步採樣 K 個後綴，計算組內標準化優勢 Â_i，最大化 clipped surrogate objective 並加入 KL 散度正則化。每個（注入目標、使用者任務）配對獨立訓練，直到策略達成完美分數或耗盡查詢預算 B=260。

    攻擊生成器：策略模型 Qwen2.5-1.5B，反饋模型 GPT-4o-mini，最大後綴長度 30 tokens，溫度 0.9，top-p 0.95。

    對我們的啟發

    • RL-based 攻擊方法揭示了當前 safety tuning 和 template-based 防禦的根本不足：靜態防禦無法泛化到自適應對手，需要結合持續性紅隊測試與動態防禦機制
    • 密集獎勵設計（comparison-based feedback）解決了安全領域中常見的稀疏信號問題，此技術可推廣至其他需要二元成功判定的 RL 應用場景
    • 通用可遷移後綴的存在（如 "allelujah" 系列）表明不同 LLM 的安全機制存在共通的脆弱模式，防禦者應關注跨模型的系統性漏洞而非個別攻擊模式

    限制與未來工作

    本文攻擊假設目標模型的 tool-calling 決策受其處理內容的影響（即 agent 不會在執行前進行確認），Claude Haiku 4.5 等要求確認的模型可有效阻斷此攻擊管線。此外，plan-then-execute 架構（如 CaMeL、IPI-Guard）透過解耦規劃與執行來防禦注入，但犧牲了 agent 的靈活性。論文僅在 AgentDojo 環境中評估，未涵蓋更廣泛的真實世界部署場景。未來工作方向包括：開發能對抗 RL-based 自適應攻擊的動態防禦、探索 deliberative alignment（模型主動求確認）作為正交防禦策略、以及研究攻擊效率與對應防禦機制的共同進化。
