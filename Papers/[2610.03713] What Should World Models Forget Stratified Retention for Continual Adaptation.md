# What Should World Models Forget? Stratified Retention for Continual Adaptation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.03713)
- 📥 [PDF](https://arxiv.org/pdf/2610.03713v1)

## 摘要（中文翻譯）

傳統 continual learning 將先前資料上的性能下降視為失敗，因其假設 prediction target 穩定且正確標籤永久有效。然而，world model 預測的是會變動的環境；曾經正確的知識可能因道路重建、物體移動或場景重排而過時，適時捨棄這些知識反而是必要行為。本文指出，world model 同時包含必須永不修改的 invariant，例如 physics 與 object permanence，以及應隨環境變化更新的 instance-level facts，因此需要依 invariance timescale 分層 retention。作者主張標準 forgetting metrics 無法區分正確修訂過時知識與 catastrophic forgetting，甚至會偏好 frozen model。為此提出 differential retention，以 adaptation stream 中的 invariant regression testing 聯合 revision latency 進行評估，且不將兩者聚合為單一分數。

## 問題背景

論文處理 continual world models 的評估錯置問題。既有 continual-learning metrics 把所有舊知識性能下降都算作 forgetting，無法辨識環境改變後的正確 revision 與真正的 catastrophic forgetting；固定目標的 benchmarks 也排除了 obsolescence。現有 consolidation 方法依過去任務重要性保護參數，而非依知識可持續多久，因此可能過度保護過時場景、又不足以保護 physics、geometry 與 causal invariants。

## 解決方案

作者提出以 invariance timescale τ 對 world-model knowledge 分層，並讓保護程度隨 τ 增加。τ=∞ 的 invariants（如 gravity、object permanence、geometric consistency 與 action–effect structure）不可被更新破壞；environment regularities 應隨累積證據較慢修訂；instance configuration 應在環境變化後迅速修訂；transient state 則不要求 retention。核心評估框架 differential retention 包含兩個分開報告的量：每輪 adaptation 後對 held-out invariants 執行 regression testing，以及量測模型修訂變動事實所需的 observations 數量與永不修訂的比例。

## 核心貢獻
1. 將 world-model 的 obsolescence 與 catastrophic forgetting、deliberate unlearning 明確區分，指出環境變動使傳統 stationary-target 假設失效。
2. 提出依 invariance timescale τ 分層 knowledge，涵蓋不可修改的 invariants、應慢速更新的 environment regularities、應快速更新的 instance configurations，以及不需 retention 的 transient state。
3. 提出 differential retention 評估協議，將 invariant regression testing 與 revision latency 分開呈現，避免以單一 forgetting 分數獎勵 frozen model。

## 技術方法

本文是 position paper，沒有提出新的模型架構、訓練演算法或資料集，而是提出評估與知識組織框架。首先將 knowledge 依環境真值的 invariance timescale τ 分為 invariants、environment regularities、instance configuration 與 transient state，主張保護強度應隨 τ 增加，而非依 past-task importance 決定。評估流程包含兩部分：(1) 從 τ=∞ strata 建立與 adaptation data 分離的 held-out probe set，在每一輪更新後重新測試，以定位哪次更新破壞 invariant；作者指出 WorldBench 與 PhyGround 的 concept-isolated physical probes 可直接重用，但目前僅涵蓋 physical sub-case。(2) 對已改變的環境事實持續提供 observations，計算模型預測反映新事實所需的 observation 數量，並另計永不 revision 的事實。兩項結果不可合併：frozen model 可能有高 invariant retention 卻無法 revision，而覆寫式更新可能快速 revision 卻損害 invariants。論文未指定完整資料處理、模型架構或實作演算法。

## 對我們的啟發
- [ ] 部署 continual world model 時，應將 physical invariant probes 納入每輪更新後的 regression suite，而不是只在最終 checkpoint 評估。
- [ ] 評估 adaptation 不應只看舊任務性能下降；應同步記錄新證據出現後的 revision latency，以及模型是否錯誤保留已過時的環境事實。
- [ ] 記憶或 consolidation 機制的保護對象應依知識的環境穩定性設計，而不能只依 past-task importance；但這是依本文框架提出的實務應用方向，論文未驗證具體架構效果。

## 限制與未來工作

本文是 position paper，未提供實驗、模型比較、資料規模或量化驗證。τ 的邊界可能依領域而異，尚不清楚能否由 observations 估計或必須由 domain knowledge 指定。目前足夠嚴謹的 probes 主要限於 physical invariants；geometric consistency 與 causal structure 尚缺乏對應測試。此外，invariants 是否在 learned world model 中局部化仍未知，若知識彼此糾纏，可能需要 architectural support。
