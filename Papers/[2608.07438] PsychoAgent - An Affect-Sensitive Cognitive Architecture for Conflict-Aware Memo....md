# PsychoAgent: An Affect-Sensitive Cognitive Architecture for Conflict-Aware Memory in LLM Agents

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.07438)
- 📥 [PDF](https://arxiv.org/pdf/2608.07438v1)

## 摘要（中文翻譯）

人類式認知不會只依主題相似度選取過去經驗；情感重要性與未解決的衝突也會影響記憶可及性。本文提出 PsychoAgent，一種為 LLM agents 設計的認知架構，將事實記憶與情感記憶分離，並透過具衝突感知能力的 executive controller 加以整合。情感記憶先經 semantic relevance 篩選，再依 salience 重新排序，在維持主題適配性的同時，使情緒上重要的記憶能進入 prompt。在三個受控衝突情境中，完整架構所取回的衝突關鍵記憶多於 semantic-affective 與 single-memory RAG baselines，比例為 0.933、0.500 與 0.667，並僅付出小幅 semantic-similarity 成本。五名盲評者評估 27 個輸出；within-rater standardization 後，完整架構的 overall mean 最高，為 +0.22 SD，但校正後的 pairwise differences 並不顯著。三天示意性 trace 進一步展示持續性情感、離線記憶重組與選擇性記憶重新加權。結果支持將 affect-sensitive retrieval 作為可檢查、可稽核的人類式衝突效應建模機制。

## 問題背景

現有 LLM agent memory 與 RAG 多以 semantic similarity、recency、utility 或單一 importance score 選取記憶，可能忽略文字不相似但具有情感重要性、未解決衝突或關係意義的經驗。本文要探討的是：如何在不讓無關高情緒記憶主導 prompt 的前提下，讓 affect-laden memories 影響衝突情境中的記憶存取與決策。作者並非宣稱修復 LLM 的臨床缺陷，也不以本文驗證 psychoanalysis 或神經等價性。

## 解決方案

作者提出 PsychoAgent，將記憶分為 factual memory 與 affective memory，並由單一 conflict-aware executive controller 進行整合。核心機制是 affective retrieval 的兩階段程序：先用 semantic relevance 建立候選集合，再以 affective salience 重新排序，使衝突關鍵記憶能超越稍高語義相似度但情感較弱的項目。controller 同時讀取 current affect、persona、beliefs、relationship constraints 與兩類記憶，形成可觀察的衝突整合流程。架構亦支援 memory-access regulation、salience revision，以及每日一次的 offline recombination，將近期事件重組為下一週期使用的 temporary affective trace。作者將 ACC、Type 1/Type 2 與 psychoanalytic vocabulary 僅作功能性或次要類比，主要主張是可記錄、可消融、可稽核的 affect-sensitive retrieval。

## 核心貢獻
1. 提出 PsychoAgent 認知架構，明確分離 factual memory 與 affective memory，並由 conflict-aware executive controller 整合情境、人格、關係、當前情感與兩條記憶路徑。
2. 設計 context-count-matched 的三方比較，特別以 Full PsychoAgent 與 semantic-affective ablation 對照，隔離 semantic preselection 後的 salience re-ranking 對記憶可及性的影響。
3. 提供可檢查的 longitudinal trace，包括 affective-state persistence、offline recombination、temporary affective trace 與 selective memory reweighting，並明確限制其為工程類比而非神經或心理診斷模型。

## 技術方法

PsychoAgent 由一個 decision loop 與兩條 memory paths 組成。唯一負責決策的 conflict-aware executive controller 讀取 persona and beliefs、observable context、dynamic affective-state vector、relationship graph，以及 factual 與 affective memories，輸出 speech/action 並記錄狀態更新。每個重要事件建立兩個 linked traces：factual record 描述發生內容，affective interpretation 則附有 salience w_j∈[0,1]。Factual retrieval 以 query embedding 的 semantic similarity 取 TopK10；affective retrieval 先取 semantic TopK30，再依 salience 降冪排序取 TopK10，最終 prompt 含 10 筆 factual 與 10 筆 affective memories。比較三個 context-count-matched 變體：完整架構、只用 semantic similarity 的 semantic-affective ablation，以及合併兩類記憶後取 Top20 的 single-memory RAG。資料包含三個 hand-authored conflict scenarios：家庭財務衝突、職場批評與友誼背叛；每個情境有 15 筆 factual、36 筆 affective memories，其中 10 筆事前標為 conflict-critical，標籤對生成器、automatic judge 與評分者隱藏。使用 Gemini 2.5 Flash、temperature 0.7、thinking budget 0，三個 seeds 產生 27 個 outputs；retrieval 使用 768 維 Gemini Embedding 2 vectors。指標包括 critical retrieval rate、mean affective salience 與 mean semantic similarity。retrieval 以三個獨立 scenarios 進行 exact Friedman permutation test；行為評估由五名 blind raters 以 1–5 分評估 persona consistency、memory grounding、conflict sensitivity、naturalness 與 action appropriateness，並進行 within-rater z-score standardization、Friedman test 與 Holm 校正的 paired Wilcoxon tests。另有三天 illustrative family trace，展示 affect persistence、每日 offline recombination 與 reflection 後的 selective salience reweighting，但作者明確將其視為示意而非受控 temporal experiment。

## 關鍵結果

| 評估項目 | Full PsychoAgent | Semantic-affective ablation | Single-memory RAG |
|---|---:|---:|---:|
| Critical retrieval rate | 0.933 ± 0.058 | 0.500 ± 0.100 | 0.667 ± 0.115 |
| Affective salience | 0.902 ± 0.004 | 0.789 ± 0.027 | 0.792 ± 0.038 |
| Semantic similarity | 0.718 ± 0.025 | 0.729 ± 0.026 | 0.734 ± 0.024 |
| Human overall standardized score | +0.22 ± 0.23 SD | -0.09 ± 0.17 SD | -0.13 ± 0.30 SD |

在 retrieval 層面，完整架構三個情境的 critical retrieval rate 分別為 1.0、0.9、0.9；exact Friedman permutation test 為 Q=6.00、p=0.0278，但各 pairwise Wilcoxon test 的 Holm-adjusted p=.75。相較 semantic-affective ablation，完整架構的 semantic similarity 低 0.011，而 critical retrieval 提高 0.433。人類評估涵蓋 5 名評分者、27 個輸出與五項標準；overall Friedman test p=.121，Full 與兩個 baseline 的最強 pairwise 趨勢經 Holm 校正皆為 p=.082，因此論文未建立行為品質的顯著優勢。Automatic judge 因多項分數達量表上限、區辨力不足，論文以 human ratings 作為主要行為結果。

## 對我們的啟發
- [ ] 在 agent memory retrieval 中，可將 task relevance 與 affective priority 分成兩階段處理：先以 semantic relevance 排除無關記憶，再以 salience 排序相關候選，有助於避免高情緒但不相關的記憶主導 context。
- [ ] 評估 memory architecture 時，應同時測量記憶選取品質與最終行為品質；本文顯示 critical-memory retrieval 有明顯提升，但人類評分的行為優勢尚未達統計顯著。
- [ ] 實務部署應保留 memory provenance、記憶 ID、salience 變化與 retrieval logs，並考慮限制重複取回及衰減缺乏支持的 salience，以降低偏誤記憶或反芻式重複對 agent 行為的影響。

## 限制與未來工作

研究僅使用三個 hand-authored conflict scenarios、單一 model family、固定 memory banks 與研究者預先定義的 critical labels；seeds 是同一任務內的重複，不能視為獨立情境。人類評分存在 ceiling effects，且 longitudinal trace 未標準化每日 turns。未來需進行多模型、多情境、多輪互動與 module-level ablation，並測試 noisy 或 biased salience 的影響。
