# OmniScientist: An Omni-Modal Omni-Discipline AI Scientist

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.13558)
- 📥 [PDF](https://arxiv.org/pdf/2608.13558v1)

## 摘要（中文翻譯）

基礎模型的進步使 AI scientist 能自動化假說生成、程式執行與論文撰寫等研究流程。然而，流程覆蓋並不等於能取得科學發現所依賴的完整證據；現有系統多半只處理文字、程式碼、標籤或預先計算的摘要，因而失去關鍵的空間、時間、跨通道與程序關係。本文提出 OmniScientist，一個端到端、全模態且跨學科的 AI scientist，直接從異質原始證據進行研究。系統由 perception layer 與 ideation、experiment、writeup 三個 autonomous agents 組成，置於 deterministic pipeline 中，使觀察能持續影響研究問題、實驗決策與最終主張。系統以程式碼執行 idea、rigour 與 claim checks，檢查新穎性、統計有效性、執行 provenance 及數值可追溯性。在涵蓋五類學科、36 個真實資料案例的評估中，系統完成全部端到端流程；使用 reference reasoning backbone 時，平均論文總分為 6.3。在與僅接收預計算 scalar features 的 blind variant 配對比較中，直接 perception 在七項評估維度皆有改善，並贏得 85% 的一對一判斷。

## 問題背景

現有 AI scientist 雖能涵蓋假說生成、程式執行與論文撰寫，卻通常只接收文字、程式碼、標籤或預計算摘要。這些介面會丟失影像的空間結構、訊號的時間順序、跨通道關係與實驗程序資訊，使代理只能在人工選定的表示上推理，限制異常發現、問題形成與主張支持；即使具備多模態能力，既有系統也多只在單一局部階段使用 perception。

## 解決方案

作者提出 OmniScientist，將直接 raw-evidence perception 與三個 autonomous agents——ideation、experiment、writeup——整合進 deterministic pipeline。每個階段內部以 ReAct 交錯觀察、推理與工具操作，但階段轉移、失敗回溯與結果接納由程式碼控制。其核心創新是 lifecycle-wide perception：同一組原始觀察可影響研究問題、實驗設計、結果檢查與論文主張；同時透過 idea、rigour、claim checks 強制新穎性與可反駁性、統計嚴謹性、執行 provenance、anti-HARKing 及數值與主張追溯。新增學科主要透過 specification file，而非修改核心引擎。

## 核心貢獻
1. 提出 OmniScientist，一個可直接處理異質原始科學證據、跨五類學科與多種模態的端到端 AI scientist。
2. 提出 perception-first 的多代理研究架構，使原始觀察能在 ideation、experiment 與 writeup 全生命週期中影響決策。
3. 將 novelty、falsifiability、leakage、effective sample size、multiple comparisons、execution provenance、anti-HARKing 與 claim traceability 等檢查以程式碼強制執行，並建立包含36個案例的跨學科 demonstration suite。

## 技術方法

OmniScientist 將任務表示為 specification file，包含 dataset、scientific subject、target property、原始資料與模態資訊。Perception layer 先按 perceptual、symbolic、quantitative-statistical、procedural 四類 evidence family 組織資料，再依 modality 提供原生 numeric readers 與視覺工具；系統可分析 FFT、趨勢、軌跡、音訊統計、3-D PCA，也可渲染 image、signal、audio、video、3-D 或 trajectory 供模型檢視，並設有視覺檢查預算。Ideation agent 透過 ReAct 流程盤點資料、搜尋 OpenAlex／Crossref 文獻、產生至少五個候選想法，評估 novelty risk、可行性、可反駁性與統計 power，最後形成可執行的 falsifiable hypothesis。Experiment agent 在受控 run_python 環境中迭代產生與除錯程式，執行 primary test、baseline、ablation、mechanism、breakdown、sensitivity 與 leakage/grouping 分析，保存 data I/O、stdout、figures、configs 與所有嘗試。Rigour check 驗證資料確實載入、程式成功執行、數值來自真實輸出、測試數量完整計入 multiple-comparison correction、避免 leakage 與 circular prediction，並將不支持的分析降級至 trace。Writeup agent 依五種學科寫作規格逐節撰寫，只能引用 execution record；最後由 claim check 將論文數值與主張逐一追溯到輸出與分析。評估使用七個維度：Novelty、Soundness、Clarity、Significance、Reproducibility、Multimodal Grounding、Factual Accuracy，並由兩個跨系統 judge 評分。

## 對我們的啟發
- [ ] 若評測目標是證據導向的科學代理，應將原始觀察能力納入評估，而不能只比較文字、特徵向量或最終論文。
- [ ] 將開放式 LLM reasoning 放在由程式碼控制的 deterministic pipeline 內，可降低階段轉移、統計報告與數值引用依賴模型自律的風險。
- [ ] 研究代理應保存完整 execution record，將所有嘗試過的分析、資料輸入、stdout、圖表與設定納入 provenance，並讓最終主張只能引用已驗證紀錄。

## 限制與未來工作

評估主要是 36 個 demonstration cases，且論文未提供與完整既有 AI scientist 系統的全面端到端 baseline；論文分數由兩個 model judges 評定，可能不足以代表真實專家審查。系統也受限於可計算研究、工具與時間預算，且許多案例的科學發現仍屬資料內驗證，未證明可泛化或具因果性。
