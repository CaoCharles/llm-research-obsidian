# WearableQA: A Benchmark for Health Reasoning over Real-World Wearable Data

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.05405)
- 📥 [PDF](https://arxiv.org/pdf/2609.05405v1)

## 摘要（中文翻譯）

穿戴式感測技術的進步，已能持續監測生理與行為訊號；然而，現有 benchmark 很少評估 AI 系統是否能根據真實使用者的 longitudinal wearable record 進行推理。本文提出 WearableQA：由 200 名真實使用者的 wearable time series、血液 biomarkers 與 demographic 資訊建立的 benchmark，包含 4,084 道十選一選擇題；每位使用者最多有 500 天的每日測量資料。WearableQA 保留真實穿戴式資料中的裝置雜訊與個體差異，並以 data versus health reasoning 及 single- versus cross-signal reasoning 兩個互補軸線，設計 16 種題型。為大規模建立可靠題目，作者提出結合文獻支持生理發現與經統計驗證之 population-grounded 生理模式的 dual-grounding framework。14 個 proprietary 與 open-source LLM 的準確率介於 19.6% 至 72.9%，相對於 10% 猜測基準仍有顯著差異，但多數模型低於 60%，顯示此 benchmark 尚未被解決。

## 問題背景

現有健康與 time-series benchmark 多以靜態文字、考試題、ECG 或 synthetic/simulated signals 為主，無法充分評估模型從真實使用者數百天的 noisy longitudinal wearable data 中計算趨勢、異常與訊號關係，再進行個人化生理解讀的能力。尤其資料推理、跨訊號整合，以及 wearable measurements 與 blood biomarkers、demographics 的聯合分析仍缺乏具診斷性的系統化評測。

## 解決方案

作者提出 WearableQA，一個以 200 名真實使用者、最多 500 天每日 wearable measurements、17 項 blood biomarkers 與 demographic attributes 為基礎的 4,084 題 benchmark。核心是 dual-grounding framework：一方面從 11 篇經全文核驗、且至少有兩項同方向獨立研究支持的 biomedical literature findings 建題；另一方面從大型 cohort 挖掘並通過 effect size、bootstrap/leave-one-out robustness 與 cross-user null test 的 population-grounded patterns。題目先由 reasoning objective 轉換為可組合的 computation primitives，再對個人資料執行 deterministic labeling，並以 16 種題型診斷 data/health reasoning 與 single/cross-signal reasoning 的差異。

## 核心貢獻
1. 提出包含 4,084 道十選一問題的 WearableQA，將 200 名真實使用者的最多 500 天 longitudinal wearable data、blood biomarkers 與 demographics 納入 LLM health reasoning 評測。
2. 提出 dual-grounding 與 discover-then-label 建構流程，結合 literature-grounded findings、population-grounded patterns、統計驗證及 deterministic computation graphs，以產生可重現的 ground truth。
3. 建立涵蓋 data/health reasoning 與 single/cross-signal complexity 的 16 類診斷性 taxonomy，並以 14 個模型揭示資料計算、跨訊號整合與工具使用上的能力差異。

## 技術方法

資料包含 200 名真實使用者的 16 項每日 wearable metrics，涵蓋 cardio-fitness、activity/energy、sleep 與 stress 四個領域；另提供 17 項 blood biomarkers、age、sex、BMI、ethnicity，以及五項核心 wearable metrics 的 cohort-relative percentiles。題目沿兩個 2×2 軸分類：data versus health reasoning，以及 single- versus cross-signal reasoning，並另標記 literature-grounded 或 population-grounded。建題採 discover-then-label 流程：先由文獻或 cohort pattern 定義 reasoning objective，再以 reusable computation primitives，例如 mean、coefficient of variation、slope、rolling mean、lagged correlation、threshold flags 等，組成 explicit computation graph。每個使用者的答案由 deterministic program 從原始測量計算；若資料缺失或結果模糊則剔除。資料題的 distractors 包含反向趨勢、相鄰時間窗與錯誤幅度，並要求唯一選項滿足計算條件；健康題則以 grounded finding 建立臨床上合理但不符合個人資料的替代解釋。Population pattern 須滿足相關係數門檻、兩半窗口方向一致、30 次 bootstrap 至少 80% 重現、leave-one-out 穩定，以及 FDR≤0.20。評估 14 個 proprietary/open-weight LLM，使用十選一 exact-match accuracy、95% Wilson confidence interval，並比較 chain-of-thought 與 direct-answer、資料表徵、Python agentic tool use 及移除 time-series 的 ablation。

## 關鍵結果

| 實驗項目 | 主要結果 |
|---|---|
| 整體模型準確率 | 19.6%–72.9%；十選一 chance baseline 為 10%，多數模型低於 60% |
| 最佳模型 | Gemini 3.1 Pro：72.9%；data 75.4%、health 67.8%、single 72.4%、cross 73.2% |
| 次佳模型 | Claude Opus 4.6：60.2%；data 57.1%、health 66.3%、single 64.9%、cross 56.8% |
| 最佳 open-source 模型 | Gemma-4-26B-A4B：42.5%；data 33.8%、health 59.8% |
| 最低模型 | Llama-3.2-3B：19.6%，接近 10% chance baseline |
| Data vs. health reasoning | 除 Gemini 3.1 Pro 外，多數模型 health reasoning 高於 data reasoning；例如 GPT-4o 為 53.5% vs. 25.3% |
| Single vs. cross-signal | 多數 proprietary models 的 single-signal 高於 cross-signal；GPT-5.4 為 59.1% vs. 45.7% |
| 困難題型 | Strongest pair 與 recovery time 對多數模型較難；cross-signal prediction 最高僅 Claude Opus 4.6 的 40.5% |
| CoT 效果 | Claude Opus 4.6 整體由 direct-answer 40.6% 升至 60.2%；GPT-5.4 由 33.5% 升至 51.2%；Gemini 3.1 Pro 僅由 71.3% 升至 72.9% |
| Python agentic tool use | GPT-5.4 由 row baseline 51.2% 升至 fixed-representation agentic 71.3%；data reasoning 45.0% 升至 72.9% |
| 輸入表徵 | GPT-5.4 的 CSV 整體 51.5%，較 row baseline 51.2% 僅增加 1.2 個百分點；image-grid 為 36.6% |

| 先驗依賴 | 部分模型在 definitional signal pairs 顯著優於 empirical pairs；Gemini 2.5 Pro 為 87.8% vs. 36.3%，差距 51.5 個百分點 |

## 對我們的啟發
- [ ] 若要建置個人健康 AI，不能只測試醫學知識；應分開評估模型是否能從長期原始測量正確計算，以及是否能進行生理詮釋。
- [ ] 對 longitudinal wearable data，提供可執行的 Python 計算工具比單純改變 CSV、Markdown 或圖像輸入格式更有效；論文中 GPT-5.4 的 agentic fixed-representation 結果由 51.2% 提升至 71.3%。
- [ ] 評測題目應同時包含 single-signal 與 cross-signal、個人歷史與 cohort-relative context，並用 balanced answer positions、distractor auditing 及移除資料測試檢查位置偏差與資料依賴性。

## 限制與未來工作

資料僅涵蓋 200 名使用者，且論文未報告更完整的族群代表性、跨裝置泛化或外部 cohort 測試結果。十選一選擇題主要衡量選項準確率，未完整評估臨床安全性、解釋品質與實際醫療決策。作者也未提供各題型完整的使用者分層與獨立測試集結果；未來可擴大族群、驗證跨 cohort 泛化，並加入臨床專家與安全性評估。
