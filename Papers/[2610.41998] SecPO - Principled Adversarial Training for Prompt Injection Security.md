# SecPO: Principled Adversarial Training for Prompt Injection Security

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.41998)
- 📥 [PDF](https://arxiv.org/pdf/2610.41998v1)

## 摘要（中文翻譯）

Prompt injection 是 AI agent 面臨的主要威脅之一，攻擊者可將惡意指令植入 email、文件或網站等不受信任資料，操控 agent 的行為。現有防禦模型 Meta-SecAlign 採用 DPO，但在 adaptive prompt injection 下的 attack success rate（ASR）仍接近 100%。作者指出，DPO 以不安全的 undefended model 作為 reference，限制了安全能力提升。為此，論文提出 Secure Preference Optimization（SecPO），以理想化、具 injection-invariance 且維持效用的 oracle distribution 作為參考；此分布可由 undefended model 在 clean input 上的輸出近似取得。同時，作者建立以 PAIR 為基礎的 adversarial training（AT）流程，透過 best@240 搜尋產生強注入。相較 Meta-SecAlign，AT 可降低三種 adaptive attacks 的 ASR 1.5–14.5 倍，SecPO 再降低 2.4–4.6 倍。在 AgentDojo AttackerMovesSecond 評估中，SecPO + AT 的 Qwen3.6-27B ASR 為 8.8%，Meta-SecAlign 為 78.8%，且九項 benign utility benchmark 未見明顯下降。

## 問題背景

論文處理 AI agent 從不受信任資料讀取內容時遭受 indirect prompt injection 的問題。Meta-SecAlign 雖以 DPO 學習忽略注入，但其 static、弱攻擊訓練資料難以涵蓋 adaptive attacks；更根本地，DPO 將模型約束在不安全的 undefended reference 附近，抑制安全行為與 utility 的兼顧。

## 解決方案

作者提出 SecPO 與 adversarial training 的聯合方案。SecPO 將 DPO 在 injected input 上使用的 undefended reference，改為 oracle reference：對注入輸入，oracle 的目標分布等於 undefended model 在對應 clean input 上的輸出分布。因此訓練時只需以 clean input 查詢初始模型，即可近似 oracle，而無需建立真正的 oracle checkpoint。另一方面，AT 使用 attacker LLM、victim LLM 與 judge LLM 迭代搜尋高成功率注入，並將最佳注入加入偏好訓練。核心創新是以 security-informed regularization 保留 clean-input utility，同時不把模型鎖定在 injected-input 上的不安全行為。

## 核心貢獻
1. 提出 SecPO loss，將 DPO 的不安全 injected-input reference 改為由 undefended model 在 clean input 上提供的 oracle-like reference，從理論上解除安全提升受到的錯誤 KL 約束。
2. 建立可並行化的 PAIR-based adversarial training pipeline，以 attacker、victim 與 judge LLM 迭代搜尋強注入，並證明訓練於強攻擊可泛化至未見的 Genetic、TAP 與 PISmith attacks。
3. 在 instruction-following 訓練資料上訓練的模型，展現對多步驟 agentic tool-calling 任務的安全泛化；同時釋出程式碼、最佳化注入訓練資料與模型權重。

## 技術方法

模型層級防禦使用額外的 input message role 封裝不受信任資料，假設 trusted prompt 與 untrusted data 的界線已知。訓練資料由 Cleaned-Alpaca 中具有 data 欄位的 instruction-following samples 建立，共 19,157 個 preference pairs；clean sample 以另一筆樣本的指令初始化 simulated injection，並產生 desirable response 與 undesirable response。作者微調 Llama-3.1-8B-Instruct 與 Qwen3.6-27B；前者使用 LoRA，後者採 offline AT 使用預先最佳化的注入資料。SecPO loss 將分母 reference 改為 π_undef(y|x_clean)，而非 DPO 的 π_undef(y|x_inj)。AT 中 attacker 每輪提出 8 個候選注入，victim 產生回應，judge 以 1–10 分評估攻擊效果，重複 30 輪，形成 best@240；搜尋期間各 batch 樣本的 API 呼叫並行處理。評估涵蓋 SEP、Genetic、TAP、PISmith、AgentDojo、AgentDyn、DTaP-Bench-Indirect，以及 MMLU-Pro、GPQA Diamond、GSM8K、Minerva Math、AlpacaEval2 等。安全指標為 ASR（含 ASR@800 或 ASR@10），效用則依各 benchmark 的任務成功率或準確率計算。

## 關鍵結果

主要結果如下（ASR 越低越安全；utility 越高越好）：

| 模型／方法 | 評估 | Meta-SecAlign | SecPO + AT／offline AT |
|---|---:|---:|---:|
| Llama-3.1-8B | Genetic ASR@800 | 89.1% | 12.3% |
| Llama-3.1-8B | TAP ASR@800 | 84.6% | 12.2% |
| Llama-3.1-8B | PISmith ASR@10 | 95.1% | 7.0% |
| Qwen3.6-27B | Genetic ASR@800 | 93.7% | 13.3% |
| Qwen3.6-27B | TAP ASR@800 | 90.1% | 12.5% |
| Qwen3.6-27B | PISmith ASR@10 | 94.0% | 1.8% |
| Qwen3.6-27B | AgentDojo adaptive ASR@800 | 78.8% | 8.8% |
| Qwen3.6-27B | AgentDojo static ASR | 2.2% | 0.0% |
| Qwen3.6-27B | AgentDyn ASR | 4.8% | 0.0% |
| Qwen3.6-27B | DTaP ASR | 45.9% | 7.6% |
| Qwen3.6-27B | 六項 benign utility 平均 | 88.4% | 89.1% |

在 Llama 模型上，三種 adaptive attacks 的平均 ASR 由 89.6% 降至 10.5%；在 Qwen 模型上則由 92.6% 降至 9.2%。論文另報告 SEP ASR 為 1.4%（Llama）與 1.8%（Qwen），並指出九項涵蓋 tool calling、instruction following、science 與 math 的 benchmark 未見明顯 benign utility 損失。

## 對我們的啟發
- [ ] 實務上不應只用 static 或模板式注入做安全微調；應以 adaptive red-teaming 搜尋接近部署環境的攻擊，並將強攻擊樣本納入訓練或離線重用。
- [ ] 安全訓練的 reference model 需要與目標行為一致：在 injected context 上直接模仿不安全初始模型，可能抵消偏好學習；以 clean context 的輸出作為 utility target，是較合理的 security-informed regularization。
- [ ] 評估 agent 安全性時，應同時測試單一注入、多重注入、語義接近任務的注入與多次攻擊嘗試，並分開報告 ASR 與 benign utility；單一 static ASR 可能嚴重高估防禦效果。

## 限制與未來工作

論文的設定假設 trusted 與 untrusted input 的標籤已知，未處理信任關係本身不明或需要判定的情境；也未以 reasoning model 為主要研究對象。AT 依賴大量 attacker、victim 與 judge API 呼叫，成本仍高。測試時主要假設黑箱 adaptive attack，白箱 gradient attack 並非核心評估。
