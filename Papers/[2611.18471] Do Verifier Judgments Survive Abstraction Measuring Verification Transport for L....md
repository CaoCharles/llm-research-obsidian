# Do Verifier Judgments Survive Abstraction? Measuring Verification Transport for LLM Agent Evaluation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.18471)
- 📥 [PDF](https://arxiv.org/pdf/2611.18471v1)

## 摘要（中文翻譯）

LLM-based verifiers 日益用於評估 agent 執行，但其可靠性通常只在單一 trajectory 表示下衡量。在部署系統中，同一執行可能經由 composed tools、delegation boundaries 或 compacted histories 呈現，導致 verifier 可直接觀察的 execution evidence 改變。因此，正確的 verifier judgment 是否能跨越 abstraction boundary 仍不明確。作者提出 Verification Transport，衡量 judgment 在 abstraction 導致的 observability 改變下是否穩定。研究建立同一 frozen execution 的 native、abstracted 與 restored views，固定 task、realized trajectory、outcome、ground truth、evaluation criterion 與 verifier。跨四個 agent-evaluation benchmarks、七個 verifier backbones、四種 verification protocols 及三類 abstraction boundaries，macro abstraction 與 delegation 的 transport failure 約達31%。Direct verification 較常產生錯誤 verdict；evidence-grounded 與 deliberative protocols 在觀測受限時較常 abstain。恢復 execution provenance 可修復85.5%的 transport failures，顯示 native-view accuracy 不足以完整描述跨抽象邊界的 verifier reliability。

## 問題背景

現有 agent verifier 評測多在固定 trajectory 表示下計算 accuracy，隱含假設執行證據始終完整且以相同方式暴露。然而部署系統常透過 macro tools、delegation 或 history compaction 隱藏、群組或摘要化低階事件；即使 underlying execution 未變，verifier 仍可能改變判斷或無法給出 verdict。論文因此研究 native-correct judgment 能否在 observability shift 後保持正確，並指出 native-view accuracy 無法反映此類可靠性。

## 解決方案

作者提出 Verification Transport，將「正確判斷是否能跨 abstraction boundary 保持」定義為獨立可靠性標準。對每條 frozen trajectory 建立 native view、abstracted view 與 provenance-restored view，僅改變 verifier 可見的 execution evidence，固定 task、outcome、ground truth、criterion 與 verifier。研究涵蓋 macro abstraction、delegation、history compaction，並以 VTFR 衡量 native-correct judgment 在抽象後變成 wrong verdict 或 no verdict 的比例，再以 RRR 與 RDR 評估恢復 provenance 的修復及副作用。核心創新是將觀測可得性與 provenance transport 納入 agent verifier 評測。

## 核心貢獻
1. 提出 Verification Transport，將 native-correct verifier judgment 在 observability abstraction 後是否保持正確，定義為 agent verification 的補充可靠性指標。
2. 建立 native–abstracted–restored 的 matched evaluation framework，控制 underlying execution、outcome、ground truth、criterion 與 verifier，只改變 execution evidence 的可見性，並涵蓋 macro、delegation 與 compaction 三種邊界。
3. 在四個 benchmarks、七個 verifier backbones 與四種 protocols 上系統分析 transport failure、wrong/no-verdict failure modes，以及 provenance restoration 的 recovery 與 degradation。

## 技術方法

研究使用四個 benchmark：AgentProcessBench 250 條、ATBench 758 條、PlanRewardBench 441 個 pairwise comparisons，以及 AgentDojo 754 條符合 matched construction 條件的 instances。評估七個 verifier backbones：Gemini-3.7-Flash、Gemini-2.5-Flash、GPT-OSS-120B、GPT-OSS-20B、Gemma-4-31B、Gemma-4-26B-A4B 與 Llama-4-Maverick；所有模型 temperature=0，輸出映射至 benchmark canonical labels。四種 protocol 為 V-LLM direct single-pass、V-EVIDENCE 顯式列出並檢查可見證據、V-AGENTIC 可從同一 frozen trajectory 請求 provenance，以及 V-DELIBERATIVE 先使用 frozen V-EVIDENCE judgment，再以相同可見證據進行 audit。三類抽象分別隱藏 operation-level low-level events、delegated execution，或以 compacted history 取代早期紀錄；restoration 重新加入相應 provenance。VTFR 只在 native-view 正確判斷上計算，將 wrong verdict 與 no verdict 分開；另報告 native operational balanced accuracy、Restoration Recovery Rate（RRR）及 Restoration Degradation Rate（RDR）。研究也以 A25/A50/A75 測試抽象嚴重度，並比較 requery、lossy restoration 與 exact restoration。

## 關鍵結果

主要結果如下（數值為論文報告的 pooled、denominator-weighted 結果）：

| 比較項目 | Macro abstraction | Delegation | Compaction |
|---|---:|---:|---:|
| Overall VTFR | 31.0% | 30.9% | 20.3% |
| Overall RRR | 87.9% | 86.9% | 79.8% |
| Overall RDR | 5.3% | 5.4% | 4.9% |
| V-LLM VTFR | 16.4% | 17.3% | 14.1% |
| V-EVIDENCE VTFR | 34.5% | 34.0% | 18.7% |
| V-AGENTIC VTFR | 25.0% | 23.6% | 18.2% |
| V-DELIBERATIVE VTFR | 49.3% | 50.2% | 30.7% |
| Overall Wrong Verdict component | 13.4% | 13.2% | 12.2% |
| Overall No Verdict component | 17.7% | 17.7% | 8.0% |

其他結果：跨所有條件 restoration 整體修復85.5%的 transport failures，且僅使5.2%的原本抽象後仍正確判斷退化。V-LLM 的 macro failure 主要是 wrong verdict（15.8%），而 V-EVIDENCE 為 wrong verdict 10.6%、no verdict 24.0%；V-DELIBERATIVE 則為9.4%與39.9%。抽象嚴重度由 A25 提升至 A75 時，四個 model–benchmark 組合的 VTFR 端點皆上升；provenance recovery 依序為 Requery < LossyR < ExactR。

## 對我們的啟發
- [ ] 部署 agent verifier 時，除了 native-view accuracy，也應在 composed tools、sub-agent delegation 與 history compaction 等實際 observability boundary 上測量 VTFR。
- [ ] 評估 protocol 不應只比較 aggregate failure rate：direct verification 的低 VTFR可能伴隨較多錯誤 verdict，而 evidence-grounded 或 deliberative protocol 可能以 abstention、no verdict 換取較保守行為。
- [ ] 若系統允許，應保存可選擇且忠實的 execution provenance；論文結果顯示 exact restoration 的 recovery 高於 lossy restoration 與單純 requery，支持設計可恢復的 trace metadata。

## 限制與未來工作

研究只涵蓋 macro abstraction、delegation 與 history compaction，且使用由 frozen trajectories 建立的受控轉換，不一定代表 live execution 中自然產生的抽象。VTFR 只衡量 native-correct judgments 的保存，不等同整體 verifier competence。restoration 也假設原始 provenance 可重新提供；作者僅以有限的 lossy-fidelity ablation 檢驗此問題。未來可研究更多自然發生的 abstraction boundary、領域與 verifier 設計。
