# RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.13889)
- 📥 [PDF](https://arxiv.org/pdf/2610.13889v1)

## 摘要（中文翻譯）

隨著 AI agents 越來越依賴外部工具，準確的工具檢索對可靠行為至關重要。現有方法主要最佳化語義相關性，卻大多忽略工具在執行期間的可用性。為此，作者提出 RATED（Reliability-Aware Tool Retrieval via Execution Dynamics），結合穩健的 semantic matching 與動態 reliability adaptation。RATED 使用經 contrastive fine-tuning 的 frozen dual-encoder 進行語義匹配，並加入輕量級 contextual bandit，根據即時執行回饋重新排序候選工具。此設計可在不昂貴地重新訓練模型下，快速適應 runtime tool failures。作者提出 EcoAgent benchmark，包含 5,172 個真實世界工具及超過 210,000 組 query–tool pairs，用於離線檢索與動態可靠性評估。實驗顯示，在真實世界查詢上，RATED 相較 ToolLLM API retriever 的 MRR 相對提升 52.2%；在 30% failure rate 的嚴重 API outage 情境下，fault selection rate 從 86.2% 降至 2.9%，相較 encode-only inference 的額外延遲低於 1 ms。

## 問題背景

論文處理 AI agent 從大規模工具庫中選擇可正確執行工具的問題。既有 ToolLLM、ToolExpNet 等方法多將工具檢索視為靜態 semantic ranking，難以反映 API outage、錯誤或 timeout 等 runtime 狀態。即使部分方法使用 execution feedback，也主要更新 planner 或以批次方式學習，無法在單次執行失敗後即時調整候選工具排序，因此可能持續選擇不可用工具。

## 解決方案

作者提出 RATED，將工具選擇拆成 semantic perception 與 reliability-aware re-ranking 兩階段。第一階段以 DRAGON dual-encoder，利用 EcoAgent-Syn 的 synthetic query–tool pairs 進行 contrastive fine-tuning，取得 top-K 語義候選；第二階段保持 encoder frozen，使用以 query embedding 為 context 的 discounted LinUCB，從每次被選工具的 binary execution feedback 更新可靠性估計。最終分數融合 semantic relevance、bandit score 與 metadata-based static prior。核心創新是將語義匹配與執行可靠性解耦，使系統能以低延遲、無需重新訓練語義模型的方式適應非平穩工具故障。

## 核心貢獻
1. 提出 RATED reliability-aware tool retrieval framework，以 frozen dual-encoder 結合 discounted LinUCB，根據逐次 execution feedback 動態重新排序工具。
2. 建立 EcoAgent benchmark，收集 5,172 個真實世界工具，並提供 EcoAgent-Syn 與 EcoAgent-Real 兩類資料及 failure injection 評估協定。
3. 實驗證明 RATED 在工具故障情境下可將 fault selection rate 降至 2.5–2.9%，同時只增加 0.172 ms 的平均推論延遲。

## 技術方法

EcoAgent 收集 LangChain、CrewAI、LlamaIndex 與 n8n 的 5,172 個工具，將功能描述、名稱、endpoint 與 authentication 欄位正規化。每個工具依 name–description consistency、source credibility 與 documentation quality 計算 0–1 的 metadata reliability score；分數至少 0.8 的工具共有 2,940 個。EcoAgent-Syn 以 Gemma-3-1b 為每個工具生成 10–20 個 5–120 字的任務查詢，移除 Jaccard similarity 超過 0.7 的近重複項，並加入 SBERT hard negatives 與 random negatives，共有 69,501 個 unique synthetic queries、70,122 個 positive pairs 與 140,244 個 negative pairs。EcoAgent-Real 由 ToolBench 查詢建立，先以 GTE-Large 取得 top-5 候選，再由 Gemma-3-1b 驗證，保留 functional match score 至少 0.85 的配對，經人工抽樣 200 個查詢審查後，得到 94% 一致率；最終包含 6,379 個查詢與 9,946 個 verified pairs。模型以 DRAGON query/tool encoder 的 normalized CLS embedding 計算 dot-product semantic score，透過 in-batch InfoNCE fine-tuning。部署時先取 semantic top-K（K=10），再以每個工具獨立的 discounted LinUCB 重排；其矩陣與向量以 γ=0.95 衰減，根據成功或失敗的 binary reward 更新，並以 α=0.1 控制 exploration。最終分數權重為 semantic 0.75、bandit 0.15、static prior 0.10。離線指標包括 MRR、Recall@1、Recall@5；動態評估以 10,000 次 sequential selections、20% 或 30% persistent failure injection，計算 Post-Fail SR、fault selection rate（FSR）及 adaptation steps。

## 關鍵結果

主要結果如下（數據均來自論文）：

| 實驗 | 方法 | MRR | Recall@1 | Recall@5 |
|---|---|---:|---:|---:|
| EcoAgent-Real | ToolLLM API Retriever | 0.406 | 0.222 | 0.409 |
| EcoAgent-Real | RATED (Full) | 0.618 | 0.516 | 0.740 |
| EcoAgent-Real | OpenAI Ada-002 | 0.670 | 0.430 | 0.750 |
| EcoAgent-Real | SPLADE-v3 | 0.626 | 0.491 | 0.789 |
| EcoAgent-Syn | RATED (Full) | 0.845 | 0.804 | 0.893 |

RATED (Full) 在 EcoAgent-Real 相較 ToolLLM API Retriever 的 MRR 相對提升為 52.2%。

| Failure rate | 方法 | Post-Fail SR (%) | FSR (%) | Adaptation steps |
|---:|---|---:|---:|---:|
| 20% | ToolLLM API Retriever | 17.4 | 79.6 | Failed |
| 20% | RATED (Full) | 83.4 | 2.5 | 1,603 |
| 30% | ToolLLM API Retriever | 10.5 | 86.2 | Failed |
| 30% | RATED (Full) | 82.1 | 2.9 | 0 |

在 30% failure rate 下，RATED 將 ToolLLM 的 FSR 從 86.2% 降至 2.9%。延遲方面，DRAGON encode-only 平均為 3.223 ms；RATED (Full) 平均為 3.395 ms、P95 為 4.391 ms，額外延遲為 0.172 ms。論文未報告真實線上 agent runtime 的實地結果。

## 對我們的啟發
- [ ] 工具檢索系統不應只以語義相關性評估；在 agent 部署情境中，應將 execution success、timeout 與 API availability 納入排序或決策回饋。
- [ ] 將 semantic retriever 固定、把可靠性估計放在輕量 online re-ranker，可在不重新訓練主模型的情況下快速處理工具狀態變化，適合對延遲敏感的互動式 agent loop。
- [ ] 評估工具選擇時可同時報告離線 ranking 指標與 sequential failure recovery 指標；論文結果顯示，高離線排名表現本身不保證故障期間的穩健工具選擇。

## 限制與未來工作

論文指出仍需評估新加入工具的 cold-start 路徑，並在真實線上 agent runtime 驗證 RATED。EcoAgent-Real 的標註部分依賴 Gemma-3-1b，人工審查僅涵蓋 200 個查詢；動態結果則來自固定 failure injection，而非實際 API outage。論文未報告更多真實部署結果。
