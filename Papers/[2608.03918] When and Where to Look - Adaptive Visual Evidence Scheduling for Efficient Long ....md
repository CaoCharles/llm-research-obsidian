# When and Where to Look: Adaptive Visual Evidence Scheduling for Efficient Long Video Understanding

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.03918)
- 📥 [PDF](https://arxiv.org/pdf/2608.03918v1)

## 摘要（中文翻譯）

高效率的長影片理解需要 Vision-Language Models（VLMs）在稀疏視覺證據中挑選少量影格進行推理。既有 relevance-based 方法通常採用靜態的一次性選擇、固定影格預算與候選池；agent-based scheduler 雖具適應性，卻需多輪推理與互動式搜尋，成本高昂。本文提出免訓練的 EcoFrame，用低額外成本進行 query-adaptive visual evidence scheduling。其 entropy-gated budget scheduling 根據輸出不確定性決定是否增加影格預算；attention-guided candidate proposal 則將 frame-level attention 轉為時間先驗，在資訊集中區域進行密集局部搜尋，注意力分散時維持全域覆蓋。在 Video-MME、LongVideoBench 與 MLVU 上，EcoFrame 於多個 VLM backbone 展現更佳的準確率—效率折衷。Qwen2.5-VL 上平均準確率為 64.4，高於 BOLT 的 63.5，且相較 AKS 與 BOLT 提供 1.85 倍加速；相較 agent-based A.I.R.，準確率相近而推理速度最高提升 13.5 倍。

## 問題背景

長影片包含遠超 VLM context window 的影格，必須在有限預算下選取足夠的視覺證據。Uniform sampling 忽略問題需求；靜態 relevance-based 方法固定候選池與影格數，可能漏掉局部事件或浪費計算；agent-based 方法雖能迭代搜尋，卻依賴多輪 VLM 推理與驗證，延遲和成本高。核心問題是如何在不採用昂貴 agent 推理下，適應每個 query 所需的證據量與時間位置。

## 解決方案

作者提出 EcoFrame，一個免訓練、低額外成本的 query-adaptive visual evidence scheduling 框架。它把 VLM 一次低預算回答所產生的兩種內部訊號轉為排程決策：以 output entropy 判斷目前證據是否足夠，低於輪次 threshold 即提前停止，否則逐步增加 frame budget；以 frame-level attention 推斷值得搜尋的時間區域，注意力集中時進行局部加密，分散時維持全域探索。新候選再透過 query-frame relevance 與 temporal diversity 重新選取，使證據搜尋逐輪由粗到細，兼顧準確率、覆蓋率與延遲。

## 核心貢獻
1. 提出免訓練的 EcoFrame，利用目標 VLM 推理期間產生的 output entropy 與 frame-level attention，取代昂貴的額外 agent 推理。
2. 提出 entropy-gated budget scheduling，以逐輪放寬的 entropy threshold 決定提前停止或以幾何序列增加影格預算。
3. 提出 attention-guided candidate proposal 與 marginal-utility frame reselection，結合注意力先驗、query-frame relevance 與時間多樣性，實現由粗到細的候選搜尋。

## 技術方法

EcoFrame 以目標 VLM 作為回答模型，另使用 CLIP-ViT-L/14 計算 query-frame relevance；論文未提出新的 VLM backbone 或訓練階段。給定影片與問題，先以均勻取樣建立初始候選池 P1，設定影格預算 B1=4，並依 relevance 與時間覆蓋選出輸入集合 S1。每一輪將 St 輸入 VLM，取得答案、平均 token output entropy et，以及選定深層 attention layer 與 head 的 visual-token attention，再將 attention 平均到 frame level。若 et 小於輪次 threshold τt，立即輸出答案；否則令下一輪預算為 min(ceil(αBt), Bmax)，實驗採 α=2、Bmax=32。候選擴張時，以相鄰輸入影格中點形成 temporal cells，將 frame attention 傳播為時間先驗；候選分數同時考慮注意力先驗與距離既有候選池的多樣性，逐次加入最高分位置，再計算新影格的 CLIP relevance。重新選擇輸入影格時，以 normalized relevance 的 λrel 次方乘上與目前集合的距離，反覆選取至達到新預算。實驗使用 Video-MME、LongVideoBench、MLVU，並補充 ActivityNet-QA；評估平均 accuracy、端到端 GPU latency 與最終平均影格數，模型包括 LLaVA-OneVision-7B、Qwen2.5-VL-7B、InternVL-3-8B。

## 關鍵結果

主要結果如下（準確率為百分比；延遲為秒；Speedup 以表中靜態 relevance baseline 為基準）：

| VLM | 方法 | 平均影格數 | 平均準確率 | 平均延遲 | Speedup |
|---|---|---:|---:|---:|---:|
| LLaVA-OneVision-7B | BOLT | 32 | 62.2 | 3.88 | 1.00× |
| LLaVA-OneVision-7B | EcoFrame | 19.1 | 63.5 | 2.17 | 1.79× |
| Qwen2.5-VL-7B | BOLT | 32 | 63.5 | 3.22 | 1.00× |
| Qwen2.5-VL-7B | EcoFrame | 21.3 | 64.4 | 1.74 | 1.85× |
| InternVL-3-8B | BOLT | 32 | 66.9 | 3.88 | 1.00× |
| InternVL-3-8B | EcoFrame | 17.4 | 67.8 | 2.05 | 1.89× |

在與 A.I.R. 比較時，論文指出 EcoFrame 維持相近準確率，推理速度最高提升 13.5 倍；各模型的 A.I.R. 平均延遲分別為 29.20、22.10 與 27.12 秒。消融結果顯示，LLaVA-OneVision-7B 上 Video-MME／LongVideoBench 的完整 EcoFrame 準確率為 61.0／59.9；移除 attention-guided proposal 後為 60.7／59.2，relevance-only reselection 後為 60.6／58.7。

## 對我們的啟發
- [ ] 若部署情境重視延遲，可從低影格預算開始，使用模型輸出 entropy 作為是否追加視覺證據的門控訊號；論文結果顯示此作法能在固定最大預算下減少平均計算。
- [ ] 候選搜尋不必在整部影片建立密集候選池：可依目前影格注意力在局部區域加密搜尋，同時以距離項維持全域覆蓋，降低漏掉不同時間事件的風險。
- [ ] 實務部署應依模型、影片領域與成本需求校準 entropy threshold 與最大預算；論文也顯示更嚴格 threshold 通常提高準確率但增加延遲，沒有單一普適設定。

## 限制與未來工作

作者指出 entropy threshold 與最大影格預算仍是全域設定，可能不適合所有模型、影片領域與部署成本，未來可進行輕量校準或 cost-aware scheduling。對極短的 needle-in-a-haystack 事件，即使保留全域覆蓋，有限候選影格仍可能遺漏；未來可加入事件邊界或 motion saliency。
