# When VLMs Destroy What They Know: Spatial Representations Fall Below Lexical Priors

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.13910)
- 📥 [PDF](https://arxiv.org/pdf/2610.13910v1)

## 摘要（中文翻譯）

Vision-Language Models（VLMs）日益被用於分析與推理影像，但其內部表徵是否忠實編碼推理所需的結構化關係，仍不清楚。本文提出 EICS（Evaluation-Invariant Concept Stability），用於測試表徵在受控單一概念介入下，是否以一致方式編碼概念；並提出 CASP-VL（Causally controlled Spatial Perturbations for Vision-Language models），這是一個源自 Visual Genome scene graph 的因果控制空間擾動 benchmark。多種 VLM 架構的結果顯示，即使模型在 compositional benchmark 上明顯高於隨機機率，其空間關係表徵仍顯著不如 lexical information。進一步分析發現，關係可在 predicate 自身 token 中被辨識，卻在句子聚合為全域表徵時遺失，不論採用 [EOS] token 或 mean pooling。這揭示一種 output-based evaluation 無法發現的系統性失敗：VLM 未能在下游使用的表徵中保留輸入本身已提供的 relational information。

## 問題背景

現有 compositionality benchmark 多以模型輸出或影像—文字偏好評分，無法判斷模型是否在內部表徵中真正保留空間關係；模型可能依賴 lexical priors，卻仍答對問題。既有 hard negative 與 word-order 測試能揭露行為缺陷，但未回答概念是否被編碼、在哪一層遺失，以及 contextual encoding 是否反而丟失輸入中的關係資訊。

## 解決方案

作者提出 CASP-VL 與 EICS 的互補框架。CASP-VL 從 Visual Genome scene graph 建立 controlled triplets，只改變一個 attribute 或 spatial relation，並以固定模板產生原始與擾動 caption。EICS 先只用原始 caption 訓練 linear probe，再在擾動 caption 上檢查 probe 是否預測新的概念標籤，並扣除 chance。作者同時以 Bag-of-Words（BoW）作為 lexical baseline，逐層比較 VLM 是否保留超越或至少不低於詞面資訊的概念表徵，並以 predicate-token、句子 pooling、argument swap 與跨架構分析定位資訊遺失位置。

## 核心貢獻
1. 提出 CASP-VL，從 Visual Genome scene graph 建立受控的單一概念 attribute 與 spatial relation counterfactual perturbations，並以 image-grouped split 減少影像洩漏。
2. 提出 EICS，透過只在原始 caption 上訓練的 probe，評估表徵是否能在介入後穩定解碼新概念，並以 BoW 分離 lexical information 與 contextual representation 的差異。
3. 以多層、多架構、不同 pooling 與 caption style 實驗指出：空間關係可在 predicate token 局部辨識，卻在 [EOS] 或 mean-pooled 全域表徵中大量遺失；此現象不會被傳統 output-based compositional benchmark 充分揭露。

## 技術方法

主要模型為 CLIP ViT-B/32，並比較 CLIP ViT-L/14、ViT-L/14@336、SigLIP-B/16 與 LLaVA-1.5-7B。CASP-VL 包含 2,400 個 color triplets 與 1,491 個 spatial triplets，另有 4,200 個跨 relation taxonomy triplets。每個項目由 Visual Genome scene graph 出發，改動一個 attribute 或 relation，再以「A [attr] [subj] is [pred] a [attr] [obj].」產生 caption；資料依 image 分組，以 80/20 切分，避免同一影像跨集合。對每層 hidden state 取 [EOS] 表徵，使用原始 caption 訓練具 L2 regularization 的 logistic-regression probe，測試對應 perturbed caption 是否預測新 label。EICS 定義為新標籤預測正確率減去 1/|C| chance；以 1,000 次 bootstrap 建立 95% 信賴區間，並以 normalized word-count BoW 作基準。另比較 mean pooling 與 predicate-token pooling，測試 subject/object 交換的 argument-order sensitivity，分析不同 caption style、MLP probe、模型寬度及 image-text grounding。

## 關鍵結果

主要結果如下；EICS 為「新標籤預測率減 chance」，數值越高表示越能穩定追蹤介入概念。

| 模型／表徵 | Color EICS | Spatial EICS | Spatial BoW 對照 |
|---|---:|---:|---:|
| CLIP ViT-B/32，[EOS]，L12 | +0.070（主文五 split 平均為 +0.070±0.012） | +0.070（split 42 為 +0.066） | +0.372（split 42 為 +0.359） |
| CLIP ViT-B/32，L12，主文五 split | +0.312±0.019 | +0.070±0.012 | +0.372±0.022 |
| CLIP ViT-L/14，L12 | +0.303 | +0.053 | +0.359 |
| CLIP ViT-L/14@336，L12 | +0.298 | +0.045 | +0.359 |
| SigLIP-B/16，最終層 | +0.339 | +0.038 | +0.359 |
| LLaVA-1.5-7B，最後 prompt token | +0.143 | +0.115 | +0.305（同 split） |
| CLIP B/32，predicate-token pooling，L12 | +0.917 | +0.930 | — |
| CLIP B/32，mean pooling，L12 | +0.309 | +0.093 | — |

CLIP ViT-B/32 的原始結果顯示，color 約保留 BoW 的 94%，spatial 僅約 19%；spatial flip 後 [EOS] cosine similarity 為 0.992，color flip 為 0.943。argument swap 的 [EOS] probe 準確率為 0.574，BoW 為 0.500。SugarCrepe relation accuracy 為 CLIP 69.3%、SigLIP 70.6%，但其 spatial EICS 分別只有 +0.066 與 +0.038，顯示輸出 benchmark 與表徵忠實度不一致。單句 caption 可將 CLIP spatial EICS 提升至 +0.487，但仍只達 BoW 的 52%。

## 對我們的啟發
- [ ] 實務上的 VLM 評測不應只看最終答案或 image-text ranking；可加入 controlled concept intervention、layer-wise probing 與 lexical baseline，檢查下游表徵是否仍保留關係資訊。
- [ ] 若系統需要空間推理，僅提高模型規模、改變 contrastive objective 或增加一般性的 pooling 未必有效；論文結果支持評估 argument order、subject-predicate-object 結構及明確 spatial supervision。
- [ ] 部署 VLM 時應區分「模型能辨識 relation token」與「模型在全域表徵中保留 relation」；predicate-token 的高 EICS 不能代表下游 embedding 或分類器具有可靠的 relational faithfulness。

## 限制與未來工作

研究主要探測 text encoder，而非 image encoder 或 joint vision-language representation；影像未隨 caption intervention 改變，因此測量的是對反事實描述的文字表徵反應。模型範圍仍有限，未涵蓋更大型或具明確空間監督的 VLM。CASP-VL 也使用最多五句的 scene-graph caption，雖已測試單句、自然描述與 LLM paraphrase，pooling 與 caption 分布仍可能影響絕對分數。EICS 主要依賴 logistic probe，MLP 結果雖未達 BoW，仍不能完全排除其他非線性編碼。
