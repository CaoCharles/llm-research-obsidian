# Large Language Models (LLMs) for Telecom Root Cause Analysis (RCA): A Structured Reasoning Framework for Evidence-Grounded Diagnosis

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.02805)
- 📥 [PDF](https://arxiv.org/pdf/2609.02805v1)

## 摘要（中文翻譯）

根因分析（RCA）是電信網路營運的關鍵任務，但現代 5G 與新興 6G 網路具有跨無線、傳輸與核心層的複雜依賴，使效能劣化診斷相當困難。大型語言模型（LLM）具備推理與知識整合潛力，但直接使用 vanilla LLM 進行電信 RCA，容易產生 hallucination、不穩定推理，以及與結構化網路證據對齊不佳的問題。本文回顧電信 RCA 從 rule-based、machine learning 到 LLM-enabled 方法的演進，並討論 structured reasoning、retrieval-augmented knowledge grounding、agentic orchestration 與 verifiable reasoning 等範式。在此基礎上，作者提出結構化推理框架，先將異質 network telemetry 組織成 canonical contexts，再於診斷時強制執行 decision-path reasoning，最後產生 evidence-grounded explanations。TeleLogs 與 TelecomTS 兩個 5G RCA 資料集的實驗顯示，該方法相較基線能提升診斷準確度與決策一致性。

## 問題背景

論文聚焦於 5G／6G 電信網路的 RCA。傳統 rule-based 方法依賴人工維護的告警模式與 KPI 閾值，難以隨場景擴展；ML 方法主要學習 telemetry 的統計模式，通常輸出標籤而缺乏可追溯診斷路徑，且面對未見故障或分布變化時受限。Vanilla LLM 雖能整合跨層資料並產生解釋，卻可能依賴表面相關性、產生 hallucination，並對相似證據採取不一致的推理流程。

## 解決方案

作者提出 SEKA-FT（Structured Evidence- and Knowledge-Aligned Fine-Tuning），將 RCA 從 input-to-label prediction 重新表述為 evidence-to-path-to-decision 的結構化推理問題。框架包含三項核心設計：將 user-plane KPI、control-plane events、topology relationships 與 configuration parameters 正規化為 canonical context blocks；以 CoT-enabled decision path 執行分階段診斷檢查，逐步排除缺乏證據支持的假設；將 evidence- and knowledge-anchored explanations 納入 supervision target，使最終 root-cause label、診斷路徑與可觀測指標共同學習。其創新在於以統一 fine-tuning 目標耦合結構化證據、中間檢查、假設精煉、最終決策與可追溯解釋，而非只監督分類標籤。

## 核心貢獻
1. 系統回顧電信 RCA 從 rule-based、ML 到 LLM-enabled 方法的演進，並整理 CoT、RAG、agentic orchestration 與 RLVR 等增強可靠性的技術範式。
2. 提出 SEKA-FT，將 canonical context、CoT-enabled decision path、evidence-grounded explanation 與 root-cause decision 整合於 evidence-to-path-to-decision 的 fine-tuning supervision 結構。
3. 在 TeleLogs 與 TelecomTS 上進行跨資料集驗證；SEKA-FT 分別取得 0.942／0.937 與 0.647／0.615 的 Accuracy／Macro-F1，並顯著優於所比較基線。

## 技術方法

SEKA-FT 的輸入先經 canonical context structuring，將異質資料整理為 Bottleneck Snapshot、UE Global State、Trajectory-Level Events 與 Serving Cell Engineering Parameters 等固定語意區塊，並保留 serving-cell metrics、neighbor-cell relations、mobility indicators 等欄位，移除非必要雜訊。接著模型依決策路徑產生中間檢查，例如 Maximum UE speed 是否超過 40 km/h、average Scheduled RBs 是否低於 160、handover count 是否顯示不穩定，以及 UE-to-serving-cell distance 是否涉及 overshooting；正向檢查可直接支持相應原因，負向檢查則剪枝候選。第二階段依檢查結果與電信 domain knowledge 進行 hypothesis refinement，最後輸出 root-cause label 與 evidence-grounded explanation。訓練採 token-level causal language-modeling loss，mask prompt tokens，使用 Qwen2.5-1.5B-Instruct，並以 LoRA 微調最後四個 Transformer blocks；設定包括 learning rate 1e-5、12 epochs、batch size 2、最大序列長度 2048、bf16 與 AdamW。比較方法包括 ICL、LSTM、Vanilla SFT、SFT + Structured Input、SFT + Explanation，另測試 Qwen2.5-7B-Instruct 與 Qwen3-32B。評估指標為 Accuracy、Macro-F1 與 decision-path consistency；結果取十次不同 random seeds 的平均及 95% confidence interval，並使用 McNemar’s test、paired permutation test 與 Holm–Bonferroni 校正。

## 關鍵結果

論文報告的主要結果如下；數值為平均值 ± 95% confidence interval：

| 方法 | TeleLogs Accuracy | TeleLogs Macro-F1 | TelecomTS Accuracy | TelecomTS Macro-F1 |
|---|---:|---:|---:|---:|
| ICL 1.5B | 0.021 ± 0.004 | 0.018 ± 0.003 | 0.033 ± 0.006 | 0.031 ± 0.005 |
| ICL 7B | 0.053 ± 0.006 | 0.043 ± 0.005 | 0.041 ± 0.005 | 0.028 ± 0.003 |
| ICL 32B | 0.126 ± 0.010 | 0.109 ± 0.009 | 0.061 ± 0.005 | 0.053 ± 0.004 |
| LSTM | 0.132 ± 0.012 | 0.090 ± 0.011 | 0.115 ± 0.010 | 0.080 ± 0.010 |
| Vanilla SFT | 0.007 ± 0.003 | 0.013 ± 0.004 | 0.050 ± 0.021 | 0.052 ± 0.016 |
| SFT + Structured Input | 0.256 ± 0.018 | 0.234 ± 0.016 | 0.132 ± 0.009 | 0.138 ± 0.009 |
| SFT + Explanation | 0.030 ± 0.005 | 0.020 ± 0.004 | 0.047 ± 0.008 | 0.041 ± 0.008 |
| **SEKA-FT** | **0.942 ± 0.006** | **0.937 ± 0.007** | **0.647 ± 0.004** | **0.615 ± 0.005** |

SEKA-FT 在兩個資料集相較 SFT + Structured Input 的 Accuracy 與 Macro-F1 改善均達統計顯著，論文報告 p < 0.001。ICL 中模型由 1.5B 擴展至 32B 仍維持低絕對效能。TeleLogs 上，SEKA-FT 的四項代表性 decision checks 接近完美一致；但論文未提供其逐項具體數字。

## 對我們的啟發
- [ ] 實務部署不應只把原始 KPI、logs 與工程參數直接串接至 LLM；先建立固定語意欄位與 canonical context，有助於降低輸入表徵不一致。
- [ ] RCA 評測應同時檢查最終 root-cause label 與中間 decision path，並要求每個診斷結論連結到可觀測指標，以提升可追溯性並辨識 hallucination。
- [ ] 單純增加模型規模或加入 explanation supervision 未必足夠；本文結果顯示，結構化 evidence alignment 與分階段假設剪枝對此任務更關鍵。

## 限制與未來工作

評估主要涵蓋 TeleLogs 與 TelecomTS 的 5G RAN／observability 情境；論文尚未提供 core、transport、多域故障、真實營運商事件或未見故障的結果。SEKA-FT 的解釋由標籤、deterministic checks 與 domain-rule templates 自動建構，解釋品質及與真實因果的獨立驗證仍未充分報告。
