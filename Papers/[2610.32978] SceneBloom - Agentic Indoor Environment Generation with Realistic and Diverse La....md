# SceneBloom: Agentic Indoor Environment Generation with Realistic and Diverse Layouts for Embodied Learning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.32978)
- 📥 [PDF](https://arxiv.org/pdf/2610.32978v1)

## 摘要（中文翻譯）

訓練具備泛化能力的 embodied agents，需要真實、多樣且可直接用於模擬的室內環境。Language-guided 方法能支援語義規劃與物件層級推理，但精確空間定位仍然困難；visual generative models 雖具備合理家具配置的豐富先驗，其輸出仍需幾何推理才能轉換為物理有效的 3D scenes。本文提出 SceneBloom，一個結合 visual layout sampling 與 contract-guided 3D compilation 的 agentic framework。階層式 sampler 使用 diffusion priors，在 functional zones 內生成家具配置；compiler 則從各提案擷取關係，指導幾何 fitting 與局部姿態修正。在五種房間類型中，SceneBloom 的視覺品質與物理穩定性均優於比較方法，且沒有偵測到 mesh collisions 或 out-of-bounds objects。其布局分布也最接近真實房間。以這些場景訓練的 object navigation policies，在保留的真實掃描環境中表現優於使用相同數量真實掃描訓練的政策。

## 問題背景

論文要解決的是如何自動生成兼具真實性、多樣性、空間合理性與 simulation-ready 特性的室內 3D 環境，以支援 embodied learning。既有 language-guided 方法擅長語義規劃，卻常難以精確落實物件位置與朝向；visual generation 雖能產生自然的家具關係，但從影像 lifting 至 3D 時會產生深度、尺度、姿態誤差，導致碰撞、越界或功能關係被破壞。逐物件迭代修正也會增加成本並累積不一致。

## 解決方案

SceneBloom 將生成拆成 hierarchical visual sampling 與 contract-guided 3D compilation。首先由 vision-language model 根據房間描述與 retrieved exemplars 規劃 functional zones、家具清單、anchor、牆面與區域提示；再由具 asset-specific LoRA 的 diffusion model，對每個 zone 聯合生成家具布局影像，透過不同 seed 取得多樣配置。接著使用 3D perception 將影像 lifting 為物件幾何，並由 VLM 擷取 facing、alignment、proximity 等 relation contracts。compiler 先在 zone 內、再於房間層級進行幾何 fitting，最後以局部旋轉或平移恢復高信心關係，兼顧物理有效性與功能布局。

## 核心貢獻
1. 提出 SceneBloom agentic indoor-environment generation framework，以 diffusion-based visual layout sampling 結合 contract-guided 3D compilation，將可保留的質性關係與需修復的數值姿態分離。
2. 使用 asset-specific LoRA 使 visual proposals 描繪實際要放入場景的 catalog assets，並透過 hierarchical fitting 與 relational refinement 同時改善布局真實性、物理穩定性與功能一致性。
3. 在五類房間及 object navigation 實驗中證明，生成場景具有較低的 real-layout distribution discrepancy，且能以相同或較少的訓練資源改善真實掃描環境中的導航轉移與 unseen-goal 泛化。

## 技術方法

輸入房間描述後，VLM 使用最多三個 retrieved indoor floor-plan exemplars，輸出無重疊且覆蓋房間地面的軸對齊 functional zones；每個 zone 定義家具類別與數量、anchor、相鄰牆面及 diffusion prompt。FLUX.1-dev 結合 FreeFuse 與每個 catalog asset 的 LoRA，依公式 Ij=G(qj,Λj;εj) 生成各區家具提案；改變 diffusion seed 可產生不同布局。Grounding DINO 提供 2D boxes，OVMono3D-LIFT、Depth Pro 與單眼相機內參估計物件的 3D 尺寸、位置與朝向。VLM 從原始提案擷取最多十項關係，僅使用 face、alignment、proximity、beside、back to 等規定關係，高信心值 γ≥0.75 者進入編譯。幾何 compiler 先固定 anchor 並消除 zone 內 footprint overlaps，再依 zone envelope 與規劃順序組合整個房間；relational refinement 透過關係特定的局部旋轉、平移與邊界／footprint 可行性檢查修復違反關係，最後加入牆面與家具表面物件。場景評估包含 object/scene mesh collision、out-of-bounds、REST3D stable-object rate、GPT-4o 評分的 realism、functionality、coherence、completeness，以及相對 Matterport3D 和 Scan2CAD 的 LDD。導航實驗在 Habitat 中比較從零訓練與 pretrained policy fine-tuning，並以真實 HM3D 掃描環境的 SR、SPL 評估轉移。

## 關鍵結果

主要結果如下（作者報告）：

| 實驗面向 | SceneBloom | 主要比較結果 |
|---|---:|---|
| Scene-level collision rate | 0.0% | Holodeck 78.0%、SceneWeaver 47.2%、SAGE 12.7% |
| Out-of-bounds objects | 0.000/scene | Holodeck 0.160、SceneWeaver 0.0004、SAGE 0.020 |
| Stable-object rate | 75.3% | Holodeck 35.1%、SceneWeaver 45.3%、SAGE 45.1% |
| Visual realism / functionality / coherence / completeness | 6.18 / 6.29 / 4.76 / 6.74 | 四項均為比較方法最高；GPT-4o 0–10 分制 |
| LDD against Matterport3D / Scan2CAD | 0.1759 / 0.1340 | 兩個真實房間參考集均為最低 |
| Generation time | 2.7 分鐘/布局 | Holodeck 21.6、SceneWeaver 313.0、SAGE 73.6 分鐘 |
| Navigation from scratch, 120 houses, SR | 35.63% | Real scans 32.87%、Randomized 33.50%、Agent-planned 34.40% |
| Fine-tuning on real HM3D environments, SR | 48.57% | Real-scan continuation 47.57%、Randomized 48.15%、Agent-planned 47.99% |
| Fine-tuning with occluders, SR | 49.50% | Randomized with occluders 48.34%、pretrained 48.26% |
| Visual proposal ablation: contract violations | 4.25% | Visual proposal without contract 37.45%；textual proposal with contract 10.75% |

在 50 個共享 inventory、asset 與尺寸的 ablation scenes 中，visual proposal 加 contract 保持 0% collision，並將 coherence 從 4.31 提升至 4.65、realism 從 5.66 提升至 5.83。

## 對我們的啟發
- [ ] 對 embodied-agent 訓練資料而言，物件的聯合布局與可通行空間可能比單純增加場景數量更重要；論文中 Randomized 控制使用相同房間與家具，但因破壞布局組織而表現較差。
- [ ] 可將生成流程設計為「關係抽取—幾何修復」兩階段：先保存 facing、alignment 等功能語義，再以局部幾何操作處理碰撞與越界，避免直接以坐標約束重新生成而破壞功能關係。
- [ ] 場景難度應可控制且嵌入合理布局；加入 occluder zone 後，SceneBloom 的真實環境 SR 從 48.57% 提升至 49.50%，顯示任務相關變化需與一致的空間組織共同設計。

## 限制與未來工作

論文實驗主要涵蓋五種室內房間類型，導航評估聚焦 object-goal navigation，未報告 manipulation 或真實機器人上的直接驗證。場景品質部分依賴 GPT-4o 評分與多個 VLM、diffusion、3D perception 模組，論文未提供完整的人類評測結果。生成時間雖低於部分 agentic baseline，但仍為每布局 2.7 分鐘。
