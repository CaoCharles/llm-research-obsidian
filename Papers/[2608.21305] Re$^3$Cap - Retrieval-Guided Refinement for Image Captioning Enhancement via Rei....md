# Re$^3$Cap: Retrieval-Guided Refinement for Image Captioning Enhancement via Reinforcement Learning

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.21305)
- 📥 [PDF](https://arxiv.org/pdf/2608.21305v1)

## 摘要（中文翻譯）

Reinforcement Learning（RL）已在 image captioning 中帶來顯著提升，但仍難以促使 Large Vision-Language Models（LVLMs）探索新的推理策略，因而造成 RL 與 Supervised Fine-Tuning（SFT）之間的效能差距。本文主張，multi-modal retrieval 可作為有效的 caption refinement 推理訊號，並提出 Retrieval-Guided Refinement for Image Captioning（Re3Cap），在不需要額外人工標註的情況下改善影像描述。Re3Cap 由 Caption Refinement Suggester（CRS）與 Caption Quality Assessor（CQA）組成，用以辨識 caption 中的 hallucinations 與 omissions，產生更準確且詳細的描述。實驗顯示，Re3Cap 在多種 LVLM、資料集與 reward functions 上優於既有方法，甚至超越 SFT；在 COCO-LN500 的 relation reasoning 上，平均較 GRPO 提升 8.64%。

## 問題背景

現有 LVLM image captioning 容易產生 hallucinations，並遺漏細粒度視覺細節。傳統 RL 多以 CLIP、keyword 或 image-caption similarity 作為 reward，容易受 VLM compositional reasoning 限制而 reward hacking；且 RL 往往只在 base model 已產生的候選中選擇高 reward caption，缺乏新的推理策略與探索，因此表現可能落後 SFT。本文要解決的是：如何在不增加額外標註的情況下，擴展 caption 候選空間並同時減少錯誤與遺漏。

## 解決方案

作者提出 Re3Cap，一個以 retrieval-guided refinement 為核心的 RL 框架。對每張影像先產生 initial captions，再以影像與 caption 分別查詢多模態資料庫，分析兩組 retrieval descriptions 的語意重疊與差異。CRS 從視覺相似影像的共同描述中找出應保留或加入的關鍵內容；CQA 比較影像檢索與文字檢索結果，辨識 caption hallucinations 與 omissions。這些 guidance 被注入 refinement prompt，使 LVLM 產生更準確、詳細且可能超出原本輸出分布的 refined captions，並以其 reward 進行 RL。訓練時移除 initial caption 與 guidance，使推論時僅需影像輸入。

## 核心貢獻
1. 提出 retrieval-based reasoning strategy，利用影像檢索與 caption 檢索結果的語意差異，在不需額外標註下指出 caption 的 hallucinations 與 omissions。
2. 提出由 Caption Refinement Suggester（CRS）與 Caption Quality Assessor（CQA）組成的 Re3Cap RL 框架，將檢索推理訊號注入 caption refinement。
3. 在多種 LVLM、兩個評測基準及多種 reward functions 上驗證方法，並透過 max@k、元件消融、編碼器與超參數穩健性實驗分析其效果。

## 技術方法

Re3Cap 使用資料集 D 中的 image-text pairs 建立檢索語料。給定影像 v，先以 OpenCLIP ViT-H/14 進行 image retrieval，取 top-K 結果；將其文字切成句子，以 SBERT（MPNet-base）計算句子相似度，建立 graph，並以 k-core 保留密集且一致的語意節點，形成 CRS 訊號。給定 LVLM 產生的 caption c，再以文字檢索取得 top-K 結果，採相同方式形成 caption graph。接著在影像與 caption retrieval 結果間建立 bipartite graph 並計算 k-core；共同內容表示正確性，caption k-core 減去共同內容表示 hallucinations，image k-core 減去共同內容表示 omissions。訓練時，每張影像取 M=5 個 initial captions，產生對應 guidance 與 refined captions，再用 reward function 評分並計算 group advantage。作者採用 decoupled PPO，以 behavior policy 修正由 refinement prompt 造成的 off-policy 分布差異，同時加入 proximal policy、clipping 與 reference-model KL penalty。訓練資料為 RefinedCaps 的 6.5K 張影像；檢索庫由 RefinedCaps 與 DenseFusion-1M 擴充而成，且與評測基準不重疊。設定 K=3、k=2、τ=0.7，訓練兩個 epochs。評估使用 COCO-LN500 與 DOCCI500，指標包括 objects F1、attributes F1，以及以 Qwen3 VQA accuracy 測量的 relations QA。

## 關鍵結果

主要作者實驗結果如下；表中數值為論文報告的分數。

| 實驗設定 | COCO-LN500 Objects F1 | Attributes F1 | Relations QA | DOCCI500 Objects F1 | Attributes F1 | Relations QA |
|---|---:|---:|---:|---:|---:|---:|
| LLaVA-1.5-7B + CLIP GRPO | 66.66 | 53.15 | 22.58 | 61.77 | 53.62 | 18.42 |
| LLaVA-1.5-7B + CLIP Re3Cap | 72.03 | 54.73 | 30.38 | 68.51 | 57.68 | 23.86 |
| Qwen2-VL-7B + SC GRPO | 76.80 | 57.49 | 30.46 | 72.49 | 57.75 | 23.50 |
| Qwen2-VL-7B + SC Re3Cap | 77.77 | 58.79 | 44.60 | 73.29 | 58.88 | 36.40 |
| Qwen2-VL-7B + CIM SFT+CIM | 76.65 | 58.09 | 42.12 | 73.87 | 58.68 | 36.32 |
| Qwen2-VL-7B + CIM Re3Cap | 78.18 | 59.28 | 44.19 | 73.92 | 58.99 | 40.15 |

- 跨多個 base LVLM 與 reward functions 平均而言，Re3Cap 相對 GRPO 在 COCO-LN500 的 Relations QA 提升 8.64%，在 DOCCI500 提升 7.57%。
- 在 Qwen2-VL-7B、CIM reward 的消融實驗中，GRPO 為 Objects/Attributes/Relations：75.80/58.22/38.71；僅 CRS 為 76.83/58.98/40.90；僅 CQA 為 77.14/59.04/42.69；兩者合併為 78.18/59.28/44.19。
- 在 SC reward 下，GRPO 約需 192 GPU hours 收斂，Re3Cap 約需 216 GPU hours，增加 24 GPU hours，即約 12.5%。
- max@k 分析顯示，CIM-RL 在 k=1 表現強，但隨 k 增加成長較慢並最終低於 base model；未訓練的 retrieval-guided strategy 隨較大 sampling budget 持續受益。

## 對我們的啟發
- [ ] 若任務需要提升視覺描述的 faithfulness，可將影像條件檢索與文字條件檢索的結果差異，轉化為可操作的保留、補充與移除訊號。
- [ ] 對 RL 系統而言，先以外部推理策略產生 refined candidates，再訓練模型直接輸出，可能比單純提高 reward selection efficiency 更能擴展輸出分布。
- [ ] CRS 與 CQA 具有互補作用：前者聚焦於保留視覺相似樣本中的穩定語意，後者聚焦於檢查 caption 與影像檢索結果的不一致；實務部署仍應監控檢索庫的規模、品質與分布。

## 限制與未來工作

作者明確指出，方法效果依賴 retrieval set 的品質與規模；資料庫過小時，影像 caption 可能無法取得相關結果，方法可能退化為一般 RL。論文建議擴大檢索庫的規模與多樣性。另有資料集社會偏誤、annotation artifacts 與 sampling bias 等既有風險。
