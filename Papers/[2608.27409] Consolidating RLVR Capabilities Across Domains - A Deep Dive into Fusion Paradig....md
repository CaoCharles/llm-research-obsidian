# Consolidating RLVR Capabilities Across Domains: A Deep Dive into Fusion Paradigms

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.27409)
- 📥 [PDF](https://arxiv.org/pdf/2608.27409v1)

## 摘要（中文翻譯）

具可驗證獎勵的強化學習（RLVR）能提升大型語言模型在特定領域的能力，但若要涵蓋多種能力，通常需分別訓練 domain experts，再將其整合。本文依重用 artefacts 將融合方法分為三類：Merge 結合 expert task vectors；Mix RL 混合各領域資料集共同訓練；multi-teacher on-policy distillation（MOPD）同時使用 experts 與資料。作者在 4B 和 8B Qwen3 backbone、共用 experts、資料及多領域 benchmark 下進行比較。三者平均表現差距最多 1.4 分，但單一 benchmark 可達 8.6 分；領域差異與 task-vector geometry 所呈現的跨域關係一致。Mix RL 受資料比例影響，MOPD 受 teachers 表現上限約束，Merge 則將所有 expert updates 壓縮為單一更新。三者均提升 single-sample accuracy，但未觀察到 solution coverage 擴張或 held-out 能力損失。作者建議依 experts 是否已存在、成本與領域關係選擇方法。

## 問題背景

論文探討如何把分別透過 RLVR 取得的 math、science、code、instruction following 與 agent 能力，整合為一個可服務多領域的模型。既有 Merge、混合資料 RL 與 MOPD 多半在不同 backbone、資料和 benchmark 上個別研究，缺乏公平的共同框架比較，因此難以判斷三者的相對效果、跨域增益或干擾來源，以及應依哪些成本和前置條件選擇方法。

## 解決方案

作者建立以重用 artefacts 為核心的統一分析框架，將方法明確區分為 Merge、Mix RL 與 MOPD。三者從同一 base model 和五個 domain experts 出發，分別重用 task vectors、domain datasets，或同時重用兩者。研究不只比較平均 benchmark 分數，也分析 experts 的跨域行為、task-vector cosine geometry、訓練步數與 prompt exposure，並測量 pass@k 和 held-out capabilities。核心創新是以共享 experts、資料、backbone 與評估套件，直接揭示各融合范式如何在性能、成本、領域轉移及能力保留間取捨。

## 核心貢獻
1. 在相同 Qwen3 backbone、五個 domain experts、訓練資料與多領域 benchmark 下，首次對 Merge、Mix RL 和 MOPD 進行受控比較。
2. 以跨域行為轉移與 task-vector geometry 連結性能差異，指出 math、science、code 互相強化，而 instruction following 與 agent 使用近乎正交的更新方向。
3. 刻畫三種范式的性能界限與資源取捨：Mix RL 依賴資料比例，MOPD 快速但受 teachers 約束，Merge 在已有 experts 時幾乎零額外訓練成本。

## 技術方法

實驗使用 Qwen3-4B-Instruct-2507 與 Qwen3-8B（non-thinking mode）兩個 backbone，涵蓋 math、science、coding、instruction following 和 agent 五域。Math 從 Polaris 篩除 pass rate 大於 4/8 的樣本，保留 38,131 筆；science 篩除 pass rate 大於 6/8 後隨機取 50,000 筆；code、IF、agent 分別使用 19,169、16,575、10,229 筆資料。每域以 full-parameter 與 LoRA（rank 32、alpha 64）進行 RLVR expert 訓練。Merge 使用 Task Arithmetic，令 θmerge=θ0+λΣτi，主實驗 λ=0.6；Mix RL 將資料按 25% math、22% science、22% code、19% IF、12% agent 混合，以 GRPO 單次訓練；MOPD 則以五個 full-parameter experts 作 domain-specific teachers，在 student 自身 rollout 的每個 token 上最小化 student 對 teacher 的 reverse KL，不使用 verifier reward。評估涵蓋 AIME 2025/2026、GPQA-Diamond、LiveCodeBench v5/v6、IFEval、IFBench、BFCL v3，主要回報 mean@16；另以 AIME pass@k 測量 solution coverage，並用 SimpleQA-Verified 和 AA-LCR 測試 held-out factual recall 與 long-context reasoning。

## 關鍵結果

主要結果如下（分數為論文 Table 1 的 mean@16；Avg. 為八個 benchmark 平均）：

| Backbone | Base Avg. | Per-domain RL Full Avg. | Merge Full Avg. | Mix RL Avg. | MOPD Avg. |
|---|---:|---:|---:|---:|---:|
| Qwen3-4B-Instruct-2507 | 57.0 | 63.9 | 63.7 | 62.3 | 63.3 |
| Qwen3-8B (non-thinking) | 42.0 | 53.8 | 53.7 | 54.6 | 53.2 |

|---|---:|---:|---:|---:|---:|---:|
| 4B Base | 49.1 | 53.1 | 57.2 | 59.6 | 30.3 | 63.9 |
| 4B Merge Full | 54.9 | 61.6 | 63.4 | 63.9 | 41.0 | 71.8 |
| 4B Mix RL Full | 53.0 | 59.0 | 61.1 | 64.1 | 39.8 | 71.3 |

| 8B Merge Full | 41.4 | 43.3 | 54.4 | 51.4 | 37.0 | 63.5 |
| 8B Mix RL Full | 45.7 | 47.2 | 54.5 | 51.1 | 37.9 | 65.6 |

作者報告三種融合方法平均差距最多 1.4 分，但單一 benchmark 差距最高達 8.6 分。Math、science、code 的跨域轉移大致正向；IF 與 agent 對其他域近乎正交，4B 中 IF expert 使 BFCL v3 下降約 9.8 分。4B 的 pass@1 較 base 提升 4.5–6.9 分，但至 pass@32 三種融合方法均與 base 無可區分差異。held-out 的 SimpleQA-Verified 與 AA-LCR 沒有方法低於 base；論文未報告具體顯著性檢定數值。成本方面，Mix RL 相對 per-domain RL 為 0.58×（4B）及 0.67×（8B）；MOPD 為 1.14×及 1.19×；Merge 在 experts 已存在時僅需約數分鐘算術操作。

## 對我們的啟發
- [ ] 若已具備多個 domain experts 且首要目標是低成本產生單一部署模型，論文證據支持優先考慮 Merge；但應檢查 task-vector 方向，因低相關領域可能只保留部分增益。
- [ ] 若沒有既有 experts、希望直接訓練統一模型，可採 Mix RL；資料比例不應視為固定設定，應依跨域正負轉移調整，尤其需留意 IF 等缺乏正向轉移的領域。
- [ ] 若重點是保存各 teachers 的 domain-specific gains，而非超越 teachers，可選 MOPD；其 dense teacher supervision 使收斂較快，但端到端成本仍包含 experts 訓練，且標準 reverse-KL 目標沒有超越 teachers 的訊號。

## 限制與未來工作

研究只使用兩個 Qwen3 backbone、五個領域與特定資料混合比例，且 Merge 主結果採單一 Task Arithmetic λ=0.6；因此不同模型、領域、融合規則或比例的泛化仍未確定。held-out 評估依賴 Qwen3-32B LLM judge。作者也未研究可超越 teachers 的 MOPD 變體，並將其留作未來工作。
