# Consolidating RLVR Capabilities Across Domains: A Deep Dive into Fusion Paradigms

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.27409)
- 📥 [PDF](https://arxiv.org/pdf/2608.27409v1)

## 摘要（中文翻譯）

具可驗證獎勵的強化學習（RLVR）能提升大型語言模型在特定領域的能力，但若要涵蓋多種能力，通常需分別訓練領域專家，再將其整合。本文依所重用的訓練產物，整理三種 fusion paradigm：Merge 結合 expert task vectors，Mix RL 混合各領域資料集，multi-teacher on-policy distillation（MOPD）同時使用專家與資料。作者在共享專家、資料、不同模型規模及多領域 benchmark 下進行比較。三者平均表現差距至多 1.4 分，但單一 benchmark 的差距可達 8.6 分；領域差異與 task-vector geometry 所呈現的跨域關係一致。訓練動態顯示，Mix RL 受資料比例影響，MOPD 受教師能力上限限制，而 Merge 將所有專家更新壓縮成單一更新。三者皆提升 single-sample accuracy，卻未測得 solution coverage 增益，也未造成 held-out 能力損失。實務上，已有專家且重視低成本時適合 Merge；沒有專家、要訓練統一模型時適合 Mix RL；重視保留領域增益時則可採用 MOPD。

## 問題背景

論文要解決的是：如何將多個以 RLVR 分別取得的領域能力，整合為一個可部署模型，以及三種 fusion paradigm 應如何選擇。既有研究多分開評估 Merge、Mix RL 或 MOPD，使用不同 backbone、資料與 benchmark，難以公平比較其效能、成本與失真來源，也未釐清跨領域 transfer、interference 及各領域能力保留程度。

## 解決方案

作者建立一個統一比較框架，將方法依重用的訓練產物分類：Merge 重用專家的 task vectors；Mix RL 重用各領域資料與 verifiers，在單次 RLVR 中共同訓練；MOPD 同時重用專家與資料，以多教師 on-policy distillation 將領域教師行為蒸餾至單一學生。核心創新是使用相同 base models、五個領域、專家與資料，跨 4B 與 8B 規模直接比較三者，並將 benchmark 行為、task-vector geometry、訓練動態、計算成本與 solution coverage 聯繫起來，據此提出依專家可得性、跨域關係與成本選擇方法的指南。

## 核心貢獻
1. 在相同 Qwen3-4B 與 Qwen3-8B backbone、五個領域、共享專家與資料及多領域 benchmark 下，首次對 Merge、Mix RL 與 MOPD 進行受控比較。
2. 證明跨域行為 transfer 與 task-vector geometry 具有一致結構：math、science、code 的 reasoning 能力多半互相促進，而 IF 與 agent 和其他領域近乎正交；此關係解釋了不同 fusion 方法的領域級差異。
3. 分析三種方法的訓練與成本限制：Mix RL 受 domain mixture proportions 影響，MOPD 快速收斂但受教師能力上限約束，Merge 將多個專家更新壓縮為單一更新；並指出 fusion 提升 single-sample accuracy，卻未帶來可測得的 solution coverage 增益。

## 技術方法

研究使用 Qwen3-4B-Instruct-2507 與 Qwen3-8B（non-thinking mode）作為 backbone，涵蓋 math、science、coding、instruction following（IF）與 agent 五個領域。資料包括 38,131 個 math、50,000 個 science、19,169 個 code、16,575 個 IF 及 10,229 個 agent 範例；Mix RL 與 MOPD 使用混合比例 25%、22%、22%、19%、12%。每個領域從共同 base model 以 GRPO 訓練 full-parameter 與 LoRA 專家；LoRA rank 為 32、alpha 為 64。Merge 使用 λ=0.6 的 Task Arithmetic，將五個 task vectors 合併；Mix RL 從 base model 以混合資料進行單次 GRPO，訓練 800 steps；MOPD 將五個 full-parameter 專家作為 domain teachers，以學生自身 rollout 狀態上的 reverse-KL、逐 token teacher log-probability 進行蒸餾，訓練 300 steps。評估涵蓋 AIME 2025/2026、GPQA-Diamond、LiveCodeBench v5/v6、IFEval、IFBench 與 BFCL v3，主要回報 mean@16；另以 pass@k（k 至 32）測試 solution coverage，並以 SimpleQA-Verified 與 AA-LCR 評估 held-out factual recall 及 long-context reasoning，兩者由 Qwen3-32B 評分。研究亦比較 domain-level transfer、task-vector layer-wise cosine similarity、prompt exposure、training steps，以及 fusion 與 per-domain RL 的 GPU-hours。

## 對我們的啟發
- [ ] 若已有多個領域專家且主要目標是以最低額外成本產生單一部署模型，應優先評估 Merge；但需檢查 task-vector 的跨域相似性，因為低相關領域的能力可能只部分保留。
- [ ] 若沒有預先訓練的專家，Mix RL 能以較低端到端 GPU 成本直接建立 unified model；資料比例不應只按資料量設定，應根據跨域 transfer 調整，尤其要避免低相關領域因樣本占比不足而落後。
- [ ] 若重點是快速保留多個教師的領域表現而非超越教師，MOPD 可用密集的 token-level supervision 加速收斂；但其完整成本仍包含教師訓練，且標準 reverse-KL objective 不提供超越教師的明確訊號。

## 限制與未來工作

研究只涵蓋兩個 Qwen3 backbone、五個領域，Merge 主實驗採固定 Task Arithmetic λ=0.6，MOPD 也限於標準 reverse-KL on-policy 形式。held-out 結果僅在 4B 報告，且部分評估由 LLM judge 完成。作者未驗證能超越教師的 MOPD 變體、更多 backbone、不同資料混合策略或更廣泛部署情境，這些留待未來研究。
