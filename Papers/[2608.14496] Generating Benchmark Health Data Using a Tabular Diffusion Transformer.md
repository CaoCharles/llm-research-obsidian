# Generating Benchmark Health Data Using a Tabular Diffusion Transformer

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.14496)
- 📥 [PDF](https://arxiv.org/pdf/2608.14496v1)

## 摘要（中文翻譯）

Cross-Tabular Data Generation（CTDG）旨在從多個異質資料表學習生成模型，產生新的合成表格資料。然而，現有 Synthetic Tabular Data Generation（STDG）方法大多限於單一輸入表格，難以處理具有不同特徵集合的多個異質表格。本文提出兩階段 CTDG framework：第一階段將每個異質原始表格轉換為具有統一欄位的 standardized statistical table，描述原始欄位的邊際分布與兩兩相關性；第二階段訓練 Tabular Diffusion Transformer，學習這些同質統計表格的結構模式並生成合成統計表格。接著透過 multivariate Gaussian sampling 與 inverse probability integral transform 重建合成原始表格。實驗顯示，統計表示具有高 fidelity，生成資料亦取得良好的 fidelity–diversity trade-off。

## 問題背景

現有 synthetic tabular data generation 方法主要以單一資料表為輸入，假設固定 schema、欄位集合與資料型態，因此難以同時學習多個欄位結構不同的 heterogeneous tables。這限制了跨資料集知識共享，也使健康 benchmark 難以兼具真實統計特性、多樣性與可重現的大規模生成能力。本文聚焦於從多個真實健康及一般 tabular datasets 學習統一生成模型。

## 解決方案

作者提出兩階段 CTDG framework。第一階段把每個 heterogeneous raw table 壓縮為同質化 statistical table，以 Beta–Binomial 參數描述欄位 marginal distribution，以 missing rate 描述缺失模式，並以 spectral factorization 表示欄間 correlation structure。第二階段將每個 statistical table 視為一個可變長度序列，使用 Tabular Diffusion Transformer 學習跨表格的分布與結構，再透過 DDPM 反向去噪生成新的統計表格。最後以 Gaussian sampling 加 inverse probability integral transform 重建 synthetic raw tables。核心創新在於以 table-level statistical representation 取代 record-level schema 對齊，讓模型能生成未與原始欄名及類別定義綁定的異質資料表。

## 核心貢獻
1. 提出一個可從多個 heterogeneous tables 學習的兩階段 Cross-Tabular Data Generation（CTDG）framework，將不同 schema 統一轉換為 statistical tables。
2. 設計結合 Beta–Binomial 邊際統計、缺失率與 spectral correlation representation 的固定維度表格級表示，並以 Tabular Diffusion Transformer 生成新的統計表格。
3. 以 144 個 Health domain datasets 進行重建、消融與五折交叉驗證，並公開生成 1,000 個健康 benchmark datasets，支援大規模可重現評測。

## 技術方法

方法分為兩階段。第一階段對每個原始表格逐欄提取統計表示。Categorical column 依頻率排序類別並映射為整數，再以 Beta–Binomial distribution 擬合，取得 alpha、beta 與 cardinality；numerical column 先離散化為 100 個 intervals，再採相同程序；每欄另記錄 missing rate。為保存欄間依賴，將 mapped columns 經 probability integral transform 轉為 normal variables，計算 correlation matrix，並以 eigen-decomposition 得到 A=U Lambda^{1/2}，每個欄位以其 spectral row vector 表示。固定 K=256；欄數不足時 zero-padding，超過時隨機刪除欄位至 K。每個統計表欄位列包含 K+4 個參數。接著對全部統計表的各參數施加 global quantile transformation，映射至可比較尺度。

第二階段使用 Tabular Diffusion Transformer：每個統計表的 row 作為 embedding，整個表格作為可變長度 sequence；輸入投影至 768 維，加上 sinusoidal diffusion timestep embedding，經 12 層、12 attention heads 的 Transformer encoder，再由輸出投影還原為 260 維。模型採 DDPM noise-prediction loss，T=1000、AdamW learning rate=1e-4、batch size=64、訓練 500 epochs；先以 4,095 個 OpenML datasets 預訓練，再用 131 個 OpenML Health datasets 與 13 個 healthcare datasets 微調。生成後反轉 quantile transformation，依 A 重建 correlation matrix，從 multivariate Gaussian sampling，再以 inverse probability integral transform 映射至各欄 Beta–Binomial 分布，最後按 missing rate 隨機加入缺失值。評估使用 dimension-Normalized Wasserstein Distance（dNWD）衡量重建 fidelity，以及無一對一對應時使用 Closest Wasserstein Distance（CWD）評估生成表格與 real domain 的接近程度。

## 關鍵結果

主要結果如下；除論文明確報告的數字外，未補充其他結果。

| 評估項目 | 設定 | 結果 |
|---|---|---|
| 原始表格重建 | 144 個 Health datasets，完整統計表示 | dNWD 平均 **0.095**，標準差 **0.061**；多數低於 0.2 |
| 重建消融 | 僅 marginal statistics，identity correlation | dNWD 平均 **0.304**，標準差 **0.164** |
| 重建消融 | random correlation matrix | dNWD 平均 **0.636**，標準差 **0.270** |
| 生成資料 fidelity | 五折交叉驗證，生成 2,000 個 synthetic tables，與 29 個 Health real tables 比較 | Health CWD 五折平均 **0.72** |
| 跨 domain 比較 | Economics、Statistics、Engineering、Finance、Games 的 CWD 五折平均 | 分別為 **0.97、0.98、1.35、1.55、1.75**；Health 最低 |
| 生成資料 diversity | synthetic samples 對 real tables 的 neighborhood coverage | 比率接近 **0.95**；論文據此主張廣泛涵蓋 real Health domain |
| 公開 benchmark | 生成資料集 | 1,000 個 datasets；每個 10,000 rows，欄數 10–256 |

論文未報告與 CTGAN、TabDDPM、TabSyn 等方法在同一 CTDG 設定下的直接 baseline 數字，也未報告完整 downstream utility 或正式 privacy attack 數字。

## 對我們的啟發
- [ ] 若目標是生成跨資料集的 benchmark，先將異質原始資料轉成統一的 table-level statistical representation，可避免直接對齊欄名與語意的限制。
- [ ] 評估合成表格時不應只檢查 marginal distributions；論文的消融結果顯示，保留真實 correlation structure 對重建 joint distribution 十分重要。
- [ ] 使用此類資料進行模型 benchmark 時，應將其視為保留一階與二階統計特性的合成資料，並另外檢查 outliers、極高維欄位與實際任務效用。

## 限制與未來工作

作者指出，statistical table representation 可能遮蔽原始資料中的 outliers，極端值可能需要後續人工加入。模型最多支援 256 個欄位，無法處理更高維 benchmark。未來可研究保留更多結構資訊的其他 embedding techniques。論文亦未提供正式差分隱私保證或 membership、attribute disclosure 的量化評估。
