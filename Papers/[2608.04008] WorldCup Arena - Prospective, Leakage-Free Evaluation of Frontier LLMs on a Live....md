# WorldCup Arena: Prospective, Leakage-Free Evaluation of Frontier LLMs on a Live Tournament

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.04008)
- 📥 [PDF](https://arxiv.org/pdf/2608.04008v1)

## 摘要（中文翻譯）

現有衡量大型語言模型 forecasting 能力的 benchmark 幾乎都是 retrospective：事件已經發生，答案已存在於 Web 上，因此評估必須防範模型記憶或資料污染。本研究採用相反設計：在 2026 FIFA World Cup 的 39 天期間，六個具 extended thinking 與原生 server-side web search 的 frontier LLM，在每場比賽 kickoff 前逐場完成七市場 prediction card，涵蓋 104 場比賽、12 個分組冠軍及賽前 outright pool；提問當下答案尚不存在，因此天生具備 leakage-free 特性。凍結資料庫共包含 4,494 個 scored predictions。結果顯示，模型平均 match outcome 準確率為 63.9%，與直接支持 bookmaker favourite 的 64.4% 相當；模型彼此高度一致但未因此更準確，且共同低估 draws 與 goals、集中預測單一典型比分。模型表現主要隨比賽強弱差距變化，而非隨可取得資訊量變化；整體賽事層級問題表現優於單場預測。六個系統的排名差距狹窄，作者並釋出 briefing dossiers、fixtures、官方結果與 scoring code 作為 benchmark。

## 問題背景

既有 LLM forecasting benchmark 多為 retrospective：事件已結束且答案可能存在於 Web，難以排除模型記憶、訓練資料污染與事後檢索。匿名化或 filtering 只能間接控制 leakage，亦通常缺乏連續、密集且具有客觀結果的比較。本文要解決的是如何在真實未來事件中，於答案尚不存在時，公平評估具搜尋與 extended thinking 能力的 frontier LLM forecasting 表現。

## 解決方案

作者提出 WorldCup Arena，一個以完整 2026 FIFA World Cup 為測試場域的 prospective、leakage-free evaluation framework。系統每日建立並凍結球隊 dossiers、賽程、場地與 bookmaker handicap，於每場 kickoff 前讓六個模型在相同 prompt 與資料條件下逐場預測；比賽結果僅在賽後回寫。框架以三項時間與內容鎖定機制確保答案不可提前取得，並以七個固定市場、預先指定權重、官方 90 分鐘比分及 deterministic scoring 統一評分。核心創新是以日曆上的未來性直接保證 leakage-free，同時保留 live web search 與完整賽事密度，以分析模型間一致性、時序表現與 leaderboard 不確定性。

## 核心貢獻
1. 提出一套完整 prospective、leakage-free 的 LLM forecasting 評估流程，在事件結果尚未存在時進行提問，避免 retrospective benchmark 的記憶污染問題。
2. 在 2026 FIFA World Cup 全部 104 場比賽上建立公開 benchmark，釋出 48 個球隊 dossiers、46 個 timestamped snapshots、fixture metadata、官方結果及 scoring code。
3. 以 bootstrap intervals 與五種 scoring designs 檢驗 leaderboard 不確定性，並系統性揭示六個 frontier LLM 的共同行為：追隨 bookmaker、低估平局與進球、模型 herd、比分模式坍縮，以及單場與賽事層級預測能力的落差。

## 技術方法

研究將 benchmark 設計為一個 rolling、prospective evaluation：在 2026 年 6 月 10 日至 7 月 19 日的 39 天內，六個模型依實際賽程、每場 kickoff 前逐一回答 104 場比賽。模型包括 Claude、GPT、Gemini、Kimi、GLM 與 Seed；均使用各 API 可提供的最高 extended-thinking 設定及供應商原生 server-side web search。論文未提供這些模型的內部架構，而是比較其公開 API configuration。每場輸入包含賽事階段、日期、場地、天氣、裁判、教練、固定 bookmaker handicap line，以及雙方球隊的完整 pre-match dossier。dossier 涵蓋 FIFA ranking、Elo、球員表、歷史、近四年戰績與最新消息，並以 46 個 timestamped snapshots 滾動更新。輸出必須是與比分一致的 JSON，包含 handicap、half-time/full-time、1X2、over/under 2.5、both teams to score、correct score、odd/even total goals 七個市場。各市場權重分別為 4、3、2、2、2、2、1，單場最高 16 分；另評估 12 個 group winners 與 pre-tournament outright pool。三項 leakage locks 包括 snapshot lock、kickoff lock 與 template lock；結果在賽後才寫回 dossier。評估使用 deterministic scoring script、match points、各市場 accuracy、bookmaker favourite baseline、uniform/modal guess，以及以 10,000 次 bootstrap 重抽比賽所得的 95% confidence intervals。作者另以五種 scoring designs 檢查 leaderboard 對計分方式的敏感度。

## 關鍵結果

| 評估模型數量 | 6 |

| Scored predictions | 4,494 |
| Match outcome 平均準確率 | 63.9% |
| Bookmaker favourite baseline（1X2） | 64.4% |

| 模型對 match outcome 的平均一致率 | 76.0% |

| Claude 相對 GPT 的 match 分數差 | +22；95% CI 為 [−49,+94] |

| Tournament-level questions | 模型表現比 single-match 預測高 20–44 個百分點 |

論文指出，六個系統在各市場的差距狹窄；五種 scoring designs 下由不同模型取得第一名，唯一跨五種設計一致的排序結論是 Gemini 從未高於第三名。

## 對我們的啟發
- [ ] 若要評估模型的真實 forecasting 能力，應優先採用 prospective、時間鎖定且答案尚未產生的任務，而非只依賴事後去污染或匿名化。
- [ ] 模型間的高度一致不代表集體智慧；本文中模型在 76.0% 比賽上對 match outcome 達成一致，但 majority vote 的準確率僅 65.4%，未顯示穩定優勢。
- [ ] 實務部署預測系統時，應與 bookmaker favourite 等強 baseline 比較，並分離賽事層級與單事件表現；僅超越 uniform guessing 不足以證明模型具備有用的預測能力。

## 限制與未來工作

研究只涵蓋單一足球賽事，因此 breadth 有限，結果不能直接推廣至其他運動、領域或事件類型。每個市場要求 single choice，未評估完整機率分布與 calibration。六個模型是特定時間點的 purposive snapshot，且不同供應商的 thinking 與 search 控制介面不完全相同。論文未報告更廣泛跨賽事重複實驗。
