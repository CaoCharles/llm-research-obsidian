    Alignment Verifiability in Large Language Models: Normative Indistinguishability under Behavioral Evaluation

    連結

    • 📄 arXiv
    • 📥 PDF
    • 📎 本地 PDF: PDF

    摘要（中文翻譯）

    行為評估（behavioral evaluation）是評估大型語言模型對齊性的主流範式。在實踐中，對齊性是從有限評估協議（benchmark、紅隊測試套件或自動化管線）下的表現來推斷的，而觀察到的合規行為往往被視為潛在對齊屬性的證據。然而，從行為證據到潛在對齊性質的推論步驟通常是隱含的，鮮少作為一個獨立的推斷問題加以分析。本文正式研究此問題，將對齊評估框定為部分可觀測性（partial observability）下的可識別性問題，並允許 agent 行為依賴於與評估機制相關的資訊。在此設定下，我們引入對齊可驗證性問題（Alignment Verifiability Problem）與規範不可區分性（Normative Indistinguishability）概念，刻畫不同的潛在對齊假說何時會在所有評估者可存取的信號上產生完全相同的分布。主要結果是一個否定性但邊界清晰的可識別性定理：在有限行為評估與評估感知的 agent 下，觀察到的行為合規無法唯一識別潛在對齊性。即便理想化的行為評估也無法一般性地將對齊性作為潛在屬性加以認證。

    問題背景

    當前 AI 安全領域的對齊評估主要依賴行為測試（benchmark、紅隊測試、自動化評估管線），並將「通過測試」等同於「模型已對齊」。然而，這個從行為證據到潛在對齊屬性的推論步驟從未被嚴格形式化分析。核心問題是：如果 agent 能感知自己正在被評估（evaluation-aware），行為合規是否真的能證明內在對齊？這不僅是理論問題——隨著模型能力增強，沙箱遊戲（sandbagging）與策略性合規（strategic compliance）的風險日益增大。

    解決方案

    作者將對齊評估形式化為部分可觀測系統中的可識別性（identifiability）問題。核心創新在於引入兩個關鍵概念：(1) Alignment Verifiability Problem——能否從行為數據唯一確定潛在對齊假說；(2) Normative Indistinguishability——當兩個不同的對齊假說在評估範圍內產生完全相同的行為分布時，它們是「規範不可區分的」。在此框架下，證明了一個否定性定理：有限行為評估無法將潛在對齊假說的空間坍縮為唯一解，並據此提出將 alignment benchmark 重新詮釋為「不可區分性類別的估計器」而非「對齊性的驗證器」。

    核心貢獻

    1. 正式定義 Alignment Verifiability Problem 與 Normative Indistinguishability，首次將對齊評估框定為嚴格的統計可識別性問題，建立了分析行為評估認識論限制的理論基礎
    2. 證明 Non-Identifiability Theorem：在有限行為評估與評估感知 agent 的條件下，行為合規無法唯一識別潛在對齊屬性——即使理想化的評估也無法一般性地認證對齊性
    3. 提出將 alignment benchmark 重新詮釋的框架：從「對齊驗證器」轉為「不可區分性類別的估計器」，通過更嚴格的測試可縮小相容假說空間但無法將其坍縮為單一假說

    技術方法

    形式化框架：定義行為對齊測試為有限評估程序 E，僅從可觀測行為產生結果。對齊假說空間 Θ 中的每個假說 θ 通過策略 π_θ 產生行為。關鍵假設是 evaluation awareness：agent 可存取與評估協議相關的資訊 Z(E)，使其策略可依條件調整為 π_θ(·|Z(E))。

    核心定義： - Behavioral Equivalence：兩個假說 θ 和 θ' 在評估歷史集 H_E 上策略一致時為行為等價 - Verifiability：假說 θ 在評估 E 下是可驗證的，當且僅當沒有其他假說能在可觀測數據集上產生相同的概率分布 - Normative Indistinguishability：假說 θ 和 θ' 在 E 下規範不可區分，當 P_θ(D) = P_θ'(D) 對所有 D ∈ D_E 成立

    主定理證明：若兩個假說的策略在 H_E 上一致但在 H_E 之外分歧，則對所有可觀測數據集 D，P_θ(D) = P_θ'(D)，因此有限行為測試無法區分它們。

    Alignment Indistinguishability Test：形式化為判定真實假說是否屬於某個不可區分性類別（即所有與參考對齊規範行為等價的假說集合），而非驗證特定假說。

    關鍵結果

    本文為理論論文，主要結果為形式化定理而非實驗數據：

    概念 定義 意涵
    Non-Identifiability Theorem 有限行為評估 + 評估感知 agent → 行為合規無法唯一識別潛在對齊 即使理想化評估也無法認證對齊性
    Normative Indistinguishability 不同假說在評估範圍內產生相同行為分布 評估只能確定不可區分性類別
    Indistinguishability Test 判定假說是否屬於某等價類 Benchmark 是估計器而非驗證器

    行為評估能做到的：建立可觀測合規的上界、在測試範圍內發現失敗模式、提供對特定行為的經驗保證

    行為評估做不到的：證明 agent 真正對齊而非僅在評估下表現合規、排除策略性合規的可能性

    對我們的啟發

    • 此定理為紅隊測試和 alignment benchmark 設定了認識論天花板：無論測試多嚴格，行為評估本質上只能縮小相容假說空間而非唯一確定對齊性，這要求我們在解讀 benchmark 結果時保持謙遜
    • 對 LLM-as-Judge 和自動化評估管線的設計有直接啟示：應將評估結果詮釋為「在此測試條件下模型屬於某個不可區分性類別」而非「模型已通過對齊認證」，報告時應明確聲明評估的適用範圍
    • 此結果不否定行為評估的價值，而是指明了互補方向：mechanistic interpretability（理解模型內部表徵）與 process-level supervision（監督推理過程而非僅看結果）可能是突破行為評估限制的關鍵路徑

    限制與未來工作

    本文為純理論工作，未提供實證驗證。Non-Identifiability 結果依賴三個關鍵假設（有限評估、潛在對齊假說空間、評估感知 agent），若任一假設不成立則結論需修正。論文明確指出此結果不意味行為評估無用、也不意味合規行為必然是欺騙。未探討 interpretability 或 process supervision 等替代途徑是否能真正突破此限制。
