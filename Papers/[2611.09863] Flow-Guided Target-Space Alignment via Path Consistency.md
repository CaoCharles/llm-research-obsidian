# Flow-Guided Target-Space Alignment via Path Consistency

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.09863)
- 📥 [PDF](https://arxiv.org/pdf/2611.09863v1)

## 摘要（中文翻譯）

許多多模態對齊問題需要將來源模態映射至由目標模態定義的固定空間；此目標空間不只是中間嵌入，而會直接用於下游分析。因此，成功的對齊必須同時保留目標分布的全域結構，以及配對來源—目標訓練資料中的實例級對應。既有目標各自只處理部分需求：contrastive loss 鼓勵相對相似性，distribution matching 改善邊際分布一致性，而 pointwise regression 雖能擬合配對目標，卻未明確建模目標空間的路徑幾何。本文提出 FlowAlign，一種 flow-guided target-space alignment 方法，將 conditional flow matching 重新用作訓練期間的對齊訊號，而非推論期間的 transport model。FlowAlign 利用學得的 flow field 引導來源表示對齊固定目標空間，使其保留配對對應，同時符合目標空間的全域結構。理論分析顯示，FlowAlign 可透過控制 endpoint accuracy 並捕捉局部目標空間幾何，改善配對對應。合成資料、paired single-cell multiome 與 image–text 實驗均顯示，FlowAlign 能提升 instance-level correspondence，並在不同模態設定下維持 target-space structure。

## 問題背景

論文研究將來源模態映射到固定目標表示空間的問題，且該空間會直接用於鄰域、分群、標註與下游分析。挑戰在於同時保留目標分布的全域幾何與配對樣本的實例級對應。既有 contrastive 方法偏重相對相似性，distribution matching 只對齊邊際分布，pointwise regression 則擬合配對端點但未建模目標空間的路徑幾何，因而難以兼顧兩者。

## 解決方案

作者提出兩階段 FlowAlign。第一階段以配對來源表示 s 與目標表示 t 建立 source-conditioned conditional flow field：從以 s 為中心的局部高斯起點取樣，沿線性路徑前往 t，並以 conditional flow matching 學習速度場。第二階段凍結速度場，將模型輸出的候選目標表示帶入候選路徑，計算其速度與凍結場的 residual 作為 path-consistency loss，更新來源側 mapper。核心創新是把 flow matching 從推論時的 transport 機制改為訓練時的 target-space compatibility score，使候選端點同時受到配對資訊與局部目標幾何約束；方法亦可作為既有任務目標的 plug-in regularizer。

## 核心貢獻
1. 提出固定 target-space alignment 設定，明確要求同時維持目標空間全域結構與配對樣本的 instance-level correspondence。
2. 提出 FlowAlign，透過 source-conditioned conditional flow matching 學習配對路徑，再以凍結速度場的 path-consistency score 作為訓練訊號或既有模型的 regularizer。
3. 提供 endpoint control、局部 source-conditioned metric 與來源條件降低 velocity ambiguity 的理論分析，並在合成、single-cell multiome 與 image–text 任務驗證方法。

## 技術方法

資料先由固定的來源與目標表示管線取得 s,t∈R^d；來源可為 PCA、預訓練 encoder 或投影後特徵，目標表示固定不更新。第一階段對每個配對樣本由 p0(·|s)=N(s,σ²I) 取樣 x0，隨機取 τ∈[0,1]，形成 xτ=(1−τ)x0+τt，並以 t−x0 為監督速度，訓練具來源條件的 vψ(xτ,τ;s)，之後凍結 vψ。第二階段由來源模型產生候選表示 t̂θ，形成 x̃τ=(1−τ)x0+τt̂θ，最小化 Cψ(t̂θ;s)=E||vψ(x̃τ,τ;s)−(t̂θ−x0)||²；也可與 endpoint、reconstruction、contrastive 或其他 base objective 加權結合。推論時不使用 flow integration，只以來源模型單次前向輸出固定目標空間表示。理論上，在速度場局部 Lipschitz 且配對路徑 residual 足夠小時，path score 可控制端點誤差；局部上則近似由速度場 Jacobian 誘導的 source-conditioned quadratic metric。實驗涵蓋合成軌跡、PBMC/BMMC paired single-cell multiome 與 CUBICC image–text。評估包括 MMD、endpoint MSE、latent-position MAE、FOSCTTM、exact cell match 或 R@1，以及 LTA、NMI、ARI、ASW-O。

## 關鍵結果

主要結果如下；數值為論文表格中的單次彙總值，PBMC/BMMC 與 CUBICC 的變異結果另於附錄提供。

| 實驗 | 方法 | 主要結果 |
|---|---|---|
| Synthetic | FlowAlign | MMD=7.79×10^-2；MSE=2.87×10^-4；latent MAE=5.10×10^-3 |
| Synthetic | MSE regression | MMD=8.13×10^-2；MSE=3.54×10^-4；latent MAE=5.61×10^-3 |
| Synthetic | MMD alignment | MMD=6.99×10^-3；MSE=1.50×10^-1；latent MAE=1.68×10^-1 |
| PBMC | FlowAlign | FOSCTTM=0.039；Cell match=0.141；LTA=0.920；NMI=0.872；ARI=0.885；ASW-O=0.978 |
| PBMC | MSE | FOSCTTM=0.048；Cell match=0.110；LTA=0.902；NMI=0.821；ARI=0.814；ASW-O=0.973 |
| BMMC | FlowAlign | FOSCTTM=0.019；Cell match=0.050；LTA=0.836；NMI=0.797；ARI=0.768；ASW-O=0.988 |
| BMMC | MSE | FOSCTTM=0.042；Cell match=0.032；LTA=0.786；NMI=0.757；ARI=0.711；ASW-O=0.980 |
| CUBICC | FlowAlign | FOSCTTM=0.063；R@1=0.075；LTA=70.42% |
| CUBICC | MSE | FOSCTTM=0.069；R@1=0.067；LTA=57.49% |

作者報告 FlowAlign 在兩個 single-cell 資料集取得最低 FOSCTTM 與最高 exact cell-match，並在 CUBICC 三項指標皆優於比較方法。消融顯示移除局部起點取樣、來源條件或候選路徑位置輸入均會降低表現；直接將 flow field 作為推論 transport map 雖具競爭力，但生物結構指標較弱。

## 對我們的啟發
- [ ] 若下游分析直接依賴某一固定嵌入空間，對齊目標不應只看檢索或配對誤差，也應同步評估分布、鄰域與分群結構。
- [ ] Flow matching 不必用作推論時的生成或 transport；凍結後的速度 residual 可作為結合配對監督與局部幾何的訓練期評分器。
- [ ] 局部起點擾動與 source conditioning 是方法的重要設計：前者讓模型看到鄰域路徑，後者可區分經過相近空間位置但對應方向不同的樣本；實務上仍需檢查 field quality 與 σ 的尺度敏感性。

## 限制與未來工作

方法需要 paired data、可在共同向量空間建構路徑，以及品質足夠好的第一階段 velocity field。若來源表示不相容或 field 學習不佳，對齊訊號會變弱。理論目前以 Euclidean linear paths 為基礎，且 standalone alignment 不保證保留目標空間未包含的來源特有資訊。作者未來將研究更彈性的起點分布、field diagnostics、部分配對或 unpaired 設定。
