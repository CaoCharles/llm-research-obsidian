# Are We on the Right Way to Assessing LLM-as-a-Judge?

## 連結

## 摘要（中文翻譯）

LLM-as-a-Judge 已被廣泛採用作為評測方法，並作為模型訓練中的監督式獎勵信號。然而，現有的 LLM-as-a-Judge 基準測試主要依賴人工標註的 ground truth，這引入了人類偏見，削弱了可靠性評估並帶來可擴展性限制。為克服這些局限，本文提出 Sage，一個無需任何人工標註即可評估 LLM 評審品質的新型評測套件。受理性選擇理論公理啟發，Sage 引入兩個衡量 LLM-as-a-Judge 的新維度：局部自一致性（pair-wise preference stability）和全局邏輯一致性（偏好的傳遞性）。研究團隊整合結構化基準問題與真實用戶查詢，建構了包含 650 個問題的資料集。實驗結果證明這些指標具有穩定性，且與 LLMBar、RewardBench2 等監督式基準高度相關，驗證了 Sage 作為評測 LLM-as-a-Judge 穩健性和準確性工具的可靠性。研究還揭示即使是最先進的模型在約四分之一的困難案例中也無法維持一致的偏好判斷。

## 問題背景

現有 LLM-as-a-Judge 基準測試過度依賴人工標註的 ground truth，這帶來兩大問題：(1) 人類標註本身存在顯著不一致性，未必是可靠的黃金標準；(2) 人工標註成本高昂，限制了評測的可擴展性。這使得我們無法客觀且大規模地評估 LLM 評審的可靠性，也無法識別模型在擔任評審角色時的系統性弱點。

## 解決方案

提出 Sage 評測套件，核心創新是從理性選擇理論借鑑公理化方法，定義兩個無需人工標註的一致性指標：(1) 局部自一致性（Local Self-Consistency）衡量模型在成對比較中的偏好穩定性；(2) 全局邏輯一致性（Global Logical Consistency）衡量偏好在完整集合中的傳遞性。這種方法的本質區別在於，它從「評審判斷是否與人類一致」轉向「評審判斷是否在邏輯上自洽」，從而繞過了人類標註偏差的問題。

## 核心貢獻
1. 提出基於理性選擇理論的無監督 LLM-as-a-Judge 評測框架 Sage，無需人工標註即可衡量評審品質
2. 發現 situational preference 現象：LLM 評審的偏好會隨上下文呈現方式改變，明確的 rubric 可顯著提升一致性
3. 實證揭示人類標註本身存在顯著不一致性，質疑將人工標註作為 LLM-as-a-Judge 黃金標準的傳統假設

## 技術方法

Sage 的技術方法建立在理性選擇理論的兩個核心公理上。首先，局部自一致性測量透過多次重複同一成對比較（改變回應順序和提示格式），檢驗 LLM 評審是否能穩定給出相同偏好，量化為 pair-wise preference stability 分數。其次，全局邏輯一致性測量構建完整的偏好圖譜，檢驗傳遞性（若 A > B 且 B > C，則應 A > C），量化為 transitivity violation rate。

資料集方面，研究團隊整合了結構化基準問題（如數學、邏輯推理）和真實世界用戶查詢，共 650 個問題，並按難度分級。實驗涵蓋 scoring 和 pairwise 兩種評審模式，測試了包括 Gemini-2.5-Pro、GPT-5 在內的多個最先進模型。

為驗證 Sage 的有效性，研究將其指標與 LLMBar 和 RewardBench2 等依賴人工標註的監督式基準進行相關性分析，確認高度一致。此外還進行了消融實驗，分析 explicit rubrics、panel-based judge（多模型投票）和 deep reasoning 對一致性的影響。

## 關鍵結果

| 模型 | 局部自一致性 | 全局邏輯一致性 | 困難案例失敗率 |
|------|-------------|---------------|---------------|
| Gemini-2.5-Pro | 最佳表現 | 高 | ~25% |
| GPT-5 | 接近最佳 | 高 | ~25% |
| 其他 SOTA 模型 | 中等 | 中等 | >30% |
| + Explicit Rubric | 顯著提升 | 顯著提升 | 降低 |
| + Panel Judge | 提升 | 提升 | 降低 |
| + Deep Reasoning | 提升 | 提升 | 降低 |
| Finetuned Judge | 顯著提升 | 顯著提升 | 顯著降低 |

## 對我們的啟發
- [ ] 評測 LLM-as-a-Judge 不應僅依賴與人類標註的一致性，應同時衡量邏輯自洽性——這為評測框架設計提供了新的方法論基礎
- [ ] Situational preference 現象揭示了 LLM 評審的脆弱性本質：明確的評分標準（rubric）是提升一致性的最有效手段，這對實際部署評測系統有直接指導意義
- [ ] 人類標註的不一致性（約 25% 困難案例）挑戰了將人工標註視為黃金標準的假設，未來評測研究應探索混合式或無監督的品質控制方法

## 限制與未來工作

Sage 目前僅針對文本生成品質的評審場景驗證，對於程式碼評測、多模態評審等特殊場景的適用性尚未驗證。全局一致性的計算需要大量成對比較，計算成本隨候選數量二次增長。此外，650 個問題的資料集規模仍有限。
