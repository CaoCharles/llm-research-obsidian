# The Dual-Tier Sentiment Framework: Scalable Multimodal UX Attribution in Web Search

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.27899)
- 📥 [PDF](https://arxiv.org/pdf/2611.27899v1)

## 摘要（中文翻譯）

大規模 Web Search 要維持使用者體驗（UX）品質，需要可擴展的評估方法。傳統問卷耗時且限制快速 A/B 測試；自動化指標則通常缺乏診斷視覺與空間 UX 異常的細緻度。本文提出 Dual-Tier Sentiment Framework，一種自動化 UX attribution 架構。Tier 1（Macro System）以基於 Gemini XS 的 fine-tuned encoder-decoder LLM 處理 telemetry features，作為可擴展的使用者情緒 regression detector；在超過 500,000 筆留出資料上，PR-AUC 提升 9.8%，並在 12 個留出實驗中維持 baseline recall、相對 precision 提升約 20%。Tier 2（Micro System）使用 Gemini 3.0 Pro 的 Multimodal LLM 評估網頁結果區塊的視覺呈現與空間布局，以 User Toil 量化抵達滿意結果所需的估計努力。結合 RL-based prompt optimization 與 AI judge 後，F1 提升超過 6.5%。框架每日處理約 O(100k) 個 live experiment queries，將測量延遲由數週縮短至數小時，並降低問卷負擔超過 40%。

## 問題背景

論文聚焦於大規模 Web Search A/B 實驗中的 UX attribution。人工問卷可反映主觀滿意度，但速度慢、具評分者雜訊與回應偏差，無法支援高頻實驗。點擊等 telemetry 能提供整體監控，卻難以解釋視覺布局、結果區塊與瀏覽流程造成的摩擦；傳統 DOM 啟發式指標也無法辨識語意與視覺上的細微差異。因此，問題是如何同時取得可擴展的全頁 regression detection 與可診斷的多模態、細粒度 UX 評估。

## 解決方案

作者提出平行運作的 Dual-Tier Sentiment Framework，並以雙重 launch gate 作為決策規則。Tier 1 Macro System 使用 survey-calibrated、dual-head 的 Gemini XS encoder-decoder LLM，從 lexical context、quantitative metadata 與 aggregate user interactions 預測全頁 sentiment regression；decoder 的 CoT distillation 只在訓練時提供 regularization。Tier 2 Micro System 使用 Gemini 3.0 Pro 評估 rendered SRP、query intent 與 landing-page context，計算結果區塊及整頁的 User Toil。其創新包括以 AI-as-a-Judge 協助 SxS 標註與錯誤分析，以及以 RL Mentor-Student 框架自動最佳化 prompt。只有 Tier 1 無全頁退化且 Tier 2 顯示細粒度改善時，實驗才通過。

## 核心貢獻
1. 提出 Dual-Tier Sentiment Framework，以 Macro System 的全頁 sentiment safeguard 與 Micro System 的視覺 UX diagnostics 共同構成嚴格的雙條件 launch gate，支援約 O(100k) queries/day。
2. 提出基於 Gemini XS 的 dual-head encoder-decoder Macro System，結合 telemetry feature engineering、多任務學習與 CoT distillation，在留出資料上相對 baseline 提升 9.8% PR-AUC，並降低測量延遲與問卷負擔。
3. 建立以 Gemini 3.0 Pro、AI-as-a-Judge、SxS human annotation 與 RL Mentor-Student prompt optimization 為核心的 Micro System，透過 pixel bounding boxes、query intent 與 landing-page context 評估 User Toil。

## 技術方法

Tier 1 以 11 個 A/B 實驗資料訓練，並在模型 checkpoint freeze 後的 12 個未見實驗、超過 500,000 筆 control/treatment records 上測試。模型由 encoder 分類 Regression/No Regression，decoder 生成由 teacher model 蒸餾的 CoT rationale；輸入包括 query、廣告標題與 organic snippets（TEXT）、addensity、commercial load、match types 和 UI layout configuration（QF），以及 click-through rate、post-click abandonment 等 aggregate user signals（UF）。主要指標為 PR-AUC，並在操作 gating threshold 下以 experiment-level precision/recall 評估。Tier 2 先從 live traffic 取樣 SRP、標註各 result block 的 pixel bounding boxes，再加入 rendered visual context、Refined Query Intent 與 landing-page summary。MLLM 對每個區塊評估 intent alignment、semantic relevance 與 visual clarity，輸出四級 ordinal satisfaction 及 rationale。User Toil 將首次 Very Satisfied 結果前各區塊的 pre-click scanning effort 與 post-click friction penalty 加總；數值權重由歷史 timing distributions 校準，屬 ordinal penalty 而非實際秒數。人類雙重標註、專家 adjudication、AI Judge 的 SxS loss analysis 與獨立 First-Result survey 用於對齊和驗證。RL Mentor 逐 token 產生 prompt，凍結 Student，透過含 KL regularization 的 reward 在離線資料上最佳化，最後以 deterministic greedy decoding 部署。

## 關鍵結果

|---|---|---|
| Tier 1 PR-AUC ablation | 僅 TEXT | 參考基線；論文未報告絕對 PR-AUC |
| Tier 1 PR-AUC ablation | TEXT + decoder CoT + teacher CoT | 相對 baseline 提升 2.0% |
| Tier 1 PR-AUC ablation | TEXT + QF | 相對 baseline 提升 5.1% |
| Tier 1 PR-AUC ablation | TEXT + QF + UF | 相對 baseline 提升 9.8% |

## 對我們的啟發
- [ ] 若產品評估同時需要高召回的整體護欄與可操作的根因診斷，可將低成本 telemetry 模型作為第一層篩選，再對必要樣本啟用高成本多模態分析。這是基於本文架構的實務建議。
- [ ] 對主觀 UX 評估，應明確分離模型效能驗證與標註品質改善：本文以獨立人類標註、AI Judge 的錯誤分群及外部 real-user survey 進行對齊，顯示 prompt 優化不能只依賴單一自動評分來源。
- [ ] User Toil 適合被視為經校準的 ordinal decision metric，而不是直接測得的秒數；實務部署時應同步檢查 penalty weighting、query intent 與頁面布局變化造成的分布漂移。

## 限制與未來工作

Tier 2 的 rendering 與 MLLM inference 成本高，目前只能以非同步 batch 支援 A/B launch gating。實驗主要涵蓋美國 mobile traffic，尚未完整驗證多欄 desktop layout 與非美國地區。survey denoising 仍可能受 filtering criteria 影響；目前亦主要評估 static rendering，互動式 carousel、dynamic filter 與 video preview 的多狀態 UX 尚待研究。
