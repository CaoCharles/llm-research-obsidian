# ARB: A Matched Authorship-Rewriting Benchmark Dataset for AI-Text Detector Evaluation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.29539)
- 📥 [PDF](https://arxiv.org/pdf/2607.29539v1)

## 摘要（中文翻譯）

標準的 AI-text detection benchmark 通常比較 human-written text 與由大型語言模型（LLM）直接生成的文字。雖然既有研究顯示 rewriting 與 paraphrasing 會降低 detector 效能，但傳統 benchmark 的結果是否能預測「人類撰寫內容經 LLM 改寫」時的 detector 行為，仍不明確。作者提出 Authorship-Rewriting Benchmark（ARB），以 XSum、WritingPrompts 與 OpenWebText 各 600 篇、共 1,800 篇 human source texts，以及四個 open-weight generators 建立配對資料。每個來源產生 HUMAN、FREE-LLM、H2L 與同生成器 LLM2L 四種變體。五個 detectors 在 1% false-positive rate 下評估。FastDetectGPT 與 Binoculars-falcon-7b 對直接生成文字的 recall 為 91.2% 與 93.5%，但對人類文字經 LLM 改寫的 H2L 僅 30.8% 與 15.1%；相對地，LLM2L 仍保有 78.3% 與 83.0% recall。結果顯示，傳統 human-vs.-LLM benchmark 會高估 detector 對人類來源、LLM-mediated writing 的可靠性。

## 問題背景

現有 AI-text detection benchmark 多將問題簡化為 HUMAN 對 FREE-LLM，因而混淆 content origin 與 final linguistic surface。真實寫作常是人類先產生內容，再由 LLM 進行潤飾、改寫或摘要；此類 H2L 文字可能不具備直接生成文字的可偵測訊號。既有 paraphrase 研究雖證明改寫會削弱 detector，卻未直接回答傳統 benchmark 的效能是否能轉移至 matched、human-origin 的 LLM-mediated writing。

## 解決方案

作者提出 ARB 及 benchmark-transfer 評估框架，以同一 human source item 建立四種 matched regime：HUMAN、FREE-LLM、H2L 與同生成器的 LLM2L。FREE-LLM 提供傳統 direct-generation baseline；H2L 測試 human-origin content 經 LLM 改寫；LLM2L 則控制 content origin 為 LLM、只加入第二次 LLM rewriting。透過 shared HUMAN reference、dataset×generator paired comparisons、低 FPR 指標及分層分析，作者可區分來源內容、改寫表面與轉換強度的影響，而不是把所有 rewritten text 視為同一攻擊類別。

## 核心貢獻
1. 提出 benchmark-transfer framing，將 content origin（human 或 LLM）與 linguistic surface（原始文字、直接生成或 LLM 改寫）分離評估。
2. 建立包含 HUMAN、FREE-LLM、H2L、LLM2L 的 matched four-regime ARB dataset，涵蓋三個英文領域、四個 open-weight generators 與 1,800 個 human source items。
3. 以 dataset×generator matched blocks、paired deltas、macro-averaging、bootstrap confidence intervals 及主要指標 TPR@1%FPR，證明直接生成 benchmark 的效能不會均勻轉移至 H2L。

## 技術方法

ARB 從 XSum、WritingPrompts 與 OpenWebText 的 training split 取樣，每個資料集依 150–220、221–350、351–500 whitespace-delimited words 三個長度區間各抽 200 篇，共 1,800 篇 HUMAN source texts。每篇 source 與四個 generators 配對：Llama-3.2-3B-Instruct、Qwen2.5-7B-Instruct、Mistral-7B-Instruct-v0.3、Gemma-2-9B-it，形成 7,200 個 source-item×generator matched blocks。HUMAN 保留原文；FREE-LLM 根據資料集特定 topic 直接生成；H2L 將完整 human text 以 meaning-preserving rewrite prompt 改寫；LLM2L 則由產生 FREE-LLM 的同一模型進行第二次 rewrite。生成時使用 bfloat16、do_sample=True、temperature=0.7、top_p=0.9、top_k=40、max_new_tokens=512，並固定 random seed 42。評估五類 passive detectors：FastDetectGPT、Binoculars-falcon-7b、RADAR、BERT-Defense 與 RoBERTa-Defense；配置固定，不依 ARB labels 或 regime-specific 結果調參。主要指標是固定 1% FPR 的 TPR@1%FPR，並以 AUROC 作為 global ranking separability 的補充指標。分析在 dataset×generator block 內計算 target-minus-baseline paired deltas，再進行 macro-averaging，並使用 bootstrap confidence intervals；同時分析 detector、dataset 與 generator 的異質性及文字轉換特徵。

## 關鍵結果

論文主要結果如下（主要指標為 TPR@1%FPR）：

| Detector | FREE-LLM | H2L | LLM2L | FREE-LLM→H2L 變化 |
|---|---:|---:|---:|---:|
| FastDetectGPT | 91.2% | 30.8% | 78.3% | 約下降 60 個百分點 |
| Binoculars-falcon-7b | 93.5% | 15.1% | 83.0% | 約下降 78 個百分點 |
| RADAR | 66.8% | 12.2% | 論文摘要未報告具體數字 | 約下降 55 個百分點 |
| BERT-Defense | 低於 3% | 低於 3% | 低於 3% | 全部 regime 均低於 3% |
| RoBERTa-Defense | 低於 3% | 低於 3% | 低於 3% | 全部 regime 均低於 3% |

作者另報告 H2L 的 AUROC 與 TPR@1%FPR 存在 dataset×generator heterogeneity；完整分塊數值見論文 Figures 6–7。論文未在提供內容中報告所有 detectors 與所有 regime 的完整 aggregate AUROC 數字。整體結論是：H2L 的 detector recall 顯著低於 FREE-LLM，而同生成器 LLM2L 的下降幅度較小，顯示困難度與 content origin 及 transformation strength 都有關。

## 對我們的啟發
- [ ] 實務部署 AI-text detector 時，不應只依賴 human-vs.-direct-LLM 的 benchmark 分數；教育、新聞與組織寫作應額外測試人類草稿經 LLM polishing 或 rewriting 的情境。
- [ ] 低 false-positive operating point 對高風險應用尤其重要；應同時報告 TPR@1%FPR 與 AUROC，而非只使用整體 ranking 指標。
- [ ] ARB 的四種 regime 可作為後續 detector 開發與稽核的測試模板，並應依 detector family、dataset domain 與 generator model 分層呈現結果。

## 限制與未來工作

研究僅涵蓋英文、三個來源資料集與四個 open-weight instruction-tuned generators，結果不應直接泛化至 closed-source models、其他語言或更多真實 co-writing workflow。H2L 與 LLM2L 由固定 prompt、temperature 0.7、top-p 0.9 等設定產生，未涵蓋人類實際編修及 adaptive attacks。資料亦保留少量短文本、拒答、非英文與重複輸出。
