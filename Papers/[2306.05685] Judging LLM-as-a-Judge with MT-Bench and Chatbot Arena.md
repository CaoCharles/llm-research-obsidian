# Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena

## 摘要（中文翻譯）

評估基於大型語言模型（LLM）的對話助手極具挑戰性，因其能力廣泛且現有基準測試難以衡量人類偏好。本文探索使用強大的 LLM 作為評審（judge）來評估模型在開放式問題上的表現。作者系統性地檢視了 LLM-as-a-Judge 的使用方式和局限性，包括位置偏差（position bias）、冗長偏差（verbosity bias）和自我增強偏差（self-enhancement bias），以及有限的推理能力，並提出相應的緩解方案。透過引入兩個基準測試——MT-Bench（多輪問答集）和 Chatbot Arena（群眾外包對戰平台）——驗證 LLM 評審與人類偏好的一致性。結果顯示，GPT-4 等強大 LLM 評審與人類偏好的一致率超過 80%，達到人類評審間的相同一致水平。因此，LLM-as-a-Judge 是一種可擴展且可解釋的人類偏好近似方法。

## 問題背景

基於 LLM 的對話助手能力日益廣泛，但現有基準測試（如 MMLU、HellaSwag）主要測量封閉式問題的準確率，無法有效衡量開放式對話中的人類偏好。人工評估雖然可靠但成本極高且難以擴展，這構成了 LLM 評估的核心瓶頸。需要一種可擴展、可重現且與人類偏好高度一致的自動化評估方案。

## 解決方案

提出 LLM-as-a-Judge 範式，使用 GPT-4 等強大模型作為自動評審，並設計兩個互補的基準測試：(1) MT-Bench——包含 80 道高品質多輪問題，涵蓋 writing、roleplay、reasoning、math、coding、extraction、STEM、humanities 等 8 個類別，每題設計兩輪對話以測試多輪能力；(2) Chatbot Arena——開放式群眾外包對戰平台，使用者與兩個匿名模型同時對話並投票選出較好的回應，採用 Elo 評分系統排名。同時系統性分析和緩解 LLM 評審的偏差問題。

## 核心貢獻
1. 系統性分析 LLM-as-a-Judge 的三類偏差（position bias、verbosity bias、self-enhancement bias），並提出具體緩解策略（如交換位置取平均、few-shot 校準）
2. 設計 MT-Bench 多輪基準測試和 Chatbot Arena 群眾外包平台，驗證 GPT-4 作為評審與人類偏好一致率超過 80%，與人類間一致率相當
3. 公開 3K 專家投票和 30K 對話資料集，建立 LLM 自動評估的方法論基礎，推動後續 LLM-as-a-Judge 相關研究

## 技術方法

**LLM-as-a-Judge 框架**：設計三種評審模式——pairwise comparison（兩兩比較）、single answer grading（單一評分）和 reference-guided grading（參考答案引導評分）。以 GPT-4 為主要評審模型，也測試了 Claude、GPT-3.5 等作為替代評審。

**偏差分析方法**：(1) Position bias——將兩個回答交換位置，觀察評審判斷是否改變；(2) Verbosity bias——分析評審是否傾向選擇較長回答；(3) Self-enhancement bias——測試 LLM 是否傾向為自己生成的回答給出更高分。提出緩解方案：交換位置取平均、few-shot 示範、chain-of-thought 推理。

**MT-Bench 設計**：80 道多輪問題，每題 2 輪對話，涵蓋 8 個類別。評分採用 1-10 分制，由 GPT-4 逐一評分。

**Chatbot Arena 設計**：開放式平台，使用者匿名與兩個模型對話後投票。採用 Elo rating system 計算模型排名，收集超過 30K 對話。

**一致性驗證**：比較 LLM 評審與人類專家（3K 投票）及群眾外包偏好的一致率，以 Cohen's Kappa 和 agreement rate 為指標。同時與傳統基準（MMLU 等）進行互補性分析。

## 關鍵結果

| 指標 | 結果 |
|------|------|
| GPT-4 與人類專家一致率 | >80%（與人類間一致率相當） |
| Claude 作為評審一致率 | 略低於 GPT-4，但仍具參考價值 |
| GPT-3.5 作為評審 | 存在較明顯偏差，不建議作為主要評審 |
| Position bias 影響 | 交換位置後部分判斷會改變，交換取平均可有效緩解 |
| MT-Bench 問題數 | 80 題 × 2 輪 = 160 輪對話，涵蓋 8 類別 |
| Chatbot Arena 資料量 | 30K+ 對話，3K 專家投票 |
| 與傳統基準互補性 | MT-Bench/Arena 排名與 MMLU 等傳統基準存在差異，兩者互補 |

## 對我們的啟發
- [ ] LLM-as-a-Judge 為 LLM 評估提供了可擴展的解決方案，但必須注意三類偏差的存在。在實際應用中，建議採用交換位置取平均的策略來緩解 position bias，這是成本效益最高的緩解手段
- [ ] MT-Bench 的多輪設計理念值得借鑑：單輪評測無法反映模型的上下文理解和指令跟隨能力，多輪問答能更有效區分模型的真實對話品質
- [ ] Chatbot Arena 的群眾外包 Elo 排名系統提供了最接近真實使用場景的評估信號，可作為自動評估方法的校準基準。在設計內部模型評估流程時，可結合自動評審和小規模人類評估進行交叉驗證

## 限制與未來工作

LLM-as-a-Judge 在需要精確推理的數學和編程問題上表現較弱，存在無法完全消除的系統性偏差。Chatbot Arena 的使用者群體可能不代表一般用戶，且 Elo 排名的穩定性依賴足夠的對戰數量。評審模型本身的更新可能影響評估的一致性和可重現性。
