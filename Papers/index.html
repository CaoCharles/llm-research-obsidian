    確保 LLM 不會生成有害、偏見或危險的內容。包括防止模型被濫用、避免輸出有毒內容、以及保護用戶隱私。

    提示注入 (Prompt Injection)

    攻擊者通過惡意輸入操縱 LLM 的行為，繞過安全限制或竊取資料。類似於傳統的 SQL 注入攻擊。

    對齊 (Alignment)

    讓 LLM 的行為符合人類意圖和價值觀。確保模型「做人類想要的事」而不是「字面上被要求的事」。

    幻覺 (Hallucination)

    LLM 生成與事實不符或虛構內容的現象。模型可能「一本正經地胡說八道」，生成看似合理但實際上錯誤或不存在的資訊。

    arXiv ID 論文標題
    2602.04731 Less Finetuning, Better Retrieval: Rethinking LLM Adaptation for Biomedical Retrieval
    2602.03507 Learning to Reason Faithfully through Step-Level Faithfulness Maximization
    2602.03263 CSR-Bench: A Benchmark for Evaluating the Cross-modal Safety and Reliability of MLLMs
    2602.02290 Hallucination or Creativity: How to Evaluate AI-Generated Scientific Stories

    忠實度 (Faithfulness)

    生成內容是否忠於來源資料。在 RAG 系統中尤為重要——模型應該基於檢索到的資料回答，而不是編造。
