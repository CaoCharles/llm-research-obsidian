# A Survey on Evaluation of Large Language Models

## 摘要（中文翻譯）

大型語言模型（LLMs）在學術界和產業界日益普及，其在各種應用中展現出前所未有的性能。隨著 LLMs 在研究和日常使用中扮演越來越重要的角色，對其評估變得日益關鍵——不僅在任務層面，更在社會層面以更好地理解其潛在風險。本文從三個關鍵維度對 LLM 評估方法進行全面綜述：評估什麼（what to evaluate）、在哪裡評估（where to evaluate）、如何評估（how to evaluate）。首先，從評估任務的角度提供概覽，涵蓋一般自然語言處理任務、推理、醫療應用、倫理、教育、自然與社會科學、Agent 應用等領域。其次，深入探討評估方法和基準測試。接著總結 LLMs 在不同任務中的成功和失敗案例。最後，揭示 LLM 評估未來面臨的若干挑戰。

## 問題背景

LLMs 的快速發展使評估工作面臨前所未有的挑戰：評估維度從單一任務性能擴展到社會影響，應用場景從傳統 NLP 延伸到醫療、教育、科學等專業領域，評估方法從靜態基準測試發展到動態人機互動評估。現有文獻缺乏一個系統性的綜述來整合這些分散的評估研究，為研究者提供完整的評估知識圖譜。

## 解決方案

提出「What-Where-How」三維評估框架：(1) What——系統化梳理 LLM 需要評估的能力維度，從傳統 NLP 到推理、倫理、Agent 等新興領域；(2) Where——整理主流評估基準和資料集，包括 MMLU、BIG-Bench、HELM、HumanEval 等；(3) How——歸納自動評估、人工評估、LLM-as-a-Judge 等多種評估方法論。此外，通過成功與失敗案例分析，揭示 LLMs 的真實能力邊界，並提出未來評估的關鍵挑戰。

## 核心貢獻
1. 建立首個涵蓋「What-Where-How」三維度的 LLM 評估綜述框架，系統化整合超過 10 個評估領域的研究進展
2. 全面梳理 LLMs 在各領域的成功案例（如文本生成、翻譯、程式碼生成）和失敗案例（如數學推理、事實一致性、倫理偏見），為研究者提供能力邊界的清晰認知
3. 識別 LLM 評估的未來關鍵挑戰，包括動態評估、robustness 評估、社會影響評估等方向，為後續研究提供路線圖

## 技術方法

**文獻綜述方法**：系統性收集和分析 LLM 評估相關文獻，按三維框架組織：

**What to evaluate（評估任務維度）**：
- 傳統 NLP 任務：sentiment analysis、text classification、NER、QA、summarization、machine translation
- 推理能力：mathematical reasoning、logical reasoning、commonsense reasoning
- 專業領域：medical（MedQA、PubMedQA）、legal、education
- 倫理與安全：bias detection、toxicity、fairness、misinformation
- 自然與社會科學：scientific QA、social understanding
- Agent 應用：tool use、planning、interactive decision-making

**Where to evaluate（基準測試）**：
- 綜合基準：MMLU、BIG-Bench、HELM、C-Eval、AGIEval
- 專項基準：HumanEval（coding）、GSM8K（math）、TruthfulQA（factuality）
- 動態基準：Chatbot Arena、AlpacaEval

**How to evaluate（評估方法）**：
- 自動評估：metric-based（BLEU、ROUGE、accuracy）、model-based（BERTScore、GPTScore）
- 人工評估：expert evaluation、crowdsourcing
- LLM-as-a-Judge：使用 GPT-4 等強大模型作為自動評審
- 對抗評估：adversarial testing、red-teaming

## 關鍵結果

| 評估維度 | 涵蓋範圍 | 代表性基準 |
|---------|---------|----------|
| 傳統 NLP | 情感分析、分類、QA、摘要、翻譯 | GLUE, SuperGLUE, SQuAD |
| 推理能力 | 數學、邏輯、常識推理 | GSM8K, ARC, HellaSwag |
| 程式碼生成 | 函數生成、程式修復 | HumanEval, MBPP |
| 醫療應用 | 醫學問答、臨床決策 | MedQA, PubMedQA |
| 倫理安全 | 偏見、毒性、事實性 | TruthfulQA, RealToxicityPrompts |
| 綜合評估 | 多任務多維度 | MMLU, BIG-Bench, HELM |
| Agent 應用 | 工具使用、規劃、互動 | WebShop, ALFWorld |
| 動態評估 | 即時人類偏好 | Chatbot Arena, MT-Bench |

## 對我們的啟發
- [ ] 三維評估框架（What-Where-How）提供了組織和設計 LLM 評估體系的實用方法論：在規劃新的評估計畫時，可先系統性盤點需要評估的能力維度，再選擇適當的基準和方法
- [ ] LLMs 在推理和事實一致性方面仍有顯著不足，這提示在部署 LLM 應用時，應特別針對這些弱項設計專項測試和防護機制（如 RAG 增強事實性、chain-of-thought 改善推理）
- [ ] 評估正從靜態基準轉向動態評估（如 Chatbot Arena），且社會影響評估（偏見、安全、倫理）的重要性日益提升。建構內部評估體系時，應同時包含自動化指標和人類評估的混合方案

## 限制與未來工作

作為綜述論文，主要是對現有研究的整理而非提出新方法。部分領域（如多模態 LLM 評估）在當時覆蓋不足。隨著 LLM 技術快速發展，部分基準和結論可能已不適用於最新模型。未提供統一的評估框架實作工具。
