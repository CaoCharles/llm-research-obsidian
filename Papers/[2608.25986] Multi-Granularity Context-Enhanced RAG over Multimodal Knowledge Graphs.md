# Multi-Granularity Context-Enhanced RAG over Multimodal Knowledge Graphs

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.25986)
- 📥 [PDF](https://arxiv.org/pdf/2608.25986v1)

## 摘要（中文翻譯）

Retrieval-Augmented Generation（RAG）廣泛用於減少 Large Language Models（LLMs）與 Multimodal Large Language Models（MLLMs）的幻覺問題；其中，基於 Knowledge Graph（KG）的 RAG 可提供結構化外部知識。近期研究進一步以 Multimodal Knowledge Graphs（MMKGs）支援 GraphRAG，使系統能整合多種模態。然而，現有 MMKG-RAG 通常先獨立處理不同模態，再進行融合，視覺資訊擷取與跨模態知識融合僅使用有限的文字脈絡，造成影像與文字間的語義落差。本文提出 Context-Enhanced MMKG（CEMMKG）建構框架，在 local 與 global 層級為影像加入互補文字脈絡。Local context 不僅包含鄰近文字，也納入語義相關句子；global context 則提供全文摘要，並進一步以多粒度 local context 捕捉不同細節層次。VisionHeavy 資料集實驗顯示，CEMMKG 能改善 MMKG-based RAG，且可整合至不同方法。

## 問題背景

論文聚焦於 document-derived、node-based MMKG 的建構問題。現有方法多將文字與視覺內容分開轉換成圖，再於後期融合；影像處理通常只使用位置上鄰近的文字片段，未能找出文件其他位置明確討論該影像的句子。這可能造成視覺知識擷取不完整、跨模態對齊效果不佳與影像—文字語義落差。論文因此探討應選取哪些文字、採用何種粒度，以及如何在 MMKG 建構不同階段有效使用脈絡。

## 解決方案

作者提出 Context-Enhanced MMKG（CEMMKG），為文件中的每個視覺元素建立多粒度文字脈絡。Local context 同時保留影像前後的 surrounding text，並從提及該影像 identifier 的句子建立三種替代粒度：reference sentence、reference paragraph 與 reference paragraph summary。Global context 則使用文件原始 abstract；若無 abstract，改以 LLM 產生全文 summary。核心創新是將脈絡設計與使用階段分離：Image2Graph 同時輸入完整 local 與 global context，協助 MLLM 產生更完整的視覺實體與關係；modality fusion 僅使用 local context，作為影像實體與文字實體對齊的補充證據。

## 核心貢獻
1. 提出 CEMMKG，多系統化定義視覺元素的 local 與 global textual context，並比較 reference sentence、paragraph 與 paragraph summary 等 local 粒度。
2. 提出 multi-stage context utilization：在 Image2Graph 階段使用完整 local/global context，在 modality fusion 階段使用聚焦的 local context，以分別支援視覺知識擷取與跨模態實體對齊。
3. 在 MMLongBench-Doc 的 VisionHeavy 子集上驗證方法，並將 CEMMKG 整合至 MMGraphRAG 與 RAG-Anything，顯示其跨不同 MMKG-based RAG 方法的適用性。

## 技術方法

輸入為多模態文件 D，先以 MinerU 擷取有序段落、句子及視覺元素，並從 caption 取得如 Figure 3 或 Table 2 的 identifier。對每個影像 Ii，建立 reference set Ri，收集全文中提及其 identifier 的句子。Local context 固定包含影像鄰近 text chunks，並在 reference sentence、reference paragraph、reference paragraph summary 三者中擇一；global context 使用原始 abstract，無 abstract 時由 LLM 摘要全文。為避免長脈絡降低模型利用率，作者限制 reference sites、分別設定 reference 與 global context 的長度上限，且 fusion 階段使用較少 reference。接著以 Image2Graph 模組計算 Gv_i=fv(Ii,Ci)，在該階段輸入完整 eCi={cLi,cG}；再將文字圖 Gt、所有視覺圖與 local contexts 一併送入既有 fusion 流程，由 LLM 判定候選實體對應關係。實驗使用 MMLongBench-Doc 的 VisionHeavy 子集，共 106 題；80.2% 可回答問題需要視覺資訊，43.2% 依賴跨頁資訊。比較 Direct Inference、MMGraphRAG 與 RAG-Anything，指標為 strict full-credit accuracy 與官方 soft accuracy。

## 關鍵結果

主要結果如下；表中數值為 strict full-credit accuracy / official soft accuracy（%）。

| 方法 | 額外 local context | global context | Overall |
|---|---|---|---:|
| Direct Inference | – | – | 11.32 / 11.32 |
| MMGraphRAG | – | – | 23.58 / 24.17 |
| CEMMKG + MMGraphRAG | Reference Paragraph | Doc-level | 22.64 / 22.64 |
| CEMMKG + MMGraphRAG | Reference Paragraph Summary | Doc-level | 31.13 / 32.82 |
| CEMMKG + MMGraphRAG | Reference Sentence | Doc-level | **34.91 / 36.84** |
| RAG-Anything | – | – | 28.89 / 36.18 |
| CEMMKG + RAG-Anything | Reference Paragraph | – | 28.89 / 34.49 |
| CEMMKG + RAG-Anything | Reference Paragraph Summary | – | 31.11 / 33.13 |
| CEMMKG + RAG-Anything | Reference Sentence | – | **35.56 / 41.12** |

在 MMGraphRAG 上，Reference Sentence 配合文件層級 context 整體最佳；相較 MMGraphRAG，strict accuracy 提升 11.33 個百分點，soft accuracy 提升 12.67 個百分點。完整 reference paragraph 反而低於原始 MMGraphRAG。視覺類型方面，reference sentence 使 Figure soft accuracy 由 6.25% 提升至 24.70%；reference paragraph summary 的 Table soft accuracy 為 26.46%，高於 MMGraphRAG 的 22.46%。Misc soft accuracy 則由 34.15% 提升至 54.01%。

## 對我們的啟發
- [ ] 實務上不應以「加入更多文字」直接取代脈絡選擇；實驗顯示完整 reference paragraph 可能因冗餘或弱相關內容而降低效能，應依任務採用適當資訊密度。
- [ ] 對長文件中的圖表，應以明確 mention 或語義關聯尋找跨頁描述，而非只擷取位置鄰近文字；這有助於補足影像的語義背景與文字對齊證據。
- [ ] 不同建構階段需要不同脈絡：視覺描述可使用 local 加 global 的廣泛資訊，實體融合則應使用較短且聚焦的 local context，以降低長上下文干擾。

## 限制與未來工作

研究只在 MMLongBench-Doc 的 VisionHeavy 子集、共 106 題上驗證，資料類型與視覺需求具有選擇性，泛化到其他文件與領域仍未由本文證明。實驗主要回報下游 QA accuracy，未提供 MMKG 的實體、關係或對齊品質指標，也未量化額外摘要與脈絡處理成本。
