# Non-penetrating World Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.27963)
- 📥 [PDF](https://arxiv.org/pdf/2611.27963v1)

## 摘要（中文翻譯）

本文研究互動式 video world models 如何避免物體穿透，並提出 NoPeBench 評估模型面對物理障礙時的反應。實驗顯示，現有開源模型皆無法可靠防止穿透；然而，模型已編碼可預測違規所需的資訊。作者發現 diffusion transformers（DiTs）的 hidden states 能預測候選動作是否會穿透障礙。基於此，NoPeWorld 在 frozen DiT hidden states 上訓練小型 prediction head，判斷候選動作是否安全；對不安全動作，選擇最能保留原始意圖的安全替代動作。跨六個 video world models，physical violation rate 平均由 74% 降至 16%，並可 zero-shot 泛化至開放域影像、第三人稱視角與移動障礙物。作者公開程式碼、NoPeBench、模型權重及專案頁面。

## 問題背景

現有互動式 video world models 多以 open-loop 方式依照 camera pose 或 key input 生成影片，沒有明確的場景幾何或 collision constraint，因此遇到要求直行撞向牆面等 out-of-distribution 指令時，可能穿過障礙、消除障礙或產生不合理軌跡。單純 prompt 幾乎無效；外部 depth estimator 雖能偵測障礙，卻需逐幀解碼與額外推論，且通常只能停止，無法保留使用者的滑行意圖。既有 benchmark 也多使用無碰撞路徑，難以直接衡量 non-penetration。

## 解決方案

作者提出 NoPeWorld，一個在不更新原始 video generator 的情況下，直接讀取 frozen DiT hidden states 的碰撞預防框架。其核心是以 Unreal Engine 幾何產生候選動作的 swept clearance、collision safety 與 intent labels，訓練少於 2M parameters 的 prediction head。推論時，head 為候選動作估計安全性、障礙距離及意圖分數；若原始動作安全便保留，否則從停止、縮短步伐及轉向等 34 個候選中，選擇安全且最接近原始意圖者。框架支援 collision mode 與 prediction mode，前者在目前 chunk 的初始 denoising state 判斷，後者利用前一 chunk 的 commit state 提前預測。

## 核心貢獻
1. 提出 NoPeBench，透過 ground-truth history、Unreal 幾何 closed-loop rollout 與 open-domain VLM evaluation，直接測試互動式 video world models 的 non-penetration 能力。
2. 提出 NoPeWorld，使用少於 2M parameters 的 prediction head 讀取 frozen DiT hidden states，預測安全性、障礙距離與使用者意圖，並以 safe collide-and-slide 候選替換不安全動作。
3. 實驗顯示 DiT hidden states 在影片 chunk 生成前已包含即將碰撞的資訊；方法跨六個 generator，並 zero-shot 泛化至開放域影像、第三人稱視角與移動障礙物。

## 技術方法

NoPeWorld 將每個 chunk 的動作選擇形式化為：在連續 swept path 上維持 signed obstacle gap 不小於安全 margin，並最小化候選動作與 collide-and-slide response 的 intent error。訓練資料來自 UnrealZoo 的 Unreal Engine 模擬；作者以 729 段影片、44 個訓練場景，在 frozen DiT 上進行 teacher forcing，對 34 個候選動作計算 clearance 與碰撞標籤。prediction head 從中深層 DiT tokens 取特徵，經 token projector、action conditioning 與兩個 cross-attention blocks，由 learned query 輸出 safety logit、clearance、intent score，並以 BCE、Huber、listwise KL 等損失訓練。推論時先以安全機率門檻建立可行集合；若原命令安全且意圖分數足夠則保留，否則選擇意圖分數最高的安全候選，無可行候選時停止。NoPeBench 分為三項任務：Task 1 在 ground-truth history 上評估單步決策；Task 2 在 Unreal 幾何上評估 closed-loop 影片；Task 3 以開放域影像、第一或第三人稱視角及靜態或移動障礙物進行 VLM 評估。主要指標包括 Missed、False、decision score、violation rate、Slide、Safe-Intent Score（SIS）及 Task 3 的 VLM violation rate。

| 六個模型、Task 2、NoPeWorld collision mode | 平均 violation rate 由 74% 降至 16%。 |

| HY-WorldPlay、Task 2 | Raw violation 86%、SIS 5；NoPeWorld Coll violation 15%、SIS 38；Pred violation 21%、SIS 43。 |
| Echo-WM、Task 2 | Raw violation 86%、SIS 11；NoPeWorld Coll violation 3%、SIS 44；Pred violation 5%、SIS 42。 |
| Evoke-Turbo、Task 2 | Raw violation 77%、SIS 8；NoPeWorld Coll violation 30%、SIS 27。Prediction mode 不適用。 |

## 對我們的啟發
- [ ] 對互動式生成模型而言，安全控制不一定需要重新訓練大型 generator；可先探測其 hidden states 是否已包含可用的物理或風險訊號，再以輕量控制 head 將資訊轉化為決策。
- [ ] 安全機制不應只追求停止或拒絕，也應建模使用者意圖；本文以候選動作排序與 collide-and-slide 投影，在降低違規的同時保留部分原始運動方向。
- [ ] 評測應同時區分單步決策、closed-loop rollout 與 domain-shift 情境，並加入無障礙控制路徑，以避免安全方法透過過度停止而取得表面上的低違規率。

## 限制與未來工作

訓練標籤依賴 Unreal Engine 幾何與 first-person、static UnrealZoo 場景；雖然作者報告可泛化至開放域、第三人稱與移動障礙物，仍未證明對所有真實世界場景或更複雜接觸的可靠性。候選動作集合固定為 34 個，且部分模型仍有較高違規率；Task 3 也依賴 VLM judges。論文提出接觸推、承載與破壞物體作為未來方向，但未提供其結果。
