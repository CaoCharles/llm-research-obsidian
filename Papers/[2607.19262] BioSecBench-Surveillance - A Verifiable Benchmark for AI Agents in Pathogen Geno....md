# BioSecBench-Surveillance: A Verifiable Benchmark for AI Agents in Pathogen Genomic Surveillance

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.19262)
- 📥 [PDF](https://arxiv.org/pdf/2607.19262v1)

## 摘要（中文翻譯）

隨著病原體 genomic surveillance 擴大，瓶頸正由資料產生轉向資料分析。本文提出 BioSecBench-Surveillance，一個可驗證的 benchmark，包含 100 項 evaluation，用以測試 AI agents 是否能根據 raw sequencing data 與 surveillance context 推斷正確分析流程。每項 evaluation 僅提供人類分析師可取得的資料與背景，並以 deterministic grader 評分 structured answer。任務涵蓋 taxonomic classification、variant detection、AMR、source tracking、toxin and virulence、genetic-engineering detection 與 anomaly detection，涉及多種樣本及 sequencing technology。3,962 次可評分嘗試顯示，最佳配置僅通過約一半；Opus 4.8/PI 與 GPT-5.5/Codex 均為 50.2%。錯誤多非工具選擇本身，而是 references、thresholds、filters 與 normalization 等周邊決策。

## 問題背景

Pathogen genomic surveillance 的資料量與樣本多樣性持續增加，但從 sequencing data 推導公共衛生決策仍依賴專家，難以擴展。現有 AI benchmark 多聚焦一般問答、程式修復、生物資訊特定領域，或僅測試資料庫檢索，未能驗證 agent 是否能自行選擇適當 workflow、tools、references、filters 與 thresholds，並產生正確 surveillance 結論。

## 解決方案

作者提出 BioSecBench-Surveillance，將真實 biosurveillance workflow 在決策前的狀態封裝成 100 個 evaluation。每項只提供人類分析師可取得的 sequencing data、reference files 與 context，不直接揭示正確 workflow；agent 必須自行選擇分析工具、資料庫、references、thresholds 與 filters，最後依指定 schema 回傳 JSON。作者以 validated gold-standard workflows 或文獻建立 ground truth，透過 domain-expert review 與 typed deterministic grader 驗證答案。核心創新在於把「是否執行正確分析」而非「是否能描述分析」作為評測目標，並可由 trajectory 分析診斷工具配置與結果解讀失敗。

## 核心貢獻
1. 提出包含 100 項 evaluation 的 BioSecBench-Surveillance，將 pathogen genomic surveillance 的實際分析決策轉化為可執行、可驗證的 agent benchmark。
2. 設計以 raw 或 near-raw sequencing artifacts、surveillance context 與 structured JSON answer 為核心的評測流程，並使用 typed deterministic grader 進行可重現評分。
3. 以 16 個 model–harness configurations、3,962 次可評分嘗試分析 agent 能力與失敗模式，指出正確工具之外的 references、thresholds、filters、normalization 及結果解讀是主要瓶頸。

## 技術方法

Benchmark 由 100 個 evaluation 組成，每項以單一 biosurveillance workflow 中、接近 surveillance decision 前的 empirical decision 為核心。輸入為 raw 或 near-raw sequencing artifacts，包括 FASTQ reads、assembled contigs 或 aligned reads，資料來自 NCBI SRA 或帶有已知 ground truth 的 simulated reads；檔案會移除 identifying metadata，ground truth 則依 validated gold-standard workflows 或文獻建立，並由 domain experts peer-review。任務涵蓋七類：variant detection、taxonomic classification、AMR characterization、source tracking、toxin and virulence characterization、genetic-engineering characterization 及 anomaly detection；並涵蓋 isolate、wastewater、clinical、agricultural、air、water 等樣本，以及 short-read、long-read、hybrid sequencing。模型並非固定架構，而是 model 與 inference harness 的配對；測試 16 個 configurations，使用 Claude Code、PI 或 OpenAI Codex 提供 prompt、工具與檔案存取。所有 agent 在相同 containerized sandbox 執行，預載 assemblers、aligners、taxonomic classifiers、variant callers 及 AMR/virulence databases，並可透過 internet 取得額外 references。每個 configuration 對每項 evaluation 執行三次。agent 須輸出指定 schema 的 JSON；grader 以 typed field checks 評估數值 tolerance、Jaccard set overlap、exact/normalized categorical match、multiple choice 或 per-key dictionary，並依明確 all-of 規則合併。每次 run 分為 correct、incorrect 或 refused；endpoint pass rate 為 correct/(correct+incorrect)，以排除 refused 的 gradable attempts 計算。95% confidence intervals 使用以 evaluation 為 sampling unit 的 Student-t intervals。

## 關鍵結果

| 比較面向 | 主要結果 |
|---|---|
| 整體配置 | 16 個 model–harness configurations；endpoint pass rate 約 14%–50%，平均 41% |
| 最佳配置 | Opus 4.8/PI：50.2%，95% CI 40.1%–60.3%，涵蓋 83 項 evaluations |
| 並列最佳 | GPT-5.5/Codex：50.2%，95% CI 40.8%–59.6% |
| 其他前段配置 | Opus 4.7/PI：49.6%；Sonnet 4.6/PI：48.6% |
| 任務類別 | Source tracking 50%；taxonomic classification 46%；anomaly detection 20%；genetic-engineering characterization 35% |
| 樣本類型 | Clinical 45%；isolate 44%；wastewater 37% |
| Sequencing technology | Short-read 41%；long-read 26% |
| Nucleic-acid target | DNA 39%；RNA 42% |
| Assay type | Shotgun 與 targeted 均約 40% |
| Refusal | 不同配置由 0% 至近三分之一；OpenAI 在 PI 為 27%–29%，在 Codex 為 8%–9% |

作者指出，各配置的難度排序大致一致；agents 通常會使用 validated tools，但在 references、thresholds、filters、normalization 或輸出解讀上犯錯。

## 對我們的啟發
- [ ] 實務部署不應只檢查 agent 是否呼叫了合理工具，還應記錄並驗證 reference database、threshold、filter、normalization 與 control 等關鍵參數。
- [ ] 評測結果顯示應針對 anomaly detection、genetic-engineering characterization 及 long-read data 設計額外測試與人工覆核流程，因其通過率明顯較低。
- [ ] benchmark 的 deterministic structured grading 適合驗證客觀分析決策；對於真實 surveillance 中的模糊判斷，仍需另建能處理多種合理答案的評測方法，並同步衡量 refusal。

## 限制與未來工作

任務在類別、樣本類型與 sequencing technology 間分布不均，aggregate score 因而偏重樣本較多的標籤。排除 refusals 的分母可能使高拒答配置看似受益，需搭配專門的 refusal evaluation。資料集完整版本受限存取。更根本的限制是 benchmark 僅納入具有單一客觀答案、可 deterministic grading 的任務，尚未涵蓋大量需要專業判斷的開放式 surveillance 分析。
