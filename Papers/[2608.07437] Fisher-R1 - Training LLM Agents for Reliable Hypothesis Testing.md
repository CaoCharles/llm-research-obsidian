# Fisher-R1: Training LLM Agents for Reliable Hypothesis Testing

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.07437)
- 📥 [PDF](https://arxiv.org/pdf/2608.07437v1)

## 摘要（中文翻譯）

可靠的假設檢定是許多實證科學主張的基礎。大型語言模型（LLM）agents increasingly automate this process，能夠檢查資料集、產生程式碼，並端到端完成分析。然而，作者發現它們經常犯下細微的推論錯誤：即使分析程式正確執行，仍可能因統計方法選擇不當而導致錯誤結論。現有 benchmarks 很少評估給定資料假設時，reported p-value 是否具有統計有效性，因此無法捕捉此類失敗。作者建立 P-Bench，包含 425 個來自 economics、biology 與 medicine 的開放式真實假設檢定任務；每項任務要求 agent 選擇方法、計算 p-value，並根據 scientific hypothesis 與 dataset 作出結論。此外，作者提出 Fisher-R1，一個以 synthetic tasks、supervised fine-tuning 與 reinforcement learning 訓練的 open-weight LLM agent。Fisher-R1-14B 在 P-Bench 上超越其 backbone，以及 GPT-5.4、DeepSeek-V4-Pro 等模型，較 DeepSeek-V4-Pro 的 single-trial success 平均相對提升 21%，最具挑戰任務最高提升 26%。結果顯示，現有 LLM agents 的統計推理仍不可靠，而具 verified statistical reward 的 reinforcement learning 能顯著提升可靠性。

## 問題背景

現有 LLM data-analysis benchmarks 多聚焦於程式可執行性、factoid answer 或 predictive performance，通常不檢查 statistical method 是否符合資料假設，也不核對 reported p-value 是否來自正確分析。因此，agent 可能執行無錯的 code，卻因忽略 outliers、non-normality、clustering 或模型設定而產生 false discovery。論文要解決的是如何可靠評估並訓練 agent 完成從方法選擇、分析執行到統計結論的完整 hypothesis-testing workflow。

## 解決方案

作者提出兩部分解決方案。第一，建立 P-Bench：將真實科學問題、資料集、可執行 R 分析與隱藏且專家審核的 answer key 結合，直接檢驗 method、p-value 與 reject/fail-to-reject decision。第二，訓練 Fisher-R1：以 synthetic data-generating processes 產生可驗證任務，先用高品質 expert trajectories 進行 SFT，再用 DAPO 執行 reinforcement learning。其核心創新是以實際統計結果而非僅語言相似度作為 reward，主要獎勵 p-value 的 z-space closeness，並以結論正確性與格式約束共同訓練，使模型學習檢查資料、選擇方法並使報告結果與執行分析一致。

## 核心貢獻
1. 提出 P-Bench：一個包含 425 個真實、可執行且由專家審核的開放式 hypothesis-testing tasks benchmark，涵蓋 economics、biology 與 medicine。
2. 提出 Fisher-R1 open-weight LLM agent，以 synthetic executable tasks、SFT 及 outcome-grounded reinforcement learning 訓練，直接強化統計推論可靠性。
3. 以 Raw 與 Strict 兩種指標區分結論方向正確與 p-value 數值也足夠接近，揭示 conclusion-only evaluation 會高估 LLM agent 的實際可靠性。

## 技術方法

P-Bench 每項任務提供 scientific question、CSV dataset 與 data/study description，但不指定統計方法；agent 在固定的 R execution sandbox 中以多輪 CodeAct/ReAct 形式探索資料、撰寫並執行程式，最後輸出 method、p-value、effect 或結論。425 項任務來自 economics papers、biology studies 與 Vanderbilt biostatistics teaching materials，涵蓋 17 類方法，包括 t-test、χ²、OLS、Fisher exact、Cox、IV/2SLS、mixed-effects、log-rank、Mann–Whitney、Tobit 與 probit。資料建構流程會重現 canonical reference analysis、記錄執行結果、移除無法重現的案例，並由統計與 biostatistics experts 審核；另加入 outlier、heteroskedasticity、clustered observations、missingness 等陷阱。Fisher-R1 以 Qwen2.5-Coder-7B/14B 為 backbone，先使用 Claude Sonnet 4.6 產生的 expert trajectories 進行 SFT，再在 8,642 個 synthetic executable tasks 上使用 DAPO RL。synthetic task 由 method、scenario、sample size、effect size、prompt style 與 random seed 組合生成，answer key 由 canonical method 實際執行所得。RL reward 要求輸出格式有效，並以 p-value 的 two-sided z-score closeness 給予 0.9 權重，以 conclusion correctness 給予 0.1 權重。評估每題取三次 rollout，報告 pass@1 與 pass@3；Raw 衡量結論方向，Strict 進一步要求 |z(p̂)-z(p*)|<0.5。

## 關鍵結果

主要結果如下；數值為 pass@1 / pass@3（百分比）。

| 模型 | P-Easy Raw | P-Easy Strict | P-Hard Raw | P-Hard Strict |
|---|---:|---:|---:|---:|
| GPT-5.4 | 92.9 / 95.6 | 64.7 / 73.4 | 58.3 / 68.0 | 30.5 / 39.2 |
| DeepSeek V4 Pro | 70.9 / 93.1 | 54.2 / 71.9 | 46.8 / 69.7 | 26.3 / 42.5 |
| Qwen-2.5-Coder-7B | 61.4 / 83.7 | 36.3 / 54.7 | 37.5 / 63.1 | 13.2 / 25.2 |
| Fisher-R1-7B | 87.0 / 96.6 | 65.7 / 74.9 | 63.4 / 82.4 | 30.6 / 44.1 |
| Qwen-2.5-Coder-14B | 78.5 / 88.2 | 41.4 / 49.8 | 51.5 / 66.7 | 23.7 / 33.3 |
| Fisher-R1-14B | **87.4 / 94.1** | **64.2 / 75.9** | **65.8 / 81.1** | **33.0 / 45.5** |

Raw 只要求 α=0.05 下 reject/fail-to-reject 結論正確；Strict 另要求 reported p-value 與標準答案的 two-sided z-score 差距小於 0.5。Fisher-R1-14B 在 P-Hard Strict pass@1 達 33.0%，高於 GPT-5.4 的 30.5% 與 DeepSeek V4 Pro 的 26.3%。對 7B backbone，P-Hard Strict pass@1 從 13.2% 提升至 30.6%。作者的 ablation 顯示 SFT 與 DAPO 結合在所有指標上最佳；論文未報告獨立的人類統計專家基準。

## 對我們的啟發
- [ ] 評估資料分析 agent 時，不應只檢查程式是否可執行或結論方向是否正確，還應核對統計方法、p-value 與資料假設是否一致。
- [ ] 對高風險科學與醫療工作流，可將 EDA、missingness、outlier、heteroskedasticity、clustering 等 assumption checks 設為 agent 的強制步驟，並保留完整 code trace 供人工覆核。
- [ ] 若能取得可程式化驗證的結果標籤，outcome-grounded reinforcement learning 可能比單純擴大模型規模更有效；但實務部署仍應將 agent 視為輔助與 oversight 工具，而非統計專家的替代品。

## 限制與未來工作

P-Bench 每項任務目前只評估單一 hypothesis test，尚未涵蓋多重檢定與 multiple-comparison correction。未來工作包括 multi-test pipelines、明確要求 agent 論證 assumptions、量化 method choice uncertainty，以及辨識不適合單一檢定的問題。作者也強調 Fisher-R1 不能取代 human statistical review。
