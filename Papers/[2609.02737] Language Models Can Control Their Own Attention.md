# Language Models Can Control Their Own Attention

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.02737)
- 📥 [PDF](https://arxiv.org/pdf/2609.02737v1)

## 摘要（中文翻譯）

Language Models 在長上下文中通常只將大部分注意力集中於少數 token，卻仍須讀取完整 KV cache 才能找出相關內容。例如，在 1M-token 對話中查詢早期細節時，每個回答 token 都可能觸發全域 context 掃描。既有方法以輕量 proxy score 預先選取相關 token，但此 extrinsic scoring 每步仍需 O(N) 掃描。本文提出 intrinsic 的 Declarative Attention（DA），要求模型在 chain-of-thought 中宣告其注意範圍，並分為 <global>（完整 context）、<focus>（指定區域）與 <local>（僅近期輸出）三種模式。推理引擎將宣告解析為類似 tool call 的控制訊號，跳過大部分 KV cache 讀取。在 15 個長上下文任務的 zero-shot 評估中，Gemma-4-31B 與 Qwen-3.6-27B 分別降低 52.0% 與 31.1% 的 decoding attended tokens，準確率僅下降 1.27 與 2.75 個百分點。結果顯示 DA 提供了新的 sparse attention 軸線，未來仍可透過訓練進一步改善。

## 問題背景

長上下文 decoding 的主要瓶頸之一是每一步都讀取完整 KV cache，即使真正影響輸出的 token 只占少數。固定 recency 或歷史 attention heuristic 難以預測 query-dependent 的相關內容；較新的 proxy scorer 雖能近似選取 mask，卻仍須每步對 O(N) context 進行掃描，無法完全消除選取成本。論文因此探討能否讓模型直接表達自身的注意範圍。

## 解決方案

作者提出 Declarative Attention（DA）protocol，將模型生成切分為注意範圍穩定的連續 reasoning spans，並以可解析標籤宣告模式。<global> 保留所有 context segment，用於導航與尋找相關區域；<focus magic_chunks="K"> 僅保留指定 magic chunk，用於擷取具體事實；<local> 不讀取 context，只依賴問題、既有輸出與已擷取資訊進行推理。推理引擎中的 DA state machine 監看標籤轉換，動態重寫 KV-cache block table，讓 attention kernel 跳過未宣告的區塊。核心創新是把 attention selection 從外部 scorer 移至模型生成的控制協定，從而取消每步額外的 O(N) 選取掃描。

## 核心貢獻
1. 提出不需額外 scorer 或參數更新的 Declarative Attention protocol，讓 off-the-shelf language models 以可解析生成標籤控制自身的 context 可見範圍。
2. 設計 global、focus、local 三模式、magic-chunk context delivery，以及可整合 vLLM 的 block-aligned KV-cache masking state machine，將模型宣告直接轉換為推理遮罩。
3. 在 15 個長上下文來源與六個模型上展示 zero-shot 的 cost-accuracy trade-off；大型模型可維持接近 Vanilla 的準確率，同時大幅降低 decoding attended tokens。

## 技術方法

實驗使用 Gemma-4-{31B,12B,E4B}、Qwen-3.6-27B 與 Qwen-3.5-{9B,4B}，主要比較 Gemma-4-31B 和 Qwen-3.6-27B；模型支援的輸入上限通常為 256K token，Gemma-4-E4B 為 128K。長文本以約 2,048 token 為目標切成 magic chunks，分割優先使用段落、換行、句末、子句與詞邊界；每個 segment 透過模擬 tool-use transcript 呈現，並保留完整、無損的文本分割。DA state machine 預設處於 global；解析到 focus 開啟標籤的結尾即只保留指定 chunk，local 則遮蔽所有 context segment，結束標籤後回到 global。遮罩以 vLLM 的 16–32 token block 為單位，透過 attention metadata hook 重寫 KV block table，未修改 FlashAttention kernel 或 scheduler；DA 僅作用於 global attention layers，不處理 sliding-window 或 Gated DeltaNet 等固定成本層。評估涵蓋 RULER、LongBench v1/v2、LooGLE 與 ZeroSCROLLS 的 15 個來源，最多每來源抽取 128 個樣本。比較 Vanilla、DA-no-mask（相同 DA prompt 但完整 causal attention）與 DA。準確率以 Gemini-3-Flash 產生 rubric，再由 thinking-enabled Qwen-3.5-4B 進行 binary LLM-as-a-judge 評分；效率以每回答 decoding 期間累計 attended KV positions 衡量，另以 MFU 40%、MBU 70% 的 roofline 分析估算 wall-clock time。

## 關鍵結果

主要結果如下（表中平均值為 15 個來源等權平均）：

| 模型與方法 | 準確率 | 每回答 attended tokens | 相對 Vanilla 的 token 變化 | 相對 Vanilla 的準確率變化 |
|---|---:|---:|---:|---:|
| Gemma-4-31B Vanilla | 87.01% | 13.43M | — | — |
| Gemma-4-31B DA-no-mask | 87.01% | 22.31M | +66.2% | 0.00pp |
| Gemma-4-31B DA | 85.74% | 6.45M | -52.0% | -1.27pp |
| Qwen-3.6-27B Vanilla | 85.31% | 22.54M | — | — |
| Qwen-3.6-27B DA-no-mask | 84.62% | 29.02M | +28.8% | -0.69pp |
| Qwen-3.6-27B DA | 82.56% | 15.52M | -31.1% | -2.75pp |

其他論文報告結果包括：Gemma 上 DA 相對 DA-no-mask 減少 71.1% attended tokens，Qwen 減少 46.5%；DA 在 Gemma 的單跨度與多跨度任務分別節省 54.8% 與 48.5%，Qwen 分別節省 29.7% 與 32.6%。Gemma 上 DA 在 15 個任務中的 7 個達到或超過 Vanilla，Qwen 則為 5 個；最明顯的單任務提升是 Gemma 的 longdep_qa（+3.1pp）與 Qwen 的 code_repo（+5.6pp）。Gemma 的 roofline 估計 decoding wall-clock 為 Vanilla 的 0.71 倍，Qwen 為 0.77 倍；這是理論估計而非實測時間。

## 對我們的啟發
- [ ] 在長上下文 RAG 或 agent tool-use 系統中，可將文件段落、對話輪次或工具回應作為可尋址 segment，讓模型先導航、再聚焦擷取、最後以 local mode 推理，降低反覆讀取整個 context 的成本。
- [ ] 評估長上下文系統時，不能只看準確率；應同時記錄 per-step KV 讀取、生成步數、模式分布與終止率，因為 DA 可能以較長輸出換取較低的每步注意力成本。
- [ ] 模型能力與 protocol adherence 密切相關；部署前應監測標籤可解析率、focus chunk 有效率與多跨度任務表現，並考慮以訓練或 constrained decoding 強化控制格式，而非直接假設 zero-shot DA 對小模型可靠。

## 限制與未來工作

DA 目前依賴模型遵循標籤語法、正確追蹤 chunk 邊界並在 focus 中擷取足夠資訊；小模型的 protocol adherence 與準確率明顯較差。多跨度推理、長文本切割破壞證據及輸出長度增加仍會造成失效。wall-clock 結果是採用固定 MFU/MBU 的 roofline 估計，非實際端到端測量，且未涵蓋 prefill。作者指出未來可透過 protocol-specific training、自然語義邊界與 thinking mode 支援改善。
