# Muslim: A Deployed Arabic Voice AI Platform for Grounded Islamic Knowledge

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.31511)
- 📥 [PDF](https://arxiv.org/pdf/2609.31511v1)

## 摘要（中文翻譯）

本文介紹 Muslim，一個已部署、面向真實使用者的阿拉伯語 voice AI 平台，提供有來源依據的伊斯蘭知識。系統採用 NeMo Arabic ASR、OpenAI-compatible LLM endpoint、自託管 TTS，以及透過六個 Model Context Protocol（MCP）伺服器路由的 deterministic multi-source retrieval layer。作者釋出 Muslim-6B-PRO（5.94B 參數工具路由 LLM）與 Fasih-TTS-V1（Modern Standard Arabic TTS）等模型，其中 Fasih-TTS-V1 在 Arabic TTS Arena 的 MSA 評比中，17 個系統總排名第 5、11 個 open-weight 系統中排名第 2。平台亦包含帳戶與用量管理、容量感知拒絕，以及針對 GPU agent 主機失效情境設計的三層 observability。實測結果包括 124 個案例中 98.4% 的 recitation-validation accuracy，以及 0.9–1.7 秒的端到端語音延遲。

## 問題背景

現有商業 voice assistant 對阿拉伯語支援有限，回答伊斯蘭問題時多依賴 parametric memory，缺少可驗證的來源引用；一般宗教參考網站雖具備 Qur’an 與 Hadith 的來源性，卻沒有即時語音互動與誦讀驗證。對於錯誤歸屬聖訓可能造成實際傷害的領域，單純生成式回答不足。論文因此聚焦於如何建立具 Arabic-first 語音能力、retrieval grounding、recitation validation，且能承受真實流量的部署系統。

## 解決方案

作者提出 MUSLIM 微服務平台：瀏覽器透過 WebRTC/LiveKit 連接 stateless voice agent，依序執行 VAD、Arabic ASR、LLM 與 TTS，並經由 MCP 呼叫六個知識伺服器。Tafsir 使用八本古典阿拉伯文獻的 deterministic JSON lookup；Hadith 伺服器自託管 17 個 collections、50,000 多則 narrations；Qur’anic audio 則直接串流真人誦讀，避免以 TTS 合成 Tajweed。平台另加入帳戶、rolling quota、capacity wall、heartbeat、錯誤回報與產品分析。核心創新不是單一模型，而是將來源受控的 retrieval、可部署語音管線、recitation validator 與 production reliability 機制整合為實際運行的 Arabic Islamic knowledge 服務。

## 核心貢獻
1. 提出並部署一套 Arabic voice AI 平台，整合 Arabic ASR、OpenAI-compatible LLM、self-hosted TTS，以及透過六個 MCP 伺服器執行的多來源、來源導向 retrieval。
2. 釋出 Muslim-6B-PRO 與 Fasih-TTS-V1 等 Arabic Islamic model artifacts，並報告 Fasih-TTS-V1 在 Arabic TTS Arena 與 SILMA benchmark 的結果。
3. 提出面向實際營運的帳戶與 metering、capacity-aware refusal，以及針對 GPU agent host 靜默失效的 heartbeat、錯誤回報與產品分析三層 observability 設計。

## 技術方法

系統採 hybrid deployment：web/account tier 使用 managed platform 與 managed Postgres，WebRTC media layer 使用 managed infrastructure；voice agent、GPU-dependent ASR/TTS 則運行於 operator-controlled host。語音流程以 Silero VAD 偵測語音結束，使用 NVIDIA NeMo Arabic FastConformer 進行 ASR，並在 trailing-silence 期間預先啟動 LLM inference，以重疊延遲；LLM 透過 OpenAI-compatible interface 接入，TTS 預設使用 Fasih-TTS-V1，並保留 cloud fallback。Muslim-6B-PRO 是以 QLoRA、4-bit NF4、rank 16 微調 5.94B 參數 Qwen3-architecture base，使用 2,731 筆 tool-calling／production-derived examples，面向 31 個工具的路由與 persona discipline。Fasih-TTS-V1 由 Coqui XTTS v2 以 1,297 段、約 2.4 小時 MSA 單一說話者語音微調，搭配 Arabic normalization、diacritization 與 chunking。recitation validator 採七步 Arabic normalization、2,290 組 Uthmani-to-Standard word mapping，以及四層 verse-matching search，不使用 LLM。評估包含 124-case validator accuracy、ASR 與 LLM latency、端到端語音延遲、30 個 held-out Islamic questions 的 retrieval success，以及超過 1,000 個自動化測試；論文未提供正式 expert-annotated faithfulness 或完整 user study。

## 關鍵結果

| 評估項目 | 結果 |
|---|---|
| Recitation validator | 122/124，98.4% accuracy |
| Qur’an verse ambiguity | 6,236 節中 16.5%（369 組）具有至少一個相同的四詞 normalized opening；83.5% 可無歧義解析 |
| ASR latency | 平均 235.5 ms；RTF 0.025，約為播放速度的 40 倍 |
| LLM first-token latency | 平均 519.7 ms |
| End-to-end voice latency | 語音結束至首次音訊回應約 0.9–1.7 秒 |
| Retrieval success | 30 個 held-out Islamic questions 中 100% 成功 |
| Retrieval latency overhead | retrieval-augmented 786 ms；parametric-only 736 ms；平均增加約 50 ms |
| Fasih-TTS-V1 Arabic TTS Arena | MSA 總排名第 5/17；open-weight 系統排名第 2/11；資料快照為 2026-08-18、245 場對戰 |
| Fasih-TTS-V1 SILMA benchmark | CER 1.3%；human-recording baseline 為 1.8% |
| 自動化測試 | 889 個 Python、119 個 TypeScript，合計超過 1,000 個測試 |

上述為作者報告的測量結果。論文未報告 Muslim-6B-PRO 的量化 benchmark，也未提供正式 RAG faithfulness、expert-annotated ground truth 或受控使用者品質研究。

## 對我們的啟發
- [ ] 對高風險知識領域，直接查詢可定位來源的 deterministic retrieval 能在特定 reference-addressable query 上降低複雜度，且本文測得相較 parametric-only 僅增加約 50 ms；但應明確界定 indexed corpus 的覆蓋範圍。
- [ ] 部署評測不應只檢查網站是否回應 200；當 web tier 與 GPU agent 分離時，應從 agent 向外發送 heartbeat，並將 liveness、例外錯誤與產品事件分層監測。
- [ ] 用量限制與容量拒絕可被視為可靠性與濫用防護的一部分；將硬性 turn limit 寫入 agent token，可在資料庫 usage report 失敗時維持限制，但 fail-open capacity check 仍需搭配獨立監控。

## 限制與未來工作

系統依賴單一 GPU host，故 voice agent 離線時無法對話；ASR 主要針對 Modern Standard 與 Quranic Arabic，方言表現未測。論文沒有 formal user study、expert-annotated faithfulness 評估或完整 RAGAS 結果；索引外問題可能退回 parametric knowledge。Muslim-6B-PRO 尚無量化 benchmark，TTS Arena 排名也會隨時間變動。
