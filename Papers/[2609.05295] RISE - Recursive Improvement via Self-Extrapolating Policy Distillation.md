# RISE: Recursive Improvement via Self-Extrapolating Policy Distillation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.05295)
- 📥 [PDF](https://arxiv.org/pdf/2609.05295v1)

## 摘要（中文翻譯）

On-policy distillation（OPD）能提供逐 token 的密集監督，但其效果受限於 teacher 品質：external teacher 會遭遇 distribution mismatch，而帶有 privileged conditioning 的 self-distillation 則受限於 in-context learning 能力。本文提出 RISE（Recursive Improvement via Self-Extrapolating Policy Distillation），直接從模型自身的 RLVR training trajectory 建構 synthetic teacher。RISE 在 parameter space 或 output logit space 外推 current checkpoint 與 trailing anchor 之間的 displacement，將由 outcome reward 產生的稀疏 parameter update 轉化為密集的 token-level target，不需 external model 或 privileged conditioning。RLVR 以可驗證 outcome reward 錨定正確 reasoning 方向，OPD 再細化 token-level decisions；teacher 於每輪更新，使 distillation 成為 recursive improvement，而非一次性壓縮。實驗涵蓋數學、多領域 STEM、程式生成及多輪 agentic tasks，RISE 均優於 RLVR-only 與 on-policy self-distillation。

## 問題背景

論文要解決的是 post-training 中 sequence-level reward 的 credit assignment bottleneck：RLVR、preference 或 accept/reject 訊號只告訴模型整段回應是否成功，無法指出各 token 應如何改進。OPD 雖能提供逐 token 分布監督，卻依賴高品質 teacher。External teacher 會因 student prefix 未見於 teacher 訓練分布而產生 distribution mismatch；privileged-conditioned self-distillation 則受限於模型的 ICL 能力，且 teacher 與 student 輸入不一致。

## 解決方案

RISE 將模型自身 RLVR trajectory 的改善方向視為未來較佳 policy 的近似。給定 anchor policy 與 RLVR 更新後 policy，在 representation space φ 中以 φ(πfuture)=φ(πanchor)+β(φ(πupdated)−φ(πanchor))、β>1 進行 extrapolation，再將此 synthetic teacher 的逐 token 分布蒸餾回 updated student。作者實作兩種版本：weight-space extrapolation 直接外推參數；logit-space extrapolation 外推 log probabilities，等價於對兩個 policy 做 geometric mixture。RLVR 負責以 verified reward 錨定方向，OPD 透過 token-level JSD 將外推方向轉為穩定更新；β 隨訓練遞減至 1，避免接近最佳點時 overshoot。

## 核心貢獻
1. 提出 RISE，從模型自身 RLVR training trajectory 外推 future teacher，消除 external teacher 與 privileged conditioning 的必要性。
2. 在統一 representation-map 框架下實作並比較 logit-space 與 weight-space extrapolation，並提出遞減 β 與 anchor dynamics 設計以控制 overshoot。
3. 在數學、多領域 STEM、程式生成及多輪 agentic tasks 上，以實驗、消融、多 seed 與 compute-matched 比較證明 RISE 相較 RLVR-only 和既有 OPSD 方法具有較佳表現或 sample efficiency。

## 技術方法

RISE 每輪包含兩階段。第一階段從目前 policy πθn 取樣 rollouts，以 outcome reward 計算 GRPO 類 policy-gradient update，得到 πθ′n+1；第二階段以 anchor 與該更新的 displacement 建構 future teacher，並從 πθ′n+1 開始以 OPD 最小化逐位置 Jensen–Shannon divergence。Logit-space 版本在每個 rollout position 取 post-RLVR policy 的 top-K token，加上 tail bucket，對 anchor 與 updated policy 的 log-probability 做外推並 cache teacher；預設 K=100，code 任務 K=20。Weight-space 版本使用 θfuture=θanchor+β(θ′n+1−θanchor)，在 OPD 時對其作 forward pass。teacher 全程 stop-gradient。β0 預設 1.2，採線性遞減至 1；anchor 可使用前一 checkpoint 或 EMA，Qwen 預設 η=0.1、OLMo 預設 η=1。OPD 重用 RLVR rollouts，因此不增加 sampling cost，但作者報告 wall-time overhead 為 1.3–1.6 倍。評估涵蓋 MATH500、AIME、AMC、Minerva、OlympiadBench、GPQA、IFEval、MMLU-Pro、TheoremQA、HumanEval+、MBPP+、LiveCodeBench、ALFWorld 與 WebShop，主要指標為 accuracy、avg@N、pass@N、agent success rate 及 WebShop score/accuracy。

## 關鍵結果

主要結果如下；數值為論文報告的 accuracy（%）、success rate 或 score。

| 設定與指標 | GRPO | RISE（logit） | RISE（weight） |
|---|---:|---:|---:|
| Qwen3-8B 數學 Math Avg | 60.0 | 62.5 | 62.7 |
| Qwen3-1.7B 數學 Math Avg | 45.4 | 50.2 | 49.2 |
| OLMo3-7B 數學 Math Avg | 47.6 | 56.4 | 53.7 |
| Qwen3-8B OOD Avg | 70.6 | 71.3 | 72.0 |
| OLMo3-7B OOD Avg | 51.2 | 55.5 | 53.7 |
| Qwen3-4B mixed Math Avg | 40.2 | 43.3 | 44.8 |
| Qwen3-4B mixed STEM Avg | 45.5 | 47.4 | 47.5 |
| ALFWorld success rate | 75.0 | 78.1 | 84.4 |
| WebShop WS-A | 63.3 | 68.0 | 74.2 |

細項亮點：OLMo3-7B 的 AIME’24 從 GRPO 30.2 提升至 RISE（logit）46.9（+16.7）；Qwen3-1.7B 的 AIME’24 從 30.0 提升至 36.3。多 seed 結果中，Qwen3-8B RISE（weight）Math Avg 為 62.4±0.2，GRPO 為 60.1±0.2；Qwen3-1.7B RISE（logit）為 49.6±0.4，GRPO 為 45.1±0.4。移除 RLVR 會導致 accuracy 崩潰、生成長度達 8K context cap；直接採用 θfuture 而移除 OPD 時，Qwen3-8B Math Avg 僅由 60.0 到 60.3，顯示穩定收益來自 RLVR grounding 與 OPD projection 的結合。

## 對我們的啟發
- [ ] 若只有 sparse outcome reward，可利用相鄰 checkpoint 的改善位移建構 dense token-level supervision；但必須讓方向由可驗證 reward grounding，不能單靠 self-distillation 反覆外推。
- [ ] Extrapolation 不宜採固定幅度：論文顯示接近訓練後期時 safe β range 會縮小，因此實務上應使用遞減 β，並依 RLVR update 的穩定性選擇 previous 或 EMA anchor。
- [ ] RISE 的收益不是單純採取更大的 parameter step；消融顯示 OPD 將外推 teacher 投影回 student 的 token 分布，是把改善方向轉為跨 benchmark 穩定收益的關鍵。

## 限制與未來工作

論文未提供更大模型、更多訓練 epoch 或更廣泛任務上的結果；外部 teacher OPD 也未納入直接比較，因其需要額外強模型。方法對 β、anchor rate、top-K 及模型訓練動態敏感，且 weight-space 版本需 materialize teacher、增加計算。安全性、長期遞迴穩定性與非 verifiable reward 情境仍未充分評估。
