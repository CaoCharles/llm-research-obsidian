# REFLECT: Role-Aware Detection of Sentiment, Emotion, Politeness, and Formality

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.13797)
- 📥 [PDF](https://arxiv.org/pdf/2610.13797v1)

## 摘要（中文翻譯）

在對話中偵測溝通意義，不僅需要建模詞彙內容，也需要建模 sentiment、emotion、politeness 與 formality（SEPF）所依賴的參與者角色結構。現有方法多使用 contextual language representations，卻將 semantic roles 保持隱性。本文提出 role-aware transformer architecture，將四種 SEPF 維度映射至具理論基礎的 Semantic Role Labeling（SRL）配置，並直接納入 transformer 的 self-attention。sentiment 與 emotion 使用非方向性的 role-aware attention；politeness 與 formality 則使用捕捉 initiator-to-recipient 關係的 directional role-aware attention。模型透過 learned gate 融合 role-aware 與 contextual representations。四個 benchmark 顯示，模型在 emotion、politeness 與 formality 上相較 BERT baseline 有統計可靠的提升；sentiment 改善幅度有限且不顯著。真實 mental-health 資料亦顯示其預測與模型 traceability 均有所改善。

## 問題背景

本文處理對話中的 sentiment、emotion、politeness 與 formality 偵測問題。既有方法通常將這些任務視為依賴詞彙內容的獨立分類或回歸問題，主要使用 contextual representations，未明確建模誰對誰、對何種事件採取行動等 semantic-role 結構。即使加入額外特徵，也多以缺乏理論依據的 auxiliary concatenation 實現，因此無法充分表達 internal states 與 external cues 在參與者關係上的差異。

## 解決方案

作者提出 REFLECT，一個將 theory-grounded Semantic Role Labeling（SRL）直接整合至 transformer self-attention 的 role-aware framework。sentiment 與 emotion 被視為以單一參與者為中心的 internal states，分別使用 PRED+ARGM 與 PRED+ARG1+ARGM 配置及非方向性 attention；politeness 與 formality 被視為參與者互動形成的 external cues，分別使用 ARG0→ARG2+ARGM 與 ARG0→ARG1 配置及 directional attention。模型不是把角色向量單純附加至輸入，而是透過 learned gate 自適應控制 role-aware representation 對 BERT 表徵的更新程度，並保留可追溯的角色基礎解釋。

## 核心貢獻
1. 提出將 SEPF 維度映射至具理論依據之 SRL 配置的方法，區分 internal states 與 external cues，並將角色結構視為溝通意義的核心表示。
2. 設計 role-aware attention 與 directional role-aware attention，將角色配置直接納入 transformer attention，並以 gated fusion 自適應整合角色表徵與 BERT contextual representation。
3. 在 GoEmotions、Holistic Politeness 與 GYAFC 等 benchmark 及 EMA mental-health 資料上評估，顯示 emotion、politeness 與 formality 的改善，並提供與模型實際角色表徵相連的 traceable explanation 方式。

## 技術方法

REFLECT先以 BERT-based SRL framework 為輸入句建立 semantic frames、predicate 與角色標註。對 internal states，sentiment 使用 {PRED, ARGM}，emotion 使用 {PRED, ARG1, ARGM}；模型對每個 frame 中屬於指定角色的 token 做 masked mean pooling，再以 [CLS] 表徵作 query，對角色向量計算 role-aware attention，並以 role-existence mask 排除未實現角色。對 external cues，politeness 使用 ARG0→ARG2+ARGM，formality 使用 ARG0→ARG1；模型保留 frame-level token 結構，加入 role-indicator 與 predicate-relative position embeddings，經 BiLSTM contextualization 後，以 ARG0 平均表徵作 source query，對指定 target-role positions 做 directional attention。各 frame 的結果再聚合為 utterance-level role representation，與 BERT global representation 以 feature concatenation 或 gated residual fusion 合併；gate 由兩種表徵共同計算，最後接 linear 或 MLP prediction head。資料方面，internal-state 實驗使用 GoEmotions；sentiment 合併為 positive、negative、neutral、ambiguous 四類，emotion 保留原始類別。politeness 使用 Holistic Politeness，預測 0–4 連續分數；formality 使用 GYAFC，作二元分類。評估指標分別為 macro-F1、Pearson’s r 與 F1，並使用 McNemar’s test 比較配對正確性。另以 1,924 則 EMA mental-health 訊息及 14 種自陳情緒評分進行應用研究。

## 關鍵結果

主要結果如下（作者以單一 random seed 42 的訓練執行報告）：

| 任務 | 最佳模型設定 | BERT baseline | REFLECT 最佳結果 | 統計結果 |
|---|---|---:|---:|---|
| Sentiment，Macro-F1 | Feature concatenation + linear | 0.6594（MLP） | 0.6695 | McNemar p=0.1527，不顯著 |
| Emotion，Macro-F1 | Gated fusion + linear | 0.4594（linear） | 0.4803 | McNemar p=0.0037，顯著 |
| Politeness，Pearson’s r | Gated fusion + linear | 0.6222（MLP） | 0.6412 | 論文未提供整體顯著性檢定 p 值 |
| Formality，F1 | Gated fusion + linear | 0.9342（linear） | 0.9480 | McNemar p=3.0×10^-5，顯著 |
| EMA emotion，Pearson’s r | Feature concatenation + linear | 0.5687 | 0.5754 | 論文報告整體提升；逐情緒顯著性依類別不同 |

Emotion 的改善集中於低頻或複雜類別，例如 remorse 0.651 對 0.636、fear 0.667 對 0.613、embarrassment 0.421 對 0.386；grief 由 0.000 提升至 0.286。Politeness 在較高區間改善較大，Slightly Polite 為 0.299 對 0.246，Polite 為 0.435 對 0.326。EMA 資料中，14 種情緒有 9 種達顯著相關；論文未報告跨資料集的完整統計檢定。

## 對我們的啟發
- [ ] 對需要理解互動關係的分類或回歸任務，可將 semantic roles 納入 attention，而非僅把角色標籤當作附加特徵；此做法在本文的 emotion、politeness 與 formality 任務中較有效。
- [ ] gated fusion 可讓模型在角色結構不完整或不具資訊時保留原始 contextual representation，實務部署時可優先比較 gated fusion 與直接 concatenation，而不應預設單一融合方式適用所有任務。
- [ ] 若要聲稱模型具備可解釋性，應讓解釋輸入與模型實際使用的中間表示一致；本文的 SRL-grounded explanation 比單純描述詞彙線索更能對應 ARG0、ARG1、ARG2 與 ARGM，但仍需額外的 faithfulness 評估。

## 限制與未來工作

作者僅以單一 random seed 42、每個設定一次訓練報告結果，可能限制結果穩定性的判斷。sentiment 提升不具統計顯著性，顯示角色結構並非所有 SEPF 任務都同樣有益。EMA 實驗僅聚焦 emotion，且資料來自 74 名 13–15 歲青少年及其 outgoing messages。解釋研究主要是質性示例，尚未進行系統性人類評估或 perturbation-based faithfulness 測試；作者將此列為未來工作。
