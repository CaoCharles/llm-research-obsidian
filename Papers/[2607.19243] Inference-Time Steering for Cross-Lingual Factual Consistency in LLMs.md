# Inference-Time Steering for Cross-Lingual Factual Consistency in LLMs

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2607.19243)
- 📥 [PDF](https://arxiv.org/pdf/2607.19243v1)

## 摘要（中文翻譯）

大型語言模型（LLM）雖具備多語言流暢性，其內部知識表徵仍偏重高資源語言，因而可能僅因提示語言不同而產生跨語言事實不一致。本文研究能否在 inference time 將英文提示的模型導向如同使用德文、西班牙文或保加利亞文提問時的回答分布，並比較四類介入策略：zero-shot contextual steering（persona prompting）、以 Contrastive Activation Addition（CAA）操弄內部表徵，以及使用基準資料或概念泛化資料訓練的 Direct Preference Optimization（DPO）LoRA adapters。作者建立多語言事實資料集與文化情境泛化基準，在 Gemma 3 12B Instruct 上實驗。結果顯示 persona prompting 在效能、安全性與分布外泛化間取得最佳整體平衡；CAA 能大幅改變不一致性基準，但對設定敏感且可能損害知識；DPO adapters 的效果較永久卻較狹窄。研究因此主張，跨語言不一致部分屬於答案選擇問題，簡單的 contextual intervention 可能比侵入性方法更穩健且可轉移。

## 問題背景

LLM 可能在提示語言改變時，對同一事實選擇不同答案，反映高資源語言與英語中心偏差。既有方法多依賴大規模預訓練或參數微調，成本高，且可能造成模型其他能力退化；單次正確率也難以捕捉多次生成下的答案分布差異。本文因此探討能否以 inference-time intervention，讓英文提示模型呈現目標語言的事實偏好，並同時驗證安全性與文化泛化。

## 解決方案

作者建立由淺入深的比較框架。首先以 persona prompting 透過上下文指令喚回模型既有的目標文化訊號；其次以 CAA 從英文偏好與目標偏好 completion 的 hidden-state 差異計算 steering vector，於生成時加入 residual stream；最後以 DPO LoRA 將偏好固化為參數更新，並分別使用基準事實對比與文化泛化資料訓練。核心創新是把跨語言事實一致性重新表述為 preference realignment 問題，並以 JSD、TPM、普通事實保存及文化泛化共同判斷介入是否真正有效。

## 核心貢獻
1. 建立涵蓋英文、德文、西班牙文、保加利亞文、瑞典文與韓文的多語言原子事實資料集，並以重複取樣與答案分布分析跨語言不一致。
2. 提出包含每種目標語言50個文化根植情境的泛化基準，用於檢驗事實偏好介入是否能轉移至更廣泛的目標文化偏好。
3. 在 Gemma 3 12B Instruct 上系統比較 persona prompting、CAA、基準衍生 DPO 與泛化衍生 DPO，指出 prompting 在目標對齊、普通事實保存與概念泛化之間具有最佳整體表現。

## 技術方法

研究首先以 Gemma 3 12B Instruct 為主要實驗模型；初始跨語言比較另涵蓋 gpt-oss-20b、Qwen 3 30B-A3B 與 Llama 4 Maverick Instruct。多語言事實基準以 atomic triples（subject、relation、object）組成，涵蓋七種關係，包括 capital、city of origin、country of origin、country of citizenship、languages、occupation 與 religion。每個 subject-relation pair 使用隨機 prompt templates，在溫度 T=0.8 與1.2 各生成10次；輸出經 extraction 與 canonicalization 正規化為英文答案，再以 pairwise Jensen–Shannon distance（JSD）衡量分布差異，並以 target probability mass（TPM）評估目標偏好答案的機率質量。四種介入包括：一、在英文提示前加入「出生、成長並居住於目標國家」的 persona instruction；二、CAA，從英文偏好與目標語言偏好答案的 activation difference 建立 steering vector，於指定層加入 residual-stream 向量，並掃描 Gemma 的48層與 multiplier 0.5至30；三、以相同 factual contrast pairs 訓練 benchmark-derived DPO LoRA；四、以文化泛化資料訓練 generalization-derived DPO LoRA。DPO 使用 rank=16、alpha=32、dropout=0.05、learning rate=1e-5、5 epochs。安全性在排除實驗 subject union 的 held-out 普通事實上比較 ΔTPM、ΔJSD 及其絕對值；泛化測試則使用每種目標語言50個英文撰寫、二選一且採第二人稱的文化情境，分別以隨機取樣與 greedy decoding 評估目標中心選擇率。

## 關鍵結果

主要結果如下；JSD 越低代表越接近目標語言分布，TPM 越高代表目標偏好答案的經驗機率質量越高。

| 目標/版本 | Baseline JSD/TPM | Prompting JSD/TPM | Steering JSD/TPM | DPO（Ben.）JSD/TPM | DPO（Gen.）JSD/TPM |
|---|---:|---:|---:|---:|---:|
| bg v1 | 0.583 / 0.662 | 0.490 / 0.729 | 0.504 / 0.755 | 0.501 / 0.745 | 0.522 / 0.726 |
| de v1 | 0.524 / 0.707 | 0.396 / 0.789 | 0.436 / 0.748 | 0.458 / 0.743 | 0.439 / 0.739 |
| es v2 | 0.423 / 0.778 | 0.468 / 0.737 | 0.433 / 0.796 | 0.348 / 0.837 | 0.413 / 0.776 |

論文報告 prompting 在9個評估格中有8個改善 JSD 與 TPM；CAA 改善 JSD 的格數為8/9，但需要依語言、對比版本、層與 multiplier 調校。基準衍生 DPO 在9個格中全部改善 JSD、8個改善 TPM；泛化衍生 DPO 亦在9個格中全部改善 JSD、8個改善 TPM。v1 下的部分結果達統計顯著：prompting 對 Bulgarian 的 JSD 改善 p<0.01、CLES=0.672，對 German p<0.05、CLES=0.705；CAA 對 Bulgarian p<0.01、CLES=0.741，對 German p<0.01、CLES=0.705。

安全性方面，普通事實的平均絕對變動為：prompting 的 |ΔTPM|=0.0041、|ΔJSD|=0.0034；steering 為0.0203、0.0181；DPO（Ben.）為0.0019、0.0019；DPO（Gen.）為0.0011、0.0015。泛化基準的目標偏好率中，baseline 平均約32.7%，prompting 提升至86.0%；steering 為33.3%，DPO（Ben.）為32.7%。

## 對我們的啟發
- [ ] 若模型已具備目標語言或文化相關訊號，部署時可優先採用明確的 persona prompting，避免先進行成本較高的權重更新或 activation engineering。
- [ ] 評估跨語言對齊不應只看目標基準上的 JSD 或 TPM；應同步檢查未介入的普通事實，因為 CAA 在部分設定下造成明顯的分布退化。
- [ ] 若採用 CAA 或 DPO，對比資料的結構十分關鍵：論文中的 v1（交叉配對且排除相同答案）比資料過稀的 v0 或包含矛盾相同配對的 v2 更穩定；但此結論僅由本研究設定支持。

## 限制與未來工作

研究只在單一模型 Gemma 3 12B Instruct、三種目標語言（德文、西班牙文、保加利亞文）上進行；CAA 與部分 DPO 使用的事實對比資料較小。答案 extraction 與 judgment 部分依賴 GPT-5.1，可能引入標註噪聲；研究重點是分布一致性而非完整事實正確性。未來可擴大文化資料、測試瑞典文與韓文，以及其他架構。
