# Robust and Efficient Motion Reasoning for Privacy-Aware Classroom Incident Recognition

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.05115)
- 📥 [PDF](https://arxiv.org/pdf/2608.05115v1)

## 摘要（中文翻譯）

電腦視覺能否協助提升教室安全？本 pilot study 探討從 CCTV-style 觀察中進行具隱私意識且計算高效的教室事件辨識。此場景仍缺乏研究，現有 benchmark 與方法較少考慮真實部署所需的隱私、效率與泛化能力。作者提出結合生成式 CCTV-style 影片與真實教室 pose 資料的 hybrid benchmark，並提出輕量而穩健的 motion-reasoning framework。該方法基於許多事件在 pose 之外，更主要由運動方向、速度、加速度與強度區分的觀察，先建立階層式 kinematic representations，再將大型 teacher 的階層式 multi-order kinematic reasoning distill 至小型 single-order student，使其能以低成本進行 per-person inference，同時保留具表達力的運動理解。實驗顯示，模型以不到較大 baseline 十分之一的計算成本取得更佳表現，並展現較強的 out-of-domain motion reasoning 與 zero-shot synthetic-to-real generalization。作者將公開 benchmark、程式碼與支援工具。

## 問題背景

論文聚焦於 preschool 教室 CCTV 中 fall、punch、kick、throw、run 等安全事件的自動辨識。現有 classroom vision 研究主要處理 engagement、attendance、活動或一般行為，通用 action-recognition benchmark 也缺乏教室特有的高風險事件。真實場景還有高視角、小尺度、遮擋、姿態噪聲、成人與幼兒共存，以及兒童影像隱私問題；既有方法多未同時處理隱私、計算效率與 synthetic-to-real 泛化。

## 解決方案

作者提出以 skeleton pose trajectories 為唯一辨識輸入的 privacy-aware framework，避免模型直接依賴可識別的 RGB 外觀。核心是 hierarchical kinematic representation：從平滑後的 joint positions 計算 velocities 與 accelerations，分別建模位置、方向速度及運動強度變化，再融合為 multi-order teacher。為了適合 edge 或資源受限部署，作者將 teacher 的 softened predictions 及 ground-truth supervision 蒸餾至較小的 single-order student；student 僅使用 zeroth-order joint positions，卻能在訓練期間吸收 multi-order motion reasoning。框架同時搭配生成式 CCTV-style synthetic benchmark 與 real-world anonymized pose evaluation。

## 核心貢獻
1. 建立以 CCTV 視角為目標的教室事件辨識 hybrid benchmark，包含 1296 筆 synthetic samples 與 574 筆 real-world pose samples，涵蓋 fall、punch、jump、kick、throw、run、sit 及 background 八類。
2. 提出以 skeleton pose 為輸入的隱私導向辨識 framework，從 joint positions 建立 velocities 與 accelerations，並以 order-specific backbones 融合 multi-order kinematic representations。
3. 提出 multi-objective knowledge distillation，將 multi-order、較大型 teacher 的 motion reasoning 壓縮至僅使用 zeroth-order joint positions 的小型 student，以降低部署成本並改善 synthetic-to-real 泛化。

## 技術方法

資料方面，作者以 Kling 與 Seedance 生成符合教室 CCTV 特性的影片，透過 scenario prompt、校服 asset library、三位作者一致審查，以及 preschool teachers 的標註與品質驗證，形成 1296 筆 synthetic samples；另收集 574 筆 real-world samples，僅保留 anonymized video 所抽取的 pose keypoints 與事件標籤。辨識模型不直接存取 RGB，只接收 per-person pose trajectories。首先以 linear interpolation 補齊遺失 joint coordinates，再以 Savitzky–Golay filter 平滑軌跡；由 joint position j 建立 velocity v=(j_t-j_{t-δ})/δ，並建立 acceleration a=(v_t-v_{t-δ})/δ。position、velocity、acceleration 各自輸入獨立的 STGCN++ order-specific backbone；其 latent features 投影至共同維度後，依人工權重加權平均形成 multi-order teacher representation。teacher 使用 64 base channels，student 使用僅 32 channels 的 STGCN++，且 inference 只處理 zeroth-order position。student 同時最小化 temperature=4 的 teacher-student KL distillation loss 與 ground-truth classification loss，權重為 λKD=0.3、λCls=1.0。所有模型先以 NTURGBD 預訓練；synthetic 資料按 80%/20% 分為 train/test。評估指標主要為 accuracy，消融另報告 macro-F1；實驗包括 synthetic-domain comparison、zero-shot synthetic-to-real transfer，以及 kinematic fusion、distillation weight 與 student compression 的消融。

## 關鍵結果

主要結果如下：

| 評估設定 | 方法 | Accuracy (%) |
|---|---|---:|
| Synthetic test | AAGCN | 66.39 |
| Synthetic test | STGCN++ | 68.05 |
| Synthetic test | CTRGCN | 65.56 |
| Synthetic test | MSG3D | 68.88 |
| Synthetic test | PoseC3D | 70.54 |
| Synthetic test | Ours | **71.78** |
| Zero-shot synthetic-to-real | AAGCN | 54.70 |
| Zero-shot synthetic-to-real | STGCN++ | 57.32 |
| Zero-shot synthetic-to-real | CTRGCN | 53.83 |
| Zero-shot synthetic-to-real | MSG3D | 59.23 |
| Zero-shot synthetic-to-real | PoseC3D | 54.36 |
| Zero-shot synthetic-to-real | Ours | **63.41** |

作者指出，Ours 在 synthetic test 比最佳 baseline PoseC3D 高 1.24 個百分點，在 zero-shot real-world test 比最佳 baseline MSG3D 高 4.18 個百分點。Figure 2 顯示 Ours 使用約為 PoseC3D 十分之一的 parameters；論文文字另指出 student 為 teacher 的六分之一，但未完整報告各模型的 FLOPs、參數量與推論延遲數值。消融實驗顯示最佳 fusion weights 為 {w0,w1,w2}={1.0,0.8,0.2}，最佳 distillation loss weight λKD=0.3、λCls=1.0；作者另報告相較 STGCN++，accuracy 提升 4.1 個百分點、macro-F1 提升 5.2 個百分點。

## 對我們的啟發
- [ ] 若部署場景對原始影像敏感，可將辨識模型限制在 anonymized pose trajectories；但論文的部署設定仍假設 pose 可由資料持有機構先從 CCTV 提取。
- [ ] 對快速或具力量的事件，除靜態 pose 外，velocity 與 acceleration 等時間動態特徵值得納入；論文也顯示先以 temporal interpolation 與 Savitzky–Golay smoothing 降噪，有助於降低高階導數的噪聲放大。
- [ ] 評估教室安全模型時，不應只看 synthetic-domain accuracy；zero-shot synthetic-to-real 測試揭示 domain gap，且論文報告 synthetic 71.78% 降至 real-world 63.41%。

## 限制與未來工作

論文將研究定位為 pilot study，整體 accuracy 仍有限，且 synthetic-to-real 仍有由 71.78% 降至 63.41% 的 domain gap。資料聚焦新加坡 preschool 場景與八類別，跨地區、跨年齡及更廣泛事件的泛化未被驗證。融合權重採人工設定；論文也未報告完整的 latency、各類別數量、信賴區間或部署端 pose extraction 成本。
