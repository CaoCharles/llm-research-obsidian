# Wyvern: An Agentic Framework for Generating Grounded Multimodal Reports

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.14446)
- 📥 [PDF](https://arxiv.org/pdf/2608.14446v1)

## 摘要（中文翻譯）

在人工智慧驅動創新的時代，知識成長速度加快，使人們難以持續掌握最新資訊。生成模型雖日益用於內容綜合，卻經常缺乏資訊 grounding。為此，本文提出 Wyvern，一個用於自動生成 grounded、多模態技術報告的 multi-agent framework。Wyvern 將 images、tables、text 與 supporting references 整合於統一報告中，並特別設計 claims auto-revision 階段，以強化內容 grounding。作者透過 human evaluation 評估框架品質；結果顯示，在 87% 的比較中，其 figures informativeness 被認為優於近期 baseline，且相較三種替代方法，Wyvern 報告在 63% 至 100% 的比較中被評為更有用。Automatic evaluation 也顯示，相較 baselines，Wyvern 的 citation recall 最高提升 2.3 倍，citation precision 最高提升 1.6 倍。

## 問題背景

Web 與科學文獻持續快速增長，使研究者難以整理異質且大量的資訊。既有自動長文生成方法雖能檢索與綜合內容，但常缺乏可追溯的 grounding，且多數只輸出文字，未能有效整合 figures 與 tables。論文因此聚焦於如何產生兼具資訊覆蓋、多模態呈現與 citation-supported factuality 的技術報告。

## 解決方案

作者提出 Wyvern multi-agent framework，以模組化 workflow 協調多個 LLM agents。系統先透過 web search、文件解析、品質評分、連結擴展、去重與摘要建立 knowledge base，再以 outline planning 和 section expansion 生成報告。其核心創新包括從來源文件選擇並定位 informative figures、建立 overview table，以及在生成後將文字拆為 atomic claims，依 cited references 進行兩階段 grounding 檢查，對不精確 claims 進行 auto-revision，或移除 unsupported claims。

## 核心貢獻
1. 提出 Wyvern，一個由多個專責 LLM agents 組成的框架，能從 web retrieval 到報告生成，產出含文字、圖片、總覽表格與 references 的 grounded multimodal technical reports。
2. 設計 figures retrieval、selection、section assignment、placement 與 text integration 流程，並以 figure descriptions、captions 和來源內容協助選取較具資訊性的圖片。
3. 提出 claims auto-revision grounding module：將段落拆解為 atomic claims，先以 reference summaries、再以 references full text 進行 grounding/NLI 檢查，並修訂或移除 unsupported claims；同時比較 automatic evaluation 與 human judgment。

## 技術方法

Wyvern 由 search、report generation 與 grounding 三個 sequential modules 組成，並以多個專責 LLM agents 處理子任務。Search phase 接收使用者 topic title、興趣範圍與可選 URLs；LLM 先細化主題並生成 30 個 search queries，透過 Serper 取得每個 query 的 top-3 URLs。系統依網頁類型使用 Docling、Playwright、Trafilatura 或 Wikipedia API 解析內容，接著以 completeness、追加搜尋需求與 embedded-link relevance 評分，依門檻 5、5、7 篩選，並用 Jaccard similarity 0.9 去重；之後摘要、過濾 semantic outliers，建立 references 與 reference summaries。Report generation 先由多個候選 outlines 探索主題覆蓋，再合併成 final outline，並平行擴寫 sections。圖片流程會從來源文件擷取 figures，利用 title、summary、caption 與 figure-related excerpts 生成描述，再選取圖片、分配 section、決定位置、產生 caption 並修正文句；另建立 overview comparative table，最後進行 section refinement。Grounding phase 將 paragraph-level text units 拆成 atomic claims，先以 cited reference summaries 檢查，疑似 unsupported 時再對 full text 進行 entailment/NLI 評估；claims 會被修訂或刪除，並重新調整 headings。主要指標為 citation recall、citation precision，以及 human/automatic pairwise report-quality 評估。實驗使用 DeepSeek-R1 作 reasoning agents、DeepSeek-V3 作一般 agents，並與 STORM、WebThinker、WikiAutoGen 比較。

Human study 使用 23 份完成問卷；整體而言，Wyvern 在與 STORM 的所有比較項目均獲較高偏好，但 WebThinker 在 structure 與 engagement 上分別獲得較高偏好。60 個 claims 的人工與 LLM grounding 判斷一致率為 93.33%。

## 對我們的啟發
- [ ] 若應用於研究報告生成，應把 citation verification 放在完整內容生成之後，並以 atomic-claim 粒度檢查，避免整句部分被來源支持時仍被誤判為完全正確。
- [ ] 多模態 RAG 不宜只做圖片檢索；圖片的來源 caption、內文提及、主題描述與目標 section 應共同用於 selection 和 placement，且需要最終的人工作品質審查。
- [ ] LLM-as-judge 不應被視為穩定的人類評測替代品：本文觀察到 DeepSeek-V3 與 Qwen3-32B 的 ordering bias 分別為 36.11% 與 30.56%，因此實務上應採用雙向排序、多人類抽查與多評審交叉驗證。

## 限制與未來工作

框架依賴 search APIs，因此來源會受時間、地點與搜尋引擎索引變化影響，完整性與 reproducibility 均有限。實驗只涵蓋英文主題，跨語言能力尚未驗證。系統也沒有過濾 web sources 中偏見或錯誤資訊的機制；此外，報告可能過長、冗餘，圖片解析與 placement 也可能失準。
