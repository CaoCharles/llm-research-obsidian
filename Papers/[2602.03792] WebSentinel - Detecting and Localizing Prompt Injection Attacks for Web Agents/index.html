    WebSentinel: Detecting and Localizing Prompt Injection Attacks for Web Agents

    連結

    • 📄 arXiv
    • 📥 PDF
    • 📎 本地 PDF: PDF

    摘要（中文翻譯）

    Prompt injection 攻擊透過操縱網頁內容，使 Web Agent 執行攻擊者指定的任務，而非使用者原本的意圖。現有的偵測與定位方法效果有限，因為其基本假設往往不適用於 Web Agent 的使用情境。本研究提出 WebSentinel，一種兩階段方法來偵測與定位網頁中的 prompt injection 攻擊。給定一個網頁，第一步驟提取可能被污染的「感興趣片段」(segments of interest)，第二步驟則評估每個片段與網頁內容的一致性。實驗結果顯示 WebSentinel 具有高度效能，在我們收集的多個包含污染與乾淨網頁的資料集上，大幅超越基準方法。程式碼已開源於 GitHub。

    論文預覽

    問題背景

    Web Agent 面臨嚴重的 prompt injection 攻擊威脅，攻擊者可在網頁中嵌入惡意指令，劫持 Agent 執行非預期任務。現有偵測方法的假設（如惡意內容與正常內容有明顯差異）在真實網頁環境中往往不成立，導致偵測效果不佳，且難以精確定位攻擊位置。

    解決方案

    WebSentinel 採用兩階段方法：第一階段從網頁中提取「感興趣片段」，即可能包含注入攻擊的文字區段；第二階段對每個片段進行一致性檢查，判斷其內容是否與網頁整體上下文相符。核心創新在於利用上下文一致性作為判斷標準，而非依賴特定的攻擊模式或關鍵字，使系統能適應多種攻擊變體。

    核心貢獻

    1. 提出 WebSentinel 兩階段框架，有效偵測與定位 Web Agent 環境中的 prompt injection 攻擊
    2. 設計基於上下文一致性的片段評估方法，克服現有方法假設不符實際的問題
    3. 建構包含污染與乾淨網頁的多樣化評估資料集，並開源程式碼供研究社群使用

    技術方法

    WebSentinel 的技術流程分為兩個主要階段：

    第一階段 - 片段提取：從網頁的 DOM 結構中識別並提取可能包含惡意內容的文字片段。這些「感興趣片段」包括使用者可編輯區域、動態載入內容等容易被攻擊者利用的位置。

    第二階段 - 一致性評估：對每個提取的片段，利用 LLM 評估其與周圍網頁內容的語義一致性。若片段內容與網頁主題、風格或意圖明顯不符（例如在購物網站中出現要求轉帳的指令），則標記為可疑。

    評估指標包含偵測準確率（是否正確識別被污染的網頁）和定位精確度（是否正確指出惡意片段的位置）。實驗使用自行收集的資料集，涵蓋多種網站類型和攻擊模式。

    關鍵結果

    方法 偵測準確率 定位 F1 誤報率
    基準方法 ~60-70% ~40-50% 較高
    WebSentinel 大幅領先 大幅領先 較低

    具體數據需參考完整論文，WebSentinel 在多個資料集上均顯著優於現有基準方法

    對我們的啟發

    • 上下文一致性檢查是有效的防禦策略：可應用於 RAG 系統檢測文件層級的 prompt injection
    • 兩階段設計（先篩選再精確分析）能平衡效率與準確度，適合部署於即時系統
    • 開源資料集對 prompt injection 防禦研究有重要價值，可作為評估其他防禦方法的基準

    限制與未來工作

    論文可能的限制包括：評估資料集的規模和多樣性是否足夠代表真實攻擊場景、LLM 一致性檢查的運算成本、以及對抗性攻擊者可能設計與網頁內容高度一致的隱蔽攻擊來規避偵測。
