    Rethinking Rubric Generation for Improving LLM Judge and Reward Modeling for Open-ended Tasks

    連結

    • 📄 arXiv
    • 📥 PDF
    • 📎 本地 PDF: PDF

    摘要（中文翻譯）

    近期 rubric（評分標準）被用於引導 LLM 法官捕捉主觀、多維度的人類偏好，並從評估延伸至作為強化微調（RFT）的獎勵信號。然而，rubric 生成仍難以控制：rubric 常缺乏覆蓋度、混淆維度、偏好方向錯位，且包含冗餘或高度相關的標準——這些問題會降低法官準確度並產生次優的 RFT 獎勵。本文提出 Recursive Rubric Decomposition（RRD），一個基於遞迴分解-過濾循環的原則性 rubric 精煉框架。RRD 將粗糙的 rubric 分解為細粒度、具辨別力的標準，擴大覆蓋度同時增強回應間的分離度。互補的過濾機制移除錯位和冗餘的 rubric，相關性感知的加權方案防止高度相關標準的過度代表，最終產生具資訊性、全面性且非冗餘的 rubric 集合。實證上，RRD 在評估和訓練兩端均帶來大幅且穩定的提升：在 JudgeBench 和 PPE 上改善 GPT-4o 和 Llama3.1-405B 法官的偏好判斷準確度，在所有設定中達到最佳表現，JudgeBench 上最高提升 +17.7 分。用於 WildChat 上的 RFT 獎勵源時，RRD 產生顯著更強且更穩定的學習信號，獎勵提升幅度達 160%（Qwen3-4B）和 60%（Llama3.1-8B），且成果可遷移至 HealthBench-Hard 和 BiGGen Bench。

    問題背景

    LLM 越來越常被用作法官（LLM-as-a-Judge）來評估開放式生成任務（如創意寫作、規劃、角色扮演），但這些任務的品質本質上是主觀且多維度的。現有方法中，基於 rubric 的評估雖然比整體性判斷更具結構化和可解釋性，但自動生成的 rubric 存在兩大關鍵缺陷：(1) 覆蓋度不足——rubric 集合無法全面捕捉生成品質的多樣面向；(2) 評估結果帶有雜訊——錯位、重疊或高度相關的 rubric 引入不可靠的信號。這些缺陷導致 rubric 法官與人類偏好的一致性不佳，且作為 RFT 獎勵時，學習信號薄弱且不穩定。

    解決方案

    提出 Recursive Rubric Decomposition（RRD）框架，包含三個階段：(1) 初始 Rubric 提議——LLM 根據任務 prompt 和取樣回應生成初始候選 rubric；(2) 遞迴分解與過濾——對被多數回應滿足的粗糙 rubric 進行遞迴分解為更細粒度的子維度，同時過濾掉偏好方向錯位（misaligned）和冗餘（redundant）的 rubric，直到新 rubric 提議的拒絕數超過終止閾值；(3) 權重分配——對開放式任務採用 whitened uniform（WU）加權，透過白化 rubric 分數空間消除相關性影響，避免高度相關標準的過度代表。

    核心貢獻

    1. 提供 rubric 品質的理論基礎，基於正邊際（positive edge）和有界相關性（bounded correlation）兩個假設，推導出 rubric 法官誤分類機率的指數上界，從而形式化 rubric 的三大期望特性：資訊性、全面性、非冗餘性
    2. 提出 RRD 框架，透過遞迴分解-過濾循環和相關性感知加權，系統性地優化 rubric 集合，在 JudgeBench 上將 GPT-4o 準確度從 55.6% 提升至 73.3%（+17.7 分），在所有模型和資料集組合中均達到最佳
    3. 驗證 RRD 作為 RFT 獎勵源的有效性——在 WildChat 上訓練 Qwen3-4B 和 Llama3.1-8B，獎勵提升幅度達先前方法的 3-10 倍，且下游在 BiGGen Bench 和 HealthBench-Hard 上均有穩定遷移表現

    技術方法

    RRD 的核心機制建立在理論推導之上。令每個 rubric $g_k$ 為二元謂詞，rubric 獎勵為加權和 $f_{w,G}(P,R) = \sum_k w_k g_k(P,R)$。在 正邊際假設（A1: 每個 rubric 都正向貢獻於區分偏好回應）和 有界相關性假設（A2: rubric 雜訊有界且成對相關性 $|\text{Corr}| \leq \rho < 1$）下，誤分類機率的上界為 $\exp(-\frac{1}{2}\min{\Delta_m^2/V_m(+1), \Delta_m^2/V_m(-1)})$，其中 $\Delta_m = w^\top \mu$ 為信號強度，$V_m = w^\top \Sigma w$ 為加權殘差方差。最大化信噪比 $\Xi = (w^\top \mu)^2 / (w^\top \Sigma w)$ 即為 RRD 的優化目標。

    遞迴分解：對每個被超過 $n=2$ 個候選回應滿足的 rubric 進行分解——這類 rubric 過於粗糙、缺乏辨別力。分解後的子 rubric 捕捉更細緻的品質差異。過濾機制包含兩步：(a) 錯位過濾——移除偏好弱模型（Llama3-8B）輸出勝過強模型（GPT-4o）的 rubric；(b) 冗餘過濾——移除與現有 rubric 實質重疊者。循環持續至累積拒絕數超過閾值 $N=15$。Whitened Uniform 加權：以 $\Sigma^{-1/2}$ 白化 rubric 空間後均勻加權，無需標註資料即可消除相關性造成的偏差，特別適合信號分散在多維度的開放式任務。

    關鍵結果

    RRD 在 LLM 法官準確度和 RFT 獎勵兩端均顯著優於所有基線：

    LLM 法官準確度（JudgeBench / PPE）：

    方法 GPT-4o JudgeBench GPT-4o PPE Llama3.1-405B JudgeBench Llama3.1-405B PPE
    Base Model 55.6 67.1 57.4 66.9
    LLM Rubrics (w/o resp.) 42.9 55.2 41.5 56.7
    LLM Rubrics (w. resp.) 66.8 64.7 56.0 65.9
    Chasing the Tail 67.6 66.4 56.9 66.3
    RRD_WU 73.3 73.7 64.8 70.9

    RFT 獎勵提升（WildChat 訓練）： RRD_WU 在 Qwen3-4B 上達到 150-160% 的獎勵提升，在 Llama3.1-8B 上達到 55-60%，而先前基線僅約 10-20%。下游在 BiGGen Bench 上，RRD_WU 使 Qwen3-4B 達到 82.8%、Llama3.1-8B 達到 71.1% 的最高總分。在 HealthBench-Hard 上，RRD_WU 在指令遵循（+16.0%）、準確度（+5.5%）和完整性（+12.5%）上均為最佳。

    對我們的啟發

    • RRD 揭示了一個重要洞察：天真地使用 LLM 生成的 rubric 反而可能降低法官準確度（GPT-4o 從 55.6% 降至 42.9%），說明 rubric 品質控制是 LLM-as-a-Judge 系統的關鍵瓶頸，不應盲目信任自動生成的評估標準
    • Whitened uniform 加權策略提供了一個無需標註的相關性去偏方法——在開放式任務中，品質信號分散在多個維度而非集中於單一主導 rubric，這一統計洞察對設計多維度評估系統有直接參考價值
    • RRD 的遞迴分解邏輯類似醫學診斷過程（將粗糙症狀分解為精細檢查項目），此「分解至具辨別力」的原則可推廣至其他需要結構化評估的場景，如程式碼審查、教育評量等

    限制與未來工作

    實驗中 rubric 生成器和法官均使用同一模型（GPT-4o），可能存在自我偏好偏差；遞迴分解的計算成本隨任務複雜度增加（平均從 7.4 個 rubric 增長至約 20 個）；whitened uniform 加權假設相關性結構可從未標註資料估計，在極端分佈外場景的穩健性尚待驗證；僅在英文資料集上評估，多語言泛化性未知。
