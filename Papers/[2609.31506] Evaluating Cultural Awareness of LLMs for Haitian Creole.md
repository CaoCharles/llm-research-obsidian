# Evaluating Cultural Awareness of LLMs for Haitian Creole

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.31506)
- 📥 [PDF](https://arxiv.org/pdf/2609.31506v1)

## 摘要（中文翻譯）

大型語言模型（LLMs）在高資源與低資源語言之間呈現顯著的效能落差；除了任務表現較低，也常無法掌握弱勢社群的文化規範與價值。本研究首次系統性評估 LLMs 對海地克里奧爾語（Haitian Creole）的文化意識，該語言雖有數百萬使用者，卻嚴重缺乏數位資源。作者以母語者整理的文化顯著提示，透過文字填空任務，從 specificity、bias、diversity 與 variation 四個互補面向進行評估。結果顯示，Haitian Creole 的文化意識明顯低於高資源語言 French，且不同文化領域間更加不均衡，也更容易受到 French 語言干擾。故事生成進一步發現，模型反覆以困境與韌性描繪海地人物，顯示即使是正面刻畫，也可能承載刻板敘事。作者公開釋出程式碼、benchmark 與評估框架。

## 問題背景

論文探討多語言 LLM 是否能在 Haitian Creole 中忠實且包容地表徵 Haitian culture。既有 Haitian Creole 資源主要用於 machine translation、reading comprehension 或一般 NLP 任務，受限於聖經、醫療或翻譯導向資料，無法充分涵蓋日常生活、文化實踐與社群經驗。因此，僅以語言流暢度或標準任務分數，無法判斷模型是否具備文化 awareness，也難以揭露跨語言資源不平等與刻板印象。

## 解決方案

作者建立首個以 Haitian Creole 為核心的文化意識 benchmark，收錄由四名 Haitian Creole 母語者整理與驗證的文化實體及提示。框架結合 cultural entity infilling 與 story generation：前者以 specificity、bias、diversity、variation 衡量文化知識的對齊程度、覆蓋廣度與生成穩定性；後者分析不同文化條件下的人物描述與敘事刻板印象。研究並以 French 作為較高資源文化的比較條件，藉此分離語言資源差異、文化領域不均衡與 French linguistic interference 等現象。

## 核心貢獻
1. 建立首個由 Haitian Creole 母語者整理與註釋、聚焦 Haitian cultural awareness 的文化實體與提示 benchmark，涵蓋七類文化實體。
2. 將 CAMeL/MAKIEval 啟發的 specificity、bias、diversity、variation 指標應用於 Haitian Creole，並比較 Mistral medium/large 及 French 與 Haitian Creole 的文化表徵差異。
3. 透過故事生成與 z-score 描述詞分析，揭示 Haitian 人物反覆被放入貧困、困境與韌性敘事，說明正面形容詞仍可能承載刻板印象。

## 技術方法

研究先檢視既有 Haitian Creole 資源，但因資料規模、領域限制、拼寫差異或翻譯導向等問題，改以人工建構 benchmark。文化實體分為 Food、Music Groups、Music Type、Festivals、Political Figures and Heroes、Authors、Locations；其中 Authors 與 Locations 部分參考 Wikidata，其餘由母語者從頭整理，並納入區域名稱與別名。提示分為 culturally contextualized 與 culturally agnostic：前者明確提供 Haitian context，後者不提供文化線索，用以觀察模型預設的文化指涉。作者考察 Qwen、LLaMA 3 等模型家族後，因 Mistral 產生較連貫的 Haitian Creole，主要實驗採用 Mistral medium 與 large，使用 API 預設 decoding 參數。生成結果以 reference list 進行 exact matching；specificity 是文化情境提示中命中 Haitian 實體的比例，bias 是無文化線索提示中非目標文化輸出的比例，diversity 是生成之不同目標實體數除以有效參考實體數，variation 則是每一提示生成十次時，不同回答數除以十後再按類別平均。故事實驗使用 Names、Food、Musical Groups 三類 Haitian/French 實體，生成約 500 字 Haitian Creole 故事，再由同一 Mistral 模型抽取五個顯著描述詞，透過 z-score 比較文化條件與形容詞的關聯。

## 關鍵結果

論文未報告各指標的具體數值，主要以圖表、定性比較與案例分析呈現。可確認的結果如下：

| 比較面向 | 實驗觀察 |
|---|---|
| Mistral medium vs. large | medium 在多數類別具有較高 specificity，且多數類別 bias 較低；large 的 diversity 通常較高，但只在其產生文化對齊回答時成立。 |
| Model size 與 variation | 兩種模型的 variation 均偏低且相近，顯示模型規模對重複生成差異的影響有限。 |
| Haitian Creole 的文化領域 | medium 在 Music Groups 與 Authors 較強，在 Festivals 與 Locations 較弱；Locations 常混用 French 與 Haitian Creole 地名形式，Festivals 則常被誤認或錯誤描述。 |
| French vs. Haitian Creole | French 整體 specificity 與 diversity 較強，但差距依類別而異。Food 的 bias 差距較小，Locations 的差距較大；Music Groups 中 Haitian condition 沒有可量測 bias，而 French 有時產生如 BTS 等全球知名團體。 |
| Story generation：Haitian 人物 | 常與 hardworking、resilient、strong、devoted、generous 等詞共同出現，故事經常涉及 poverty、hardship、humble circumstances 與克服困境。 |
| Story generation：French 人物 | 較常以 independent、reserved、calm、thoughtful、methodical、organized 描寫，並出現 exploration、intellectual pursuits 或 adventurous experiences。 |
| 跨條件刻板印象 | 即使以 Food 或 Musical Groups 提供文化線索而非直接指定國籍，Haitian 人物仍較常與 hardship、urgency、strength、determination 相關；作者指出正面詞彙也可能形成窄化的 resilience narrative。 |

## 對我們的啟發
- [ ] 評估低資源語言時，不應只測量語法流暢度或一般任務效能；應加入由社群參與建構的文化實體、日常情境與母語者驗證。
- [ ] specificity 與 diversity 必須聯合解讀：模型可能在少數命中時展現很高的實體多樣性，因此不能以單一指標代表整體文化 awareness。
- [ ] 文化評估應將拼寫變體、French interference、區域差異與口語形式納入 normalization 和人工審查，否則 exact matching 可能把文化上合理的回答誤判為錯誤。

## 限制與未來工作

benchmark 與 reference inventories 不完整，可能低估區域與社群文化多樣性；exact matching 也受 Haitian Creole 拼寫變體、French interference 與提示歧義影響。故事分析以同一 Mistral 生成並抽取描述詞，可能產生自我強化偏差。模型數量亦因計算資源有限而偏少，論文未提供全面的跨模型比較與各指標具體數值。
