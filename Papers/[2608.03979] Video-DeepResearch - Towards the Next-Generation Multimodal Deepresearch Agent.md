# Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.03979)
- 📥 [PDF](https://arxiv.org/pdf/2608.03979v1)

## 摘要（中文翻譯）

本文提出 Video-DeepResearch（Video-DR），將 multimodal deep-research agent 從靜態影像延伸至連續影片串流，要求模型同時進行密集的時空 grounding 與開放網路探索。作者發現現有模型存在兩項瓶頸：偏好文字搜尋而忽略視覺工具的 modality bias，以及依賴參數記憶、未真正執行工具增強推理的 parametric knowledge leakage。為此，作者設計 decoupled perception-exploration pipeline，透過 stage-wise tool unlocking，先強制跨影格視覺 grounding，再開放網路檢索。訓練採用 supervised fine-tuning（SFT）接續 Group Relative Policy Optimization（GRPO），並建立含複雜 multi-hop VQA 的 Video-DR-Bench。Video-DeepResearch-35B-A3B 達 64.0% 平均準確率，30B-A3B 達 59.3%。

## 問題背景

現有 deep-research agent 多從文字或靜態影像出發，難以處理連續影片中的跨影格、跨實體時空 grounding 及後續開放網路查證。作者的初步實驗顯示模型偏好文字搜尋、幾乎不使用視覺工具；部分模型即使幾乎不呼叫工具仍能答對，反映既有基準容易受到 parametric knowledge leakage 影響，無法可靠衡量真正的工具增強影片研究能力。

## 解決方案

作者提出 Video-DeepResearch，將感知與探索解耦。agent 先使用 Select_Keyframe 選取關鍵時刻，再以 Crop_Search 對人物、物件、標誌或文字等實體進行局部視覺搜尋；只有完成視覺 grounding 後，才解鎖 Search 與 Visit 進行外部知識檢索和答案整合。資料方面以多階段篩選、視覺搜尋驗證、tool-free leakage 過濾及 reject sampling 建構高品質軌跡；訓練方面結合 SFT 與 GRPO，使模型先模仿正確流程，再透過成功 rollout 學習自主探索。

## 核心貢獻
1. 提出 Video-DeepResearch 框架，以 Select_Keyframe 與 Crop_Search 執行跨影格、跨實體的視覺 grounding，並在後續階段進行文字網路探索。
2. 建立資料生成與軌跡建構流程，產生 30K video-grounded VQA pairs 與 7K 經驗證的正確執行軌跡，並以 SFT 加 GRPO 訓練 agent。
3. 提出 Video-DR-Bench，由人類與 AI 協作建立 multi-hop VQA 評測集，用工具依賴過濾降低 parametric knowledge leakage。

## 技術方法

任務被形式化為序列決策問題：agent 根據問題、影片或預取 keyframes、歷史動作與觀察結果產生工具動作。資料處理分三階段。第一階段以影片長度規則與 agent-based filter 篩選多領域影片。第二階段先以 CLIP 產生候選 keyframes，再由 Qwen3.5-397B-A17B 選取影格並預測 bounding boxes；對實體 crop 執行 visual search，由 Qwen3.5-35B-A3B 驗證搜尋結果與影像語義是否一致，形成含影格、框選實體與搜尋摘要的 metadata。接著以 single-entity 或 multi-entity 模式生成 VQA，並進行四次 tool-free rollout；若任一次可答對，便刪除該題，以降低參數記憶洩漏。第三階段建構軌跡：感知階段只開放 Select_Keyframe 與 Crop_Search，強制跨影格、跨實體視覺探索；達到充分感知或上限後，才解鎖 Search 與 Visit。僅保留成功軌跡，得到 7K trajectories。訓練先用 7K video trajectories 加 7K text-only QA 進行 SFT，再以 2K 中等難度資料進行 GRPO；每題四次 rollout，保留 Pass@4 介於 0 與 1 的樣本，正確答案獲得二元 reward，並對格式錯誤或重複迴圈的負梯度以 20% 機率採用。評測在 agentic setting 下進行，模型可使用完整視覺與文字工具；最後答案由 Qwen3-VL-30B-A3B-Instruct 依官方 judge prompt 判定，指標主要為 accuracy，並另報告六類別分數與平均工具呼叫次數。

## 關鍵結果

主要結果如下；論文表格將 VideoDR 與 VideoDR-Bench 分開報告，且正文稱 VideoDR-Bench 為 200 instances，但實驗設定段落稱評估集為 100 VQA pairs，存在規模表述不一致。

| 模型 | Video-DR Acc. | VideoDR-Bench Overall | Avg. |
|---|---:|---:|---:|
| GPT-5 | 57.0% | 48.0% | 52.5% |
| Gemini 2.5 Pro | 62.0% | 53.0% | 57.5% |
| Claude-4.5-Sonnet | 63.0% | 55.0% | 59.0% |
| Qwen3-VL-30B-A3B-Instruct | 38.0% | 43.0% | 40.5% |
| Video-DeepResearch-30B-A3B | 62.0% | 56.5% | 59.3% |
| Qwen3.5-35B-A3B | 42.0% | 43.5% | 42.8% |
| Video-DeepResearch-35B-A3B | 68.0% | 60.0% | 64.0% |

30B 相對其 base model 的平均提升為 18.8 個百分點，35B 提升 21.2 個百分點。消融實驗中，30B 的 Base、4K-SFT、7K-SFT、加入 7K text-only SFT，以及再加入 2K-RL 的平均分數分別為 40.5%、46.0%、53.0%、56.8% 與 59.3%。工具使用方面，Video-DR 上 30B-A3B 平均呼叫視覺工具 2.33 次、文字工具 4.24 次；論文未報告工具使用與正確率的因果分析。

## 對我們的啟發
- [ ] 對 multimodal agent 評測而言，僅看最終答案不足以確認真實的視覺理解；應同時記錄視覺工具、文字搜尋、資料來源與執行順序。
- [ ] stage-wise tool unlocking 可作為訓練與評測設計模式，先要求模型取得可驗證的視覺證據，再允許外部知識檢索，以降低文字捷徑與記憶猜答。
- [ ] 消融結果顯示視覺軌跡 SFT、文字研究資料與 RL 各自提供增益；實務上可採 curriculum training，逐步培養 grounding、檢索及自主探索能力。

## 限制與未來工作

框架需要大量 GPU 與動態網路搜尋，資料生成、模型部署及訓練成本高。基準建立仍依賴人工標註，限制快速擴展。論文也存在資料集規模表述不一致，且主要正確性由 Qwen3-VL-30B-A3B judge 評估，未充分報告多評審一致性、工具軌跡品質與外部模型偏差。未來將探索更高效的 pipeline、輕量架構及自動化 LLM 評測。
