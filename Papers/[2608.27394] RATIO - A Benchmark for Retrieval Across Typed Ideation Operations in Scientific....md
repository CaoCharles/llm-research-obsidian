# RATIO: A Benchmark for Retrieval Across Typed Ideation Operations in Scientific Literature

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.27394)
- 📥 [PDF](https://arxiv.org/pdf/2608.27394v1)

## 摘要（中文翻譯）

科學文獻的檢索結果可為人類與 AI 科學家提供靈感，而靈感具有不同形式：既有研究可能直接建議如何處理問題，也可能在不同抽象層次提供方向，例如向上概括為更一般的觀點，或向下具體化為可實現的案例。本論文提出 RATIO（Retrieval Across Typed Ideation Operations）benchmark，以三種 ideation moves 定義 relevance：ADDRESS 檢索可處理既定問題的潛在方法；BROADEN 檢索更一般化的表述；SPECIFY 檢索具體的實例化。RATIO 從 CS 領域數百萬篇 full-text 論文建立，將原本用於 classification 的 discourse-marker distant supervision 擴展至 corpus-scale retrieval，並結合廣泛的 LLM 與 human vetting。實驗顯示，針對操作進行 fine-tuning 能大幅提升 retriever 表現，但仍有相當大的改進空間。RATIO 提供可擴展的 training 與 evaluation framework，支持以文獻為基礎的科學構想生成。

## 問題背景

現有 scholarly retrieval benchmark 多以 topical relevance 或回答 search query 為核心，無法區分一段文獻在構想過程中是用來解決問題、提升抽象層次，還是提供具體實例。這使支援 literature-grounded ideation 的系統缺乏針對性 retrieval 評測與訓練資源。另一方面，若以人工方式在數百萬篇 full-text 論文中標註這些隱含且具方向性的關係，成本過高，因此需要兼具規模與品質的 benchmark construction 方法。

## 解決方案

作者提出 RATIO，將科學靈感檢索形式化為 relation-conditioned retrieval。給定 query sentence 與指定 ideation operation，系統須從共享且異質的科學句子 corpus 中排序候選句：ADDRESS 尋找可直接回應問題的方法或洞見，BROADEN 尋找更廣泛或更高階的表述，SPECIFY 尋找更具體的案例、機制或例子。核心創新是以經驗驗證的 discourse markers 作為 distant supervision，從相鄰句子挖掘 query–positive pairs，再透過 temporal split、distractor markers、human vetting 與 human-calibrated LLM judgments 建立高品質評測集。

## 核心貢獻
1. 提出以 ADDRESS、BROADEN、SPECIFY 三種明確 ideation operation 定義科學靈感 retrieval relevance 的任務形式化。
2. 提出將 discourse-marker distant supervision 從 sentence-pair classification 擴展至大規模 relation-conditioned retrieval 的 benchmark construction recipe，並結合 LLM 與 human validation。
3. 建立含超過 3 百萬 query–positive pairs、temporal held-out split、共享候選池與 distractor hard negatives 的 RATIO benchmark，並證明 operation-specific fine-tuning 能改善 retrieval，但任務仍未解決。

## 技術方法

資料來自 Kinney et al.（2023）的 CS full-text 論文 corpus，論文先清理、正規化並切分句子，再掃描連續句對。若後一句以已驗證 marker 開頭，便移除 marker，將前一句作為 query q、後句剩餘內容作為 gold candidate g，並依 marker 歸入 ADDRESS、BROADEN 或 SPECIFY。marker lexicon 透過人工整理、可延伸 connective、LLM expansion 與 rule-based pattern expansion 建立；最終共有 4,252 個 marker，其中 809 個在約 366.6M 個連續句對中實際命中。資料依出版日期切分：train 為 2015 至 2025-09-30，validation 為 2025 年末，test 為 2026-01-01 至 2026-05-05；候選池跨三種 operation 共享，並加入非目標 discourse markers 產生 hard distractors。主要模型包括 BM25、all-mpnet-base-v2、ModernBERT-embed-large 與 Stella-en-1.5B-v5；dense retriever 使用 relation-specific contrastive fine-tuning 與 in-batch negatives。評估包含 Recall@1/10、MRR@10/100，以及由 GPT-5.4 依人類校準 prompt 判斷 top-10 候選的 Hit Rate、Precision、nDCG、MRR、MAP；另以 reference-free pairwise judge 比較 fine-tuned 與 baseline ranking 的 inspiration potential。

## 關鍵結果

主要結果如下（silver test set，數值為百分比）：

| Operation | Model | Setup | R@1 | R@10 | MRR@10 |
|---|---|---:|---:|---:|---:|
| SPECIFY | ModernBERT-embed-large | Baseline | 20.5 | 39.1 | 26.7 |
| SPECIFY | ModernBERT-embed-large | Tuned | 37.2 | 65.5 | 46.7 |
| ADDRESS | ModernBERT-embed-large | Baseline | 6.7 | 17.8 | 10.2 |
| ADDRESS | ModernBERT-embed-large | Tuned | 17.2 | 40.0 | 24.5 |
| BROADEN | ModernBERT-embed-large | Baseline | 13.4 | 26.0 | 17.3 |
| BROADEN | ModernBERT-embed-large | Tuned | 20.9 | 41.4 | 27.3 |

作者報告 operation-specific fine-tuning 對三種操作皆有實質提升；ModernBERT-embed-large 在 silver set 的各 operation 均為最佳模型。即使是最佳模型，ADDRESS 與 BROADEN 仍有多數 query 無法成功命中 gold，且 MRR@100 相較 MRR@10 最多僅增加 0.8 個百分點，顯示失敗通常不是接近正確答案。Top-10 候選的 LLM 評估顯示，tuned 模型的 Hit Rate@10 為 SPECIFY 89.0%、ADDRESS 76.5%、BROADEN 29.0%，baseline 分別為 65.5%、40.5%、19.3%。在 reference-free inspiration preference 中，tuned list 被偏好：ADDRESS 70.2%、SPECIFY 61.6%、BROADEN 56.2%。

## 對我們的啟發
- [ ] 若 RAG 系統的目的不只是找主題相關文獻，而是支援研究構想，retrieval query 應明確指定 ADDRESS、BROADEN 或 SPECIFY 等功能，並可採用 operation-specific expert 或 routing。
- [ ] 單一 gold 的 Recall/MRR 可能低估實際 retrieval 能力；實務評估應允許多個有效候選，並加入 candidate-level judgment、Hit Rate、nDCG 或 MAP。
- [ ] 共享候選池與非目標 discourse-marker distractors 能降低只靠候選風格或 operation classification 的捷徑，適合用於測試真正的 query-conditioned relational matching。

## 限制與未來工作

RATIO 的 supervision 主要來自相鄰句子與 discourse markers，未涵蓋跨段落、跨論文推理，也不保證 marker pair 永遠符合目標關係。資料目前聚焦 CS，且 BROADEN 樣本較少、表現最弱。silver test 與 top-10 評估大量依賴 human-calibrated LLM judgments，完整人工標註仍有限。作者建議擴展至其他領域、非相鄰句關係、更多人工 annotations，以及端到端科學 reasoning 與 ideation 系統。
