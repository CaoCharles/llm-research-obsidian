# RATIO: A Benchmark for Retrieval Across Typed Ideation Operations in Scientific Literature

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.27394)
- 📥 [PDF](https://arxiv.org/pdf/2608.27394v1)

## 摘要（中文翻譯）

科學文獻可為人類與 AI 科學家提供靈感，而靈感具有不同形式：既有研究可能直接提出解決問題的方法，也可能在不同抽象層次上提供方向，例如將問題推向更一般的表述，或落實為更具體的實例。本論文提出 RATIO（Retrieval Across Typed Ideation Operations）benchmark，以三種 ideation moves 定義相關性：ADDRESS 檢索可處理既定問題的潛在方法；BROADEN 檢索更一般化的 formulation；SPECIFY 檢索具體的 instantiation。RATIO 從 CS 領域數百萬篇全文論文建立，將 discourse-marker distant supervision 從分類任務擴展至大規模 retrieval，並結合 LLM 與人工審查。實驗顯示，針對操作進行 fine-tuning 能顯著提升 retriever，但整體仍有很大改進空間。

## 問題背景

現有 scientific retrieval benchmark 多評估 topical relevance，或文件是否回答 search query，無法區分候選句在科學構思中扮演的功能角色。對 literature-grounded ideation 而言，系統需要分別找到解決問題的方法、較高層次的概括，以及更具體的實例；然而這些關係常由隱含語意決定，表面詞彙不一定明顯。論文因此要建立可大規模訓練與評估 typed inspiration retrieval 的 benchmark。

## 解決方案

作者提出 RATIO，將檢索相關性明確化為 ADDRESS、BROADEN、SPECIFY 三種 ideation operation，並以全文論文中的 discourse markers 作為作者自我標示的 distant supervision。方法先建立並驗證 operation-specific marker lexicon，再從相鄰句擷取 query–candidate pair，移除 marker 後放入共享候選池。透過人工審查、LLM 驗證與人類校準，建立較高品質的 silver test set；同時採用時間切分與非目標 discourse-marker distractors，降低資料洩漏及候選池捷徑。

## 核心貢獻
1. 提出以 ADDRESS、BROADEN、SPECIFY 三種 typed ideation operation 定義 scientific inspiration retrieval 的 RATIO benchmark。
2. 提出將 discourse-marker distant supervision 從 sentence-pair classification 擴展至大規模、關係條件式 corpus retrieval 的建構流程，並結合 LLM 與人工校準。
3. 建立包含時間切分、共享異質候選池、distractor negatives 與 silver test set 的全文句子級資源，並證明 operation-specific fine-tuning 能改善 retriever。

## 技術方法

任務輸入為 scientific statement q、操作 r∈{ADDRESS,BROADEN,SPECIFY} 與全文句子候選庫 C，模型須依 q 與 r 排序候選句。ADDRESS 定義為候選句提出可直接處理問題的方法或洞見；BROADEN 將 q 改寫至更高抽象層次；SPECIFY 則提供 q 的具體案例、機制或實例。資料來自 2016 年前後至 2026 年的 CS 全文論文，先進行句子切分、清理與相鄰句配對，再使用人工 curated、LLM-generated、可延伸 connective 與 pattern expansion 建立 marker lexicon。共取得 4,252 個 marker，其中 809 個在約 366.6M 個相鄰句對中觸發，形成約 3.02M 個 pair。資料按出版日期切分：訓練集至 2025 年 9 月 30 日，驗證集為 2025 年第四季，測試集為 2026 年初；候選池跨三種操作共享，並加入非目標 discourse marker 產生的 distractors。模型比較 BM25、all-mpnet-base-v2、ModernBERT-embed-large 與 Stella-en-1.5B-v5；dense retriever 使用 operation-specific contrastive fine-tuning 與 in-batch negatives。主要指標為 Recall@1/10、MRR@10/100，以及以 LLM 評估 top-10 候選的 Hit Rate、Precision、nDCG、MRR、MAP。silver set 由人類校準的 LLM prompts 篩選，另以 top-10 candidate-level judgment 與 reference-free inspiration preference 補充單一 gold 指標。

## 關鍵結果

主要結果如下（silver test set，百分比）：

| 操作 | 模型/設定 | R@1 | R@10 | MRR@10 | MRR@100 |
|---|---|---:|---:|---:|---:|
| SPECIFY | BM25 | 13.0 | 27.3 | 17.6 | 18.1 |
| SPECIFY | ModernBERT baseline | 20.5 | 39.1 | 26.7 | 27.3 |
| SPECIFY | ModernBERT tuned | 37.2 | 65.5 | 46.7 | 47.4 |
| ADDRESS | BM25 | 5.3 | 15.2 | 8.3 | 8.7 |
| ADDRESS | ModernBERT baseline | 6.7 | 17.8 | 10.2 | 10.6 |
| ADDRESS | ModernBERT tuned | 17.2 | 40.0 | 24.5 | 25.3 |
| BROADEN | BM25 | 7.9 | 17.6 | 10.9 | 11.3 |
| BROADEN | ModernBERT baseline | 13.4 | 26.0 | 17.3 | 17.9 |
| BROADEN | ModernBERT tuned | 20.9 | 41.4 | 27.3 | 27.8 |

ModernBERT tuned 在三種操作均優於未微調版本；相對提升約為 1.6–2.4 倍，但 ADDRESS 與 BROADEN 的絕對表現仍有限。top-10 LLM candidate evaluation 顯示，tuned 模型的 hard-agreement Hit Rate 為 SPECIFY 89.0%、ADDRESS 76.5%、BROADEN 29.0%，相較 baseline 分別為 65.5%、40.5%、19.3%。對 top-10 list 的 Precision，tuned 結果為 23.0%、16.7%、3.6%。此外，ADDRESS 有 41.2% 的 query 雖未取回 mined gold，卻取回其他被判定有效的候選；SPECIFY 與 BROADEN 分別為 24.0% 與 12.0%。reference-free inspiration preference 中，tuned list 被偏好的比例為 ADDRESS 70.2%、SPECIFY 61.6%、BROADEN 56.2%。

## 對我們的啟發
- [ ] RAG 系統不應只用 topical similarity 衡量文獻相關性；可依使用者意圖將檢索路由至 addressing、generalizing 或 concretizing 等不同操作。
- [ ] 單一 gold 的 Recall/MRR 可能低估 inspiration retrieval，實務評估應允許多個有效候選，並加入 top-k candidate-level judgment。
- [ ] 共享候選池與 hard negatives 有助於檢驗模型是否真正學到 query-conditioned compatibility，而非只辨識候選句的文體或 rhetorical role。

## 限制與未來工作

資料主要來自 CS 全文論文，且 supervision 依賴相鄰句與 discourse markers，可能遺漏沒有明示標記的有效關係。silver 與 top-k 評估大量依賴經人類校準的 LLM，仍可能存在判斷偏差。BROADEN 資料量與表現尤其有限。作者建議擴展至非相鄰句、其他領域、更多人工標註，並整合至端到端 scientific reasoning 系統。
