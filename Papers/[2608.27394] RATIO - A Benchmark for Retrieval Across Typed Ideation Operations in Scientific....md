# RATIO: A Benchmark for Retrieval Across Typed Ideation Operations in Scientific Literature

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.27394)
- 📥 [PDF](https://arxiv.org/pdf/2608.27394v1)

## 摘要（中文翻譯）

Retrieved scientific literature 可作為人類與 AI 科學家的靈感來源，而靈感具有不同形式：既有研究可能直接提出解決問題的方法，也可能在不同抽象層次提供方向，包括向上概括為更一般的觀點，或向下具體化為可實現的案例。我們提出 RATIO（Retrieval Across Typed Ideation Operations）大型 benchmark，以三種 ideation moves 定義 relevance：ADDRESS 從既定問題中檢索潛在方法，BROADEN 檢索更一般的 formulation，SPECIFY 檢索具體 instantiation。RATIO 從 CS 領域數百萬篇 full-text scientific papers 建構，採用將 discourse-marker distant supervision 從 classification 擴展至 corpus-scale retrieval 的通用方法，並結合廣泛的 LLM 與人工審查。實驗顯示，針對操作進行 fine-tuning 能大幅提升 retriever 表現，但仍有很大改善空間。RATIO 提供可擴展的 training 與 evaluation framework，支援以文獻為基礎的科學構想生成。

## 問題背景

現有 scholarly retrieval benchmarks 多以 topical relevance 或是否回答 search query 為標準，無法區分候選文獻在科學構想過程中扮演的不同角色。對 literature-grounded ideation 而言，系統不只要找到主題相關內容，還要辨識某段文字是在解決問題、提高抽象層次，或提供具體案例。這些關係通常是隱含的，且缺乏可大規模訓練與評估的 sentence-level retrieval 資源。

## 解決方案

作者提出 RATIO，將科學靈感檢索形式化為 query、指定 ideation operation 與候選 scientific sentence 之間的 relation-conditioned retrieval。核心創新是利用作者自行使用的高精度 discourse markers 產生 distant supervision：例如 “to address this problem” 對應 ADDRESS，“more generally” 對應 BROADEN，“as an example” 對應 SPECIFY。作者建立經人工、規則與多個 LLM 擴展及審查的 marker lexicons，從 full-text papers 擷取相鄰句對，再透過時間切分、共享候選池、distractor markers、LLM 驗證與人類校準，形成可用於訓練與評估的大型 benchmark。

## 核心貢獻
1. 提出三種具明確功能定義的 scientific ideation moves：ADDRESS、BROADEN 與 SPECIFY，將靈感檢索從一般 topical relevance 擴展為 operation-conditioned relevance。
2. 提出以 discourse-marker distant supervision 建構 relation-conditioned、sentence-level、corpus-scale retrieval benchmark 的通用 recipe，並結合 LLM validation 與 human calibration。
3. 發布 RATIO 大型 full-text benchmark、temporal held-out evaluation sets 與共享候選池，實驗證明 operation-specific fine-tuning 可提升檢索品質，但任務仍未解決。

## 技術方法

RATIO 將每篇論文切分為句子，掃描連續句對。若後一句以前綴 discourse marker 開頭，便移除 marker，將前一句作為 query q、剩餘命題作為候選 gold g，並依 marker 歸入 ADDRESS、BROADEN 或 SPECIFY。marker lexicon 先由 NLP experts 手動整理，再透過 LLM generation、可擴展 connective、rule-based pattern expansion 建立；最終 4,252 個 marker 中有 809 個在語料中實際觸發，產生約 3.02M 個 query-positive pairs。資料依出版日期作 temporal split：training 為 2015 至 2025 年 9 月，validation 為 2025 年末，test 為 2026 年 1 月至 5 月，且三種 relation 共用同一候選池；另加入非目標 discourse markers 所產生的 distractors，避免以候選池來源猜測 relevance。主要模型包括 BM25、all-mpnet-base-v2、ModernBERT-embed-large 與 Stella-en-1.5B-v5；dense retrievers 分別針對三種 operation 以 in-batch negatives 進行 contrastive fine-tuning。評估使用 Recall@1/10、MRR@10/100，並建立 17,579 筆經人類校準 LLM 驗證的 silver test set。此外，抽取每種 relation 各 400 個 query，讓 LLM 對 top-10 候選進行 candidate-level 判斷，計算 Hit Rate、Precision、nDCG、MRR 與 MAP；另以 blind pairwise LLM judge 比較 fine-tuned 與 baseline top-5 ranking 的 inspiration potential。

## 關鍵結果

主要結果如下（silver test set，百分比）：

| Operation | Model | R@1 | R@10 | MRR@10 | MRR@100 |
|---|---|---:|---:|---:|---:|
| SPECIFY | BM25 | 13.0 | 27.3 | 17.6 | 18.1 |
| SPECIFY | ModernBERT baseline | 20.5 | 39.1 | 26.7 | 27.3 |
| SPECIFY | ModernBERT tuned | 37.2 | 65.5 | 46.7 | 47.4 |
| ADDRESS | BM25 | 5.3 | 15.2 | 8.3 | 8.7 |
| ADDRESS | ModernBERT baseline | 6.7 | 17.8 | 10.2 | 10.6 |
| ADDRESS | ModernBERT tuned | 17.2 | 40.0 | 24.5 | 25.3 |
| BROADEN | BM25 | 7.9 | 17.6 | 10.9 | 11.3 |
| BROADEN | ModernBERT baseline | 13.4 | 26.0 | 17.3 | 17.9 |
| BROADEN | ModernBERT tuned | 20.9 | 41.4 | 27.3 | 27.8 |

Move-specific fine-tuning 在三種 operation 均有效；ModernBERT tuned 在 silver set 所有 operation 均為最佳。top-10 candidate-level hard agreement 下，tuned 模型的 Hit Rate@10 為 SPECIFY 89.0%、ADDRESS 76.5%、BROADEN 29.0%，baseline 分別為 65.5%、40.5%、19.3%。ADDRESS 中有 41.2% 的 query 雖未找回 mined gold，top-10 仍包含被判定有效的替代候選；SPECIFY 與 BROADEN 分別為 24.0% 與 12.0%。blind inspiration comparison 中，tuned list 被偏好的比例為 ADDRESS 70.2%、SPECIFY 61.6%、BROADEN 56.2%。

## 對我們的啟發
- [ ] 若 RAG 系統的目標是研究構想生成，retrieval query 應明確指定功能，例如尋找解法、一般化原理或具體案例，而不應只依賴單一相似度搜尋。
- [ ] 同一候選池中混合不同 rhetorical functions 並加入 hard distractors，有助於測試模型是否真正學到 query-conditioned relation，而不是只做主題匹配或 operation 分類。
- [ ] 單一 gold 的 Recall 或 MRR 可能低估靈感檢索能力；實務評估宜同時採用多正例、candidate-level judging 與 reference-free ranking comparison，以辨識有效但不同於標註 gold 的候選。

## 限制與未來工作

資料主要來自 CS full-text papers，且正例依賴相鄰句子與 discourse markers，可能遺漏未使用明確標記或跨句、跨段落的有效關係。silver test 與 top-10 評估大量依賴 LLM 判斷，BROADEN 的校準一致性相對較低。作者指出未來應擴展至其他領域、非相鄰文本、更多人工標註，並整合至端到端 scientific reasoning 與 ideation systems。
