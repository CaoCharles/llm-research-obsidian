# Defining Decentralization: An Ontological Perspective

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.09748)

## 摘要（中文翻譯）

去中心化（Decentralization）在 computer science 中已存在逾半世紀，並廣泛應用於 security、distributed computing、artificial intelligence、cloud infrastructure 與 Internet of Things（IoT）架構。然而，目前仍缺乏適用於各類 computer communication systems 的普遍定義。隨著 collaborative training、distributed inference、blockchain-based AI 與 agentic AI 等 decentralized AI／machine learning 範式興起，此問題更加嚴重。既有研究常將去中心化與 trust distribution 或特定實作範式混為一談，造成系統分析不一致、研究結果難以比較，也削弱通信架構與協定設計的形式化推理。本文將此研究缺口定義為 Decentralization Problem，分析其形式語義、認識論與實務基礎，提出以圖為基礎的 ontology，將去中心化定義為 computer communication systems 的 relational 且 subject-specific property。本文進一步提出 Void Tolerance 與 Imperviousness 兩項指標，並提供 browser-based implementation，以自動分類任意系統並計算指標。對 federated learning 與 blockchain 的實例化顯示，該框架能產生一致且可比較的評估。

## 問題背景

本文要解決 computer communication systems 缺乏普遍且一致的 decentralization 定義之問題。現有研究常把 decentralization 與 distribution、trust distribution 或特定實作範式混為一談，導致系統分析不一致、不同研究難以比較，並削弱通信架構與協定設計中的形式化推理。這些問題在 decentralized AI、collaborative training、distributed inference、blockchain-based 與 agentic AI 興起後更加突出。

## 解決方案

作者提出一套跨領域的 graph-based ontology，從 formal-semantic、epistemological 與 pragmatic 基礎重新界定 decentralization。該框架將去中心化視為 computer communication systems 的 relational 與 subject-specific property，因而能描述「對何種 subject、基於何種關係」的去中心化，而非將其簡化為節點分散或信任分散。框架也形式化區分 decentralization 與 distribution，並引入 Void Tolerance 與 Imperviousness 兩項指標；配合 browser-based implementation，可對任意系統自動分類與計算指標。

## 核心貢獻
1. 將跨 computer communication systems 的去中心化定義問題明確化為 Decentralization Problem，並分析其 formal-semantic、epistemological 與 pragmatic foundations。
2. 提出 graph-based ontology，將 decentralization 定義為具 relational 與 subject-specific 性質的系統屬性，並形式化區分 decentralization 與 distribution。
3. 提出 Void Tolerance 與 Imperviousness 兩項評估指標，且提供 browser-based implementation，支援任意系統的自動分類與指標計算。

## 技術方法

本文首先從 formal-semantic、epistemological 與 pragmatic 三個層面分析 decentralization 的基礎，並將現有研究把 decentralization 與 distribution、trust distribution 或特定 implementation paradigm 混用的問題界定為 Decentralization Problem。接著，作者建立 graph-based ontology，以通信系統中的關係與特定 subject 為分析單位，將 decentralization 表述為 relational 且 subject-specific property，並在形式上區分 decentralization 與 distribution。評估部分引入兩項新指標：Void Tolerance 與 Imperviousness；摘要指出它們可用於系統評估，但未提供完整數學公式、輸入表示、演算法步驟、閾值設定或複雜度資訊。實作方面，作者提供 browser-based implementation，支援對 arbitrary systems 進行 automated classification 與 metric computation。驗證則透過 federated learning 與 blockchain architectures 的 instantiation，檢查框架是否能產生一致且可比較的分析，並與既有 definitions 所導致的不完整或矛盾結論形成對照。摘要未說明資料集、實驗樣本數、baseline、統計檢定或具體數值。

## 對我們的啟發
- [ ] 在評估 federated learning、blockchain 或 agentic AI 系統時，不宜僅以節點數量、資料分散或 trust distribution 判定是否去中心化，應先明確指定評估關係與 subject。
- [ ] 若需比較不同通信架構，應採用一致的 ontology 與可計算指標，以減少因定義不一致造成的矛盾結論。
- [ ] 系統設計與協定分析可將 Void Tolerance、Imperviousness 作為補充性分析維度；不過，實際採用前仍需依論文完整定義確認其計算方式與適用範圍。
