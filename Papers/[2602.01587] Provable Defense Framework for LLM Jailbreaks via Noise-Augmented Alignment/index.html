    Provable Defense Framework for LLM Jailbreaks via Noise-Augmented Alignment

    連結

    • 📄 arXiv
    • 📥 PDF

    摘要（中文翻譯）

    本研究針對大型語言模型在對抗性擾動下的越獄攻擊提出可證明的防禦框架。儘管現有安全對齊技術取得一定成效，但 LLM 仍容易受到精心設計的對抗性提示攻擊。論文提出噪聲增強對齊（Noise-Augmented Alignment）框架，在訓練過程中引入可控噪聲來增強模型對對抗性擾動的魯棒性。關鍵創新是建立理論證明：在特定噪聲分佈下，模型對一定範圍內的對抗性擾動具有可證明的防禦能力。框架結合隨機平滑技術和對齊訓練，在保持模型正常性能的同時顯著提升對越獄攻擊的抵抗力。實驗顯示該方法能夠在多種攻擊場景下提供理論保證的防禦效果，為 LLM 安全部署提供更可靠的解決方案。

    問題背景

    現有 LLM 安全對齊方法缺乏理論保證，在面對適應性對抗攻擊時容易失效。啟發式防禦機制（如提示過濾、輸出檢測）可被繞過，而缺乏可證明安全性的對齊框架。如何在理論上保證 LLM 在對抗性擾動下仍能維持安全行為，是實際部署的關鍵挑戰。

    解決方案

    提出噪聲增強對齊框架，結合隨機平滑和安全對齊訓練。核心機制：(1) 在訓練時對輸入添加高斯噪聲，學習對噪聲魯棒的安全策略；(2) 利用隨機平滑理論，建立對抗魯棒性的可證明界限；(3) 設計噪聲感知的對齊目標函數，平衡安全性、可用性和魯棒性。理論分析證明，在 L2 範數有界的對抗擾動下，模型輸出安全性可得到概率保證。

    核心貢獻

    1. 提出首個為 LLM 越獄防禦提供理論安全保證的對齊框架
    2. 設計噪聲增強訓練方法，結合隨機平滑技術實現可證明魯棒性
    3. 在保持模型可用性的前提下，對多種對抗攻擊提供理論保證的防禦能力

    技術方法

    框架包含訓練和推理兩階段。訓練階段：(1) 對每個訓練樣本的嵌入表示添加高斯噪聲 N(0, σ²I)；(2) 在噪聲增強樣本上執行標準安全對齊（如 DPO、PPO）；(3) 使用認證損失函數，鼓勵模型在噪聲球內保持一致的安全輸出。推理階段：採用隨機平滑認證，對輸入進行多次噪聲採樣，透過多數投票決定輸出，並計算安全性的認證半徑。理論分析基於 Neyman-Pearson 引理，證明在給定信心水平下，模型對特定擾動範圍內的攻擊具有防禦保證。評估在多個對抗攻擊基準上測試認證準確率和魯棒半徑。

    關鍵結果

    防禦方法 乾淨準確率 認證魯棒率 (ε=0.5) 認證半徑
    標準對齊 92.3% 23.1% 0.18
    對抗訓練 88.7% 54.6% 0.31
    噪聲增強對齊 90.1% 78.4% 0.52
    認證安全保證 - 95% 信心 -

    對我們的啟發

    • 隨機平滑技術可成功遷移到 LLM 安全領域，為對齊提供理論保證
    • 噪聲增強訓練的關鍵是平衡噪聲強度：過低無法提供足夠魯棒性，過高損害模型可用性
    • 可證明防禦相比啟發式方法更可靠，但計算成本較高，需在安全性和效率間權衡

    限制與未來工作

    隨機平滑推理需要多次前向傳播，增加 10-50 倍延遲，限制實時應用。認證半徑與模型性能存在權衡，更大的魯棒性需要犧牲準確率。理論保證基於 L2 範數擾動，對離散文本空間的對抗攻擊保證較弱。未考慮適應性攻擊者專門針對隨機平滑防禦的策略。
