# DreamFly: Causal Memory and Receding-Horizon Diffusion Planning for Aerial Vision-Language Navigation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.12308)
- 📥 [PDF](https://arxiv.org/pdf/2608.12308v1)

## 摘要（中文翻譯）

Aerial vision-language navigation（Aerial VLN）要求具身 agent 在部分可觀測環境中，隨時間整合視覺證據、規劃未來動作，並判斷是否抵達導航目標。現有 VLA 方法應用於空中導航時，可能因歷史上下文不足而遺失地標，單步動作預測的規劃視野有限，且透過一般動作生成隱式決定終止往往不可靠。本文提出建立於 Dream-VLA 之上的 diffusion-based 框架 DreamFly。其一，設計因果對齊的歷史記憶，只使用當前決策步驟之前取得的觀測，避免未來資訊洩漏；其二，將導航形式化為 receding-horizon diffusion planning，預測 K 步 action chunk，但僅執行第一個動作後重新規劃；其三，提出 LiteStop，從初始 all-mask 狀態的 action logits 直接估計停止機率，使終止判斷與動作生成解耦。在 OpenFly 上，DreamFly 於 seen 與 unseen 環境均提升表現。

## 問題背景

Aerial VLN 是部分可觀測的閉迴路 3D 導航問題，UAV 必須同時處理水平、垂直與視角變化。現有方法主要有三項不足：僅依賴當前觀測時容易遺失歷史地標；單步動作預測缺乏短期 lookahead；將 Stop 與一般動作一起生成，可能造成終止判斷不可靠。本文聚焦如何在不洩漏未來資訊下，統合歷史記憶、多步規劃與顯式終止。

## 解決方案

作者提出 DreamFly，一個建構於 Dream-VLA 的閉迴路 aerial VLN framework。第一，使用 read-before-write 的 causal memory，確保步驟 t 的歷史分支只包含 t 之前取得的視覺觀測，並透過 instruction-conditioned candidate selection、固定容量 slots 與 gated cross-attention 融合相關證據。第二，以 bidirectional discrete diffusion 預測 K 步 action chunk，但採 plan-K、execute-one：只執行首動作，之後依新觀測重新規劃。第三，LiteStop 從初始 all-mask action logits 推斷停止機率，獨立於 motion action policy 訓練，以改善顯式終止控制。

## 核心貢獻
1. 提出具有明確時間邊界的因果對齊歷史記憶，採用 read-before-write 協議，僅讓決策步驟前的觀測進入歷史分支，並以 gated cross-attention 融合目前視覺特徵。
2. 提出 receding-horizon diffusion planning，以 bidirectional diffusion 聯合預測 K 步離散動作，採用 plan-K、execute-one 策略，在利用未來動作結構的同時維持閉迴路重新規劃。
3. 提出 LiteStop 終止模組，從初始 all-mask planning logits 的完整 K×|A| action-logit grid 預測停止機率，並在凍結導航策略下獨立訓練。

## 技術方法

DreamFly 建立於 Dream-VLA 的離散 diffusion VLA backbone。輸入為導航指令 I、當前 egocentric RGB observation Ot，以及只由先前觀測構成的歷史記憶 M<t。記憶模組以 frozen CLIPSeg dense router 與 frozen OWLv2 region router 擷取 instruction-conditioned candidates，透過視覺與空間一致性建立 active tracks；穩定或符合條件的候選寫入最多 16 個 long-term slots，每步最多選擇兩個寫入候選。每個 slot 可保存 anchor、prototype、有效性與距離上次更新的步數。當前影像 token 作為 query、記憶 slot 作為 key/value，經 masked cross-attention 取得歷史 context，再以 gated residual connection 融合；其 projection 與 gate 零初始化，使初始 adapter 等同 identity mapping。訓練與部署皆採 read-before-write，訓練使用 expert trajectory prefix memory，部署則使用 agent 實際取得的歷史。動作規劃方面，模型以固定長度 K 的 masked action slots 聯合預測目前及未來動作，對有效 prefix 施加 cross-entropy，尾端 padding 的 Stop 不計入損失，並以 horizon weighting 強調近端動作。推論從全 MASK 狀態開始進行 iterative discrete diffusion，限制生成 token 屬於 action-token set；完整 chunk 生成後僅執行首動作，接收新觀測後重新規劃。LiteStop 讀取初始 all-mask 狀態下所有 K 個位置的 action-logit slices，經 LayerNorm 與 MLP 輸出停止機率；以當前 expert action 是否為 Stop 作二元標籤，正類權重為 4.0，且凍結導航策略獨立訓練。OpenFly 評估指標包括 navigation error（NE，越低越好）、success rate（SR）、oracle success rate（OSR）與 success weighted by path length（SPL）。成功條件為最終位置與目標的 Euclidean distance 小於 20 m。

## 對我們的啟發
- [ ] 對需要長序列決策的 embodied agent，歷史記憶應明確定義資訊可見性與讀寫時序；read-before-write 可作為避免時間洩漏的工程規範。
- [ ] 多步預測不必等同於開迴路執行；預測 action chunk、只執行首動作並在新觀測後重規劃，可兼顧短期規劃結構與環境反饋。
- [ ] 終止判斷具有不同於一般動作的錯誤代價，將其設為獨立模組與專門二元目標，有助於分析和控制 premature stopping 與抵達後繼續移動的問題。

## 限制與未來工作

目前評估僅在模擬環境 OpenFly 進行，尚未驗證實體 UAV 上的導航能力。作者將未來工作指向真實平台部署，並評估感測噪聲、環境擾動及 sim-to-real domain shift 下的 robustness。論文也未提供實機延遲、能耗或完整部署成本分析。
