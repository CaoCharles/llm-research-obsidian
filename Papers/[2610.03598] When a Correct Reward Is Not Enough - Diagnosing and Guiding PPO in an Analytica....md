# When a Correct Reward Is Not Enough: Diagnosing and Guiding PPO in an Analytically Solved Broker-Trader Game

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.03598)
- 📥 [PDF](https://arxiv.org/pdf/2610.03598v1)

## 摘要（中文翻譯）

強化學習（RL）日益用於複雜動態下的金融最佳控制問題；金融數學文獻則提供許多可解析模型，其方程式與控制策略可用來評估及引導學習。本文探討 RL 是否能利用這些結果。作者將 proximal policy optimisation（PPO）代理置於一個具有解析解的連續時間 broker–trader game 中，由 PPO 取代 broker，選擇交易速度，並與 informed trader 及隨機 uninformed order flow 互動。研究從 broker 的連續時間 payoff 推導 finite-step reward，並透過網格細化與 exact one-step identity 驗證離散實作。無 uninformed flow 時，經 validation 選出的 PPO–FFNN 可接近參考動作；加入隨機 uninformed flow 後，PPO–FFNN 與 PPO–LSTM 仍不準確，儘管 supervised learning 證實 actor 具備表達該動作的能力。Monte Carlo 診斷顯示 critic 無法可靠排序鄰近動作，potential-based reward shaping 也未帶來可靠改善。在 partial information 下，基於可觀測歷史的 causal certainty-equivalent controller 接近參考策略，而 PPO 的誤差較大、payoff 較低。最後，作者固定解析策略，讓 PPO 在 execution cost 改變後學習調整；成本減半時，方法重複性地改善表現，縮小相對新成本參考解差距的 2.22%。因此，解析解既可作為診斷 RL 的基準，也可作為策略適應的起點。

## 問題背景

本文研究 PPO 能否僅依靠正確的環境 reward，在具有已知解析最優策略的 broker–trader game 中恢復 state-dependent trading strategy，並在 execution cost 改變後進行適應。既有 optimal-execution RL 研究多聚焦於學習策略或調整解析排程，較少將可解析控制、離散 reward、partial information 與同狀態動作比較結合。本文特別要釐清：失敗究竟來自離散化、actor 表達能力、資訊不完整，還是 critic 無法提供可靠的局部動作排序。

## 解決方案

作者建立一個以 Cartea、Jaimungal 與 Sánchez-Betancourt broker–trader model 為基礎的 PPO 評測框架。首先由連續時間 broker payoff 推導含 Δt² cross-product 修正的 finite-step reward，並以 grid refinement、exact one-step identity 及 finite-grid LQ backward recursion 驗證參考策略。其次比較 full-information 下的 PPO–FFNN 與 PPO–LSTM，使用 supervised action imitation、payoff、action RMSE、LQ loss、critic local-ranking Monte Carlo 診斷及 potential-based shaping 分離問題來源。partial-information 下則與 causal certainty-equivalent controller 比較。最後固定原 execution cost 下的解析 broker policy，以零初始化的 residual PPO network 學習成本變動後的 additive adjustment。核心創新是把解析解同時用作嚴格 benchmark、學習診斷工具與 residual adaptation 起點。

## 核心貢獻
1. 推導並驗證適用於離散 PPO 環境的 finite-step broker reward，納入離散乘積法則產生的 Δt² 修正，並以網格細化、exact one-step identity 與 finite-grid LQ 解確認數值誤差不是主要因素。
2. 建立以解析 broker strategy 為 ground-truth 的 PPO 診斷流程，證明在 stochastic uninformed flow 下，actor 雖可透過 supervised learning 表達參考動作，PPO critic 卻無法可靠排序鄰近動作。
3. 提出以 frozen analytical policy 加 residual PPO 適應 execution-cost misspecification；在成本減半實驗中獲得可重複但有限的 payoff 改善，顯示解析策略可兼具 benchmark 與 initialization 功能。

## 技術方法

環境為 T=1 的連續時間 broker–trader game，以 Euler–Maruyama、Δt=2×10^-4、共 5,000 步離散化。狀態包含 broker/informed-trader inventory、price-impact state、midprice、predictive signal 與 uninformed flow；PPO 選擇 broker trading rate，動作執行前裁切至 [-100,100]。full-information policy 觀察完整狀態；partial-information policy 隱藏 informed-trader inventory 與 signal，僅觀察 broker 可得歷史、目前 uninformed flow 與前一步動作。PPO–FFNN 的 actor/critic 各為兩層、每層 64 個 ReLU 單元；PPO–LSTM 使用 24-unit LSTM 加 64-unit Tanh layer。每一設定使用五個 training seeds、每 seed 4×10^6 transitions，checkpoint 由 50 條 validation paths 的平均 payoff 選取，再於未使用的 test paths 評估。reward 為 action-dependent payoff rate 乘 Δt，加上由離散乘積法則導出的 Δt² 修正；γ=1。指標包括 broker payoff、相對 clipped finite-grid reference 的 payoff shortfall、action RMSE、LQ loss、critic explained variance，以及 critic 與 Monte Carlo cumulative return 的 Pearson、Spearman correlation 和 sign accuracy。另以 supervised learning 檢查 actor 容量，以 potential-based shaping 檢驗學習訊號，並以 certainty-equivalent filter 估計隱藏狀態。成本適應實驗則固定原解析策略，使用兩層、64-unit Tanh residual network，以 additive correction 進行 PPO 訓練。

## 對我們的啟發
- [ ] 評估 RL 控制器時，不能只看 episode payoff；應加入同狀態 action RMSE、finite-grid 最優解、local action-ranking 與 Monte Carlo return 診斷，以區分策略表達問題和 value estimation 問題。
- [ ] 在具有解析或半解析控制器的環境中，可先用 supervised imitation 驗證 actor 容量，再測試 PPO；若 imitation 成功而 PPO 失敗，應優先檢查 exploration、reward scale 與 critic 局部排序能力。
- [ ] 對模型參數變動，使用 frozen analytical policy 加保守 residual adjustment 可能比從零訓練更穩健；但本文結果顯示改善幅度依成本變化而異，不能將初始化視為普遍有效。

## 限制與未來工作

實驗集中於單一解析 broker–trader game、固定參數與 PPO，且 uninformed flow、成本變化及 partial-information 設定有限。成本減半僅縮小 2.22% 差距，其他成本設定改善不具統計可靠性。論文未提供更廣泛演算法比較。作者建議未來研究導入解析 value/action-value、filter-based actor、其他 action parameterization，以及 nonlinear cost 或 uncertain market impact。
