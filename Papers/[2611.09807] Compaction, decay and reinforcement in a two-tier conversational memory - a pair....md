# Compaction, decay and reinforcement in a two-tier conversational memory: a paired evaluation against retrieval-augmented generation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.09807)
- 📥 [PDF](https://arxiv.org/pdf/2611.09807v1)

## 摘要（中文翻譯）

具備記憶能力的 conversational agent 必須決定哪些資訊值得保留。Retrieval-augmented generation（RAG）保留完整 transcript，於查詢時搜尋；另一方案則將每輪對話 compact 成 atomic facts，再搜尋這些事實。本文在 LoCoMo 上進行 paired evaluation：兩種方法均回答全部 1,985 題，使用相同 stores、generator 與 judge，並將兩者預測置於同一列，因此可對 512 個不一致樣本進行 McNemar exact test。在可與既有研究比較的四類問題中，compaction 得分 71.4%，RAG 為 64.6%，領先 6.8 個百分點，同時減少 34% prompt tokens。納入 adversarial 類別後，整體領先縮小至 2.0 個百分點且不顯著。結果顯示，reference answer 越需要保留原文措辭，compaction 優勢越低：一至兩個 reference words 時領先 9.6 個百分點，超過八個 words 後反而落後 3.1 個百分點。Compaction 保留事實主張、捨棄表達方式，因此擅長回答 value，卻不利於 phrasing。

## 問題背景

論文探討長期 conversational memory 中「保留完整 transcript」與「先 compact 成 atomic facts」的取捨。既有比較常分開執行各系統，只比較總準確率，無法利用逐題配對資訊，也容易混入 model version、provider 狀態與 judge 時間差異。另一方面，compaction 雖可降低 context spend，卻可能丟失原始措辭、qualifier 與事件脈絡；RAG 則面臨長 context、無關 passage 干擾及相對日期需在回答時解析等問題。

## 解決方案

作者提出 NMAFC（Neuromorphic Memory Architecture for Conversational AI）雙層 conversational memory。寫入時由 language-model extractor 將每輪對話轉為具 entity、atomic assertion、validity date、speaker attribution 與 related entities 的 facts，經 deduplication、linking 與 supersession consolidation 後，分別存入 working tier 與 searchable archive。facts 以 exponential decay 管理，檢索到時透過 reinforcement 恢復權重，低於 threshold 則由 working tier demote 至 archive。讀取時同時搜尋 dense、lexical 與 graph channels，以 reciprocal rank fusion 排序，並將高排名 facts 與部分 source turns hydration 到 prompt。核心創新不只是架構，而是以同一窗口、同一 store 狀態、同一 generator 與 judge 的 paired protocol，比較 compaction 與 transcript RAG。

## 核心貢獻
1. 提出並公開一套 paired conversational-memory evaluation protocol：兩個 arms 在同一窗口、相同 store 狀態下逐題執行，將兩種預測寫在同一列，使用 McNemar exact test 分析 discordant pairs。
2. 實作 NMAFC 雙層 compaction memory，結合 atomic fact extraction、validity-aware consolidation、exponential decay、retrieval reinforcement、dense／lexical／graph retrieval 與 graded source-turn hydration。
3. 以 LoCoMo 實驗量化 compaction 的收益與代價：在較短、value-oriented 或 temporal answers 上提升準確率並降低 34% context spend，但在需要保留原文 phrasing 的 adversarial、長 reference answers 上輸給 transcript RAG。

## 技術方法

NMAFC 的寫入流程包含 extraction、consolidation 與兩層儲存。Extractor 強制每筆記錄只表達一項主張，解析相對日期為 absolute date，並附加 entity、speaker、validity 與 links；facts 去重，過時內容標為 invalid 而不刪除。每個 mutable fact 的權重依 w(Δt)=w0e^-λeffΔt 衰減；λeff 受 fact type 與 retrieval 次數影響，core anchor 不衰減，權重低於 0.1 時 demote 至 archive。每次 retrieval 返回的 fact 都會 reinforcement，將權重設回 1；評估 harness 以 read-only wrapper 清除 pending buffer，避免題目間狀態漂移。讀取同時搜尋 working tier 與 archive，融合 dense、lexical 及 graph expansion 的最多五個 ranked lists，採 reciprocal rank fusion，取前 20 facts，並 hydration 前五個 facts 的 source turns。baseline 是對相同 conversations 進行 transcript chunking、embedding retrieval 的 RAG，不使用 extraction、decay、reinforcement 或 fusion；兩者共用 DeepSeek-V4-Pro generator、text-embedding-3-small embeddings 與 Kimi-K2.6 judge。資料為 LoCoMo 十段 synthetic conversations、1,985 題，分為 open-domain、adversarial、temporal、single-hop、multi-hop。主要指標是 model-judge binary accuracy、paired discordant counts、McNemar exact test、Wilson 95% intervals、retrieved-context tokens，以及 secondary token-overlap F1；延遲則比較 paired percentiles。

在 scored four categories 中，NMAFC 以 34% 較少 context tokens 顯著領先；納入 adversarial 後，整體差異不再顯著。reference answer 一至兩個 words 時，scored-four lead 為 +9.6 points；超過八個 words 後為 -3.1 points。Token-overlap F1 亦支持此方向：NMAFC 在 temporal 為 0.620 對 0.446、multi-hop 為 0.365 對 0.239；RAG 在 adversarial 為 0.443 對 0.340。Latency 的 paired 結果顯示 p50 為 1,741 對 1,769 ms，p90 為 3,570 對 3,360 ms，差異主要出現在長尾。

## 對我們的啟發
- [ ] 若產品問題主要詢問日期、數值、身份、地點或方案等 value，compaction memory 可能在降低 context spend 的同時提供優勢；但應以實際問題分布驗證，不能只依賴總體平均。
- [ ] 不要把 compaction 視為 transcript 的完全替代品。對需要回答「使用者原話」「完整理由」或長 paraphrase 的查詢，應保留短 verbatim spans、source turns，或採用依問題型態路由的混合檢索。
- [ ] 評估 memory 或 RAG 系統時，應逐題 paired 執行並固定 generator、judge、store 狀態，再檢視 discordant wins/losses；僅比較兩次獨立總分可能誤判效果、延遲與負結果。

## 限制與未來工作

LoCoMo 僅包含十段 synthetic conversations，未必反映真實對話中的 interruptions、corrections 與 topic drift。adversarial 類別主要是長 paraphrase，可能放大 phrasing 損失。研究共用 generator、embedding model 與 model judge，絕對分數受 common-mode 偏差影響；模型輸出具非決定性，跨週 accuracy 漂移約 0.040。類別與總體檢定未做完整 family-wise correction，且部分 ablation 使用已建立的 stores。
