# GRAC: Graph-Based Retrieval-Augmented Captioning for Surgical Scene Description

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.09866)
- 📥 [PDF](https://arxiv.org/pdf/2611.09866v1)

## 摘要（中文翻譯）

目的：手術術中報告支援程序記錄、手術訓練、表現評估與流程回顧，但從中擷取有意義的資訊通常需要大量人工審查與臨床專業。自動生成具臨床意義且符合上下文的手術場景描述，可降低人工審查負擔。方法：提出 GRAC（Graph-Based Retrieval-Augmented Captioning），以圖表示手術場景，捕捉器械、動作與解剖結構間的關係。給定輸入場景圖後，模型從訓練資料檢索相關的圖－caption 配對，比較檢索案例與輸入場景中的器械－組織互動，並以比較特徵在生成過程中調節檢索 caption 表徵。結果：在 EndoVis-18 上，GRAC 的 CIDEr-D 為 5.88，高於 SGT 的 4.23 與最佳傳統 Transformer baseline 的 3.36；精確器械－動作－目標 triplet-set accuracy 為 52.6%，高於 SGT 的 32.7% 與最佳傳統 baseline 的 26.2%。在 TORS 上，GRAC 的 CIDEr-D 為 5.06，高於最佳 baseline 的 3.80。結論：結合結構化手術場景表示與檢索案例，可提升手術場景 captioning 的語言品質與事實一致性。

## 問題背景

論文處理從單一手術影格的結構化場景資訊生成具上下文且事實正確描述的問題。既有方法多直接將 scene representation 映射至自然語言，當標註資料有限時，模型難以學習結構資訊與語言間的關係。雖然手術活動具有重複模式，但僅依賴外觀或整體相似度檢索可能混淆相同器械的不同動作或解剖目標，因此需要同時建模互動關係並比較檢索場景與當前場景。

## 解決方案

作者提出 GRAC，一個 scene-graph-to-caption 的 retrieval-augmented framework。第一，使用具 interaction-aware 能力的 GATv2 graph encoder 表示器械、組織及其互動；第二，透過 caption-supervised contrastive learning，使具有相同器械－動作－目標 triplet-set 的跨序列場景在 embedding space 中接近，據此檢索三個具活動多樣性的 graph-caption pairs；第三，建立 graph-conditioned caption memory，依器械對齊比較當前與檢索場景的節點及邊特徵，並將比較結果注入檢索 caption 表徵。模型再以 query graph、檢索 caption 與互動比較特徵生成描述，並以 compatibility supervision 改善事實對齊與降低器械 hallucination。

## 核心貢獻
1. 提出 caption-supervised contrastive retrieval，使 scene graph embedding 依據跨序列的器械－動作－目標活動相似性檢索，而非僅依賴視覺或器械外觀相似度。
2. 提出 instrument-aligned graph comparison，顯式比較當前與檢索場景的節點及器械－組織互動邊，並將差異特徵注入檢索 caption memory。
3. 整合 interaction-aware graph encoding、activity-guided retrieval、graph-conditioned generation 與 compatibility supervision，在 EndoVis-18 與 TORS 上提升 caption 品質及 triplet-based factual agreement。

## 技術方法

每個影格表示為 G=(V,E,Xv,Xe)，節點包含器械與單一組織節點，節點及邊特徵皆為 512 維；非零邊表示標註的器械－組織 active interaction，但不直接指定動作。GRAC 使用兩層、四頭、隱藏維度 512 的 edge-aware GATv2，並以 attention pooling 取得 graph embedding。模型將 graph token、節點 token 與雙向互動 edge tokens 組成最多 19 個 token，再經兩層 Transformer query-memory encoder。retrieval head 將 graph embedding 投影為 128 維 L2-normalized 向量，以 cosine similarity 從僅含訓練資料的 memory bank 檢索 K=3 個不同 triplet-set 的 graph-caption pairs；訓練時排除同一手術序列候選。對匹配器械，模型比較當前與檢索節點表徵、差異、逐元素乘積、原始及投影後邊特徵，並加入檢索相似度。每個檢索 caption 經 Transformer encoder 後，融合比較向量與 matching-status embedding，與 query memory 一同供 Transformer decoder 生成最多 20 tokens 的 caption。訓練損失由 label-smoothed caption cross-entropy、multi-positive InfoNCE retrieval loss 及 compatibility binary cross-entropy 組成；推論採 beam width 2。資料包括 EndoVis-18 的 392 個 held-out frames，以及 TORS 的 36 個 test frames。評估使用 BLEU-1–4、METEOR、ROUGE-L、CIDEr-D，以及 rule-based parser 擷取的 exact triplet-set accuracy、triplet precision/recall/F1 與 instrument hallucination；統計採三個 random seeds 與 10,000 次 paired frame-level bootstrap，並使用 Holm correction。

## 關鍵結果

主要結果如下；數值為論文報告的三個 seed 平均值，除非另有說明。

| 資料集／指標 | GRAC | SGT | 最佳傳統／其他 baseline |
|---|---:|---:|---:|
| EndoVis-18 CIDEr-D | 5.883 ± 0.085 | 4.234 ± 0.604 | Transformer 3.356 ± 0.144 |
| EndoVis-18 BLEU-4 | 0.715 ± 0.006 | 0.610 ± 0.033 | Transformer 0.514 ± 0.016 |
| EndoVis-18 METEOR | 0.541 ± 0.007 | 0.459 ± 0.003 | Transformer 0.458 ± 0.009 |
| EndoVis-18 ROUGE-L | 0.828 ± 0.008 | 0.751 ± 0.021 | Transformer 0.697 ± 0.018 |
| EndoVis-18 exact triplet-set accuracy | 0.526 ± 0.008 | 0.327 ± 0.114 | GET 0.262 ± 0.043 |
| EndoVis-18 triplet F1 | 0.636 ± 0.012 | 0.510 ± 0.107 | GET 0.508 ± 0.041 |
| EndoVis-18 instrument hallucination | 0.037 ± 0.015 | 0.047 ± 0.003 | Transformer 0.056 ± 0.019 |
| TORS CIDEr-D | 5.06 ± 0.26 | 3.73 ± 1.46 | Transformer 3.80 ± 1.35 |
| TORS exact triplet-set accuracy | 0.454 ± 0.016 | 0.343 ± 0.153 | Transformer 0.352 ± 0.160 |
| TORS triplet F1 | 0.621 ± 0.013 | 0.516 ± 0.143 | Transformer 0.592 ± 0.038 |
| TORS instrument hallucination | 0.083 ± 0.028 | 0.245 ± 0.189 | Transformer 0.102 ± 0.016 |

在 EndoVis-18，GRAC 相較 SGT 的 CIDEr-D 差異為 +1.650，95% CI [1.394, 1.917]，Holm-adjusted p<0.001；相較 SGT 的 exact triplet-set accuracy 差異為 +0.199，95% CI [0.171, 0.228]。消融結果顯示，無 retrieval 或 edge features 時 CIDEr-D 為 4.870；加入 edge features 為 5.632；再加入 caption retrieval 為 5.805；完整 GRAC 為 5.883。完整模型相較 caption-only retrieval 的 instrument hallucination 由 0.049 降至 0.037，p=0.003，但 CIDEr-D 差異未達統計顯著（p=0.054）。

## 對我們的啟發
- [ ] 在資料量有限且活動模式重複的領域，檢索既有描述可作為語言先驗；但應保留 query-specific graph conditioning，因為直接複製 Top-1 caption 的 EndoVis-18 CIDEr-D 僅為 5.332，低於 GRAC 的 5.883。
- [ ] 檢索數量不宜無限制增加：論文的 development 結果顯示 K=3 的 R@3 為 0.855，而 K=5 未改善 caption quality；實務上應優先控制檢索相關性與活動多樣性。
- [ ] 語言品質與事實可靠性應分開評估。完整 GRAC 的主要額外收益較明顯地體現在 instrument hallucination 降低，而非 aggregate CIDEr-D 顯著提升，因此醫療 captioning 應同時使用 triplet accuracy、F1 與 hallucination 指標。

## 限制與未來工作

資料集與測試規模有限：EndoVis-18 為 392 個測試影格，TORS 僅 36 個影格且來自三個測試序列；活動與詞彙亦較重複。模型使用標註或已提供的 scene-graph features，尚未充分驗證自動預測 scene graph 的誤差影響。評估是 frame-level，無法代表 procedure-level 變異；triplet 指標也依賴 parser 與標註品質，未直接衡量臨床錯誤嚴重度。未來需在更多手術類型、未見活動及臨床專家評估下驗證。
