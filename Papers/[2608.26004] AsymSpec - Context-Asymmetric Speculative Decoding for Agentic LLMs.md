# AsymSpec: Context-Asymmetric Speculative Decoding for Agentic LLMs

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.26004)
- 📥 [PDF](https://arxiv.org/pdf/2608.26004v1)

## 摘要（中文翻譯）

Agentic LLM pipeline 會因 retrieval、tool use 與 multi-turn interaction 累積 context，導致 inference cost 與 latency 上升。部署通常壓縮 input 以控制成本，但會損害 task accuracy。Speculative decoding（SD）雖能 losslessly 加速 generation，卻要求 drafter 與 verifier 使用相同 context，因此無法同時處理 accuracy 與 overhead 的取捨。作者提出 AsymSpec：lightweight drafter 讀取 full input，而大型 verifier 僅處理 compressed view；再透過 contrastive δ-fusion logits，以及 divergence-aware Context-Divergence Acceptance（CDA）gate，引導 verifier 並維持穩定驗證與較高 draft acceptance rate。在四項 agentic capabilities 與兩個 end-to-end agent benchmarks 上，平均達到約 full-context accuracy 的 90%，孤立文字能力可取得 1.3–1.7 倍 throughput，compute cost 為 0.2–0.3 倍。

## 問題背景

論文處理 agentic LLM 中 context 隨 retrieval、工具輸出、對話歷史與記憶持續增長，造成大型 verifier 的 inference latency 與 compute cost 過高。context compression 可降低成本，卻會刪除多跳推理、工具 schema 等關鍵細節。既有 standard SD 要求 drafter 與 verifier 讀取相同 input，只能加速固定 target distribution，無法由 full-context drafter 協助 compressed verifier 恢復遺失資訊。

## 解決方案

作者提出 AsymSpec，明確解除 SD 的 context symmetry：large verifier 僅讀取 compressed context，以取得主要 latency 與 compute 節省；lightweight drafter 則讀取 full context，負責提取壓縮所丟失的訊息。方法以同一 drafter 在 full 與 compressed views 的 logits 差值 δ=a−b，消除 model-specific、context-independent preferences，形成 context-gain signal，並將其融合至 verifier logits。另提出 parameter-free 的 CDA gate，以 full/compressed drafter distributions 的 Jensen–Shannon divergence 動態調整接受門檻，在 divergence 較大處允許更寬鬆的 draft acceptance。框架亦可延伸至 vision-language drafter 與 text-only verifier 的 cross-modal 設定。

## 核心貢獻
1. 提出 AsymSpec context-asymmetric speculative decoding，讓 full-context lightweight drafter 引導只讀 compressed context 的 large verifier，在低 verifier 成本下恢復接近 full-context 的準確率。
2. 提出同模型跨 context 的 contrastive δ-fusion（a−b），用 logits 差值隔離 full context 帶來的資訊增益；消融結果顯示其優於 raw augmented logits 與 SCD-style 的 δ 建構。
3. 提出不需 per-dataset tuning 的 Context-Divergence Acceptance（CDA）gate，根據 JSD 動態調整 draft acceptance threshold，並展示其可用於文字、agent loop 與 cross-modal vision-language 設定。

## 技術方法

令大型 verifier L、輕量 drafter S，輸入包含 full prompt x_full，以及由 black-box compressor 產生的 x_comp。每個 speculation step 中，S 先以 x_full 與既有輸出 y 產生 logits a，並 draft K 個 tokens；接著 S 以 x_comp、y 與 drafts 產生相同位置的 logits b，L 則以 compressed view 平行驗證 drafts，得到 logits t。對每個位置計算 δ_i=a_i−b_i，並計算 D_i=JSD(softmax(a_i)||softmax(b_i))。CDA 有效門檻為 γ_eff(i)=γexp(−D_i)；因 JSD 上界為 ln 2，γ_eff 位於 [γ/2,γ]。若 verifier 對 draft token 的機率高於 γ_eff(i) 乘以 base drafter 機率，便接受該 token；首次拒絕時，改輸出 argmax(t_i+βδ_i)，若全部接受則輸出 verifier 的下一 token。主要設定為 Qwen3-32B verifier、Qwen3-4B text drafter，multimodal 使用 Qwen3-VL-2B，greedy decoding、K=2、β=1.0、γ=0.5。評估涵蓋 LongBench 多跳 QA、MultiChallenge、API-Bank、MathVista，以及 GAIA、SimpleQA agent loops；指標包括官方 task accuracy、wall-clock token throughput speedup 與相對 full-context Ceiling 的 prefill FLOPs。

## 對我們的啟發
- [ ] 若 compression 會刪除關鍵 reasoning signals，可把 full-context 存取配置給較小模型、把昂貴 verifier 限制在 compressed view；這提供不同於「全模型全 context」與「全模型壓縮 context」的新部署 operating point。
- [ ] 應依 compression-induced Floor–Ceiling gap 評估是否導入 AsymSpec：論文中 MultiChallenge 壓縮近乎無損，改善僅為 23.4 至 23.5；LongBench 壓縮越嚴重，恢復幅度越大。
- [ ] 實際部署需同時追蹤 accuracy、acceptance rate、throughput 與 FLOPs；論文顯示 FLOPs 降幅不會線性轉化為 latency，且需取得 verifier logits，因此較適合可控的 open-weight serving stack，而非僅提供文字輸出的 proprietary API。

## 限制與未來工作

方法受 compressed view 保留資訊與 drafter capacity 限制，論文指出 0.6B 以下 drafter 難以可靠提取 context-gain signal，實務最低門檻約為 1.7B。cross-modal 效果受 caption/OCR 品質與 text-only verifier 無法直接理解 pixels 所限。cross-family δ-fusion 需 vocabulary alignment；方法也依賴 verifier logits，且目前實驗聚焦 deterministic greedy decoding（τ=0），隨機 sampling 的 CDA 延伸仍屬未來工作。
