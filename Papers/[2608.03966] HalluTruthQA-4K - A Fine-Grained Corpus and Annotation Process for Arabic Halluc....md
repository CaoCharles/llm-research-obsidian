# HalluTruthQA-4K: A Fine-Grained Corpus and Annotation Process for Arabic Hallucination Detection and Truth Verification

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.03966)
- 📥 [PDF](https://arxiv.org/pdf/2608.03966v1)

## 摘要（中文翻譯）

大型語言模型能生成流暢的阿拉伯語回答，卻可能產生難以辨識與驗證的事實錯誤。現有阿拉伯語 hallucination 資源多半只對完整回答標註二元 hallucination／非 hallucination，缺乏錯誤位置、錯誤原因與正確事實等細節。本文提出 HalluTruthQA-4K，為擴充自 HalluTruthQA 的 4,000 筆專家整理語料庫，涵蓋伊斯蘭知識、歷史、科學與地理四個知識密集領域。每筆資料包含阿拉伯語問題、模型生成回答、驗證過的參考答案，以及一個正確答案和五個合理干擾項。Hallucinated 回答另附 character-level 錯誤 span、人工說明與階層式 hallucination 類型。資料集含 1,643 筆 hallucinated 與 2,357 筆非 hallucinated 回答，以及 1,843 個錯誤 span，支援回答層級偵測、錯誤定位、解釋生成、答案選擇與 factual verification。

## 問題背景

現有阿拉伯語 hallucination 資源多以整體回答的二元標籤為主，無法指出錯誤位於何處、屬於何種錯誤、為何不正確，也難以同時驗證正確答案。這使模型偵測能力與 span 定位、解釋生成、證據忠實度及事實修正能力無法被分開評估，尤其不足以處理伊斯蘭知識中的引文、來源與證據錯誤，以及歷史、科學、地理中的細粒度事實差異。

## 解決方案

作者提出 HalluTruthQA-4K，將同一筆阿拉伯語知識密集 QA 實例中的問題、模型自由回答、verified reference answer、hallucination label、六個候選答案、character-level 錯誤 span、人工 explanation 與階層式錯誤 taxonomy 統一對齊。核心創新在於把 response-level detection、span-level localization、錯誤類型分類、錯誤解釋與 candidate-based factual verification 放入同一資料結構，並透過專家製題、控制式回答生成、獨立複核與裁決提高標註可靠性。

## 核心貢獻
1. 提出 4,000 筆、涵蓋四個阿拉伯語知識密集領域的 HalluTruthQA-4K，並作為 HalluScoring 2026 Track 2 的官方資料集。
2. 將 response-level 二元標籤與 character-level 錯誤 span、人工錯誤說明、五類 macro-type 及 22 類 micro-type 對齊於同一 QA 實例。
3. 建立包含專家出題與答案驗證、Fanar-1-9B-Instruct 控制式生成、干擾項建構、獨立複核、裁決與品質控制的完整資料建構流程。

## 技術方法

資料集固定涵蓋 Islamic knowledge、history、science 與 geography，每域 1,000 筆，按域切分為 train 400、development 200、test 400。問題由各領域專家人工撰寫，並以對應可靠來源驗證 reference answer；含糊、資訊不足或存在多個合理答案的問題會修訂或移除。回答使用單一模型 Fanar-1-9B-Instruct 生成，設定為 maximum 1,024 new tokens、temperature 0.0、top-p 1.0、batch size 4、bfloat16，於 48 GB GPU 執行。每題建立一個 verified answer 與五個語意相關、事實錯誤且風格相近的 distractors，形成六選一選項。若完整回答含任何錯誤、捏造、無支持、誤導或脈絡不一致主張，即標為 hallucination；專家依 minimal-but-complete 原則以 zero-based、end-exclusive character offsets 標註每個獨立錯誤 span，並撰寫錯誤原因與 correction。每個 span 再標註五個 macro-types 與 22 個 micro-types。四位領域專家先完成標註，兩位研究助理獨立複核問題、答案、標籤、span、說明、類型與選項，爭議交由專家裁決。評估標註品質使用 binary、macro、micro 類別的 Cohen’s κ，選項使用 exact agreement，span 使用 character-level F1 與 IoU。

## 對我們的啟發
- [ ] 若評估目標是 factual reliability，不應只採用整體 hallucination accuracy；應同時衡量錯誤 span 定位、類型辨識、說明品質與正確答案恢復。
- [ ] 對涉及引文、經文、hadith、來源或證據的領域，回答主結論正確仍可能不具 faithfulness，因此標註與測試應檢查支撐證據。
- [ ] 實務上可將 character offsets、錯誤類型與人工 correction 用於訓練可解釋的 factuality checker；但候選答案評估應與開放式校正分開解讀。

## 限制與未來工作

資料只使用單一 Arabic-centric 生成模型 Fanar-1-9B-Instruct，且僅涵蓋四個領域，未代表完整的阿拉伯語方言、使用情境與知識來源。候選答案選擇也不等同於開放式事實校正。作者未來將加入更多模型、領域與 Arabic varieties，並研究跨模型及跨領域泛化。
