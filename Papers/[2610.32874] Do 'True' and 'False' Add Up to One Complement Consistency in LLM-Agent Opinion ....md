# Do "True" and "False" Add Up to One? Complement Consistency in LLM-Agent Opinion Simulations

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.32874)
- 📥 [PDF](https://arxiv.org/pdf/2610.32874v1)

## 摘要（中文翻譯）

在 LLM-agent opinion simulation 中，每個 agent 觀察自己的前一輪機率與鄰居機率後，回報某一 claim 為真的機率，並將其作為下一輪狀態。若此數值代表 agent 的立場，而非所呈現句子的表面形式，將 claim 改寫為其 complement，並把所有機率 p 替換為 1−p，兩次回報應相加為一。作者以 Qwen3-4B、Llama-3.2-3B 與 Gemma-3-4B 測試此性質。Qwen 在模擬狀態的配對回報平均總和為 1.18，在 48 個 AVeriTeC fact-checking claims 上也高於一。由 24 個嚴格二元世界組成的 controlled benchmark 顯示三個模型皆失敗；差異是同義 paraphrase 變化的 2 至 10 倍，且在重複抽樣、不同 peer 數量與回報強度下仍存在。將回報回饋至互補初始狀態的兩個 population 後，五輪時所有模型均出現正 divergence。以 paired report 的 complement 進行 averaging 可由構造恢復 consistency，並降低兩種 wording 的平均 Brier loss，但只有一個模型在最終輪次優於兩種原始 wording 中較佳者。因此，讀取模擬機率為 beliefs 前，必須獨立檢驗其 rewording consistency。

## 問題背景

論文探討 LLM agent 將生成的機率作為後續 simulation state 時，是否會對互補且資訊等價的 claim 給出互補回報。既有 schedule、graph 或 evidence-targeting robustness 實驗，可能只檢驗集體結果，無法發現局部 wording 導致的數值不一致；同義 paraphrase 或一般 accuracy 也不能直接測量互補機率關係。若互補性失敗，誤差會經由 feedback 改變後續軌跡，因此需要專門的 complement-consistency 評估。

## 解決方案

作者提出 complement-consistency test。對完整 update request 同時轉換 claim、own prior 與 ordered peer reports，固定 factual evidence、referent、time 與其他條件，要求兩次輸出 q0、q1 滿足 q0+q1=1，並以 signed discrepancy δ=q0+q1−1 與 absolute discrepancy |δ| 評估。框架另加入 same-polarity paraphrase control、repeated sampling、explicit-negation control、peer sensitivity 與 paired feedback propagation，以區分互補不一致、語句敏感度和抽樣變異。作者也提出 symmetrization：將 q0 與映回原座標的 1−q1 平均，令 R=(q0+1−q1)/2，從而對固定配對請求保證互補輸出，並進一步檢查其閉迴路 factual loss 與成本。

## 核心貢獻
1. 提出適用於 LLM-agent numerical update 的 complement-consistency criterion，將 claim、own probability 與 ordered peer reports 一併互補轉換，並以 δ 與 |δ| 量化不一致。
2. 透過 simulation states、AVeriTeC real claims 與嚴格二元 controlled benchmark，顯示三個小型 open models 均可能違反互補機率關係，且效果大於 matched paraphrase sensitivity。
3. 證明局部 complement consistency 足以在相同 graph、evidence 與 execution rules 下維持互補 simulation trajectories，並實驗評估 feedback divergence 與 symmetrization repair 的 factual loss、閉迴路效應及成本。

## 技術方法

研究使用三個本地小型 open models：Qwen3-4B-Inst.-2507 Q4_K_M、Llama-3.2-3B-Inst. Q4_K_M 與 Gemma-3-4B-IT QAT Q4_0，透過 llama.cpp 產生單一 [0,1] 機率；network、preserved-state 與 real-claim 實驗使用 Qwen、temperature 0.2，controlled studies 多採 greedy decoding。首先建立 16 個 fictional campus claims 的 network simulation，含 12 agents、6 rounds、三種 schedule 與三種 evidence delivery policy，並保存 2,304 個 agent states。其次使用 48 個 AVeriTeC claims，交叉 initial positions、peer opposition、source visibility、wording、audience 與 peer order。核心 controlled benchmark 有 24 個 worlds，分屬 exclusive color、binary switch、integer parity、threshold、set membership、strict event order 六類；每個 world 僅有兩個 exhaustive、mutually exclusive outcomes，並配對 affirmative descriptions、same-meaning paraphrases 及 explicit negation。每次 complement transformation 同時將 p、每個 peer report rj 轉為 1−p、1−rj，保留 evidence 不變。主要指標包括 signed/absolute complement discrepancy、paraphrase sensitivity、Brier loss、peer attraction、trajectory divergence d(t)，以及 repeated sampling 下的 mean-level 與 independent-draw discrepancy。最後以八-agent、五輪 synchronous feedback 比較互補 population，並評估 reminder、greedy averaging 與 symmetrization 的閉迴路效果；不確定性主要以 bootstrap intervals 報告。

## 對我們的啟發
- [ ] 當生成機率會成為下一輪 agent state 時，評測不應只看 calibration、accuracy 或 schedule robustness；應對完整 request 做 paired complement probe，並追蹤不一致是否在 feedback 中改變軌跡。
- [ ] 應同時報告 signed discrepancy、absolute discrepancy 與抽樣分布；signed 平均可能因正負誤差抵消而低估問題，而 matching paraphrase control 有助於區分互補邏輯失效與一般 wording sensitivity。
- [ ] Symmetrization 適合視為需驗證的 inference-time repair，而非自動提升效用的方法：它能對固定配對保證 consistency、降低兩 wording 的平均 Brier loss，但閉迴路效果、最佳 orientation 與呼叫成本仍須分開評估。

## 限制與未來工作

研究只測試三個小型模型，且模型大小、quantization 與 prompt format 不同，不能歸因於單一 architecture。controlled follow-up 多使用六個 worlds；材料未經 human raters 驗證，peer groups 為 homogeneous，未涵蓋 heterogeneous peers。bootstrap 只反映既定材料與條件，不能代表未測試的模型、graph 或 population；論文也未建立 discrepancy 的普遍成因。
