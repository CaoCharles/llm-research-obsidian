# Handover of In-Context Learning State Across Session Boundaries

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.14528)
- 📥 [PDF](https://arxiv.org/pdf/2608.14528v1)

## 摘要（中文翻譯）

本研究探討使用大型語言模型之應用中的 session handover 方法與理論性質。當 context 達到模型輸入上限、應用程式重啟，或改由另一個 agent 接續任務時，系統必須決定從前一 session 傳遞哪些資訊。作者將 handover 定式化為與任務相關的 in-context learning（ICL）state transfer，並區分先前材料的 exact recovery 與 target distribution 的 preservation。在 exogeneity 條件下，predictive equivalence 可刻畫最粗的 deterministic sufficient handover，並給出固定長度的 bit requirement。研究分離 memory constraint、writer 與 continuation procedure 的影響，也量化在未知 downstream query 前寫入記錄的成本。作者提出由精確保存 decisions 與 constraints、以任務有充分理由的 statistics 壓縮重複證據，以及保留統計量未能涵蓋之原始觀察所組成的三部分記錄。Gaussian linear regression 展示 exact finite-dimensional handover 與 finite-bit perturbation bounds；nonparametric regression 則建立 memory 與 squared prediction error 的上下界。

## 問題背景

論文處理多次 LLM 呼叫或 agent 接力時的 session handover 問題：當 context 超限、程式重啟或任務移交，系統如何在有限記憶體下保留真正影響後續 prediction 或 action 的資訊。既有 prompt compression 常可先看到 query，具有 query-aware 優勢；文字摘要則可能遺漏 constraints、decisions、examples 或 tool evidence。研究因此需要區分全文 exact recovery、target distribution preservation，以及固定 continuation procedure 的實際任務表現。

## 解決方案

作者把 handover 視為 task-relative ICL state 的編碼問題，writer 在 downstream query 尚未知時產生 record，並以 predictive sufficiency 判定資訊是否足夠。核心框架包括：以 predictive equivalence 找出最粗 deterministic sufficient state；以 risk decomposition 分離 memory、writer 與 decoder 造成的損失；以資訊理論量化遺失資訊與 pre-query writing cost。具體記錄採三部分設計：exact 部分保存不可改寫的 decisions、constraints 與 unresolved issues；stat 部分只使用有任務保證的 sufficient statistics 或近似統計量；residual 部分保留統計量未涵蓋的原始觀察。Gaussian regression 顯示可有固定維度 state，nonparametric regression 則說明記憶需求會隨精度與函數類增長。

## 核心貢獻
1. 將 session handover 形式化為任務相對的 ICL state transfer，並以 predictive sufficiency 區分任務資訊保存與全文重建。
2. 在 later input 對先前 context 具 exogeneity 時，提出 predictive equivalence、最粗 sufficient state 與固定長度 bit 下界之理論刻畫。
3. 提出由 exact、statistical、residual 三部分組成的 handover record，並以 Gaussian 與 nonparametric regression 推導精確充分性、有限位元誤差及 memory–risk 上下界。

## 技術方法

作者以 episode ω=(C,T,X,Y) 建模：C 是 handover 前的對話、指令、examples 與 tool results；T 是 writer 已知的任務資訊與 scoring rule；handover 後才觀察 X，即 query 或 current task state；Y 是被評分的答案、最終狀態或允許 action。writer E 在未知道 realized X 前產生 H=(V,M)，其中 V 是新 session 直接使用的 record，M 是可讀取的外部 file、index 或 archive，並分別限制 prompt 大小與總儲存量。後續由 prompt construction、LLM generation、decoding、parser 及 environment interaction 組成 continuation procedure D，使用 expected task loss、trajectory loss、log loss、KL divergence、Brier score 或 squared error 評估。理論上以 P(Y|C,X,T)=P(Y|H,X,T) 定義 predictive sufficiency；在 exogeneity 下，依據 contexts 對後續 target distribution 的 predictive equivalence 建立最粗 sufficient state 與 bit requirement。風險分解為 memory budget 的不可避免損失、writer 額外損失及 continuation procedure 相對 ideal decoder 的損失。方法設計採三部分 record：精確保存 decisions、constraints 與 unresolved issues；僅在有 sufficient statistic 或誤差保證時壓縮重複 evidence；其餘保留 residual 原始 observations。統計驗證包括已知 noise variance 的 Bayesian Gaussian linear regression，以及 Hölder 函數類的分箱 nonparametric regression，分別推導 exact statistic、量化穩定性、achievable upper bound 與 minimax memory lower bound。

## 關鍵結果

論文主要提供理論結果與回歸分析，未報告以實際 LLM、代理任務或外部 benchmark 進行的實驗；因此沒有可呈現的模型間實驗數據對比。

| 分析設定 | 主要結果 |
|---|---|
| Predictive state | 在 exogeneity、finite/countable context support 下，predictive equivalence classes 構成最粗的 deterministic sufficient handover；若有 $N_t$ 個狀態，固定長度至少需 $\lceil\log_2 N_t\rceil$ bits。 |
| Log loss | 理想 handover 與完整 context 的風險差等於 $I(Y;C\mid H,X,T)$。 |
| Query 未知的成本 | Bernoulli 座標例中，若 $I(C;H)\le B$，則 $H_2(Y\mid H,X)\ge\max\{0,1-B/m\}$；query-aware encoder 則以 1 bit 傳送 $C_X$ 可達零 log loss。 |
| Gaussian linear regression | $(G_n,b_n)=(X_n^\top X_n,X_n^\top y_n)$ 對所有後續輸入 $x$ 都是 predictively sufficient；其維度為 $d(d+1)/2+d$ 個實數。有限位元量化後，預測 KL divergence 可達 $O(2^{-2(B-B_0)/p})$，其中 $p=d(d+1)/2+d$。 |
| Nonparametric regression | Cell statistics 的誤差上界包含 approximation、sampling、empty-cell 與 quantization 四項；適當選擇 $M\asymp n^{d/(2\beta+d)}$、$q\asymp n^{-\beta/(2\beta+d)}$ 時，達到 $O(n^{-2\beta/(2\beta+d)})$。所需記憶量為 $O(n^{d/(2\beta+d)}\log n)$ bits。 |
| Memory lower bound | 非參數模型的 minimax risk 至少為 $c\max\{n^{-2\beta/(2\beta+d)},(B+1)^{-2\beta/d}\}$。 |

## 對我們的啟發
- [ ] 實務上不應以摘要與原始對話的文字相似度評估 handover；應以後續 prediction、action 或 trajectory 的 task loss，以及可計算時的 ideal risk 評估。
- [ ] handover writer 通常在 realized downstream query 尚未出現前寫入記錄，因此不能直接套用 query-aware prompt compression；記錄應保留能跨後續輸入維持效用的資訊。
- [ ] 應分開報告 prompt 中的記錄大小、外部檔案或 archive 的總儲存量，以及 continuation procedure 的使用能力，否則無法辨識 memory loss、writer loss 與 decoder loss。

## 限制與未來工作

研究核心是理論與兩類回歸模型，未提供實際 LLM、agent session、真實工具使用情境或 benchmark 的量化實驗，因此三部分記錄在自然語言任務中的效能仍未驗證。Predictive sufficiency 的主要 state quotient 亦依賴 exogeneity；若後續輸入受先前 context 影響，需改用聯合任務分布分析。論文也指出 adaptive trajectory 不能僅由單一步驟 target 的 sufficiency 保證。
