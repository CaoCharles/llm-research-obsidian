# Intern-S2-Preview: Scientific Agentic Foundation Model

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.13505)
- 📥 [PDF](https://arxiv.org/pdf/2608.13505v1)

## 摘要（中文翻譯）

科學發現需要 AI 系統能對異質模態的科學證據進行推理、操作科學工具與環境，並在長期任務中持續推進。本文提出 Intern-S2-Preview 系列 Scientific Agentic Foundation Models，支援多模態科學理解、推理、生成與長時域任務。訓練先涵蓋 rendered scientific documents、交錯圖文資料及多樣科學語料的 scientific multimodal pre-training，再採用 supervised fine-tuning、可擴展 multi-task reinforcement learning、black-/white-box agentic RL 與 on-policy distillation。系統另提出 partial rollout with off-policy correction、adaptive length regularization、online speculative decoding、GEPO 與 trace-aware experience assembly 等技術。397B 模型加入 time-series forecasting 分支；獨立的 Memory Decoder 則在凍結 backbone 下進行科學領域特化。評估顯示模型在多項科學、多模態、agentic 及通用 benchmark 具競爭力。

## 問題背景

現有通用 LLM 雖具指令遵循與推理能力，卻未充分專精於異質科學模態、領域協議與可驗證工具互動；科學多模態模型也多以靜態問答評估，缺乏長時域規劃、反覆執行與環境回饋。因此，論文要解決的是如何建立可整合科學證據理解、數值訊號處理、工具使用及持續任務推進的科學 agentic foundation model。

## 解決方案

作者提出 Intern-S2-Preview 系列及其主模型 Intern-S2-Preview-397B，採用從科學多模態預訓練到 SFT、multi-task RL、agentic RL，再到 on-policy distillation 的分階段統一流程。資料層面保留 PDF 的文字、圖表、方程式與版面關係；訓練層面以可驗證獎勵和黑／白盒環境培養推理與工具互動。架構上加入專用 time-series forecasting branch，並以凍結 397B backbone 外接 Memory Decoder，透過 token-level router 動態融合領域記憶與通用模型，達成不改寫核心參數的快速科學特化。

## 核心貢獻
1. 提出面向科學發現工作流的 Intern-S2-Preview-397B，將多模態科學理解、推理、生成、工具互動與長時域 agentic 能力整合於單一 foundation model。
2. 建立由 scientific multimodal pre-training、SFT、multi-task RL、agentic RL 及 on-policy distillation 組成的統一訓練流程，並配套 partial rollout、off-policy correction、adaptive length regularization 與 online speculative decoding 等穩定化及效率技術。
3. 提出兩條互補的架構路徑：在 397B backbone 中加入 time-series numerical forecasting 模組，並以凍結 backbone 搭配獨立 Memory Decoder 實現不改寫核心參數的領域特化。

## 技術方法

模型以 Intern-S2-Preview-397B 為主體。預訓練包含 scientific text、rendered scientific pages 的 Visual Pre-training，以及由 PDF 經 OCR/layout parsing、視覺單元裁切、交錯序列組裝與 visual-gain filtering 建立的 image-text corpus；另以 image embedding 建立向量資料庫，支援 text-to-image 與 image-to-image retrieval，並以去重、reranking 和品質分數後處理。時間序列 encoder 使用 temporal chunk、normalization、CNN、compressive patching、Q-Former、channel-wise Transformer 與全局 temporal modelling，支援最高約 300,000 time steps；forecasting branch 以 LLM 語義表徵和數值時間表徵條件化 causal Transformer，並由 horizon predictor 決定預測長度。後訓練依序採 SFT、具 verifiable objectives 的 multi-task RL，以及 black-/white-box agentic RL；以 harness×task abstraction 對齊環境軌跡與 token rollout，最後用 on-policy distillation 合併專家策略。RL 系統採 partial rollout、token-level importance sampling correction、staleness 約束、R3 routing replay、BKL outlier mask、GEPO、adaptive length regularization 與 online speculative decoding。Memory Decoder 以 retrieval distillation 加 gold-token CE 訓練，推論時由 router 動態融合 backbone 與 memory distributions。評估涵蓋科學、多模態、agentic、通用及 SciTS 等 benchmark，並報告任務分數、forecasting 表現與輸出長度／reward 比較。

## 關鍵結果

| 評估或設定 | 結果 |
|---|---|
| SciTS time-series understanding and forecasting | 論文稱 time-series modules 帶來改善，但未報告具體數字 |

## 對我們的啟發
- [ ] 若要訓練長時域科學 agent，應將可驗證任務獎勵、工具互動軌跡、環境觀察及 token-level rollout trace 對齊，避免只以靜態問答衡量能力。
- [ ] 在多任務 RL 中，可採用按任務難度啟用的 adaptive length regularization：對已具較高通過率的問題鼓勵較短的正確推理，對困難問題保留探索空間。這是根據論文方法提出的實務應用洞察。
- [ ] 對持續演化且長尾的科學領域，可考慮以外接 parametric memory 進行模組化特化，保留凍結通用 backbone；實際部署仍需同步驗證專業任務與通用能力。

## 限制與未來工作

論文未完整提供各 benchmark 的數值表格、baseline 細節、資料規模與消融結果，因此難以獨立判斷各訓練技術的個別貢獻。Memory Decoder 只以 Biology-Instructions 展示，領域泛化、記憶衝突、長期可靠性與實際科學發現成效仍需更多評估；模型規模與 agentic RL 的部署成本也未量化。
