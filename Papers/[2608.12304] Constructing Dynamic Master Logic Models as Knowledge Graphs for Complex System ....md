# Constructing Dynamic Master Logic Models as Knowledge Graphs for Complex System Diagnostics Using Retrieval-Augmented Large Language Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.12304)
- 📥 [PDF](https://arxiv.org/pdf/2608.12304v1)

## 摘要（中文翻譯）

Dynamic Master Logic（DML）提供階層式框架，將系統行為表示為功能目標與底層結構元素的連結。DML不同於事件導向的Fault Tree Analysis，能在統一功能階層中描述系統目標、功能依賴與未預期失效情境。然而，DML建構通常依賴專家解讀技術文件，限制了複雜系統的擴展性。本研究提出一套自動化框架，利用Retrieval-Augmented Generation（RAG）與Large Language Models（LLMs），從系統描述建構DML模型，並以Knowledge Graph表示為KG-DML。模型沿DML階層逐層建構，透過目標式檢索保留功能依賴與明確邏輯關係。KG-DML可支援診斷推理、安全評估、失效向上傳播與依賴向下追蹤。研究以多層次驗證評估各層precision、recall、邏輯閘一致性與整體結構完整性，並以已除役沸水反應器的Low-Pressure Coolant Injection系統進行案例研究。結果顯示，自動化KG-DML建構能將技術文件轉換為可執行的功能模型，用於診斷與可靠度分析。

## 問題背景

複雜工程系統具有多層目標、功能、子功能、元件與成功條件，傳統ETA、FTA等事件導向方法需預先列舉失效事件與因果序列，難以涵蓋未預期或級聯情境。DML雖能以功能階層表達依賴與失效傳播，但其建構長期依賴專家閱讀大量技術文件，擴展性有限；既有LLM又可能產生幻覺、推理不一致與結構不穩定。

## 解決方案

作者提出以RAG支援的LLM自動建構KG-DML框架。方法將大型工程文件切分並嵌入向量資料庫，依DML階層逐層檢索；每次檢索同時考慮當前層的語義定義與已建構的父節點，讓LLM在受限schema內輸出節點及其邏輯關係。經JSON結構驗證後，再轉換為Neo4j圖資料庫，並以閘節點保留AND/OR及巢狀邏輯。核心創新並非單獨提出RAG或LLM技術，而是整合受控抽取、階層式建構、可執行KG表示與多層結構評估，使模型可支援失效向上傳播、依賴向下追蹤與診斷推理。

## 核心貢獻
1. 提出從工程技術文件自動建構DML功能模型的方法，結合目標式RAG、LLM結構化抽取、預定義DML schema與JSON驗證流程。
2. 將先前針對小型系統的KG-DML方法擴展至較大型且文件密集的複雜系統，並以Neo4j實作可遍歷、可執行的圖表示。
3. 提出多層次評估框架，分別衡量Goals、Functions、Subfunctions、Components與Success Conditions的節點品質，以及跨層連結、邏輯閘與整體結構完整性。

## 技術方法

框架分為文件處理、逐層建構與圖合成三階段。首先標準化元件識別碼、展開縮寫、補充元件功能或位置描述，並解析代名詞與簡寫；文件依段落切分，每段上限1,500字元、重疊150字元，使用text-embedding-3-small建立向量並存入向量資料庫。其次依序處理Goals、Functions、Subfunctions、Components與Success Conditions。每一層以該層語義定義及上一層已驗證的父節點形成查詢，利用cosine similarity選取top-K=10個文件片段，交由GPT-4o（temperature=0）依預定義JSON schema抽取候選節點與AND/OR邏輯關係。輸出經結構正確性、識別碼有效性及層級限制檢查後，加入master JSON；不合格結果記錄並標示低信心。最後將JSON轉換為Neo4j Cypher，建立節點、父子關係與可遞迴表示巢狀Boolean gates的中介閘節點。評估先對預測模型與gold model做名稱標準化及語義對齊，再逐層計算precision、recall與偏重召回率的F2；另評估跨層連結的缺失、錯誤與多餘關係，以及各父節點的邏輯閘準確率。整體Integrity Score以加權各層F2，並透過結構錯誤的指數懲罰反映節點、連結、閘錯誤及孤立節點對完整功能路徑的影響。

## 對我們的啟發
- [ ] 對工程文件建模而言，先依DML階層逐層建構，再以既有父節點限制檢索範圍，有助於降低開放式KG抽取的歧義。
- [ ] 若下游推理依賴圖遍歷與Boolean propagation，評測不能只看節點precision與recall，還應檢查跨層連結、邏輯閘及端到端功能路徑。
- [ ] RAG與schema-constrained extraction可降低LLM自由生成的範圍，但論文也明確指出KG-DML仍屬LLM-informed模型，部署於安全或可靠度場景時必須保留領域專家驗證。

## 限制與未來工作

論文僅以一個已除役沸水反應器的Low-Pressure Coolant Injection系統展示方法，提供的內容未報告跨系統泛化、與人工建模或其他方法的baseline比較，也未完整呈現整體Integrity Score數值。作者指出模型仍需領域專家驗證；未來方向包括持續改善大型文件的建構與驗證，以及提升模型穩定性與結構完整性。
