# Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.18514)
- 📥 [PDF](https://arxiv.org/pdf/2611.18514v1)

## 摘要（中文翻譯）

Mechanistic Interpretability（MI）在解釋 Large Language Models（LLMs）內部計算方面已有進展，但尚未同樣成功地解釋 LLM-based agents 的決策過程。本研究探討 MI 工具應用於真實 agent 失敗情境時的挑戰，聚焦於 web agents 產生網站不存在操作的 hallucination。作者讓 Qwen2.5-7B-Instruct 與真實網站互動，發現基於最後一個 prompt token 訓練的 linear probe，可在生成前預測 hallucination，達到 0.80 AUC；沿 probe direction 進行 steering 可修正 85% 的 hallucination，但會使 7% 的有效操作失效。然而，這些結果只提供部分解釋：probe direction 對 prompt formatting 敏感，稍微改變 action 表示方式後 steering 效果大幅下降；此外，相關計算分散於多個元件與位置，且模型依賴的資訊因樣本而異。研究據此指出，標準 MI 的 circuit discovery 與 feature identification 假設並不完全適用於 agent，並提出未來發展方向。

## 問題背景

論文探討如何以 Mechanistic Interpretability 解釋真實 LLM agent 的失敗，具體是 web agent 生成網站不存在的操作。現有 MI 多在固定輸入、短任務與單一模型行為中尋找局部 circuits 或 features，但 agent 失敗可能跨越多個時間步、上下文、環境狀態與模型元件。研究顯示，localizability、stationarity、temporal locality 及跨分布穩健性等假設，在長程、具狀態的 agent 情境中可能失效。

## 解決方案

作者沒有提出已完成的單一修正演算法，而是以 Qwen2.5-7B-Instruct 的 web element hallucination 作為案例，系統性測試 linear probing、representation steering、activation patching、元件介入與 pretrained sparse autoencoders（SAEs）。研究提出一個面向 agent 的 MI 路線：建立包含環境、trajectory distribution、trajectory-level failure 與觸發因素 ground truth 的 MI benchmark；發展能處理跨元件、跨位置與跨時間步的 causal attribution；在 stateful environment 中構造可比較的 counterfactual；以 agent trajectory 訓練 SAE 並建立 agent-specific feature ontology；追蹤模型 belief 與 plan commitment 的演化，並檢驗不同 agent 類型間的 universality。核心創新在於以實證結果揭示標準 MI 方法的適用邊界，而非宣稱已完整解析 hallucination 機制。

## 核心貢獻
1. 以真實網站互動案例展示：MI 可在生成前偵測並部分修正 web element hallucination，但尚不足以完整解釋其形成機制。
2. 透過元件介入、activation patching、linear probing 與 steering，實證指出 hallucination 的計算分散於多個元件與輸入位置，且不同樣本依賴的資訊不穩定。
3. 提出 agent-oriented MI 的研究議程，包括 agentic MI benchmarks、跨時間與跨元件 causal attribution、stateful counterfactual、trajectory-trained SAE、belief monitoring 與跨 agent universality。

## 技術方法

研究使用 Qwen2.5-7B-Instruct，於 Online-Mind2Web 的 live websites 互動。每個網頁步驟最多執行 10 次，模型接收任務、DOM 摘要與由網頁建立的可用 action list，限制操作類型為 CLICK、SCROLL、TYPE、HOVER；若生成的操作不在清單中，即標記為 hallucinated action。資料包含 300 個 episodes、2,071 個 actions，其中 32.6% 為 hallucination。作者先以 FFN amplification、attention-head noise 與 joint interventions 分析元件因果作用，再以 activation patching 比較 selector start、task description、action list 等輸入區段的影響。Feature identification 方面，在 prompt_end、selector_start、selector_value_start 三個位置、各 28 層訓練 linear probes，採 episode-level 70/15/15 train/development/test split，並以 ROC-AUC 評估預測能力。接著將 probe 權重標準化為 steering vector，測量修正 hallucination 的 fix rate 與使有效行動變成 hallucination 的 break rate。研究亦測試 action list 從 JSON 改為 numbered markdown 後的分布轉移，並在 layer 27 使用 131,072 個 features、每 token 啟用 k=64 的 pretrained BatchTopK SAE，以比較 hallucinated 與 valid cases 的 feature activation。

## 關鍵結果

| 分析方法／設定 | 主要結果 |
|---|---|
| 資料集與失敗率 | 300 episodes、2,071 actions；32.6% actions 為 hallucinated |
| prompt_end linear probe | 生成前即可預測 hallucination；layer 18 測試 AUC 為 0.80 |
| selector_start L17 steering，原始 JSON 格式，α=40 | fix rate 85.4%；break rate 7.0% |
| selector_start L18 steering，原始 JSON 格式，α=40 | fix rate 82.9%；break rate 7.0% |
| 同一 L17 steering，numbered markdown 格式，α=40 | fix rate 58.1%；break rate 7.0%；相較原格式下降 27.3 個百分點 |
| 最佳 joint component intervention | 修正 8.9% hallucination；破壞 2.4% valid actions |
| activation patching | action list 在 P(Search) 的因果恢復最多達 0.36；selector_start 與 task description 的恢復低於 0.02 |
| counterfactual trajectory | 移除原選定 valid action 後，僅 38% 案例在第 0 步產生 hallucination；後續 selector agreement 約降至 25%，DOM Jaccard 約為 0.52 |
| pretrained SAE | 最具差異的 features 多數促進與觀察到的 hallucination 無關 token；論文未報告可解釋的 SAE feature 成功率 |

## 對我們的啟發
- [ ] 若將 probe 或 steering 用於 agent safety，應在不同 prompt/action 格式與環境分布上重新驗證，不能把單一格式下的 85.4% fix rate 視為可泛化保證。
- [ ] agent 監控可在生成前檢查 residual-stream 中的 hallucination risk；但部署時必須同時追蹤 break rate，避免以降低 hallucination 為代價破壞有效操作。
- [ ] 評估 agent 失敗原因時，不宜只尋找單一 attention head、FFN 或 token；應設計能整合歷史上下文、action list、環境狀態與多時間步的分析與反事實評估。

## 限制與未來工作

研究僅分析單一模型 Qwen2.5-7B-Instruct、單一 web-agent failure mode 與 Online-Mind2Web live websites，未證明結果可泛化至其他模型、agent 類型或失敗形式。作者也未提供完整可驗證的 failure trigger ground truth；提出的 benchmark、跨時間 attribution、trajectory-trained SAE 與 universality 仍屬未來方向。
