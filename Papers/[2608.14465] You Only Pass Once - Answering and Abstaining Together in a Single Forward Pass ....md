# You Only Pass Once: Answering and Abstaining Together in a Single Forward Pass of a Frozen Language Model

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.14465)
- 📥 [PDF](https://arxiv.org/pdf/2608.14465v1)

## 摘要（中文翻譯）

Frozen language model 在推理任務中有兩個相互耦合的弱點：未充分利用 residual stream 已編碼的證據，以及無法辨識輸入資訊不足而產生 confabulation。本文將兩條研究線整合到同一 residual stream：conditional steering probe 在中間層寫入訊息，以提升 frozen backbone 的推理準確率；zero-shot sufficiency direction 則讀取該表示，於資訊不足時 abstain。兩者在單次 forward pass 中會互相干擾，尤其小模型的跨域 AUROC 最多下降 8 個百分點。作者因此訓練小型 reconstruction network，從 steered residual 重建 pre-steering residual，使用 steered-clean 配對的 MSE，且不使用 sufficiency labels，再於重建結果上讀取固定方向。YOPO 可在一次 forward pass 中回答、steer 並 abstain；在 Qwen2.5-1.5B 的 alphaNLI 上，three-way accuracy 由 0.375 提升至 0.798，且單次推論在各模型規模均超過 two-pass reference。

## 問題背景

Frozen language model 在推理時一方面未能把 residual stream 中已有的證據傳到答案輸出，另一方面在資訊不足時仍自信作答，造成 confabulation。既有 steering 方法改善回答卻會改變 sufficiency reader 所依賴的表示；clean second pass 可恢復讀取品質，但推論成本加倍。直接對 steered state 訓練 supervised gate 又容易吸收來源任務特徵，導致跨域轉移崩潰。

## 解決方案

作者提出 YOPO（You Only Pass Once），在同一次 frozen backbone forward pass 中整合 conditional steering writer 與 zero-shot sufficiency reader。核心創新是只修復 steering 對 residual 的幾何擾動，而不重新訓練 abstention：以同一輸入的 steered/clean residual 配對，使用無 sufficiency labels 的 MSE 訓練小型 reconstruction map M，將 steered state 映射回 pre-steering state，再以固定 direction d 讀取 sufficiency score。低於 calibrated threshold 即 abstain，否則輸出 steering 強化的答案；另提供加入 BCE boost 的 flagship，並明確量化其 in-domain 與 transfer 的交換代價。

## 核心貢獻
1. 提出 YOPO 單次 forward pass 融合框架，以 label-free residual reconstruction 消除 steering writer 對 sufficiency reader 的干擾，同時保留回答與 abstention 能力。
2. 在 Qwen2.5 1.5B、3B、7B 及十個跨六種模型家族的 backbone 上，系統性量化 steering、sufficiency reading、重建修正與監督式 gate 之間的 capacity-transfer frontier。
3. 建立 answer-or-abstain hybrid benchmark，並以 SQuAD2、RepLiQA、MuSiQue 等 native-label 資料驗證：label-free direction 最能維持跨域轉移，而訓練 abstention 的方法通常承擔 transfer cost。

## 技術方法

YOPO 使用 frozen Qwen2.5 backbone（1.5B、3B、7B），僅訓練約 1% 參數的 probes。conditional steering writer 在三個中間層讀取 spread-5 prompt positions 的 residual，透過 MLP 產生 input-conditioned unit direction u(r) 與 gated magnitude a，並寫回 r' = r + a||r||u(r)；writer 以 answer cross-entropy 訓練，backbone 保持凍結。reader 則由 source-domain sufficient 與 insufficient 樣本的 residual 平均差建立固定 direction d，於指定 read layer 計算 s=dᵀh，並以 in-domain threshold 或跨域未標註資料的 median/percentile calibration 決定 abstain。為避免 writer 改變 reader 所讀的狀態，作者收集同一輸入在 steering hooks on/off 下的 (hsteer, hclean) 配對，訓練 reconstruction map M，使 M(hsteer) 以 MSE 重建 hclean；M 不使用 sufficiency labels。YOPO 推論時只執行一次 forward pass：沿途寫入 steering、擷取 steered residual、套用 M、讀取 d，若分數低於 threshold 則 abstain，否則輸出 steered answer logits。作者比較 single-layer residual corrector、multi-layer MLP、疊加 BCE supervised boost，以及 two-pass clean-read reference。資料包含 alphaNLI、HellaSwag、RepLiQA、BoolQ 的 constructed conditions，以及具 native labels 的 SQuAD2、RepLiQA、MuSiQue；指標包括 steering accuracy、full-versus-replace AUROC、cross-domain transfer AUROC、三向 answer-or-abstain accuracy 與 abstention recall。

作者另報告：standard four-domain suite 中，supervised gate 在所有資料集的 in-domain 表現最佳；label-free direction 是唯一能在跨域轉移中存活的 gate family。

## 對我們的啟發
- [ ] 若部署同時需要提升回答品質與避免資訊不足時的幻覺，可將回答用的 activation write 與 abstention 用的 representation read 分離，並以無判斷標籤的 reconstruction 先恢復乾淨表示。
- [ ] 模型容量與監督式 gate 的增加不必然改善實際部署：論文顯示小模型上 in-domain 準確率提升可能換來跨域能力下降，因此應以 transfer performance 與容量—轉移 Pareto frontier 共同選擇方案。
- [ ] 評估 answer-or-abstain 系統時，應同時報告回答正確率、abstention、AUROC、跨域校準與三向準確率；僅看模型是否能辨識 sufficiency，可能掩蓋決策層 threshold 或 force-answer 行為的失敗。

## 限制與未來工作

論文的部分 constructed transfer axis 過於容易，因表面差異即可辨識；同文件刪除答案句的 hard variant 又使所有 gate 接近 0.56–0.68。多層 reconstruction 在 7B 及 native-label 實驗多次不收斂。監督式 flagship 在小模型跨域表現明顯下降，且主要 backbone 實驗集中於 Qwen2.5；論文未報告更廣泛真實部署成本、延遲與長期校準結果。
