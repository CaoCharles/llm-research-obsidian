# SocietyBench: Forecasting Counterfactual Social-World Evolution

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.04009)
- 📥 [PDF](https://arxiv.org/pdf/2608.04009v1)

## 摘要（中文翻譯）

大型語言模型（LLM）及其代理系統目前多以完成任務的能力進行評測，例如修復程式錯誤、操作瀏覽器或使用圖形介面；然而，理解並預測真實社會事件如何演變的社會能力，幾乎尚未被量化。本文提出 SocietyBench：輸入一行事件主題，蒐集五個平台的網路新聞與社群媒體貼文，將其整理為按日期索引、區分事實事件與公共輿論的時間線，再把每個截點轉換為經人工審核的預測問題庫。問題分別以機率校準與時間準確度兩個互相獨立的 100 分軸評分。為避免模型依靠預訓練記憶，作者替換所有具名實體，並以每個事件獨立的常數平移日期，建立與真實事件結構相同、但表面標籤不同的反事實社會世界。在五個異質事件、125 個預測點及中英文版本上，六個前沿 LLM 中最強者得分為 75.0，僅高於 50 分的簡單基準。實驗顯示校準與時間能力可能分離，代理框架未改善基礎模型，且單一事件的結果差異可達 21.4 分。作者釋出匿名時間線、問題庫、真值與評分程式。

## 問題背景

現有 LLM benchmark 主要測試任務完成，較少衡量模型能否理解真實社會事件並預測其後續演變。既有 forecasting benchmark 多集中於二元的是非問題，或依賴尚未結束的即時事件；歷史事件又可能被模型從預訓練資料記憶。相關社會模擬工作則評估生成社會的逼真度，而非對真實事件逐點預測。此外，既有方法通常忽略公共輿論，也缺乏同時評估機率不確定性與事件時間的框架。

## 解決方案

作者提出 SocietyBench，將已完成的真實社會事件轉換為可回溯評測的反事實世界。系統先從新聞與五個社群平台蒐集資料，建立按日期排列且分離事實與輿論的時間線；接著以實體替換及一致日期平移去除事件名稱與絕對時間線索，再將每個截點自動生成並經稽核的校準題與時間題。評分採兩個互相獨立的 100 分軸：校準軸衡量機率與二元真值的偏差，時間軸衡量預測日期與真實日期的距離。這個設計可在不等待新事件發生的情況下使用完整歷史事件，同時降低事件記憶造成的分數膨脹。

## 核心貢獻
1. 提出 SocietyBench 端到端社會事件預測 benchmark，涵蓋五個異質領域，結合網路新聞與五個社群媒體平台，並提供中英文一對一版本。
2. 設計三階段實體與日期匿名化，將已完成的真實事件轉為反事實社會世界，以降低依靠預訓練記憶進行事件召回的可能性。
3. 建立分離的機率校準與時間準確度評估軸，並比較六個 LLM、三種代理框架及兩個非 LLM 基準，公開資料與評分程式。

## 技術方法

任務以每個匿名事件的截點 dP 為單位：模型只能看到此前的時間線內容 CP，並預測其後的真值節點 GP。資料涵蓋公共爭議、地緣政治、科技政策、金融市場與貿易政策五類事件；每事件建立 39 至 168 個節點、25 個預測點，並從網路新聞及五個社群平台整理事實層與公共輿論層。匿名化包含三階段：先以最長匹配替換具名實體，再對所有日期套用每事件獨立、均勻取樣且範圍為 ±180 天的常數偏移，最後由三個對抗式 LLM 稽核者嘗試辨識原事件與時段，必要時增補替換表或重新取樣；另執行段落、事件與敘事層級的一致性檢查。校準問題要求模型輸出事件在指定日期視窗內發生的機率，使用時間衰減因子與視窗因子加權 MAE，並轉換為 0–100 分：S_cal=100×max(0,1−wMAE)。時間問題要求預測未來事件日期，以真實日期誤差計算三個 30 天區間內的正規化 miss，再以時間因子加權轉為 S_time。兩軸各自對每事件計算，最後取五事件平均；實驗以 temperature 0、固定推理預算，在中英文版本評估六個 API LLM、三個代理框架與兩個非 LLM 啟發式基準。

## 關鍵結果

| 系統 | 校準平均 | 時間平均 | Overall |
|---|---:|---:|---:|
| GPT-5.5 | 75.3 | 74.6 | 75.0 |
| Gemini-3.5-Flash | 73.9 | 67.3 | 70.6 |
| Claude-Opus-4.8 | 62.5 | 70.0 | 66.3 |
| DeepSeek-V4-Pro | 62.5 | 64.9 | 63.7 |
| Kimi-K2.5 | 63.3 | 63.6 | 63.4 |
| Doubao-Seed-2.0-Pro | 64.3 | 62.6 | 63.4 |

論文報告的整體結果：五個事件、125 個預測點、兩種語言版本中，最佳 LLM 的 Overall 為 75.0；校準與時間兩軸的簡單基準均約為 50。三個以 Doubao 為基礎的代理框架中，LangGraph、AutoGen、MiroFish 的 Overall 分別為 62.1、60.5、63.1，而基礎 Doubao 為 63.4。兩個非 LLM 校準基準的分數為 53.8 與 54.2，時間軸均記為 50。最大單事件單軸差距出現在 Trump Tariff 的 GPT-5.5 與 Kimi-K2.5 時間分數：85.4 對 64.0，差 21.4 分。消融結果顯示，移除 A 型時間梯度問題使六模型平均校準分數上升 7.2 分；較晚截點的平均校準分數由 66.7 上升至 68.7。

## 對我們的啟發
- [ ] 若要評估社會世界預測能力，應同時測量事件是否發生的機率校準與發生時間，不能以單一準確率或單一總分替代；這是根據論文觀察到兩軸能力明顯分離所得的實務啟發。
- [ ] 評測資料可採用實體替換與一致日期平移，降低模型直接匹配歷史事件與絕對日期的機會；但仍應搭配多事件與匿名化稽核。
- [ ] 代理編排不必然改善預測：在本文設定中，LangGraph、AutoGen 與 MiroFish 均未超越 Doubao 基礎模型，因此部署代理系統前應以同一基礎模型做嚴格對照。

## 限制與未來工作

論文僅使用五個事件與 125 個預測點，事件池仍有限，單一事件可能造成顯著波動；作者也指出需更強匿名化、更廣事件範圍、更細緻區分近似模型，並鼓勵社群貢獻事件與系統。論文未報告模型內部架構，且釋出資料不包含逐題模型回答。
