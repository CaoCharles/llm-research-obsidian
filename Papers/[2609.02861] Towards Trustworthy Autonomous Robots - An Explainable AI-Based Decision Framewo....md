# Towards Trustworthy Autonomous Robots: An Explainable AI-Based Decision Framework

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.02861)
- 📥 [PDF](https://arxiv.org/pdf/2609.02861v1)

## 摘要（中文翻譯）

由 deep learning 驅動的 autonomous robots 面臨根本性的可稽核性挑戰：事故發生後，調查人員往往無法重建系統作出特定決策的原因。本文提出 TRACE（Transparent Reasoning Architecture for Credible Execution），透過記錄化的因果鏈，確保每個自主動作都能追溯至 sensor evidence。TRACE 將決策分為四個可稽核層次：以證據為基礎的實體辨識（Semantic Perception）、結合 probabilistic state estimation 與 causal graphs 的信念推理（Belief Reasoning）、具約束感知規劃與 counterfactual documentation 的動作合成（Action Synthesis），以及合規監控（Execution Verification）。TRACE 具 model-agnostic 特性，可整合 CNN、transformer 等 learning-based perception 模組，同時維持 decision-level auditability。作者以 Evidence Traceability、Decision Reconstructability 與 Temporal Continuity 三項指標，在 warehouse robot navigation 的 500 個 simulated decision cycles 中評估，分別達到 98.6%、98.1% 與 99.0%。

## 問題背景

論文聚焦於 deep learning autonomous robots 的決策難以在事故後稽核與重建問題。現有 LIME、SHAP 等 post-hoc XAI 主要提供單次模型輸出的 feature attribution，無法保存跨時間的決策序列、候選動作與選擇理由；attention 也不必然代表因果關係。Runtime verification 可偵測規格違反，卻不記錄決策為何形成，因此難以支援事故調查、安全認證與高風險 AI 的透明度要求。

## 解決方案

作者提出 TRACE（Transparent Reasoning Architecture for Credible Execution），將可稽核性直接嵌入 autonomous robot 的決策架構，而非事後從 opaque model 抽取解釋。框架包含四層：Semantic Perception 將 sensor data 轉為附帶證據連結的實體；Belief Reasoning 以 probabilistic scene graph 與 causal graph 表示觀測及推論狀態；Action Synthesis 記錄候選動作、選擇 rationale 與 Counterfactual Decision Tree；Execution Verification 則比對預期與實際執行並產生 timestamped audit records。核心創新是以統一 artifact structure 保存 sensor-to-decision causal chains、替代方案及反事實條件，支援獨立調查者進行 decision-level reconstruction。

## 核心貢獻
1. 提出具正式層間介面的四層 TRACE decision architecture，使 audit artifacts 從 Semantic Perception、Belief Reasoning、Action Synthesis 延續至 Execution Verification。
2. 定義 Evidence Traceability、Temporal Continuity 與 Decision Reconstructability 三項 auditability metrics，直接衡量 sensor evidence、時間記錄及決策重建條件。
3. 提出 Counterfactual Decision Trees，記錄已選動作、替代動作、選擇 rationale 及觸發替代方案的條件，支援事故後的 what-if 分析。

## 技術方法

TRACE 將每個 decision cycle 分為四層處理。第一層 Semantic Perception 融合 LiDAR、camera 與 ultrasonic 等 sensor data，輸出包含 id、class、pose、calibrated confidence distribution 及 evidence set 的 evidence-grounded entities；evidence set 記錄 sensor source、contribution weight 與 spatial region。第二層 Belief Reasoning 建立 probabilistic scene graph G=(V,E,P)：實體形成節點，推理規則產生具 conditional probability 的關係邊，並將如「aisle blocked」等 derived states 連回父證據節點。第三層 Action Synthesis 產生候選動作，依 objectives 與 constraints 評估，並以 Counterfactual Decision Tree 記錄 alternatives、rationale 及觸發其他動作的條件。第四層 Execution Verification 監控 command 執行，記錄 intended/actual deviation、flags，以及包含時間、實體、belief state 與 selected action 的 audit record。評估使用 Python warehouse simulation，環境為 50m×30m，10Hz，五種場景各 100 cycles，共 500 cycles；設定 LiDAR 2%、camera 12%、evidence link corruption 3%、causal edge write failure 2%、rationale truncation 2% 與 counterfactual timeout 2.5% 等失效模式。指標為 Evidence Traceability（決策因素是否連至 sensor evidence）、Temporal Continuity（audit trail 的時間完整性）及 Decision Reconstructability（action、alternatives、rationale 是否均被記錄）。

## 關鍵結果

| 方法 | Evidence Traceability（ET） | Temporal Continuity（TC） | Decision Reconstructability（DR） | 時間 |
|---|---:|---:|---:|---:|
| TRACE | 98.6% ± 7.0% | 99.0% | 98.1% | 0.12 ms |
| Attention | 20–25% | 70–80% | 論文未報告（N/A） | <0.01 ms |
| SHAP | 30–35% | 0% | 論文未報告（N/A） | 0.02 ms |
| LIME | 25–30% | 0% | 論文未報告（N/A） | 1.29 ms |

TRACE 的 ET 未完全滿足比例為 1.4%（500 次中的 7 次），ETpartial 為 0.98；TC 缺口為 1.0%（5 筆記錄）。DR 有 23/500 筆未完全可重建。各場景 ET 為 96.4%–100%，TC 為 99%–100%，DR 為 96.6%–99.0%。上述 baseline 為 architectural capability analysis，並非直接實作比較。

## 對我們的啟發
- [ ] 若系統需要事故後稽核，應在執行時保存實體、信念更新、候選動作與執行偏差，而不只保存模型輸出或 feature attribution。
- [ ] 可將 TRACE 的四層 artifact interface 作為既有 robotic software stack 的整合要求；論文指出底層模組需暴露 detected entities、belief updates 與 candidate actions 等中間表示。
- [ ] 部署 audit trail 時需同時規劃可靠寫入與分層儲存；論文估計完整記錄可能造成大規模儲存負擔，並提出 hot、warm、cold storage、壓縮及 delta encoding 作為策略，但其 fleet-scale 效益仍待驗證。

## 限制與未來工作

評估完全在 simulation 中進行，感測器噪聲與失效模式較理想化，0.1–0.12 ms 的 overhead 也未在 embedded hardware 驗證。指標只衡量由 artifacts 重建的能力，未證明調查人員實際使用效益；部分決策仍有不完整證據鏈。未來工作包括 ROS 2、實體機器人驗證、調查人員 user study、formal verification 與大規模壓縮驗證。
