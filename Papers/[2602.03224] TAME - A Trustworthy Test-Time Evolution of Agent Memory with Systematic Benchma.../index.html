    TAME: A Trustworthy Test-Time Evolution of Agent Memory with Systematic Benchmarking

    連結

    • 📄 arXiv
    • 📥 PDF
    • 📎 本地 PDF: PDF

    摘要（中文翻譯）

    測試時代理記憶體演化是透過經驗累積增強複雜推理以達成 AGI 的關鍵範式。然而，即使在良性任務演化期間，代理安全對齊仍然脆弱——這種現象稱為「代理記憶體錯誤演化」。為評估此現象，我們構建 Trust-Memevo 基準，評估良性任務演化期間的多維度可信度，發現跨任務領域和評估設定的可信度整體下降。為解決此問題，我們提出 TAME 雙記憶體演化框架：分別演化執行器記憶體（蒸餾可泛化方法論以提升任務效能）和評估器記憶體（基於歷史回饋精煉安全和效用評估）。透過記憶體過濾、草稿生成、可信精煉、執行和雙軌記憶體更新的閉環，TAME 在保持效用的同時維護可信度。

    論文預覽

    問題背景

    代理系統在測試時透過記憶體演化累積經驗，但這種演化過程可能導致安全對齊的退化——即使執行的是良性任務。現有方法缺乏系統性評估此「記憶體錯誤演化」現象的基準，也缺乏同時保持可信度和任務效能的解決方案。

    解決方案

    提出 TAME 雙記憶體演化框架，核心創新是將記憶體分為兩個獨立演化的軌道：(1) 執行器記憶體專注於蒸餾可泛化的任務方法論；(2) 評估器記憶體基於歷史回饋精煉安全和效用評估標準。透過閉環機制確保每次記憶體更新都經過可信度檢查。

    核心貢獻

    1. 提出「代理記憶體錯誤演化」概念並構建 Trust-Memevo 評估基準
    2. 設計雙記憶體演化架構，分離任務效能和可信度的演化路徑
    3. 實現記憶體過濾-生成-精煉-執行-更新的閉環可信演化機制

    技術方法

    TAME 框架包含五個閉環階段：(1) 記憶體過濾：根據當前任務檢索相關記憶；(2) 草稿生成：基於檢索記憶生成執行計劃；(3) 可信精煉：評估器記憶體檢查計劃的安全性；(4) 執行：執行精煉後的計劃；(5) 雙軌更新：分別更新執行器和評估器記憶體。評估在 Trust-Memevo 基準上進行，涵蓋多個任務領域和維度的可信度指標。

    關鍵結果

    方法 任務效能 可信度
    無記憶體演化 基準 高
    標準記憶體演化 高 下降
    TAME 高 維持

    對我們的啟發

    • 代理記憶體演化是一把雙刃劍：提升效能的同時可能損害安全對齊
    • 分離任務效能和可信度的演化路徑是解決權衡問題的有效策略
    • 評估器記憶體的持續演化可作為代理系統的「安全護欄」

    限制與未來工作

    TAME 增加了系統複雜度和計算開銷。雙記憶體的同步演化策略可能需要針對不同任務領域調整。長期演化後兩個記憶體軌道的一致性維護仍是開放問題。
