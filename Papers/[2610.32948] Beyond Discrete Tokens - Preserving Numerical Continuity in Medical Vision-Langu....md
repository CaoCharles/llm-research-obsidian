# Beyond Discrete Tokens: Preserving Numerical Continuity in Medical Vision-Language Models

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.32948)
- 📥 [PDF](https://arxiv.org/pdf/2610.32948v1)

## 摘要（中文翻譯）

目標：開發一個統一的 vision-language model，用於由 prompt 條件化的定量超音波測量，解決連續測量目標與離散 token 數值預測之間的不匹配。方法：本文提出 HAD-VLM，一種 hybrid autoregressive-diffusion 框架，在共享 backbone 中結合 autoregressive 文字生成與連續測量預測。模型以 visual prompt tuning 使 vision encoder 適應超音波影像，並透過 diffusion process 預測由測量卡尺兩端座標及測量長度組成的五元素表示。作者另提出結合 coordinate-length consistency mechanism 與 ensemble prediction 的後處理策略，以精煉測量結果。結果：在 EchoNet-LVH 的四項心臟超音波測量任務中，IVSd、LVIDd、LVIDs 與 LVPWd 的 MAE 分別為 1.36、2.77、3.05 與 1.16 mm，相較 Vicuna-based autoregressive baseline 降低 21.4–37.6%。HAD-VLM 亦優於 fine-tuned Qwen3-VL 與 direct MLP regression。醫學問答表現得以保留；在 X-ray 椎體測量中，MAE 由 11.4 降至 6.7 pixels。結論：結合 autoregressive language generation 與 diffusion-based continuous prediction，可改善定量醫學影像測量，同時保留 prompt-conditioned task flexibility。意義：HAD-VLM 提供整合語言互動與具解剖定位之數值預測的方法。

## 問題背景

現有醫學影像測量模型多針對預先定義的解剖目標與輸出格式，缺乏由自然語言 prompt 彈性指定測量任務的能力。VLM 雖能進行影像問答與文字生成，但通常以離散 token 自回歸預測數值；token 化不直接表達數值距離，數字或小數點錯誤可能造成不成比例的測量誤差，也未明確維持卡尺端點與長度之間的幾何關係。

## 解決方案

作者提出 HAD-VLM，將 autoregressive 文字生成與 diffusion-based 連續測量預測整合於共享的 vision-language backbone。模型以 CLIP ViT-L/14 搭配 visual prompt tuning 處理超音波影像，並透過 projector 對齊 LLM 表徵。數值測量以五元素向量表示，包括卡尺起點與終點的 normalized coordinates 以及長度，由插入 LLM 數值槽位的 diffusion process 預測。核心創新包括 coordinate-length consistency mechanism，利用座標推導長度與直接預測長度的差異進行修正，以及多次 diffusion sampling 的 ensemble aggregation。

## 核心貢獻
1. 提出 HAD-VLM，將 autoregressive 文字生成與 diffusion-based continuous measurement prediction 整合於共享的 vision-language backbone，支援由自然語言 prompt 指定多項超音波測量任務。
2. 提出包含卡尺端點座標與測量長度的五元素表示，並以 coordinate-length consistency mechanism 連結解剖定位與數值估計。
3. 透過 visual prompt tuning、coordinate-length consistency 與 diffusion ensemble，在 EchoNet-LVH 四項測量上優於 autoregressive VLM、fine-tuned Qwen3-VL 與 direct MLP regression，並初步展示 X-ray 跨模態適用性。

## 技術方法

HAD-VLM 使用凍結的 CLIP ViT-L/14 vision encoder，於每個 Transformer layer 加入 4 個 local prompts，並在第一層加入 4 個 global prompts；串接 class token 與第一個 global prompt，經兩層 MLP projector 映射至 LLM embedding space。語言 backbone 為 Vicuna-7B-v1.5，輸入包括 user prompt 與 visual tokens，輸出同時包含 autoregressive 文字及 diffusion 數值。每項測量表示為 x0=[us,vs,ue,ve,m]，其中座標經 normalized，m 為像素長度。模型以 DDPM-style denoising process 從雜訊樣本恢復五元素向量，並以 language modeling cross-entropy loss 與 diffusion denoising MSE loss 聯合訓練。訓練分為三階段：先以文字損失對齊 visual prompts 與 connector，再訓練 diffusion 模組並對 LLM 最後四層使用 LoRA，最後共同最佳化兩項損失。推論時以方括號控制文字與 diffusion 模式切換，使用 4-step DDIM，獨立取樣 20 次。後處理比較座標推導長度與直接預測長度；差異超過 validation set 的 85th percentile threshold 時採直接長度，否則取兩者平均，再以 median aggregation 得到最終長度。資料來自 EchoNet-LVH，訓練、驗證、測試比例為 87:3:10，評估 IVSd、LVIDd、LVIDs、LVPWd。主要指標為 MAE、RMSE、R²、Pearson correlation；另評估 word-level F1、BERTScore，以及 CSXA X-ray 椎體測量的 pixel MAE。

## 關鍵結果

EchoNet-LVH 四項測量結果：

| 模型 | IVSd MAE (mm) | LVIDd MAE (mm) | LVIDs MAE (mm) | LVPWd MAE (mm) |
|---|---:|---:|---:|---:|
| VLM (Vicuna) | 1.82 | 3.62 | 3.88 | 1.86 |
| Fine-tuned Qwen3-VL | 1.68 | 3.71 | 3.82 | 1.47 |
| VLM + MLP Regression | 1.41 | 3.00 | 3.42 | 1.28 |
| HAD-VLM | **1.36** | **2.77** | **3.05** | **1.16** |

HAD-VLM 相較 Vicuna baseline 的 MAE 降幅依序為 25.3%、23.5%、21.4% 與 37.6%；其 R² 分別為 0.56、0.78、0.77、0.55，Pearson correlation 分別為 0.75、0.89、0.88、0.74。消融實驗顯示，移除 visual prompt tuning 後，四項 MAE 變為 1.93、5.07、5.60、1.58 mm；移除 consistency 與 ensemble 後則為 1.49、3.04、3.31、1.31 mm。醫學 QA 中，word-level F1 由 0.298 提升至 0.320，BERTScore F1 由 0.869 提升至 0.882。CSXA X-ray 椎體測量中，MAE 由 11.4±93.9 pixels 降至 6.7±5.7 pixels。

## 對我們的啟發
- [ ] 對需要精確數值的 multimodal 系統，將數值從文字 token 生成中分離，改以連續變數分支建模，可能比單純 autoregressive numerical decoding 更合適。
- [ ] 若測量同時包含空間定位與數值長度，應在輸出表示或後處理中顯式加入幾何一致性檢查；論文結果顯示 consistency 與 ensemble 可在 diffusion 預測之上提供額外改善。
- [ ] 多任務 prompt-conditioned training 不僅保留單一模型支援多種測量的彈性，論文在四項 EchoNet-LVH 任務中亦觀察到優於獨立 single-task models 的結果；實務部署仍應同步驗證端點解剖正確性，因為長度準確不必然代表卡尺位置準確。

## 限制與未來工作

論文指出目前 HAD-VLM 聚焦於線性測量，尚未處理更複雜的幾何或面積測量。作者將跨機構與不同影像條件的驗證、測量不確定性估計，以及整合完整報告生成列為未來工作。X-ray 實驗以 pixel space 評估，因資料缺乏一致的實際距離校正；與專家變異的比較也受資料集與評估流程差異限制。
