# An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity: Decoupling Confidence and Consistency

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.22043)
- 📥 [PDF](https://arxiv.org/pdf/2609.22043v1)

## 摘要（中文翻譯）

LLM agent 的記憶系統過去主要聚焦於高效率 retrieval，但對 retrieved memories 是否值得信任的決策關注較少。當 memory store 含有相互衝突的立場時，standard RAG 會盲目注入 memories，並放大 hallucination；對容易受 memory injection 影響的模型而言，衝突記憶下的 RAG hallucination rate 明顯高於無記憶 baseline。本文提出 Memory Decision Layer（MDL），一個位於 retrieval 與 generation 之間的 zero-parameter memory decision controller。其核心是 three-signal complementary encoder，透過 QR-based orthogonal subspace projection 融合 relevance、reliability 與 task risk，並結合 meta-working-memory signal，形成可解釋的記憶可信度表示。MDL 明確區分 confidence 與 consistency，並引入 risk inversion 與 explicit abstention。多個 LLM 與 open-source datasets 的評估顯示，MDL 在一般衝突記憶情境下約降低 56.04% hallucination rate，在高風險情境接近零 hallucination。控制器完全 white-box、無需訓練參數，每次決策僅約 0.14 ms。

## 問題背景

論文處理 retrieved memory 被注入 LLM context 前缺乏信任判斷的問題。現有 RAG 多以 relevance 或 retrieval score 決定採用記憶，無法辨識高相關但過時、錯誤或立場衝突的內容；Self-RAG、Reflexion 與 post-hoc detection 則在錯誤記憶已污染 context 或生成結果後才處理，難以事前阻止 hallucination。

## 解決方案

作者提出位於 retrieval 與 generation 之間的 Memory Decision Layer（MDL）。MDL 以 relevance（M）、reliability（R）與 task risk（A）三種訊號建立 zero-parameter complementary encoder，利用 value encoding、QR 產生的 orthogonal subspaces、meta-working-memory fusion 與 risk inversion，形成決策向量。其核心創新是將 confidence C（向量 norm）與 directional consistency α（cosine）分開計算，再以 Cfinal=C·(0.3+0.7α) gating，映射至 Active、Suppress、Silent、Opt-Out 四種行動，讓高風險或衝突記憶能被抑制或拒答。

## 核心貢獻
1. 提出位於 retrieval 與 generation 之間的 zero-parameter Memory Decision Layer，以 relevance、reliability 與 task risk 三訊號進行記憶採用或 abstention 決策。
2. 提出以 QR orthogonal subspace projection、value encoding 與 meta-working-memory fusion 建立可解釋的決策表示，並將 confidence norm 與 directional consistency cosine 分開審計。
3. 透過 risk inversion 與四級 action mapping 實現高風險拒答；在 TruthfulQA、HaluEval 及多個 LLM 上驗證衝突記憶 hallucination 抑制，並維持約 0.14 ms 的低延遲。

## 技術方法

MDL 的輸入包含 query、candidate memories、relevance、reliability 與 risk。M 定義為 query embedding 與候選記憶 embedding 的最大 cosine similarity；R 為相關記憶的平均 pairwise similarity，乘以 conflict rate 的平方補數，衝突由涵蓋否定、yes/no polarity 與 antonym pairs 的 lexical detector 判定。A 依 TruthfulQA 類別或 HaluEval 的 health、legal、finance 與 science keywords 指派，並以 1−A 進行 risk inversion。三個 scalar 透過 16 維 Gaussian-peak value encoding 轉為向量，再依 5、5、6 維配置投影至 QR 建立的互相正交子空間，經 risk modulation 與 tanh fusion 得到 vmeta。其 norm 經校準正規化為 C，與 relevance pathway 的 cosine 得到 α，再計算 Cfinal 並以三個 thresholds 產生四級 action。實驗在 TruthfulQA 與 HaluEval 建立包含正確答案、錯誤答案及兩筆 distractor 的衝突 memory store，以 embedding similarity、錯誤答案相似度超過 0.5 且高於正確答案來判定 hallucination，明確 refusal 則視為 safe abstention。比較 B1 no memory、B2 standard RAG、B3 MDL，以及 CRAG、Self-RAG 和 supervised LR、MLP、XGBoost；另進行訊號組合、模組 ablation、跨模型、跨資料集與 latency 評估。

## 關鍵結果

## 對我們的啟發
- [ ] 在 RAG pipeline 中，retrieval 與 generation 之間可增設獨立的 trust-decision gate，避免將「高相關」直接等同於「可採用」。
- [ ] 高風險任務不應只提高 retrieval 或 generation 品質，也需要明確的 risk-aware abstention policy；本文結果顯示 risk inversion 對高風險 hallucination 控制尤其關鍵。
- [ ] 可將 confidence 與 directional consistency 作為不同的 audit signals，而不是只輸出單一 retrieval score；不過本文也顯示兩者正相關（r=0.902），因此其價值是可分別解讀與稽核，並非統計獨立。

## 限制與未來工作

論文指出，高風險且高相關（A≥0.70、M≥0.70）時，極高 relevance 可能抵銷部分 risk suppression，117 筆醫療資料的 decision accuracy 為 55.6%；Active action 仍有 8.0% hallucination。訊號抽取依賴 heuristic lexical detector 與規則式 risk mapping，且評估主要使用 TruthfulQA、HaluEval 及構造的衝突 memory store。未來方向包括 differentiable signal extraction、fragment-level filtering，以及更大模型與 adversarial multi-turn dialogue 的驗證。
