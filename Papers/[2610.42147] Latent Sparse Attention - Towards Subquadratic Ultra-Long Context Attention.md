# Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.42147)
- 📥 [PDF](https://arxiv.org/pdf/2610.42147v1)

## 摘要（中文翻譯）

Agentic workflow 正逐漸轉向長期、多步驟任務，例如開放式科學研究；在此類任務中，模型可受益於長 context window。然而，當 context 超過 1M tokens 時，full attention 的成本高得難以實用。Sparse attention 透過專用 indexer 選取部分 keys，是可行方向，但現有 indexing 方法不是仍具有對 context 長度的 quadratic cost，就是在 ultra-long context 下準確率下降。本文提出 Latent Sparse Attention（LSA）：在 learned latent space 中對 keys 進行階層式 clustering，讓 queries 搜尋 cluster hierarchy，而非逐一評分所有 keys，從而加速 prefill、decode 與 training。作者提出可透過 distillation 套用於預訓練模型的 Distilled-LSA（D-LSA），以及僅以 next-token loss 原生訓練的 Native-LSA（N-LSA）。在 10M tokens 下，D-LSA 可大幅加速 attention layer，且在多類任務維持相近準確率。

## 問題背景

論文聚焦於 ultra-long context（超過 1M tokens）下 attention 成本過高的問題。Full attention 的 prefill 為 O(T²)、decode 為 O(T)；現有 sparse attention 雖減少實際參與 attention 的 keys，卻通常仍需對每個 preceding key 或 block 進行 indexing，因此 indexer 本身在 prefill 仍為 O(T²)、decode 為 O(T)，並在 10M tokens 時成為主要瓶頸。部分 block-based 方法還可能因群組摘要而遺漏少量但關鍵的 token。

## 解決方案

作者提出 Latent Sparse Attention（LSA），先將 keys 投影至低維 learned latent space，再經 L2 normalization、consecutive-key pooling 與 semantic clustering，建立包含 cluster centroid 和 token index table 的 bucket cache。Query 不再掃描所有 keys，而是評分 bucket centroids，選取 top-p buckets，再展開為固定數量的 long-range keys，並加入 sink keys 與 recent window。LSA 支援 Flat search 與以 beam search 遍歷多層 hierarchy 的 Tree search；後者使 indexer prefill 成本由 quadratic 降為 O(T log T)。D-LSA 透過 frozen pretrained model 的 attention distillation 學習 index projections；N-LSA 則直接以 attention keys、NTP loss 原生訓練，不需 teacher、額外參數或 auxiliary loss。

## 核心貢獻
1. 提出 LSA，透過 learned latent space 的 semantic clustering 與 Flat/Tree search，將 query 的 key selection 從逐 key 掃描改為 cluster 搜尋；Tree 版本的 indexer prefill 理論複雜度為 O(T log T)。
2. 提出 D-LSA 與 N-LSA 兩種訓練方案：D-LSA 只訓練每層小型 index projections 與 temperature 以蒸餾至預訓練模型；N-LSA 僅以 NTP loss 原生訓練，無需 teacher、額外參數或 auxiliary loss。
3. 在 QWEN-3.8-27B 與 GLM-5.3-FLASH 上，將 D-LSA 實際評估至 10M tokens，涵蓋 RULER、PaperTrail、知識、推理與端到端 serving，並整合 SGLang、context parallelism 及 GPU kernels。

## 技術方法

D-LSA 對既有模型的 attention keys/queries 使用低維 projections；query heads 的投影結果加總為單一 index query。Keys 先以每 npool 個 consecutive keys pooling，再在固定 cluster block 內以 Ward’s method bottom-up clustering，限制 bucket 大小並快取 centroid 與索引。Flat search 評分先前所有 bucket；Tree search 將 buckets 再組成多層 node buckets，以固定 beam 逐層下降，理論上每 query 評分 O(log T) 個 centroids。每個 query 最終選取 k 個 long-range keys，加上 nsink 個 sink keys 與 nw 個 recent window keys，再由原 attention kernel 計算。D-LSA 的 distillation 使用 frozen attention 在可選 keys 上的 head-averaged attention distribution，最小化 forward KL；訓練資料為 352M tokens、48k steps。評估涵蓋 QWEN-3.8-27B、GLM-5.3-FLASH，使用 MMLU-Pro、GPQA-Diamond、AIME25、MATH500、LongBench v2、RULER 與作者提出的 PaperTrail，context 最長 10M tokens，並測量單層及端到端 TTFT、TPOT。N-LSA 另以約 0.5B 參數模型，在 4k 與 128k context 上比較 Full Attention、SWA、NSA、PISA。

## 關鍵結果

| 實驗項目 | 結果 |
|---|---|
| D-LSA，GLM-5.3-FLASH，10M tokens，單 attention layer prefill | 相對原 sparse attention 加速 22.7× |
| D-LSA，GLM-5.3-FLASH，10M tokens，單 attention layer decode | 相對原 sparse attention 加速 4.6× |
| D-LSA，QWEN-3.8-27B，10M tokens，單 attention layer prefill | 相對 full attention 加速 72.4× |
| D-LSA，QWEN-3.8-27B，10M tokens，單 attention layer decode | 相對 full attention 加速 42.5× |
| GLM-5.3-FLASH，10M tokens，端到端 CP8 | TTFT 降低 2.2×、TPOT 降低 2.1× |
| QWEN-3.8-27B，10M tokens，端到端 H200、TP8+DCP8 | TTFT 降低 9.2×、TPOT 降低 2.9× |
| N-LSA，128k tokens，單 attention layer training | 相對 Full Attention 加速 1.6× |
| N-LSA，128k tokens，validation loss | 1.085，與 Full Attention 的 1.085 相同 |
| N-LSA，128k tokens，RULER | 32.2；Full Attention 為 34.7，NSA 為 19.2，PISA 為 14.6 |
| QWEN-3.8-27B，10M tokens，RULER | D-LSA 63.9；Full Attention 59.9 |
| QWEN-3.8-27B，10M tokens，PaperTrail | D-LSA 29.1；Full Attention 19.8 |
| GLM-5.3-FLASH，10M tokens，RULER | D-LSA 與 baseline sparse attention 差距在 4 分內 |

論文亦指出，D-LSA Tree 在 GLM-5.3-FLASH 的 10M-token RULER 得分為 55.8，低於 D-LSA Flat 的 66.8；因此 tree search 的理論效率優勢尚未在所有設定中轉化為準確率優勢。

## 對我們的啟發
- [ ] 若應用需要處理百萬至千萬 token 的長期 agentic workflow，降低 indexer 掃描成本可能比單純降低 attention 計算量更關鍵；LSA 的 cluster cache 與固定 key budget 提供一種工程化路徑。
- [ ] 評估 ultra-long-context 方法時，應同時報告準確率、單層 prefill/decode、端到端 TTFT/TPOT、記憶體與平行化通訊成本；單層理論 speedup 不必然等於整體模型的相同比例改善。
- [ ] 語義 clustering 相較連續 block selection 能降低遺漏分散關鍵 token 的風險，但 search hierarchy 可能造成準確率損失；實務部署應依 context 長度、並行 request 數與 accuracy 需求選擇 Flat 或 Tree，而非只依理論複雜度決定。

## 限制與未來工作

作者指出 LSA 仍需完整保存隨 context 線性成長的 KV cache，未解決儲存本身的問題。D-LSA Tree 在 GLM-5.3-FLASH 超過 1M tokens 後準確率下降；N-LSA 目前僅在約 0.5B 模型、最高 128k tokens、Flat search 上驗證。更大模型、更長 context、native Tree training，以及與 sparse training 結合仍待研究。
