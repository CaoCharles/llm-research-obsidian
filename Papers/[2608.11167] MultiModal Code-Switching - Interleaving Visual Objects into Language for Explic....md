# MultiModal Code-Switching: Interleaving Visual Objects into Language for Explicit Object-Level Alignment

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.11167)
- 📥 [PDF](https://arxiv.org/pdf/2608.11167v1)

## 摘要（中文翻譯）

現有 Multimodal Large Language Models（MLLMs）主要以 image-text pairs 進行模態對齊預訓練，將整體影像表示映射至長篇文字描述。然而，這種 image-level alignment 存在指涉歧義：當影像包含多個物件時，模型難以從全域表示推斷多個視覺物件與文字實體的對應關係，造成資料使用效率低及語意 grounding 不佳。為此，本文提出 MultiModal Code-Switching（MMCS）預訓練範式，提供明確的 object-level supervision。受語言 code-switching 現象啟發，MMCS 以對應的視覺物件取代文字中的實體，交錯排列 vision 與 language，強制進行局部 vision-language grounding。作者並建立可擴展的資料合成流程，產生含準確物件—實體對應的 773K 筆預訓練樣本。實驗顯示，僅使用 50K 筆 MMCS 樣本即可匹敵或超越使用 600K image-text pairs 訓練的模型，且在不同模型規模下持續提升 visual grounding 與 perception 能力。

## 問題背景

主流 MLLM alignment pretraining 以整張影像對應 dense caption，雖提供較多文字細節，卻把多個物件壓縮在 global visual representation 中。模型必須自行推斷每個文字實體對應哪個視覺區域，形成 referential ambiguity 與 many-to-many mapping，容易依賴統計共現而非真正 semantic grounding，因而資料效率、物件辨識、區域理解與 visual grounding 均受限制。

## 解決方案

作者提出 MultiModal Code-Switching（MMCS），把 vision 與 language 視為兩種可交錯的 code，將 caption 中可定位的文字實體替換成其對應的 visual object tokens。如此，物件後續的上下文生成及被替換實體的重建都直接依賴局部視覺特徵，對模型施加明確 object-entity correspondence 約束。方法不新增專用 grounding module 或 coordinate token，而是在 representation level 以兩項互補 loss 同時學習語意精確性與上下文整合，並透過自動 caption、entity extraction、grounding 與 segmentation 建立可擴展資料。

## 核心貢獻
1. 提出 MultiModal Code-Switching（MMCS），以視覺物件 token 取代文字實體，將模態對齊由隱式 image-level association 轉為明確 object-level correspondence。
2. 建立由詳細 caption、entity extraction、Grounding DINO 定位、篩選及 SAM-2.1 mask 處理組成的資料合成管線，產生 773K 筆帶物件—實體對應的預訓練樣本。
3. 在不同 LLM 規模、vision encoder、資料量與解析度設定下評估 MMCS，並以消融、representation alignment metrics 及 attention maps 分析其效益來源。

## 技術方法

模型採用 ViT-MLP-LLM 架構：預設 vision encoder 為具 tile-wise dynamic resolution 的 SigLIP2-SO-400M，projector 為含 2×2 pixel unshuffle 的兩層 MLP；LLM backbone 使用 Qwen2.5-3B-Instruct、Qwen3-8B 或 Llama3-8B-Instruct。資料合成時，先以 Qwen3-VL-32B-Instruct 產生詳細 image caption，再用 Qwen2.5-72B-Instruct 抽取 noun phrases 及辨識所需 attributes，接著以 Grounding DINO 取得文字實體的 bounding box 與 confidence，並以 box threshold 0.4、text threshold 0.3 篩選；移除小於單一 visual patch、超過影像 50%的框，最後用 SAM-2.1 產生 mask，剔除 mask area 小於 box area 20%的高度遮擋物件，形成 773K 樣本。對連續文字實體 e=[x_i,…,x_{i+m}]，MMCS 以其 bounding box 相交的 image tokens 所構成之 visual object tokens 取代 e，建立交錯序列。訓練包含僅對文字 token 計算的 language-modeling loss，以及根據 preceding context 與 visual object 重建原文字實體的 entity-reconstruction loss，兩者相加。預訓練後使用固定的 LLaVA-NeXT instruction SFT 資料，SFT 階段恢復 global image representation。評估涵蓋 visual grounding（RefCOCO、RefCOCO+、RefCOCOg）、visual perception（CVBench、OCRBench、TextVQA、V-Star 等）與 general VQA（MMBench、MME、MMStar、MMVet、GQA 等）；內部分析使用 CKA、CKNNA、Mutual k-NN 量測跨模態表示對齊，並比較 attention maps。

## 關鍵結果

主要結果如下；數值為論文報告的 benchmark 分數或平均分數，RefCOCO 系列為 Acc@0.5。

| 設定／方法 | General | Perception | Grounding |
|---|---:|---:|---:|
| Qwen2.5-3B，Caption | 51.19 | 55.77 | 59.12 |
| Qwen2.5-3B，MMCS | 51.84 | 58.24 | 70.29 |
| Qwen3-8B，Caption | 57.61 | 61.23 | 76.89 |
| Qwen3-8B，MMCS | 58.34 | 63.40 | 79.79 |
| Llama3-8B，Caption | 53.48 | 59.57 | 63.16 |
| Llama3-8B，MMCS | 54.01 | 61.15 | 72.91 |

在 Qwen2.5-3B、SigLIP2 設定下，MMCS 的 RefCOCO/+/g 平均 grounding 分數為 70.29，Caption baseline 為 59.12；論文概括其平均提升為 7.9%。Perception 類任務的平均提升為 2.1%，其中 CVBench 提升 4.0%、OCRBench 提升 2.8%、V-Star 提升 2.0%。資料效率實驗指出，50K MMCS 樣本超越 600K image-level baseline，但圖表未提供所有資料量與方法的完整數值。消融中，移除 L_entity 的 grounding/perception/general 平均為 67.55/54.23/51.45；移除 L_LM 為 65.44/56.26/51.37；完整 MMCS 為 70.29/58.24/51.84。

## 對我們的啟發
- [ ] 若多模態資料包含多個可辨識實體，將全域 caption 改造成局部物件—文字對應，可能比單純增加 image-text pair 數量更有效；論文中 50K MMCS 樣本超越 600K image-level 樣本的結果支持此資料效率方向。
- [ ] 實務上可將 entity reconstruction 與 contextual language modeling 分開設計：前者強化物件身分辨識，後者強化物件與上下文的整合；消融結果顯示兩者對 perception 與 grounding 的作用不同。
- [ ] 自動產生的 grounding 標註不必要求像素級完美才可能有效，但仍應進行 confidence、box area、mask area 與空間條件篩選；論文的 10% 與 30% 對應擾動實驗可作為噪聲測試參考。

## 限制與未來工作

目前主要聚焦自然影像中的 visual objects，尚未涵蓋 chart understanding、scene text recognition、複雜 relations 或 actions。資料依賴自動 captioning 與 grounding，可能繼承來源資料及模型偏差；物件類別覆蓋亦可能不均。作者未來將探索更廣泛領域、iterative self-improvement 與複雜關係／動作建模。
