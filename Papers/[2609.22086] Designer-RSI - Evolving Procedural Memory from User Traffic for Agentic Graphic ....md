# Designer-RSI: Evolving Procedural Memory from User Traffic for Agentic Graphic Design

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2609.22086)
- 📥 [PDF](https://arxiv.org/pdf/2609.22086v1)

## 摘要（中文翻譯）

專業 graphic design 是一項長時程 agentic task：結構化且可編輯的 artifacts 由許多相互依賴的操作逐步形成，但結果沒有可靠的 programmatic oracle。本文提出持續適應框架：由 frozen frontier model 透過 230 多項工具操作專業設計軟體，外部 procedural memory 則從經驗累積並改良可重用的 natural-language skills。記憶體一方面透過 widening，為反覆出現且尚未涵蓋的子任務新增程序；另一方面透過 deepening，根據既有程序的成功與失敗執行結果修訂技能，並使用 matched replay gate，只接受能修復失敗且不使既有成功退化的變更。五輪演化涵蓋 1,406 個真實 user briefs 與 1,869 條自動評分 trajectories，在不更新模型權重、也不使用人工標註的情況下，將技能庫由 76 個 documentation-derived skills 增至 139 個。Claude-Sonnet-4 在 GenEval2 的 execution success 由 72.7% 提升至 99.3%，generation quality 增加 11.99 個百分點；在四個專業設計 benchmark 上，對無技能 agent 的勝率亦達 61.8% 至 67.6%。結果顯示，procedural memory 能在回饋嘈雜且不可完全驗證的環境中支持 agent 的持續適應。

## 問題背景

專業 graphic design 涉及數十個相互依賴的工具操作，必須同時滿足具體要求、主觀構圖與可編輯性。終端結果難以進行長時程 credit assignment，且設計不像程式具有可靠的成功 oracle；自動評估器只能部分捕捉主觀品質。當 frontier model 為外部託管或不宜更新時，監督式學習需要昂貴示範，outcome-based optimization 又容易受 proxy reward 與 judge noise 影響。

## 解決方案

作者將持續學習的對象從 frozen model 權重轉移至外部 procedural memory，即可檢索、注入模型上下文的自然語言 SKILL.md playbooks。框架包含兩種互補機制：widening 從反覆出現、尚未覆蓋的子任務中蒸餾新技能，以擴大能力覆蓋；deepening 對反覆失敗的既有技能，對照相似成功與失敗執行進行針對性修訂，以提高可靠性。兩者都必須通過 matched replay gate：在固定上游情境下，以候選版本與 incumbent 或 no-skill baseline 進行配對重播，只有至少贏得一個 prompt 且沒有輸掉任何 prompt 的變更才會部署。

## 核心貢獻
1. 提出以外部 procedural memory 作為 frozen frontier model 周邊學習目標的 graphic-design agent 持續演化框架，並以 widening 與 deepening 分別處理能力覆蓋與程序可靠性。
2. 提出 matched replay gate，在固定上游情境、配對重播及隨機化 pairwise judging 下，僅部署修復失敗且不回歸既有成功的技能變更，以應對 noisy、不可驗證的設計回饋。
3. 透過五輪 user-traffic 演化、三個 frozen backbones、一般 T2I 與專業 graphic-design benchmarks，證明 widening 與 deepening 的組合優於單獨使用，且不需模型權重更新或人工 reward labels。

## 技術方法

系統由四個角色組成：Prompter 產生 design briefs，Solver 是使用 frozen frontier model、skill bank 與 230 多項設計工具的 agent，Grader 以 multimodal evaluation kit 為圖像及各項要求評分並說明未滿足原因，Reflector 將失敗轉為 SKILL.md 編輯。執行時先以技能檢索取得 top-k playbooks，並可過濾相關工具；模型接著反覆呼叫 raster、vector、layout、asset retrieval 與 verification 工具，建立可編輯 artifact。Widening 會從未被技能涵蓋的 trajectory 抽取並 canonicalize subtasks，依標籤累積；同一標籤達到 k_min=3 次後蒸餾候選技能，再與 no-skill agent 重播。Deepening 對 failure count 達 m=2、且 trajectory 分數低於 τ=0.6 的技能進行修訂，Reflector 同時查看失敗理由、目前技能及相似成功 calls、tool sequences 與 intermediate states；必要時可整體重寫、刪除或將不可修復案例回送 coverage pool。Replay gate 固定每個 prompt 的 asset retrieval 與 upstream state，對 candidate 與對照組執行多個 contexts，採 order-randomized pairwise judging；prompt 必須在多數 contexts 勝出，且整體不得出現 prompt-level regression。實驗使用 Claude-Opus-4.6、Claude-Sonnet-4 與 Qwen3.6-27B，五輪處理 1,406 個演化 briefs，並以固定且不重疊的 200 個 human-authored briefs 評估。另以 GenEval2、DPG-Bench、OneIG-EN/ZH 評估一般 T2I 品質與成功率，並以 OpenCOLE、GraphicBench、CreatiDesign、BannerRequest400 的 GPT-5.4 blind pairwise win rate 評估專業設計能力。

## 對我們的啟發
- [ ] 對長時程 agent，可將可持續更新的知識放在外部技能庫，而非每次重新訓練模型；技能應位於 atomic tool call 與完整 trajectory 之間，兼顧可重用性與執行彈性。
- [ ] 在自動評分不穩定時，應優先採用同一上游情境下的 paired replay、對照比較與 regression gate，而非只比較跨批次的絕對平均分數。
- [ ] 能力擴充與可靠性修補需要聯動：widening 發現新程序，deepening 則修正其誤用；部署時可透過失敗回流 coverage pool，形成覆蓋與穩定性的閉環。

## 限制與未來工作

論文指出，自然語言技能不一定能覆寫模型既有策略；細緻幾何操作仍受模型 perception 與自動驗證限制。長程序會在標註、蒸餾與執行階段累積 fidelity loss。Replay gate 只保證 replay cases 不回歸，不能保證整體 user distribution 單調改善。未來需結合 preference-aware retrieval、deterministic primitives、numeric 或 human-assisted verification、plan-level orchestration 與模型更新。
