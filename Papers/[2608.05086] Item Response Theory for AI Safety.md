# Item Response Theory for AI Safety

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.05086)
- 📥 [PDF](https://arxiv.org/pdf/2608.05086v1)

## 摘要（中文翻譯）

語言模型在安全行為上存在差異，而這些差異通常由 safety benchmarks 衡量。然而，彙總後的 benchmark 分數難以信任與解讀，因為不同 benchmark 可能重複、彼此高度相關，且模型在察覺評測時可能 sandbagging。為了解決這些問題，本文引入 Item Response Theory（IRT）：根據模型在各個 item 上的表現，推估 item 的 psychometric properties 與模型的潛在能力。作者在 192 個語言模型與八個安全 benchmark 上擬合 IRT 模型，完成截至本文所述最大規模的 LLM safety psychometric analysis。研究發現，拒答嚴格度、truthfulness 與 contextual harm 三個可解釋因素能說明模型間 77% 的變異；經 psychometric selection 的 item 比同規模隨機子集更準確地恢復完整 benchmark 分數，若採用 adaptive testing，部分 benchmark 約十個 item 即可將成本降低 97–99%；此外，IRT 也能透過 person-fit、ability shift 與 response fingerprint 審計模型，偵測 naive sandbagging 及 API 背後模型的變更。作者建議 frontier labs 與評測者採用 IRT 來理解、縮減與審計安全 benchmark。

## 問題背景

現有安全 benchmark 多以彙總分數呈現，但不同測試與 item 可能重複、相關性高，且分數方向可能互相衝突，導致單一平均分難以解釋模型真正具備的安全行為。完整測試成本高，許多 item 幾乎由所有模型通過或失敗，區辨力有限；此外，模型可能察覺評測而改變行為，API 也可能在相同識別名稱下更換模型或推理後端，使原始分數的可信度與可持續性受到質疑。

## 解決方案

作者提出以 Item Response Theory 作為安全評測的統一 measurement framework。IRT 從模型對 item 的 response 聯合估計模型 latent ability、item difficulty 與 discrimination，使不同 item 對能力估計的資訊量可被量化。研究先以 regularized 2PL 校準八個 benchmark，再以 factor analysis 與 MIRT 探索跨 benchmark 的 latent structure；接著依 Fisher information 設計 static tests 與 computerized adaptive testing，從少量高資訊 item 恢復完整分數與排名。最後將 IRT 的期望 response pattern 延伸至 person-fit、歷史 ability shift 和 response fingerprint，形成可檢查選擇性 sandbagging、整體行為漂移及 API model substitution 的 audit ladder。

## 核心貢獻
1. 以八個安全 benchmark、5,067 個經前處理 item 與最多 192 個語言模型建立 regularized 2PL IRT calibration，並分析模型能力、item difficulty 與 discrimination。
2. 透過 per-benchmark ability 的 factor analysis，提出拒答嚴格度、truthfulness 與 contextual harm 三個因素可解釋 77% 的模型間變異，並指出安全 benchmark 不能被單一 safety ability 充分概括。
3. 以 psychometric item selection 與 computerized adaptive testing（CAT）縮減評測；三個各含 25 個 item 的固定測試可估計三項 latent abilities，部分單一 benchmark 約十個 adaptive item 即能維持分數與排名恢復效果。

## 技術方法

作者將模型視為 test-taker、prompt/item 視為測驗題，將 benchmark 判定為正確的 response 記為 1。資料來自 OpenRouter API，在 zero temperature、maximum generation length 1,024 tokens 下，每個 model–item pair 收集一次回答；八個 benchmark 原有 5,255 items，移除無效 judge score、未回答與跨模型無變異 item 後保留 5,067 items。作者先對各 benchmark 分別擬合 regularized 2PL IRT：P(x_mj=1|θ_m,a_j,b_j)=σ(a_j(θ_m−b_j))，其中 θ 是模型 latent ability，b 是 item difficulty，a 是 discrimination；使用 marginal maximum likelihood，並對 discrimination 與 item intercept 加入 priors，以降低約 170 個模型下的估計不穩定。取得每個模型在八個 benchmark 的 ability 後，以 minimum-residual factor analysis、oblimin rotation、RMSEA、CFI 與 Horn parallel analysis 選擇因素數，另以 unconstrained MIRT 作 robustness check。縮減評測部分，依 Fisher information 選高資訊固定 item，或使用 CAT 根據目前 θ 選擇最 informative item、觀察 response 後更新 θ；以 20 次 75% calibration/25% held-out model splits 評估，透過 RMSE 衡量 full-benchmark score recovery，並以 Spearman ρ 衡量 ranking recovery，和相同預算的 random subsets 比較。審計部分使用 person-fit l_z、historical ability shift 與 response fingerprint，並以 prompted sandbagging、model-pair discrimination 及 16 個 endpoint 的重複收集驗證。

## 關鍵結果

| 分析 | 論文結果 |
|---|---|
| 潛在因素 | 三因素模型解釋 77% 變異；一因素 47%、二因素 69%；一因素 RMSEA=0.32，二因素 CFI=0.88，三因素 CFI=0.97。 |
| 固定短測試 | 三個各 25-item 測試的 RMSE：refusal strictness 0.047（random 0.062）、truthfulness 0.041（0.048）、contextual harm 0.065（0.067）；排名 Spearman ρ 分別為 0.94、0.83、0.89。 |
| CAT 單一 benchmark | 約十個 adaptive item 對 HarmBench、SORRY-Bench、OR-Bench-Hard 的分數誤差比隨機十題低 18–34%，排名恢復 ρ=0.92–0.94，評測成本降低 97–99%。 |
| 全 suite composite | CAT 在 25 items 時的 score error 比 random subset 低 22%；排名 ρ=0.92，而 random sampling 約需 75–100 items 才達相近程度。 |
| Person-fit | 在設定 10% false-positive rate 下，targeted 與 triggered prompted sandbagging 的 pooled detection rate 分別為 90% 與 97%；uniform sandbagging 為 35%。 |
| Ability shift | 40-item historical ability check 偵測 84% uniform sandbagging；與 person-fit 結合後，各 scope 的 sandbagging detection 為 94–97%。 |
| API identity audit | 40-item ability test 可區分 8,911 個 model pairs 中的 99.5%；response fingerprint 在 16 個 endpoint 中辨識 13/14 個 distinct model identities。 |
| TruthfulQA 壓縮 | TruthfulQA 單獨在 50 items 時的排名恢復為 ρ=0.71；論文未報告可將其穩定壓縮至約十題的同等效果。 |

## 對我們的啟發
- [ ] 實務上不宜直接平均高度相關或方向相反的安全 benchmark；應先檢查 latent structure、相關性與分數方向，並分別報告拒答嚴格度、truthfulness 與 contextual harm。
- [ ] 若已完成校準並在新模型 cohort 上驗證，評測流程可優先使用高 discrimination 的固定測試或 CAT，以降低推理成本；但縮減測試只能重現原 benchmark，不能證明其具備部署安全性的 predictive validity。
- [ ] API 審計可採分層方式：用 person-fit 偵測選擇性 sandbagging、用歷史 ability 偵測整體行為漂移，再用 response fingerprint 辨識 ability 相近但 item-level 行為不同的 endpoint；各方法都需要相應的校準與參考資料。

## 限制與未來工作

跨 benchmark latent-structure 分析最多只有 134 個完整模型，仍小於傳統 human psychometric datasets；三因素名稱主要依據 loading pattern，尚未完成 construct validity 與 predictive validity 驗證。sandbagging 實驗使用 prompted model organisms，而非 fine-tuned 或更具對抗性的模型；作者也未證明方法能抵抗專門規避審計的模型。
