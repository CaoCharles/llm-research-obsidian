# Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.18397)
- 📥 [PDF](https://arxiv.org/pdf/2611.18397v1)

## 摘要（中文翻譯）

本文提出 Gamer，一個面向複雜互動環境長視域任務的通用 agent framework。其 end-to-end 架構整合 perception、memory management 與 multi-step reasoning，透過共同的訓練與部署流程，同時支援傳統 2D 圖形介面及複雜 3D simulated worlds。作者首先以數萬小時的 device-level keyboard and mouse interaction trajectory 進行 continued pre-training，使模型學習虛擬與具身環境中的動態。接著以 sparse-thinking instruction tuning 減少冗餘計算，並保留複雜決策所需的 reasoning。針對長視域互動，作者提出穩定的 multi-turn reinforcement learning 方法，處理有限 context window、rollout error 累積及 sparse reward。其 cloud-edge inference engine 可並行服務多個遊戲環境、支援 unbounded-context execution，並維持低線上延遲。Gamer 在多個 3D open-world games 展現接近熟練玩家的泛化與操作效率，也在多項 2D game benchmarks 取得具競爭力的結果。

## 問題背景

現有 game agents 常依賴 privileged internal states、專用 API 或 tailored action spaces，難以跨遊戲泛化，也不符合人類透過螢幕與標準鍵鼠操作的情境。複雜 3D 遊戲還具有 partial observability、延遲回饋、資源管理及長達數小時的多階段任務；若 inference latency 過高，環境會在動作送達前改變，進而造成控制錯誤與 rollout 品質下降。論文旨在建立能以 raw pixels 和 native keyboard-mouse controls 執行長視域、即時且跨 2D/3D 遊戲互動的通用模型。

## 解決方案

Gamer 使用單一 vision-language-action policy，以 screen observation、game control specification、task instruction、short-term history 與 long-term memory 為輸入，輸出可直接執行的鍵盤滑鼠動作。核心流程包含三階段：以跨遊戲 trajectory 進行 continued pre-training，透過 random key remapping 與 repeat-aware loss decay 學習可轉移控制；以多層級、LLM-assisted 標註資料進行 sparse-thinking instruction tuning，學習在關鍵決策時 reasoning 並以 summary 跨 context 保存任務狀態；最後以 Temporal-Aware GRPO 在環境回饋下優化長視域策略。配套的 Streaming-vLLM 則透過 KV-cache reuse、memory compaction、FSM-guided speculative decoding 與 streaming action dispatch 支援低延遲並行互動。

## 核心貢獻
1. 提出以 raw screen pixels 為觀測、以標準 keyboard-mouse events 為統一 action space 的通用 game-agent framework，支援跨多種 2D 與 3D 遊戲的非侵入式互動。
2. 建立從數萬小時 gameplay trajectory 到約 1K 小時多層級 instruction data 的資料管線，加入 sparse reasoning、task segmentation 與 persistent memory supervision。
3. 提出 TA-GRPO 與 memory-linked rollout，將長視域互動切為具記憶連結的 segments，利用 environment-verifiable feedback 與 temporal credit assignment 進行 online policy optimization。

## 技術方法

模型以 Qwen3-VL 或 Qwen3.5 為基礎，採用共同的自回歸輸出格式。觀測每 200ms 取樣一次，即 5Hz；每個觀測間隔拆成六個約 33ms 的 keyboard-mouse action blocks，形成約 30Hz 的低階控制。動作包含累積滑鼠位移及六組按鍵／滑鼠按鈕狀態，並將各遊戲的實體輸入透過 control specification B 對映至邏輯功能。CPT 使用約 2.4K 小時的主要資料設定（論文另描述原始資料為數萬小時），以 random key remapping 降低對按鍵身份的捷徑依賴，並以 γ=0.9 對連續重複動作衰減 loss。SFT 使用約 1K 小時 annotated pool，將資料標成 local operation、intermediate subgoal 與 complete task，並在關鍵步驟加入 current reasoning 或 memory summary；short-term history 為 20 turns，long-term memory budget 為 512 tokens。RL 採 TA-GRPO，把長 rollout 切成最多 20 turns 的 memory-linked segments，以 environment-verifiable binary reward 計分，群組內計算 relative advantage，再以 β=0.9 的 temporal weighting 分配至各步驟。部署與 rollout 使用 32 個平行 Windows VMs、64 張 H200，並以 Streaming-vLLM 保持快取與並行服務。評估區分 time-paused 與 real-time，涵蓋 3D commercial game navigation／puzzle 任務及傳統 2D game benchmarks；論文提供成功率、完成時間、延遲與吞吐相關結果，但不同實驗的完整 baseline 數值並未全部在所提供文字中列出。

## 對我們的啟發
- [ ] 若不同遊戲共享可解釋的 device-level interface，random key remapping 與動作持續時間的 loss reweighting 可減少按鍵頻率及重複控制造成的學習偏差。
- [ ] 長視域 agent 不必在每一步都產生長 reasoning；將 reasoning 限定於路線修正、目標切換及記憶更新等關鍵決策，有助於兼顧計算成本與任務持續性。
- [ ] 評估即時 agent 時應分開 time-paused 與 real-time 條件，並讓訓練 rollout 使用接近部署的 serving path，否則 inference latency 造成的狀態偏移可能掩蓋或扭曲策略能力。

## 限制與未來工作

論文未完整提供所有 3D 與 2D benchmark 的逐項分數、baseline 對照及統一 latency 表格，因此部分整體宣稱難以由所提供文字獨立量化。TA-GRPO 的 segment grouping 不要求相同中間狀態，且 reward 主要依賴環境 verifier；其對更遙遠未見遊戲、真實世界及非遊戲長任務的有效性仍未被本文充分驗證。
