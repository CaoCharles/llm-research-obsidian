# PlanSightRAG: A Visual-First Multimodal RAG for Automating Question Answering and Compliance Checking for Civil Standard Plans

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.26091)
- 📥 [PDF](https://arxiv.org/pdf/2608.26091v1)

## 摘要（中文翻譯）

民用基礎設施的合規檢查長期依賴工程師人工閱讀傳統 2D 圖紙；然而，以 OCR 為核心的自動化會移除解讀圖紙所需的幾何與版面資訊。本文提出 Visual-First Multimodal Retrieval-Augmented Generation（RAG）框架 PlanSightRAG，直接對圖紙影像建立索引並進行推理，整合 ColNomic-3B multi-vector retrieval、Agentic Planner–Retriever–Auditor–Synthesizer，以及作為證據軌跡的 MaxSim heatmap。作者建立涵蓋五個州 Department of Transportation（DOT）、1,898 頁圖紙的 4,056 對 benchmark。ColNomic-3B 在 zero-shot retrieval 達到 91.47% Recall@5，於保留的 Michigan DOT corpus 達 91.40%。在合成、參數化生成的合規圖紙上，Qwen2.5-VL-72B 只有在提供預先解決的規則 threshold 時達到 100% verdict accuracy；此外，系統展示了從 specification corpus 直接擷取數值限制、無需人工提供規則的 visual rule-grounding。

## 問題背景

論文處理 civil standard plans 的問答與合規檢查問題。傳統工程師人工檢查耗時、昂貴，且多頁圖紙中的幾何關係、版面配置、符號與跨視圖參照難以擴展。OCR-based RAG 將圖紙線性化為文字 token，會破壞空間與幾何語義；一般 VLM 又缺乏大規模檢索、可靠證據定位及跨圖紙合規推理能力。

## 解決方案

作者提出 PlanSightRAG，一個 visual-first multimodal RAG 框架，直接將標準圖紙頁面或高解析度 tiles 編碼為 multi-vector patch embeddings，透過 ColNomic-3B 與 late-interaction MaxSim 保留局部版面及空間資訊。系統以 Planner–Retriever–Auditor–Synthesizer 分工處理複雜合規查詢：Planner 拆解驗證步驟，Retriever 為各步驟找標準圖紙，Auditor 進行視覺檢查，Synthesizer 彙整結論。MaxSim heatmaps 與區域證據提供可追溯的視覺 grounding；系統亦示範從規格文件自行擷取數值門檻，再進行 rule-grounded auditing。

## 核心貢獻
1. 建立涵蓋五個州 DOT、1,898 頁與 4,056 對問答的 visual benchmark，並另以 93 對 Michigan DOT 查驗跨機構 zero-shot transfer。
2. 提出以 ColNomic-3B multi-vector late-interaction retrieval 為核心的 visual-first RAG，結合 MaxSim heatmap 與區域證據，避免 OCR 線性化造成的幾何與版面資訊遺失。
3. 提出 Planner–Retriever–Auditor–Synthesizer agentic compliance pipeline，並展示無人工提供規則時，從 specification corpus 擷取數值限制並進行 visual rule-grounding。

## 技術方法

資料處理上，作者將五個州 DOT 的標準圖紙去除近似修訂版本後，得到 1,898 頁；主要索引以 200 DPI rasterization 建立。另以 400 DPI 將頁面切成 1024×1024、256 像素重疊的 tiles，作為解析度 ablation。每頁或 tile 由 ColNomic-3B 產生 dynamic-resolution、32×32 patch grid 的 multi-vector embeddings，並保存 plan ID、頁碼、標題、類別及 tile bounding box 等 metadata。查詢編碼為 token vectors，使用 ColBERT-style MaxSim：每個 query token 與頁面 patch 取最大內積後加總排序；可選擇 VLM cross-encoder re-ranking 與 BM25 metadata fusion。前五頁影像交由 Qwen2.5-VL-7B、Qwen2.5-VL-72B 或 InternVL-2.5-8B 回答。合規任務則由 Qwen2.5-VL-72B 執行單次或 agentic auditing，輸出 pass、fail、unclear 等結構化結果。評估包括 Recall@5 與由 Qwen2.5-VL-72B 擔任 judge 的 Judge Accuracy，另使用合成參數化圖紙測試合規 verdict，以及以 Recall@5、TPR、FNR、TNR、precision、F1 和 Cohen’s kappa 評估違規偵測。

## 關鍵結果

| 評估項目 | 方法／資料集 | 結果 |
|---|---|---:|
| 五-DOT page-disjoint retrieval | ColNomic-3B，424 對測試集 | Recall@5 **92.69%** |
| 五-DOT benchmark headline retrieval | ColNomic-3B，4,056 對 | Recall@5 **91.47%** |
| Michigan DOT zero-shot transfer | ColNomic-3B，93 對、298 頁 | Recall@5 **91.40%** |
| OCR 文字基線 | BGE-M3 + OCR，424 對測試集 | Recall@5 **36.79%** |
| OCR+BM25 案例基線 | WYDOT 查詢案例 | Recall@5 **58.02%** |
| VisionRAG Pyramid 案例基線 | WYDOT 查詢案例 | Recall@5 **45.99%** |
| ColPali zero-shot | 五-DOT page-disjoint 測試集 | Recall@5 **76.89%** |
| 人工整理 WYDOT anchor set | 78 對 | Recall@5 **91.03%**；Judge Accuracy **80.77%** |
| 合成 compliance drawings | Qwen2.5-VL-72B，預先提供 rule threshold | Verdict Accuracy **100%** |
| 合成 compliance drawings | non-VLM OCR baseline | Verdict Accuracy **76.4%** |
| 規則 corpus retrieval | 1,913 個候選項 | Recall@5 **100%** |
| all-PASS 合規測試 | 8 個查詢 | Accuracy **100%**；僅反映避免誤判為不合規 |
| 合成 FAIL sensitivity | 24 個 FAIL 查詢 | TPR **79.17%**；FNR **20.83%** |
| FAIL：dimension mutation | 8 個查詢 | TPR **87.5%** |
| FAIL：note omission | 8 個查詢 | TPR **87.5%** |
| FAIL：symbol/component swap | 8 個查詢 | TPR **62.5%** |
| 部署延遲 | 1,898 頁、單張 80GB GPU | Retrieval p50 約 **0.10 秒**；agentic audit 平均 **60.9 秒／query** |

作者明確指出，MaxSim heatmap 的真正 grounding IoU 尚未被有效評估：16-query pilot 的 ground-truth box 曾以 predicted boxes 初始化，因此不能視為有效的 IoU 結果。

## 對我們的啟發
- [ ] 對工程圖紙 RAG，檢索表徵本身應保留 patch-level 空間資訊；僅增加 OCR 或文字 reranking 未必能恢復幾何關係。
- [ ] Recall@5 很高不代表端到端問答可靠；人工 WYDOT 集合的 retrieval 為 91.03%，但 Judge Accuracy 僅 80.77%，顯示圖紙中的數值—元件綁定與跨視圖推理仍是瓶頸。
- [ ] 合規系統應分開評估通過判定與違規偵測；本文 all-PASS 測試達 100%，但 FAIL sensitivity 僅 79.17%，尤其 symbol/component swap 僅 62.5%，因此部署時需要明確的反例與 abstention 評估。

## 限制與未來工作

合規主結果部分依賴預先提供的規則 threshold；all-PASS 測試不能衡量違規敏感度。FAIL sensitivity 僅以 24 個合成查詢測試，且符號替換容易漏判。MaxSim grounding 的有效 IoU 尚未完成：16-query pilot 的 ground-truth boxes 曾由預測框初始化。Agentic audit 平均 60.9 秒，成本與延遲仍高；作者將違規圖紙大型語料與更可靠的人工 grounding 標註列為後續工作。
