# Yalda-Embedding: Open Development of a Competitive Persian Retrieval Model

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2610.32933)
- 📥 [PDF](https://arxiv.org/pdf/2610.32933v1)

## 摘要（中文翻譯）

儘管 multilingual text representation 持續進步，Persian 的有效 dense retrieval 仍受限於語言專屬訓練資源不足，以及 compact embedding model 選擇有限。本文提出 YALDA-EMBEDDING，一個由 Qwen3-Embedding-0.6B 調適而來、擁有 595.8M 參數的 Persian retrieval model，使用超過一百萬組 query-document pairs 訓練。在 FaMTEB 的八項 Persian retrieval tasks 上，模型取得受評 0.6B 模型最高的 macro-average，分數為 0.5488，且每項任務皆優於 Qwen3-Embedding-0.6B 與 F2LLM-v2-0.6B。相較 Qwen3-Embedding-4B，模型在四項任務勝出、一項持平，macro-average 僅低 0.0075。增量 ablation 分析 contrastive batch size、optimization stabilization，以及來自 F2LLM-v2-8B 的 relational knowledge distillation。最終蒸餾設定將平均分數由 0.4813 提升至 0.5488，且不增加 inference-time model size。作者同時釋出模型權重、訓練與評估程式、pairwise dataset 及 teacher-embedded dataset，支援獨立檢驗與後續重用。

## 問題背景

Persian 在 dense retrieval 的模型與高品質語言專屬訓練資源相對有限，使 multilingual embedding model 未必能充分處理 Persian 的檢索需求。現有 compact 模型在 Persian retrieval 上仍有提升空間，而直接依賴較大型模型會增加推論成本。論文因此探討如何在固定約 0.6B student architecture 下，透過 Persian pairwise data、較大 contrastive batch 與 knowledge distillation，提升多領域檢索表現。

## 解決方案

作者提出 YALDA-EMBEDDING，從 Qwen3-Embedding-0.6B 初始化，使用 1,035,981 組 Persian query-positive-document pairs 進行單 epoch fine-tuning。訓練先以 in-batch negatives 的 InfoNCE 建立 Persian retrieval 表徵，再加入 global batch size 擴大、gradient clipping、learning-rate warmup 與 cosine decay。核心創新是使用 F2LLM-v2-8B 的 offline teacher embeddings，透過 batch 內 query-to-document ranking distributions 執行 relational knowledge distillation，而非直接回歸 teacher 向量。最終以 0.25 InfoNCE 與 0.75 KD loss 組合，在不增加部署模型大小的情況下轉移大型 teacher 的排序知識。

## 核心貢獻
1. 提出 595.8M 參數的 Persian dense retrieval model，在八項 FaMTEB 任務的受評 0.6B 模型中取得最高 macro-average 0.5488，並在每項任務優於 Qwen3-Embedding-0.6B 與 F2LLM-v2-0.6B。
2. 整理並公開 1,035,981 組來自 13 個資源的 Persian query-document pairs，同時提供原始資料與預先計算的 F2LLM-v2-8B teacher representations。
3. 以增量 ablation 展示 batch size、optimization stabilization 與 relational knowledge distillation 的效果；KD 將非蒸餾設定的平均 0.4813 提升至 0.5488，且不增加 inference-time model size。

## 技術方法

模型為 595,776,512 參數的 Qwen3-Embedding-0.6B 架構，包含 28 個 Transformer blocks、151,669 詞彙、1,024 hidden/embedding size、16 個 query heads、8 個 key/value heads、RoPE、causal attention，採最後一個非 padding token pooling，訓練最大長度為 512 tokens。Query 使用固定 instruction「Given a web search query, retrieve relevant passages that answer the query」，document 不加 instruction。資料來自 13 個 Persian retrieval resources，共 1,035,981 組 pair；合併後全球 shuffle，未重採樣，訓練只使用各來源 training split。InfoNCE 將 query 與 positive document 編碼並 L2 normalize，以 cosine similarity 除以 student temperature 0.05，batch 內其餘 511 個 documents 作 negatives，僅使用 query-to-document 方向。Teacher 使用 F2LLM-v2-8B 的 4,096 維 Matryoshka embedding 前 1,024 維並重新 normalize，teacher temperature 為 0.07；以 batch 內 soft ranking distributions 計算 forward KL divergence。最終 loss 為 0.25 InfoNCE 加 0.75 KD，global batch size 512、AdamW、peak learning rate 2×10^-5、10% warmup、cosine decay、gradient clipping 1.0，使用八個 TPU v5e。評估採 FaMTEB 八項 test-split retrieval tasks，以 MTEB 回傳分數及八項 unweighted macro-average 衡量。

## 對我們的啟發
- [ ] 若部署場景重視固定推論成本，可採用大型 teacher 的 offline relational distillation，將其 batch 內排序分布轉移到較小 student，而不需在 inference 時載入 teacher。
- [ ] 對 dense retrieval fine-tuning 而言，global batch size 從 64 增至 512 是本文增量實驗中最大的單項平均增益，顯示更多 in-batch negatives 可能是有效且簡單的優化方向。
- [ ] 即使訓練未明確提供或挖掘 hard negatives，in-batch negatives 加上 relational distillation 仍在三項 hard-negative evaluation tasks 上取得具競爭力結果；但實務採用時應依論文所示資料與評估設定重新驗證。

## 限制與未來工作

論文未報告統計顯著性，也未分離 gradient clipping、warmup 與 cosine decay 各自的效果。評估僅涵蓋 FaMTEB 八項任務，且比較依可用精度與各模型原有 prompting/pooling 設定進行。最終訓練固定為單一 epoch，資料 permutation seed 未固定；論文亦未提供跨 seed 變異、更多語言或實際 RAG 端到端效果。
