# Can Agentic Systems Close the Gap in Radiology with Production AI Tools?

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.09836)
- 📥 [PDF](https://arxiv.org/pdf/2611.09836v1)

## 摘要（中文翻譯）

Radiology AI 沿兩條路線發展：專門模型在狹窄任務上表現良好，但涵蓋的臨床發現有限；通用模型能處理較廣泛任務，卻容易產生 hallucination 與不準確的測量結果。透過 agentic system 結合兩者，可望生成較完整的放射科報告，但既有系統通常僅適用於單一 modality 或身體部位。本文提出一個 radiology agentic framework，標準化 orchestrator 呼叫模組化工具以產生結構化報告，並以 FDA-cleared radiology AI devices 的工具評估其能力。作者在大型多 modality 報告語料上模擬報告生成，分別比較受限於已核准工具目錄與 unlimited catalog 的情況，並比較依 clinical indication 或 target report 規劃。工具輸出由 reference report 模擬，以隔離工具可用性與 orchestration 的影響。結果顯示，工具覆蓋率與有效 orchestration 是完整 AI 輔助放射科報告的互補限制。

## 問題背景

放射科報告涵蓋多個器官、病灶、測量、比較與臨床判讀，並非單一檢測任務。現有 specialized models 雖在特定 finding 上準確，卻難以涵蓋完整報告；generalist vision-language models 則可能遺漏 findings、產生 hallucination、測量不準或陷入 template collapse。既有 agentic systems 又多侷限於單一 modality 或 anatomy，因此本文要量化：現有 FDA-cleared 工具經由 agent orchestration 能恢復多少 clinically actionable findings，以及不足來自工具目錄覆蓋還是 orchestrator 執行。

## 解決方案

作者提出仿照 Model Context Protocol 的跨工具 radiology agentic framework，透過共同介面統一 resources、tools 與 orchestrator。框架包含 patient context、prior studies、templates、guidelines、工具目錄及研究影像等 resources，並提供 viewer interaction、multi-series operations、AI vision、quantification、dynamic analysis、longitudinal comparison 與 clinical intelligence 七類工具。orchestrator 採 ReAct 式規劃與行動流程，由 Planner 產生分析步驟，Grouper 將獨立步驟分軌並行，ReAct loops 呼叫工具，Analyzer 整合與必要時重新規劃，Reporter 依模板撰寫報告，Reviewer 檢查並重寫。核心創新是以相同 orchestrator 比較 FDA-cleared catalog 與 tool-infinite catalog，並將遺漏歸因為 catalog gap 或 orchestration gap。

## 核心貢獻
1. 提出一個跨 modality、跨 anatomy 的 radiology agentic framework，以共同工具介面、ReAct loops、平行分軌、分析整合、報告生成與審查流程組合模組化 AI tools。
2. 建立由 1,164 個 FDA-cleared radiology AI devices 整理而成的 1,989-class catalog，並在工具輸出由 reference report 完美模擬的條件下，分離評估 tool availability 與 orchestration。
3. 以 finding-level RadMatch 與遺漏原因歸因量化 catalog gap 和 orchestration gap，並在 held-out reports 上顯示加入 99 個 recurring missing tools 可閉合約 74% 的 Cleared-to-Tool-Infinite recall gap。

## 技術方法

研究使用 PARROT fictional radiology report corpus；原始資料有 2,658 份報告，涵蓋 CT、MRI、radiography 與 ultrasound，以及 chest、abdomen、head、pelvis；篩選含 clinical indication 且四種模式皆產生可解析輸出的報告後，留下 1,059 份。作者從 FDA radiology AI device 清單建立 cleared catalog，涵蓋截至 2026 年 3 月的 1,164 個 devices。經兩階段 LLM 擷取與 consolidation 後，得到 1,989 個 finding classes，並依 modality 過濾可用性。實驗交叉比較兩種 catalog：Cleared 與可要求任意 plausible tool/class 的 Tool-Infinite；以及兩種 Planner 資訊：僅 clinical indication 的 realistic setting，或讀取 target report 的 oracle setting。所有工具輸出均由 reference report 模擬，因此不評估真實工具錯誤。框架依序執行 Context Loader、Planner、Grouper、平行 ReAct loops、Analyzer、Reporter 與 Reviewer。報告以 RadMatch 評估：LLM 將報告拆為 atomic findings，進行 finding-level matching，並將 critical、urgent、notable findings 的恢復比例定義為 actionable recall；held-out 實驗另報 actionable precision。作者也以 LLM 對遺漏 finding 進行五類原因歸因，從 659 份 derivation reports 挖掘 recurring missing tools，於 400 份測試資料中的 100 份 held-out reports 加入工具，並比較不同 orchestrator model 的影響。

## 關鍵結果

主要結果如下（RadMatch score 為 actionable recall）：

| 實驗條件 | 資料/設定 | Actionable recall |
|---|---:|---:|
| Cleared + Clinical Indication | 1,059 reports | 0.290 |
| Tool-Infinite + Clinical Indication | 1,059 reports | 0.437 |
| Cleared + Report oracle | 1,059 reports | 0.426 |
| Tool-Infinite + Report oracle | 1,059 reports | 0.740 |

在 9,675 個遺漏或錯誤 findings 中，61.8% 屬於 study modality 沒有對應 cleared class 的 catalog gap；18.3% 是 class 已提供但未被呼叫，13.6% 是 class-free tool 存在但未被呼叫，6.1% 需要新的工具類型，0.2% 無法由 imaging tool 找出。於 100 份 held-out reports 上，Cleared catalog 的 recall 為 0.347、precision 為 0.386；加入至少在 10、5、2 份 derivation reports 出現的 missing tools 後，recall 分別為 0.434、0.519、0.534，對 Cleared 至 Tool-Infinite 差距的閉合比例分別為 37%、74%、80%；Tool-Infinite recall 為 0.580、precision 為 0.501。使用 Tool-Infinite catalog 時，gpt-5.6-luna 的 recall 為 0.580，gpt-5.4-nano 為 0.355，Qwen3.5 9B 為 0.356；Qwen 有 100 份中 10 份未產生報告。

## 對我們的啟發
- [ ] 實務部署不應只增加模型能力，也應先盤點各 modality 的 finding coverage；研究顯示常見但未被工具涵蓋的 findings，可能比大量罕見工具更值得優先補足。
- [ ] 工具可用不等於工具會被使用；約三成遺漏是已有工具卻未被 orchestrator 呼叫，因此應設計系統化 coverage checklist、強制性 survey steps 或工具呼叫審計。
- [ ] 工具目錄擴充與 orchestrator 能力必須同步提升；較小的 orchestrator 即使擁有 unlimited catalog，表現也約等同較強模型使用 cleared catalog，顯示工具投資的效益取決於有效規劃與執行。

## 限制與未來工作

資料來自 fictional PARROT reports，且評估是 text-only；工具輸出由 reference report 模擬，排除了漏檢、誤報與工具間衝突。held-out 實驗僅 100 份，無法穩健排序工具擴充門檻。FDA catalog 由 LLM 擷取與合併，且為單一時間快照；主要結果也依賴單一 orchestrator。未來需以真實影像、真實工具錯誤、臨床報告與 prospective evaluation 驗證。
