# Test-Time Self-Evolving GUI Visual Grounding via Reflection-Guided On-Policy Self-Distillation

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.11191)
- 📥 [PDF](https://arxiv.org/pdf/2608.11191v1)

## 摘要（中文翻譯）

GUI Visual Grounding 是 GUI agent 的基礎能力，但現有模型部署後通常凍結參數，難以適應未見過的介面。近期的 test-time reinforcement learning 雖能進行適應，卻無法反思失敗探索。本文提出 Test-Time Self-Evolving framework，在無人工標註 ground truth 的情況下，透過 Exploration、Evaluation、Reflection 與 Internalization 建立閉環。代理先根據指令預測 grounding 座標，再由基於 MLLM 的 Reflector 評估結果並產生 reasoning reflection。作者提出 Reflection-Guided On-Policy Self-Distillation（R-OPSD），利用 conditioned self-teacher 將高階推理轉換為密集的 token-level supervision，並以 Contrastive Calibration 避免失敗探索中的錯誤 autoregressive prefix 污染監督訊號。在六個 benchmark 上，方法相對 base model 平均提升 7.4% accuracy；相較 GUI-RCPO，平均最高提升 7.7%。作者稱這是首個將 on-policy self-distillation 用於 GUI visual grounding test-time adaptation 的工作。

## 問題背景

GUI visual grounding 模型部署後通常凍結參數，因此面對未見應用程式、平台或介面布局時，無法從互動經驗改善。既有 test-time reinforcement learning 多依賴成功/失敗的 sparse scalar reward，雖能指出結果，卻不能解釋座標為何錯誤，也難以在一組探索全部失敗時提供有效更新。本文要解決的是：在沒有人工 ground-truth 的部署環境中，如何評估探索、反思失敗原因，並將反思安全地內化到 grounding model。

## 解決方案

作者提出 Test-Time Self-Evolving framework，將部署後適應組織成 Exploration、Evaluation、Reflection、Internalization 的閉環。Grounding model 先自行探索並產生座標；MLLM-based Reflector 再根據 screenshot、instruction 與預測座標判斷成功與否，並輸出診斷性文字 reflection。核心方法 R-OPSD 將 Reflector 的高階反思作為 privileged information，透過 conditioned self-teacher 對模型自身 rollout 產生 dense token-level supervision。針對失敗 rollout 的 autoregressive prefix 污染問題，作者加入 Contrastive Calibration，以 inverse-prompted student 壓制初始錯誤並使後續不可靠訊號衰減，另以 advantage clamping 與 query-level GRPO advantage 穩定整體更新。

## 核心貢獻
1. 提出包含 Exploration、Evaluation、Reflection、Internalization 的 Test-Time Self-Evolving GUI grounding 閉環，使模型能在部署後、無人工 ground truth 下更新參數。
2. 提出 Reflection-Guided On-Policy Self-Distillation，透過以評估結果與文字 reflection 為 privileged information 的 conditioned self-teacher，將高階診斷轉換為 coordinate token 的 dense supervision。
3. 提出 Contrastive Calibration、direction-based advantage clamping，以及 query-level advantage 整合機制，以抑制錯誤 autoregressive prefix 造成的 corrupted supervision，並透過多 benchmark 實驗與 ablation 驗證各元件。

## 技術方法

輸入為 screenshot I 與語言指令 L，grounding model πG 自己抽樣產生座標或 bounding box B，形成 on-policy exploration。由於沒有 ground truth，凍結的 MLLM-based Reflector πR 接收 I、L、B，輸出二元成功判定 S 與包含 intent analysis、coordinate grounding、verification、conclusion 的文字 reflection R。Reflector 先以 GroundCUA 約 10,160 個 prediction-label pairs 透過 GRPO 訓練，資料由每個樣本八個座標預測中保留同時含正負結果的群組，再各取一正一負；部署適應時則不使用目標資料的 ground-truth。內化階段採 R-OPSD：以 πG 在原始提示下的 token 機率，與加入 S、R 的 reflection-guided teacher 機率之 log-ratio 作為 token-level advantage。成功樣本使用成功提示；失敗樣本加入錯誤預測與 reflection。為處理錯誤 prefix，Contrastive Calibration 另以「先前正確預測」的 inverse-prompted student 作對比，使初始錯誤 token 受到負 advantage，而後續漂移 token 的 advantage 趨近零。Direction-based clamping 使成功樣本只保留非負更新、失敗樣本只保留非正更新，並可與 group-based GRPO query-level advantage 以 λ=0.2 整合。模型以共享 base model、切換 LoRA adapter 的方式扮演 πG 與 πR。評估採 Element Accuracy：預測點落在目標 UI 元素 bounding box 內即算正確；測試涵蓋 ScreenSpot、ScreenSpot-v2、ScreenSpot-Pro、MMBench-GUI、OSWorld-G 與 OSWorld-G-Refine。

作者摘要所述的跨六個 benchmark 相對 base model 平均提升為 7.4%；相較 GUI-RCPO，平均性能最高提升 7.7%。在 Qwen2.5-VL-3B、MMG adaptation 的 ablation 中，完整方法達 68.2%，base model 為 57.5%。R-OPSD with CC 的訓練時間為 151 分鐘，標準 GRPO baseline 為 449 分鐘；加入 CC 與 query-level advantage 的完整框架為 778 分鐘。

## 對我們的啟發
- [ ] 若 test-time adaptation 只能取得成功或失敗的 sparse reward，加入描述錯誤原因的 reflection 可能提供更具方向性的更新訊號；實務部署時可將評估器輸出與模型更新流程分離。
- [ ] 對 autoregressive 座標生成而言，失敗軌跡不應直接對所有後續 token 施加同等更新；Contrastive Calibration 所採取的「強化初始錯誤修正、讓漂移後訊號衰減」是一種可參考的穩定化設計。
- [ ] Reflector 的可靠性是整體閉環的關鍵。論文中的 trained Reflector 在測試集 accuracy 為 89.5%（Qwen2.5-VL-3B）與 91.7%（Qwen3-VL-2B），因此實際應用仍應監控自動評估錯誤及其可能造成的負遷移。

## 限制與未來工作

論文顯示框架高度依賴 MLLM-based Reflector；其在 held-out 測試集仍非完美，accuracy 為 89.5% 或 91.7%，錯誤評估可能導致錯誤內化。實驗主要使用 Qwen2.5-VL/Qwen3-VL 與所列 GUI benchmark，未報告更長期、多輪真實互動中的累積漂移、跨域失敗案例或不同 Reflector 的系統性比較。
