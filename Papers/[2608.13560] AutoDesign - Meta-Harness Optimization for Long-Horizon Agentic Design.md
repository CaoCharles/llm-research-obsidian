# AutoDesign: Meta-Harness Optimization for Long-Horizon Agentic Design

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2608.13560)
- 📥 [PDF](https://arxiv.org/pdf/2608.13560v1)

## 摘要（中文翻譯）

將多模態來源轉換為濃縮且結構化的媒體輸出，可視為以 model harness 為核心的長視域 agentic process。理想的 harness 應符合人類設計先驗，並透過經驗探索累積可重用知識，以遞迴自我改進；然而既有方法多為靜態系統。本文提出 AutoDesign，由 meta-harness optimizer 根據 rollout feedback 引導 code agent 遞迴改進 harness。作者以學術論文轉海報為實例，建立涵蓋五個學科、100 篇論文的 PosterBench Main Track，以及用於受控評估的10篇 PosterBench-mini。在 Main Track 中，AutoDesign 得分78.32，較封閉商用系統 Claude Design 高7.45分。七種受控 code-agent/model 設定中，加入學得的 DesignHarness 後，平均分數由54.99升至67.39，增加12.4分。全自主長視域流程在40分鐘內完成253次工具呼叫與11輪編輯，成本低於3美元；盲測人評亦顯示其獲得最高偏好。

## 問題背景

多模態設計需要長流程地擷取來源證據、組織高密度內容、完成渲染並維持可用性，而非只改善一次輸出。既有 paper-to-poster 方法多分別評估 layout、extraction、faithfulness 或 visual quality，且設計系統通常把 feedback 視為一次性訊號，無法累積成可重用、符合人類設計偏好的 harness 能力。

## 解決方案

作者提出 AutoDesign，將 design harness 本身而非模型權重作為優化對象。系統以內層 artifact revision 與外層 harness evolution 組成巢狀迴圈：內層透過來源擷取、可編輯 HTML、規則驗證及 VLM critic 反覆修訂；外層由 meta-harness optimizer 分析多次 rollout 的軌跡與評分，讓 code agent 每輪只提出一個 functional component 的程式更新，再以 training gain 與 development retention 的 acceptance gate 決定是否採用。持續累積的更新形成 DesignHarness，使人類設計先驗、來源 provenance、品質檢查與修訂經驗成為可重用的系統能力。

## 核心貢獻
1. 提出 AutoDesign meta-harness optimization，透過 rollout、評估、單一元件更新與 acceptance gate，遞迴改進固定模型周邊的 design harness。
2. 建立可編輯、具來源脈絡的 DesignHarness，結合 paper ingestion、HTML 生成、rule-based validator、VLM critic、局部修訂與候選版本選擇。
3. 提出 PosterBench，涵蓋100篇、五個學科與七維評分，並以 PosterBench-mini、受控消融及 system-blind human study 評估系統品質。

## 技術方法

AutoDesign 將系統分成內外兩層迴圈。Design harness H 在固定底層模型參數 πθ 下，把 paper.pdf 與設計條件轉成 editable HTML artifact；其五個功能元件為 Context and Memory、Tools and Specifications、Execution Runtime、Orchestration，以及 Evaluation and Feedback。內層由 designer code agent 產生或局部修訂 artifact，並接受 rule-based validator 與 VLM critic 的回饋；validator 檢查資產、provenance、overflow、overlap、字體與版面等 blocking constraints，critic 評估渲染後的 layout、readability、aesthetics 與設計符合度，最多進行 K=12 次 refinement，最後選出最佳有效候選並輸出 HTML、PNG、PPTX 或 MP4。外層 meta-harness optimizer 先在 training tasks 上 rollout，收集 execution trajectories、分數與 optimization record，再由 planner 分析反覆失敗，派遣 subagents 整理證據，接著由 code editor 僅修改五個 functional components 中的一個。候選 harness 必須同時滿足 training objective 嚴格提升、development objective 不下降，才通過 acceptance gate；否則保留原版本。優化時間的 Rmeta 由人類標註 reference artifacts 建立，結合規則檢查與 VLM 判斷，並在自主迭代中固定；最終比較則使用獨立凍結的 PosterBench。PosterBench 對每篇海報評估 Faithfulness、Coverage、Density、Visual Evidence、Layout、Readability、Aesthetics 七維，權重為10/10/15/10/20/25/10，套用 layout、viability、failure 與 render-integrity ceilings 後取100篇平均。另以PosterBench-mini進行七種設定的 harness 消融，並以11位 reviewer 的 system-blind pairwise comparison 進行人類驗證。

## 關鍵結果

| 評估或設定 | 結果 |
|---|---|
| PosterBench Main Track，AutoDesign + Claude Code + Claude 4.8 | **78.32** |
| Claude Design，同一主評估比較 | 70.87；AutoDesign 高 **7.45** 分 |
| OpenDesign，同一主評估比較 | 69.45；AutoDesign 高 **8.87** 分 |
| PosterBench-mini，七種設定平均：未加入/加入 DesignHarness | 54.99 → 67.39，增加 **12.40** 分 |
| DesignHarness 對七種 code-agent/model 設定的增益 | **5.0–19.6** 分；最佳整體分數 81.5 |
| PosterBench-mini，Codex 設定：原生 Codex / AutoDesign | 75.87 / 81.46 |
| PosterBench-mini，Claude Code 設定：原生 / AutoDesign | 69.55 / 74.56 |
| 全自主長視域生成流程 | 253次工具呼叫、11輪編輯、約40分鐘、低於3美元 |
| System-blind human study | 933次有效排名；Bradley–Terry 偏好估計 **64.0%**，95%區間55.2–77.8% |

上述結果支持：優化可重用的 DesignHarness，不只改善單一 artifact，也能在多種固定 code-agent/model 組合上帶來一致提升；人評則提供自動 PosterBench 之外的獨立驗證。

## 對我們的啟發
- [ ] 若模型權重固定，仍可藉由改進 context/memory、工具規格、runtime、orchestration 與 feedback 機制，取得跨模型的系統性增益。
- [ ] 將可編輯 artifact、來源定位、規則驗證與視覺批評組成內層迴圈，有助於把局部錯誤修復轉化為可重複的生產流程。
- [ ] 訓練集增益加上 development retention 的 acceptance gate，可作為 harness 演化的基本防過擬合機制；但實務部署仍應維持獨立且凍結的外部評估。

## 限制與未來工作

論文目前主要以 paper-to-poster 驗證，PosterBench 雖涵蓋100篇論文，仍不能代表所有多模態媒體與長視域任務。更新每次只限一個 harness functional component，且自主搜尋可能過早停滯，需要 human guidance 重新導向。外部評估含 VLM judgment；人評名義 Krippendorff agreement 僅0.101。作者將 slides、webpages、videos 的格式適配與各自 rendering、communication release gate 列為未來方向。
