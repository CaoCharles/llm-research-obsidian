# Efficient Evaluation of LLM Performance with Statistical Guarantees

## 連結

## 摘要（中文翻譯）

大規模評估眾多大型語言模型（LLMs）在大量基準測試上的表現代價高昂。本文將基準測試框定為有限母體推斷（finite-population inference）問題，在固定查詢預算下尋求具有有效頻率論覆蓋率（frequentist coverage）的緊密信賴區間。作者提出因子化主動查詢（Factorized Active Querying, FAQ），其特點包括：(a) 透過貝葉斯因子模型利用歷史資訊；(b) 使用混合方差縮減/主動學習的抽樣策略自適應選擇問題；(c) 透過主動式主動推斷（Proactive Active Inference）——active inference 的有限母體擴展——維持統計有效性，同時支持直接問題選擇。在可忽略的額外開銷下，FAQ 在兩個基準測試套件上實現高達 5 倍的有效樣本量增益，即以最多 5 倍少的查詢量達到與均勻抽樣相同的信賴區間寬度。

## 問題背景

全面評估大量 LLM 在多個基準測試上的表現計算成本極高——每個模型-問題組合都需要一次推理，模型數量和基準規模的乘積使得完整評估不切實際。現有方法要麼犧牲統計嚴謹性（如只測部分問題但無信賴區間），要麼效率低下（如均勻抽樣需要大量查詢才能獲得窄信賴區間）。

## 解決方案

提出 FAQ（Factorized Active Querying）框架，將 LLM 基準測試形式化為統計推斷問題。核心創新在於三個組件的融合：(1) 貝葉斯因子模型利用已有評測結果的結構性（模型和題目間的低秩關係）來預測未觀察的結果；(2) 主動抽樣策略在每步選擇最能降低目標信賴區間寬度的查詢；(3) Proactive Active Inference 保證在自適應抽樣下信賴區間仍具有有效的頻率論覆蓋率。

## 核心貢獻
1. 將 LLM 基準測試形式化為有限母體推斷問題，提出結合因子模型和主動學習的 FAQ 框架
2. 開發 Proactive Active Inference 方法，解決自適應抽樣下信賴區間覆蓋率失效的技術挑戰
3. 實現 5 倍有效樣本量增益且保持統計有效性，開源程式碼和資料集支持可重現研究

## 技術方法

FAQ 框架的技術實現分為三個階段。首先，因子模型建構：將模型-問題的結果矩陣分解為低秩因子結構，利用已有的歷史評測數據（允許存在缺失值）學習模型能力向量和題目難度向量。因子模型提供未觀察結果的後驗預測分佈。

其次，主動抽樣策略：在每一步，框架計算所有未查詢的模型-問題組合對目標信賴區間寬度的預期縮減，選擇縮減最大的組合進行查詢。這結合了兩個信號：方差縮減（選擇不確定性最大的查詢）和主動學習（選擇最具資訊量的查詢）。

最後，統計有效性保證：Proactive Active Inference 擴展了 Zrnic & Candès (2024) 的 active inference 框架到有限母體設定，核心是在自適應數據收集過程中構建 e-values 序列，透過 anytime-valid 推斷保證信賴區間在任意停止時間都具有有效覆蓋率。實驗在 HELM 和 Open LLM Leaderboard 兩個基準套件上進行，比較了 FAQ 與均勻抽樣、分層抽樣等基準方法。

## 關鍵結果

| 方法 | 有效樣本量增益 | 覆蓋率有效性 | 需要歷史數據 |
|------|---------------|-------------|-------------|
| 均勻抽樣 | 1× (基準) | 有效 | 否 |
| 分層抽樣 | ~1.5-2× | 有效 | 否 |
| FAQ (無歷史) | ~2-3× | 有效 | 否 |
| FAQ (有歷史) | 最高 5× | 有效 | 是 |
| 純因子模型 | 高 | 不保證 | 是 |

| 基準套件 | 均勻抽樣 CI 寬度 | FAQ CI 寬度 | 查詢節省 |
|----------|------------------|------------|----------|
| HELM | 基準 | 相當 | 最高 80% |
| Open LLM Leaderboard | 基準 | 相當 | 最高 80% |

## 對我們的啟發
- [ ] LLM 基準測試應被視為統計推斷問題而非窮舉計算——主動抽樣可在保持統計嚴謹性的前提下節省 80% 計算成本
- [ ] 歷史評測數據的結構性資訊（模型-題目的低秩關係）是大幅提升評測效率的關鍵資源，排行榜間應共享數據
- [ ] Proactive Active Inference 為自適應評測提供了嚴格的統計保證，這一方法論可推廣到任何需要自適應數據收集的評測場景

## 限制與未來工作

FAQ 的效率增益依賴模型-問題結果矩陣的低秩假設，對於能力高度異質的模型集合效果可能下降。歷史數據的缺失程度影響因子模型的預測品質。此外，框架目前專注於選擇題基準，對開放式生成任務的擴展需要不同的準確度定義。
