# Agentic AI for Discovering Fault-Tolerant Quantum Circuits

## 連結
- 📄 [arXiv](https://arxiv.org/abs/2611.18504)
- 📥 [PDF](https://arxiv.org/pdf/2611.18504v1)

## 摘要（中文翻譯）

將量子計算擴展至實用的 quantum advantage，目前受到量子錯誤更正碼上運作之電路效率的限制。完整的量子計算堆疊包含邏輯碼態準備、邏輯閘實作，以及編碼量子位元上的邏輯例程等任務；然而，這些電路大多針對個別案例以人工設計，近期才有部分工作導入 machine learning。本文將問題形式化為 agentic evolutionary program synthesis：大型語言模型（LLM）利用預訓練知識與工具使用能力，在 circuit verifier 的引導下演化定義 Clifford circuit 的程式，處理邏輯狀態準備、邏輯閘設計、code-switching、code growth 等多種任務。作者表示，方法能穩定找到各類 fault-tolerant circuits，且每個電路都經由涵蓋故障事件的 exhaustive check 驗證。

## 問題背景

論文處理量子錯誤更正碼中 fault-tolerant circuit 的自動設計問題，涵蓋邏輯狀態準備、邏輯閘與更高階邏輯例程。既有方法多依賴人工設計；SAT 方法主要處理小型狀態準備，reinforcement learning 研究則多限於 distance-five 以下或尚未延伸至邏輯閘與複合例程，且一般 LLM 的 one-shot 電路生成尚未成功處理 fault tolerance。

## 解決方案

作者提出 hybrid agentic FunSearch，將 LLM 作為程式變異算子，將 Python function 視為量子電路程式，並透過 verifier 反覆評分與回饋。LLM 不只提交候選程式，也能直接呼叫 verifier 與一般 Python 工具測試、修改及比較方案；演化搜尋則以多個 islands 保存候選程式、週期性遷移最佳解，並把驗證指標、packed circuit 與 scratchpad notes 回饋至後續提示。核心創新是把 agentic tool use、演化程式搜尋與 exhaustive fault verification 結合，並以 dynamic Clifford circuits、mid-circuit measurement 及 conditional Pauli feedforward 支援非 post-selection 的邏輯操作。

## 核心貢獻
1. 提出 agentic FunSearch 框架，將具工具呼叫能力的 LLM、演化式程式搜尋與 circuit verifier 結合，用於自動發現 fault-tolerant Clifford circuits。
2. 將搜尋範圍從 logical state preparation 擴展至 logical gate design，以及 code-switching、code growth 等 higher-level logical routines，並支援不同 QEC codes 與 qubit connectivity。
3. 設計以 exhaustive fault enumeration、flag detector、residual reduced weight 與 decoder bin 為核心的驗證和排序機制，並展示多個電路在深度或 two-qubit gate 數上優於所列既有結果。

## 技術方法

方法以 stabilizer tableau 表示 n-qubit stabilizer state，候選程式透過自訂 Python circuit API 建立 Clifford gates、Z-basis ancilla measurement，以及依測量結果 parity 條件執行的 X/Z gates。Prompt 指定 QEC code、[[n,k,d]] 參數、目標 stabilizers、資料與 ancilla 佈局、可用耦合與 gate set，邏輯閘則以 channel-state duality 轉為 logical Choi-state preparation。Verifier 先對所有測量分支檢查目標是否達成、資料是否與 ancilla disentangle，再枚舉 input、gate 與 measurement faults；對 distance d 的 code，檢查 fault order i≤t=⌊(d−1)/2⌋，並依 residual 的 reduced weight、detector pattern、後續 syndrome 與 decoder bin 判定。狀態準備採 post-selection，依序最小化 silent-cost、depth、herald 與 waste；邏輯閘及 code routines 則避免一般性丟棄，使用 flag detectors 與 syndrome correction，依序評估 silent-cost、undecodable-cost、forfeit-cost、depth。搜尋在多個 islands 上進行，每代由 LLM 產生、工具驗證並排名候選，最佳程式與 scratchpad notes 持續回饋；論文使用 GPT-6-luna 作為 base、GPT-6.1-sol 的 high 與 xhigh 作為 strong、elite tiers。

## 對我們的啟發
- [ ] 對可驗證的科學與工程搜尋問題，讓 LLM 產生候選程式並由獨立 verifier 決定有效性，比依賴一次性生成更適合處理嚴格約束。

- [ ] 評估不應只使用單一效率指標；本文以 lexicographic score 同時處理 correctness、fault tolerance、depth、detector 代價與 two-qubit gate 數，適合延伸至多目標電路最佳化。

## 限制與未來工作

研究聚焦 dynamic Clifford circuits 與 stabilizer formalism，故不涵蓋一般 non-Clifford 電路。驗證採論文設定的 Pauli fault、measurement fault 與 flag fault-tolerance 模型，未等同於所有實體硬體雜訊。搜尋成本、各 tier 的呼叫量與整體成功率論文未提供完整統計；部分結果依賴 all-to-all 或特定佈局，泛化範圍仍需進一步驗證。
