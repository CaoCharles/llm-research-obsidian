## 重點發現

- 若將 LLM 限定於異質訊號的判斷與提案，並把 budget feasibility 交給 deterministic optimizer，可降低語言模型產生數值不合法配置的風險。 — [CORAL: An LLM-Native Harness for Production Recommender Systems](https://arxiv.org/abs/2609.02730)
- 在長上下文 RAG 或 agent tool-use 系統中，可將文件段落、對話輪次或工具回應作為可尋址 segment，讓模型先導航、再聚焦擷取、最後以 local mode 推理，降低反覆讀取整個 context 的成本。 — [Language Models Can Control Their Own Attention](https://arxiv.org/abs/2609.02737)
- 若團隊會持續加入 embedding 或 query variants，可先以 3–5 個系統建立基礎 pool，之後只評估新系統帶來的 unique (query, document) pairs，以降低重複成本。 — [Incremental Pooled LLM Evaluation for Cost-Effective Retrieval Model Selection](https://arxiv.org/abs/2609.02745)
- 若反思內容的正確性取決於隱藏環境狀態、執行結果或 repository 測試，實務上應優先導入 environment-grounded verifier，而非只增加 text-only critic 的模型能力。 — [Bilevel Coordinated Reflection: A Game-Theoretic Approach to Multi-Agent LLM Systems](https://arxiv.org/abs/2609.02750)
- RACG 的安全邊界不只在模型與 prompt，也包括資料匯入、公共程式碼來源、版本更新與知識庫建立流程；實務上應對外部條目進行來源驗證、漏洞掃描與人工抽查。 — [CodePoisonRAG: Knowledge Poisoning Attacks on Retrieval-Augmented Code Generation](https://arxiv.org/abs/2609.02774)
