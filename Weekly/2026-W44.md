- 對採用固定 vision encoder 的 retrieval、filtering、indexing 或 nearest-neighbor 系統，不應將 raw embedding similarity 視為充分的語義證據；可加入影像內容驗證或多模型一致性檢查。 — [SPOOK: Sparse Pixel Optimization for Off-Manifold Knowledge in Vision Encoders](https://arxiv.org/abs/2610.32835)
- 若知識由具備穩定 provenance 的 agent 產生，可優先在 artifact、service、domain 與 workflow 層建立可導航結構，避免一開始就承擔完整 entity-level ontology 的對齊成本。 — [Reimagining Enterprise RAG for Multi-Agent Systems: A Knowledge Layer That Organizes Before It Retrieves](https://arxiv.org/abs/2610.32851)
- 若 fine-tuning 的安全審計需求很高，可考慮採用具固定稀疏路由的 adapter，使更新本身更容易被分解、排名與介入；但論文只在 syntactic trigger 的受控 model organisms 中驗證。 — [Interpretable sparse fine-tuning with TopKLoRA enables faithful circuit discovery](https://arxiv.org/abs/2610.32866)
- 當生成機率會成為下一輪 agent state 時，評測不應只看 calibration、accuracy 或 schedule robustness；應對完整 request 做 paired complement probe，並追蹤不一致是否在 feedback 中改變軌跡。 — [Do "True" and "False" Add Up to One? Complement Consistency in LLM-Agent Opinion Simulations](https://arxiv.org/abs/2610.32874)
- 若 RL 訓練反覆重用相同 prompts，應優先檢查跨 step 或 epoch 的 prompt-conditioned temporal locality，而不只依賴單次 context lookup；這可作為 rollout acceleration 的工程切入點。 — [NgramRL: Accelerating RL Post-Training for Structured Generation via Rollout-Aware N-gram Speculative Decoding](https://arxiv.org/abs/2610.32881)
